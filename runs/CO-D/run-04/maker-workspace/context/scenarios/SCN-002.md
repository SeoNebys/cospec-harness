Scenario ID: SCN-002
Title: Open a saved link to return to the page
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Clicking anywhere on a saved link's card opens the real website in a new browser
tab. The library page stays open behind it, so the client does not lose their
place. This is the core "getting back to the page" purpose of the library.

## Gherkin
Feature: Open a saved link

  Scenario: Clicking a card opens the real page
    Given a saved link is shown in the library
    When the client clicks anywhere on its card
    Then the real website opens in a new browser tab
    And the library remains open in the original tab

## Assumptions
- The whole card is the click target, not just the title. (client confirmed)
- Opens in a new tab, not the same tab. (client confirmed)
