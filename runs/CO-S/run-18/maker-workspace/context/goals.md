# Cycle 1 goal

## Client statement

> Honestly, right now saving a link is a pain and finding it again later is worse. So a few things would make my life easier:
>
> When I save a link, I'd love the app to just grab the page's title and a bit of description on its own, so I'm not typing all that out. I want to paste a URL and be mostly done.
>
> Then I need to actually find things later. So being able to put tags on links, filter by a tag, and search across everything — not just titles but my notes and the web address too — matters a lot. If I save the same link twice, I don't want a duplicate; it should just take me to the one I already have.
>
> I'd also like a "read later" pile I can look at separately and clear out as I get to things, and a way to tidy up — set links aside without deleting them forever, versus actually deleting them for good.
>
> The list itself should be easy to read at a glance and clicking a link should take me to the actual page.
>
> That's the heart of it. There are some nice-to-haves too, but that's what would change my day-to-day.

## Confirmation and clarification

> Yes, that's the right direction. You've captured what matters most to me.
>
> One small thing to keep in mind under search: when I said broad search, I do mean I want to search by tags too, not only plain text. And when I put tags on a link, it'd help if the app suggested tags I've already used so I'm not reinventing names.
>
> But you've got the heart of it right — that's exactly what I'm after.

## Confirmed direction

Saving a link should be nearly effortless, and finding or acting on it later should be reliable. The core includes automatic page titles and descriptions, tags with suggestions from previously used tags, search across titles, notes, URLs, and tags, duplicate prevention that returns the existing bookmark, a separate read-later flow, archiving versus permanent deletion, and a scannable list whose links open the original pages.

## Interface form

> A web app would suit me best — something I can open in my browser on my computer. That's where I usually am when I'm saving and looking up links. It's just for me, so I don't need anything fancy for other people.

Confirmed as a personal web app used in a computer browser.
