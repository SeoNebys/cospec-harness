Scenario ID: SCN-017
Title: Show a usable library after deleting the last bookmark
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
After the last bookmark is permanently deleted, the All, Unread, and Archived
counts each show zero. The bookmark area plainly says that nothing is there yet,
while the library views remain available so the person can continue using the
app and save again.

## Gherkin
Feature: Empty bookmark library

  Scenario: Permanently delete the last bookmark
    Given the library contains one active bookmark
    When the person permanently deletes that bookmark and confirms
    Then the All count is zero
    And the Unread count is zero
    And the Archived count is zero
    And the bookmark area says that nothing is there yet
    And the library views remain available

## Assumptions
- Empty counts are shown explicitly as zero.
- The empty library remains ready for another bookmark to be saved.
