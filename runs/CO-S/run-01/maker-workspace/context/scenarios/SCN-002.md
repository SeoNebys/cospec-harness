Scenario ID: SCN-002
Title: Find a saved link by typing; live filtering across title and site
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The client types into a search box and the saved-links list narrows live with
each keystroke — no Enter key or search button, no waiting. The search matches
against both the page title (headline) and the site address (host), and the
matching text is highlighted in the results. A count of matches is shown. The
client explicitly prefers live filtering over type-then-Enter, and confirmed
that matching title + site covers what they would reach for.

## Gherkin
Feature: Finding a saved link by search

  Scenario: Live filtering as the client types
    Given the client has several saved links
    When the client types text into the search box
    Then the list narrows to matching links after each keystroke
    And no Enter press or search button is required

  Scenario: Match on title or site address
    Given the client has saved links with various titles and sites
    When the client types a term found in a page title
    Then links whose title contains the term are shown with the term highlighted
    When the client types a term found in a site address
    Then links whose site contains the term are shown with the term highlighted

## Assumptions
- Search matches page title and site host (not full page contents).
- Matching is case-insensitive substring; matched text is highlighted.
- A match count is displayed.
- (Prototype-only) the list was pre-seeded with example saved links.
