Scenario ID: SCN-012
Title: Bulk selection and actions on multiple links
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Each card has a selection checkbox. Selecting one or more links reveals a bulk
action bar showing the count and offering: add a tag (with existing-tag
suggestions as the client types), remove a tag (a menu of tags present across the
selection), mark as read, mark as To read, and archive. A "Select all N matching"
control selects every link matching the current view, search, and tag filters —
the whole matching set, not merely a visible page. Permanent deletion is offered
only in the Archived view, behind a confirmation. Selection behaviour after an
action: links that remain visible in the current view stay selected (e.g. adding
or removing a tag that doesn't remove them from view), while links that leave the
current view — marked read while in To read, archived, or deleted, or a tag
removed while filtering by that tag — are dropped from the selection so no
invisible links stay selected.

## Gherkin
Feature: Bulk actions

  Scenario: Select several and add a tag with suggestions
    Given several links are shown
    When the client ticks two and types into the bulk add-tag box
    Then existing matching tags are suggested
    And choosing one adds it to both selected links
    And both remain selected because they are still visible

  Scenario: Select all matching the current scope
    Given a view, search, or tag filter is active
    When the client chooses "Select all N matching"
    Then every link matching that scope is selected, not only a visible page

  Scenario: Selection clears for links that leave the view
    Given links flagged To read are selected in the To read view
    When the client marks them read
    Then they leave the To read view
    And they are dropped from the selection

  Scenario: Bulk archive and archive-only bulk delete
    Given links are selected in a main view
    When the client archives them
    Then they move to Archived and drop from the selection
    And bulk permanent delete is available only in the Archived view, behind a confirmation

## Assumptions
- "Select all N matching" == all links matching the current view + search + tag
  filters (independent of any future links-per-page limit).
- Bulk delete is confined to the Archived view with confirmation (same safeguard
  as single-link deletion).
- After an action, the selection is pruned to links still visible in the current view.
