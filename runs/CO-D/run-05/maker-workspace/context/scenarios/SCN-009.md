Scenario ID: SCN-009
Title: Pasting something that isn't a link
Type: Error Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When the client tries to save something that isn't a web link (e.g. "asdf"), the app does
not save it and shows a gentle inline nudge — the input turns pink with a one-line plain
explanation ("that doesn't look like a web link yet — it should include something like
.com"). No jarring popup. The client: "a big alarming popup for a simple typo would feel
like being scolded."

## Gherkin
Feature: Rejecting non-links gently

  Scenario: Non-link input
    Given the save box contains text that is not a web link
    When I press Save
    Then nothing is saved
    And a gentle inline message explains what's wrong
    And no modal popup appears

## Assumptions
- "Looks like a link" is judged loosely (has a dot / a hostname); the client can type
  without the "https://" prefix.
