Scenario ID: SCN-003
Title: Saving a link that is already saved does not create a duplicate
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When the client enters a link that is already saved, the app does not create a
second bookmark. It tells the client the link is already saved and takes them
to the existing bookmark, opening it for editing so they can update its tags,
note, or other details. Nothing on the existing bookmark is overwritten
automatically; the client makes any changes themselves.

## Gherkin
Feature: Prevent duplicate bookmarks

  Scenario: Entering an already-saved link
    Given a bookmark for a given link already exists
    When the client enters that same link to save
    Then no duplicate bookmark is created
    And the app informs the client the link is already saved
    And directs the client to the existing bookmark opened for editing
    And no existing detail is overwritten automatically

## Assumptions
- Links are matched ignoring protocol, "www.", and trailing slashes.
