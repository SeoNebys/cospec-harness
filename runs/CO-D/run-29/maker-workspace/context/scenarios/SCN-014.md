Scenario ID: SCN-014
Title: Prevent duplicate tags regardless of letter case
Type: Edge Case
Approval status: approved
Approval session: SESSION-014
Approval cycle: 1

## Approved behaviour
Entering a tag that is already attached to the bookmark, using any combination of capital and lowercase letters, does not create another tag pill. The established spelling remains, and a clear message states that the tag is already added.

## Gherkin
Feature: Keep bookmark tags unique

  Scenario: Enter an existing tag using different letter case
    Given a bookmark already has the tag `travel`
    When the client enters `TRAVEL`
    Then no second tag pill is created
    And the existing `travel` spelling remains
    And the editor explains that the tag is already added

## Assumptions
- Tag uniqueness comparisons ignore letter case.
- Existing tag spelling is not rewritten by a duplicate entry.
