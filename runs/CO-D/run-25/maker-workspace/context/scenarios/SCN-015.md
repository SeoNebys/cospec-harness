Scenario ID: SCN-015
Title: Exclude search results with not
Type: Happy Path
Approval status: approved
Approval session: SESSION-015
Approval cycle: 1

## Approved behaviour
The person can place "not" before a search condition to exclude every bookmark matching that condition. It works with exact label conditions as well as the other searchable information.

## Gherkin
Feature: Combining bookmark searches

  Scenario: Exclude bookmarks carrying a label
    Given two bookmarks carry the label "Reference"
    And one bookmark does not
    When the person searches for "not #reference"
    Then only the bookmark without the "Reference" label is shown

## Assumptions
- Search command words ignore capitalization.
