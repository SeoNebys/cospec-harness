Scenario ID: SCN-015
Title: Sort the list, and see each link's saved date
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The client can change the order of the list to cope with volume: Newest first
(default), Oldest first, and Title A–Z. Sorting applies to whatever is currently
shown (all links, a search result, a label filter, or the reading pile). Each
link shows its saved date — kept small and quiet so it informs without competing
with the title and summary. The date now earns its place by driving the sort;
imported links sort by their preserved original dates.

## Gherkin
Feature: Sort and dates

  Scenario: Sort oldest first surfaces the oldest links
    Given links with a range of saved dates, including old imported ones
    When the client sorts "Oldest first"
    Then the links with the earliest dates appear at the top

  Scenario: Sort by title
    When the client sorts "Title A–Z"
    Then links are ordered alphabetically by title

  Scenario: Default order is newest first
    Given no sort is chosen
    Then the most recently saved links appear at the top

## Assumptions
- Three sort orders: Newest, Oldest, Title A–Z (client's core set).
- "By recently opened" is a parked welcome-bonus order (see goals parking lot).
- Saved date is shown subtly on each card (was NF-2; now promoted to visible
  because it drives sorting).
