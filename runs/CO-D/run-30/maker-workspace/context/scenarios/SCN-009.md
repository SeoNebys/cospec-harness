Title: Attach labels while initially saving a bookmark
Type: Happy Path
Approval status: approved
Approval session: SESSION-009
Approval cycle: 1

## Approved behaviour

After a pasted link is recognized and its editable title and description appear, the same save pop-up also presents the approved label picker. The client can reuse an existing label, create a personal label, and attach several labels before saving. The resulting card shows all selected labels. No separate labeling step is required.

## Gherkin

Feature: Saving bookmarks with labels

  Scenario: Label a bookmark during its initial save
    Given the user has pasted a valid link into the save pop-up
    When the page title and description appear automatically
    Then the label picker appears alongside those editable details
    When the user selects "Recipes"
    And creates and selects "Weekend plans"
    And saves the bookmark
    Then the new card shows both "Recipes" and "Weekend plans"

## Assumptions

- The same label picker is used during initial saving and later editing.
- Label selection becomes available after the link has been recognized.
