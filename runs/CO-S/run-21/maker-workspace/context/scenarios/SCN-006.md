Scenario ID: SCN-006
Title: Filter the collection by clicking a bookmark tag
Type: Happy Path
Approval status: approved
Approval session: SESSION-006
Approval cycle: 1

## Approved behaviour
Clicking a tag displayed on a bookmark narrows the collection to only bookmarks carrying that tag. The focused collection is named after the selected tag and shows the number of matching bookmarks.

## Gherkin
Feature: Find bookmarks by tag

  Scenario: Focus the collection on a bookmark tag
    Given the collection contains bookmarks with different tags
    And two bookmarks carry the tag "Design"
    When the person clicks the "Design" tag on a bookmark
    Then only bookmarks carrying "Design" remain visible
    And the focused collection heading is "Design"
    And the result count shows two matching bookmarks

## Assumptions
- A tag displayed on a bookmark is directly clickable.
- Tag filtering applies one selected tag at a time in this flow.
