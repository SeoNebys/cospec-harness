# Non-functional backlog

- Keep common saving and organizing actions low-effort, with minimal extra decisions.
- Keep collection views scannable even when the collection and individual bookmarks contain abundant information.
- Use calm, plain-language feedback for empty states and correctable errors.
- Preserve visible context and user-entered text when an action fails or needs correction.
- Let the person choose how many bookmarks appear at once.
- Let the person choose their default collection order.
- Let the person choose a comfortable text size.
