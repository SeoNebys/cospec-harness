Scenario ID: SCN-006
Title: Save-time problems — missing title, duplicate link, non-link input
Type: Error Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

Title could not be fetched: the link is still saved (saving is never blocked by
a failed title fetch). It shows the site name with a "title not found" flag and
an inline "add a name" action so the client can immediately give it a
recognizable name. Client confirmed: do not block on failed title; easy inline
naming is the right fix.

Saving a duplicate link: if the same link is already saved, a second copy is NOT
created. A gentle "You already saved this link" notice appears with a "Show me
the one I saved" action that highlights the existing item. Client confirmed this
directly addresses their original "pile of repeats" problem.

Pasting something that is not a link: Save is blocked, nothing is saved, the
input is kept, and a gentle inline message explains it doesn't look like a link.
Client confirmed blocking with explanation is correct.

## Gherkin
Feature: Handling problems while saving

  Scenario: Page title cannot be fetched
    Given the client saves a link whose title cannot be retrieved
    Then the link is still saved showing the site name
    And it is flagged that the title was not found
    And an inline action lets the client give it a recognizable name

  Scenario: Saving a link that is already saved
    Given a link is already in the library
    When the client tries to save the same link again
    Then no duplicate is created
    And a notice says the link is already saved
    And an action highlights the existing saved link

  Scenario: Pasting input that is not a web link
    Given the client enters text that is not a link
    When the client presses Save
    Then nothing is saved and the input is kept
    And a gentle message explains it does not look like a link

## Assumptions
- Duplicate detection is by the link address (same URL = duplicate).
- "Not a link" is judged by a basic address-shape check.
- A saved link with no fetched title is allowed to exist until named.
