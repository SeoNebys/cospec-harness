Scenario ID: SCN-007
Title: Empty and no-result states
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

Each place that can be empty shows a clear, friendly message rather than a blank
or confusing area:
- A new collection with nothing saved shows a "nothing saved yet" message; since
  the save form sits directly above it, this is enough of a nudge to save the
  first link (client confirmed no extra prompting is needed).
- An empty reading queue ("To read" view with nothing left) shows a "reading
  queue is clear" message.
- An empty archive shows a message explaining how to archive a link.
- A search or topic filter with no matches shows a "no links match" message
  (see SCN-002).

## Gherkin

Feature: Empty and no-result states

  Scenario: New, empty collection
    Given I have no saved links
    Then a clear "nothing saved yet" message is shown above which the save form appears

  Scenario: Empty reading queue
    Given every link is marked read
    When I view the "To read" queue
    Then a "reading queue is clear" message is shown

  Scenario: Empty archive
    Given I have no archived links
    When I open the archive
    Then a message explaining how to archive a link is shown

## Assumptions

- Empty states are plain informative messages; no extra onboarding prompts are
  required (client confirmed the message plus the always-visible save form is
  enough).
