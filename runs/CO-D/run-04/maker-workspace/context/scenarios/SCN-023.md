Scenario ID: SCN-023
Title: Oversized content stays tidy (long text, many labels)
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Very long titles, descriptions, notes, and links carrying many labels never
break the layout or let one link hog the screen (protecting the scannability
that was the client's first concern). In the list: titles wrap, the description
is clamped to two lines, notes wrap, and labels flow onto multiple rows rather
than pushing the card sideways. Crucially, clamping is cosmetic only — the FULL
description (and all content) is still there and fully visible when the client
opens or edits the link; nothing is lost, just tidied in the list.

## Gherkin
Feature: Oversized content

  Scenario: A link with very long text and many labels
    Given a link with an over-long title, description, note and many labels
    When it is shown in the list
    Then the title and note wrap, the description is clamped to two lines,
         and labels flow onto multiple rows without breaking the card
    When the client opens or edits that link
    Then the full untruncated description and content are available

## Assumptions
- List clamping is display-only; full text preserved and reachable on open/edit.
  (client confirmed)
- Many labels wrap rather than overflow. (client confirmed)
