Scenario ID: SCN-006
Title: Search the library as a word is typed
Type: Happy Path
Approval status: approved
Approval session: SESSION-006
Approval cycle: 1

## Approved behaviour
As the user types in the library search field, the visible bookmarks narrow immediately. Search is case-insensitive and matches partial words found in bookmark titles, descriptions, website addresses, or tags, allowing a result to appear before the full word is entered.

## Gherkin
Feature: Search saved bookmarks

  Scenario: Find a bookmark from part of its description
    Given the library contains a bookmark whose description includes the word "focus"
    When the user types part of "focus" in the search field
    Then the library immediately narrows to matching bookmarks
    And the bookmark containing that partial word in its description is shown

  Scenario Outline: Search across saved bookmark details without case sensitivity
    Given a saved bookmark contains a searchable value in its <field>
    When the user types part of that value using different capitalisation
    Then the matching bookmark is shown

    Examples:
      | field           |
      | title           |
      | description     |
      | website address |
      | tag             |

## Assumptions
- Search results update on each change to the search field without a separate search action.
- An empty search field shows the full current library view.
- Matching is based on literal partial text rather than inferred meaning.
