Title: Filter and sort the everyday bookmark list
Type: Happy Path
Approval status: approved
Approval session: SESSION-005
Approval cycle: 1

## Approved behaviour

The everyday bookmark list opens with newest bookmarks first. Always-visible tag controls above the list immediately narrow it to bookmarks carrying the selected tag. A visible order control can sort the current list by date saved or title. The selected filter and order operate together, and the matching count and order are reflected in the displayed list.

## Gherkin

Feature: Filter and sort bookmarks

  Scenario: Filter by tag and show the oldest matches first
    Given the everyday list contains six bookmarks ordered newest first
    And three bookmarks have the tag "animals"
    When the user selects the visible "animals" tag filter
    Then only the three bookmarks tagged "animals" are shown
    When the user changes the order to "Oldest first"
    Then those three bookmarks are ordered from the oldest saved date to the newest

  Scenario Outline: Order the current bookmark list
    Given a bookmark list is visible
    When the user chooses <order>
    Then the visible bookmarks are ordered by <basis> in <direction> order

    Examples:
      | order        | basis      | direction          |
      | Newest first | saved date | newest to oldest   |
      | Oldest first | saved date | oldest to newest   |
      | Title A–Z    | title      | ascending          |
      | Title Z–A    | title      | descending         |

## Assumptions

- The everyday list defaults to newest first.
- Tag filters and the order control remain visible above the list.
- Selecting a tag filter updates the results immediately without a separate apply action.
- One tag filter is selected at a time in this scenario.
