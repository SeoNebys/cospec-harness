Scenario ID: SCN-002
Title: Add tags and a note while saving, with suggestions from existing tags
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

The save area shows, beneath the link box, an optional **Tags** field and an
optional **Note** field. The user captures the reason for saving in one step,
without a separate action after saving (this was chosen over adding tags/notes
afterward or via an auto-opening editor).

As the user types in the Tags field, the app **suggests existing tags** that
match what is typed, so near-duplicate tags are avoided. The user can pick a
suggestion instead of retyping it. When the typed text does not match an
existing tag, the suggestion list offers a clear **"Create …"** option so a
genuinely new tag is still easy to add; suggestions never block creating a new
tag.

Both Tags and Note are **optional** — a link can be saved with neither, keeping
quick saving quick. On Save, the item is stored with whatever tags/note were
entered, and the tags are shown as chips on the saved item; the note is shown in
its own highlighted area.

## Gherkin
Feature: Tag and annotate a link while saving

  Scenario: Save with an existing tag chosen from suggestions
    Given the user is saving a link
    And tags "reading" and "reference" already exist
    When the user types "re" in the Tags field
    Then the app suggests the existing tags "reading" and "reference"
    And the user can select one instead of typing it in full

  Scenario: Create a new tag while saving
    Given the user is saving a link
    When the user types a tag that does not match any existing tag
    Then the suggestion list offers a "Create …" option for that text
    And selecting it adds the new tag to the item

  Scenario: Save with a note
    Given the user is saving a link
    When the user types a note and presses Save
    Then the saved item shows the note

  Scenario: Save with neither tags nor a note
    Given the user is saving a link
    When the user leaves the Tags and Note fields empty and presses Save
    Then the link is saved without tags or a note

## Assumptions
- Tags and note are entered in the save area before pressing Save (Version B).
- Both fields are optional.
- Tag suggestions are drawn from the user's existing tags.
