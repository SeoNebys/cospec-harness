Scenario ID: SCN-018
Title: Reject an incomplete web address without guessing
Type: Error Case
Approval status: approved
Approval session: SESSION-018
Approval cycle: 1

## Approved behaviour

When the client attempts to save an incomplete address that does not begin with http:// or https://, the save pop-up stays open, no bookmark is created, and an inline message explains what a complete address looks like. The app does not guess or silently modify the address.

## Gherkin

Feature: Saving bookmarks

  Scenario: Enter an incomplete web address
    Given the save pop-up is open
    When the user attempts to save "seriouseats.com/recipe"
    Then no bookmark is created
    And the save pop-up remains open
    And the address field explains that a full address beginning with http:// or https:// is required
    And the entered address is not silently changed

## Assumptions

- Address correction is left to the client to avoid pointing a bookmark somewhere unintended.
