Scenario ID: SCN-003
Title: Browse saved links by group
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A list of groups is shown down the left side, plus an "All bookmarks" entry.
Clicking a group shows only the links in that group; clicking "All bookmarks"
shows everything. A link that belongs to several groups appears under each of
those groups. The client confirmed the same link correctly appeared under both
"Recipes" and "Read later", "which is exactly what I hoped for". Left-side group
list confirmed by the client.

## Gherkin
Feature: Browsing by group

  Scenario: Show links in a chosen group
    Given the user has saved links in several groups
    When the user clicks a group in the left-side list
    Then only the links belonging to that group are shown

  Scenario: A multi-group link appears under each of its groups
    Given a link belongs to two groups
    When the user browses either of those groups
    Then that same link is shown

  Scenario: Show everything
    Given the user has saved links
    When the user clicks "All bookmarks"
    Then links from every group are shown

## Assumptions
- Groups are listed on the left; "All bookmarks" is the default view.
- Within a view, newest-first ordering is retained (from SCN-001).
