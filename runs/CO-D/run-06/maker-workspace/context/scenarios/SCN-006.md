Scenario ID: SCN-006
Title: Search across saved bookmark details
Type: Happy Path
Approval status: approved
Approval session: SESSION-006
Approval cycle: 1

## Approved behaviour
As a person types in the collection search box, the visible bookmarks narrow immediately without a separate submit action. A bookmark matches when the search text appears in its title, short description, or web address. The collection shows how many bookmarks match out of the full collection.

## Gherkin
Feature: Finding saved bookmarks

  Scenario: Narrow the collection by search text
    Given the collection contains multiple saved bookmarks
    When the person types text that appears in a bookmark's title, short description, or web address
    Then the collection immediately shows only matching bookmarks
    And the collection shows the matching count out of the full count

## Assumptions
- Search updates as the person types.
- No separate search submission is required.
- Title, short description, and web address are searched together.
