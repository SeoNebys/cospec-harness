Scenario ID: SCN-004
Title: Browse bookmarks by label and return to the full library
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The library gathers all labels in the left sidebar with a count of bookmarks under each. Clicking a label either on a bookmark card or in the sidebar narrows the library to bookmarks carrying that label, changes the library heading to the selected label, and clearly highlights the active label. Clicking All bookmarks clears the label filter, restores the full library, and visibly selects All bookmarks again.

## Gherkin
Feature: Browse bookmarks by label

  Scenario: Filter from a label on a bookmark card
    Given the library contains bookmarks with different labels
    When the user clicks a label on a bookmark card
    Then only bookmarks carrying that label are shown
    And the library heading identifies the selected label
    And the corresponding sidebar label is visibly selected

  Scenario: Filter from the sidebar label list
    Given the sidebar lists labels with their bookmark counts
    When the user clicks a label in the sidebar
    Then only bookmarks carrying that label are shown

  Scenario: Return to the full library
    Given the library is filtered by a label
    When the user clicks All bookmarks
    Then all bookmarks are shown
    And All bookmarks is visibly selected in the sidebar

## Assumptions
- Every assigned card label is directly clickable.
- The sidebar is the persistent overview of available labels and their bookmark counts.
