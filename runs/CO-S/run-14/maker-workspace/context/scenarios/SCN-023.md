## Approved behaviour

A Preferences panel offers these display settings, applied live:
- **Appearance**: Light / Dark / Match system.
- **List density**: Comfortable / Compact (compact tightens cards and shrinks
  thumbnails).
- **Text size**: Small / Medium / Large (resizes titles and descriptions).
- **Show preview images**: on/off (off gives a cleaner text-only list).
- **Bookmarks shown per page**: 5 / 10 / 25 / 50 / All (see SCN-024).
- **Open to**: which view the app starts on (All / To read).
- **Default sort**: the starting sort order (mirrors the list's Sort control).
- **Automatically save a full-page copy of new bookmarks**: on/off (the setting
  for SCN-019).

## Gherkin
Feature: Display preferences

  Scenario: Change appearance
    When the user selects Dark or Match system
    Then the app re-themes accordingly

  Scenario: Change density, text size, previews
    When the user changes density, text size, or the show-previews setting
    Then the list updates live to reflect it

  Scenario: Set defaults for view and sort
    When the user sets "open to" and "default sort"
    Then the app opens on that view with that sort order

## Assumptions
- "Match system" follows the OS light/dark setting.
- Preferences persist for the user (single-user app).
