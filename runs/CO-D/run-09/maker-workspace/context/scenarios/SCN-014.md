Title: Sort the list and remember the chosen order
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A compact "Sort by" dropdown lets the user order the list by "Newest added",
"Oldest added", or "Title A–Z". Changing the order re-orders the list immediately.
The chosen order is remembered and used as the default the next time the app is opened
— there is no separate "make this my default" step. Sorting works together with search
and the status views. Newest added is the initial default before the user chooses.

The dropdown control was chosen over an always-visible segmented switch because the
client changes sort order only occasionally and prefers the more compact control.

## Gherkin
Feature: Sorting the list

  Scenario: Change the sort order
    Given saved links are shown
    When the user selects a sort order from the "Sort by" dropdown
    Then the list is reordered accordingly (newest added, oldest added, or title A–Z)

  Scenario: The chosen order is remembered
    Given the user selected a sort order
    When the user reopens the app later
    Then the list uses the previously chosen order as the default

  Scenario: Sorting combines with search and status views
    Given a search term and/or a status view is active
    When a sort order is chosen
    Then the shown links are ordered by that sort within the current search and view

## Assumptions
- Initial default before any choice is "Newest added".
- "Remembering" means keeping the last chosen order; no explicit set-default action.
