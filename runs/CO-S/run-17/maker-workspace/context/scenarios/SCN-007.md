Scenario ID: SCN-007
Title: Open a bookmark's original page in a new tab
Type: Happy Path
Approval status: approved
Approval session: SESSION-007
Approval cycle: 1

## Approved behaviour

The client clicks anywhere on a bookmark card to open its original page in a new browser tab. The full card is an easy target, and the separate tab leaves the bookmark library available behind it.

## Gherkin

Feature: Revisit saved pages

  Scenario: Open the original page from a bookmark
    Given a saved bookmark has an original page address
    When the user clicks the bookmark card
    Then the original page opens in a new browser tab
    And the bookmark library remains open in its existing tab

## Assumptions

- The whole bookmark card is clickable, except for controls that perform their own actions.
- Original pages open in a new browser tab.
