Scenario ID: SCN-008
Title: Empty states across the three views
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When a view has no bookmarks to show, a friendly, purposeful message is shown
instead of a blank area:
- All (nothing saved yet): "Nothing here yet. Paste a link above to start."
- Read later (none marked): "No bookmarks marked 'Read later' yet."
- Archived (none): "Nothing archived."
(The no-search-match empty state is covered in SCN-003.)

## Gherkin
Feature: Empty states

  Scenario: Brand-new user, nothing saved
    Given the collection is empty
    When the user views All
    Then a "Nothing here yet" message invites them to save a link

  Scenario: No read-later items
    Given no bookmarks are marked read later
    When the user opens the Read later view
    Then a "No bookmarks marked Read later yet" message is shown

  Scenario: No archived items
    Given no bookmarks are archived
    When the user opens the Archived view
    Then a "Nothing archived" message is shown

## Assumptions
- Each view has its own tailored empty message.
