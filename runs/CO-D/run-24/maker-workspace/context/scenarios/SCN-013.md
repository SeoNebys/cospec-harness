Scenario ID: SCN-013
Title: Save searches as named, live collections
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

The client can save the current search as a named collection. A collection is a
saved search (words and `#tags` to include, `NOT` to exclude) reusing the same
search language already approved — not a fixed hand-picked folder. The client
prefers this because bookmarks can start or stop matching as they are updated.

Saving: with a search active, a "Save current search" action opens a dialog with
the query pre-filled; the client names it and may tweak the include/exclude terms
before saving. Collections appear as chips in a "Collections:" row above the list.

Opening: clicking a collection chip applies its search live (switching to the
main list view and filling the search box so the applied filter is transparent)
and shows whatever currently matches — the result set is dynamic, never frozen.
A collection can be removed via an × on its chip.

## Gherkin

Feature: Collections (saved searches)

  Scenario: Save the current search
    Given a search is active
    When the client saves it with a name
    Then a collection chip with that name appears

  Scenario: Open a collection shows live matches
    Given a saved collection
    When the client opens it
    Then the current matches for its search are shown
    And the search box reflects the applied query

  Scenario: Collection reflects later changes
    Given a collection and a bookmark that does not currently match it
    When the bookmark is edited so it now matches
    And the client reopens the collection
    Then the bookmark is now included

  Scenario: Remove a collection
    When the client removes a collection
    Then its chip is gone and the underlying bookmarks are unaffected

## Assumptions

- A collection stores a name + a query string (the approved search language).
- Collections are live saved searches, not fixed folders.
- Removing a collection deletes only the saved search, not any bookmarks.
