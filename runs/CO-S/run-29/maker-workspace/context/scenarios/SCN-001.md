Scenario ID: SCN-001
Title: Save a named link from an empty collection
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
From an empty personal collection, the user can start with one clear “Add your first bookmark” action. A short form asks for a recognizable name and web address. Saving closes the form, shows the new bookmark as a card under “All bookmarks” with its name and address, increases the bookmark count, and gives a clear saved confirmation.

## Gherkin
Feature: Saving bookmarks

  Scenario: Open the save form from an empty collection
    Given the personal bookmark collection is empty
    When the user chooses to add their first bookmark
    Then a short bookmark form is shown
    And the form asks for a name and web address

  Scenario: Save a recognizable bookmark
    Given the user has opened the save form from an empty collection
    When the user enters the name “MDN Web Docs”
    And enters the web address “https://developer.mozilla.org”
    And saves the bookmark
    Then the form closes
    And a bookmark card named “MDN Web Docs” is shown under “All bookmarks”
    And the card shows the web address “https://developer.mozilla.org”
    And the collection count is 1 bookmark
    And a clear saved confirmation is shown

## Assumptions
- The collection belongs to one person and has no sharing or collaboration.
- This scenario begins with an empty collection.
- The supplied name and web address are valid.
- A bookmark is represented in the collection as a card.
- Saving is initiated by a prominent button that opens a short form.
