Scenario ID: SCN-003
Title: Find bookmarks with one search box across all fields
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A single search box searches across every part of a bookmark at once: title,
description, tags, note, and web address. Typing narrows the list live. Search
ignores capitalization. Typing several ordinary words narrows the results
further — a bookmark must contain all of the words (implicit AND). The count
shows "showing N of M" while a search is active. When nothing matches, a clear
"No bookmarks match …" message is shown instead of a blank list.

## Gherkin
Feature: Search across all fields

  Scenario: Search matches any field
    Given a collection of saved bookmarks
    When the user types a word that appears in a bookmark's title, description, tag, note, or address
    Then that bookmark is shown in the results

  Scenario: Case-insensitive
    Given a collection of saved bookmarks
    When the user types a word in any capitalization
    Then results are the same regardless of capitalization

  Scenario: Multiple words narrow (implicit AND)
    Given a collection of saved bookmarks
    When the user types several ordinary words
    Then only bookmarks containing all of the words are shown

  Scenario: Result count while searching
    Given a search is active
    Then the count reads "showing N of M"

  Scenario: No matches
    Given a search that matches no bookmarks
    Then a "No bookmarks match" message is shown instead of a list

## Assumptions
- Search updates live as the user types.
- Searchable fields are title, description, tags, note, and address
  (client-confirmed "one search box across everything").
