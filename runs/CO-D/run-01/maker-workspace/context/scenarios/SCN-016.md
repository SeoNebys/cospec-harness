Scenario ID: SCN-016
Title: Act on many links at once (bulk actions)
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The client can enter a deliberate "Select" mode (checkboxes are not shown the
rest of the time, to keep browsing uncluttered; a normal click opens a link).
While selecting, clicking a card selects it. "Select all shown" selects only the
links currently visible, respecting any active search or label filter. With a
selection, the client can, in one action:
- Add a label to all selected (with the same existing-label reuse discipline).
- Remove a label from all selected — the offered labels are only those actually
  present on the selection (the mirror of add).
- Flag all selected "Read later".
- Mark all selected as read — clearing them from the reading pile while keeping
  them saved (the mirror of Read later).
- Delete all selected, with a single confirmation that states the saved copies
  go too (consistent with single delete, SCN-012).

## Gherkin
Feature: Bulk actions

  Scenario: Select mode is deliberate
    Given the client is browsing normally
    Then no selection checkboxes are shown and a click opens a link
    When the client turns on Select mode
    Then checkboxes appear and a click selects instead of opening

  Scenario: Select all shown respects the current filter
    Given the client has filtered by search or label
    When the client chooses "Select all shown"
    Then only the currently visible links are selected

  Scenario: Add and remove a label in bulk
    Given several links are selected
    When the client adds a label
    Then it is applied to all selected (reusing an existing label if it matches)
    And when the client removes a label, only labels present on the selection are offered
    And removing strips it from all selected

  Scenario: Flag and clear the reading pile in bulk
    Given several links are selected
    When the client chooses "Read later"
    Then all selected are flagged to read
    And "Mark read" clears the selected from the pile while keeping them saved

  Scenario: Bulk delete with one confirmation
    Given several links are selected
    When the client deletes and confirms
    Then all selected links and their saved copies are removed
    And only one confirmation was required for the batch

## Assumptions
- Select mode is entered deliberately; checkboxes are not always visible.
- "Select all shown" is scoped to the current filtered view.
- Bulk delete uses one batch-level confirmation stating copies are removed too.
