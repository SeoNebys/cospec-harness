Scenario ID: SCN-007
Title: Search across all saved bookmark information
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A person can search across bookmark titles, descriptions, personal notes, labels, site names, and saved page text. A bookmark can match text found only inside its saved page, and the result shows a highlighted passage explaining that less-obvious match.

## Gherkin
Feature: Searching saved bookmarks

  Scenario: Find a bookmark by text inside its saved page
    Given a saved bookmark's page text contains "flexbox"
    And "flexbox" is absent from its title and description
    When the person searches for "flexbox"
    Then that bookmark appears in the results
    And a highlighted passage from the saved page explains the match

## Assumptions
- Search covers titles, descriptions, personal notes, labels, site names, and saved page text.
- Page text needed for search has been successfully saved and indexed.
- Less-obvious matches display a relevant highlighted passage.
