Scenario ID: SCN-020
Title: Reuse an existing label despite capitalization differences
Type: Edge Case
Approval status: approved
Approval session: SESSION-020
Approval cycle: 1

## Approved behaviour
If a person types an existing label with different capitalization and adds it without choosing the suggestion, the established label and its spelling are reused. No capitalization variant is created, and a message explains that the existing label was reused.

## Gherkin
Feature: Prevent accidental label variants

  Scenario: Add an existing label with different capitalization
    Given the collection already uses the label "reference"
    When the person types "REFERENCE" and adds it without choosing a suggestion
    Then the established label "reference" is attached
    And no separate "REFERENCE" label is created
    And a message says the established spelling was reused

## Assumptions
- Label identity ignores capitalization.
