Scenario ID: SCN-002
Title: Return to an existing bookmark instead of saving a duplicate
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When an address that is already in a multi-bookmark library is pasted into the save box, no new card is added and the saved count stays unchanged. The existing bookmark is brought into view, briefly highlighted, and opened for in-card editing. A notice says that the bookmark was already saved.

## Gherkin
Feature: Prevent duplicate bookmarks

  Scenario: Save an address that is already in the library
    Given the library contains several bookmarks
    And one bookmark has the same web address the client is about to save
    When the client pastes that address and saves it
    Then no new bookmark is added
    And the saved bookmark count stays unchanged
    And the existing card is brought into view and briefly highlighted
    And its in-card editor opens
    And the client is told that the bookmark was already saved

## Assumptions
- This approved case covers the same web address with URL fragments ignored.
- Whether other variations of an address count as the same page remains to be explored.
