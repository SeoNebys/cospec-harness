Scenario ID: SCN-011
Title: Preserve a copy of a page (self-contained copy, PDF, Internet Archive)
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Preserving a page is on-demand (not automatic for every bookmark), via the item's
"⋯" menu. Three, coexisting, forms:
1. Local saved copy: a self-contained readable copy of the page at capture time that
   still opens if the original site changes or disappears. Viewed read-only with its
   capture date and an "Open original" link; can be Updated (re-captured) or Removed.
2. PDF: when the target is actually a PDF, the PDF itself is preserved (not turned
   into a page copy). IMPORTANT: whether it is a PDF must be decided from the ACTUAL
   fetched file's content type, not merely a ".pdf" address — some download links
   return a PDF with no .pdf suffix.
3. Internet Archive: an optional, separate preservation that submits the page to the
   Internet Archive and shows a link to the archived version; removable. A local copy
   and an Internet Archive link may coexist on the same bookmark.
Ordinary search does not look inside a saved copy's body text (client accepted this).

## Gherkin
Feature: Preserve a page

  Scenario: Save and view a self-contained page copy
    Given a (non-PDF) bookmark
    When the client chooses "Save a copy"
    Then a self-contained readable copy is stored and shown on the card
    When the client opens it
    Then it is shown read-only with its capture date and a link to the original
    And the client can Update or Remove the copy

  Scenario: Preserve a PDF as a PDF, by actual file type
    Given a bookmark whose fetched content is a PDF (regardless of the address suffix)
    When the client saves a copy
    Then the PDF file itself is preserved rather than a page copy

  Scenario: Preserve on the Internet Archive
    Given a bookmark
    When the client chooses "Preserve on Internet Archive"
    Then the page is submitted to the Internet Archive
    And a link to the archived version is shown and can be removed
    And this can coexist with a local saved copy

## Assumptions
- Copies are on-demand; heavy so not made for every bookmark automatically.
- Build note: real PDF detection uses the response content type, not the URL suffix.
  Real Internet Archive preservation submits via the Archive's Save Page Now.
- Prototype simulates captured content and Archive submission (offline).
