Scenario ID: SCN-007
Title: Block an incomplete bookmark address inline
Type: Error Case
Approval status: approved
Approval session: SESSION-007
Approval cycle: 1

## Approved behaviour

When the client tries to save text that is not a complete web address, the
save window stays open and a clear correction appears directly beneath the
address field. No bookmark is created until a valid address is supplied.

## Gherkin

Feature: Saving bookmarks

  Scenario: Reject an incomplete web address
    Given the save-bookmark window is open
    When the client tries to save "interesting article"
    Then the save-bookmark window remains open
    And guidance for entering a complete web address is shown beneath the address field
    And no bookmark is created

## Assumptions

- A bookmark address must be a complete HTTP or HTTPS web address.
- Validation feedback appears in the save window rather than elsewhere on the page.
