Scenario ID: SCN-023
Title: Sort the bookmark collection
Type: Happy Path
Approval status: approved
Approval session: SESSION-023
Approval cycle: 1

## Approved behaviour
The collection has a compact dropdown for sorting. Recently saved is the default. The person can switch between newest saved first, oldest saved first, title A–Z, and title Z–A, and the visible cards immediately reorder accordingly.

## Gherkin
Feature: Sorting bookmarks

  Scenario: Use the default order
    Given the full bookmark collection is open
    Then bookmarks are ordered with the most recently saved first

  Scenario Outline: Choose another bookmark order
    Given the bookmark collection is open
    When the person chooses <choice> from the sort dropdown
    Then the visible bookmark cards are ordered <result>

    Examples:
      | choice       | result                         |
      | Oldest saved | from oldest saved to newest   |
      | Title A–Z    | alphabetically by title       |
      | Title Z–A    | reverse-alphabetically by title |

## Assumptions
- Sorting is controlled by one dropdown near the collection heading.
- Sorting applies to the currently visible collection.
