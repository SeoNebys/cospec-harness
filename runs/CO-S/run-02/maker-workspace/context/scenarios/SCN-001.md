Scenario ID: SCN-001
Title: Save a link and see it appear in the list
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The user pastes a link into a save box. They may optionally add a short name
to help them recognize it later, but the name is not required. When they save,
the link immediately appears in a list below the save box. The most recently
saved link appears at the top of the list. If a name was given, the item shows
that name; if not, the item shows the link itself. The save box clears after
saving, ready for the next link.

## Gherkin
Feature: Save a bookmark

  Scenario: Save a link with a name
    Given the user is on the bookmarks screen
    And the user has entered a link
    And the user has entered a name for it
    When the user saves
    Then the bookmark appears at the top of the list
    And the bookmark is shown by its name
    And the save box is cleared

  Scenario: Save a link without a name
    Given the user is on the bookmarks screen
    And the user has entered a link
    And the user has left the name blank
    When the user saves
    Then the bookmark appears at the top of the list
    And the bookmark is shown by the link itself
    And the save box is cleared

  Scenario: Newest bookmark is listed first
    Given the user has already saved one or more bookmarks
    When the user saves another link
    Then the newest bookmark appears above the previously saved ones

## Assumptions
- The save form captures a link plus an optional name (confirmed by client).
- Newest-first ordering in the list (confirmed by client).
- A blank name falls back to displaying the raw link (confirmed by client).
