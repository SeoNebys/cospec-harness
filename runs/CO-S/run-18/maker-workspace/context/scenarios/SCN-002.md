Scenario ID: SCN-002
Title: Add suggested existing tags while saving
Type: Happy Path
Approval status: approved
Approval session: SESSION-002
Approval cycle: 1

## Approved behaviour
While saving a bookmark, the person may add optional tags in the same action. The app suggests tags they have used before, and choosing one attaches it to the bookmark when Save link is selected.

## Gherkin
Feature: Tagging bookmarks

  Scenario: Reuse an existing tag while saving a bookmark
    Given the person has used tags on earlier bookmarks
    And the person is entering a web address to save
    When the person chooses a suggested existing tag and saves the link
    Then the bookmark is saved with that tag
    And the tag is visible on the saved bookmark

## Assumptions
- Tags are optional when saving.
- Tag selection appears with the web-address field before the bookmark is saved.
- Previously used tags are presented as suggestions.
- The person may complete the save without a separate post-save tagging step.
