Scenario ID: SCN-019
Title: Edit a saved bookmark directly from its library card
Type: Happy Path
Approval status: approved
Approval session: SESSION-019
Approval cycle: 1

## Approved behaviour
Every saved bookmark has a plainly labelled Edit button on its library card. The client can use it at any later time to edit the bookmark's title, tags, and personal notes without re-pasting the address. Saving updates the card immediately. Editing these client-owned details does not change the saved web address or disturb the preserved readable copy.

## Gherkin
Feature: Edit saved bookmarks

  Scenario: Open a saved bookmark for editing from its card
    Given a bookmark has been in the library for any length of time
    When the client selects its labelled Edit button
    Then an editor opens with the bookmark's current title, tags, and personal notes

  Scenario: Save changed bookmark details
    Given a saved bookmark is open for editing
    When the client changes its title, tags, and personal notes
    And saves the changes
    Then the library card reflects the changed title and tags
    And the changed personal notes are retained
    But the saved web address remains unchanged
    And the preserved readable copy remains unchanged

## Assumptions
- Edit is a visible labelled action on each card rather than hidden in an overflow menu.
- Editable client-owned details are title, tags, and personal notes.
- The original address and saved copy are not editable through this flow.
