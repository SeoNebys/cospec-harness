Scenario ID: SCN-009
Title: Separate To read and Done into counted tabs
Type: Happy Path
Approval status: approved
Approval session: SESSION-009
Approval cycle: 1

## Approved behaviour
To read and Done are separate, full-width collection views selected by tabs across the top. Each tab displays its current bookmark count. Changing a bookmark's status moves it immediately out of the current view and updates both counts; selecting the other tab reveals it in its new place.

## Gherkin
Feature: Separate bookmarks by reading status

  Scenario: Move a To read bookmark into the Done collection
    Given the To read tab contains two bookmarks
    And the Done tab contains one bookmark
    And the To read tab is selected
    When the person marks one visible bookmark done
    Then it immediately disappears from the To read view
    And the To read count becomes one
    And the Done count becomes two
    When the person selects the Done tab
    Then the moved bookmark is visible there

## Assumptions
- Status tabs appear across the top of the collection.
- Only one status collection occupies the full available width at a time.
