Scenario ID: SCN-026
Title: Preserve a complete draft when saving fails
Type: Error Case
Approval status: approved
Approval session: SESSION-026
Approval cycle: 1

## Approved behaviour

If saving fails after the bookmark details have been prepared, the save pop-up stays open and clearly states that the bookmark was not saved. The entered address, adjusted title and description, and selected labels remain intact so the user can retry without re-entering anything. No incomplete or ghost bookmark appears in the collection. The bookmark appears only after a retry succeeds.

## Gherkin

Feature: Recovering from a failed save

  Scenario: Saving a prepared bookmark fails
    Given the user has entered a valid address
    And has adjusted the bookmark title, description, or labels
    When saving the bookmark fails
    Then the save pop-up remains open
    And it clearly says that the bookmark was not saved
    And every entered and selected detail remains intact
    And no bookmark is added to the collection

  Scenario: Retry after a failed save
    Given a prepared bookmark failed to save
    When the user retries and saving succeeds
    Then the pop-up closes
    And one complete bookmark appears in the collection with the retained details

## Assumptions

- Retrying uses the unchanged draft already visible in the pop-up.
