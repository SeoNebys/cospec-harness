Scenario ID: SCN-023
Title: Import and export standard browser-bookmarks file
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The client can export all bookmarks to a standard browser-bookmarks file
(Netscape bookmark HTML), including each title, its tags, and its original saved
date. The client can import such a file (including files exported from real web
browsers). On import, bookmarks are added preserving their titles, tags, and
original saved dates. Links already present are skipped (matched the same way as
elsewhere). Because the standard file carries no read/finished status, imported
bookmarks default to Finished/reference so they do not flood the "To read" list;
the client can move individual ones to "To read" afterward. A message reports how
many were imported and how many skipped.

## Gherkin
Feature: Import and export

  Scenario: Export to standard format
    Given saved bookmarks exist
    When the client exports
    Then a standard browser-bookmarks file is produced
    And it includes each bookmark's title, tags, and original saved date

  Scenario: Import from standard format
    Given a standard browser-bookmarks file
    When the client imports it
    Then bookmarks are added preserving titles, tags, and original saved dates
    And links already present are skipped
    And imported bookmarks default to Finished/reference status
    And a summary of imported and skipped counts is shown

## Assumptions
- Format is the Netscape bookmark HTML used by web browsers.
- Imported items default to Finished/reference (client approved).
