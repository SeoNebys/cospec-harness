Scenario ID: SCN-015
Title: Keep a readable saved copy of the page content so the content survives if the original dies
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
On every save, the app automatically and silently keeps a readable copy of the
page's content as it was at save time — the client does not have to trigger it.

- When viewing an item, the client can switch between the "Original page" and
  "Your saved copy" at any time, even while the original is still alive.
- When the original page is gone, opening the item lands directly on the saved
  copy with a note that the original is unavailable, so the client can still read
  the FULL content — not just the title/summary. (This is the core of the
  client's "it won't disappear on me" requirement.)
- Search also reaches INTO the saved copy content, so the client can rediscover a
  page by a remembered phrase from the body, not only the title/summary/labels.

## Gherkin
Feature: Saved readable copy

  Scenario: A copy is kept on save
    When the client saves a link
    Then a readable copy of the page content is stored automatically

  Scenario: Read the saved copy anytime
    Given a saved item whose original is still reachable
    When the client opens it and chooses the saved copy
    Then the full stored content is shown

  Scenario: Original page has gone
    Given a saved item whose original page is no longer available
    When the client opens it
    Then the saved copy is shown with the full content and a note about the original

  Scenario: Find by words inside the content
    Given a saved item whose body contains a word not in its title or summary
    When the client searches that word
    Then the item is found (see SCN-016 for ranking of such matches)

## Assumptions
- Copy kept automatically and silently on every save. (Approved.)
- Original vs saved-copy toggle in the viewer; gone → default to saved copy. (Approved.)
- Search includes full saved-copy text. (Approved, with ranking caveat -> SCN-016.)
