# Cycle 1 goal

> Right now my bookmarks are a mess — they're scattered, and when I actually need one later I can never find it. So the big thing that should be different is that saving a link is quick and painless, and then I can actually get back to it when I want it.
>
> So really: I want to be able to save a bookmark (with its web address and some kind of name so I recognize it), see everything I've saved in one place, organize them somehow so related ones stay together, search or filter to find one fast, and delete the ones I don't need anymore. If I can do those things without it being a hassle, that's the win for me.

## Confirmed direction

> Yes, that's the right direction. Saving a named link, keeping related ones together, finding them by search or filter, and removing them — that's exactly what I need. And it being just for me, no sharing, is fine.

Status: confirmed.

## Interface form

> A web app would suit me best — something I can just open in my browser on my computer. That's where I usually run into links I want to save.

Confirmed form: web app used in a desktop browser.
