Scenario ID: SCN-015
Title: Reuse tags despite capitalization or surrounding spaces
Type: Edge Case
Approval status: approved
Approval session: SESSION-015
Approval cycle: 1

## Approved behaviour
Tag matching ignores capitalization and removes extra spaces around the entered tag. If the normalized entry matches an existing tag, the app reuses that tag instead of creating a near-duplicate.

## Gherkin
Feature: Consistent tag reuse

  Scenario: Enter an existing tag with typing variations
    Given the tag "reference" already exists
    When the person enters " Reference " as a tag
    Then surrounding spaces are removed for matching
    And capitalization is ignored for matching
    And the existing "reference" tag is reused
    And no additional near-duplicate tag is created

## Assumptions
- Tag display uses the existing tag's stored form when it is reused.
- Only surrounding whitespace is normalized; meaningful spaces within a tag remain allowed.
