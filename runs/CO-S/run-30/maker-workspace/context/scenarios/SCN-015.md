Scenario ID: SCN-015
Title: Keep long bookmark content skimmable and searchable
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When a page has a very long title or description, the bookmark card visually shortens each to a compact number of lines so the library remains skimmable. All labels wrap within the card rather than being discarded. Search still uses the complete title and description, including text not visible in the shortened card.

## Gherkin
Feature: Displaying long bookmark content

  Scenario: Display a bookmark with unusually long details and many labels
    Given a bookmark has a very long title and description
    And it has several labels
    When the client views the library
    Then the visible title and description are shortened to keep the card compact
    And all labels remain visible by wrapping within the card
    And the card remains the link to the saved page

  Scenario: Search text hidden by visual shortening
    Given part of a bookmark's complete title or description is not visible on its compact card
    When the client searches for that text with different capitalization
    Then the bookmark appears in the search results

## Assumptions
- Visual shortening does not discard the complete stored title or description.
- All labels remain visible on the bookmark card.
