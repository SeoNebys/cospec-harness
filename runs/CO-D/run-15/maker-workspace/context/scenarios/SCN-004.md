Scenario ID: SCN-004
Title: Add another tag by reusing an existing tag suggestion
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

A bookmark can hold several tags. When the client starts typing another tag, the app suggests matching tags already used in the collection. Choosing a suggestion adds that existing tag, preserving its established spelling and leaving the bookmark's earlier tags in place.

## Gherkin

Feature: Organize bookmarks with tags

  Scenario: Add a second tag from an existing-tag suggestion
    Given a bookmark already has the tag "Cooking"
    And the tag "Italian" has been used in the collection
    When the client starts adding another tag to the bookmark
    And types text matching the beginning of "Italian"
    Then the app suggests the existing "Italian" tag
    When the client chooses that suggestion
    Then the bookmark displays both "Cooking" and "Italian"
    And the app reuses the established spelling of "Italian"

## Assumptions

- Suggestions match the beginning of an existing tag without requiring the same capitalization.
- Choosing a suggestion reuses the existing tag rather than creating a new tag with similar text.
- The inline interaction approved in SCN-003 remains in use.
