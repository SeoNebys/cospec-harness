# Cycle 1 goal

> Honestly, today my bookmarks are a mess — they're scattered across my browser, buried in long lists, and I can never find the one I'm looking for. So here's what I'm hoping for:
>
> - I want to save a link just by pasting its address, and have the app figure out the page's title and details for me so I don't have to type them.
> - I want to organize things with tags and labels, and be able to search my saved links quickly — by words in the title, by tag, that kind of thing — and actually find what I saved.
> - I'd like a way to mark some links as "read this later" and see just those, so my reading list doesn't get lost in everything else.
> - And I want to tidy up — edit a saved link, delete ones I don't need, and ideally set aside old ones without losing them permanently.
>
> Basically, saving should be effortless and finding things again should be reliable. That's the main pain I want gone.

Confirmed by the client as the overall goal for cycle 1.
