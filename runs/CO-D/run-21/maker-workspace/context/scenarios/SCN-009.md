Scenario ID: SCN-009
Title: Empty states and clearing a search
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When the collection is empty, the list shows a guiding message to save the first
link (the primary action) and mentions that existing browser bookmarks will be
importable (the actionable Import control ships with the import feature). When a
search matches nothing, the list shows a clear "no matches" message with a count
of zero. A "Clear" control appears whenever the search box is non-empty and
resets the search.

## Gherkin
Feature: Empty states and clearing search

  Scenario: Empty collection
    Given there are no saved bookmarks
    Then the list shows a message to save the first link
    And it mentions that browser bookmarks can be imported later

  Scenario: Search matches nothing
    Given saved bookmarks exist
    When the user searches a term that matches none
    Then a "no matches" message and a count of zero are shown

  Scenario: Clear the search
    Given the search box has text
    Then a "Clear" control is shown
    When the user clicks it
    Then the search is emptied and the full list returns

## Assumptions
- Import mention is text only in cycle 1; the Import action lands with L-06.
