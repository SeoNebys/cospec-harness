Scenario ID: SCN-014
Title: Recover safely from invalid and empty searches
Type: Error Case
Approval status: approved
Approval session: SESSION-014
Approval cycle: 1

## Approved behaviour
An incomplete or malformed search expression is not partially applied. The site explains the specific correction in plain language and leaves the client's current library view unchanged. A valid search with no matches shows a deliberate empty state rather than a blank screen, and offers a one-action way to clear the search and return to the full library.

## Gherkin
Feature: Recover from unsuccessful searches

  Scenario: Reject an unfinished search without disturbing the current view
    Given the client is viewing a set of library bookmarks
    When they submit an expression ending with an unfinished OR group
    Then the site explains that another condition and a closing parenthesis are required
    And the expression is not partially applied
    And the previously visible bookmarks remain unchanged

  Scenario: Show and clear a valid search with no matches
    Given no bookmark has the tag "astronomy"
    When the client searches for "tag:astronomy"
    Then a clear no-matches state is shown
    And the client can clear the search with one action
    When the client clears it
    Then the full library is visible again

## Assumptions
- Search errors identify a useful correction rather than showing a generic failure.
- Invalid expressions never replace the current result set.
- The zero-result state includes a direct clear action.
