# Business goal statement

## Cycle 1 — recorded 2026-09-24 (SESSION-001)

### Client's request (verbatim)
> I want to build an app to save and manage bookmarks.
>
> It's for me personally. Right now my bookmarks become a long, messy list, so I
> often can't find a useful link when I need it—or remember why I saved it.
>
> I want one place where I can quickly save links, organise them with tags,
> search them easily, and keep track of things I still want to read. I'd also
> like important links to remain useful even if the original page later
> disappears or changes.
>
> Preserving pages is important, but it's more of a safety net than the main
> reason for the app.
>
> I'd prefer a web app that I can use from my browser.

### Goal (in the client's language)
A single personal place for links, where the core problem being solved is
"I can't find or recall the link I need."

The app should let the client:
- Save a link quickly when they come across it
- Organise links with tags (instead of one long flat list)
- Search to find a link again easily
- Track which links they still intend to read
- Keep important links useful even if the original page later changes or
  disappears (safety net — secondary, not the main reason)

### Scope notes
- Personal, single-user.
- Core value: findability / recall of saved links.
- Page preservation is a secondary safety net, not the central feature.

### Interface form
Web app, used from the browser.
