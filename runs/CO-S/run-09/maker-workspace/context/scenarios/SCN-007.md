Scenario ID: SCN-007
Title: Browse the library by tag
Type: Happy Path
Approval status: approved
Approval session: SESSION-007
Approval cycle: 1

## Approved behaviour
The library sidebar shows the person's existing tags alongside All bookmarks and Read later. Selecting a tag narrows the library in place to bookmarks carrying that tag, updates the visible result count, and leaves each result's own tags visible so the reason for the match is clear.

## Gherkin
Feature: Browse bookmarks by tag

  Scenario: Filter the library with an existing tag
    Given the library contains bookmarks with several tags
    And the existing tags are visible in the library sidebar
    When the person selects a tag
    Then the library shows only bookmarks carrying that tag
    And the result count reflects the narrowed library
    And each result continues to show its own tags

## Assumptions
- Existing tag filters live in the library sidebar.
- Selecting a tag filters the current library in place.
- Tag filtering does not remove or modify bookmarks.
- Tags remain visible on result cards.
