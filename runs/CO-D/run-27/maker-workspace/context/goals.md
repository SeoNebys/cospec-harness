# Business goal

## Cycle 1 — Session 1 (2026-09-26)

### Client's own words (verbatim)

> I'm saving links in browser folders, notes, and messages to myself, so they're
> scattered and hard to find again. I want one personal place where I can quickly
> save a link, organise it, search for it later, and keep track of what I still
> want to read. I'd also like to avoid ending up with duplicates when I save the
> same link twice.
>
> This is mainly just for me, not a team or the public.

> Finding a saved link again quickly is the main problem, but keeping a clear
> "read later" list is also important—not merely a nice extra.

> I picture this as a web app I can open in a browser, on both my computer and phone.

### Confirmed goal statement

One personal place to collect links that are currently scattered across browser
folders, notes, and self-messages, so that a previously saved link can be **found
again quickly**, and so the client can keep a **clear "read later" list**.

Supporting capabilities named by the client:
- quickly save a link
- organise saved links
- search for a link later
- keep track of what is still to be read (read-later list)
- avoid duplicates when the same link is saved twice

### Priority (client-confirmed)

1. Finding a saved link again quickly — the main pain
2. Keeping a clear "read later" list — also central, not a nice-to-have
3. Organise / search / duplicate-avoidance — in service of the above

### Scope

- Single user, personal use. Not a team or public product.

### Interface form (client-confirmed)

Web app, opened in a browser, used on both computer and phone.
-> Prototyping method: HTML-based interactive prototype, responsive layout.
