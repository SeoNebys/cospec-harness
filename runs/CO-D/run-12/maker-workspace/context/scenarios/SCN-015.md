Scenario ID: SCN-015
Title: Prevent labels that differ only by capitalization or spacing
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When the user enters a label name that differs from an existing label only by capitalization or surrounding spaces, the app treats it as the same label, suggests the existing label, and does not create a near-duplicate.

## Gherkin
Feature: Organizing bookmarks with labels

  Scenario Outline: Reuse an existing label despite an insignificant variation
    Given the label "Cooking" already exists
    When the user enters <entered label> for a bookmark
    Then the existing "Cooking" label is suggested
    And a second label is not created

    Examples:
      | entered label |
      | cooking       |
      | " Cooking"   |
      | "Cooking "   |

## Assumptions
- Label comparisons ignore capitalization and surrounding spaces.
- The existing label's displayed capitalization is preserved.
