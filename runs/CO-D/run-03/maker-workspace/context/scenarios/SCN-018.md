Scenario ID: SCN-018
Title: Search operates within the current scope (active label group or to-read pile), not always the whole collection
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When the client has narrowed to a corner of the collection — an active label
group, the to-read pile, or the archive — searching hunts ONLY within that
subset. All ranking and operators behave identically inside the scope. A clear
banner names the current scope ("Searching within label 'cooking'" / "within your
To read pile") and always offers a one-click "Search all bookmarks instead" to
widen back out, so the client never feels trapped in a corner.

Confirmed still-holding when integrated: archived items remain excluded from
everyday search (SCN-008).

## Gherkin
Feature: Scoped search

  Scenario: Search within an active label group
    Given the client has selected a label group
    When the client searches
    Then only items in that group are searched, with full ranking and operators
    And a banner names the scope and offers a one-click return to searching all

  Scenario: Search within the to-read pile
    Given the client is viewing the to-read pile
    When the client searches
    Then only unread items are searched

  Scenario: Widen back to the whole collection
    Given the client is searching within a scope
    When the client chooses "Search all bookmarks instead"
    Then the search term is kept and the scope is dropped

## Assumptions
- Current view/label narrows the search space; one-click widen always available. (Approved.)
