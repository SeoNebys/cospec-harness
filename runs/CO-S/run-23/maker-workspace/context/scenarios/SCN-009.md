Scenario ID: SCN-009
Title: Save a valid page when its details are unavailable
Type: Error Case
Approval status: approved
Approval session: SESSION-009
Approval cycle: 1

## Approved behaviour
The client saved a valid web address whose title and description could not be collected. The bookmark was still created, using the site name as a recognizable fallback and clearly noting that page details were unavailable and could be added through editing later. The client preferred capturing the link over refusing to save it.

## Gherkin
Feature: Save bookmarks

  Scenario: Page details cannot be collected
    Given a valid web address has been entered
    And the page title and description cannot be collected
    When the user saves the bookmark
    Then the bookmark is added to the collection
    And the site name is used as its fallback title
    And the bookmark clearly states that page details are unavailable
    And the user is directed toward editing the missing context later

## Assumptions
- Failure to collect page details does not make an otherwise valid address unsaveable.
- The source site remains available even when richer page details are not.
