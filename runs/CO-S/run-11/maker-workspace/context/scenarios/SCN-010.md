Scenario ID: SCN-010
Title: Long titles, descriptions and addresses stay readable
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When a bookmark has a very long title, description, or web address, the content
wraps neatly inside its card and does not break or overflow the layout.

## Gherkin
Feature: Readable layout for long content

  Scenario: Very long content wraps within the card
    Given a bookmark with a very long title, description and web address
    When it is shown in the list
    Then the content wraps within its card without breaking the layout

## Assumptions
- Long unbroken strings (e.g. long addresses) are allowed to wrap.
