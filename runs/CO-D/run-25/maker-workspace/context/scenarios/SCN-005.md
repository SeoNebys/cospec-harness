Scenario ID: SCN-005
Title: Format a personal note with typed shorthand
Type: Happy Path
Approval status: approved
Approval session: SESSION-005
Approval cycle: 1

## Approved behaviour
While writing a personal note, the person can type lightweight shorthand for bold text, bulleted lists, and links without leaving the keyboard. After saving, the bookmark card renders the finished formatting rather than showing the shorthand marks.

## Gherkin
Feature: Personal bookmark notes

  Scenario: Save a lightly formatted note
    Given a saved bookmark's inline editor is open
    When the person writes a note using supported shorthand for bold text, a bulleted list, and a link
    And saves the changes
    Then the note appears on the bookmark card with bold text, a real bulleted list, and a working link
    And the formatting shorthand is not shown on the card

## Assumptions
- The supported light formatting is bold text, bulleted lists, and links.
- Handling stray or incomplete formatting marks is resolved as an edge case.
