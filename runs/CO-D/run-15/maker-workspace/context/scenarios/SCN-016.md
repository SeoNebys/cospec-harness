Scenario ID: SCN-016
Title: Keep long notes compact without losing content
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

A long formatted note is visually collapsed to a short preview in the bookmark list so the collection remains scannable. The client can expand it on demand and collapse it again. The note's complete content and formatting remain stored, and every word remains searchable even while the note is collapsed.

## Gherkin

Feature: Keep formatted notes readable in the collection

  Scenario: View and expand a long note
    Given a bookmark has a formatted note longer than the compact card preview
    When the bookmark is shown in the collection
    Then only a compact visual preview of the note is shown
    And the note indicates that the full content can be expanded
    When the client expands the note
    Then the complete formatted note is shown
    And the client can collapse it again

  Scenario: Search words hidden by the compact note preview
    Given a bookmark's long note contains a word outside the visible preview
    When the client searches for that word
    Then the bookmark is shown

## Assumptions

- Visual collapsing does not truncate or discard stored note content.
- The entire readable note participates in search regardless of expansion state.
