Scenario ID: SCN-016
Title: Suggest already-used tags while typing a tag
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

While the user types in the Tags field, a dropdown suggests the user's
already-used tags that match what is typed, ordered most-used first, each showing
how many times it has been used. Tags already attached to the current bookmark
are excluded from the suggestions. The user can pick a suggestion by clicking it
or by highlighting it with the arrow keys and pressing Enter. If the typed text
is not an existing tag, the dropdown offers to add it as a new tag (Enter adds
it), keeping new tags flexible.

## Gherkin

Feature: Tag suggestions

  Scenario: Suggest matching existing tags with usage counts
    Given the user has previously used several tags
    When the user types in the Tags field
    Then matching existing tags are suggested, most-used first, each with its usage count
    And tags already attached to the current bookmark are not suggested

  Scenario: Choose a suggested tag
    When the user selects a suggestion by click or by arrow-key and Enter
    Then that tag is added to the bookmark

  Scenario: Add a new tag not previously used
    When the user types a word that is not an existing tag
    Then the dropdown offers to add it as a new tag
    And pressing Enter adds it

## Assumptions
- Suggestions are drawn from tags already used across the user's bookmarks.
- Usage counts are shown to help choose between similar tags.
