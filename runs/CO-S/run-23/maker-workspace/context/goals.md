# Cycle 1 goal

## Client statement

> Honestly, today my bookmarks are a mess — they're scattered, hard to find, and I can never remember why I saved something. So when this is done, here's what I'm hoping for:
>
> - I want to just paste or type in a web address and have it saved, and ideally the app grabs the page's title and a bit of description on its own so I don't have to type all that.
> - I want to organize things with tags, and easily find stuff later by searching — searching the title, the notes I wrote, whatever — without worrying about capital letters.
> - I want to filter down to just one topic when I click a tag.
> - I'd love a "read this later" pile that I can look at separately, and mark things done once I've read them.
> - I want to be able to edit or delete a saved link, and if I accidentally save the same page twice, it shouldn't create a messy duplicate.
> - And the list itself should be easy to skim — I should see the title and what it is at a glance.
>
> There are some nice-to-haves too (jotting notes on a link, tidying up old ones without fully deleting them, moving my existing bookmarks in), but the things above are the heart of what would make my day-to-day easier.

## Confirmed direction

> Saving with little effort, keeping enough context to remember why a link mattered, and being able to find things again — that's the heart of it. And I agree the notes, archiving, and importing can come later.
>
> The one thing I want to make sure stays in that first version alongside search and tags is the read-later flow — being able to set something aside as "read this later" and see just that pile is a big part of my daily habit.

## Interface

> A web app, please. I mostly save links while I'm browsing on my computer, so something I can open in my browser is what fits my day best. It's just me using it, so I don't need anything fancy for multiple people.
