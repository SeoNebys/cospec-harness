Scenario ID: SCN-019
Title: Import browser bookmarks and export, preserving titles, tags, and saved dates
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

From an "Import / Export" panel (opened from a header button) the client can:

Import — choose an exported browser bookmarks file (.html) or a JSON backup.
Titles, tags, and original saved dates are preserved. Folders in the file become
tags, added alongside any tags already present in the file. Before anything is
added, a preview shows how many bookmarks were found, how many are new, and how
many are already saved, with a sample list (title, saved date, tags). On confirm,
only the new ones are imported; bookmarks whose address already exists are
skipped, avoiding clutter.

Export — save all bookmarks to a file in either of two formats: a
browser-compatible bookmarks file (HTML) that preserves title, tags, and original
saved date (and re-imports into browsers), or a fuller JSON backup that also keeps
notes, descriptions, and read/archive state. A preview of the exported content is
shown.

## Gherkin

Feature: Import and export

  Scenario: Import a browser bookmarks file
    Given an exported browser bookmarks .html file (or a .json backup)
    When I choose it
    Then a preview shows how many bookmarks were found, new, and already saved
    And each preview row shows the title, original saved date, and tags
    And folders in the file are turned into tags alongside any existing tags
    When I confirm the import
    Then the new bookmarks are added with their original saved dates
    And bookmarks whose address already exists are skipped

  Scenario: Export a portable bookmarks file
    When I export as a bookmarks file (HTML)
    Then it contains each bookmark's title, tags, and original saved date
    And it can be re-imported into a browser

  Scenario: Export a full backup
    When I export as a full backup (JSON)
    Then it additionally preserves notes, descriptions, and read/archive state

## Assumptions
- Duplicate detection on import uses the same address-equivalence as saving.
- Folder path names each become a tag.
