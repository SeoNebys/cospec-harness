Scenario ID: SCN-005
Title: Archive a link and restore it
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

Each saved item has an **Archive** action. Archiving an item removes it from
both the **All** and **To read** views, so the main list stays uncluttered. The
archived item remains available under the **Archived** view and can be brought
back with **Restore to list**, which returns it to the main views.

## Gherkin
Feature: Archive and restore

  Scenario: Archive removes from main and to-read views
    Given a saved item is shown in the All view
    When the user archives it
    Then it no longer appears in the All view
    And it no longer appears in the To read view
    And it appears in the Archived view

  Scenario: Restore an archived item
    Given an item is in the Archived view
    When the user restores it
    Then it appears again in the All view (and To read if still flagged)
    And it no longer appears in the Archived view

## Assumptions
- Archived state is separate from the read-later flag; an archived item is
  excluded from All and To read regardless of its flag.
- Archiving keeps the item (it is not deleted).
