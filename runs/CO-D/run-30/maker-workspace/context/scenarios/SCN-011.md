Scenario ID: SCN-011
Title: Remove a completed item from the Read later view
Type: Happy Path
Approval status: approved
Approval session: SESSION-011
Approval cycle: 1

## Approved behaviour

While viewing only Read later bookmarks, the client can uncheck Read later on a card. That card immediately drops out of the current view and the result count decreases, leaving the remaining unread items visible. This allows the reading pile to shrink as items are completed.

## Gherkin

Feature: Reading saved bookmarks later

  Scenario: Remove a completed bookmark from the reading list
    Given the Read later view contains two marked bookmarks
    When the user unchecks "Read later" on one bookmark
    Then that bookmark immediately disappears from the Read later view
    And the result count changes to one result
    And the other marked bookmark remains visible

## Assumptions

- Unmarking removes only the Read later status; it does not delete the bookmark from the collection.
