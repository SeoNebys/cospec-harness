Scenario ID: SCN-005
Title: Narrow by several tags at once (match all selected)
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

The tag filter accepts more than one tag at a time. When several tags are
selected, the list shows only links that carry ALL of the selected tags (AND).
Each additional selected tag narrows the list further.

- Clicking an unselected tag adds it to the filter; clicking a selected
  (highlighted) tag again removes it.
- Selected tags are highlighted on the entries and listed in the filter bar,
  where each can be removed individually via its "✕".
- "Clear tag filter" removes all selected tags at once.
- The multi-tag filter still applies within the current view (All / Unread /
  Archived), consistent with SCN-004.

The client confirmed "match all" is the intended behaviour and that removing
filters individually, toggling a tag off, and clearing all feel straightforward.

## Gherkin

Feature: Filter by multiple tags (match all)

  Scenario: Combining tags narrows to links carrying all of them
    Given links exist with various tags in the current view
    When the client selects tag A
    Then only links tagged A are shown
    When the client also selects tag B
    Then only links tagged with both A and B are shown

  Scenario: Remove one tag from a multi-tag filter
    Given the filter has tags A and B selected
    When the client removes tag B
    Then the list shows links tagged A again

  Scenario: Toggling a selected tag off
    Given tag A is selected
    When the client clicks tag A again
    Then tag A is removed from the filter

  Scenario: Clear all tag filters
    Given one or more tags are selected
    When the client chooses "Clear tag filter"
    Then no tag filter is applied and the full current view is shown

## Assumptions

- Combination semantics = AND (match all). OR / "any of" was not requested.
- Selection is case-insensitive, consistent with SCN-004.
