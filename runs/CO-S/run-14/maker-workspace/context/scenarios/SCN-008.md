Scenario ID: SCN-008
Title: Reject input that is not a valid link
Type: Error Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

When the user presses Save with input that is not a valid link (empty, or text
with no recognizable domain such as "notalink"), the app does **not** create a
bookmark. Instead it shows a **gentle inline message** explaining the problem
(e.g. "That doesn't look like a link") and leaves the input focused so the user
can correct it.

## Gherkin
Feature: Reject invalid link input

  Scenario: Save with non-link text
    Given the user typed text that is not a valid link
    When the user presses Save
    Then no bookmark is created
    And an inline message explains it is not a valid link

  Scenario: Save with an empty box
    Given the save box is empty
    When the user presses Save
    Then no bookmark is created
    And an inline message asks for a link

## Assumptions
- Validity is based on a recognizable domain in the entered text.
