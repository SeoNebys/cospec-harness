Scenario ID: SCN-003
Title: Find bookmarks with live text search
Type: Happy Path
Approval status: approved
Approval session: SESSION-003
Approval cycle: 1

## Approved behaviour
A person can type a word or phrase into search and the bookmark list narrows immediately while they type. Search matches bookmark titles, descriptions, and tags. Matching results remain in the familiar bookmark-list layout.

## Gherkin
Feature: Searching bookmarks

  Scenario: Search by title or description
    Given several bookmarks have been saved
    When the person types a word found in a bookmark title or description
    Then the list immediately shows only matching bookmarks
    And the results use the normal bookmark-list layout

  Scenario: Search by tag
    Given multiple bookmarks share a tag
    When the person types that tag into search
    Then the list immediately shows every bookmark carrying that tag
    And a bookmark may match even when the phrase is absent from its title and description

## Assumptions
- Search filtering happens live as the person types.
- Matching is not limited to exact full-field matches.
- Search covers titles, descriptions, and tags in one search box.
