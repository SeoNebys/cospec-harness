Scenario ID: SCN-015
Title: Import and export via the standard bookmarks HTML file
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

Import: the client chooses a standard bookmarks HTML file (as exported by
browsers). The app adds its links, preserving:
- titles,
- tags — from an explicit TAGS attribute, and by converting each meaningful
  containing folder name into a tag (generic root folders such as "Bookmarks
  bar", "Favorites", "Other bookmarks", "Mobile bookmarks" are skipped),
- original saved dates (from ADD_DATE), so imported items sort by their real dates
  under Oldest/Newest, not as if saved just now.
Links already saved are skipped (same duplicate matching as pasting a link), so
importing twice creates no duplicates.

Export: the client downloads the whole collection as a standard bookmarks HTML
file ("bookmarks.html") that any browser or bookmark tool can read back,
embedding titles, tags (TAGS attribute), and saved dates (ADD_DATE). It round-trips.

(Review used a built-in "load sample" convenience to stand in for choosing a real
file; the real Import uses the OS file picker.)

## Gherkin

Feature: Import / Export

  Scenario: Import a bookmarks HTML file
    When the client imports a standard bookmarks HTML file
    Then its links are added with titles, tags, and original saved dates preserved

  Scenario: Folders become tags
    Given the imported file organises links in folders
    When it is imported
    Then each meaningful folder name becomes a tag
    And generic root folders are not turned into tags

  Scenario: Import skips duplicates
    Given some imported links are already saved
    When the client imports
    Then those links are skipped and not duplicated

  Scenario: Export standard bookmarks HTML
    When the client exports
    Then a standard bookmarks HTML file downloads with titles, tags, and saved dates
    And it can be read back by browsers and re-imported

## Assumptions

- Import maps explicit TAGS plus meaningful folder names to tags; skips generic roots.
- Original ADD_DATE is preserved and used by sort.
- Duplicate detection on import matches the paste/save rule.
- Export format is Netscape bookmark HTML with TAGS and ADD_DATE.
