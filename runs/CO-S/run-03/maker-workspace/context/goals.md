# Business goal

## Cycle 1 — recorded SESSION-001, 2026-07-13

### Client's words (verbatim, preserved)

> my bookmarks are a mess. I save links all over the place — browser, notes app,
> messages to myself — and then I can never find anything again. So really I just
> want one place to save a link and actually be able to find it later. Nothing fancy.

> When I think "where did I put that," I usually picture typing in a word or two to
> search for it. But I also imagine having some folders or groups — like work stuff,
> recipes, things to read later — so I can just click into a group and browse if I
> don't remember the exact word. Probably a mix of both, honestly.

> I mostly picture something in my web browser on my computer... a website I can log
> into would be my first thought.

### Goal statement (confirmed by client)

Replace the scattered mess of links (across browser, notes app, messages) with one
single place to save any link — so that later the user can reliably get back to it,
either by searching for a word or two, or by browsing groups such as "work",
"recipes", or "read later".

The saving is the means; **reliable re-findability later is the heart of the goal.**

### Interface form (confirmed by client)

Web app, used from a desktop browser. The client pictures "a website I can log into".

### Notes on scope
- "Nothing fancy" — client wants a lean, focused tool, not a feature-heavy product.
- Two ways to re-find: (1) keyword search, (2) browse by group/folder.
