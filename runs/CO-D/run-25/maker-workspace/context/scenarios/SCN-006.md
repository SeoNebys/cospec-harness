Scenario ID: SCN-006
Title: Add and remove bookmark labels as tokens
Type: Happy Path
Approval status: approved
Approval session: SESSION-006
Approval cycle: 1

## Approved behaviour
In the bookmark's inline editor, the person types a short label and presses Enter to turn it into a distinct pill. Added labels are visible before saving and each can be removed directly. After saving, the labels appear as clickable pills on the bookmark card.

## Gherkin
Feature: Bookmark labels

  Scenario: Add labels to a bookmark
    Given a saved bookmark's inline editor is open
    When the person types a label and presses Enter
    Then the label becomes a distinct removable pill in the editor
    When the person adds another label and saves
    Then both labels appear as clickable pills on the bookmark card

  Scenario: Remove a label before saving
    Given a label is shown as a pill in the inline editor
    When the person removes that pill
    Then that label is no longer included in the pending bookmark changes

## Assumptions
- Labels are short reusable names.
- Existing-label suggestions are explored as a related behaviour.
