Renaming a link — two ways

Same list, same links. The only difference is how you start renaming. Try renaming a link in each and see which feels more natural.

Option A — Click the name

Click a link's name and it becomes editable right where it is. Press Enter to keep it.

    Option B — "Edit" button

    Each link has a small "Edit" button. Click it to change the name, then press Enter.
