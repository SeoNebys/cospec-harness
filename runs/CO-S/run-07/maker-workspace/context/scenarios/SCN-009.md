Scenario ID: SCN-009
Title: Edit all saved bookmark details inline
Type: Happy Path
Approval status: approved
Approval session: SESSION-009
Approval cycle: 1

## Approved behaviour
The user can edit a saved bookmark directly inside its card while keeping the bookmark in context. The title, description, website address, and tags can all be corrected. Saving returns the card to its normal view with the updated details and an immediate confirmation. Changing the website address does not replace the user's title, description, or tags.

## Gherkin
Feature: Edit a saved bookmark

  Scenario: Correct a saved bookmark's details
    Given the library contains a saved bookmark
    When the user begins editing from its card
    Then editable title, description, website address, and tag fields appear within the card
    When the user changes those details and saves
    Then the card returns to its normal view
    And it shows the updated title, description, source website, and tags
    And it immediately confirms that the changes were saved

  Scenario: Preserve user-edited details when the website address changes
    Given the user has edited a bookmark's title, description, or tags
    When the user changes its website address and saves
    Then the edited title, description, and tags remain unchanged
    And the bookmark uses the corrected website address

## Assumptions
- Editing takes place inline within the bookmark card.
- The corrected website address is valid.
- Existing tags can be removed and new tags use the behaviour approved in SCN-004.
