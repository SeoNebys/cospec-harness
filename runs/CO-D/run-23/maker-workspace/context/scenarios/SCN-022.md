Scenario ID: SCN-022
Title: Recognize tracked and section-specific forms of a saved page
Type: Edge Case
Approval status: approved
Approval session: SESSION-022
Approval cycle: 1

## Approved behaviour
When a person tries to save a page that is already bookmarked but the new address only adds common tracking information or a jump-to-section marker, the app treats it as the same underlying page. It creates no duplicate, keeps the library count unchanged, ignores the noisy address additions, and brings the existing clean bookmark into view with a clear explanation.

## Gherkin
Feature: Avoid duplicate bookmarks

  Scenario: Save a tracked address for an existing page
    Given the clean address of a page is already bookmarked
    And a new address points to the same page with newsletter tracking information and a section marker
    When the person tries to save the new address
    Then no new bookmark is created
    And the library count remains unchanged
    And the tracking information and section marker are ignored
    And the existing clean bookmark is brought into view

## Assumptions
- Common marketing-tracking parameters do not identify distinct page content.
- A fragment that jumps to a section does not identify a distinct page.
- Other meaningful address parameters are not automatically discarded.
