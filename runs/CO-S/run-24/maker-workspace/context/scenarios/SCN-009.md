Scenario ID: SCN-009
Title: Empty states — first run, empty reading list, and no search matches
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

Absence of data is always shown as a calm, one-line guiding message inside the
normal layout — never a blank screen.

- First run (nothing saved): the save box is ready and the list area shows "No
  links saved yet. Paste a link above and press Save." No longer intro/tutorial
  is wanted.
- Reading list empty: "Your reading list is empty. Add links with ＋ Reading list."
- Search / filter with no matches: "No links match …, try fewer words or clearing
  a filter." (see SCN-005)

## Gherkin
Feature: Empty states

  Scenario: First run shows a ready, guiding empty state
    Given the user has never saved a link
    When the app opens
    Then the save box is shown ready for input
    And a one-line message invites them to paste and save a link
    And no tutorial or example is required

  Scenario: Empty reading list
    Given no links are in the reading list
    When the user opens the reading list view
    Then a one-line message invites them to add links to it

  Scenario: No search matches
    Given a search or filter matches nothing
    Then a one-line "no matches" message is shown (not a blank screen)

## Assumptions
- Collection default ordering is newest-first.
- Managing a large collection is done via search + tag filters (not manual
  scrolling); performance/paging polish is deferred (non-functional backlog).
