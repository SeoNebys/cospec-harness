Scenario ID: SCN-009
Title: Optionally pull fresh info when the address is changed to a different page
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Changing the web address never re-fetches automatically (SCN-005). But when the
client changed the address because they had saved the WRONG page, they can press
an explicit "Re-fetch info from this link" button in the editor to pull fresh
title, summary, and image for the new address. It only happens on that deliberate
press, so it can never clobber the client's own words by surprise.

## Gherkin
Feature: Deliberate re-fetch

  Scenario: Re-fetch fresh details for a changed address
    Given the client is editing an item and has changed the web address
    When the client presses "Re-fetch info from this link"
    Then fresh title, summary, and image are pulled for the new address
    And this never happens automatically, only on that press

## Assumptions
- Re-fetch is an explicit, manual action. (Approved.)
