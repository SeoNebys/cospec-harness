Scenario ID: SCN-007
Title: Add a personal note to a bookmark
Type: Happy Path
Approval status: approved
Approval session: SESSION-007
Approval cycle: 1

## Approved behaviour

The client can open a bookmark's secondary-action menu and add a personal note in a focused window. After saving, the note remains visibly attached to the bookmark card, making it useful as a reminder when the client returns to the collection. The application confirms that the note was saved and will stay with the bookmark.

## Gherkin

Feature: Keep personal context with saved bookmarks

  Scenario: Add a note from a bookmark card
    Given a saved bookmark does not have a personal note
    When the user chooses to add a note from the bookmark's secondary-action menu
    And enters and saves a reminder
    Then the reminder is displayed on the bookmark card
    And the application confirms that the note was saved with the bookmark

## Assumptions

- Adding a note is a secondary action in the same card menu used for other infrequent actions.
- A bookmark has one personal note, which can contain free-form text.
- Editing a saved note is explored separately as an edge case.
