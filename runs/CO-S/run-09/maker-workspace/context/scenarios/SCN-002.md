Scenario ID: SCN-002
Title: Re-saving a link updates the existing bookmark without duplication
Type: Edge Case
Approval status: approved
Approval session: SESSION-002
Approval cycle: 1

## Approved behaviour
When a person pastes a web address already in the library, the app stops before creating another copy, clearly identifies the matching bookmark, and offers a Review & update action instead of silently overwriting it. The original bookmark opens with its current title and description already filled in and explains that changes apply to the existing item. Saving changes updates that one library card, gives a distinct confirmation, and leaves the bookmark count unchanged.

## Gherkin
Feature: Prevent duplicate bookmarks

  Scenario: Detect a link that is already saved
    Given the library contains a bookmark for a web address
    When the person pastes the same web address again
    Then the app says that the bookmark is already in the library
    And the app shows which existing bookmark matched
    And the app does not create a second bookmark
    And the app offers to review and update the existing bookmark

  Scenario: Review the existing bookmark
    Given the app has detected a web address already in the library
    When the person chooses to review and update it
    Then the original bookmark opens with its current title and description filled in
    And the app explains that changes apply to the existing bookmark without making a copy

  Scenario: Save changes to the existing bookmark
    Given the person has changed the title of the existing bookmark
    When the person saves the changes
    Then the app confirms that the bookmark was updated
    And the original library card shows the changed title
    And the library still contains exactly one bookmark for that web address

## Assumptions
- Duplicate detection occurs before a second bookmark can be saved.
- A duplicate is identified by its web address.
- The app does not silently replace the person's existing title or description.
- Review and update uses a prefilled form for the original bookmark.
