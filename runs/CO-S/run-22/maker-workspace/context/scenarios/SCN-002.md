Title: Organise links with tags and narrow the list by tag
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When saving a link, the client can attach one or more tags. A tag is entered by
typing a word and pressing Enter (or comma), which turns it into a removable
chip; tags are stored lower-cased so differently-cased spellings of the same word
do not become duplicates, and the same tag cannot be added twice to one link. A
saved link displays its tags. Above the saved-links list, a "Filter by tag" row
lists all tags currently in use. Clicking a tag narrows the list to links carrying
that tag and the count reflects the narrowed view; clicking the same tag again, or
"clear filter", restores the full list. A tag shown on a saved link can also be
clicked to filter by it. Filtering by one tag at a time is sufficient for the
client's basic organisation needs.

## Gherkin
Feature: Organising links with tags

  Scenario: Attach tags while saving a link
    Given the client is saving a link
    When the client types a word in the tags field and presses Enter
    Then the word becomes a removable tag chip on the form
    And the tag is stored in lower case
    And saving the link stores it with those tags and displays them on the link

  Scenario: Duplicate and case-variant tags are not duplicated
    Given a tag "work" has been added to the current link
    When the client adds "Work" or "work" again
    Then only a single "work" tag remains on the link

  Scenario: Narrow the list by clicking a tag
    Given saved links carry various tags
    When the client clicks a tag in the filter row or on a link
    Then the list shows only links carrying that tag
    And the count reflects the narrowed list

  Scenario: Clear the tag filter
    Given the list is filtered by a tag
    When the client clicks the active tag again or clicks "clear filter"
    Then the full list of saved links is shown again

## Assumptions
- Tag entry is by typing then pressing Enter/comma, producing chips.
- Tags are lower-cased and de-duplicated per link.
- Filtering is by a single tag at a time (not multi-tag combinations).
- Free-text search is a separate flow, explored next.
