Scenario ID: SCN-010
Title: Search for an exact quoted phrase
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Text enclosed in quotation marks is searched as one uninterrupted phrase rather than as loose words. Matching results show the exact phrase in context.

## Gherkin
Feature: Searching saved bookmarks

  Scenario: Find an exact phrase
    Given one bookmark contains the uninterrupted phrase "visual hierarchy"
    And other bookmarks may contain either word separately
    When the person searches for '"visual hierarchy"'
    Then only bookmarks containing that uninterrupted phrase appear
    And each result shows the exact phrase in its matching context

## Assumptions
- Double quotation marks indicate exact-phrase matching.
- Exact-phrase matching ignores capitalization while preserving word order and adjacency.
