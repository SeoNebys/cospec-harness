Scenario ID: SCN-016
Title: Per-bookmark offline copy and manual Internet Archive submission
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

Offline copy: each bookmark can have a single offline copy. The app chooses the
type automatically — a self-contained single-page file for a normal page, or the
original PDF file for a PDF link. Saving shows an indicator (a badge) and offers
Open offline copy and Remove offline copy. To refresh a copy, the user removes it
and saves again. Offline capture is a per-bookmark action (no bulk capture).

Internet Archive: a separate, manual per-bookmark action submits the page to the
Internet Archive; it must not happen automatically on every save (private saves
should not be published). After submission the bookmark offers a link to the
public archived snapshot. No bulk Archive submission.

Neither offline capture nor Archive submission counts as a "meaningful change"
for Recently-updated sorting.

## Gherkin
Feature: Offline copy and Internet Archive

  Scenario: Save an offline copy of a normal page
    Given a bookmark to a normal page
    When the user saves it offline
    Then a self-contained page snapshot is kept and an "Offline copy" indicator and Open/Remove actions appear

  Scenario: Save a PDF link offline preserves the PDF
    Given a bookmark whose link is a PDF
    When the user saves it offline
    Then the original PDF is kept (a "PDF saved" indicator) rather than a page snapshot

  Scenario: Refresh an offline copy
    Given a bookmark with an offline copy
    When the user removes it and saves offline again
    Then a fresh copy replaces the old one

  Scenario: Manual Internet Archive submission
    Given a bookmark
    When the user submits it to the Internet Archive
    Then submission happens only on that explicit action and a link to the public snapshot is offered
    And saving a bookmark never submits to the Archive automatically

## Assumptions
- The prototype simulates capture and Archive submission; production performs the
  real capture (single-file page / PDF) and Archive save request.
- Offline copy and Archive submission are per-bookmark only (no bulk actions).
