Scenario ID: SCN-004
Title: Open a saved bookmark from the collection
Type: Happy Path
Approval status: approved
Approval session: SESSION-004
Approval cycle: 1

## Approved behaviour
Saved bookmarks are shown newest first. Each item clearly shows its page title, short description, site icon, and web address. Clicking the full title opens the saved page in a new browser tab while leaving the collection open in its current place.

## Gherkin
Feature: Viewing saved bookmarks

  Scenario: Open a saved bookmark
    Given the collection contains saved bookmarks ordered newest first
    When the person clicks a bookmark's title
    Then the saved web address opens in a new browser tab
    And the bookmark collection remains open at its current place

  Scenario: View a bookmark in the collection
    Given the collection contains a saved bookmark with retrieved page details
    Then the bookmark shows its title, short description, site icon, and web address

## Assumptions
- The full bookmark title is the link-opening control.
- Newest-first is the default ordering.
