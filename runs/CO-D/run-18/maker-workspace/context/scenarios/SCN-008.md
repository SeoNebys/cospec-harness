Scenario ID: SCN-008
Title: Archive and restore a bookmark without losing information
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
An active bookmark has a direct, one-click Archive button on its library card. Archiving immediately removes it from the active library without a confirmation interruption because the action is reversible. The Archive sidebar view contains only archived bookmarks and preserves each bookmark's title, tags, web address, note, and other information. Restoring an archived bookmark removes it from the archive and returns it to the active library with all information intact. The client selected the direct button after comparing it with an overflow-menu action.

## Gherkin
Feature: Archive bookmarks

  Scenario: Archive an active bookmark
    Given an active bookmark is visible in the library
    When the user selects its direct "Archive" button
    Then the bookmark immediately leaves the active library
    And no confirmation is required
    And the bookmark and all its information remain stored in the archive

  Scenario: View archived bookmarks separately
    Given the library contains active and archived bookmarks
    When the user opens "Archive" from the sidebar
    Then only archived bookmarks are visible
    And each archived bookmark retains its title, tags, web address, note, and other saved information

  Scenario: Restore an archived bookmark
    Given a bookmark is visible in the archive
    When the user restores it and returns to all bookmarks
    Then the bookmark leaves the archive
    And it reappears in the active library
    And all its saved information remains intact

## Assumptions
- The direct Archive action is available on library cards.
- Archiving is reversible and therefore does not require confirmation.
- Active bookmarks do not appear in the archive view, and archived bookmarks do not appear in the active library.
