Scenario ID: SCN-014
Title: Search for an exact phrase
Type: Happy Path
Approval status: approved
Approval session: SESSION-014
Approval cycle: 1

## Approved behaviour
Text inside quotation marks is matched as an exact phrase: its words must be adjacent and in the same order. Phrase matching ignores capitalization. Bookmarks containing the individual words only in other positions are excluded.

## Gherkin
Feature: Search for exact phrases

  Scenario: Distinguish an exact phrase from separated words
    Given one bookmark contains the adjacent words "A Weekend"
    And another bookmark contains "A" and "Weekend" separated by other words
    When the person searches for "\"a weekend\""
    Then the bookmark containing the adjacent phrase is shown
    And the bookmark containing only the separated words is not shown

  Scenario: Match an exact phrase without regard to capitalization
    Given a bookmark contains the phrase "A Weekend"
    When the person searches for "\"A WEEKEND\""
    Then that bookmark is included in the results

## Assumptions
- Quotation marks require adjacent words in the same order.
- Exact phrase matching remains capitalization-insensitive.
