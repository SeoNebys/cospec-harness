Scenario ID: SCN-013
Title: Keep long bookmark content complete while cards remain scannable
Type: Edge Case
Approval status: approved
Approval session: SESSION-013
Approval cycle: 1

## Approved behaviour
When a bookmark has an unusually long title, description, personal note, and many tags, the library card shortens the long text previews with an ellipsis and wraps tags cleanly so the overview remains tidy. Opening Edit bookmark presents the full uncut title, description, and note for reading and editing. Display shortening never discards the person's content.

## Gherkin
Feature: Display long bookmark content

  Scenario: Show long content on a library card
    Given a bookmark has a very long title, description, personal note, and several tags
    When the person views it in the library
    Then the card shows compact shortened previews of the long text
    And the card wraps the tags cleanly
    And the card remains scannable

  Scenario: Edit the full long content
    Given long bookmark text is shortened on its library card
    When the person opens Edit bookmark
    Then the full title is present and editable
    And the full description is present and editable
    And the full personal note is present and editable

## Assumptions
- Text is shortened only for the library-card presentation.
- Shortening is visibly indicated with an ellipsis.
- The stored content is never truncated.
