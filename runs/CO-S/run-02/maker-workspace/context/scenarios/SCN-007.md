## Approved behaviour
Three save-time problems are handled gracefully rather than silently:

1. Title lookup fails — when the app cannot reach the page to fetch its title,
   it does not hang or insert garbage. It tells the user it couldn't grab the
   title, reassures them the link is still fine to save, and lets them type
   their own name and continue.

2. Duplicate link — when the user tries to save a link they already saved, the
   app does not create a silent duplicate. It warns that this link is already
   saved, names the existing bookmark, and offers to jump to it. (Avoiding
   clutter/duplicates is a core user goal.)

3. Not a link — when the user tries to save text that doesn't look like a web
   link, the app gently flags it (suggesting they check it or add https://)
   rather than saving junk.

## Gherkin
Feature: Save-time error handling

  Scenario: Page title cannot be fetched
    Given the user has entered a link whose page cannot be reached
    When the title lookup fails
    Then the app tells the user the title couldn't be grabbed
    And it lets the user type their own name
    And the link can still be saved

  Scenario: Saving a link that already exists
    Given a link is already saved
    When the user tries to save the same link again
    Then the app warns that it is already saved
    And it identifies the existing bookmark and offers to show it
    And no duplicate is created

  Scenario: Saving text that is not a link
    Given the user has entered text that is not a web link
    When the user tries to save
    Then the app flags that it doesn't look like a link
    And nothing is saved until corrected

## Assumptions
- On title-fetch failure, saving is still allowed with a user-typed name
  (client confirmed).
- Duplicates are detected and blocked-with-warning, not silently allowed
  (client confirmed). Duplicate matching ignores things like a leading
  http(s)://, www., and a trailing slash (facilitator assumption for what
  counts as "the same link"; exact rule is a Phase 2 detail).
- Non-link input is flagged and blocks saving until corrected (client confirmed).
