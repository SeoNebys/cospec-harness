Scenario ID: SCN-001
Title: Save a recognizable bookmark from a page address
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

From an empty personal bookmark library, the client pastes a page address into a clear address box at the top and saves it. The saved bookmark appears in the library with the page's real title, a plain-language description, and the website name, making it recognizable without opening the page.

## Gherkin

Feature: Save bookmarks

  Scenario: Save a link with recognizable page details
    Given the personal bookmark library is empty
    And a clear address box for saving a bookmark is shown at the top
    When the user enters a page address and saves the bookmark
    Then the bookmark appears in the library
    And it shows the page title
    And it shows a plain-language page description
    And it shows the website name

## Assumptions

- Saving a bookmark begins from a prominent address box at the top of the library.
- The app obtains page details automatically after the user supplies the address.
- A bookmark's recognizable summary consists of its title, description, and website name.
