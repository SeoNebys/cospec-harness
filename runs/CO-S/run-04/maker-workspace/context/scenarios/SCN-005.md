Scenario ID: SCN-005
Title: First-time / empty state
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When there are no saved links (e.g. a brand-new user), the list area shows a
welcoming empty state instead of a blank space: a bookmark icon, a "No links
saved yet" heading, and a short line telling the user to paste a link in the box
above and it will show up here. The saving box is still present and usable. The
count line is hidden while empty. Once the first link is saved, the empty state
is replaced by the list. Clearing the last remaining link returns to this state.

## Gherkin
Feature: Empty state

  Scenario: New user sees a welcoming empty state
    Given there are no saved links
    When the user opens the bookmarks page
    Then a welcoming empty-state message explains how to add the first link
    And the saving box is available
    And no saved-links count is shown

  Scenario: Empty state disappears after first save
    Given the empty state is shown
    When the user saves their first link
    Then the list replaces the empty state

## Assumptions
- The empty state is friendly/instructional, not an error.
- Returning to zero links (after removing the last one) shows the empty state again.
