Scenario ID: SCN-012
Title: Keep unusually long bookmark details skimmable
Type: Edge Case
Approval status: approved
Approval session: SESSION-012
Approval cycle: 1

## Approved behaviour
The client viewed an unusually long bookmark above a normal bookmark. The long title and description were limited to two lines each, four tags remained visible, and four additional tags were summarized. The client confirmed this retained enough context to recognize the page without allowing it to overwhelm or bury nearby bookmarks.

## Gherkin
Feature: Browse bookmarks

  Scenario: Display a bookmark with unusually long details and many tags
    Given a bookmark has an unusually long title and description
    And the bookmark has more than four tags
    When the collection is displayed
    Then the title is limited to two lines
    And the description is limited to two lines
    And the first four tags are visible
    And the number of additional tags is summarized
    And the next bookmark remains readily visible and readable

## Assumptions
- Full bookmark details remain available through editing and the destination page.
- Tag order determines which four tags are shown on a compact card.
