Scenario ID: SCN-004
Title: Add an existing tag from narrowing suggestions
Type: Happy Path
Approval status: approved
Approval session: SESSION-004
Approval cycle: 1

## Approved behaviour
A person adds a tag directly on a bookmark card. Typing narrows a compact suggestion list of tags they have already used. Selecting an existing tag immediately attaches it to the bookmark, nudging the person away from creating slightly different versions of the same tag. A compact list is preferred over a spread of visible tag chips.

## Gherkin
Feature: Reuse bookmark tags consistently

  Scenario: Attach an existing tag from suggestions
    Given the person has previously used the tag "Design"
    And a bookmark is visible in the collection
    When the person starts adding a tag on that bookmark
    And types text that matches "Design"
    Then a compact suggestion list includes the existing "Design" tag
    When the person selects "Design"
    Then the tag is immediately attached to the bookmark

## Assumptions
- Tag matching ignores letter case when finding suggestions.
- Selecting a suggestion is enough to save that tag assignment.
- Tag suggestions are shown in a compact list that narrows while typing.
