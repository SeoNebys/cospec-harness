Scenario ID: SCN-006
Title: Filter by tag with a tag filter bar, combinable with search and views
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

Under the search box there is a **"Filter by tag:"** bar listing all of the
user's tags (chosen over clicking a tag on a card, so the user can browse all
tags without first finding an item that has the right one). Tapping a tag shows
only bookmarks with that tag; tapping it again clears it. The chosen tag is
highlighted, and the list heading reflects the active tag.

The tag filter **combines** with the text search and with the current view
(All / To read / Archived): all active constraints apply together (logical AND
across view + tag filter + search query). Tag chips shown on a card are also
clickable and set the same tag filter.

## Gherkin
Feature: Tag filter bar

  Scenario: Filter to a single tag
    Given the tag filter bar lists the user's tags
    When the user taps the tag "dev"
    Then only bookmarks tagged "dev" (in the current view) are shown
    And tapping "dev" again removes the filter

  Scenario: Combine tag filter with search
    Given the tag "dev" filter is active
    When the user also types a search query
    Then only bookmarks matching both the tag and the query are shown

  Scenario: Tag filter respects the current view
    Given the Archived view is selected
    When a tag filter is active
    Then only archived bookmarks with that tag are shown

## Assumptions
- The tag filter bar lists every tag the user has.
- View + tag filter + search combine with AND.
