Scenario ID: SCN-014
Title: Preserve a saved copy of the page (and PDFs), with optional Internet Archive
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When a readable bookmark is saved, the app automatically keeps a private local
copy captured at save time. For a normal page the copy is a self-contained single
HTML file that works independently (offline). For a PDF, the actual PDF file is
preserved. Each card shows the saved-copy status (with capture date) and a way to
open it; PDFs are labelled as a saved PDF. Submitting a copy to the public
Internet Archive is an explicit, optional action (a checkbox at save time or a
"Send to Internet Archive" action later); once present, an "Internet Archive copy"
link is shown. The copy is captured once and is NOT silently replaced later. If a
capture fails (page unreadable at save), no copy exists yet and it can be retried
once the page becomes available (the retry then captures the copy). Archiving a
bookmark keeps its saved copy; permanently deleting the bookmark also removes its
saved copy.

## Gherkin
Feature: Page preservation

  Scenario: Automatic local copy on save
    When a readable page is saved
    Then a private local copy is captured at save time
    And for a normal page it is a self-contained single HTML file
    And for a PDF the actual PDF file is preserved

  Scenario: Open the saved copy
    Given a bookmark with a saved copy
    When the user opens the saved copy
    Then the page as captured (with its capture date) is shown, working offline

  Scenario: Optional Internet Archive submission
    Given a bookmark whose page is preserved locally
    When the user opts to also save it to the Internet Archive
    Then an Internet Archive copy link becomes available

  Scenario: Capture once, not silently replaced
    Given a bookmark with a saved copy
    Then the copy is not automatically re-captured later

  Scenario: Retry a failed capture
    Given a bookmark whose capture failed because the page was unavailable
    When the page becomes available and the user retries
    Then the copy is captured

  Scenario: Archive keeps the copy; delete removes it
    Given a bookmark with a saved copy
    When the bookmark is archived
    Then the saved copy is kept
    When the bookmark is permanently deleted
    Then the saved copy is removed too

## Assumptions
- Local copy: self-contained single HTML for pages; original file for PDFs.
- Internet Archive is a real external service; availability is reported honestly
  at build/verification time. Prototype simulates it offline.
- No automatic re-capture; a manual refresh/re-capture is NOT included (recorded
  as a possible later option, L-10).
