# Business goal statement

- Cycle: 1
- Session: SESSION-001
- Interface form: Web app (opened in a browser)

## Confirmed goal (client's own words)

> I want one private place for my own bookmarks. Right now they're scattered
> across browser folders, and I often can't remember where I saved something or
> whether I saved it at all.
>
> I'd like to paste in a web address and have the app pick up the page's details
> automatically, while still letting me add tags or notes and correct anything.
> Later, I want to find links quickly by searching or filtering, keep a separate
> "read later" list, and archive things I want to retain without cluttering the
> main list. It's just for me.

## Heart of the goal (confirmed)

One trustworthy, private place where nothing gets lost and links can always be
found again.

- Most important: reliably saving a link and finding it again.
- Automatic page details make saving quicker, but the client must always be able
  to correct them.
- Single user; private use only.

## Desired capabilities mentioned (to explore across the cycle)

1. Save a link by pasting a web address; page details auto-fill; editable.
2. Add tags and notes; correct anything auto-filled.
3. Find links quickly by searching or filtering.
4. A separate "read later" list.
5. Archive links to retain them without cluttering the main list.
