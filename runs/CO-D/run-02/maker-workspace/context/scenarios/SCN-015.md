Scenario ID: SCN-015
Title: Sort a view (and its search results) by date or title
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

A "Sort by" control above the list orders the current view and its search
results. The available orders are: Newest first (default), Oldest first, Recently
updated, Title A–Z, and Title Z–A. The chosen order applies consistently to
whichever view (Collection, Reading list, Archive) and search the client is in,
and persists as they move between views. Title sorting ignores letter case.

## Gherkin

Feature: Sorting

  Scenario: Change the sort order
    Given a view with several bookmarks
    When I choose a sort order (newest, oldest, recently updated, title A–Z, title Z–A)
    Then the list is reordered accordingly

  Scenario: Sort applies across views and search
    Given a chosen sort order
    When I switch views or run a search
    Then the results remain in the chosen order

  Scenario: Default order
    Given I have not changed the sort
    Then bookmarks are shown newest first

## Assumptions
- The client's own default order will be configurable later (see EB-08); the
  built-in default is Newest first.
