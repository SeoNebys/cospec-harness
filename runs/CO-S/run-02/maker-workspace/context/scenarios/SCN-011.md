Scenario ID: SCN-011
Title: Preserve captured bookmark details over time
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
After a bookmark is saved, its captured title remains unchanged even if the source page changes its title. The saved title changes only when the client edits it.

## Gherkin
Feature: Preserving bookmark details

  Scenario: Source page title changes after saving
    Given a bookmark was saved with a captured title
    And the source page later changes its title
    When the user views the saved bookmark
    Then the bookmark still shows the originally captured title
    When the user edits the bookmark title
    Then the bookmark shows the user-entered title

## Assumptions
- Saved bookmark metadata is a stable snapshot and is not refreshed automatically.
