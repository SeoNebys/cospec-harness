Scenario ID: SCN-015
Title: Reject a malformed web address without losing input
Type: Error Case
Approval status: approved
Approval session: SESSION-015
Approval cycle: 1

## Approved behaviour
Attempting to save malformed text is blocked and creates no bookmark. The entered text remains in the field for correction, and a clear, non-scolding message gives an example of a complete web address.

## Gherkin
Feature: Validate a web address before saving

  Scenario: Attempt to save malformed address text
    Given the person has entered "not a web address"
    When the person selects Save link
    Then no bookmark is created
    And the entered text remains available to correct
    And a message asks for a complete web address
    And the message includes an example such as "https://example.com"

## Assumptions
- Only complete HTTP or HTTPS web addresses can be saved.
