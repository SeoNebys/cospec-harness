Scenario ID: SCN-009
Title: Correct bookmark details without losing organization
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

The client can open a focused edit window containing an existing bookmark's address, title, and description. When the address is corrected to a cleaner version of the same page, the changed fields are saved while the bookmark's tags, formatted note, read-later state, site identity, and preview remain intact.

## Gherkin

Feature: Correct bookmark details

  Scenario: Correct a gathered title and description
    Given an existing bookmark has gathered page details
    When the client edits the bookmark's title and description
    And saves the changes
    Then the corrected title and description are displayed
    And the bookmark's address, tags, note, read-later state, site identity, and preview remain unchanged

  Scenario: Replace a cluttered address with a clean address for the same page
    Given an existing bookmark has a tracking-cluttered address
    And the bookmark has tags, a formatted note, and a read-later flag
    When the client replaces the address with a clean address for the same page
    And saves the changes
    Then the bookmark opens the clean address
    And its title, description, tags, note, read-later state, site identity, and preview remain unchanged

## Assumptions

- The corrected address in this scenario identifies the same underlying page.
- Behaviour when the corrected address identifies a genuinely different page or site is covered by SCN-017.
- Editing the address, title, and description uses a focused window rather than expanding those fields directly on the bookmark.
