Scenario ID: SCN-008
Title: Correct the saved details of a bookmark inline
Type: Happy Path
Approval status: approved
Approval session: SESSION-008
Approval cycle: 1

## Approved behaviour
A person can edit a bookmark's web address, title, and description directly inside its card. The form is prefilled with the existing values, so only incorrect details need to be changed. Saving a corrected address updates the source shown on the card while preserving the person's current title and description rather than fetching replacements for them.

## Gherkin
Feature: Edit a saved bookmark

  Scenario: Correct an automatically gathered title
    Given a bookmark has a gathered title and description
    When the person opens its inline details editor
    Then the existing web address, title, and description are prefilled
    When the person changes the title and saves
    Then the card shows the corrected title
    And the unchanged description remains as it was

  Scenario: Correct a bookmark's web address without overwriting its details
    Given a bookmark has a title and description the person wants to keep
    When the person changes its web address in the inline editor and saves
    Then the bookmark uses the corrected address
    And the source shown on the card updates to match the corrected address
    And the current title and description remain unchanged

## Assumptions
- Editing happens directly inside the bookmark card.
- Existing values are prefilled.
- Correcting an address does not automatically gather a replacement title or description.
