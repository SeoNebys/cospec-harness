Scenario ID: SCN-018
Title: Save and reuse named searches (query + tag filter + view)
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

The user can save the current search as a named, reusable saved search. A saved
search **captures the whole combination**: the text query, the active tag filter,
and the current view (All / To read / Archived) — this is what makes it a reusable
filter rather than just saved text. Saved searches appear as chips; clicking one
re-applies its whole combination at once and highlights it as active; a small ×
removes it.

The **Save** action is disabled when there is nothing to save (empty query, no
tag filter, default view) or when the exact same combination is already saved, so
duplicates and empty saves are prevented.

**Sort order is deliberately NOT part of a saved search** — sorting stays
independent so the user can reorder results without changing the saved search.

## Gherkin
Feature: Saved searches

  Scenario: Apply a saved search
    Given a saved search exists
    When the user clicks it
    Then its text query, tag filter and view are all applied together
    And it is highlighted as the active saved search

  Scenario: Save the current search
    Given the current search has a query, tag filter, or non-default view
    And the same combination is not already saved
    When the user saves it and gives it a name
    Then it appears as a reusable saved search

  Scenario: Prevent empty or duplicate saves
    Given the current search is empty (default) or identical to an existing saved search
    Then the Save action is unavailable

  Scenario: Remove a saved search
    When the user removes a saved search
    Then it no longer appears

  Scenario: Sorting is independent of saved searches
    Given a saved search is applied
    When the user changes the sort order
    Then the saved search itself is unchanged

## Assumptions
- Captured criteria: text query + tag filter + view (not sort).
- Names are user-provided (with a suggested default).
