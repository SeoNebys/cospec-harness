Title: Search directly by label
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Typing a label prefixed with `#` into the main search box returns every bookmark carrying that label. Label search ignores capitalization, and each result identifies the matching label as its reason for appearing.

## Gherkin
Feature: Searching saved bookmarks

  Scenario: Find all bookmarks carrying a named label
    Given two bookmarks carry the label "Cooking"
    When the person searches for "#cooking"
    Then both bookmarks carrying "Cooking" appear
    And other bookmarks do not appear
    And each result identifies "#Cooking" as the reason it matched

## Assumptions
- A leading `#` distinguishes a label search from ordinary text search.
- Label search ignores capitalization.
- The label name after `#` is matched as a complete label.
