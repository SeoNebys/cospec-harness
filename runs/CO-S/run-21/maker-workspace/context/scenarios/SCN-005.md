Scenario ID: SCN-005
Title: Deliberately create and attach a new tag
Type: Happy Path
Approval status: approved
Approval session: SESSION-005
Approval cycle: 1

## Approved behaviour
When typed tag text has no exact existing match, the compact suggestion list shows a distinct, clearly labelled choice to create that text as a new tag. Selecting it deliberately creates the tag and immediately attaches it to the bookmark, consistent with selecting an existing tag. The creation choice does not appear when an exact tag already exists.

## Gherkin
Feature: Create bookmark tags when needed

  Scenario: Create a tag when no exact existing tag matches
    Given a person is adding a tag to a bookmark
    And no existing tag exactly matches the text they type
    When they type the new tag text
    Then the suggestion list shows a distinct choice labelled as creating a new tag
    When they select that choice
    Then the app creates the new tag
    And immediately attaches it to the bookmark

  Scenario: Do not offer duplicate tag creation
    Given a person is adding a tag to a bookmark
    And an existing tag exactly matches the text they type
    When they type that text
    Then the app does not offer to create a new tag with the same text

## Assumptions
- Exact matching ignores letter case.
- New-tag creation uses the same compact suggestion list as existing-tag selection.
