Scenario ID: SCN-003
Title: Change tags and edit the note on a saved item later
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

On any already-saved item the user can adjust how it is organized after the
fact:
- **Remove a tag** by clicking the × on its chip.
- **Add a tag** by typing in the item's tag field, with the same existing-tag
  suggestions and "Create …" option as when saving.
- **Edit the note**: an item with a note shows an "edit" affordance to change
  its text; an item without a note shows an "＋ Note" affordance to add one.

This lets the user keep organization current as the way they think about their
links changes.

## Gherkin
Feature: Edit tags and note after saving

  Scenario: Remove a tag from a saved item
    Given a saved item has the tag "reference"
    When the user clicks the × on the "reference" tag
    Then the tag is removed from that item

  Scenario: Add a tag to a saved item with suggestions
    Given a saved item is shown
    When the user types in that item's tag field
    Then existing-tag suggestions and a "Create …" option appear
    And selecting or creating a tag adds it to that item

  Scenario: Edit an existing note
    Given a saved item has a note
    When the user chooses to edit the note and changes the text
    Then the item shows the updated note

  Scenario: Add a note to an item that has none
    Given a saved item has no note
    When the user chooses "add note" and enters text
    Then the item shows the new note

## Assumptions
- Tag editing on a saved item uses the same suggestion behaviour as SCN-002.
