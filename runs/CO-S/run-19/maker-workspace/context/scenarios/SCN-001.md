Scenario ID: SCN-001
Title: Save a recognizable bookmark from a link
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

Starting from an empty personal library, the client pastes a web address into one field and activates one save button. The app saves the link and presents a recognizable bookmark containing the page title, a short description, the source, when it was saved, and a preview image.

## Gherkin

Feature: Save a bookmark

  Scenario: Save a link with recognizable page details
    Given the personal bookmark library is empty
    And page details are available for a valid web address
    When the user pastes the web address into the save field
    And saves the bookmark
    Then one bookmark is added to the library
    And the bookmark shows the page title
    And the bookmark shows a short description
    And the bookmark shows the source
    And the bookmark shows when it was saved
    And the bookmark shows a preview image

## Assumptions

- The library belongs to one person and requires no account selection or sign-in.
- The page details can be retrieved successfully for this scenario.
- The saved time is presented in a human-readable form.
- Saving requires one text field and one explicit save action.
