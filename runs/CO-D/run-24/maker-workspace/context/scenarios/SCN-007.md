Scenario ID: SCN-007
Title: Sort the list (newest/oldest, title A–Z/Z–A) via a dropdown
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

A compact dropdown control lets the client change the order of the shown list.
The client chose the dropdown after comparing it against a segmented button strip
and a menu-button; the dropdown was preferred for staying tidy on both computer
and phone while clearly showing the current order.

Available orders: Newest first, Oldest first, Title A–Z, Title Z–A. "Newest first"
is the default order on load. Sorting applies to the currently shown list, so it
works together with the active tab and any search. Title sorting is
case-insensitive.

## Gherkin

Feature: Sort

  Scenario: Default order
    Given the list is shown
    Then bookmarks are ordered newest first by default

  Scenario: Change sort order
    Given the list is shown
    When the client selects "Oldest first", "Title A–Z", or "Title Z–A" from the sort dropdown
    Then the shown list reorders accordingly

  Scenario: Sort works with tab and search
    Given a tab is active and/or a search is applied
    When the client changes the sort order
    Then only the currently shown bookmarks are reordered

## Assumptions

- Sort control is a compact dropdown (client's chosen interaction).
- Orders: newest, oldest, title A–Z, title Z–A; default newest first.
- Title sort is case-insensitive; sort applies after tab + search filtering.
