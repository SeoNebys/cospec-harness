Scenario ID: SCN-017
Title: Import and export browser bookmarks
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The user can import a standard browser bookmarks HTML file (Chrome/Firefox/Safari/
Edge). On import, titles, tags, and original dates are retained; browser folders
become tags. Addresses that already exist are skipped (never overwritten or
silently merged), and the import summary clearly reports how many were imported and
how many skipped. The user can export a standard, browser-compatible bookmarks HTML
file that retains titles, tags, and original dates. This export is described as a
browser-compatible export, NOT a complete backup: it does not carry notes,
read/archive state, or saved page copies. The empty state offers a working import
action.

## Assumptions
- Folders -> tags on import; duplicates skipped by same-address rule (SCN-005).
- Export omits notes, read/archive state, and saved copies by design.
- A full-fidelity backup/restore is a possible later option (L-11).
