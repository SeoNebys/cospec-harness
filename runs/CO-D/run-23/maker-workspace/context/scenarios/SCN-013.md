Scenario ID: SCN-013
Title: Apply an action to multiple selected bookmarks
Type: Happy Path
Approval status: approved
Approval session: SESSION-013
Approval cycle: 1

## Approved behaviour
The everyday library stays uncluttered until the person deliberately enters selection mode. They can select individual bookmarks or select every bookmark visible in the current search or label-filtered view; hidden bookmarks are never silently included. One action bar then applies a change to the selected bookmarks and clears the selection afterward. Labels can be added or removed, reading status can be changed to read or unread, and bookmarks can be put away or permanently deleted in a batch. These actions operate on the existing bookmarks without making duplicates. Bulk Put away preserves selected bookmarks intact in the separate Put away view. Bulk Delete names every selected bookmark, warns that their saved copies will be removed, offers a way to back out, and leaves unselected bookmarks untouched.

## Gherkin
Feature: Manage multiple bookmarks

  Scenario: Enter selection mode only when needed
    Given the person is viewing the everyday library
    Then selection checkboxes and bulk actions are hidden
    When the person chooses Select bookmarks
    Then selection controls appear on the visible cards

  Scenario: Select all bookmarks in a filtered view
    Given a filter shows two of three bookmarks
    And the person is in selection mode
    When the person chooses Select all results
    Then the two visible bookmarks are selected
    And the hidden third bookmark is not selected

  Scenario: Add or remove a label from selected bookmarks
    Given two bookmarks are selected
    When the person adds an existing label to the selection
    Then that same label is attached to both bookmarks without creating a duplicate label
    And the selection clears
    When the person selects those bookmarks and removes that label
    Then the label is removed from both bookmarks
    And the selection clears

  Scenario: Mark selected bookmarks unread or read
    Given two bookmarks are selected
    When the person marks the selection unread
    Then both existing bookmarks appear in Read later
    And no bookmark is duplicated
    When the person selects them and marks them read
    Then both bookmarks leave Read later

  Scenario: Put selected bookmarks away
    Given two of three bookmarks are selected
    When the person chooses Put away
    Then the selected bookmarks leave the main library
    And the unselected bookmark remains there
    And both selected bookmarks remain intact in the Put away view

  Scenario: Permanently delete selected bookmarks
    Given two of three bookmarks are selected
    When the person chooses Delete
    Then the app names both selected bookmarks
    And it warns that their saved copies will be permanently removed
    And it offers a way to keep them or confirm deletion
    When the person confirms deletion
    Then the two selected bookmarks and their saved copies are removed
    And the unselected bookmark remains in the library

## Assumptions
- Bulk controls are hidden until selection mode is entered.
- The action bar contains Labels, Reading, Put away, and Delete.
- Labels groups both add and remove; Reading groups both mark read and mark unread.
- Select all is always scoped to the current visible result set.
- Bulk deletion requires confirmation; bulk Put away does not.
