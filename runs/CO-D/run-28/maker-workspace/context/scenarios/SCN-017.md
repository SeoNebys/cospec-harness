Scenario ID: SCN-017
Title: Save a search + tags as a reusable, live collection
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The client can save the current search — its search text plus the included tag
chips — as a named collection. Excluded tags are preserved naturally inside the
search text as NOT #tag. Saved collections appear as clickable chips under the
fixed view tabs (All / To read / Archived), distinct from those views. Clicking a
collection re-applies its search text and included tags in one action, and the
chip highlights while the current criteria match it; diverging un-highlights it.
A collection can be removed via a small × on its chip. A "Save current search"
control appears only when a search or tags are active and the current criteria are
not already saved.

Collections are LIVE saved searches: they store the criteria, not a frozen result
set, so opening one later shows whatever bookmarks match at that time.

## Gherkin
Feature: Saved collections (live saved searches)

  Scenario: Save the current search and tags as a collection
    Given the client has a search text and/or included tag chips active
    When the client saves it as a named collection
    Then a collection chip appears under the view tabs

  Scenario: Apply a collection
    Given a saved collection exists
    When the client clicks its chip
    Then its search text and included tags are re-applied
    And the chip is highlighted while the criteria match

  Scenario: Collections are dynamic
    Given a saved collection
    When bookmarks matching its criteria change over time
    Then opening the collection shows the currently matching bookmarks, not a snapshot

  Scenario: Remove a collection
    Given a saved collection chip
    When the client removes it with its ×
    Then the collection no longer appears

## Assumptions
- Excluded tags are represented as NOT #tag within the saved search text.
- A collection stores criteria (search text + included tags), not results.
