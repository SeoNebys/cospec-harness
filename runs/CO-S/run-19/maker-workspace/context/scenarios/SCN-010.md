Scenario ID: SCN-010
Title: Read a preserved copy when the original page is unavailable
Type: Happy Path
Approval status: approved
Approval session: SESSION-010
Approval cycle: 1

## Approved behaviour

Saving a bookmark captures a readable copy of the page's meaningful content and details. Opening the bookmark uses a dedicated, focused reading page. When the original page is unavailable, the app clearly explains that it is showing the saved copy, identifies when the copy was captured, preserves the title, description, source, author and date, image, and readable page text, and still offers a way to try the original address.

## Gherkin

Feature: Preserve saved pages

  Scenario: Read a saved page after the original becomes unavailable
    Given a bookmark was saved with a readable copy of its page
    And the original page is now unavailable
    When the user opens the bookmark
    Then a dedicated reading page shows the saved copy
    And the page explains that the original is unavailable
    And the page shows when the copy was captured
    And the saved title, description, source, author, publication date, image, and readable page text are available
    And the user can still choose to try the original address
    When the user returns to the library
    Then the bookmark list is visible again

## Assumptions

- A readable page copy is captured at the time the bookmark is saved.
- The saved copy is displayed on a dedicated reading page rather than beside the library.
- The app preserves meaningful readable content and page details, not only the raw address.
- The original address remains available even when a saved copy is shown.
