Scenario ID: SCN-023
Title: The app launches by double-click on the client's own (Windows) computer, no technical setup, everything stays local
Type: Happy Path
Approval status: pending (cycle 1 — delivery fix)
Approval session: SESSION-001
Approval cycle: 1

## Requirement (client's words, plain)
"It really has to be double-click-and-go. No terminal, no typing commands, no
installing some separate 'Node' thing myself. I click an icon, the little
background bit starts itself quietly, and the app opens in my browser." Launching
should be as easy as opening any other program. Target computer: Windows.

"The 'mine / not locked in' promise still holds": everything stays on the
client's own machine, nothing slips off to a server behind the scenes, and Export
still works.

## Why this exists
Acceptance of cycle 1 was blocked here: the working app was built but delivered
only as developer run-instructions (npm install / npm start), which a
non-technical, single-user, "just for me in my browser" client cannot use. Some
approved features (auto-capture, saved copies, liveness checks, import) require a
small local background program, so the app cannot be a single double-click HTML
file like the Phase-1 prototypes. The launch/install experience was never
elicited in Phase 1 — this scenario closes that gap.

## Intended behaviour
- The client receives a self-contained folder (Windows). Nothing to install
  separately; the Node runtime is bundled.
- Double-clicking one launcher quietly starts the local background program and
  opens the app in the default browser.
- All data (bookmarks, labels, saved copies) is stored on the client's machine
  only; the program contacts the internet solely to fetch pages the client saves
  or imports (no telemetry, no server sync). Export continues to work.

## Assumptions to confirm with the client
- Windows, 64-bit (typical). A one-time unzip of the delivered folder is
  acceptable; after that it's double-click to run.
- A brief first-run Windows security prompt (unrecognised app) may appear; the
  client allows it once.
