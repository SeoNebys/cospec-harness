Scenario ID: SCN-004
Title: Edit bookmark details, personal notes, and tags
Type: Happy Path
Approval status: approved
Approval session: SESSION-004
Approval cycle: 1

## Approved behaviour
A saved bookmark has a distinct Edit bookmark button. It opens one focused form containing the gathered title and description alongside the person's own note and tags. The person can correct the gathered details, add a personal note, choose an existing tag, create a new tag with a visible Add action, and remove a selected tag. Saving clearly confirms the update and shows the note and tags on the original library card. Clicking the bookmark itself is reserved for opening the original page rather than editing.

## Gherkin
Feature: Manage bookmark details

  Scenario: Open a bookmark for editing
    Given the library contains an enriched bookmark
    When the person chooses Edit bookmark on its card
    Then one edit form opens with the bookmark title and description filled in
    And the form contains the person's note and tags

  Scenario: Add a personal note
    Given the bookmark edit form is open
    When the person enters a personal note
    Then the note remains attached to the bookmark being edited

  Scenario: Reuse an existing tag
    Given the bookmark edit form offers tags already used in the library
    When the person chooses an existing tag
    Then that tag is added to the bookmark as a removable label

  Scenario: Create a new tag
    Given the bookmark edit form is open
    When the person enters a new tag and uses the visible Add action
    Then the new tag is added to the bookmark as a removable label

  Scenario: Remove a selected tag
    Given a bookmark has a selected tag in the edit form
    When the person removes that tag
    Then the tag is no longer selected for the bookmark

  Scenario: Save managed bookmark details
    Given the person has edited bookmark details, a note, or tags
    When the person saves the changes
    Then the app confirms that the bookmark details were updated
    And the original library card shows the saved personal note and tags

## Assumptions
- Edit is a distinct, visible action on the bookmark card.
- Clicking the bookmark itself is not an editing action.
- Existing tags are offered for one-click reuse to avoid near-duplicate tags.
- A separate input and visible Add action remain available for new tags.
- Selected tags have a visible remove action.
- Title, description, personal note, and tags are managed together in one form.
