Scenario ID: SCN-026
Title: Preserve and search a saved page snapshot
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When a webpage is saved, the app preserves a readable copy of the page as it existed at that moment. If the live page is later edited, paywalled, or removed, the saved copy remains readable inside the app, identifies when it was captured, and supplies the text used by collection search. The original live address remains available to retry.

## Gherkin
Feature: Preserving saved content

  Scenario: Read a saved copy after the live page disappears
    Given a bookmark includes a readable page copy captured when it was saved
    And the live page is no longer available
    When the person opens the saved copy
    Then the captured page remains readable inside the app
    And the capture date is shown
    And the original live address remains available to retry

  Scenario: Search text from a preserved page version
    Given text existed on a page when its bookmark copy was captured
    And the live page later changes or disappears
    When the person searches for that remembered text
    Then the bookmark can still match using the preserved copy

## Assumptions
- A page copy is captured as part of a successful normal webpage save.
- Search indexes the captured copy and does not require the live page.
- A later live-page change does not silently replace the saved copy.
