Scenario ID: SCN-008
Title: Find a bookmark by words in a personal note
Type: Happy Path
Approval status: approved
Approval session: SESSION-008
Approval cycle: 1

## Approved behaviour

Personal notes are part of searchable bookmark content. When the client searches for a word that appears only in a personal note, the collection narrows to the bookmark carrying that note and highlights the matching word inside the note, making the reason for the match clear.

## Gherkin

Feature: Search personal bookmark context

  Scenario: Find a bookmark by a word that exists only in its note
    Given a saved bookmark has a personal note
    And a word from that note does not occur in the bookmark title, source site, or captured description
    When the user searches for that word
    Then the collection immediately narrows to the bookmark carrying the note
    And the matching word is highlighted inside the personal note
    And the result count is shown

## Assumptions

- Personal notes participate in the same live, case-insensitive search as captured page details.
- Search shows one bookmark once even if the search word matches more than one of its fields.
