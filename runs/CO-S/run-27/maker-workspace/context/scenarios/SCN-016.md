Scenario ID: SCN-016
Title: Save a bookmark without tags
Type: Edge Case
Approval status: approved
Approval session: SESSION-016
Approval cycle: 1

## Approved behaviour
A valid bookmark can be saved without any tags. Tags are optional so a person can capture a link quickly and return to organize it later.

## Gherkin
Feature: Optional bookmark tags

  Scenario: Save before choosing any tags
    Given a valid bookmark address and title are ready to save
    And no tags have been added
    When the person saves the bookmark
    Then the bookmark is saved without tags
    And the person can add tags later by editing it

## Assumptions
- Neither saving nor automatic page-detail retrieval depends on a tag being present.
