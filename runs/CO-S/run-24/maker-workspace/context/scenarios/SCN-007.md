Scenario ID: SCN-007
Title: Remove a saved link, with a confirmation step
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

Each saved link has a "Remove" action. Removing is not immediate: clicking it
asks "Remove this link for good?" with Remove / Cancel, so an accidental click
cannot delete something. Confirming removes the link permanently from the whole
collection; if it was in the reading list it also leaves the reading list.
Cancelling leaves everything unchanged. One confirmation step is the agreed
level of protection (no separate undo/trash required).

## Gherkin
Feature: Remove a link

  Scenario: Removing asks for confirmation
    Given a saved link
    When the user clicks "Remove"
    Then a confirmation ("Remove this link for good?") is shown
    And the link is not yet removed

  Scenario: Confirm removal
    Given the removal confirmation is shown
    When the user confirms
    Then the link is permanently removed from the collection
    And it no longer appears in the reading list

  Scenario: Cancel removal
    Given the removal confirmation is shown
    When the user cancels
    Then the link remains unchanged

## Assumptions
- Removal is permanent (no trash/undo in this cycle).
- One confirmation is sufficient protection.
