Scenario ID: SCN-006
Title: Find a link by typing remembered words
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A search box, kept visibly distinct from the Save box (a magnifier field vs. the blue
Save button, so the client never confuses "put in" with "find"), filters the list as the
client types. Search looks across everything visible on a link — title, summary, and site
name — regardless of whether the link was labelled, and it sweeps *all* links by default
(the half-remembered case: "I don't know where I filed it, just find it"). Matching words
are highlighted in the results so the client can see why each came back. Clearing the
search returns to the full list.

Multiple words are treated as "all words must appear, anywhere, in any order" (each word
narrows the results) — NOT as an exact phrase. Wrapping text in "double quotes" is the
special case that demands that exact phrase. The client was explicit: loose by default,
exact only when deliberately quoted.

## Gherkin
Feature: Searching bookmarks

  Scenario: Find by a word in the summary, not the title
    Given a link whose summary contains "coffee" but whose title does not
    When I search "coffee"
    Then that link appears with the word highlighted

  Scenario: Multiple words narrow, in any order
    Given a link whose summary contains "remote" and "office" far apart
    When I search "remote office"
    Then that link is found and both words are highlighted

  Scenario: Quoted text is an exact phrase
    Given no link contains the exact phrase "remote office"
    When I search "remote office" in quotes
    Then no links are returned

  Scenario: Search sweeps all links regardless of label
    Given I am viewing one label's pile
    When I type in the search box
    Then results are drawn from all links, not only that pile

## Assumptions
- Search covers title, summary, and site name now; the personal note field will be folded
  in once built (deferred idea #3).
- Default scope is all links; scoping search to the current pile is deferred (idea #6).
