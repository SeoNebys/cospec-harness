Scenario ID: SCN-006
Title: First-run / empty state guides the new user
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When there are no bookmarks yet (a brand-new user, or an emptied collection),
the list area does not show a blank void. Instead it shows a friendly welcome:
a short message explaining that saved links will appear here, plus a nudge that
they can be found later by searching or by clicking a tag, and a pointer up to
the save box to get started. The search box is visibly dimmed/disabled while
there is nothing to search. This reassures the user the app is working rather
than broken, and sets expectations about how finding will work.

    And the search box is shown as dimmed/disabled

## Assumptions
- A welcome message is preferred over a silent blank area (client confirmed).
- The finding hint (search or tag) is helpful for first-timers (client confirmed).
- The same empty treatment applies if the user later removes all bookmarks
  (assumption — not separately confirmed).
