Scenario ID: SCN-024
Title: Refine live search with visible precision controls
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The ordinary live search remains simple and narrows the library as the user types. A compact Search options control reveals extra precision only when requested. The visible options let the user search within one label, match the typed words as an exact phrase, choose whether all words or any word may match, exclude one label, and exclude bookmarks containing specified words. The options combine with the typed query. Exact phrase keeps the words together in order and takes priority over the all/any word choice.

The default word behavior is broad enough for half-remembered searches: all entered words may appear anywhere across the searchable title, description, address, and personal note rather than needing to be adjacent. Any word provides plain-language either/or behavior. Exclusions remove matching bookmarks only after the positive search conditions are applied. Visible reminders such as Within, Matching any word, and Leaving out remain below the search so the user can always see why the results are narrowed.

The existing search clear action resets the typed query, label scope, all/any choice, exact-phrase choice, excluded label, excluded words, and every active reminder. It restores the complete ordinary library under All bookmarks, leaving no hidden search condition active.

## Gherkin
Feature: Refine live search visibly

  Scenario: Reveal precision controls only when requested
    Given the user is using the ordinary live search
    When the user opens Search options
    Then controls for label scope, word matching, exact phrase, and exclusions appear beside the search
    And the ordinary live search remains available in the same field

  Scenario: Search within one label
    Given a word matches bookmarks under several labels
    When the user chooses a label in Within a label
    Then only bookmarks matching both the word and the chosen label remain
    And a visible reminder identifies the active label scope

  Scenario: Match an exact phrase
    Given two bookmarks contain the same entered words
    And only one contains the words together in the entered order
    When the user enables exact phrase matching
    Then only that bookmark remains
    And a visible reminder identifies exact phrase matching

  Scenario: Match any entered word
    Given no bookmark contains all the entered words
    And different bookmarks contain different entered words
    When the user chooses Any word
    Then every bookmark containing at least one entered word is shown
    And a visible reminder identifies any-word matching

  Scenario: Exclude a label
    Given positive search conditions match bookmarks under several labels
    When the user chooses a label to leave out
    Then matching bookmarks carrying that label are excluded
    And a visible reminder identifies the excluded label

  Scenario: Exclude bookmarks containing specified words
    Given positive search conditions match several bookmarks
    When the user enters words to leave out
    Then a bookmark containing any excluded word in its searchable fields is not shown
    And a visible reminder identifies the excluded words

  Scenario: Clear every search condition
    Given typed words and one or more advanced search options are active
    When the user clears the search
    Then the typed words are removed
    And every advanced option returns to its default
    And every active reminder disappears
    And the complete ordinary library appears under All bookmarks

## Assumptions
- Advanced search continues to exclude archived bookmarks from ordinary results.
- Case differences do not affect words, phrases, or label matching.
- Excluded words are matched across the same title, description, address, and personal note fields as positive search words.
