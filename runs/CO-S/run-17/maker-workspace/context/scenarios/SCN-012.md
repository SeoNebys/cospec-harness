Scenario ID: SCN-012
Title: Prevent a correction from leaving a bookmark without a title
Type: Edge Case
Approval status: approved
Approval session: SESSION-012
Approval cycle: 1

## Approved behaviour

Title and description can be corrected inline and the description may be empty. If the client erases the title and tries to save, the editor stays open, the title field is identified, and a plain explanation says a title is needed so the bookmark remains recognizable. A nameless bookmark is not saved.

## Gherkin

Feature: Correct bookmark details

  Scenario: Block an empty bookmark title
    Given a saved bookmark is being edited inline
    When the user erases its title
    And tries to save the changes
    Then the editor remains open
    And the title field is identified
    And a message explains that a title is needed for recognizability
    And the empty title is not saved

  Scenario: Allow an empty bookmark description
    Given a saved bookmark is being edited inline
    When the user leaves its title present
    And clears its description
    And saves the changes
    Then the bookmark is saved with no description

## Assumptions

- Every bookmark must have a non-empty title.
- Bookmark descriptions are optional.
