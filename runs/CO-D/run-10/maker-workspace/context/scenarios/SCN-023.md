Scenario ID: SCN-023
Title: Export portable bookmarks and a complete library backup
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Export is available from the compact Library tools menu. The export area offers two clearly differentiated downloads. The browser bookmarks file is a standard file that another browser can import. It contains every saved link and user-edited title, retains saved dates, carries labels where the receiving browser supports them, and places archived links in a separate Archive folder. The interface plainly explains that browser bookmark files cannot preserve personal notes, note formatting, or app-only states such as Read later.

The complete library backup contains every active and archived bookmark together with addresses, user-edited titles and descriptions, labels, original saved dates, formatted notes, Read later state, and Archive state. It is restorable by the app so the personal library can be rebuilt as it was. Each download has a descriptive dated filename and produces a clear completion message.

## Gherkin
Feature: Export the personal library

  Scenario: Download a portable browser bookmarks file
    Given the user opens Export or back up from Library tools
    When the user downloads the browser bookmarks file
    Then a standard browser-importable file is downloaded
    And it contains every bookmark address and saved title
    And it retains saved dates
    And it includes labels where the receiving browser supports them
    And it places archived links in an Archive folder
    And the app confirms the download

  Scenario: Explain browser export limitations before downloading
    Given the export choices are visible
    Then the browser file explains that it cannot carry personal notes, note formatting, or Read later state
    And the complete backup is presented as the way to retain those details

  Scenario: Download a complete restorable library backup
    Given the user opens Export or back up from Library tools
    When the user downloads the complete library backup
    Then the downloaded file contains every active and archived bookmark
    And it contains addresses, titles, descriptions, labels, and original saved dates
    And it contains formatted personal notes
    And it contains Read later and Archive state
    And the app confirms the download

  Scenario: Restore a complete backup
    Given the user has a valid complete library backup
    When the user restores it through the import flow
    Then the app can rebuild the library with all backed-up bookmark details and states

## Assumptions
- Compatibility limitations of a receiving browser are stated rather than hidden.
- A complete backup is intended for restoring into this app, while the browser file is intended for broader portability.
