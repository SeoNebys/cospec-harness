Scenario ID: SCN-005
Title: Mark a bookmark for later and view the read-later list
Type: Happy Path
Approval status: approved
Approval session: SESSION-005
Approval cycle: 1

## Approved behaviour
A person can mark a bookmark for later by clicking an outlined star in the corner of its card. The star fills and an immediate confirmation appears. A Read later section in the sidebar opens a dedicated list using the normal bookmark-card layout and showing only marked bookmarks, with their stars filled.

## Gherkin
Feature: Reading bookmarks later

  Scenario: Mark a bookmark for later
    Given a bookmark is not marked for later
    When the person clicks its outlined star
    Then the star is filled
    And the app immediately confirms that the bookmark was added to Read later

  Scenario: View bookmarks marked for later
    Given a bookmark has been marked for later
    When the person opens Read later from the sidebar
    Then a dedicated list shows only bookmarks marked for later
    And the bookmarks use the normal bookmark-card layout
    And each bookmark in the list shows a filled star

## Assumptions
- The star appears in the corner of each bookmark card.
- Marking happens directly from a bookmark card with one click.
- Read later is a dedicated sidebar destination.
