Scenario ID: SCN-013
Title: Bulk actions on selected bookmarks or all matching the current view
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Bulk work is occasional, so it uses a deliberate selection mode (Option A): a
"Select" control in the controls reveals a checkbox on each card; "Done
selecting" exits and clears. Cards stay clean when not selecting.

When one or more bookmarks are selected, an action bar shows the count and these
actions applied to the whole selection at once:
- Add tags (type new tags and/or click existing ones)
- Remove tags (pick from the tags present on the selected bookmarks)
- Mark To read
- Mark Finished
- Archive
- Delete (always asks to confirm the number being permanently deleted)
- Clear (deselect)

"Select all matching (N)" selects exactly the bookmarks currently shown by the
active search, tag, and status filters, so the client can filter first and then
act on the entire result.

The client confirmed Option A; "select all matching" respecting current filters;
confirmed bulk deletion; and that both status directions (To read / Finished) and
both tag operations (add / remove) are present.

## Gherkin
Feature: Bulk actions

  Scenario: Enter selection mode and select bookmarks
    When I press Select and tick one or more bookmarks
    Then an action bar shows the number selected and the available actions

  Scenario: Select all matching the current view
    Given a search and/or tag and/or status filter is active
    When I press "Select all matching"
    Then exactly the currently shown bookmarks are selected

  Scenario Outline: Apply a bulk action to the selection
    Given several bookmarks are selected
    When I choose <action>
    Then it is applied to every selected bookmark
    Examples: | action |
      | Add tags | | Remove tags | | Mark To read | | Mark Finished | | Archive |

  Scenario: Bulk delete confirms
    Given several bookmarks are selected
    When I choose Delete
    Then I must confirm the number to be permanently deleted
    And confirming removes all of them

## Assumptions
- Selection is a mode (checkboxes hidden until entered), since bulk work is occasional.
- "Select all matching" is scoped to the active search/tag/status filters.
- Bulk delete is the only bulk action that requires confirmation.
