Scenario ID: SCN-002
Title: Organize and filter bookmarks with tags
Type: Happy Path
Approval status: approved
Approval session: SESSION-002
Approval cycle: 1

## Approved behaviour
While editing a bookmark, the client sees its current tags and can select from existing tags or create a new tag. A bookmark can have multiple tags. Beside the collection, each tag shows how many bookmarks use it. Selecting a tag narrows the collection to matching bookmarks and leaves the active tag visibly selected.

## Gherkin
Feature: Organize bookmarks with tags

  Scenario: Add existing and new tags to a bookmark
    Given a bookmark is being edited
    And its current tags remain visible
    When the user selects one or more existing tags
    Or creates a new tag
    And saves the changes
    Then the bookmark has all of the selected and newly created tags

  Scenario: Filter the collection by a tag
    Given the collection contains bookmarks with one or more tags
    And each available tag is shown with its bookmark count
    When the user selects a tag
    Then only bookmarks carrying that tag are shown
    And the selected tag remains visibly active
    And a bookmark carrying several tags appears under each applicable tag

## Assumptions
- Existing tags are presented as selectable choices while editing.
- A separate field permits creation of a tag that does not yet exist.
- Tags and their counts remain available beside the collection.
