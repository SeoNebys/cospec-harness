Scenario ID: SCN-010
Title: Save a valid page when its details cannot be gathered
Type: Error Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When a valid page cannot be read, the app plainly explains that the page did not share its details and that the user can still name and save it. The web address and site name are preserved, title and description fields remain available for the user's own words, and a neutral no-preview placeholder appears instead of a broken image. The failure never discards the address or blocks the user from saving the bookmark manually.

## Gherkin
Feature: Save a page without gathered details

  Scenario: Fall back to manual details for an unreadable page
    Given the user has entered a valid web address
    When the app cannot gather details from that page
    Then the app explains that the page did not share its details
    And preserves the web address and site name
    And shows editable title and description fields
    And shows a neutral no-preview placeholder
    And allows the user to enter their own words and save the bookmark

## Assumptions
- A title is supplied by the user before a fallback bookmark is saved.
- The description may be left empty.
