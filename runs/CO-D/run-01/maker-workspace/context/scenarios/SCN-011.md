Scenario ID: SCN-011
Title: Edit a link's details fully, including a searchable personal note
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Each link has an "Edit" space that gathers everything the client might tidy up:
the title, their own personal note, the auto-filled summary (editable when it is
off), and the address (to correct a wrong paste). This full edit space sits
alongside — not instead of — the quick in-place rename (SCN-003), giving the
client both a fast path (title only) and a thorough path.

The personal note is searched exactly like the summary, so a link can be found
by the client's own words (e.g. searching "mum" finds a recipe whose note says
"the one Mum liked"). The note is shown on the card.

## Gherkin
Feature: Edit a link

  Scenario: Edit all of a link's details in one place
    Given the client opens a link's Edit space
    When the client changes the title, note, summary or address and saves
    Then the card reflects the updated details

  Scenario: Correct a wrong address
    Given a link was saved with the wrong address
    When the client edits the address and saves
    Then the link points to the corrected address

  Scenario: Personal notes are searchable
    Given a link has a personal note containing "mum"
    When the client searches "mum"
    Then that link appears in the results
    And the note text is where the match was found

## Assumptions
- The Edit space covers title, note, summary, address; quick inline rename remains.
- The note is included in the searchable text alongside title, summary, address,
  labels.
- Light note formatting (bullets, bold) is a parked nice-to-have (see goals
  parking lot).
