Scenario ID: SCN-002
Title: Fill page details automatically from a pasted link
Type: Happy Path
Approval status: approved
Approval session: SESSION-002
Approval cycle: 1

## Approved behaviour
After a complete web address is pasted, the app retrieves the page's real title, a short description, and its site icon. The retrieved title can be changed before saving. The automatically supplied description and icon do not need to be editable in the save box.

## Gherkin
Feature: Saving bookmarks

  Scenario: Retrieve page details before saving
    Given the person is entering a new bookmark
    When the person pastes a complete web address
    Then the app retrieves and displays the page title, a short description, and the site icon
    And the retrieved title remains editable before the bookmark is saved
    And the description and site icon are not presented as editable fields

## Assumptions
- Retrieval starts after a complete web address is entered.
- Retrieved details are shown before the bookmark is saved.
- The person may save the retrieved title without making a change.
