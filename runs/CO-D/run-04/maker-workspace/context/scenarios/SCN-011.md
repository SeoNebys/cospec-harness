Scenario ID: SCN-011
Title: Correct an invalid address while saving
Type: Error Case
Approval status: approved
Approval session: SESSION-011
Approval cycle: 1

## Approved behaviour
When a person attempts to save text that is not a full web address, no bookmark
is created. The save view stays open, preserves the entered text, and shows
plain-language inline guidance to include the full address. The person can
correct the address in place instead of restarting the save flow.

## Gherkin
Feature: Validate bookmark addresses

  Scenario: Attempt to save an invalid address
    Given the save view is open
    And the person has entered text that is not a full web address
    When the person attempts to save it
    Then no bookmark is created
    And the save view remains open
    And the entered text is preserved
    And inline guidance asks for a full web address including its scheme

## Assumptions
- Validation happens before page details are fetched.
- The error is shown beside the address field rather than in a separate alert.
