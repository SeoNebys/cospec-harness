Scenario ID: SCN-015
Title: Select multiple bookmarks and act on them together
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Each bookmark has a selection checkbox. Selecting one or more reveals a bulk
action bar. "Select all matching" (always available) selects the entire current
filtered set — including results not yet shown via "Show more", not just the
visible batch — and toggles to clear the selection. Bulk actions apply to all
selected bookmarks at once:
- Add a tag / remove a tag (with suggestions of existing tags);
- Mark read / mark unread;
- Archive (or, in the Archive view, Restore);
- Delete permanently, after a single confirmation that names how many will be
  removed.
After a bulk tag change the selection is kept (to allow several changes in
sequence); after archive/restore or delete the selection is cleared (those
bookmarks leave the current working set).

## Gherkin
Feature: Bulk actions

  Scenario: Select some and act
    Given several bookmarks are selected
    Then a bulk action bar shows the number selected and offers the bulk actions

  Scenario: Select all matching covers the whole filtered set
    Given a search or tag filter is active
    When the client chooses "Select all matching"
    Then every bookmark matching the current filter is selected, including
         results not yet shown

  Scenario: Bulk tag add/remove keeps selection
    Given selected bookmarks
    When the client adds or removes a tag in bulk
    Then the tag change is applied to all selected and the selection is kept

  Scenario: Bulk mark read/unread
    When the client marks the selection read or unread
    Then all selected bookmarks change status

  Scenario: Bulk archive/restore clears selection
    When the client archives (or restores in the Archive view) the selection
    Then all selected bookmarks move accordingly and the selection is cleared

  Scenario: Bulk delete with a single confirmation
    When the client deletes the selection
    Then one confirmation naming the count is shown
    And on confirming, all selected bookmarks are permanently removed and the
        selection is cleared

## Assumptions
- "Select all matching" = entire filtered set across pages (client confirmed).
- Selection kept after tag changes, cleared after archive/delete (client
  confirmed).
