Scenario ID: SCN-019
Title: Permanently delete one bookmark
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

The client can permanently delete a bookmark through its action menu. The app asks for explicit confirmation before deletion. Confirming removes the bookmark and its own note, tag associations, and read-later state, while leaving all other bookmarks and tags still used elsewhere unchanged.

## Gherkin

Feature: Remove bookmarks from the collection

  Scenario: Confirm permanent bookmark deletion
    Given a bookmark has a note, tag associations, or read-later state
    When the client chooses to delete the bookmark
    Then the app asks for explicit confirmation
    When the client confirms deletion
    Then the bookmark is permanently removed
    And its own note, tag associations, and read-later state are removed
    And other bookmarks remain unchanged
    And tags still used by other bookmarks remain available

## Assumptions

- Permanent deletion is distinct from the reversible set-aside behaviour still to be explored.
- The confirmation identifies the bookmark being deleted.
