Scenario ID: SCN-003
Title: Find bookmarks with search and collection filters
Type: Happy Path
Approval status: approved
Approval session: SESSION-003
Approval cycle: 1

## Approved behaviour
The user can narrow the bookmark list by typing part of a bookmark name or web address, and results update immediately while typing. The user can also filter the list to a named collection. Search and collection filtering can each be used alone or together; when combined, search narrows the bookmarks within the selected collection, and the heading clearly describes the active collection and search term.

## Gherkin
Feature: Finding saved bookmarks

  Scenario: Search by part of a bookmark name
    Given the personal collection contains “CSS-Tricks” and other bookmarks
    When the user types “css” in the bookmark search
    Then the results update immediately
    And “CSS-Tricks” is the only bookmark shown

  Scenario: Search bookmark names and web addresses
    Given the personal collection contains several bookmarks
    When the user types part of a saved bookmark name or web address
    Then only bookmarks whose name or web address contains that text are shown

  Scenario: Filter bookmarks by a named collection
    Given the “Web development” collection contains “MDN Web Docs” and “CSS-Tricks”
    And other bookmarks belong to other collections
    When the user selects the “Web development” collection filter
    Then only “MDN Web Docs” and “CSS-Tricks” are shown
    And the results heading identifies “Web development”

  Scenario: Search within a selected collection
    Given the “Web development” collection filter is selected
    And it contains “MDN Web Docs” and “CSS-Tricks”
    When the user types “css” in the bookmark search
    Then only “CSS-Tricks” is shown
    And the results heading says “Web development matching ‘css’”

## Assumptions
- Search matches partial text without requiring the user to type the whole name or address.
- Search results update as the user types.
- Search checks both bookmark names and web addresses.
- Search and collection filters narrow the same visible bookmark list.
- Either finding control can be used without the other.
