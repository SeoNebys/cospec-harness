Scenario ID: SCN-001
Title: Save a link as an enriched bookmark
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A person pastes a complete web address and saves it. After a brief indication that page details are being gathered, the empty state is replaced by a useful bookmark card showing the page's site icon and name, clear title, short description, preview image, URL, and a "just now" timestamp. The preview and title are visually prominent, while the other details provide context.

## Gherkin
Feature: Save enriched bookmarks

  Scenario: Turn a pasted link into a useful bookmark
    Given the bookmark collection is empty
    When the person pastes a complete web address and saves it
    Then the app briefly indicates that it is gathering page details
    And the app adds one bookmark rather than leaving the collection empty
    And the bookmark shows the page's site icon and name
    And the bookmark shows a clear title and short description
    And the bookmark shows a preview image and the saved URL
    And the bookmark shows that it was saved just now

## Assumptions
- The linked page makes usable title, description, site icon, and preview-image details available.
- Saving begins through one prominent web-address field.
- The enriched bookmark is shown as a card in the recent collection.
