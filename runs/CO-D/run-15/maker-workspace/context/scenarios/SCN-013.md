Scenario ID: SCN-013
Title: Reject text that is not a complete web address
Type: Error Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

When the client enters incomplete text or something that is not an `http` or `https` web address into the save box, the app creates no bookmark. It leaves the entered text in place, explains inline that a full web address is required, and gives an example. It does not guess an address or turn the text into a search.

## Gherkin

    And the entered text remains in the save box
    And an inline message explains that a full web address is required
    And the message provides an example
    And the app does not guess an address or perform a search

## Assumptions

- The save box accepts complete HTTP and HTTPS web addresses only.
- Search remains a separate, explicitly labeled interaction.
