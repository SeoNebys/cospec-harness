Scenario ID: SCN-003
Title: Saving a link that is already in the library
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When the client saves a link whose address is already in the library, no second
copy is created. Instead a short message appears ("You already saved this one —
here it is"), and the existing card pulses/highlights and scrolls into view.
This directly addresses the client's core pain of the same link piling up
multiple times.

## Gherkin
Feature: Duplicate save handling

  Scenario: Saving a link already in the library
    Given a link with a given address is already saved
    When the client saves the same address again
    Then no second copy is created
    And a message states the link already exists
    And the existing card is highlighted and scrolled into view

## Assumptions
- Address comparison ignores http/https, "www.", trailing slash, and case.
- "Take me to it" = highlight + scroll within the single library page, not a
  navigation away. (client confirmed)
