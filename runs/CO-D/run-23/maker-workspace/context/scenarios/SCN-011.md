Scenario ID: SCN-011
Title: Open the original website from a bookmark card
Type: Happy Path
Approval status: approved
Approval session: SESSION-011
Approval cycle: 1

## Approved behaviour
Selecting a bookmark card's title opens the original website in a new browser tab. The bookmark library remains open in the first tab so the person does not lose their place.

## Gherkin
Feature: Open a saved link

  Scenario: Visit the original website
    Given a bookmark card is visible in the library
    When the person selects the bookmark's title
    Then the original website opens in a new browser tab
    And the bookmark library remains open in the original tab

## Assumptions
- The bookmark title is the link to the original website.
- Original websites open in a new tab.
