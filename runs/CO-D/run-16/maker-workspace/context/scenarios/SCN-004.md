Scenario ID: SCN-004
Title: Edit an existing bookmark's details
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The client can open any saved bookmark for editing and change its link, title,
description, tags, and note. On saving, the bookmark updates in place. If the
link is changed, the site icon and preview image update to reflect the new
address.

## Gherkin
Feature: Edit a bookmark

  Scenario: Update a bookmark's details in place
    Given a saved bookmark
    When the client opens it for editing and changes the link, title,
         description, tags, or note
    And saves the changes
    Then the bookmark is updated in place with the new values

  Scenario: Changing the link refreshes site icon and preview
    Given the client edits a bookmark's link to a new address
    When the change is saved
    Then the site icon and preview image update to reflect the new address

## Assumptions
- Editing all five fields (link, title, description, tags, note) is supported
  (client approved).
