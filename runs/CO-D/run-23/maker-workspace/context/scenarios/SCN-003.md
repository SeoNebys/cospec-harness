Scenario ID: SCN-003
Title: Organize and filter bookmarks with personal labels
Type: Happy Path
Approval status: approved
Approval session: SESSION-003
Approval cycle: 1

## Approved behaviour
A person can add more than one visible label directly on a bookmark card. As they type a label, the app suggests matching labels already in the library and shows how many bookmarks use each suggestion, allowing the person to reuse an established label instead of creating a differently spelled or capitalized near-duplicate. Selecting a label chip narrows the whole library to bookmarks carrying that label.

## Gherkin
Feature: Organize bookmarks with labels

  Scenario: Add another label directly to a bookmark
    Given a saved bookmark already has a label
    When the person adds another label directly on its card
    Then the new label is shown as another visible chip on that card
    And the existing label remains attached

  Scenario: Reuse an existing label from suggestions
    Given the label "Design" is already used by a bookmark
    When the person begins typing "des" while adding a label to another bookmark
    Then the app suggests the existing "Design" label
    And the suggestion indicates how many bookmarks currently use it
    When the person chooses that suggestion
    Then the same existing "Design" label is attached to the bookmark
    And a differently capitalized near-duplicate is not created

  Scenario: Filter the library by a label
    Given multiple bookmarks have visible label chips
    When the person selects a label chip
    Then the library narrows to bookmarks carrying that label

## Assumptions
- Labels appear as visible chips on bookmark cards.
- Labels are added directly from the bookmark card.
- A bookmark may carry more than one label.
- Existing-label suggestions match as the person types.
