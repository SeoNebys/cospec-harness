Scenario ID: SCN-009
Title: Start from an empty bookmark collection
Type: Edge Case
Approval status: approved
Approval session: SESSION-009
Approval cycle: 1

## Approved behaviour
When the personal collection has no bookmarks, the app still shows its overall structure and zero counts for the collection, Read later, and Archive. A friendly empty state explains what happens when a bookmark is saved and offers one prominent action that leads directly into the approved paste-a-link save flow.

## Gherkin
Feature: Empty personal collection

  Scenario: Open the app before any bookmark has been saved
    Given the collection, Read later, and Archive are empty
    When the user opens the app
    Then the app structure and zero counts are visible
    And the empty collection explains how to begin
    And one prominent action offers to save the first bookmark

  Scenario: Begin saving from the empty collection
    Given the empty collection is visible
    When the user chooses to save the first bookmark
    Then the approved paste-a-link save flow opens

## Assumptions
- Empty Read later and Archive remain visible rather than being hidden.
- The empty collection does not show search controls that have nothing to search.
