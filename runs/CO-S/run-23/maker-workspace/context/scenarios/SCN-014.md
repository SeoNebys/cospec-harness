Scenario ID: SCN-014
Title: Return to a useful empty collection after deleting the last bookmark
Type: Edge Case
Approval status: approved
Approval session: SESSION-014
Approval cycle: 1

## Approved behaviour
The client confirmed deletion of the only remaining bookmark. The result clearly stated that the collection was empty and left the address box ready for the next save, matching the welcoming starting state rather than appearing broken or leaving the user stranded.

## Gherkin
Feature: Delete bookmarks

  Scenario: Delete the last bookmark
    Given the collection contains exactly one bookmark
    And its deletion has been confirmed
    When the bookmark is deleted
    Then the collection count becomes zero
    And a clear empty-collection message is shown
    And the address box is ready for the next bookmark

## Assumptions
- The empty state after deletion is the same functional starting point as a new empty collection.
