Scenario ID: SCN-010
Title: Search bookmarks as text is entered
Type: Happy Path
Approval status: approved
Approval session: SESSION-010
Approval cycle: 1

## Approved behaviour
As the person types in search, the visible bookmark list and result count update immediately. Matching ignores capitalization and looks through bookmark titles, page descriptions, and personal notes, including note text that is not present in the page title.

## Gherkin
Feature: Searching bookmarks

  Scenario: Find a bookmark from text in its personal note
    Given the collection contains a bookmark whose personal note contains "flexbox"
    And that word does not appear in the bookmark's title
    When the person types "FLEXBOX" into search
    Then the results update without a separate submission action
    And that bookmark remains visible
    And bookmarks without the word in their title, description, or note are hidden
    And the result heading and count reflect the search

## Assumptions
- Search matching ignores capitalization.
- Web-address matching is explored as an extension of this behaviour.
