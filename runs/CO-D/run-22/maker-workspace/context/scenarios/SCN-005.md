Scenario ID: SCN-005
Title: Add and remove labels on a bookmark
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
While editing a bookmark, a person can type part of a label and choose a matching label already used in the collection, or add unmatched text as a new label. Applied labels appear as chips on the bookmark and can be removed individually. Suggestions help avoid accidentally creating nearly identical labels.

## Gherkin
Feature: Labelling bookmarks

  Scenario: Choose an existing suggested label
    Given the collection already uses the label "Cooking"
    And a bookmark is being edited
    When the person types "cook" in the label field
    Then "Cooking" is suggested as an existing label
    When the person chooses that suggestion
    Then the "Cooking" label is added to the bookmark

  Scenario: Create a new label
    Given no existing label matches "Weekend"
    When the person types "Weekend" in the label field
    And adds it
    Then a new "Weekend" label is added to the bookmark

  Scenario: Remove a label from a bookmark
    Given a label chip is applied to a bookmark being edited
    When the person removes that chip
    Then the label is no longer applied to the bookmark

## Assumptions
- Suggestions match partial text without regard to capitalization.
- Choosing an existing suggestion reuses that label rather than creating another.
- A new label can be added explicitly from unmatched text.
