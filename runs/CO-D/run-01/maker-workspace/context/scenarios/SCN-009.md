Scenario ID: SCN-009
Title: Keep an automatic saved copy of every link, with fallback when the original dies
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The moment a link is saved, the app automatically keeps a copy of the page's
content — no button, no effort from the client. Any saved link offers a "Saved
copy" action that opens the archived content in a readable view, labelled as the
client's saved copy kept from when they bookmarked it.

When a link's original page has died, the link is flagged "Original unavailable".
Clicking such a link does NOT open a broken page; it drops the client straight
into their saved copy, with a clear notice that the original is gone and that
this is their kept copy. There is deliberately no "are you sure" confirmation
step before showing the copy — the notice and the content appear together.

## Gherkin
Feature: Saved copy of a link

  Scenario: A copy is kept automatically on save
    Given the client saves a link
    Then a copy of the page content is kept without any extra action

  Scenario: Read the saved copy of a live link
    Given a saved link whose original is still available
    When the client opens its saved copy
    Then the archived content is shown, marked as their kept copy
    And they can still choose to open the original

  Scenario: Dead original falls back to the saved copy
    Given a saved link whose original page is no longer available
    When the client clicks the link
    Then the saved copy is shown instead of a broken page
    And a notice explains the original is gone
    And no confirmation step is required first
    And the "open the original" action is disabled

## Assumptions
- The copy is captured at save time and stored by the app.
- Detecting that an original has died happens behind the scenes (technical;
  simulated in the prototype via a flag).
- PDF links keep the real file rather than a text copy (see SCN-010).
- An external web-archive backstop is a parked nice-to-have (see goals parking lot).
