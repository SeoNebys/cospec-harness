Scenario ID: SCN-016
Title: Select multiple bookmarks and act on them together
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

Each card has a selection checkbox. When one or more bookmarks are selected, an
action bar appears showing the number selected, a "Select all" that selects every
bookmark matching the current view and search (the whole match set, not merely the
cards on screen — the bar names the true total, e.g. "Select all 137 matching
bookmarks"), and "Clear".

From the action bar the client can, on all selected bookmarks at once:
- Add a tag or remove a tag (via one tag field; selection is kept after applying,
  so several changes can be made in sequence).
- Mark as read or Mark as unread.
- Archive them (or, in the Archive view, Restore them to the collection).
- Delete them, behind the same clear "this can't be undone" confirmation as a
  single delete.

In the Archive view the read/unread and Archive actions are replaced by Restore,
since archived bookmarks are not on the reading list. Selection is scoped to the
current view and search: items that leave the current view as a result of an
action drop out of the selection automatically.

## Gherkin

Feature: Bulk actions

  Scenario: Select all matching bookmarks
    Given a view and/or search with several matching bookmarks
    When I choose "Select all"
    Then every bookmark matching the current view and search is selected
    And the action bar states the total number matching

  Scenario: Add or remove a tag across the selection
    Given several bookmarks are selected
    When I add a tag to the selection
    Then that tag is applied to all of them and they remain selected
    And when I remove a tag from the selection
    Then that tag is removed from all of them

  Scenario: Mark read / unread in bulk
    Given several selected bookmarks
    When I choose Mark as read or Mark as unread
    Then all of them leave or join the reading list accordingly

  Scenario: Archive / restore / delete in bulk
    Given several selected bookmarks
    When I choose Archive (or Restore in the Archive view)
    Then all of them are archived (or restored)
    And when I choose Delete and confirm
    Then all of them are permanently removed after one confirmation

## Assumptions
- "Select all" always spans the full matching set across any future paging or
  display limit, not just the currently rendered cards.
- Selection persists across tag add/remove; it prunes to what remains visible
  after other actions.
