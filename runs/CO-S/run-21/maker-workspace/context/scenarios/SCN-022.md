Scenario ID: SCN-022
Title: Correct an invalid web address without losing input
Type: Error Case
Approval status: approved
Approval session: SESSION-022
Approval cycle: 1

## Approved behaviour
When entered text is not a complete web address, saving is blocked and no bookmark is created. The app preserves the person's text, keeps focus on and highlights the address field, and gives a gentle explanation with a concrete example of the expected complete-address format.

## Gherkin
Feature: Prevent broken bookmark addresses

  Scenario: Try to save an incomplete web address
    Given the person has entered text that is not a complete web address
    When the person tries to save it
    Then no bookmark is created
    And the entered text remains in the address field
    And the address field is highlighted and focused
    And the app explains the expected format with a complete-address example

## Assumptions
- A complete supported address begins with http:// or https://.
- Correcting the field and saving again clears the validation message when successful.
