Scenario ID: SCN-015
Title: Preserve unread status through archiving
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Archiving an unread bookmark removes it from both the active library and unread
pile, decreasing the unread count while increasing the archived count. Its
unread status is preserved in the archive. Restoring it returns it to both the
active library and unread pile with that status intact.

## Gherkin
Feature: Unread archived bookmarks

  Scenario: Archive an unread bookmark
    Given a bookmark is unread in the active library
    When the person archives it
    Then it leaves the active library
    And it leaves the unread view
    And the unread count decreases
    And the archived count increases
    And its unread status is preserved

  Scenario: Restore an archived unread bookmark
    Given an archived bookmark retained its unread status
    When the person restores it
    Then it returns to the active library
    And it returns to the unread view
    And the unread count increases
    And it remains visibly unread

## Assumptions
- Archived bookmarks are excluded from active search, tag, and unread views.
- Restoring a bookmark preserves its status and details.
