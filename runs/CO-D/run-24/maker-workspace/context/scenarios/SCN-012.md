Scenario ID: SCN-012
Title: Select multiple bookmarks and act on them together
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

A dedicated "Select" mode is entered from a Select button (rather than always
showing checkboxes, which the client found cleaner, especially on a phone). In
Select mode, each card shows a checkbox and tapping a card toggles its selection
instead of opening the page. An action bar appears with the count selected and
bulk actions.

Bulk actions on the current selection: add a tag, remove a tag (chosen from the
tags present across the selection), mark "read later", mark as read (unmark),
archive, restore, and delete. Delete uses the same named confirmation as single
delete, covering the whole batch. Archive vs Restore is offered automatically
depending on whether the Archived tab is active.

"Select all matching" selects the entire current view + search result set —
including matches beyond what is currently on screen — and never touches
bookmarks outside that filter. This is the way to apply an action to a whole
search/view at once.

## Gherkin

Feature: Bulk actions

  Scenario: Enter and leave select mode
    When the client clicks "Select"
    Then checkboxes appear and tapping a card toggles selection
    When the client leaves select mode
    Then selection is cleared and normal card behaviour resumes

  Scenario: Bulk add and remove tags
    Given several bookmarks are selected
    When the client adds a tag
    Then that tag is added to all selected bookmarks that lacked it
    When the client removes a tag present in the selection
    Then it is removed from all selected bookmarks

  Scenario: Bulk read-later / read / archive / restore
    Given several bookmarks are selected
    When the client applies mark read-later, mark read, archive, or restore
    Then all selected bookmarks change together
    And Restore is offered instead of Archive when the Archived tab is active

  Scenario: Bulk delete with confirmation
    Given several bookmarks are selected
    When the client deletes
    Then a named confirmation covering the batch is shown before removal

  Scenario: Act on all matching a filter
    Given a search and/or tab filter is applied
    When the client chooses "Select all matching"
    Then all bookmarks matching the current view+search are selected (including off-screen matches)
    And an applied action affects only those, leaving others untouched

## Assumptions

- Selection is a mode (button), not persistent checkboxes.
- In select mode, card tap = toggle selection (does not open the page).
- "Select all matching" scope = current tab + current search, whole result set.
