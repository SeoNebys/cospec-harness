Scenario ID: SCN-014
Title: When a saved page is no longer available, do not dead-end the client
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When the original page has vanished, opening the item does not dead-end. At a
minimum the client's saved details are shown so they still know what it was.
(Superseded/strengthened by SCN-015: show the saved readable COPY of the actual
content, which the client says is what they most want.)

## Gherkin
Feature: Handle a vanished page

  Scenario: Open an item whose page is gone
    Given a saved item whose original page is no longer available
    When the client opens it
    Then the client is not shown a dead end
    And at minimum the saved details are shown (see SCN-015 for saved copy)

## Assumptions
- Graceful handling of link rot rather than a broken destination. (Approved.)
