Scenario ID: SCN-010
Title: The empty / first-run screen
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
On a blank app (new user, nothing saved), the list area shows a friendly, non-cutesy
message — "Nothing saved yet 📎 / Paste your first link above — the title and summary fill
themselves in." The client found this a good day-one feeling: it says exactly what to do
and reassures up front that titles/summaries auto-fill. The same friendly empties apply to
"no search results" and "empty to-read pile" (the latter reads as an accomplishment).

## Gherkin
Feature: Empty states

  Scenario: First run with no bookmarks
    Given I have saved nothing
    When I open the app
    Then I see a friendly prompt telling me to paste my first link
    And a note that titles and summaries fill themselves in

## Assumptions
- Distinct empty messages per context (whole list, search, to-read pile).
