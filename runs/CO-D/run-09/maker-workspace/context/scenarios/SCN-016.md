Scenario ID: SCN-016
Title: Select several links and act on them together
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Each card has a selection control. Selecting one or more links reveals an action bar
showing the count and offering bulk actions. "Select all in this view" selects every
bookmark matching the current search, label, and view (All / To read / Finished, or
Archived) — including results not currently on screen — so an action can apply to all
of them.

Bulk actions in the normal list: mark read, mark unread, add a label, remove a label,
archive, and delete. When adding a label in bulk, the user's existing labels are
suggested for reuse; when removing a label in bulk, the labels actually present on the
selected links are offered so the user need not remember or type them exactly. Label
editing keeps the selection so several labels can be applied in a row; other actions
clear the selection when done. Switching to the Archived view also clears the current
selection.

## Gherkin
Feature: Bulk actions

  Scenario: Select links and see the action bar
    Given saved links are shown
    When the user selects one or more links
    Then an action bar shows the number selected and the available bulk actions

  Scenario: Select all matching results
    Given a search, label, or view is active
    When the user chooses "Select all in this view"
    Then every bookmark matching the current search and view is selected, including off-screen results

  Scenario: Change read status in bulk
    Given several links are selected
    When the user chooses "Mark read" or "Mark unread"
    Then all selected links change to that status
    And the selection is cleared

  Scenario: Add a label to many links with suggestions
    Given several links are selected
    When the user chooses to add a label
    Then existing labels are suggested for reuse
    And choosing or typing a label adds it to all selected links
    And the selection is kept so more labels can be added

  Scenario: Remove a label from many links with suggestions
    Given several links are selected
    When the user chooses to remove a label
    Then the labels present on the selected links are offered
    And choosing one removes it from all selected links that have it

## Assumptions
- After non-label bulk actions the selection clears; label editing preserves it until
  the user leaves that mode.
- "Select all in this view" spans all matching results, not just visible ones.
