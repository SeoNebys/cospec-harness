Scenario ID: SCN-007
Title: First-run empty state and saving a page whose details can't be read
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

First run (absence of data):
- When there are no bookmarks yet, the page shows the save box plus a friendly
  welcome ("Save your first bookmark") explaining that pasting a link auto-fills
  its details and lets the user add tags and a note. Not a blank screen.

Unreadable page (error/exception on auto-fill):
- When the app cannot read a page's details (offline, private, or the site blocks
  access), it does NOT invent details and does NOT save silently.
- The review-before-saving card still appears, with:
  - An honest warning that the details couldn't be read and nothing was made up,
    stating the user can still save the link and fill in the details themselves.
  - A title suggested from the web address (editable).
  - Empty description and a "No preview available" placeholder.
- The user decides: "Save bookmark" saves it (with whatever they filled in), or
  "Cancel" discards it. Nothing is saved before the user confirms.

## Gherkin

Feature: Empty state and unreadable-page handling

  Scenario: First run shows a welcome, not a blank page
    Given the user has no bookmarks
    When the user opens the app
    Then the save box is shown with a welcoming first-run message

  Scenario: Unreadable page still allows a reviewed save
    Given the user saves a link whose page details cannot be read
    Then the review card appears with a warning, a title suggested from the URL,
      an empty description, and a "No preview available" placeholder
    And no bookmark is saved until the user confirms

  Scenario: Confirm saves the reviewed bookmark
    Given the unreadable-page review card is shown
    When the user presses "Save bookmark"
    Then the bookmark is saved with the details the user provided

  Scenario: Cancel discards it
    Given the unreadable-page review card is shown
    When the user presses "Cancel"
    Then nothing is saved

## Assumptions

- The same "review before saving" gate from SCN-001 applies; the failure only
  changes the pre-filled content and adds a warning.
- "Couldn't read details" covers network failure, private/blocked pages, and
  missing metadata.
