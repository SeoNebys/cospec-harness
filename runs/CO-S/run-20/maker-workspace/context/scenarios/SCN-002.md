Scenario ID: SCN-002
Title: Find a saved link by searching
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

The client finds a saved link by typing in a search box above the collection.
The list filters live as the client types, showing only links whose title, page
description, personal note, or web address contains the typed text (case-
insensitive). The matching text is highlighted within the results. A running
count reflects how many links match. When no link matches, a short "No links
match" message is shown instead of a blank list. Clearing the search box brings
the full collection back.

## Gherkin

Feature: Finding a saved link

  Scenario: Filter links live while typing
    Given I have saved links
    When I type text into the search box
    Then only links whose title, description, note, or address contains that text remain
    And the matching text is highlighted
    And the results update as I type

  Scenario: No link matches the search
    Given I have saved links
    When I search for text that no link contains
    Then a "No links match" message is shown instead of a blank list

  Scenario: Clearing the search restores the full collection
    Given I have an active search that is filtering the list
    When I clear the search box
    Then the full collection is shown again

## Assumptions

- Search is a case-insensitive substring match across four fields: title, page
  description, personal note, and web address.
- Filtering happens live as the client types (no separate "search" button).
- Matching text is highlighted in the results.
