Scenario ID: SCN-023
Title: Guide the first save from an empty collection
Type: Edge Case
Approval status: approved
Approval session: SESSION-023
Approval cycle: 1

## Approved behaviour

When the collection has no bookmarks, the app shows a clear empty message and a prominent action to add the first bookmark. Search, labels, and other browsing controls are hidden because there is nothing for them to operate on. Once the first bookmark is saved, those browsing controls become available.

## Gherkin

Feature: Empty bookmark collection

  Scenario: Open a collection before saving any bookmarks
    Given the collection contains no bookmarks
    When the user opens the collection
    Then the screen says that there are no bookmarks yet
    And it offers an action to add the first bookmark
    And search, label, and other browsing controls are hidden

  Scenario: Save the first bookmark
    Given the collection contains no bookmarks
    When the user saves the first bookmark
    Then the bookmark appears in the collection
    And the search, label, and other applicable browsing controls become available

## Assumptions

- The standard add-bookmark flow is used for the first bookmark.
