Scenario ID: SCN-006
Title: Find bookmarks regardless of letter capitalization
Type: Edge Case
Approval status: approved
Approval session: SESSION-006
Approval cycle: 1

## Approved behaviour

Search matching ignores capitalization. Entering a remembered word with an initial capital letter returns the same matching bookmark and result count as entering the word in lowercase.

## Gherkin

Feature: Finding saved bookmarks

  Scenario: Search using different capitalization
    Given a bookmark contains the word "fluffy" in its description
    When the user enters "Fluffy" in the live search box
    Then the bookmark is included in the visible results
    And the result count shows one result

## Assumptions

- Capitalization is ignored across every searchable bookmark field.
