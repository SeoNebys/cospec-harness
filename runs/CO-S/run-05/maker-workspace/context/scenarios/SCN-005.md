Title: No links match the search
Type: Edge Case
Approval status: approved
Approval session: SESSION-001

## Approved behaviour
When the search text matches no saved links, the list area shows a plain
"No links match" message (naming the searched text) instead of a blank area.
The client confirmed a simple message is sufficient.

## Gherkin
Feature: Finding a saved link by search

  Scenario: Search with no matches
    Given several links are saved
    When the user searches for text that matches no link
    Then a plain "No links match" message is shown

## Assumptions
- The message references the text the user searched for.
