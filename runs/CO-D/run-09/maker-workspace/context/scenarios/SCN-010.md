Scenario ID: SCN-010
Title: First use with an empty collection
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When there are no saved links (a brand-new user, or after everything is cleared), the
list area shows a calm, welcoming empty state that explains how to begin ("Nothing
saved yet. Paste a link above to keep your first one.") rather than a blank or broken
screen. The status filter and sort controls are not shown while there is nothing to
organise.

## Gherkin
Feature: Empty collection

  Scenario: New user with nothing saved
    Given the user has no saved links
    When the app is opened
    Then a welcoming empty state explains how to save the first link
    And the status filter and sort controls are not shown

## Assumptions
- Empty state also applies after the user removes all links.
