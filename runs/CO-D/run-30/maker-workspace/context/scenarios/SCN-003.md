Scenario ID: SCN-003
Title: Edit a saved bookmark from its card
Type: Happy Path
Approval status: approved
Approval session: SESSION-003
Approval cycle: 1

## Approved behaviour

A saved bookmark card has a visible Edit button. Selecting it once opens a small edit pop-up containing the bookmark title and description. After the client changes those fields and saves, the existing card updates immediately without a page reload. The site name, icon, and address remain unchanged.

## Gherkin

Feature: Managing saved bookmarks

  Scenario: Edit the wording of an existing bookmark
    Given a bookmark is present in the collection
    When the user selects the visible Edit action on its card
    Then an editor opens with the bookmark's current title and description
    When the user changes the title and description and saves
    Then the existing card immediately shows the changed wording
    And the page does not reload
    And the bookmark's site name, icon, and web address remain unchanged

## Assumptions

- Editing an existing bookmark uses the same small pop-up pattern as saving.
- The Edit action remains directly visible when more card actions are introduced.
