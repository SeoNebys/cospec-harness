Scenario ID: SCN-012
Title: Persistence over time — nothing auto-expires; snapshots are fixed
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Nothing changes state on its own over time. Reading-list items remain to-read until
the client marks them read; archived links stay archived indefinitely; saved links
and their preserved copies persist until the client edits or deletes them. There is
no automatic expiry, aging-out, or auto-deletion.

A preserved copy is a fixed point-in-time snapshot of the page as of when it was
saved (or last re-captured). It does not update silently if the original page later
changes. A newer capture only happens when the client initiates it (e.g. via editing
the address, or Retry after a failed capture).

## Gherkin
Feature: Time-based persistence

  Scenario: No automatic expiry
    Given reading-list items, archived links, and saved copies exist
    When arbitrary time passes with no client action
    Then their state is unchanged (nothing expires, ages out, or is deleted)

  Scenario: Snapshot is fixed in time
    Given a link with a preserved copy
    When the original page later changes
    Then the preserved copy still shows the content captured at save time
    And it only updates when the client initiates a new capture

## Assumptions
- Relative-vs-absolute time display and manual-vs-automatic retry are deferred as
  polish (non-functional backlog items 5 and 6).
