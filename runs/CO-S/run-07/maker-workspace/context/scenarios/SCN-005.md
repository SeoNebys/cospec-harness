Scenario ID: SCN-005
Title: Filter the library by one visible tag
Type: Happy Path
Approval status: approved
Approval session: SESSION-005
Approval cycle: 1

## Approved behaviour
The library shows the user's available tags as visible buttons above the bookmarks. Selecting a tag immediately narrows the library to bookmarks carrying that tag. One tag is active at a time, and selecting "All" restores the complete library.

## Gherkin
Feature: Filter bookmarks by tag

  Scenario: Show bookmarks carrying a selected tag
    Given the library contains bookmarks with different tags
    And the available tags are shown as buttons above the library
    When the user selects the "Health" tag
    Then only bookmarks carrying the "Health" tag are shown
    And the "Health" tag is shown as the active filter

  Scenario: Restore the complete library
    Given the library is filtered by one tag
    When the user selects "All"
    Then every bookmark in the library is shown
    And "All" is shown as the active filter

## Assumptions
- Only one tag filter can be active at a time.
- Every tag available for filtering is visible above the library.
- Filtering updates the current library view without navigating away.
