Scenario ID: SCN-021
Title: Apply an action to several visible bookmarks at once
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The ordinary library remains free of selection controls. Choosing Select enters a temporary selection mode that shows one checkbox on each visible card, a single batch-action bar, and a Done action. Batch actions remain unavailable until at least one bookmark is selected. "Select everything in this view" selects only the currently visible results, including when the user has narrowed the library by label or search; hidden bookmarks are never selected.

The user can add a label, add to Read later, mark as read, archive, or delete the selected bookmarks. Batch label entry uses the same direct typing and matching suggestions as single-bookmark labelling, reuses an existing label case-insensitively, adds it to every selected bookmark, and preserves each bookmark's other labels. Read later and Archive report how many bookmarks changed and update their sidebar counts. Archiving remains reversible and does not use a destructive warning. Batch deletion names the selected bookmarks, explains that their saved details and notes will be lost, provides a safe cancellation action, and removes them only after explicit permanent confirmation. Each completed action provides a concise confirmation.

## Gherkin
Feature: Work with several bookmarks at once

  Scenario: Enter and leave temporary selection mode
    Given the user is browsing bookmarks normally
    When the user chooses Select
    Then a checkbox appears on each visible card
    And one batch-action bar appears
    And its actions are unavailable until at least one bookmark is selected
    When the user chooses Done
    Then the selection controls disappear

  Scenario: Select every bookmark in the current view only
    Given the user has narrowed the library by a label or search
    And selection mode is active
    When the user chooses "Select everything in this view"
    Then every visible bookmark is selected
    And no hidden bookmark is selected

  Scenario: Add an existing label to selected bookmarks
    Given several bookmarks are selected
    When the user types part of an existing label and chooses its suggestion
    Then that existing label is added to every selected bookmark
    And each bookmark's other labels remain unchanged
    And no case-variant duplicate label is created
    And the app confirms how many bookmarks were labelled

  Scenario: Change Read later for selected bookmarks
    Given several bookmarks are selected
    When the user adds the selection to Read later
    Then every selected bookmark is marked for later
    And the Read later count increases accordingly
    And the app confirms how many bookmarks were added
    When the user marks the same selection as read
    Then the Read later flag is cleared from every selected bookmark
    And the count decreases accordingly

  Scenario: Archive selected bookmarks
    Given several bookmarks are selected
    When the user chooses Archive
    Then the selected bookmarks leave the current library view
    And the Archive count increases accordingly
    And every archived bookmark and all its details remain available for restoration
    And the app confirms how many bookmarks were moved

  Scenario: Cancel permanent deletion of selected bookmarks
    Given several bookmarks are selected
    When the user chooses Delete
    Then the app names the selected bookmarks
    And warns that their saved details and notes will be permanently lost
    And offers to keep the bookmarks
    When the user chooses to keep them
    Then no bookmark is removed

  Scenario: Permanently delete selected bookmarks
    Given the batch deletion warning is showing
    When the user confirms permanent deletion
    Then every selected bookmark is removed
    And the app confirms how many bookmarks were deleted

## Assumptions
- Batch actions apply to all selected bookmarks even when some already have the requested label or state; applying an existing state is harmless and does not create duplicates.
- Selection is scoped to the visible view at the time the user selects bookmarks.
