Scenario ID: SCN-005
Title: Add and edit a formatted personal note on a bookmark
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The user can optionally add a personal note directly on one bookmark card. A small formatting bar supports bold text, bulleted lists, and links. After saving, the formatted note is visible on that card, remains associated only with that bookmark, can be found through search, and can be opened for editing later.

## Gherkin
Feature: Personal bookmark notes

  Scenario: Add a formatted note to a bookmark
    Given a saved bookmark has no personal note
    When the user adds a note directly on its card
    And applies bold text, a bulleted list, or a link using the formatting bar
    And saves the note
    Then the formatted note is displayed on that bookmark card
    And the note is associated only with that bookmark
    And words in the note can be used to find the bookmark

  Scenario: Edit a personal note later
    Given a saved bookmark has a personal note
    When the user opens that note for editing from its card
    And changes and saves the note
    Then the changed formatted note is displayed on that bookmark card

## Assumptions
- A note is optional.
- Notes are edited inline on bookmark cards using a visual formatting bar.
- Supported formatting is limited to bold text, bulleted lists, and links.
