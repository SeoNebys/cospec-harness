Scenario ID: SCN-018
Title: Deliberately refresh selected page details
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Refresh from page is an explicit action in the bookmark's three-dot menu. It compares the saved details with newer page details before changing anything. No replacement is selected by default. The person can adopt the newer title, description, icon, or picture field by field, apply only selected updates, or keep everything unchanged. Unselected personal edits remain protected.

## Gherkin
Feature: Deliberate bookmark detail refresh

  Scenario: Review newer details without changing the bookmark
    Given a saved bookmark's original page now provides different details
    When the person chooses Refresh from page
    Then saved and newer details are shown for comparison
    And no replacement is selected by default
    And keeping everything closes the review without changing the bookmark

  Scenario: Apply selected newer details
    Given newer page details are open for review
    When the person selects individual fields and applies the updates
    Then only the selected fields replace their saved values
    And every unselected saved value remains unchanged

## Assumptions
- Refresh is in the three-dot action menu because it is an infrequent bookmark-specific action.
- Title, description, icon, and picture can be selected independently.
- Opening the comparison has no side effect.
