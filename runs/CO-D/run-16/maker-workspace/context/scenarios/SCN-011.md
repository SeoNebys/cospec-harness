Scenario ID: SCN-011
Title: Saving when a valid page's details cannot be fetched
Type: Error Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When the client enters a valid web address but the app cannot fetch the page's
details (page unreachable/failed), the app does not block saving. It shows a
clear note explaining the details could not be fetched, leaves the title and
description fields available (empty) for the client to fill in, shows a plain
site icon and no preview image, and lets the client save the bookmark normally.
