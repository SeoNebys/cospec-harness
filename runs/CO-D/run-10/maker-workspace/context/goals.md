# Cycle 1 goal

> "A proper personal library instead of a mess."

The client wants the following to be different from their current browser-bookmark pile:

> "When I save a link, I don't want to have to type out what it is — I'd love it if it just figured out the title and description and the little icon on its own, and maybe a preview picture, so I can recognize it later."

> "I want to actually be able to *find* things again. Searching by words in the title or my notes, but also being able to organize with labels I make up, and then just click a label to see everything under it."

> "I'd like to jot down my own notes on a link too, and mark some as 'read this later' so I can come back to just those."

> "And I keep accidentally saving the same page twice — I'd want it to notice I already have that one and just let me update it instead of making a duplicate."

Interface form:

> "I picture something I use in my web browser on my computer."

Access scope:

> "It's just for me — I don't need other people logging in or anything like that."

Additional everyday expectations raised before implementation:

> "Once I've got a lot of links, I'd want to reorder the library — newest first, oldest, or by name — rather than one fixed order."

> "Some way to pick several and act on them all — including 'everything that matches what I'm currently looking at' — would save me a lot."

> "I'd want a way to import that in, and ideally get my collection back out again too, so I'm never trapped."

> "Sometimes I want to search *within* just one label, or match an exact phrase word-for-word, or mix a word with a topic."
