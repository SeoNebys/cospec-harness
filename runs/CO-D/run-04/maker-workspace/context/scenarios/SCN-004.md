Scenario ID: SCN-004
Title: Narrow the collection by a label
Type: Happy Path
Approval status: approved
Approval session: SESSION-004
Approval cycle: 1

## Approved behaviour
Labels are visible in a persistent sidebar with a count of the bookmarks under
each label. Selecting a label narrows the collection to only bookmarks carrying
that label, and the collection heading states how many matching bookmarks are
being shown.

## Gherkin
Feature: Organize bookmarks with labels

  Scenario: View bookmarks carrying a label
    Given bookmarks in the collection carry different labels
    And each label and its bookmark count are visible in the sidebar
    When the person selects a label
    Then only bookmarks carrying that label are shown
    And the heading identifies the selected label and number of matching bookmarks

## Assumptions
- Labels remain visible in the sidebar while browsing the collection.
- Label counts are visible before a label is selected.
- A selected label changes the current collection view rather than opening a separate page.
