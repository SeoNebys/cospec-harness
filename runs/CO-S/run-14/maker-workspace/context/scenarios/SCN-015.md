## Approved behaviour

A **Sort** control offers four orders: **Newest saved** (default), **Oldest
saved**, **Title A–Z**, and **Recently updated**. Changing it reorders the
currently shown list. The sort applies within the current view and alongside any
active search/tag filter.

## Gherkin
Feature: Sort the list

  Scenario: Default order is newest first
    Given the list is shown
    Then bookmarks are ordered newest-saved first

  Scenario: Change the sort order
    When the user selects "Title A–Z"
    Then the shown bookmarks are ordered alphabetically by title
    And selecting "Oldest saved" / "Recently updated" reorders accordingly

## Assumptions
- Sort options: Newest saved, Oldest saved, Title A–Z, Recently updated.
- Sort combines with the current view and filters.
