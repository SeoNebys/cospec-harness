Scenario ID: SCN-009
Title: Bulk actions on many selected links
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A distinct "Select" mode shows a checkbox on each card and a bulk action bar
(checkboxes appear only in this mode, keeping normal browsing uncluttered).
"Select all" selects the entire current filtered set — the whole search + tag +
list-filter result, not just the items loaded on screen. With links selected, the
client can apply one action to all of them: set reading state (Read later / Mark as
read), Archive, Add a tag, Remove a tag, or Delete.
- Add tag adds one tag to every selected link (no duplicates), leaving existing
  tags untouched.
- Remove tag removes the named tag from every selected link that has it, leaving
  each link's other tags untouched.
- In the Archived view the bar offers Restore (and Delete).
- Bulk Delete asks for confirmation stating how many will be permanently removed
  and suggesting archive instead.
After each action the selection clears; the client stays in Select mode until Done.

## Gherkin
Feature: Bulk actions

  Scenario: Select all in the current filtered set
    Given a search/tag/list filter is applied
    When the client enters Select mode and chooses Select all
    Then every link matching the current filter is selected, including unloaded ones

  Scenario: Bulk add and remove a tag
    Given several links are selected
    When the client adds a tag
    Then that tag is added to each selected link without removing existing tags
    When the client removes a tag
    Then that tag is removed from each selected link that had it, leaving other tags intact

  Scenario: Bulk reading state, archive, restore
    Given several links are selected
    Then the client can set them all to Read later or Mark as read, or Archive them
    And in the Archived view the client can Restore them

  Scenario: Bulk delete is confirmed
    Given several links are selected
    When the client chooses Delete
    Then a confirmation states how many will be permanently removed and suggests archive
    When confirmed, all selected links are permanently removed

## Assumptions
- Checkboxes appear only in Select mode.
- Selection is tracked by identity so it spans pagination.
