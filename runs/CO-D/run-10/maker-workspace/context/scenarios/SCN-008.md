Scenario ID: SCN-008
Title: Open a saved webpage without losing the library state
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Clicking a bookmark's preview picture or title opens the saved webpage in a new browser tab. The personal library remains in its original tab without losing the user's place, search, or filtered view. The separate, visibly labelled View details & note action opens stored bookmark information inside the library instead of navigating to the webpage.

## Gherkin
Feature: Open saved webpages

  Scenario Outline: Open the saved page from a bookmark card
    Given the user is browsing their bookmark library
    When the user clicks the bookmark's <target>
    Then the saved webpage opens in a new browser tab
    And the library remains unchanged in its original tab

    Examples:
      | target          |
      | preview picture |
      | title           |

  Scenario: Open stored bookmark details separately
    Given the user is browsing their bookmark library
    When the user clicks View details & note on a bookmark card
    Then the bookmark's stored information opens inside the library
    And the browser does not navigate to the saved webpage

## Assumptions
- Preserving the library's current scroll position, search, and filter matters when opening one or several saved pages.
