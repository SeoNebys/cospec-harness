Scenario ID: SCN-002
Title: Tag suggestions from previously used tags
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Tags are entered as comma-separated words. As the client types a tag, the app
suggests matching tags the client has used before. The client can pick a
suggestion by clicking it or with the keyboard (arrow keys and Enter) to fill
it in. Suggestions exclude tags already chosen in the current entry.

## Gherkin
Feature: Tagging bookmarks

  Scenario: Suggest previously used tags while typing
    Given the client has previously saved bookmarks with tags
    When the client types the start of a tag in the Tags field
    Then the app shows matching previously used tags as suggestions
    And selecting a suggestion fills it into the Tags field

  Scenario: Already-chosen tags are not suggested
    Given the client has already added a tag in the current entry
    When the client types a matching prefix
    Then that already-chosen tag is not offered again

## Assumptions
- Tags are comma-separated (client approved).
- Suggestion matching is prefix-based.
