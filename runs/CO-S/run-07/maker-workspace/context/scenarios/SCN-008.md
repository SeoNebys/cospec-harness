Scenario ID: SCN-008
Title: Switch between all bookmarks and Read later
Type: Happy Path
Approval status: approved
Approval session: SESSION-008
Approval cycle: 1

## Approved behaviour
The library offers "All bookmarks" and "Read later" as distinct, clearly identified views. The Read later view shows its bookmark count and contains only bookmarks marked for later. Switching back to All bookmarks restores the full collection.

## Gherkin
Feature: View bookmarks saved for later

  Scenario: Show only bookmarks marked for later
    Given the library contains marked and unmarked bookmarks
    And the Read later view shows how many bookmarks are marked
    When the user switches from "All bookmarks" to "Read later"
    Then only bookmarks marked for later are shown
    And the "Read later" view is clearly shown as active

  Scenario: Return to all bookmarks
    Given the user is viewing only Read later bookmarks
    When the user switches to "All bookmarks"
    Then every bookmark in the library is shown
    And the "All bookmarks" view is clearly shown as active

## Assumptions
- "All bookmarks" is the default library view.
- The Read later count reflects the current number of marked bookmarks.
- Switching views does not change which bookmarks are marked for later.
