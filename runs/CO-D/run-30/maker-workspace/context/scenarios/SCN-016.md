Scenario ID: SCN-016
Title: Archive and restore a bookmark without losing its details
Type: Happy Path
Approval status: approved
Approval session: SESSION-016
Approval cycle: 1

## Approved behaviour

The client can archive a bookmark from its editor as a reversible alternative to permanent deletion. Archiving removes it from the everyday collection and ordinary search, but it remains available in a separate Archived view. The archived bookmark retains its title, description, labels, and Read later state. Restoring returns it to the everyday collection exactly as it was.

## Gherkin

Feature: Archiving bookmarks

  Scenario: Hide a bookmark without deleting it
    Given a bookmark is visible in the everyday collection
    When the user opens its editor and archives it
    Then the bookmark is absent from the everyday collection
    And it is excluded from ordinary search
    And it is visible in the Archived view

  Scenario: Restore an archived bookmark
    Given an archived bookmark retains its title, description, labels, and Read later state
    When the user restores it
    Then the bookmark returns to the everyday collection
    And its title, description, labels, and Read later state are unchanged

## Assumptions

- Archived bookmarks are retained indefinitely until restored or permanently deleted.
- Archived items are searched only while viewing Archived.
