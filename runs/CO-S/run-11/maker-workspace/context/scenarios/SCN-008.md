Scenario ID: SCN-008
Title: Personal note on a bookmark
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A bookmark can carry an optional personal note, separate from the auto-filled
description — the user's own words about why they saved it or what to look for.
The note can be added when saving and changed when editing. When present, the
note is displayed distinctly on the bookmark (set apart from the description).
Personal notes are included in what search matches, so a link can be found by
words the user wrote themselves.

## Gherkin
Feature: Personal note

  Scenario: Add a note while saving
    Given the user is saving a bookmark
    When the user writes a personal note
    Then the note is stored with the bookmark and shown distinctly

  Scenario: A note is optional
    Given the user saves a bookmark without a note
    Then the bookmark is saved with no note and no empty note is shown

  Scenario: Search matches personal notes
    Given a bookmark has a personal note containing a word
    When the user searches for that word
    Then the bookmark appears in the results

## Assumptions
- The personal note is distinct from the description.
- Notes are optional and searchable.
