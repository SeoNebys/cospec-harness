Scenario ID: SCN-005
Title: Empty states — brand-new library and no search matches
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Absence-of-data states are explicit and guiding, not blank.

Brand-new user (nothing saved): a friendly empty screen explains there are no
bookmarks yet and directs the client to paste a link at the top to save the
first one. It also shows a short tip that the app captures each page's title
automatically, to set expectations. The client found this welcoming and clear.

Search finds nothing: instead of a blank list, a message states there are no
matches for the typed query and suggests trying fewer/different words or
clearing the search. The client approved this.

## Gherkin
Feature: Empty states

  Scenario: Brand-new library
    Given the client has not saved any links
    When the client opens the app
    Then a friendly empty state explains there are no bookmarks yet
    And it directs the client to paste a link to save the first one
    And it notes that page titles are captured automatically

  Scenario: Search returns no matches
    Given the client has saved links
    When the client's search query matches none of them
    Then a no-matches message is shown for that query
    And it suggests trying different words or clearing the search

## Assumptions
- New-user tip about automatic title capture is desired (confirmed helpful).
- No-results suggests query refinement (confirmed acceptable).
