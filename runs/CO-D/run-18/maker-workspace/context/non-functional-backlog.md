# Non-functional backlog

## Cycle 1

- The tag navigation should remain orderly, visible, and usable as the personal library accumulates many tags. The client prefers a vertical sidebar because a horizontal row could wrap into a jumble as it grows.
- Keep frequently used card actions clear without letting the card become crowded as more actions are added. The client currently prefers a direct Archive button over hiding it in an overflow menu, but wants crowding revisited if the card accumulates more controls.
