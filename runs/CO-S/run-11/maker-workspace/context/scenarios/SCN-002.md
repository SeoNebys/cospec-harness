Scenario ID: SCN-002
Title: Organise a bookmark with tags (chip entry with reuse)
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When saving a bookmark, the user can add tags. The user types a word and presses
Enter (or comma) to turn it into a removable tag "chip"; each chip can be removed
with its × control. Tags already used on earlier bookmarks are offered in a
"Reuse" row and can be added with a single click, which keeps tag names
consistent and avoids near-duplicates from spelling differences. Saved bookmarks
display their tags as chips. Saving a bookmark with no tags at all is allowed —
the user may save quickly and organise later. (The client compared this chip
approach against a plain comma-separated field and chose the chip approach.)

## Gherkin
Feature: Tag a bookmark

  Scenario: Add a tag as a chip
    Given the user is filling in a bookmark to save
    When the user types a word in the Tags field and presses Enter or comma
    Then the word becomes a removable tag chip
    And the Tags input is cleared ready for the next tag

  Scenario: Remove a tag chip
    Given a tag chip has been added
    When the user activates the chip's remove control
    Then that tag is removed from the bookmark being saved

  Scenario: Reuse a previously used tag
    Given the user has previously saved tags on other bookmarks
    When the user is adding tags to a new bookmark
    Then previously used tags are offered for one-click reuse
    And selecting one adds it as a chip without retyping

  Scenario: Save with tags
    Given one or more tag chips have been added
    When the user saves the bookmark
    Then the bookmark is stored with those tags
    And the saved bookmark displays its tags as chips

  Scenario: Save with no tags
    Given no tag chips have been added
    When the user saves the bookmark
    Then the bookmark is saved successfully with no tags

## Assumptions
- Enter and comma both commit a tag chip.
- Duplicate tags on the same bookmark are ignored.
- The "Reuse" suggestions come from tags used on previously saved bookmarks.
- A tag left half-typed in the input at save time is committed as a tag.
