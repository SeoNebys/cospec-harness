Scenario ID: SCN-002
Title: Add and remove tags on a saved link, one at a time with suggestions
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

On a saved link's card, the user adds tags in the tag area under the description.
The user types a single tag word into a small input and presses Enter; the word
becomes a tag chip and the input clears, ready for the next one. As the user
types, suggestions drawn from tag names already used elsewhere appear, so
existing names can be reused without retyping and without a busy screen. Tags
are added one at a time. Each tag chip has an "×" that removes just that tag.
Adding a tag that is already present does not create a duplicate. Tag names are
treated case-insensitively / normalised (e.g. leading "#" stripped, lower-cased).

(Chosen over two alternatives: a comma-separated multi-tag field, and a
click-to-toggle list of existing tags. The client preferred the one-at-a-time
type-and-Enter method with inline suggestions.)

## Gherkin
Feature: Tag a saved link

  Scenario: Add a tag by typing and pressing Enter
    Given a saved link
    When the user types a tag word and presses Enter
    Then the word appears as a tag chip on that link
    And the tag input is cleared for the next tag

  Scenario: Reuse an existing tag name via suggestions
    Given tag names have been used on other links
    When the user starts typing a tag
    Then matching existing tag names are suggested
    And selecting a suggestion adds that existing tag name

  Scenario: Adding a duplicate tag does nothing
    Given a link already has the tag "reading"
    When the user adds "reading" again
    Then the link still shows the tag "reading" only once

  Scenario: Remove a single tag
    Given a link has one or more tags
    When the user clicks the "×" on a tag chip
    Then only that tag is removed from the link
    And the other tags remain

## Assumptions
- Tags are per-link, user-created, and shared as a common vocabulary across links
  (a tag used on one link is suggested on others).
- Tag names are normalised (case-insensitive, trimmed) so reuse works reliably.
- Empty input on Enter adds nothing.
- The set of "existing tags" grows as the user creates new ones.
