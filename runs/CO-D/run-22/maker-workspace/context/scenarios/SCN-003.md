Scenario ID: SCN-003
Title: Correct an address on an untouched bookmark
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When a newly saved bookmark points to the wrong page and none of its gathered details have been personalized, correcting its web address refreshes the site, title, description, and preview image from the new page.

## Gherkin
Feature: Correcting a bookmark address

  Scenario: Refresh automatically gathered details after correcting an address
    Given a saved bookmark has an incorrect web address
    And its title and description still contain automatically gathered values
    When the person replaces the web address with a different valid page address
    And saves the changes
    Then the bookmark points to the new address
    And its site, title, description, and preview image are refreshed from the new page

## Assumptions
- The replacement address is valid and its page details can be gathered.
- Neither title nor description has been personalized.
