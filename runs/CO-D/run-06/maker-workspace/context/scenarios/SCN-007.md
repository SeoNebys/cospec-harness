Scenario ID: SCN-007
Title: Search without regard to capitalization
Type: Edge Case
Approval status: approved
Approval session: SESSION-007
Approval cycle: 1

## Approved behaviour
Bookmark search produces the same matches regardless of capitalization. For example, “recipe” and “Recipe” return the same saved bookmark.

## Gherkin
Feature: Finding saved bookmarks

  Scenario: Search using different capitalization
    Given the collection contains a bookmark that matches some search text
    When the person enters that text with different capitalization
    Then the same bookmark is shown as a match

## Assumptions
- Capitalization never changes whether a bookmark matches a search.
