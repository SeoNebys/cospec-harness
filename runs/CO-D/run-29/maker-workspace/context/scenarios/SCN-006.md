Scenario ID: SCN-006
Title: Search bookmark details as the client types
Type: Happy Path
Approval status: approved
Approval session: SESSION-006
Approval cycle: 1

## Approved behaviour
Search results narrow live as the client types, without requiring a search button. Ordinary search text matches without regard to letter case across bookmark titles, descriptions, the client's notes, and web addresses. If a bookmark matches only because of its private note, the result shows a short note excerpt explaining the match.

## Gherkin
Feature: Search bookmarks

  Scenario Outline: Search a bookmark detail without regard to letter case
    Given the collection contains bookmarks with titles, descriptions, client notes, and web addresses
    When the client types search text that occurs in a bookmark's <detail> using any letter case
    Then matching bookmarks are shown as the client types
    And bookmarks without that text in a searched detail are hidden

    Examples:
      | detail      |
      | title       |
      | description |
      | client note |
      | web address |

  Scenario: Explain a match found only in the client's note
    Given a bookmark's client note contains the search text
    And its other searched details do not contain the search text
    When the bookmark appears in the search results
    Then a short excerpt identifies that the match came from the client's note

## Assumptions
- Ordinary text search does not require a submit action.
- Partial text within a searched detail can match.
- Search text matching ignores letter case.
