## Approved behaviour

From the bookmarks page the client pastes a web address and clicks "Get details".
The app automatically fills in the page's Title and Description, which remain
freely editable. It also automatically collects the site icon and a preview
image, shown together in a read-only "Collected automatically" area. When a page
has no preview image, a clear "No preview image on this page" placeholder is
shown instead of a blank space.

The client can add tags (typed as comma-separated text, each becoming a rounded
label) and a personal note. On clicking "Save bookmark", a brief "Saved"
confirmation appears, the form clears, and the new bookmark appears at the top of
the "Your bookmarks" list (most-recent-first), showing its preview image, title,
site icon, tags, and note.

The Save action is only available once at least a web address and a title are
present.

## Gherkin
Feature: Saving a bookmark

  Scenario: Automatically collect page details on request
    Given I am on the bookmarks page
    And I have entered a web address
    When I request the page's details
    Then the title and description are filled in automatically
    And the title and description remain editable
    And the site icon and preview image are collected automatically and shown read-only

  Scenario: Page without a preview image
    Given I have entered a web address for a page that has no preview image
    When I request the page's details
    Then a "No preview image on this page" placeholder is shown in place of the image

  Scenario: Save a bookmark with tags and a note
    Given the page details have been collected
    And I have entered one or more comma-separated tags
    And I have entered a personal note
    When I save the bookmark
    Then a "Saved" confirmation is shown
    And the form is cleared
    And the bookmark appears at the top of my bookmark list
    And the bookmark shows its preview image, title, site icon, tags, and note

  Scenario: Save is unavailable without the minimum details
    Given I have not entered both a web address and a title
    Then the Save action is unavailable

## Assumptions
- Page-detail collection is triggered explicitly (a "Get details" action), not
  automatically on paste. (Confirmed by client.)
- Site icon and preview image are read-only; the client does not edit them.
  (Confirmed by client.)
- Tags are entered as comma-separated text for creating new tags. (Base method
  confirmed; reuse-suggestions being explored separately — see SCN-002.)
- New bookmarks are ordered most-recent-first by default. (Confirmed as default;
  changeable sort order to be explored with find/filter.)
