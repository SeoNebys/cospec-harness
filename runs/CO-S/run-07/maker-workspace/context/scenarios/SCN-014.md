Scenario ID: SCN-014
Title: Recover from a search with no matches
Type: Edge Case
Approval status: approved
Approval session: SESSION-014
Approval cycle: 1

## Approved behaviour
When a search matches no bookmarks, the app plainly states that no bookmarks matched the entered word, makes clear that the library is still intact, and shows one Clear search action. Clearing the search restores the full current library view.

## Gherkin
Feature: Handle a search with no results

  Scenario: Show and clear an empty search result
    Given the library contains bookmarks
    And none contain "volcano" in any searchable field
    When the user types "volcano" in the search field
    Then the app shows that there are zero results
    And states that no bookmarks match "volcano"
    And makes clear that the bookmarks were not removed
    And offers a Clear search action
    When the user clears the search
    Then the full current library view is restored

## Assumptions
- Clearing search preserves any active library view or tag filter.
- A zero-result state replaces the bookmark list until the search changes or is cleared.
