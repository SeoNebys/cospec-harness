Scenario ID: SCN-020
Title: Set a bookmark aside and restore it
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

The client can reversibly set a bookmark aside without confirmation. It is hidden from the main collection and everyday search, appears in a dedicated set-aside view, and can be restored. Its page details, tags, formatted note, and read-later state remain intact throughout. This is distinct from permanent deletion.

## Gherkin

Feature: Reversibly remove bookmarks from the everyday collection

  Scenario: Set a bookmark aside
    Given a bookmark has details, tags, a formatted note, and a read-later state
    And it is visible in the main collection
    When the client sets the bookmark aside
    Then no confirmation is required
    And the bookmark is hidden from the main collection and everyday search
    And the bookmark appears in the set-aside view
    And all its saved information and organization remain intact

  Scenario: Restore a set-aside bookmark
    Given a bookmark is in the set-aside view
    When the client restores it
    Then it returns to the main collection and everyday search
    And its details, tags, formatted note, and read-later state are unchanged

## Assumptions

- Setting aside is reversible and therefore does not require confirmation.
- Set-aside bookmarks are discoverable through their dedicated view rather than everyday search.
- Permanent deletion remains the separately confirmed behaviour in SCN-019.
