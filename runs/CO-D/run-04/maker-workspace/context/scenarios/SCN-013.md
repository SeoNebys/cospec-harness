Title: Set aside — a shelf for kept-but-not-active links
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A middle place between the everyday library and deletion. "Set aside" tucks a
link the client wants to keep but isn't actively using (a talk for next year, a
finished project) onto a shelf, out of the everyday library — without deleting
it. A third lens, "🗄 Set aside" (with a quiet grey count), shows the shelf; the
client can "Bring back" any link to the everyday library at any time. Available
for a single link and in bulk.

A set-aside link lives ONLY on the shelf: it is excluded from the everyday
"Everything" view, does not appear in the "To read" pile (so it never nags), and
does NOT surface in ordinary searches of the everyday library. Shelved links are
found only by going to the shelf and looking there. Set-aside is independent of
read-state (a link keeps its read/unread status while shelved).

The action is weighted as calm/amber (kept, resting) — deliberately unalarming,
distinct from red deletion (gone) and blue read-later (everyday).

## Gherkin
Feature: Set-aside shelf

  Scenario: Set a link aside
    Given a link in the everyday library
    When the client sets it aside (singly or in bulk)
    Then it leaves the everyday library and appears on the shelf
    And the set-aside count increases

  Scenario: A shelved link is out of sight everywhere everyday
    Given a link is set aside
    Then it does not appear in "Everything"
    And it does not appear in the "To read" pile
    And it does not appear in ordinary searches of the everyday library

  Scenario: Bring a link back
    When the client brings a shelved link back (singly or in bulk)
    Then it returns to the everyday library with its prior state intact

## Assumptions
- Set-aside is a separate dimension from read-state. (design)
- Shelved items excluded from everyday views AND everyday search. (client confirmed)
- Calm amber weighting, not alarming. (client confirmed)
