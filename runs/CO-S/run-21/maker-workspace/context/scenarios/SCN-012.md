Scenario ID: SCN-012
Title: Open a separate Read later collection
Type: Happy Path
Approval status: approved
Approval session: SESSION-012
Approval cycle: 1

## Approved behaviour
Persistent side navigation includes All bookmarks and Read later, with their counts. Choosing Read later shows only bookmarks that have been queued, changes the view heading to Read later, and states how many links are waiting. Side navigation is preferred over choices above the list because it remains visible and can accommodate future views such as Archive.

## Gherkin
Feature: View bookmarks queued for later

  Scenario: Open the Read later collection
    Given the full collection contains three bookmarks
    And two bookmarks are in the Read later pile
    When the person chooses "Read later" from persistent side navigation
    Then only the two queued bookmarks are shown
    And the view heading is "Read later"
    And the waiting count is visible in the side navigation
    And the view states that two links are waiting

## Assumptions
- Read later is a view of existing bookmarks, not a separate copy.
- Collection navigation remains visible while viewing Read later.
