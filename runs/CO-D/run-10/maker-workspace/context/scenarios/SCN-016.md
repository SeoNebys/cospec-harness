Scenario ID: SCN-016
Title: Retain a bookmark when its webpage becomes unavailable
Type: Error Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A bookmark is never removed automatically because its webpage temporarily or permanently stops loading. Its title, description, labels, note, and other saved information remain safely in the library until the user explicitly chooses to delete the bookmark. The bookmark remains a useful record even when its external destination is unavailable.

## Gherkin
Feature: Retain bookmarks when external pages fail

  Scenario: A saved webpage no longer loads
    Given the library contains a bookmark with personal information
    And its external webpage becomes temporarily or permanently unavailable
    When the user returns to the library
    Then the bookmark remains in the library
    And its title, description, labels, and note remain unchanged
    And the app does not delete it automatically

## Assumptions
- Only an explicit user deletion can remove a bookmark.
- The external browser page may report that the destination cannot load.
