Scenario ID: SCN-017
Title: Select multiple bookmarks and act on them together
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

The user can select bookmarks via a checkbox on each. A "Select" control selects
or clears every bookmark on the current page; when the selection does not yet
cover all matches, a "Select all N in this view" control selects every bookmark
matching the current view and search across all pages. When one or more are
selected, an action bar shows the count and offers, applied to the whole
selection: add a tag, remove a tag, mark unread (To read), mark read (Done),
archive (or, in the Archived view, restore), and delete. Delete asks for a
count-aware confirmation before permanently removing. Bulk actions apply only to
the current selection / matching set, never to unrelated items. After an action
is applied the selection clears. Bulk archiving preserves each bookmark's own
read/unread state for later restoration (as in SCN-006).

## Gherkin

Feature: Bulk actions

  Scenario: Select a page and then all matches
    Given a view with more bookmarks than fit on one page
    When the user selects the current page
    Then a "Select all N in this view" control is offered
    When the user selects all in the view
    Then every bookmark matching the current view and search is selected, across pages

  Scenario: Apply a status change to a selection
    Given several selected bookmarks
    When the user marks them read (or unread)
    Then all selected bookmarks move to Done (or To read) together
    And the selection clears

  Scenario: Add or remove a tag across a selection
    Given several selected bookmarks
    When the user adds or removes a tag
    Then that tag is added to / removed from every selected bookmark

  Scenario: Bulk archive preserves each item's status
    Given selected bookmarks with differing read/unread states
    When the user archives them together
    Then each is archived while remembering its own read/unread state for restoration

  Scenario: Bulk delete with confirmation
    Given several selected bookmarks
    When the user deletes them
    Then a count-aware confirmation is shown before permanent removal

  Scenario: Bulk actions respect the current view/search
    Given a search is narrowing the view
    When the user selects all in the view and applies an action
    Then only the matching bookmarks are affected

## Assumptions
- "Mark read" = Done; "Mark unread" = To read.
- Selection may span individual items, a page, or all matches; it clears after an action.
