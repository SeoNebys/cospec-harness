Scenario ID: SCN-015
Title: Personal display preferences (default order, links per page, text size)
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A Preferences panel offers three personal display choices:
- Default order — the sort order applied whenever the library is opened
  (Newest first, Recently updated, Oldest first, Title A–Z, Title Z–A).
- Links per page — 10 / 25 / 50 / Show all. When a limit is set, the library
  shows that many with a "Show more" control that reveals the next page in place;
  the count reads "N of M links". Changing the view, search, sort, or tag filters
  resets to the first page.
- Text size — Small / Normal / Large, changing the reading text immediately.

The Sort dropdown in the toolbar changes the order only for the current session
and does NOT overwrite the saved default; only changing "Default order" in
Preferences updates the saved default. Preferences are stored with the user's
library and sync across devices (not tied to one browser). Selecting "all N
matching" continues to include results not yet revealed by paging.

## Gherkin
Feature: Display preferences

  Scenario: Default order applies on open but the Sort dropdown is temporary
    Given the saved default order is "Title A–Z"
    When the library opens
    Then links are ordered A–Z
    When the client changes the Sort dropdown to "Newest first"
    Then the current view reorders
    And the saved default order remains "Title A–Z"

  Scenario: Only Preferences changes the default
    When the client changes "Default order" in Preferences
    Then the saved default order updates and syncs with the library

  Scenario: Paging with Show more, and select-all spans all pages
    Given "Links per page" is 10 and 12 links match
    Then 10 are shown with "10 of 12 links" and a Show more control
    When the client chooses "Select all N matching"
    Then all 12 matching links are selected, including those not yet revealed

  Scenario: Text size changes reading text immediately
    When the client picks a text size
    Then the link text resizes at once

## Assumptions
- Preferences are stored per user library and sync across devices — this implies
  an account/synced-storage model for the library (see non-functional NF-003).
- Session sort (toolbar dropdown) is separate from the saved default order.
- Pagination is presentational; matching-set operations ignore the page limit.
