Scenario ID: SCN-019
Title: Combine text search and a tag across the whole collection
Type: Edge Case
Approval status: approved
Approval session: SESSION-019
Approval cycle: 1

## Approved behaviour

The client can combine a live text search with one selected sidebar tag. Only bookmarks satisfying both conditions are shown, and the result banner displays the search phrase and tag together so the narrowing context is explicit. Both conditions are evaluated against the entire collection rather than only the currently visible numbered page.

## Gherkin

Feature: Pinpoint bookmarks with combined narrowing

  Scenario: Combine a search phrase with a selected tag
    Given the personal collection spans one or more numbered pages
    And bookmarks have different searchable content and tags
    When the user selects a tag
    And enters a search phrase
    Then the application searches the entire collection
    And only bookmarks matching the phrase and carrying the selected tag are shown
    And the result banner shows both the phrase and selected tag

## Assumptions

- Search and tag selection use intersection semantics: a bookmark must satisfy both.
- Applying or changing search and tag conditions starts the filtered result set from its first page.
