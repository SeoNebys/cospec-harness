Scenario ID: SCN-011
Title: Show an honest empty state when search finds nothing
Type: Edge Case
Approval status: approved
Approval session: SESSION-011
Approval cycle: 1

## Approved behaviour
When a search matches no saved title, description, or personal note, the app retains the entered query, shows a count of zero bookmarks, and plainly states that no bookmarks match. It does not pad the result with unrelated bookmarks, allowing the person to edit the query and try again.

## Gherkin
Feature: Search bookmarks

  Scenario: Search finds no matching bookmark
    Given the library contains bookmarks
    When the person searches for text absent from every title, description, and personal note
    Then the app keeps the entered query visible and editable
    And the app shows a result count of zero bookmarks
    And the app states that no bookmarks match the search
    And the app shows no unrelated bookmarks

## Assumptions
- A no-match search does not broaden or replace the person's query automatically.
- The search field remains editable in the empty result state.
