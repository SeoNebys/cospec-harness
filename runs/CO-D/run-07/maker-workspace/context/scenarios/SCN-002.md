Scenario ID: SCN-002
Title: Correct a bookmark's title/description — same edit screen when saving and later
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The client can correct the auto-filled title and description using one consistent
edit screen, in two situations:
1. While saving: the pre-filled preview (SCN-001) is editable; the client changes
   the title and/or description and then confirms with Save. The bookmark is
   added with the corrected details.
2. Later: each saved bookmark has a clearly labelled Edit button. Pressing it
   opens the same edit screen, pre-filled with the current details. Changing the
   title and/or description and pressing Save updates the saved bookmark.
Cancel backs out without saving: for a brand-new link nothing is added to the
collection; for an existing bookmark it is left unchanged. The client confirmed
the shared edit screen feels consistent and that Cancel behaves as expected.

## Gherkin
Feature: Correct bookmark details

  Scenario: Correct details while saving a new link
    Given the pre-filled save preview is shown for a pasted link
    When I change the title and/or description and press Save
    Then the bookmark is added with my corrected title and/or description

  Scenario: Correct details of an already-saved bookmark
    Given a saved bookmark is in my collection
    When I press its Edit button
    Then the same edit screen opens, pre-filled with the current details
    And when I change the title and/or description and press Save
    Then the saved bookmark shows my corrected details

  Scenario: Cancel a new save
    Given the pre-filled save preview is shown for a pasted link
    When I press Cancel
    Then no bookmark is added to my collection

  Scenario: Cancel an edit of an existing bookmark
    Given the edit screen is open for a saved bookmark
    When I press Cancel
    Then the bookmark is left unchanged

## Assumptions
- The same edit screen layout is used for save-time preview and later editing.
- Only title and description are edited by the client here (site, image, icon,
  link are page-derived; changing those is not part of this scenario).
