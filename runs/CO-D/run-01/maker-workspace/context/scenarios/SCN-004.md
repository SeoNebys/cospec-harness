Scenario ID: SCN-004
Title: Format a personal bookmark note
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A bookmark note can contain bold and italic emphasis, bullet lists, and links. The person applies formatting with familiar visible toolbar buttons after selecting text rather than by typing formatting symbols. The saved note is rendered with its formatting on the bookmark card, including links that can be followed.

## Gherkin
Feature: Formatted bookmark notes

  Scenario: Apply basic formatting with a toolbar
    Given a bookmark note is open for editing
    When the person selects note content and applies bold, italic, a bullet list, or a link from the toolbar
    Then the editor visibly applies the chosen formatting

  Scenario: Read a formatted saved note
    Given a bookmark note contains basic formatting
    When the person saves the note
    Then the bookmark card renders the note with its emphasis and bullet structure
    And links in the note can be followed

## Assumptions
- Formatting controls are visible in a toolbar and use familiar writing-tool interactions.
- Supported note formatting is limited to bold, italic, bullet lists, and links.
- Formatting is rendered rather than shown as formatting symbols when reading the saved note.
