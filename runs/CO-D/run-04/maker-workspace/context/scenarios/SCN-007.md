Scenario ID: SCN-007
Title: Keep and clear a Read later pile
Type: Happy Path
Approval status: approved
Approval session: SESSION-007
Approval cycle: 1

## Approved behaviour
A bookmark has a separate, always-visible one-click control for adding it to
Read later without opening it. The Read later sidebar entry shows how many
bookmarks are waiting and opens a view containing only those bookmarks. In that
view, marking a bookmark as read removes its Read later status and clears it
from the pile without removing it from All bookmarks. When the pile becomes
empty, an all-caught-up message explains that the bookmarks remain safe.

## Gherkin
Feature: Read bookmarks later

  Scenario: Add a bookmark to Read later
    Given a bookmark is visible in the collection
    When the person uses its Read later control
    Then the bookmark is added to the Read later pile
    And the Read later sidebar count increases
    When the person opens Read later
    Then the added bookmark is shown in that view

  Scenario: Mark a bookmark as read
    Given the Read later view contains a bookmark
    When the person marks the bookmark as read
    Then it leaves the Read later view
    And the Read later sidebar count decreases
    And the bookmark remains in All bookmarks
    And an all-caught-up message is shown when the pile is empty

## Assumptions
- Read later has its own persistent sidebar entry and count.
- Adding to Read later is a separate one-click control on each bookmark.
- Marking as read removes only the Read later status and does not delete or archive the bookmark.
