Scenario ID: SCN-004
Title: Opt links into a read-later list and track read/unread status
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Read-later is a deliberate choice, not automatic. When saving a link the client
can tick "Add this to my read-later list"; the box is unchecked by default, so a
link only joins the reading pile when the client opts in. Links not in
read-later show no reading status — only a "+ Add to read-later" action —
keeping tools and reference links uncluttered. A read-later link shows its
status: "● To read" by default or "✓ Read" once marked, with a reversible
"Mark as read" / "Mark as to read" toggle; a read item's card is slightly
dimmed. The client can move a link into read-later ("+ Add to read-later") or
out of it ("Remove from read-later") at any time after saving. Three view tabs —
All, To read, Read — filter the list; "To read" and "Read" contain only
read-later links (unread / read respectively), and the "To read" tab shows a
badge counting unread read-later links.

## Gherkin
Feature: Read-later list and read status

  Scenario: Save a link without read-later (default)
    Given the read-later checkbox is unchecked
    When the client saves a link
    Then the link is not in the read-later list
    And it shows only a "+ Add to read-later" action, with no reading status

  Scenario: Save a link into read-later
    Given the client ticks "Add this to my read-later list"
    When the client saves the link
    Then the link is in the read-later list with status "To read"

  Scenario: Add an existing link to read-later later
    Given a saved link not in read-later
    When the client chooses "+ Add to read-later"
    Then the link joins the read-later list as "To read"

  Scenario: Remove a link from read-later
    Given a read-later link
    When the client chooses "Remove from read-later"
    Then the link leaves the read-later list and shows no reading status

  Scenario: Mark a read-later link read and unread
    Given a read-later link with status "To read"
    When the client marks it as read
    Then its status becomes "Read" and its card is dimmed
    And the action reverses to "Mark as to read"

  Scenario: View tabs and unread count
    Given a mix of read-later and non-read-later links
    When the client opens the "To read" view
    Then only unread read-later links are shown
    And the "To read" tab shows a badge counting unread read-later links
    And the "Read" view shows only read read-later links
    And the "All" view shows every saved link

## Assumptions
- Read-later membership and read/unread status are separate concepts.
- The read-later opt-in checkbox is unchecked by default at save.
- Only read-later links carry a reading status; others show a quick add action.
- Marking read is reversible; read items remain visible but dimmed.
