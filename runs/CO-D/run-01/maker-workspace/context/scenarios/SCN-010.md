Scenario ID: SCN-010
Title: Permanently delete a bookmark with confirmation
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Delete is a permanent action in the bookmark's three-dot menu and is clearly distinct from reversible archive. Before deletion, the app names the bookmark, warns that removal cannot be undone, and offers both Keep bookmark and Delete bookmark. Keeping it changes nothing. Confirming deletion removes it from the full collection and Archive.

## Gherkin
Feature: Delete a bookmark

  Scenario: Cancel permanent deletion
    Given the delete warning for a bookmark is open
    When the person chooses Keep bookmark
    Then the warning closes
    And the bookmark remains unchanged in the collection

  Scenario: Confirm permanent deletion
    Given the delete warning names the bookmark and explains that deletion cannot be undone
    When the person chooses Delete bookmark
    Then the bookmark is removed from the collection
    And it does not appear in Archive

## Assumptions
- Delete is available from the bookmark's three-dot action menu.
- The confirmation uses explicit action names rather than a generic yes/no choice.
- There is no recovery after confirmed deletion.
