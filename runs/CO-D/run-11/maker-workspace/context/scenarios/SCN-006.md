Scenario ID: SCN-006
Title: Find bookmarks by searching, with highlighting, combinable with tags
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A search box lets the client find bookmarks by text. Search is case-insensitive
and looks across the title, description, personal note, web address, and tags.
Typing several bare words requires all of them to be present (implicit AND). The
matching text is highlighted in the results, and the heading shows how many of
the total bookmarks match. Search combines with tag filters: results must both
carry the selected tags and match the search text. When nothing matches, an
explanatory empty state names what was searched.

## Gherkin
Feature: Search bookmarks

  Scenario: Search across fields, case-insensitively
    Given saved bookmarks
    When the client types a word (in any case)
    Then bookmarks whose title, description, note, address or tags contain it are shown
    And the matching text is highlighted

  Scenario: Multiple bare words require all
    When the client types two words
    Then only bookmarks containing both are shown

  Scenario: Search combined with tag filters
    Given one or more tags are selected
    When the client also types search text
    Then results must carry the selected tags and match the search text

  Scenario: Result count shown while filtering
    When a search or tag filter is active
    Then the heading shows how many of the total bookmarks match

## Assumptions
- Search fields: title, description, personal note, address, tags (client
  confirmed; note included once note-writing exists — see SCN-008).
