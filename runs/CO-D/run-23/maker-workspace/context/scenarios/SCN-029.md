Scenario ID: SCN-029
Title: Show imported bookmarks honestly when saved dates are missing
Type: Edge Case
Approval status: approved
Approval session: SESSION-029
Approval cycle: 1

## Approved behaviour
When an imported browser bookmark has no saved date in the source file, the app displays Date unavailable rather than inventing a date. When the library is ordered by newest or oldest, bookmarks with unknown dates are grouped after every bookmark with a real date so they do not masquerade as either the newest or oldest items.

## Gherkin
Feature: Import browser bookmarks

  Scenario: Import a bookmark without a saved date
    Given a valid browser bookmark file contains a bookmark without a saved date
    When the person imports the file
    Then the bookmark is imported
    And its card shows "Date unavailable"
    And no artificial date is assigned

  Scenario Outline: Order bookmarks when some dates are unknown
    Given the library contains bookmarks with real dates
    And it contains bookmarks whose dates are unavailable
    When the person orders the library by <order>
    Then bookmarks with real dates appear in the requested order
    And bookmarks with unavailable dates appear after all dated bookmarks

    Examples:
      | order        |
      | Newest first |
      | Oldest first |

## Assumptions
- The import source is the authority for historical saved dates.
