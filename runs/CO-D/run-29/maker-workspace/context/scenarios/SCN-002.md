Scenario ID: SCN-002
Title: Visit and later edit a saved bookmark from the collection
Type: Happy Path
Approval status: approved
Approval session: SESSION-002
Approval cycle: 1

## Approved behaviour
The collection presents a saved bookmark in a readable row. Selecting its title opens the original webpage. A separate three-dot menu contains the action for editing the bookmark. Choosing that action reopens the same filled-in details. Changes to the title or description can be saved, and the changed details appear wherever the bookmark is shown in the collection.

## Gherkin
Feature: Use saved bookmarks

  Scenario: Open the original webpage from a bookmark
    Given a bookmark is shown in the collection
    When the client selects the bookmark title
    Then the bookmark's saved web address is opened

  Scenario: Open a saved bookmark for later editing
    Given a bookmark is shown in the collection
    When the client opens its three-dot menu
    And chooses to edit the bookmark
    Then the bookmark's filled-in details are opened for editing

  Scenario: Save a later correction to the title or description
    Given a saved bookmark is open for editing
    When the client changes its title or description
    And saves the changes
    Then the changed details are retained for that bookmark
    And the changed details appear when the bookmark is shown in the collection

## Assumptions
- Selecting the bookmark title is distinct from opening the bookmark's action menu.
- Bookmark actions are contained in a three-dot menu to keep the collection uncluttered.
- This scenario covers later corrections to the title and description; correcting the address is explored separately.
