Scenario ID: SCN-001
Title: Quick-save a link and see it become a recognizable entry
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

The client pastes a link's address into a single save box pinned at the top of
the page and presses Save. The system automatically retrieves recognizable
details about the page and creates a saved entry. The new entry appears at the
top of a readable list (newest first) and is briefly highlighted.

Each entry shows, so the link is recognizable at a glance:
- the page title
- a short description of the page
- the site it came from
- the site icon (favicon)
- how long ago it was saved

A plain address without the leading protocol (e.g. "example.com") is accepted
and understood. When page details cannot be retrieved, the entry is still
created using the address, with a gentle note that details couldn't be fetched.

The client confirmed: the set of details shown is right, the calm layout with a
pinned save box and newest-first ordering is right, and saving via a single
address field plus a Save button is the quick-saving experience intended.

- The entry title falls back to the address/host when no page title is found.
- "Recognizable details" = title, description, site name, favicon, saved-time
  (client confirmed this set).
