Scenario ID: SCN-005
Title: Keep an optional safety-net copy of an important link
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When saving a link, the client may tick an optional "Keep a copy in case this
page disappears" choice. It is unticked by default, so copies are kept only for
individual important links, not every bookmark. A link with a kept copy shows a
"Copy kept" badge and a "View saved copy" action. The normal link continues to
open the original page as usual; the saved copy is a separate thing the client can
open inside the app. Opening the saved copy shows the preserved content within the
app, headed by a note stating when it was captured and that it remains available
even if the original page later changes or disappears. The copy can be closed to
return to the list.

## Gherkin
Feature: Safety-net copy of a link

  Scenario: Keep a copy for an important link
    Given the client is saving a link
    And the "Keep a copy" option is unticked by default
    When the client ticks "Keep a copy" and saves
    Then the saved link shows a "Copy kept" badge and a "View saved copy" action

  Scenario: Ordinary links keep no copy
    Given the client leaves "Keep a copy" unticked
    Then the saved link has no kept copy and no "View saved copy" action

  Scenario: The normal link still opens the original
    Given a link has a kept copy
    When the client clicks the link's title
    Then the original page opens as usual (separate from the saved copy)

  Scenario: View the saved copy
    Given a link has a kept copy
    When the client clicks "View saved copy"
    Then the preserved content is shown inside the app
    And it is headed by when it was captured and that it remains available if the original is gone
    And the client can close it to return to the list

## Assumptions
- Keeping a copy is opt-in per link, unticked by default.
- The saved copy is captured at save time.
- The normal link keeps opening the live original; the copy is separate.
- The saved copy is viewed inside the app.
