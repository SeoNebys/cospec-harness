Scenario ID: SCN-004
Title: Find bookmarks by their saved content
Type: Happy Path
Approval status: approved
Approval session: SESSION-004
Approval cycle: 1

## Approved behaviour
Search results narrow as the client types. Matching is case-insensitive and looks across bookmark titles, descriptions, and personal notes. When a result matched through its note rather than visible card content, the result shows a short note excerpt explaining the match.

## Gherkin
Feature: Search saved bookmarks

  Scenario Outline: Search across saved text without case sensitivity
    Given the collection contains bookmarks with titles, descriptions, and personal notes
    When the user types a search term that occurs in a bookmark <field> using different capitalization
    Then results update as the user types
    And the matching bookmark is shown
    And bookmarks that do not match are hidden

    Examples:
      | field       |
      | title       |
      | description |
      | note        |

  Scenario: Explain a match found only in a personal note
    Given a search term matches a bookmark's note but not its title or description
    When that bookmark appears in the search results
    Then a short excerpt from the matching note is shown with the result

## Assumptions
- Search is available from the bookmark collection.
- Results update without requiring a separate submit action.
- The full note remains off the normal collection card; a relevant excerpt is exposed only to explain a note match.
