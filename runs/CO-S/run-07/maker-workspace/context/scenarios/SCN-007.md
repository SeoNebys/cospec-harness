Scenario ID: SCN-007
Title: Add and remove a bookmark from Read later
Type: Happy Path
Approval status: approved
Approval session: SESSION-007
Approval cycle: 1

## Approved behaviour
Each bookmark card has a clearly labelled "Read later" control. Selecting it adds the bookmark to Read later and immediately confirms the change on the card. Selecting the same control again removes the bookmark from Read later. Using this control does not open the bookmark's website.

## Gherkin
Feature: Mark bookmarks to read later

  Scenario: Add a bookmark to Read later
    Given a bookmark is not marked to read later
    When the user selects its "Read later" control
    Then the bookmark is added to Read later
    And the card immediately confirms that it is saved for later
    And the bookmark's website does not open

  Scenario: Remove a bookmark from Read later
    Given a bookmark is marked to read later
    When the user selects its active Read later control
    Then the bookmark is removed from Read later
    And the card immediately shows that it can be added again
    And the bookmark's website does not open

## Assumptions
- The Read later control remains visible on each bookmark card.
- Read later is a reversible state and does not create or delete a bookmark.
