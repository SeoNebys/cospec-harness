Scenario ID: SCN-017
Title: Permanently delete a bookmark only after confirmation
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Permanent deletion begins deliberately at the bottom of bookmark details, away from everyday browsing actions. Choosing Delete bookmark opens a separate confirmation that names the bookmark, explains that its saved title, labels, and personal note will be removed, states that the action cannot be undone, and offers a clear way to back out. Confirming Delete permanently removes the bookmark and clearly confirms that it was deleted.

## Gherkin
Feature: Permanently delete a bookmark

  Scenario: Back out of permanent deletion
    Given the user has opened a bookmark's details
    When the user chooses Delete bookmark
    Then the app names the bookmark that would be deleted
    And explains which saved information would be lost
    And states that deletion cannot be undone
    And offers an action to keep the bookmark
    When the user chooses to keep it
    Then the bookmark and its information remain unchanged

  Scenario: Confirm permanent deletion
    Given the user is viewing the permanent-deletion confirmation for a bookmark
    When the user chooses Delete permanently
    Then the bookmark and its saved information are removed from the library
    And the app confirms that the bookmark was deleted

## Assumptions
- Archive is a separate reversible action and is not part of permanent deletion.
