Title: Order the bookmark list — newest-first by default, plus oldest and title A–Z
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The bookmark list can be reordered via a Sort control. Ordering options are exactly
three: "Newest first", "Oldest first", and "Title A–Z".
- The default when the client opens the app is "Newest first" (most recently saved
  at top).
- Sorting applies to whatever set is currently shown — if labels/search are
  filtering the list, only that filtered pile is reordered, not the whole library.

The client explicitly rejected adding further sort options (e.g. by last-opened, or
by label): three is deliberately the complete set, to keep the control free of
noise. Sorting by label is considered already served by clicking the label.
