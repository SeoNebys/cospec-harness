Scenario ID: SCN-009
Title: Keep a link when its page details cannot be retrieved
Type: Error Case
Approval status: approved
Approval session: SESSION-009
Approval cycle: 1

## Approved behaviour

When a valid web address cannot be reached to retrieve its page details, the link is still saved so the client does not lose it. The application creates a basic card that shows the source domain and full address, clearly labels the bookmark as untitled, and offers an Edit title action so the client can make it recognizable manually.

## Gherkin

Feature: Preserve bookmarks when page details are unavailable

  Scenario: Save a reachable-format address whose page cannot be retrieved
    Given the user enters a valid web address
    And the page cannot be reached to retrieve its title, preview, description, or reading time
    When the user saves the bookmark
    Then a basic bookmark card is added to the collection
    And the card shows the source domain and full web address
    And the card is visibly identified as untitled
    And the card offers an action to edit its title manually

## Assumptions

- The entered address has a valid web-address format.
- Automatic retries are not required after the basic card is saved.
- Editing the basic card's title does not require the unavailable page to become reachable.
