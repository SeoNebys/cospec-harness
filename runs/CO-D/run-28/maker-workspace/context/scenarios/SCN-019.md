Scenario ID: SCN-019
Title: Import and export the standard browser-bookmarks HTML file
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
From Settings, the client can export all bookmarks to a standard Netscape-format
bookmarks.html (the format Chrome/Firefox/Safari read and write), carrying each
entry's title, tags (TAGS attribute) and original date (ADD_DATE; LAST_MODIFIED
where available). The client can import such a file (from this app or a real
browser); imported bookmarks retain their titles, tags and dates. Links already
saved are skipped using the same near-duplicate rules (SCN-012), and a summary
reports how many were imported and how many skipped.

## Gherkin
Feature: Import/export standard bookmarks HTML

  Scenario: Export
    When the client exports
    Then a standard Netscape-format bookmarks.html is produced
    And each entry carries its title, tags and original date

  Scenario: Import keeps fields and skips duplicates
    Given an existing collection
    When the client imports a bookmarks.html
    Then new entries are added with their titles, tags and dates
    And links already saved (by near-duplicate rules) are skipped
    And a summary reports imported and skipped counts

## Assumptions
- The interchange format is the standard browser bookmarks file; it carries only
  title/tags/dates — private notes, read-later/archive state, saved copies,
  settings and collections do NOT travel in this format (client accepted).
- A separate full backup (everything) is deferred to a later cycle.
