Scenario ID: SCN-008
Title: Archive and restore a bookmark
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A visible Archive action on each bookmark removes it from the main library,
updates the active and archived counts, and offers an immediate Undo. The
bookmark remains intact in a separate Archived view. Restoring it removes it
from the archive and returns it unchanged to the main library.

## Gherkin
Feature: Archiving bookmarks

  Scenario: Archive a bookmark without losing it
    Given a bookmark is in the active library
    When the person chooses its visible Archive action
    Then the bookmark is removed from the active library
    And the active and archived counts are updated
    And an Undo action is offered
    And the bookmark remains intact in the Archived view

  Scenario: Undo an archive action immediately
    Given a bookmark was just archived
    When the person chooses Undo
    Then the bookmark returns to the active library
    And the active and archived counts are updated

  Scenario: Restore a bookmark from the archive
    Given a bookmark is in the Archived view
    When the person restores it
    Then the bookmark leaves the Archived view
    And returns unchanged to the active library

## Assumptions
- Archive is a visible action directly on each active bookmark.
- Archived bookmarks do not appear in the main library.
- Restore is available directly on an archived bookmark.
