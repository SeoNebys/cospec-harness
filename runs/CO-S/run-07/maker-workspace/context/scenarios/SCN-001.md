Scenario ID: SCN-001
Title: Fill in page details from a pasted web address
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A new user with an empty collection can paste a full web address and ask the app to get its details. The app then shows a title and page description already filled in. Both details remain editable so the user can correct them before saving.

## Gherkin
Feature: Prepare a bookmark from a web address

  Scenario: Fill in editable page details
    Given the user's bookmark collection is empty
    And the user has entered a valid web address
    When the user asks the app to get the page details
    Then the app displays the page title filled in from the page
    And the app displays the page description filled in from the page
    And the user can edit the displayed title and description

## Assumptions
- The web address is complete, valid, and reachable.
- The page provides a title and description that can be retrieved.
- Page details are retrieved after the user selects "Get details".
- The collection belongs to one user and does not require a multi-person account flow.
