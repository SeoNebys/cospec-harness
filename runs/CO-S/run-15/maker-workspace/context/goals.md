# Business goal

## Cycle 1 — approved goal statement

### Client's request (verbatim)
- "I want to build an app to save and manage bookmarks."
- "Right now my bookmarks are scattered across browser folders and I often
  can't find something when I need it. I also save things to read later, then
  lose track of what I've actually read."
- "They're a mix of articles, useful tools, and project references. I'd like
  one place where I can save a link quickly, organise it with tags, search for
  it later, and keep a clear read-later list."
- "Finding saved links again is the biggest win. The read-later list is
  important too, but secondary."

### Goal (client's language)
One place to save a link quickly, organise it with tags, and reliably find it
again later. Keep a clear read-later list that shows what has and hasn't been
read.

### Priority
1. Primary: always be able to find a saved link when needed.
2. Secondary: stay on top of the read-later list (read vs. unread).

### Means (not the goal itself)
- Quick save
- Tagging
- Search
- Read-later / read-status tracking

### Interface form
Web app, opened in a browser, used comfortably on both computer and phone
(client's words). Confirmed by client (Cycle 1).

### Status
Goal confirmed by client (Cycle 1).
