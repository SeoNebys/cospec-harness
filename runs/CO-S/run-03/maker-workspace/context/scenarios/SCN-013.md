Scenario ID: SCN-013
Title: Explain a search with no matches
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When no bookmarks match a search, the list is empty and a plain message says
that no bookmarks match. The search text remains visible and a clear control
returns directly to the full library.

## Gherkin
Feature: Searching bookmarks

  Scenario: Search finds no bookmarks
    Given the library contains bookmarks
    When the person searches for text that matches none of them
    Then no bookmarks are shown
    And a message says that no bookmarks match the search
    And the entered search text remains visible
    When the person clears the search
    Then the full library is shown again

## Assumptions
- Clearing the search takes one action from the search box.
