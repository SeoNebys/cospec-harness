Scenario ID: SCN-026
Title: Recover clearly when a full backup cannot be created
Type: Error Case
Approval status: approved
Approval session: SESSION-026
Approval cycle: 1

## Approved behaviour
If creating the full backup fails, the app plainly reports that no backup was produced and explicitly reassures the person that their library is unchanged. The download action becomes Retry full backup so they have an immediate recovery path. No success state or file is shown for the failed attempt.

## Gherkin
Feature: Export the bookmark library

  Scenario: Full backup creation fails
    Given the person requests a full library backup
    When the backup cannot be created
    Then the app reports the failure clearly
    And it states that the library is unchanged
    And no completed backup is shown
    And the person can retry the full backup directly

## Assumptions
- A failed export never modifies library data.
