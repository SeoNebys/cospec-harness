Scenario ID: SCN-019
Title: Keep a preserved copy of a page, with optional Internet Archive
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

When saving, the user can keep a preserved copy of the page — on by default — so
it can be revisited even if the original changes or disappears. For an ordinary
page the preserved copy is a self-contained local copy the user can open
independently of the original site. For a PDF link the preserved copy is the PDF
file itself, and the option's wording reflects that. Separately, and off by
default, the user can request a copy on the Internet Archive; when requested, the
bookmark shows a link that leads to the archived version (once available). A
bookmark with a kept copy shows a "Saved copy" (or "Saved PDF") action that opens
the preserved copy.

## Gherkin

Feature: Preserved copy

  Scenario: Keep a copy by default
    Given the user saves an ordinary page with "keep a copy" left on
    Then a self-contained local copy is preserved
    And the bookmark shows a "Saved copy" action that opens it, available even if the original changes

  Scenario: PDF is preserved as the PDF
    Given the user saves a link to a PDF
    Then the preserved copy is the PDF file itself
    And the option and action wording reflect that it is a PDF

  Scenario: Optional Internet Archive copy
    Given the user ticks "also request a copy on the Internet Archive" (off by default)
    When the bookmark is saved
    Then it shows a link leading to the archived version on the Internet Archive

## Assumptions
- "Keep a copy" defaults on; Internet Archive request defaults off.
- Ordinary pages are preserved as a self-contained local copy; PDFs as the file.
- The Internet Archive link leads to the archived version once available.
