Scenario ID: SCN-013
Title: Narrow search results with and
Type: Happy Path
Approval status: approved
Approval session: SESSION-013
Approval cycle: 1

## Approved behaviour
The person can combine search conditions with the word "and". A bookmark remains visible only when both conditions match, including combinations of ordinary text and exact labels. The command word does not depend on capitalization.

## Gherkin
Feature: Combining bookmark searches

  Scenario: Require text and a label to both match
    Given one bookmark contains "flexbox" in its searchable text and carries the "CSS" label
    When the person searches for "flexbox and #css"
    Then that bookmark is shown
    And every bookmark that fails either condition is hidden

## Assumptions
- Search command words ignore capitalization.
