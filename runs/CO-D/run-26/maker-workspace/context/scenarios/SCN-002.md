Scenario ID: SCN-002
Title: Suggest existing tags while typing to avoid near-duplicates
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
While the client types in the Tags field, the app suggests tags that have been used
before and match what is being typed. The client can click a suggested tag to reuse
it exactly rather than retyping it, which avoids accidentally creating near-duplicate
tags. Tags already chosen for the current bookmark are not offered again.

## Gherkin
Feature: Reuse existing tags

  Scenario: Suggest matching existing tags as the client types
    Given the collection already contains bookmarks with tags
    When the client types text into the Tags field
    Then the app shows previously used tags that match the typed text
    And tags already added to the current bookmark are not suggested

  Scenario: Reuse a suggested tag by clicking it
    Given tag suggestions are shown
    When the client clicks a suggested tag
    Then that exact tag is added to the current bookmark's tags

## Assumptions
- Matching is a case-insensitive contains-match on the tag being typed.
- Suggestions are also usable via keyboard (up/down/enter) in the prototype; the
  approved behaviour is "match while typing and select to reuse."
