Scenario ID: SCN-005
Title: Write my own notes on a bookmark (distinct from the page's description) and search them
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A bookmark can carry the client's OWN notes, separate from the page's auto-filled
description.
- At save time there is an optional "My notes" field, shown below the Description.
  It is clearly the client's own words, distinct from "the page's own words".
- Notes are optional; most saves will leave it empty and the empty field must not
  feel like a nag.
- On a saved bookmark, the note is displayed set apart from the description (a warm
  "My note:" box), unmistakably the client's own.
- Search covers the note text as well as title, description, address, and labels.
  A word that appears ONLY in the client's note still surfaces the bookmark, with
  the match highlighted in the note.

Client framing (why this matters most): "I remember why I saved something, not what
the page called itself."

## Gherkin
Feature: Personal notes on bookmarks

  Scenario: Add a note while saving
    Given the client is reviewing a bookmark before saving
    When the client types text into "My notes"
    And saves the bookmark
    Then the saved bookmark shows that note, visually distinct from the description

  Scenario: Notes are optional
    When the client saves without entering a note
    Then the bookmark is saved with no note and nothing prompts them to add one

  Scenario: Search finds a bookmark by its note alone
    Given a bookmark whose page text never contains the word "meeting"
    And whose personal note does contain "meeting"
    When the client searches "meeting"
    Then that bookmark appears with the word highlighted in the note

## Assumptions
- "Description" = the page's own words (auto-filled). "My notes" = the client's own
  words. They are separate fields, both searchable.
- Notes placement at save time is below the description (client confirmed).
