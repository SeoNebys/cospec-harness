Scenario ID: SCN-009
Title: Permanently delete an archived bookmark deliberately
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Permanent deletion is available only for archived bookmarks and is placed inside the archived card's overflow menu as a deliberate extra step. Selecting it opens a confirmation that names the exact bookmark, says it will be removed for good, and warns that the action cannot be undone. Cancelling closes the confirmation and leaves the bookmark untouched. Confirming permanently removes the bookmark from the Archive with no restore action. The client selected the menu placement after comparing it with a direct Delete button.

## Gherkin
Feature: Permanently delete an archived bookmark

  Scenario: Ask for confirmation before permanent deletion
    Given a bookmark is visible in the Archive
    When the user opens its overflow menu and selects "Delete permanently"
    Then a confirmation names that bookmark
    And it states that the bookmark will be removed for good
    And it warns that the action cannot be undone

  Scenario: Cancel permanent deletion
    Given the permanent-delete confirmation is open for an archived bookmark
    When the user cancels
    Then the confirmation closes
    And the bookmark remains intact in the Archive

  Scenario: Confirm permanent deletion
    Given the permanent-delete confirmation is open for an archived bookmark
    When the user confirms "Delete permanently"
    Then the bookmark is removed from the Archive
    And it is no longer available to restore

## Assumptions
- Permanent deletion is available only from an archived bookmark.
- The approved interaction places it inside the archived card's overflow menu rather than directly on the card.
- Archive remains the immediate, reversible cleanup action and does not require confirmation.
