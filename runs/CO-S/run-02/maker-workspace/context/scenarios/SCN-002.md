Scenario ID: SCN-002
Title: Add a visible tag to a saved bookmark
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The client adds a tag to an already-saved bookmark. After it is added, the tag appears as a visible label directly on that bookmark.

## Gherkin
Feature: Organizing bookmarks

  Scenario: Tag a saved bookmark
    Given a bookmark has already been saved
    And it has no tags
    When the user adds a tag to the bookmark
    Then the tag appears as a visible label on that bookmark

## Assumptions
- Tags can be added after a bookmark has been saved.
- A tag is entered as a plain-text name.
- The bookmark displays its tags without requiring another view to be opened.
