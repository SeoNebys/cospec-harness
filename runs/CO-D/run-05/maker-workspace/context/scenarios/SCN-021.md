Title: Import and export in standard bookmark HTML format
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

The user can import a standard browser bookmark HTML file: each link becomes a
bookmark, preserving its title, tags, and original saved date, and any
description becomes the note. Imported links start in "To read". Links already in
the collection are skipped (no duplicates, using the same-address rule as
SCN-003), and a clear summary reports how many were imported and how many
skipped. The user can export the whole collection — including archived bookmarks
— as a standard bookmark HTML file, writing each bookmark's title, tags, original
saved date, and note, so the collection is portable and round-trips.

## Gherkin

Feature: Import and export

  Scenario: Import a standard bookmark file
    Given a standard browser bookmark HTML file
    When the user imports it
    Then each link becomes a bookmark preserving its title, tags and original saved date
    And any description becomes the note
    And imported links start in "To read"
    And a summary reports the number imported

  Scenario: Imports skip already-saved links
    Given some links in the file are already saved
    When the user imports the file
    Then those links are skipped and the summary reports how many were skipped

  Scenario: Export the whole collection
    When the user exports
    Then a standard bookmark HTML file is produced for the whole collection, including archived bookmarks
    And each entry preserves its title, tags, original saved date and note

## Assumptions
- Format is the standard (Netscape) bookmark HTML browsers read and write.
- Imported links default to "To read"; duplicates are skipped with a clear summary.
- Export includes archived bookmarks and notes; dates are the original saved dates.
