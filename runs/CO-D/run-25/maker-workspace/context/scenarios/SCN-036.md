Scenario ID: SCN-036
Title: Return to the empty collection after deleting the final bookmark
Type: Edge Case
Approval status: approved
Approval session: SESSION-036
Approval cycle: 1

## Approved behaviour
After the final bookmark is permanently removed, the collection shows a zero count and returns to the same welcoming empty state used for a new collection, including guidance to save a bookmark. It never leaves a blank or broken-looking list.

## Gherkin
Feature: Removing bookmarks

  Scenario: Permanently remove the final bookmark
    Given the collection contains exactly one bookmark
    When the person removes it and confirms permanent removal
    Then the bookmark count is zero
    And the welcoming empty-collection message is shown
    And the message guides the person toward saving another bookmark

## Assumptions
- The initial empty state and post-deletion empty state are the same.
