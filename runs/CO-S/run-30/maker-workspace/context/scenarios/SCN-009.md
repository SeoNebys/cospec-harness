Scenario ID: SCN-009
Title: Reject a malformed bookmark address
Type: Error Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When the client tries to save a malformed or incomplete address, no bookmark is created. A gentle inline message beside the address field explains that a full web address is needed and provides an example. The existing library remains unchanged and focus returns to the field.

## Gherkin
Feature: Validating bookmark addresses

  Scenario: Try to save a malformed address
    Given the client has entered a malformed or incomplete address
    When the client tries to save it
    Then no bookmark is created
    And the library remains unchanged
    And an inline message beside the field asks for a full web address
    And the message includes an example of a full web address
    And focus returns to the address field

## Assumptions
- A malformed address cannot be used as a saved-page destination.
- Validation feedback is shown inline rather than in a blocking dialog.
