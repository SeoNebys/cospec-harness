Title: Edit a saved link in place
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Each link in the list has an "Edit" button. Clicking it turns that link, in place
within the list, into editable fields for its address, title, and topic, with
"Save changes" and "Cancel". On "Save changes" the link is updated; if the topic
changed, the link moves under the new topic heading and the row of topic buttons
updates accordingly. "Cancel" leaves the link unchanged. The client confirmed
editing in place (rather than a separate popup window) feels natural.

## Gherkin
Feature: Editing a saved link

  Scenario: Change a link's topic in place
    Given a saved link under the topic "Development"
    When the client clicks its "Edit" button
    And changes the topic to "Reading" and clicks "Save changes"
    Then the link appears under the "Reading" topic heading
    And a "Reading" topic button is available

  Scenario: Cancel an edit
    Given the client is editing a link in place
    When the client clicks "Cancel"
    Then the link keeps its original address, title, and topic

## Assumptions
- Editing happens inline within the list, not in a separate window.
- All three fields (address, title, topic) are editable.
- A blank address blocks saving the edit (address is required, as on create).
- Saving an edited topic re-groups the link and refreshes the topic buttons.
