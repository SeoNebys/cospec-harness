# Business goal

- Cycle: 1
- Phase confirmed in: Phase 1, Step 1 (Goal exploration)
- Interface form: personal web app, opened in a browser
- Status: confirmed by client

## Goal statement (in the client's language)

One place to save a link, have the useful page details filled in automatically,
add my own tags or notes, and later find it quickly through browsing or search.
I want to separate things I intend to read later from things I've finished, and
put older bookmarks away without deleting them. The main goal is to make saved
links genuinely easy to find and use again.

## Underlying goal (means vs. end)

- Means: saving/collecting links.
- End (the real goal): making saved links **genuinely easy to find and use
  again** — not merely collecting more links.

## Client's own words (verbatim, do not reinterpret)

> "It's mainly for me. Right now my bookmarks are scattered and become a pile I
> rarely revisit, because I can't easily remember or find what I saved.
>
> I want one place where I can save a link, have the useful page details filled
> in for me, add my own tags or notes, and later find it quickly through
> browsing or search. I'd also like to separate things I intend to read later
> from things I've finished, and put older bookmarks away without deleting them.
> The main goal is to make saved links genuinely easy to find and use again."

> "Yes, that direction is right. I'm picturing a personal web app that I can
> open in a browser. The emphasis on finding and revisiting things—not merely
> collecting more links—is exactly what I want."

## Candidate feature themes surfaced (to explore in Step 2, not yet approved)

- Save a link with auto-filled page details
- Personal tags and notes
- Find again via browsing and search
- Reading status: to-read vs. finished
- Archive older bookmarks without deleting
