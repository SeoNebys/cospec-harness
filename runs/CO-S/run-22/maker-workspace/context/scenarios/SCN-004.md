Scenario ID: SCN-004
Title: Track links still to read and mark them read
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When saving a link, an "I still want to read this" option is ticked by default,
so new links are treated as "to read" unless the client unticks it. A link marked
to read shows a "To read" badge; a read link is shown slightly dimmed and without
the badge. Under the search box there are three views: All, "To read (n)" with a
live count of how many links are still to read, and Read. Selecting a view shows
only the matching links. On each link a button toggles its reading state ("Mark as
read" / "Mark as to read"); toggling updates the badge, the dimming, the "To read"
counter, and the current view immediately. The read views combine with the tag
filter and the search box.

## Gherkin
Feature: Tracking links to read

  Scenario: New link defaults to "to read"
    Given the client is saving a link
    Then the "I still want to read this" option is ticked by default
    And saving with it ticked shows a "To read" badge on the link

  Scenario: Save a link that is already read
    Given the client unticks "I still want to read this" before saving
    Then the saved link has no "To read" badge and is shown dimmed

  Scenario: View only links still to read
    Given links exist in both read and to-read states
    When the client selects the "To read" view
    Then only links still to read are shown
    And the view label shows the count of links still to read

  Scenario: Mark a link as read
    Given a link is marked "to read"
    When the client clicks "Mark as read" on it
    Then the badge is removed, the link is dimmed
    And the "To read" counter decreases by one
    And it no longer appears in the "To read" view

  Scenario: Read views combine with tag filter and search
    Given a tag filter or search term is active
    When the client selects a read view
    Then only links matching the tag, the search, and the selected read state are shown

## Assumptions
- New links default to "to read".
- Reading state is shown by a badge plus dimming of read items.
- Three views: All / To read (with count) / Read.
- Reading state can be toggled both ways from each link.
- Read views combine with tag filter (SCN-002) and search (SCN-003).
