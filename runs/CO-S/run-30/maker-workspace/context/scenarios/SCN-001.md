Scenario ID: SCN-001
Title: Save a valid link as a recognizable bookmark
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
With an empty library, the client saves a valid web address. The empty state is replaced by one bookmark showing the page title, source site, and a short description so the saved page can be recognized later.

## Gherkin
Feature: Saving bookmarks

  Scenario: A new library has a clear empty state
    Given the library contains no bookmarks
    When the client opens the library
    Then the library clearly says that saved pages will appear there
    And the bookmark count is zero

  Scenario: Save a valid web address
    Given the library contains no bookmarks
    And a valid page is available at the entered web address
    When the client saves the web address
    Then one bookmark is added to the library
    And the bookmark shows the page title
    And the bookmark shows the source site
    And the bookmark shows a short page description

## Assumptions
- Page details are available when the valid web address is saved.
- The library belongs to one person.
- The saved bookmark is displayed as a card beneath the save box.
