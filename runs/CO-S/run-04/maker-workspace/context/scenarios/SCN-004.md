Scenario ID: SCN-004
Title: Remove a saved link, with Undo
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Each saved link has a trash control that appears when the user hovers over the
row (same place as the rename pencil). Clicking it removes the link from the list
immediately — no confirmation step. A brief message then appears ("Removed
"<name>"") with an Undo action; if the user clicks Undo within a few seconds, the
link is restored to its previous position in the list. If Undo is not used, the
message disappears and the removal stands.

## Gherkin
Feature: Removing a saved link

  Scenario: Remove a link immediately
    Given a saved link shown in the list
    When the user hovers over the row and clicks the trash control
    Then the link is removed from the list immediately without a confirmation step
    And a brief "Removed" message with an Undo action is shown

  Scenario: Undo a removal
    Given a link was just removed and the Undo message is showing
    When the user clicks Undo
    Then the link is restored to its previous position in the list

  Scenario: Removal stands when Undo is not used
    Given a link was just removed and the Undo message is showing
    When the user does not click Undo within the allotted time
    Then the message disappears and the link stays removed

## Assumptions
- Removal is immediate (no confirm dialog); safety comes from Undo, not a prompt.
- The trash control is hover-revealed, mirroring the rename pencil.
- Undo restores the link to its original position, not the top.
- The Undo window is short (a few seconds). Exact duration is a Phase 2 detail.
