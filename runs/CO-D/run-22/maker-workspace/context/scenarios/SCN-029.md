Scenario ID: SCN-029
Title: Explain and preserve an unfinished precise search
Type: Error Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When a precise-search expression is incomplete, the app does not run it or replace the previous valid results. It explains the specific problem in plain language, keeps the entered query available, and tells the person how to correct it.

## Gherkin
Feature: Precise bookmark search

  Scenario: Submit a query with an unclosed parenthesis
    Given valid search results are already visible
    When the person submits "pasta AND ("
    Then the incomplete search is not run
    And the previous valid results remain visible
    And the query remains available to edit
    And an inline message identifies the missing closing parenthesis
    And it explains how to correct the query

## Assumptions
- Search syntax is checked before replacing the current result set.
- The error identifies a specific correctable problem rather than showing a generic failure.
