Scenario ID: SCN-006
Title: Empty state for a user with no links
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When there are no saved links at all (e.g. a brand-new user), the list area shows
a welcoming message — "No links saved yet. Add your first one above." — instead
of a blank screen. The add box remains available above it, and no topic buttons
are shown. The client found this welcome clear and appropriate.

## Gherkin
Feature: Empty state

  Scenario: No links saved yet
    Given there are no saved links
    When the bookmarks screen is shown
    Then a "No links saved yet" message invites adding the first link
    And the add box is available
    And no topic buttons are shown

## Assumptions
- Empty state is distinct from a no-search-results state (different wording).
