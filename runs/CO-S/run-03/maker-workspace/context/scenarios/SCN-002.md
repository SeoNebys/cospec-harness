Scenario ID: SCN-002
Title: Correct automatic bookmark details inline
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A saved bookmark can be edited in place. Choosing to edit opens pre-filled title
and summary fields directly beneath that bookmark. Saving a changed title or
summary immediately updates the bookmark in the list without a reload or a
separate screen.

## Gherkin
Feature: Correcting bookmark details

  Scenario: Correct the title of a saved bookmark inline
    Given a bookmark has an automatically gathered title and summary
    When the person opens its details editor
    Then the title and summary fields appear directly beneath that bookmark
    And both fields contain the bookmark's current values
    When the person changes the title and saves the changes
    Then the bookmark displays the changed title in the list
    And the person remains on the same screen
    And the page does not reload

  Scenario: Correct the summary of a saved bookmark inline
    Given a bookmark has an automatically gathered title and summary
    When the person opens its details editor
    And changes the summary
    And saves the changes
    Then the bookmark displays the changed summary in the list
    And the person remains on the same screen
    And the page does not reload

## Assumptions
- Editing is opened from the bookmark being changed.
- Editing uses inline fields rather than a pop-up or separate screen.
- Only the title and summary are corrected in this flow.
