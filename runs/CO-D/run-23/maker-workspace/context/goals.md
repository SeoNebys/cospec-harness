# Cycle 1 goal

> Honestly, right now my bookmarks are a mess — they're scattered across my browser in folders, and once I've saved a few hundred I can never find the one I'm looking for again. So the big thing is: I want to actually be able to *find* things later.
>
> A few things that would make my life better:
>
> - When I save a link, I don't want to type out what it is. I'd love it to just grab the title and a little description and the site's icon automatically, so my list is readable at a glance instead of a wall of raw web addresses.
> - I want to search across everything I've saved and actually get the right result — searching by words, not just remembering which folder I dropped it in.
> - I want to label things my own way and then pull up just the links with a certain label.
> - Some things I save because I want to read them later, and I'd like to keep those separate from the pile I've already dealt with.
> - And I get nervous that pages disappear or change — I'd feel better knowing what I saved is still there in some form even if the original goes away.
>
> That's the heart of it: save it fast, find it later, and trust it'll still be there.

Confirmed direction:

> Yes, that's the right direction — you've captured it well.

>
