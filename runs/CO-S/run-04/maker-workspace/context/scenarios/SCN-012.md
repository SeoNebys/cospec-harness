Title: The collection persists between visits (browser-local)
Type: Edge Case
Approval status: approved
Approval session: SESSION-001

Confirmation method: text (temporal behaviour; cannot be reproduced in an
in-memory prototype — reason recorded per edge-case.md).

## Approved behaviour
The client's entire collection persists between visits with nothing lost:
saved bookmarks, edited title/description/URL, tags, notes, read-later status,
and archived items are all retained when the app is closed and reopened later.
For this first version, persistence within the browser the client uses is
sufficient; the collection is private (single user). Cross-device syncing is
explicitly deferred to a later cycle.

## Gherkin
Feature: Persistent personal collection

  Scenario: Data survives between sessions
    Given the client has saved and organized bookmarks
    When the client closes the app and returns later
    Then all bookmarks, edits, tags, notes, read-later marks, and archived items are still present and unchanged

  Scenario: Private, single-user collection
    Given the collection belongs to the client
    Then it is private to the client

## Assumptions
- First version: browser-local persistence is sufficient.
- The collection is private / single-user.
- Cross-device sync is out of scope for cycle 1 (recorded for a later cycle).
