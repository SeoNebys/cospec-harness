Scenario ID: SCN-002
Title: Open a saved link
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When the client clicks a saved link's card, the original page opens in a new
browser tab. This is the payoff of having saved it.

## Gherkin
Feature: Open a saved link

  Scenario: Clicking a saved link opens the page
    Given the client has at least one saved link
    When the client clicks the saved link's card
    Then the original page opens in a new browser tab
    And the saved list remains as it was

## Assumptions
- Opening happens in a new tab so the client does not lose their list.
- Clicking anywhere on the card (outside an active edit control) opens the link.
