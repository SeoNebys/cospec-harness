Scenario ID: SCN-004
Title: Add tags and a formatted note to a bookmark
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
On the shared edit screen (used both when saving and when editing later), the
client can add their own tags and a note.

Tags: the client types a tag and presses Enter to add it as a removable #chip.
The screen also shows the tags the client has already used across their
bookmarks; clicking one adds (reuses) it. This helps avoid accidentally creating
slightly different versions of the same tag. Tags are removed with the × on the
chip. On each bookmark, tags are shown as #chips.

Note: the client writes a note that supports simple formatting and is displayed
formatted (never as raw symbols): headings, bold, italic, links, bullet lists,
numbered lists, and preserved paragraph breaks (blank line = new paragraph). The
note supports both quick reminders and longer, organised notes, and appears as a
formatted block beneath the description.

The client confirmed the tag-reuse behaviour, the #chip display, and that the
note formatting covers quick reminders and organised longer notes.

## Gherkin
Feature: Tags and notes on a bookmark

  Scenario: Add a new tag by typing
    Given the edit screen is open for a bookmark
    When I type a tag and press Enter
    Then it is added as a removable chip on the bookmark

  Scenario: Reuse an existing tag
    Given the edit screen is open and I have used tags on other bookmarks
    When I click one of my existing tags shown as a suggestion
    Then that tag is added to this bookmark without retyping

  Scenario: Write a formatted note
    Given the edit screen is open for a bookmark
    When I write a note using headings, bold, italic, links, bullet lists,
         numbered lists, and blank-line paragraph breaks, and press Save
    Then the bookmark shows the note with that formatting applied
    And no raw formatting symbols are shown

## Assumptions
- Suggested tags are drawn from tags already used across the client's bookmarks.
- Note formatting is a simple, safe subset (headings, bold, italic, links,
  bullet + numbered lists, paragraphs); links open the target page.
- Tags display as #chips; the note displays as a formatted block under the
  description.
