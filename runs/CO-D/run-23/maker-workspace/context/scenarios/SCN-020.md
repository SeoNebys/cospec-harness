Scenario ID: SCN-020
Title: Keep a valid address when page details cannot be gathered
Type: Error Case
Approval status: approved
Approval session: SESSION-020
Approval cycle: 1

## Approved behaviour
If a web address is valid but its page is temporarily unreachable while the app gathers details and a preserved copy, the address is still saved so it is not lost. The resulting card clearly shows that its title and description could not be gathered and that no copy was saved. It offers a retry action for gathering details and the saved copy later. The person can also use the ordinary inline editor to fill in details manually.

## Gherkin
Feature: Save a bookmark when its page cannot be reached

  Scenario: Keep the address and flag incomplete capture
    Given the person enters a valid web address
    And the page is temporarily unreachable
    When they save the link
    Then a bookmark is created for that address
    And it is clearly marked as missing gathered details
    And it is clearly marked as having no saved copy
    And it offers an action to retry gathering details and a saved copy
    And its details remain editable manually

## Assumptions
- The app can distinguish a syntactically valid address from an invalid one.
- A temporary retrieval failure does not prevent the address itself from being saved.
