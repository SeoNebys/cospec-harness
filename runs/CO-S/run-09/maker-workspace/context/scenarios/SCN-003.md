Scenario ID: SCN-003
Title: Search saved bookmarks by remembered context
Type: Happy Path
Approval status: approved
Approval session: SESSION-003
Approval cycle: 1

## Approved behaviour
A person searches from a prominent field above the bookmark library. The app matches the search text against bookmark titles, descriptions, and the person's own notes. Only matching bookmarks remain in the results, the result count updates, and the matching saved context stays visible so the correct item is recognizable.

## Gherkin
Feature: Search bookmarks

  Scenario: Find a bookmark by a word in a personal note
    Given the library contains several bookmarks with personal notes
    When the person searches for a word that appears only in one personal note
    Then the app shows only that bookmark
    And the matching personal note remains visible

  Scenario: Find a bookmark by a word in its description
    Given the library contains several enriched bookmarks
    When the person searches for a word that appears only in one bookmark description
    Then the app shows only that bookmark
    And the matching description remains visible

  Scenario: Find a bookmark by words in its title
    Given the library contains several enriched bookmarks
    When the person searches for words that appear in one bookmark title
    Then the app shows only that bookmark
    And the matching title remains visible

## Assumptions
- Search updates from the text entered into the field above the library.
- Search is not limited to web addresses.
- Personal notes are part of the searchable bookmark content.
- A result continues to show its title, description, source, and personal note for recognition.
