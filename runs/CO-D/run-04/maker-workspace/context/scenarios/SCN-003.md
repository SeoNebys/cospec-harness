Scenario ID: SCN-003
Title: Edit a saved bookmark from the collection
Type: Happy Path
Approval status: approved
Approval session: SESSION-003
Approval cycle: 1

## Approved behaviour
A saved bookmark has a separate, always-visible edit control so selecting the
bookmark itself remains dedicated to opening its website. Editing can change
the title, description, or web address. Changing only the address preserves a
custom title and description, updates the displayed website name, and makes the
bookmark open the corrected destination.

## Gherkin
Feature: Maintain saved bookmarks

  Scenario: Change the title and description of a saved bookmark
    Given a bookmark is visible in the collection
    When the person uses its separate edit control
    And changes the title and description
    And saves the changes
    Then the bookmark shows the changed title and description
    And selecting the bookmark still opens its website

  Scenario: Correct the web address without losing custom details
    Given a bookmark has a custom title and description
    When the person changes only its web address
    And saves the changes
    Then the custom title and description are preserved
    And the displayed website name reflects the corrected address
    And selecting the bookmark opens the corrected address

## Assumptions
- The edit control is always visible and separate from the bookmark's opening target.
- Title, description, and web address are available in the same edit view.
- A changed address does not automatically overwrite a custom title or description.
