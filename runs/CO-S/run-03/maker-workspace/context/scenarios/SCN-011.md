Scenario ID: SCN-011
Title: Keep tag names consistent
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Tag names ignore surrounding spaces and differences in capitalization. Entering
the same tag more than once produces a single lowercase tag label, preventing
near-identical tag groups.

## Gherkin
Feature: Consistent bookmark tags

  Scenario: Collapse repeated tag variants
    Given a bookmark is being tagged
    When the person enters the same tag more than once with different capitalization or surrounding spaces
    Then one lowercase tag label is saved for that tag

## Assumptions
- Tags are displayed in lowercase.
- Surrounding spaces are not part of a tag name.
