Scenario ID: SCN-009
Title: Correct an invalid web address without losing the save flow
Type: Error Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When the user tries to find details for text that is not a usable web address, the save screen remains open, the entered text is preserved, and a gentle inline message directly under the field explains that a complete web address is needed and gives a recognizable example. The user can correct the address and continue without starting over.

## Gherkin
Feature: Validate a bookmark address

  Scenario: Reject an unusable address in place
    Given the user is on the save-link screen
    And has entered text that is not a usable web address
    When the user asks the app to find page details
    Then the save screen remains open
    And the entered text is preserved
    And an inline message explains how to enter a complete web address
    And no attempt is made to create a bookmark yet

## Assumptions
- A usable saved-page address begins with or can be completed to an HTTP or HTTPS web address.
