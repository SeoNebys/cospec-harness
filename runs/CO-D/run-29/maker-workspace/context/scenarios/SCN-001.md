Scenario ID: SCN-001
Title: Save a new bookmark with automatically filled page details
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When the client pastes a new web address and saves it, the app creates one bookmark, obtains the useful page details, and immediately opens those details for review. The result prominently shows the page preview, site name and icon, title, description, and address. The title and description can be corrected immediately and the corrections saved.

## Gherkin
Feature: Save bookmarks

  Scenario: Save a new address whose page details are available
    Given the collection does not contain the web address
    And the page provides a title, description, site identity, icon, and preview image
    When the client pastes the web address and saves the bookmark
    Then one bookmark is created for that address
    And the bookmark's filled-in details are opened immediately
    And the page preview, site name, site icon, title, description, and address are shown
    And the title and description are editable

  Scenario: Correct filled-in details immediately after saving
    Given a newly saved bookmark is open with its filled-in details
    When the client changes the title or description and saves the changes
    Then the corrected details are retained for the bookmark

## Assumptions
- The submitted address is valid and reachable.
- The page exposes all of the metadata represented in this happy path.
- The collection did not already contain the submitted address.
- The title and description are the page-derived fields the client can correct in this flow.
