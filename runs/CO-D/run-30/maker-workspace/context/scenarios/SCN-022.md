Scenario ID: SCN-022
Title: Recognize the same page despite section jumps or common tracking additions
Type: Edge Case
Approval status: approved
Approval session: SESSION-022
Approval cycle: 1

## Approved behaviour

When an address points to an already-saved page but differs only by a jump to a section or common marketing tracking information, the app treats it as the existing bookmark and opens that bookmark for editing instead of creating a duplicate. Address information that meaningfully changes the page content, search, results page, or view remains distinct and can be saved as a separate bookmark.

## Gherkin

Feature: Preventing duplicate bookmarks

  Scenario: Save an existing page with non-content address noise
    Given a bookmark has already been saved for a page
    When the user saves an address for that page with only a section jump or common marketing tracking information added
    Then no additional bookmark is created
    And the existing bookmark's editor opens

  Scenario: Save an address whose options meaningfully change the content
    Given a bookmark has already been saved for a page
    When the user saves an address whose search, results page, or view is meaningfully different
    Then the address is treated as a distinct bookmark

## Assumptions

- Common marketing tracking information and section jumps do not define distinct saved content.
- Address parameters that affect the content are preserved when deciding whether a bookmark is a duplicate.
