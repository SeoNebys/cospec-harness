Scenario ID: SCN-005
Title: Search across all bookmark text without case sensitivity
Type: Happy Path
Approval status: approved
Approval session: SESSION-005
Approval cycle: 1

## Approved behaviour
The client can type one broad search term and see every bookmark where that term appears in the title, description, personal notes, or saved web address. Matching ignores capitalization. Personal notes participate even though they are not shown on compact library cards. Clearing the search restores the full library.

## Gherkin
Feature: Find bookmarks with broad text search

  Scenario Outline: Match a term in any searchable bookmark field
    Given the library contains a bookmark with "Rome" in its <field>
    When the client searches for "ROME"
    Then that bookmark is included in the results

    Examples:
      | field         |

      | personal note |
      | web address   |

  Scenario: Search ignores capitalization
    Given searchable bookmark text contains "Rome"
    When the client searches for "ROME"
    Then the bookmark is included in the results

  Scenario: Clear a broad search
    Given a broad search is limiting the visible bookmarks
    When the client clears the search
    Then every bookmark in the library is visible again

## Assumptions
- Broad search covers title, description, personal notes, and the saved web address.
- Compact library cards need not expose personal notes for those notes to be searchable.
- Results update from one simple text field.
