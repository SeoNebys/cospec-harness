Scenario ID: SCN-002
Title: Find bookmarks with live text search
Type: Happy Path
Approval status: approved
Approval session: SESSION-002
Approval cycle: 1

## Approved behaviour

The client can type a word into the search box and see the personal collection narrow immediately to matching bookmarks. Search considers the bookmark title, source site, and automatically captured description. Matching words are highlighted in the results so it is clear why each bookmark matched, and the number of results is shown.

## Gherkin

Feature: Search saved bookmarks

  Scenario: Narrow the collection with a matching search word
    Given the personal collection contains bookmarks with different titles, source sites, and descriptions
    When the user types a word that occurs in one bookmark into the search box
    Then the collection immediately shows only that matching bookmark
    And matching words in the result are highlighted
    And the number of matching results is shown

  Scenario Outline: Match searchable bookmark details
    Given a bookmark has a search word in its <field>
    When the user types that word into the search box
    Then that bookmark is included in the search results

    Examples:
      | field       |
      | title       |
      | source site |
      | description |

## Assumptions

- Results update as the client types, without a separate submit action.
- Search is case-insensitive.
- The current scope is title, source site, and description; tags and personal notes are handled in their own scenarios.
