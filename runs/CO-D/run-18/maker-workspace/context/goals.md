# Cycle 1 goal

## Client's words

> Honestly, right now my bookmarks are a mess — they're just a long flat list in my browser and I can never find anything. So the big thing is that when this is done, I'd want saving a link to actually be useful. When I paste a link in, I'd love it to just grab the page's title and a little description on its own, so I'm not typing all that out myself.
>
> And then I want to actually *find* things later — search that looks at what I saved, and a way to organize with labels or tags so I can pull up, say, all my recipes or all my work articles in one click.
>
> A few other things that'd make my life better: being able to mark something as "read this later" and see just those, jot a note to myself on a link, and clean up old stuff without losing it forever — like tucking it away rather than deleting it outright.
>
> Yes, that captures it well. And no — this is just for me. It's my own personal library, so I'm not thinking about sharing or working on it with other people at all. Just me, saving and finding my own links.
>
> The one thing I'd add so we're on the same page: when I say "find a link easily," I mean search should be pretty capable — searching what I saved regardless of capitalization, and being able to narrow down by tags too. But keep it to just me.

## Confirmed goal

Turn a long, flat browser bookmark list into a personal library where saving a link is useful and finding it later is easy. Pasting a link should grab the page's title and a little description automatically. Saved links should be findable regardless of capitalization and narrowable by tags. The library should also support “read this later,” personal notes, and tucking old links away without deleting them outright. It is only for the client; sharing and collaboration are outside the goal.

## Interface form

> A web app, please — something I open in my browser. That's where I run into most of my links anyway, so being able to just pull it up on my computer is what I picture.
