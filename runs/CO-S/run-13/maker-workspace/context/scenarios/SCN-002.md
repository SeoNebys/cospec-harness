Scenario ID: SCN-002
Title: Reuse existing tags via a suggestion dropdown while typing
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

While the client types in the Tags field, a dropdown appears directly below the
field listing the client's existing tags that match what has been typed. Matching
is against any part of the tag (typing "re" surfaces both "reading" and
"reference"). Clicking a suggested tag adds it to the field (followed by a comma
so the next tag can be typed). Suggestions only ever offer tags the client
already has, so tagging stays consistent. The client can still type a brand-new
tag normally by continuing to type and adding a comma.

Chosen over an inline keyboard-accept autocomplete (Version B) because seeing all
matching tags and clicking the intended one is clearer and more discoverable.

## Gherkin
Feature: Reusing existing tags

  Scenario: Suggest matching existing tags while typing
    Given I have previously saved bookmarks with tags
    And I am typing in the Tags field
    When the text I have typed matches part of one or more existing tags
    Then a dropdown lists those matching existing tags below the field

  Scenario: Add a suggested tag by clicking it
    Given the suggestion dropdown is showing matching existing tags
    When I click one of the suggested tags
    Then that tag is added to the Tags field
    And I can continue to add another tag

  Scenario: Create a brand-new tag
    Given I am typing a tag that matches no existing tag
    When I finish it with a comma
    Then it is accepted as a new tag

## Assumptions
- Suggestions are drawn from the set of tags across all saved bookmarks.
- Matching is case-insensitive and matches any part of the tag.
- Existing already-entered tags are excluded from suggestions.
