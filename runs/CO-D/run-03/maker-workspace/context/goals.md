# Business goal statement

- Cycle: 1
- Session: SESSION-001
- Status: confirmed by client
- Date: 2026-09-16

## Goal (in the client's language)

> I want one readable place where I can quickly save a link, have its basic
> details filled in for me, add tags or a note, and later find it through search.
> I'd also like to separate things I still need to read from things I've finished,
> and archive links I want to keep without cluttering the main list. If I save the
> same link twice, I'd expect to be taken to the existing bookmark rather than
> create a duplicate.
>
> The core success for me is: I can save something with little effort and reliably
> retrieve it later. Features for sharing with other people aren't needed.

## Confirmed understanding (played back and approved)

A single, readable, personal place where the client can:
- Save a link with very little effort, with its basic details filled in automatically.
- Add their own tags or a note so they remember why the link mattered.
- Reliably find a saved link again later through search.
- Keep "still to read" separate from "finished".
- Archive links worth keeping without cluttering the main list.
- Be taken to the existing bookmark instead of creating a duplicate when saving
  the same link twice.

## Core measure of success

Saving takes little effort, and retrieval is reliable.

## Explicitly out of scope

Sharing bookmarks with other people. (Single-user only.)

## Interface form

Web app opened in a browser, used mainly on a computer. Must remain usable on a
phone (responsive), but no separate mobile app is needed.
