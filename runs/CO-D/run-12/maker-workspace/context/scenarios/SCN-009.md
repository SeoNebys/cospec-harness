Scenario ID: SCN-009
Title: Save manually when page details are unavailable
Type: Error Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
If the app cannot obtain details from a valid web address, it clearly explains the problem without blocking the user. The user can supply a required title and, optionally, a description, then save the bookmark with those details.

## Gherkin
Feature: Saving bookmarks

  Scenario: Page details cannot be obtained
    Given the user entered a valid web address
    When the app cannot obtain that page's details
    Then the app explains that the details could not be obtained
    And the app offers fields for a title and an optional description
    And the bookmark can be saved after the user supplies a title

## Assumptions
- A title is the only manually entered page detail required for saving.
- A manually entered description is optional.
- Failure to obtain page details does not prevent the address from being saved.
