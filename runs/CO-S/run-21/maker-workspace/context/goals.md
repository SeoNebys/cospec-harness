# Cycle 1 goal

## Client statement

> Honestly, the big thing is that saving a link should be quick and the app should do the busywork for me. Right now when I bookmark something it's just a title and a messy URL — later I have no idea what it was or why I saved it. So when I paste in a link, I'd love the app to go grab the page's title, a short description, maybe the little site icon and a preview image automatically, so my list actually reads like something useful instead of a wall of blue links.
>
> After that, it's really about finding things again. I want to put my own tags on links and click a tag to see just those, and I want a proper search that looks inside titles, descriptions, my own notes, and the URLs — not just the title. If I save the same page twice, I don't want a duplicate; it should just take me back to the one I already have so I can tweak it.
>
> A few other things that matter to me: a "read later" pile I can look at on its own and clear as I get to things, being able to jot a note on a link, and a way to tidy up — set some things aside without deleting them for good, versus actually deleting when I mean it. And when I've got a bunch of links, being able to select several at once and tag or clean them up in one go.
>
> That's the heart of it. Show me saving a link and having it come back looking useful, and I'll know we're on the right track.

## Confirmed direction

> Yes, that's the right direction — you've captured it well.
>
> Two small things I'd add so we're on the same page: with tags, when I'm typing one I'd like it to suggest tags I've already used, so I don't end up with slightly different versions of the same tag. And with search, I want to be able to sort the results too — by when I added them, or by title — so a long list stays manageable.
>
> Otherwise that's exactly the heart of it. Show me a link turning into a useful bookmark and I'll feel good about where this is headed.

## Confirmed interface

> A web app, please — something I open in my browser. That's where I'm usually reading and finding links anyway, so being able to paste one in and come back to my list from any browser is what I'd want.
