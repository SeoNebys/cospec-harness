Scenario ID: SCN-011
Title: Reject text that is not a usable web address
Type: Error Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Text that is not a usable web address is not saved. The address field retains focus and shows a gentle inline explanation with an example of a complete web address, helping the client correct the entry without creating a broken bookmark.

## Gherkin
Feature: Require a usable bookmark address

  Scenario: Attempt to save non-address text
    Given the client has entered text that is not an HTTP or HTTPS web address
    When the client chooses Save bookmark
    Then no bookmark is created
    And focus remains in the address field
    And a plain inline message gives an example of a complete web address

## Assumptions
- Empty input is handled by the same required-address validation.
