Scenario ID: SCN-007
Title: Prevent duplicate tags on a bookmark
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Adding a tag already present on a bookmark does not create another label. Tag names are compared without regard to capitalization, and the app explains that the tag already exists.

## Gherkin
Feature: Organizing bookmarks

  Scenario: Attempt to add an existing tag with different capitalization
    Given a bookmark has the tag "javascript"
    When the user tries to add the tag "JavaScript"
    Then the bookmark still has only one "javascript" tag
    And the app explains that the tag already exists

## Assumptions
- Tag uniqueness is case-insensitive within a bookmark.
