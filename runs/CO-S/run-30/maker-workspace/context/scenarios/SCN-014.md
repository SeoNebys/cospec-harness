Scenario ID: SCN-014
Title: Avoid duplicating a bookmark already in the archive
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When the client tries to save a web address belonging to an archived bookmark, no copy is created. An inline notice explains that the link is in the archive and offers Keep archived or Restore bookmark. Restoring returns and refreshes the same existing bookmark.

## Gherkin
Feature: Duplicate detection across the archive

  Scenario: Save a web address already stored in the archive
    Given a bookmark for the web address exists in the Archive view
    When the client tries to save that web address again
    Then no new bookmark is created
    And an inline notice says the bookmark is in the archive
    And the client can keep the existing bookmark archived
    And the client can restore and refresh that same bookmark

## Assumptions
- Duplicate detection covers both the main library and the archive.
- Restoring an archived duplicate refreshes its page details.
