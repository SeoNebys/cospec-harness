## Approved behaviour

From a saved bookmark the user can choose Edit. The bookmark's link, title,
description, tags and note are loaded back into the form for editing. Saving the
change updates that same bookmark in place (an Update action) without creating a
duplicate, preserving its reading status and archived state.

## Gherkin

Feature: Edit a saved bookmark

  Scenario: Edit an existing bookmark
    Given a saved bookmark
    When the user chooses Edit
    Then its link, title, description, tags and note are loaded into the form
    And the Save action is presented as Update
    When the user changes some details and presses Update
    Then the same bookmark is updated in place with no duplicate created

## Assumptions
- Editing reuses the same form as saving.
- The bookmark's reading status and archived state are unaffected by editing.
