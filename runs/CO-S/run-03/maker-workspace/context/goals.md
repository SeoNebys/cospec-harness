# Cycle 1 goal

## Client request

> I want to build an app to save and manage bookmarks.

## Confirmed goal

> Honestly, right now my bookmarks are a mess. I save links in my browser and they just pile up in one long list — no real way to find anything later. A few things I really want to fix:
>
> - When I save a link, I want it to grab the page's title and a bit of info automatically, so I'm not staring at a wall of raw web addresses.
> - I want to organize things with tags and actually search through them — by title, notes, whatever — and find things fast.
> - I've got a "I'll read this later" pile that I never get back to, so I'd like a way to mark things unread and see just those.
> - And I'd like to tidy up without losing things — set old stuff aside rather than deleting it, but still delete for good when I want to.
>
> Basically, saving is easy today; it's *finding and managing* what I saved that drives me nuts. That's the main thing I want this app to solve.

## Direction confirmed by client

> Yes, that's exactly the right direction. You've captured the heart of it — finding and managing links, automatic page details, tags and search, a separate unread pile, and archiving that doesn't lose things while still allowing real deletion. That's what I'm after.

## Confirmed interface

> A web app would be ideal — something I open in my browser and use from my computer. It's just for me, so I don't need it to be anything fancy across devices. As long as I can get to it in a browser, that works for me.
