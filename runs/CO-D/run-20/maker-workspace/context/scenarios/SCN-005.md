Scenario ID: SCN-005
Title: Reading-list status ("To read") on any bookmark
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

"To read" is a status flag that can be set on any bookmark, not a mutually
exclusive type. A flagged bookmark shows a "To read" badge and appears in the
"To read" view. A "Mark as read" action clears the flag: the bookmark leaves the
"To read" view but remains in the collection.

A view switcher offers All / To read / Reference (and Archived, SCN-006). "All"
shows every non-archived bookmark. "To read" shows non-archived flagged
bookmarks. "Reference" shows non-archived bookmarks not currently flagged
to-read. Search operates within the currently selected view.

New saves default to ordinary (not to-read). The save review panel offers a
"Mark to read" toggle (off by default). Editing a bookmark can also toggle its
to-read flag.

## Gherkin
Feature: Reading-list status

  Scenario: Flag a bookmark to read and view the reading list
    Given a bookmark that is not flagged to-read
    When the user clicks "Mark to read"
    Then the bookmark shows a "To read" badge and appears in the "To read" view

  Scenario: Mark a flagged bookmark as read
    Given a bookmark flagged to-read
    When the user clicks "Mark as read"
    Then the flag is cleared and it leaves the "To read" view but stays in "All"

  Scenario: Reference view is everything not flagged to-read
    Given a mix of flagged and unflagged non-archived bookmarks
    When the user selects the "Reference" view
    Then only bookmarks not currently flagged to-read are shown

  Scenario: New save defaults to ordinary with an opt-in to-read toggle
    When the user saves a link and leaves the "Mark to read" toggle off
    Then the new bookmark is not flagged to-read
    And enabling the toggle before adding flags it to-read

## Assumptions
- "Reference" is a derived view (not-to-read), not a stored second type.
- Search runs within the currently selected view.
