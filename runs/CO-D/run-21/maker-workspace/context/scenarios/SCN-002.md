Scenario ID: SCN-002
Title: Tag suggestions and case-insensitive tag reuse
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
While entering tags, the app suggests tags the user already uses as clickable
chips that narrow as the user types the current tag. Selecting or typing a tag
that matches an existing one (ignoring capitalization) reuses the existing tag
exactly, so the collection never gains a differently-capitalized duplicate of the
same tag. Duplicate tags within one bookmark are collapsed.

## Gherkin
Feature: Consistent tagging

  Scenario: Suggest existing tags while typing
    Given the user already uses the tag "javascript"
    When the user types "ja" in the tags field
    Then "javascript" is offered as a clickable suggestion
    And clicking it adds the tag without retyping

  Scenario: Reuse an existing tag regardless of capitalization
    Given the user already uses the tag "javascript"
    When the user enters "Javascript" as a tag
    Then the saved tag is the existing "javascript"
    And no second, differently-capitalized tag is created

## Assumptions
- Tag matching for reuse is case-insensitive on the whole tag.
