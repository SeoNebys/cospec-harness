## Approved behaviour
The personal note (SCN-007) can take light shape: the note editor in the edit
pop-up offers exactly two controls — bold, and a bulleted list — and the card
renders the note with that shape (a line, a couple of bullets, a bolded word).
Deliberately capped there: no headings, colours, fonts, italics, or links —
because a note to self should stay a ten-second scribble, not tempt the client
into formatting an essay. Formatting applies ONLY to the client's own note; the
page's own description stays plain, so it remains trustworthy as what the page
actually said.
