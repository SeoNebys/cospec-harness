Scenario ID: SCN-008
Title: Click a tag to filter; note excerpt explains note-only matches
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Clicking a tag shown on a bookmark filters the list by that exact tag; the
search box is populated with the corresponding `#tag` query so the filter is
visible and adjustable. When a bookmark matches because of text in its (normally
hidden) note, the list shows a short note excerpt around the match with the
matching text highlighted, so the client understands why it appeared.

## Gherkin
Feature: Tag filtering and match explanation

  Scenario: Click a tag to filter
    Given a bookmark displaying a tag
    When the client clicks that tag
    Then the search box is populated with the exact "#tag" query
    And the list filters to bookmarks with that exact tag

  Scenario: Note excerpt for note-only matches
    Given a search term that appears in a bookmark's note
    When the bookmark appears in the results
    Then a short excerpt of the note around the match is shown with the match
         highlighted

## Assumptions
- The note is otherwise not shown in the list; it is surfaced only as a
  match-explaining excerpt during search.
