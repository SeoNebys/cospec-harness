Scenario ID: SCN-006
Title: Find bookmarks by their saved details
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Typing in the search box immediately narrows the bookmark list to matching
items. Search considers the bookmark title, personal note, automatic summary,
website details, and tags, allowing a bookmark to be found even when the search
word appears only in its personal note.

## Gherkin
Feature: Searching bookmarks

  Scenario: Find a bookmark from a word in its personal note
    Given the library contains several bookmarks
    And one bookmark has a personal note containing a distinctive word
    When the person enters that word in the search box
    Then the bookmark list narrows to the matching bookmark
    And the result count reflects the narrowed list

  Scenario Outline: Find a bookmark from another saved detail
    Given a bookmark has a distinctive word in its <detail>
    When the person enters that word in the search box
    Then that bookmark is included in the search results

    Examples:
      | detail            |
      | title             |
      | automatic summary |
      | website details   |
      | tags              |

## Assumptions
- Results narrow as the person types.
- Search is available above the bookmark list.
- Search includes active, non-archived bookmarks in this flow.
