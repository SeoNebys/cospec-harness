Scenario ID: SCN-004
Title: Delete one or several bookmarks with confirmation
Type: Happy Path
Approval status: approved
Approval session: SESSION-004
Approval cycle: 1

## Approved behaviour
Each bookmark card has its own delete control. Choosing it opens a confirmation that identifies the bookmark before permanent removal. Confirming removes the card, lowers the bookmark count, and shows a clear “Bookmark deleted” confirmation. For cleanup, the user can instead select several bookmark cards, choose to delete the selected bookmarks, confirm the number being removed, and remove them together with an updated count and confirmation.

## Gherkin
Feature: Deleting saved bookmarks

  Scenario: Delete one bookmark from its card
    Given the personal collection contains six bookmarks including “Weeknight recipes”
    When the user chooses the delete control on the “Weeknight recipes” card
    Then a confirmation asks whether to delete that bookmark
    And the confirmation identifies “Weeknight recipes”

  Scenario: Confirm deletion of one bookmark
    Given the user is being asked to confirm deletion of “Weeknight recipes”
    When the user confirms the deletion
    Then the “Weeknight recipes” card is removed from the list
    And the bookmark count changes from 6 to 5
    And a “Bookmark deleted” confirmation is shown

  Scenario: Select several bookmarks for deletion
    Given the personal collection contains “Weeknight recipes” and “Lisbon travel notes”
    When the user selects both bookmark cards
    And chooses to delete the selected bookmarks
    Then a confirmation asks whether to delete 2 bookmarks

  Scenario: Confirm deletion of several bookmarks
    Given the user is being asked to confirm deletion of 2 selected bookmarks
    When the user confirms the deletion
    Then both selected bookmark cards are removed from the list
    And the bookmark count is reduced by 2
    And a “2 bookmarks deleted” confirmation is shown

## Assumptions
- Individual deletion is the primary deletion interaction.
- Multi-select deletion is also included for occasional cleanup.
- Deletion is permanent and has no undo in this cycle.
- Both individual and multi-select deletion require confirmation.
- Deleting a bookmark removes it from the personal collection, not merely from a named collection.
