Scenario ID: SCN-018
Title: Notes support simple Markdown, rendered safely
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

A bookmark's note supports simple Markdown: bold, italic, inline code, bullet
lists, small headings, and links. While writing the note, a live preview shows
how the formatting will look. On a saved bookmark the note is displayed
formatted (links clickable), not as raw symbols. Any content that looks like raw
HTML is displayed as harmless plain text and is never executed — notes can never
run anything.

## Gherkin

Feature: Formatted notes

  Scenario: Live preview while writing
    Given the user is writing a note with Markdown
    Then a live preview renders the bold, italic, code, lists and links as typed

  Scenario: Formatted display on a saved bookmark
    Given a saved bookmark whose note uses Markdown
    Then the note is shown formatted with clickable links, not raw symbols

  Scenario: Raw HTML is never executed
    Given a note containing text that looks like HTML or a script
    Then it is displayed as plain text and nothing is executed

## Assumptions
- Supported Markdown: bold, italic, inline code, bullet lists, small headings, links.
- Note rendering is sanitised so notes can never run active content.
