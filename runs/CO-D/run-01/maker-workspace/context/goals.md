# Cycle 1 goal

> Honestly, right now my bookmarks are a mess. I save links in my browser and then I never find them again — they're just a giant unsorted pile, and half the time I've forgotten what a link even was because it's just a title I don't remember.
>
> So what I really want is a place where I can save a link and it actually helps me. When I paste in a web address, I'd love for it to go grab the details on its own — the page's title, a little description, maybe the site's icon or a picture — so I'm not stuck staring at a bare URL later trying to remember what it was.
>
> Then I want to actually be able to organize and find things. Being able to put labels on links so I can group them, and a real search that digs through everything I've saved, matters a lot to me. And a "read this later" pile that I can look at on its own, separate from everything else, would be great.
>
> That's the heart of it: save a link easily, have it remember what the link actually is, and be able to find it again later without the mess I have now.
>
> The one thing I'd add so we're on the same page: when I save a link, I don't just want it filed away, I want to actually be able to *do* things with each one afterward. Fix up the title or description if the auto-grabbed version isn't quite right, jot down my own notes on it, and get back to the original page easily when I click it. And down the line I know I'll want to tidy up — get rid of ones I don't need, and tuck away old ones I want to keep but not see all the time.
>
> But the core of what you described — paste a link, have it become something recognizable on its own, then find it again through labels, search, and a read-later pile — yes, that's exactly the heart of it.
>
> A web app would suit me best — something I open in my browser and it's just there. That way I can get to my bookmarks from whatever computer I'm on without installing anything.
>
> It's really just for me, my own personal collection, so I'm not worried about other people having accounts or logging in. Just my own bookmark home that I can pull up in a browser window.
