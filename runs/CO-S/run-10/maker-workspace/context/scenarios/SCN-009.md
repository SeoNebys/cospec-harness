Scenario ID: SCN-009
Title: Edit a bookmark's title and description (all details in one editor)
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

The inline editor for a link contains, together and saved with a single Save:
Title, Description, Tags, and Note. When the editor opens, the Title field is
focused and selected for quick overwriting. The client can correct an
auto-filled or poor title and write their own description; the card updates to
the client's wording, and that wording is searchable (SCN-002). If the Title
field is left empty on save, the link's web address is used as its name so a
bookmark is never nameless. In-progress text in Title/Description/Note is
preserved while adding or removing tags in the same editing session.

## Gherkin
Feature: Edit a bookmark's details

  Scenario: Correct the title and add a description
    Given a saved link with a poor auto-filled title and no description
    When the client edits its Title and Description and saves
    Then the card shows the client's title and description
    And searching for a word from them finds the link

  Scenario: Blank title falls back to the web address
    Given the client is editing a link
    When the client clears the Title field and saves
    Then the link's web address is used as its displayed name

  Scenario: Editing tags does not lose unsaved title/description/note text
    Given the client has typed a new title, description, and note but not saved
    When the client adds or removes a tag
    Then the typed title, description, and note text are still present

## Assumptions
- Title, description, tags, and note are edited in one inline editor, one Save.
- Title falls back to the web address when left blank.
