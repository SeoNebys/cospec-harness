Scenario ID: SCN-011
Title: Skim bookmark cards and open originals without losing library position
Type: Happy Path
Approval status: approved
Approval session: SESSION-011
Approval cycle: 1

## Approved behaviour
The main library presents each bookmark as a skimmable card containing its title, description, and tags. Selecting the title opens the original page in a separate browser tab. The library remains open and undisturbed in its existing tab, preserving the client's position so they can return and continue down the list.

## Gherkin
Feature: Browse the bookmark library

  Scenario: Skim useful details without opening a bookmark
    Given the library contains saved bookmarks
    When the client views the library list
    Then every bookmark card shows its title, description, and tags

  Scenario: Open an original page without disturbing the library
    Given the client is partway through the library list
    When the client selects a bookmark title
    Then the original page opens in a separate browser tab
    And the library remains open at the same position in its existing tab

## Assumptions
- The title is the primary link to the original page.
- Original pages open in a separate browser tab.
- The existing library tab is not navigated or reloaded by opening an original.
