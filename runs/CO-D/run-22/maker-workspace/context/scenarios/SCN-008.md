Scenario ID: SCN-008
Title: Search without regard to capitalization
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Search produces the same matching bookmarks and highlighted passage regardless of how the person capitalizes the query.

## Gherkin
Feature: Searching saved bookmarks

  Scenario: Match a query regardless of capitalization
    Given a saved bookmark's searchable text contains "flexbox"
    When the person searches for "Flexbox"
    Then the same bookmark appears as when searching for "flexbox"
    And the same highlighted matching passage is shown

## Assumptions
- Capitalization is ignored across every searchable bookmark field.
