Scenario ID: SCN-006
Title: Remove a saved link, with a confirmation safety net
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Each saved card has a quiet "Remove" action. Activating it asks the user to confirm
("are you sure?") before anything is deleted. On confirmation the link disappears
from the list; if cancelled, nothing changes. The client explicitly wanted the
confirmation step as a safety net against accidentally wiping a link.

## Gherkin
Feature: Removing a link

  Scenario: Remove after confirming
    Given a saved link
    When the user clicks "Remove" and confirms
    Then the link is deleted and no longer appears anywhere

  Scenario: Cancel removal
    Given a saved link
    When the user clicks "Remove" and cancels the confirmation
    Then the link remains unchanged

## Assumptions
- A confirmation prompt always precedes deletion (client explicitly requested this;
  do NOT switch to immediate delete).
