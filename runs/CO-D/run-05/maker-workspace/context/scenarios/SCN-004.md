Scenario ID: SCN-004
Title: View bookmarks by reading status and move between To read and Done
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

Saved bookmarks are organised under three views — To read, Done, Archived — each
showing a count. A newly saved bookmark starts in "To read". From a bookmark the
user can mark it Done (it moves to the Done view) or move it back to To read. The
counts update accordingly. Each non-archived view lists only the bookmarks with
that reading status.

## Gherkin

Feature: Reading status

  Scenario: A new bookmark starts in To read
    Given the user saves a new link
    Then the bookmark appears in the "To read" view
    And the "To read" count increases

  Scenario: Mark a bookmark as done
    Given a bookmark in the "To read" view
    When the user marks it done
    Then it moves to the "Done" view
    And it no longer appears in "To read"

  Scenario: Move a done bookmark back to To read
    Given a bookmark in the "Done" view
    When the user moves it to "To read"
    Then it appears in the "To read" view again

## Assumptions
- New saves default to "To read".
- The three views are To read, Done, Archived; each shows a count.
