Scenario ID: SCN-007
Title: Write and preserve a formatted personal note
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The save preview has a visually distinct “My note” area beneath the fetched description. The person can format note text with familiar Bold and List buttons. Saving confirms the note with its formatting, the note's words are included in library search, and the note is displayed on the bookmark's library card with the formatting preserved. The client chose formatting buttons after comparing them with typed formatting symbols.

## Gherkin
Feature: Personal bookmark notes

  Scenario: Add and format a note while saving
    Given a fetched bookmark preview is displayed
    When the user writes a personal note and applies bold and bulleted-list formatting with buttons
    And saves the bookmark
    Then the exact note is stored with its formatting
    And the confirmation displays the formatted note

  Scenario: See the formatted note later
    Given a saved bookmark has a personal note containing bold text and a bulleted list
    When the user views that bookmark in the library
    Then the note is visible on its card
    And the bold text and bulleted list formatting are preserved

  Scenario: Find a bookmark by its note
    Given a bookmark contains a personal note
    When the user searches for text that appears only in that note without matching capitalization
    Then the bookmark appears in the results
    And its visible note explains why it matched

## Assumptions
- Personal notes are visually distinct from page-supplied descriptions.
- The approved formatting interaction uses visible Bold and List controls rather than formatting symbols.
- Bold and bulleted lists are the formatting capabilities approved for this cycle.
