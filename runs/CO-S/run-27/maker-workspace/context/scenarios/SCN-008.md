Scenario ID: SCN-008
Title: Delete a saved bookmark with confirmation
Type: Happy Path
Approval status: approved
Approval session: SESSION-008
Approval cycle: 1

## Approved behaviour
Delete is shown directly on each bookmark card. Choosing it first shows a clear warning and requires explicit confirmation. Nothing is removed before confirmation. Confirming removes the card from the current list and clearly states that the bookmark was deleted.

## Gherkin
Feature: Deleting bookmarks

  Scenario: Delete a bookmark after confirmation
    Given a saved bookmark appears in the list
    When the person chooses Delete directly on its card
    Then the app warns that the bookmark will be deleted
    And the bookmark remains present
    When the person confirms Delete bookmark
    Then the bookmark is removed from the current list
    And the app clearly confirms that the bookmark was deleted

## Assumptions
- Delete is always visible directly on the bookmark card.
- Every deletion requires confirmation.
- Deletion is permanent within the current scope because archiving is deferred.
