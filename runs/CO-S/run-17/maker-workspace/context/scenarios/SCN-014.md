Scenario ID: SCN-014
Title: Preserve saved information when the original website later fails
Type: Edge Case
Approval status: approved
Approval session: SESSION-014
Approval cycle: 1

## Approved behaviour

If an original website later changes or disappears, Keepwell retains the saved title, description, personal note, tags, and stored address without deleting or rewriting anything. Clicking the bookmark still tries the stored address in a new tab, even if the website itself then shows an error. Correcting the stored address is recorded for a later cycle.

## Gherkin

Feature: Preserve bookmarks independently of their source websites

  Scenario: Keep saved information after the original website becomes unavailable
    Given a bookmark has a saved title, description, personal note, tags, and page address
    And the original website later becomes unavailable
    When the bookmark is viewed in Keepwell
    Then all saved bookmark information remains unchanged
    And the bookmark is not deleted

  Scenario: Still attempt an unavailable original address
    Given the original website for a saved bookmark is unavailable
    When the user opens the bookmark card
    Then Keepwell attempts the stored address in a new tab
    And the website may show its own error
    And the saved bookmark remains unchanged

## Assumptions

- Keepwell does not automatically rewrite or delete saved information based on later source-website availability.
- Manual correction of a stored page address is a later-cycle request.
