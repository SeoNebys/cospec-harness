Scenario ID: SCN-018
Title: Correct an unfinished exact-phrase search
Type: Error Case
Approval status: approved
Approval session: SESSION-018
Approval cycle: 1

## Approved behaviour
While an exact-phrase search has an opening quotation mark but no closing one,
the existing collection remains visible. Inline guidance asks the person to add
the closing quotation mark rather than showing zero results or clearing the
screen. The search can be corrected in place.

## Gherkin
Feature: Precise bookmark search

  Scenario: Exact phrase is missing its closing quotation mark
    Given the collection is visible
    When the person types an exact-phrase search without a closing quotation mark
    Then the existing collection remains visible
    And inline guidance asks for the closing quotation mark
    And the person can complete the search in place

## Assumptions
- An unfinished quoted phrase is not applied as a partial search.
- Search errors are shown beside the search box.
