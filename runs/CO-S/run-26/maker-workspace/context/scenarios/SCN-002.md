Scenario ID: SCN-002
Title: Add personal tags and a note to a saved bookmark
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

On a saved bookmark, the client can attach their own tags and a free-form note.

Tags: the client types into a tag field. As they type, tags they have used before
are offered as suggestions they can click to add; they can also type a brand-new
word and add it as a new tag. Added tags appear as small pills, and each pill can
be removed. A tag is not added twice.

Note: the client types free-form text into a note field for the bookmark; the note
is kept with the bookmark.

Chosen interaction (from a 3-variant comparison): suggestion-assisted tag entry
that also allows creating a new tag — the client selected this over "press Enter
to add" and "comma-separated" entry.

## Gherkin

Feature: Personal tags and notes on a bookmark

  Scenario: Add an existing tag from suggestions
    Given a saved bookmark
    And the client has previously used some tags
    When the client types in the tag field
    Then previously used tags matching the input are suggested
    And clicking a suggestion adds it as a removable pill on the bookmark

  Scenario: Create a new tag
    Given a saved bookmark
    When the client types a word that is not an existing tag and confirms it
    Then the word is added as a new removable pill on the bookmark

  Scenario: Prevent duplicate tags
    Given a saved bookmark that already has a given tag
    When the client tries to add the same tag again
    Then the tag is not added a second time

  Scenario: Remove a tag
    Given a saved bookmark that has one or more tag pills
    When the client removes a tag pill
    Then that tag is no longer on the bookmark

  Scenario: Add a note
    Given a saved bookmark
    When the client enters free-form text as a note
    Then the note is kept with the bookmark

## Assumptions

- Tags render as small removable pills. (Confirmed by client.)
- A note is free-form text. (Confirmed by client.)
- Tag suggestions come from tags the client has used before, across their
  bookmarks. (Presented and accepted via Variant 3.)
