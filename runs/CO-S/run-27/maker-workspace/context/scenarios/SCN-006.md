Scenario ID: SCN-006
Title: Open a saved bookmark
Type: Happy Path
Approval status: approved
Approval session: SESSION-006
Approval cycle: 1

## Approved behaviour
The bookmark title is a link to the saved web address. Clicking it opens the actual page in a new browser tab so the bookmark list remains open and the person does not lose their place.

## Gherkin
Feature: Opening bookmarks

  Scenario: Open a saved page from its bookmark
    Given a bookmark appears in the bookmark list
    When the person clicks the bookmark title
    Then the saved web address opens in a new browser tab
    And the bookmark app remains open in its original tab

## Assumptions
- The bookmark title is the link control.
- Saved pages open in a new browser tab.
