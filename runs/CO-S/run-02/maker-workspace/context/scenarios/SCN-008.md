Scenario ID: SCN-008
Title: Explain empty search and focused views
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A search with no matches clearly says that no bookmarks match while keeping the search box available. An empty Read later view explains that nothing has been marked and how to add an item. An empty Archive view explains that no bookmarks have been set aside and that archived bookmarks will appear there.

## Gherkin
Feature: Empty bookmark views

  Scenario: Search has no matches
    Given the collection has bookmarks
    When the user searches for words absent from all searchable titles and tags
    Then no bookmark cards are shown
    And the app explains that no bookmarks match
    And the search box remains available

  Scenario: Reading list is empty
    Given no bookmarks are marked to read later
    When the user opens the Read later view
    Then the app explains that the reading list is empty
    And it explains how to add a bookmark to the reading list

  Scenario: Archive is empty
    Given no bookmarks are archived
    When the user opens the Archive view
    Then the app explains that the archive is empty
    And it explains that set-aside bookmarks will appear there

## Assumptions
- Empty focused views use contextual messages rather than a blank collection area.
