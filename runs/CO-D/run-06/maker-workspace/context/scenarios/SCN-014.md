Scenario ID: SCN-014
Title: Guide the first save from an empty collection
Type: Edge Case
Approval status: approved
Approval session: SESSION-014
Approval cycle: 1

## Approved behaviour
When the collection has no bookmarks, the save form is immediately available with a friendly “Nothing saved yet” message that points toward saving the first link. Search and tag filters are hidden until at least one bookmark exists.

## Gherkin
Feature: Viewing saved bookmarks

  Scenario: Open a collection with no bookmarks
    Given the collection contains no bookmarks
    When the person opens the app
    Then the save form is shown
    And a friendly empty-collection message guides the first save
    And search and tag filters are not shown

## Assumptions
- Search and tag filters become available after the first bookmark exists.
