Scenario ID: SCN-019
Title: Return to the complete personal library without signing in
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Closing and later reopening the browser restores the personal library exactly as it was left, including every bookmark, edited title and description, labels, formatted personal notes, Read later status, and Archive status. The single user enters the library directly without a sign-in screen.

## Gherkin
Feature: Persistent personal library

  Scenario: Reopen the library later
    Given the user has bookmarks with personalized details and organization
    When the user closes the browser
    And later opens the bookmark app again
    Then every bookmark is present
    And edited titles and descriptions are unchanged
    And labels and formatted personal notes are unchanged
    And Read later and Archive statuses are unchanged
    And the user enters the library without signing in

## Assumptions
- The app is for one person on their own computer.
- Library data persists across browser and application restarts.
