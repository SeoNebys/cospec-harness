Scenario ID: SCN-003
Title: Pasting an already-saved link edits it instead of duplicating
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

When the user enters a link that has already been saved, no second copy is
created. Instead a notice indicates the link is already saved, and the existing
bookmark's title, description, tags and note are loaded into the fields for
editing. The Save action becomes an Update action; pressing it updates the
existing bookmark in place, leaving a single entry in the list. Two links count
as the same address when they match after ignoring a trailing slash and a
"www." prefix.

Feature: Save a link

  Scenario: Updating does not create a duplicate
    Given an already-saved link has been loaded for editing
    When the user changes some details and presses Update
    Then the existing bookmark is updated in place
    And no second copy is added to the list

## Assumptions
- Same-address matching ignores a trailing slash and a leading "www." prefix.
