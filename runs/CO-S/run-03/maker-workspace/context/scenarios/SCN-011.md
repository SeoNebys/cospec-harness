Scenario ID: SCN-011
Title: Long titles and links stay tidy
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A very long title is trimmed to two lines; a very long web address is cut off with
an ellipsis. A single oversized link cannot break the card layout. Client confirmed
this looks fine.

## Gherkin
Feature: Layout resilience for long content

  Scenario: Overlong title is clamped
    Given a bookmark with a very long title
    When it is shown in the list
    Then the title is limited (about two lines) without breaking the layout

  Scenario: Overlong address is truncated
    Given a bookmark with a very long web address
    When it is shown in the list
    Then the address is truncated with an ellipsis

## Assumptions
- Exact line counts / widths are presentational and may be tuned in implementation;
  the approved behaviour is "long content never breaks the layout".
