Scenario ID: SCN-015
Title: Replace an existing personal note
Type: Edge Case
Approval status: approved
Approval session: SESSION-015
Approval cycle: 1

## Approved behaviour

The client can choose Edit note from a bookmark's secondary-action menu. The focused note window is prefilled with the existing reminder. Saving revised wording replaces the prior note, and the card shows only the updated text with no leftover copy or duplicate reminder.

## Gherkin

Feature: Revise personal bookmark context

  Scenario: Edit an existing bookmark note
    Given a saved bookmark has a personal note
    When the user chooses Edit note from the bookmark's secondary-action menu
    Then the note window contains the existing note text
    When the user replaces the text and saves the note
    Then the bookmark card displays only the revised note
    And the previous note text is no longer displayed
    And the application confirms that the note was saved

## Assumptions

- A bookmark has one current note rather than a visible note-version history.
- Editing the note does not change other bookmark details.
