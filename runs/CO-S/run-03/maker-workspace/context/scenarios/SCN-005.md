Scenario ID: SCN-005
Title: Edit a saved link's groups after saving
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Each saved card has a quiet "Edit groups" action at the bottom. Activating it opens
an inline editor showing the link's current groups as removable chips plus an input
to add more (reusing existing groups or creating new ones, same as at save time).
Removing a chip detaches that group; typing-and-Enter attaches one. "Done" closes
the editor. Changes are reflected immediately in browsing (e.g. a link moved to a
new group appears under it). Client found editing on the card "easy" and liked the
quiet placement of actions.

## Gherkin
Feature: Editing a link's groups

  Scenario: Remove a group from a saved link
    Given a saved link that belongs to a group
    When the user opens "Edit groups" and removes that group's chip
    Then the link no longer belongs to that group

  Scenario: Add a group to a saved link
    Given a saved link
    When the user opens "Edit groups" and adds a group by typing and pressing Enter
    Then the link now belongs to that group and appears when browsing it

## Assumptions
- Group-editing on the card reuses the same type-and-Enter chip interaction as saving.
- Per-card actions are quiet/low-emphasis rather than always-visible buttons (client
  confirmed this preference).
