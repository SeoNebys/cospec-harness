Scenario ID: SCN-025
Title: Explain an empty reading-status collection
Type: Edge Case
Approval status: approved
Approval session: SESSION-025
Approval cycle: 1

## Approved behaviour
When the Done collection has no bookmarks, its tab remains visible with a zero count. Selecting it shows an explanatory empty state, reassures the person that To read bookmarks are unchanged, and provides a direct View To read action that returns to the intact collection.

## Gherkin
Feature: Display an empty status collection

  Scenario: Open Done before any bookmark is finished
    Given To read contains three bookmarks
    And Done contains zero bookmarks
    When the person selects the "Done 0" tab
    Then the screen says nothing is in Done yet
    And it explains that finished bookmarks will collect there
    And it reassures the person that To read is unchanged
    And it offers a View To read action

  Scenario: Return from empty Done to To read
    Given the empty Done state is visible
    When the person selects View To read
    Then the three To read bookmarks are shown

## Assumptions
- A zero count remains visible rather than hiding an empty status tab.
