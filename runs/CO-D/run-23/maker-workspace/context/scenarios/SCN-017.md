Scenario ID: SCN-017
Title: Export a complete backup and a portable bookmark file
Type: Happy Path
Approval status: approved
Approval session: SESSION-017
Approval cycle: 1

## Approved behaviour
A person can download a single restorable backup of their complete library. The backup includes all bookmarks with titles and descriptions, labels, saved dates, reading and put-away states, preserved page copies, and original PDF files. The app also offers a separate browser-readable bookmark file containing names and addresses with labels represented as folders, and clearly explains that this lighter portable file does not contain preserved copies or richer app state.

## Gherkin
Feature: Export the bookmark library

  Scenario: Download a complete restorable backup
    Given the library contains bookmarks, organizational state, saved page copies, and PDF files
    When the person downloads a full backup
    Then one restorable file is produced
    And it contains bookmark titles and descriptions
    And it contains labels, dates, reading states, and put-away states
    And it contains preserved page copies and original PDF files

  Scenario: Download a portable bookmark file
    Given the library contains bookmarks and labels
    When the person downloads a browser bookmark file
    Then the file contains bookmark names and addresses
    And labels are represented as folders
    And the app explains that preserved copies and richer app state are not included

## Assumptions
- Full backups can be restored into the app.
- The full backup is a single file.
- The portable file uses a browser-readable bookmark format.
