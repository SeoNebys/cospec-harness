# Business goal statement

## Cycle 1 — established 2026-07-14

### The client's words (verbatim)

- "I want to build an app to save and manage bookmarks."
- "mostly it's that I save links all over the place and then can't find them
  again later. Stuff gets lost in my browser bookmarks, and I save things
  meaning to come back and then just... never do. So being able to actually
  find what I saved is the big one."
- "It's just for me."
- "being able to find things again is the heart of it."
- "Option A ... If I can actually find what I saved when I need it, that's
  really all I want. I don't think I need it nagging me about old links."

### Goal

The core value is **reliably finding a saved link again later, when the user
needs it**. Saving should be easy; the real value is in retrieval.

### Scope decisions

- Single user (just the client).
- Findability-first (Option A): the app's job is to make finding a saved link
  easy. It does NOT actively nudge, resurface, or remind about forgotten links.

### Out of scope (for now)

- Proactive resurfacing / reminders / nagging about old links.
- Multi-user / sharing.

### Interface form

- Web app (a website opened in the browser). The client does most saving while
  browsing on their computer. Prototyping method: HTML-based interactive
  prototype.
