Scenario ID: SCN-003
Title: Search bookmarks by title or tag
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The client types in one search box and the bookmark list narrows immediately. A bookmark is included when the entered words match either its title or one of its tags, including when the matching tag word does not occur in the title.

## Gherkin
Feature: Finding bookmarks

  Scenario: Find a bookmark by a word in its title
    Given the collection contains bookmarks with different titles
    When the user types a word from one bookmark's title in the search box
    Then the list narrows as the user types
    And the bookmark with the matching title remains visible
    And bookmarks without a match are hidden

  Scenario: Find a bookmark by its tag
    Given a bookmark has a tag whose name is absent from its title
    When the user types that tag name in the search box
    Then the bookmark with the matching tag remains visible
    And bookmarks without a match are hidden

## Assumptions
- A single search box searches both bookmark titles and tags.
- Matching results update as the user types without a separate submission action.
