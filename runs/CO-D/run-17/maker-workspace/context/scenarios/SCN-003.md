Scenario ID: SCN-003
Title: Prevent duplicate saves by opening the existing entry
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When the client saves a link whose address is already in the library, the app
does not create a second copy. Instead it opens the existing entry for editing
and shows a message that the link is already saved, so the client can edit it
rather than duplicate it.

## Gherkin
Feature: Duplicate prevention on save

  Scenario: Saving an already-saved address opens the existing entry
    Given the library already contains a link with address "https://nytimes.com/"
    When the client enters "nytimes.com" and presses Save
    Then no second copy is created
    And the existing entry opens in edit mode
    And a message states the link is already in the library

## Assumptions
- Duplicate identity is the normalised address; different pages on the same site
  are not duplicates.
