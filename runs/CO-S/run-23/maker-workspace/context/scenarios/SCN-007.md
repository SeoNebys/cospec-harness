Scenario ID: SCN-007
Title: Delete one bookmark with confirmation
Type: Happy Path
Approval status: approved
Approval session: SESSION-007
Approval cycle: 1

## Approved behaviour
The client selected Delete on one bookmark and saw an in-place confirmation asking whether to delete that bookmark, with clear cancel and proceed actions. After confirming, only the selected bookmark was removed and the other three remained unchanged. The client selected this confirmation-first interaction over the alternative deletion safeguard presented.

## Gherkin
Feature: Delete bookmarks

  Scenario: Ask for confirmation before deleting
    Given a bookmark is visible in the collection
    When the user selects Delete on that bookmark
    Then the bookmark remains in the collection
    And the user is asked to confirm or cancel the deletion

  Scenario: Confirm deletion of one bookmark
    Given the user has been asked to confirm deleting a bookmark
    When the user confirms the deletion
    Then only the selected bookmark is removed
    And every other bookmark remains unchanged

## Assumptions
- Deletion is permanent.
- The confirmation appears in place on the selected bookmark card.
- Cancel leaves the collection unchanged.
