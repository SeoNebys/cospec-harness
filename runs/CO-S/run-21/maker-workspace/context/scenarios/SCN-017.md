Scenario ID: SCN-017
Title: Select several bookmarks for a bulk action
Type: Happy Path
Approval status: approved
Approval session: SESSION-017
Approval cycle: 1

## Approved behaviour
Selection checkboxes remain visible on every bookmark card so the person can begin selecting without entering a separate mode. Each selected card is highlighted, an exact selected count is shown, and a bulk-action bar with tag, archive, and delete actions appears only while at least one bookmark is selected. Always-visible checkboxes are preferred over an on-demand selection mode.

## Gherkin
Feature: Select bookmarks for bulk organization

  Scenario: Select several bookmark cards directly
    Given several bookmark cards are visible
    And each card has a visible selection checkbox
    When the person selects the first and third bookmarks
    Then both selected cards are visually highlighted
    And the selection count shows "2 selected"
    And a bulk-action bar becomes visible
    And the bar offers tag, archive, and delete actions

## Assumptions
- Deselecting every bookmark hides the bulk-action bar.
- Selection itself does not change any bookmark data.
