Scenario ID: SCN-007
Title: Duplicate link warning with guided edit, and editing a bookmark anytime
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When the user tries to save a link that is already saved, the app does not create
a second copy. It warns the user that the link is already saved, tells them where
it currently lives (main list, read-later, or archive), and offers to edit the
existing bookmark. Choosing that opens the existing bookmark in the save form
(title, note, tags) with an "editing" indication; saving updates it in place
rather than adding a copy. Separately, every bookmark in the list offers an
"Edit" action so the user can revise its title, note, or tags at any time for any
reason (not only on a duplicate).

## Gherkin
Feature: Duplicate handling and editing

  Scenario: Warn on duplicate and guide to the existing bookmark
    Given a link is already saved
    When the user tries to save the same link again
    Then the app warns that it is already saved and indicates where it lives
    And offers to edit the existing bookmark instead of creating a copy

  Scenario: Update the existing bookmark in place
    Given the duplicate warning is shown
    When the user chooses to edit the existing bookmark and saves changes
    Then the existing bookmark is updated
    And no second copy is created

  Scenario: Edit any bookmark at any time
    Given a saved bookmark
    When the user chooses Edit on it and saves changes
    Then that bookmark's title, note and tags are updated in place

## Assumptions
- Duplicate detection compares links ignoring trailing slashes and case.
- Editing preserves the bookmark's read-later / archived state and identity.
- The Edit action is available on non-archived bookmarks in the list.
