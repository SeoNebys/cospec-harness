Scenario ID: SCN-004
Title: Add and manage tags on a bookmark
Type: Happy Path
Approval status: approved
Approval session: SESSION-004
Approval cycle: 1

## Approved behaviour
When editing a bookmark, the client adds tags one at a time. Pressing Enter turns a new tag into a distinct pill, and its × removes it before saving. As the client types, matching tags used previously are suggested and labeled as such; choosing one adds that existing tag as a pill. The client can still create a genuinely new tag. Saving displays the bookmark's tags as tidy pills on its collection row.

## Gherkin
Feature: Tag bookmarks

  Scenario: Add existing and new tags while editing a bookmark
    Given a saved bookmark is open for editing
    And tags have previously been used in the collection
    When the client begins typing a tag that matches a previously used tag
    Then the matching previously used tag is suggested
    When the client chooses that suggestion
    Then it is added to the bookmark as a tag pill
    When the client types a genuinely new tag and presses Enter
    Then the new tag is added as another tag pill

  Scenario: Remove a tag before saving
    Given a bookmark has tag pills in the editor
    When the client uses the × on one tag pill
    Then that tag is removed from the bookmark being edited

  Scenario: Save bookmark tags
    Given a bookmark has tag pills in the editor
    When the client saves the changes
    Then those tags are retained with the bookmark
    And the saved tags appear as pills on the bookmark's collection row

## Assumptions
- Tag matching for suggestions ignores letter case.
- Choosing a suggestion reuses its established spelling.
- The client may create tags that have not previously been used.
