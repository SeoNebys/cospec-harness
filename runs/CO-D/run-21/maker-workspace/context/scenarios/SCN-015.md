Scenario ID: SCN-015
Title: Bulk actions on selected or all-matching bookmarks
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Each card has a selection checkbox. When one or more are selected, an action bar
shows the true count and offers: add tag, remove tag, mark read, mark unread,
archive (or restore, in the Archived view), and delete. "Select all matching"
selects the entire current result set — respecting search terms, tag filters, read
status, and Active/Archived view — not just the visible page; the action-bar count
always reflects the true number that will be changed. Adding/removing tags uses a
searchable tag picker: adding suggests existing tags (reused case-insensitively)
and allows creating a new tag; removing offers only tags actually present on the
selected bookmarks. Bulk delete asks for a counted confirmation and is permanent
(also removing saved copies), consistent with single delete. "Clear selection"
empties the selection.

## Gherkin
Feature: Bulk actions

  Scenario: Select all matching spans the whole scope
    Given a search and/or filters are active
    When the user chooses "Select all matching"
    Then every bookmark in the current result set is selected across all pages
    And the action-bar count equals that total

  Scenario: Bulk mark read/unread and archive/restore
    Given several bookmarks are selected
    When the user applies a bulk read/unread or archive/restore action
    Then it applies to all selected bookmarks

  Scenario: Bulk add tag with picker
    Given several bookmarks are selected
    When the user adds a tag via the picker
    Then existing tags are suggested and reused case-insensitively
    And a new tag can be created

  Scenario: Bulk remove tag limited to present tags
    Given several bookmarks are selected
    When the user opens the remove-tag picker
    Then only tags present on the selected bookmarks are offered

  Scenario: Bulk delete confirmation
    When the user bulk-deletes
    Then a counted confirmation warns it is permanent
    And on confirm all selected bookmarks (and their saved copies) are removed

## Assumptions
- Selection persists across pages via a selection set.
- Remove-tag choices are the union of tags on the selected bookmarks.
