Scenario ID: SCN-011
Title: Preserve a link when page details cannot be retrieved
Type: Error Case
Approval status: approved
Approval session: SESSION-011
Approval cycle: 1

## Approved behaviour
If the app cannot retrieve a page's title and description, it does not block or lose the save. It immediately saves the bookmark using the web address as its visible identity, clearly explains that page details were unavailable, and allows the person to add or correct the title and description later.

## Gherkin
Feature: Saving when page details are unavailable

  Scenario: Save the address despite failed detail retrieval
    Given the person has entered a valid web address
    And the page's title and description cannot be retrieved
    When the person saves the link
    Then a bookmark is saved immediately
    And its web address is used as its visible identity
    And the app explains that page details were unavailable
    And the bookmark's title and description can be added or corrected later

## Assumptions
- Failure to retrieve page details does not imply that the web address itself is invalid.
- The saved bookmark remains searchable by its web address.
- Later correction does not create a second bookmark.
