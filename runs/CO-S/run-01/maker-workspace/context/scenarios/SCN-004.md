Scenario ID: SCN-004
Title: Tag a link via an in-the-moment prompt right after saving
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Saving stays a single instant paste (SCN-001 unchanged). Immediately after a
link is saved, a small "Add tags for this?" prompt appears ON the just-saved
link, with the cursor ready. As the client types, existing tags are suggested
(autocomplete) so labels stay consistent; the client can also type a brand-new
tag. Pressing Enter or clicking a suggestion adds a tag; multiple tags can be
added. The client can dismiss the prompt at any time via a "skip" control or
Escape, leaving the link untagged. Tagging is therefore optional but actively
encouraged in the moment (rejected: tag-before-save which makes every save
heavier; rejected: tag-only-later-on-the-card which the client knows they would
never come back to do).

## Gherkin
Feature: Tagging a link right after saving

  Scenario: In-the-moment tag prompt after an instant save
    Given the client pastes a link and presses Save
    Then the link is saved immediately
    And a tag prompt appears on the newly saved link with the cursor ready

  Scenario: Adding a tag with autocomplete from existing tags
    Given the tag prompt is active on a newly saved link
    When the client types part of an existing tag name
    Then matching existing tags are suggested
    And selecting a suggestion (or pressing Enter) adds it as a tag
    And the client may add several tags

  Scenario: Adding a brand-new tag
    Given the tag prompt is active
    When the client types a name that is not an existing tag and confirms it
    Then a new tag is created and applied to the link

  Scenario: Skipping tagging
    Given the tag prompt is active on a newly saved link
    When the client clicks skip or presses Escape
    Then the prompt closes and the link remains saved with no tags

## Assumptions
- The prompt targets only the just-saved link and is dismissible.
- Autocomplete matches against the client's existing tags; new tags allowed.
- Leaving a link untagged is permitted.
