Scenario ID: SCN-009
Title: Notes on a bookmark with Markdown formatting, searchable and collapsible
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

A bookmark can carry the user's own free-text note. Notes are written in Markdown
and can be added/edited while saving (review panel) and later via Edit; the user
edits the raw Markdown and sees the formatted result when viewing the bookmark
(no live preview is required — it renders on save).

Supported formatting includes at least headings, lists, links, emphasis (bold/
italic) and inline code. Raw HTML/scripts in a note are not executed; note input
is treated as text and safely escaped before Markdown formatting.

The note is shown in full on the bookmark by default. A very long note (roughly
more than a paragraph or two) is collapsed with a "Show more" control that
reveals the complete note and can collapse it again ("Show less").

Note content is fully searchable together with title, description, address and
tags, and matches are highlighted within the rendered note.

## Gherkin
Feature: Notes

  Scenario: Write Markdown and view it formatted
    Given the user edits a bookmark's note in Markdown (on save or edit)
    When the user saves
    Then the bookmark displays the note formatted (headings, lists, links, emphasis, code)

  Scenario: Notes are searchable and highlighted
    Given a bookmark has a note containing a word
    When the user searches that word
    Then the bookmark matches and the word is highlighted within the rendered note

  Scenario: Long notes collapse and expand
    Given a bookmark has a long note
    Then the note is collapsed with a "Show more" control
    When the user clicks "Show more"
    Then the full note is shown and can be collapsed again

  Scenario: Note content is safe
    Given a note contains raw HTML or a script
    When the note is displayed
    Then the raw markup is shown as text and not executed

## Assumptions
- Markdown renders on save (no live side-by-side preview).
- Collapse threshold is roughly one to two paragraphs.
