Scenario ID: SCN-013
Title: Show a clear zero-match search state
Type: Edge Case
Approval status: approved
Approval session: SESSION-013
Approval cycle: 1

## Approved behaviour
When search text matches no saved bookmark, the results area explicitly says “No matching bookmarks” instead of appearing blank. The count shows zero matches out of the full collection count so it remains clear that saved links still exist.

## Gherkin
Feature: Finding saved bookmarks

  Scenario: Search finds no matching bookmarks
    Given the collection contains saved bookmarks
    When the person enters search text that matches none of them
    Then no bookmark rows are shown
    And the results area says “No matching bookmarks”
    And the count shows zero matches out of the full collection count

## Assumptions
- A zero-match result is visually distinct from a collection containing no bookmarks.
