Scenario ID: SCN-003
Title: Browse bookmarks by tag
Type: Happy Path
Approval status: approved
Approval session: SESSION-003
Approval cycle: 1

## Approved behaviour
The client viewed bookmarks carrying one or more tags and clicked the Design tag on a bookmark. The collection immediately narrowed to only bookmarks carrying Design, and a Show all action restored the full collection. The client confirmed this matched how they expect to browse by topic.

## Gherkin
Feature: Organize bookmarks with tags

  Scenario: Filter the collection by clicking a tag
    Given the collection contains bookmarks with one or more tags
    When the user clicks a tag on a bookmark
    Then the collection shows only bookmarks carrying that tag
    And the active topic is clearly identified
    And the user can return to all bookmarks

## Assumptions
- A bookmark may carry more than one tag.
- Tags are visible on bookmark cards.
- Tag filtering happens immediately after a tag is clicked.
