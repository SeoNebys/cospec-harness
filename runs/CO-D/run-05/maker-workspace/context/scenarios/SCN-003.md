Title: Open a saved link to fix its name and summary
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Each saved link has an "Edit" control. Clicking it opens that link into a small form with
clearly labelled "Title" and "Summary" fields, so the client can correct a bad auto-guess.
The client chose this "open it up and fix it" model (over a quick inline pencil or a
row menu) specifically because it reads as *the* place to fix everything about a link and
has room to grow.

The form offers "Done" (saves the changes) and "Cancel" (discards all changes and returns
the link to exactly how it was). Pressing Escape also discards. The client confirmed this
is the safety net they wanted: "I can poke at a link without fear of messing it up."

Separately, clicking the link's title (the blue link) opens the page in a new tab — this
never triggers editing.

## Gherkin
Feature: Editing a saved link

  Scenario: Fix a wrongly-guessed title
    Given a saved link with a wrong auto-generated title
    When I click Edit, change the Title, and press Done
    Then the link shows the new title

  Scenario: Abandon edits with Cancel
    Given I am editing a saved link and have changed the Title
    When I press Cancel
    Then the link returns to exactly how it was before I started editing

  Scenario: Abandon edits with Escape
    Given I am editing a saved link and have changed a field
    When I press Escape
    Then the change is discarded

  Scenario: Opening the page does not start editing
    Given a saved link
    When I click its title link
    Then the page opens in a new tab and no editing begins

## Assumptions
- The edit form is the future home for more per-link fixes the client named: correcting
  the web address, a personal note about why it was saved, and labels. (pending scenarios)
- "Done" with an emptied field keeps the previous value rather than blanking it.
