Scenario ID: SCN-012
Title: Save when page details cannot be retrieved
Type: Error Case
Approval status: approved
Approval session: SESSION-012
Approval cycle: 1

## Approved behaviour
If the web address is valid but automatic page-detail retrieval fails, the person can still save the bookmark. The app keeps the address, uses the title the person entered or falls back to the site name when the title is blank, shows a plain site icon, and omits the description. Failed detail retrieval does not block saving.

## Gherkin
Feature: Saving bookmarks

  Scenario: Save with a manually entered title after detail retrieval fails
    Given a valid web address has been entered
    And automatic page-detail retrieval has failed
    And the person has entered a title
    When the person saves the bookmark
    Then the bookmark is saved with that address and title
    And a plain site icon is shown
    And no description is shown

  Scenario: Save without a title after detail retrieval fails
    Given a valid web address has been entered
    And automatic page-detail retrieval has failed
    And the title is blank
    When the person saves the bookmark
    Then the bookmark is saved with that address
    And the site name is used as its title
    And a plain site icon is shown
    And no description is shown

## Assumptions
- A page-detail retrieval failure does not imply that the web address is invalid.
- The person does not have to retry retrieval before saving.
