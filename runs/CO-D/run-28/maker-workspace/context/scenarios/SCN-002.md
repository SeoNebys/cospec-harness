Scenario ID: SCN-002
Title: Saved-item display with a separate note, and correcting details anytime
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Each saved bookmark shows a site icon (favicon), a title that opens the original
page in a new tab when selected, the site's description, and — when present — the
client's own note under a distinct "My note" heading. The full address is shown
small and de-emphasised beneath. The site description and the client's note are
separate things: the description is the site's summary, the note is written
independently by the client and displayed with basic formatting (bulleted lists
and links). The client can correct the title and description, and add or change
the note, both before confirming the save and afterward, via the same editor.

## Gherkin
Feature: Saved-item display and correction

  Scenario: See a saved bookmark's details at a glance
    Given a bookmark has been saved
    Then it shows a site icon, the title, the site description, and the client's note when present
    And the note appears under a distinct "My note" heading, separate from the description
    And the full address is shown small and de-emphasised

  Scenario: Open the original page from a bookmark
    Given a saved bookmark is shown
    When the client selects its title
    Then the original page opens in a new tab

  Scenario: Correct a bookmark's details after saving
    Given a saved bookmark is shown
    When the client opens Edit details and changes the title, description, or note
    And confirms the change
    Then the bookmark shows the updated details

  Scenario: Note supports basic formatting
    Given the client is writing a note
    When the client uses "- " lines or [text](url) links
    Then the note is displayed as a bulleted list and clickable links

## Assumptions
- Favicon shown in the prototype is a coloured monogram standing in for the real
  site icon; the finished app shows the actual site icon.
- Note formatting is simple text conventions (lists, links), no toolbar (client
  confirmed a toolbar is not needed).
