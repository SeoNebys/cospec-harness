Scenario ID: SCN-008
Title: Empty and no-result states
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
- First run / nothing saved: the list shows a plain invitation to paste a link and
  save the first bookmark.
- Search with no matches: the list shows a plain "No bookmarks match “…”" message.
  The client confirmed a plain message is enough — no group suggestions needed.
- Browsing an empty group: shows "No bookmarks in “…” yet" (though per SCN-007 an
  emptied group normally disappears; this covers transient/other empties).

## Gherkin
Feature: Empty and no-result displays

  Scenario: First-run empty state
    Given the user has no saved bookmarks
    When the page is shown
    Then a message invites the user to save their first bookmark

  Scenario: No search matches
    Given the user has bookmarks
    When the user searches for a word that matches none
    Then a plain "no matches" message is shown

## Assumptions
- No-result messaging stays plain (no suggestions/recommendations), per client.
