Scenario ID: SCN-016
Title: Recognize harmless address variations as duplicates
Type: Edge Case
Approval status: approved
Approval session: SESSION-016
Approval cycle: 1

## Approved behaviour
A trailing slash or jump-to-section ending does not make another bookmark when the underlying page is already saved. The app keeps one copy and focuses the existing bookmark. Address differences that genuinely select different content remain separate bookmarks.

## Gherkin
Feature: Saving bookmarks

  Scenario: Save an existing page with a harmless address variation
    Given a page is already saved as a bookmark
    When the person saves the same page with only a trailing slash or jump-to-section ending added
    Then no additional bookmark is created
    And the collection count remains unchanged
    And the existing bookmark is brought into focus

  Scenario: Save an address that selects different content
    Given a bookmark is already saved for one address
    When the person saves an address variation that genuinely selects different content
    Then a separate bookmark is created

## Assumptions
- Trailing slashes and jump-to-section endings are ignored for duplicate recognition.
- Other address additions are preserved when they can identify different content.
