Scenario ID: SCN-014
Title: Add a label to several selected bookmarks
Type: Happy Path
Approval status: approved
Approval session: SESSION-014
Approval cycle: 1

## Approved behaviour

While in selection mode, the client can add an existing label to every selected bookmark at once. The added label does not replace labels those bookmarks already carry. After applying the label, the same bookmarks remain selected and the selected count and bulk actions remain available, allowing another action without selecting the items again. Done selecting ends the batch when the client is finished.

## Gherkin

Feature: Managing bookmarks in bulk

  Scenario: Add a shared label while preserving existing labels
    Given two bookmarks are selected
    And the first bookmark has the label "Recipes"
    And the second bookmark has the label "Travel"
    When the user applies the existing label "Work" to the selection
    Then the first bookmark shows "Recipes" and "Work"
    And the second bookmark shows "Travel" and "Work"
    And both bookmarks remain selected
    And the action bar still shows two selected

## Assumptions

- Successful non-destructive bulk actions preserve the active selection so several cleanup actions can be chained.
- Adding a label never removes labels already attached to a bookmark.
