Scenario ID: SCN-004
Title: Add a personal label directly to a bookmark
Type: Happy Path
Approval status: approved
Approval session: SESSION-004
Approval cycle: 1

## Approved behaviour
A person can type a personal label directly on a bookmark and add it in one step. The saved label appears as a small chip beneath that bookmark's details. Opening a separate label control or a full bookmark editor is not required for this quick action.

## Gherkin
Feature: Organize bookmarks with labels

  Scenario: Add a label from the bookmark card
    Given a saved bookmark is visible
    When the person types a label in the bookmark's label field and adds it
    Then the label is attached to that bookmark
    And the label appears as a chip beneath the bookmark details

## Assumptions
- Labels can be created using ordinary text.
- Quick label entry is visible directly on each bookmark.
- A full bookmark editor may separately support changing multiple details.
