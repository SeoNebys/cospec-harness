# Cycle 1 goal

> Turning a pile of scattered, forgettable links into a library I actually trust and can find my way around.

The library is a personal home base, just for me. When I save a link, I want to paste the address and have it sort itself out: pull in the page's title, a short description, the little site icon, and maybe a picture, so I'm not typing all that by hand. If I try to save something I already saved, I don't want a second copy; I want it to take me to the one I already have so I can tweak it.

Finding things again should be easy. I want to search across titles, my own notes, descriptions, and web addresses without worrying about capital letters. I want to search by a tag specifically and combine things, like: "show me anything about Rome that's either an article or a book." While I type tags, I want suggestions from tags I've already used so I don't end up with "recipe," "recipes," and "cooking" all meaning the same thing.

I want a "read this later" pile that I can pull up when I have time and check items off as I get through them. The list itself should be pleasant to skim, showing the title, description, and tags. Clicking an item should take me to the actual page.

I also want to keep the stuff I care about from disappearing on me, so if a page goes away later, I still have what it said saved somewhere.

There is no need for other people to log in or share bookmarks.

## Management additions raised before development

The client wants a clear, deliberate way to permanently delete a bookmark saved by mistake or no longer wanted. This must remain distinct from marking an item as read or removing it from Read later.

The client also wants to open any bookmark already in the library and directly edit its title, tags, or personal notes at any later time, without re-pasting the web address.

## Interface form

A regular website opened in a browser, primarily on a computer. It should remain usable on a phone, but there is no separate phone app and nothing to install. The personal library is available when the client logs in.
