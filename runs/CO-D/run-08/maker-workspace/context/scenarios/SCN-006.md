Scenario ID: SCN-006
Title: Filter the collection by a selected label
Type: Happy Path
Approval status: approved
Approval session: SESSION-006
Approval cycle: 1

## Approved behaviour
Selecting a label on a bookmark or in the collection-level label row shows only bookmarks carrying that label. The visible count updates and the collection states which label is active. Both entry points produce the same result.

## Gherkin
Feature: Find bookmarks by label

  Scenario Outline: Filter bookmarks using a label
    Given the collection contains four bookmarks
    And two bookmarks carry the label "javascript"
    When the person selects "javascript" from the <entry point>
    Then only the two bookmarks labeled "javascript" are shown
    And the visible count says two of four links
    And the collection says it is showing links labeled "javascript"

    Examples:
      | entry point                |
      | chip on a bookmark         |
      | collection-level label row |

## Assumptions
- Labels used in the collection are available from a row above the bookmarks.
- Label filtering shows all statuses unless another filter is also active.
