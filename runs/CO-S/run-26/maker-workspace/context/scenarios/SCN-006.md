Title: New-user / empty state
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

When there are no bookmarks yet (e.g. a brand-new user), the app shows a friendly
empty state rather than a blank page: a bookmark icon, a "No bookmarks yet"
heading, and an inviting line explaining that saved links will appear here ready
to tag, search, and revisit. The save box remains available above it.

## Gherkin

Feature: Empty state

  Scenario: No bookmarks saved yet
    Given the client has no saved bookmarks
    When the client opens the app
    Then a friendly empty state is shown (icon, "No bookmarks yet", inviting text)
    And the save box is available to save the first link

## Assumptions
- The empty state is a welcoming prompt, not an error. (Confirmed by client.)
