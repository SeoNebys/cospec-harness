Scenario ID: SCN-009
Title: Protect bookmarks during editing and deletion
Type: Error Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Canceling a deletion confirmation leaves the bookmark completely unchanged. Attempting to replace a bookmark address with malformed input keeps the edit open, explains that a complete address is required, and leaves the saved bookmark unchanged.

## Gherkin
Feature: Safe bookmark management

  Scenario: Cancel permanent deletion
    Given a bookmark has been saved
    And the deletion confirmation is visible
    When the user cancels deletion
    Then the bookmark remains unchanged

  Scenario: Reject a malformed address during editing
    Given a bookmark has a valid saved address
    And its edit controls are open
    When the user replaces the address with malformed input
    And tries to save the changes
    Then the edit controls remain open
    And the app explains that a complete address is required
    And the saved bookmark remains unchanged

## Assumptions
- Address validation is consistent between initial saving and later editing.
