Scenario ID: SCN-005
Title: Prevent an accidental duplicate bookmark
Type: Edge Case
Approval status: approved
Approval session: SESSION-005
Approval cycle: 1

## Approved behaviour
With a bookmark already in the collection, the client attempted to save the exact same address again. No second bookmark was created, the collection count remained unchanged, and the app clearly explained that the page was already saved while drawing attention to the existing bookmark. The client confirmed this prevents accidental clutter.

## Gherkin
Feature: Save bookmarks

  Scenario: Save an address that is already bookmarked
    Given a bookmark for an exact web address already exists
    When the user saves the same address again
    Then no additional bookmark is created
    And the collection count remains unchanged
    And the user is told that the page is already saved
    And the existing bookmark is brought to the user's attention

## Assumptions
- This approved case covers an exact repeat of the same address.
- The existing bookmark is not silently changed by the repeat-save attempt.
- Variations of the same address are to be explored separately as edge cases.
