Scenario ID: SCN-014
Title: Restore the last archived bookmark
Type: Edge Case
Approval status: approved
Approval session: SESSION-014
Approval cycle: 1

## Approved behaviour

The client can restore an archived bookmark from its card's secondary-action menu. Restoring the final archived bookmark removes the Archive count and displays a clear empty Archive state. The bookmark returns to All bookmarks with its saved details intact, confirming that archiving is reversible rather than a permanent loss.

## Gherkin

Feature: Restore bookmarks that were set aside

  Scenario: Restore the only bookmark from Archive
    Given exactly one bookmark is in Archive
    And the user is viewing the dedicated Archive
    When the user chooses Restore to collection from the bookmark's secondary-action menu
    Then the bookmark leaves Archive
    And the Archive count disappears
    And the Archive view says that it is empty
    And the bookmark returns to All bookmarks with its saved details intact

## Assumptions

- Restoring preserves the bookmark's tags, note, Read later state, and captured page details.
- The restored bookmark returns to the main collection without creating a copy.
