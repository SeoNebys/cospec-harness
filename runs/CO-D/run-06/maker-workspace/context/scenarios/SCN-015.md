Scenario ID: SCN-015
Title: Stays calm at the extremes — a guiding empty first run, and display-only clamping of overstuffed cards
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Absence of data (first run and empty views):
- On the very first run with nothing saved, the app shows a calm welcome (not a blank
  void, not a splashy tutorial) that points at the one action: paste a link in the box
  above; the title/description fill in; "it takes a second." An arrow points to the box.
- Empty sub-views (empty To-read pile, empty Set-aside drawer, no search results) show
  a short calm message rather than emptiness.

Boundary (overstuffed content) — display-only clamping:
- A card with a very long title, description, note, address, or many labels keeps the
  SAME tidy height as any other card, so a few long ones never wreck the scannable list.
- Title clamps to ~2 lines; description and note clamp too; the address truncates with
  "…"; labels cap at 5 with a "+N more".
- CRITICAL (client-insisted): clamping is purely about what's shown on the card. The
  FULL title, description, and note are always stored and shown in full when the
  bookmark is opened/edited — nothing is ever actually cut off or lost.
- "+N more" is not a dead end: clicking it reveals the remaining labels.

## Gherkin
Feature: Calm empty and overflowing states

  Scenario: First run guides the first save
    Given the client has no bookmarks
    Then a calm welcome invites pasting a first link and explains it takes a second

  Scenario: Long content is clamped only in the list
    Given a bookmark with a very long title and note
    Then its card is clamped to the standard height with ellipsis
    When the client opens the bookmark
    Then the full title and full note are shown, untruncated

  Scenario: Overflow labels are reachable
    Given a bookmark with more labels than fit
    Then the card shows the first few and a "+N more"
    When the client clicks "+N more"
    Then the remaining labels are revealed

## Assumptions
- Clamp counts (2 lines, 5 labels) are visual details, adjustable; the principle
  (uniform card height, nothing lost) is what is approved.
- Empty-view copy is calm and minimal by explicit client preference.
