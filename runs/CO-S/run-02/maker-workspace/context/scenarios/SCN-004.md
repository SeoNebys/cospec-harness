Scenario ID: SCN-004
Title: Organize bookmarks with multiple tags and browse by tag
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A bookmark can carry several tags at once, rather than living in a single
folder. The user sees the set of tags they have used, each with a count, and
can click a tag to narrow the list to bookmarks carrying that tag. Because a
bookmark can hold multiple tags, the same bookmark is reachable from any of the
ways the user might think of it later (e.g. a tomato-pruning video filed under
both "cooking" and "gardening" appears when browsing either). Clicking the
active tag again, or clicking "All", returns to the full list. Each bookmark in
the list displays its tags.

## Gherkin
Feature: Organize bookmarks with tags

  Scenario: A bookmark carries multiple tags
    Given the user is saving or has saved a bookmark
    Then the bookmark may be given more than one tag

  Scenario: Browse by clicking a tag
    Given the user has bookmarks with various tags
    When the user clicks a tag
    Then the list narrows to bookmarks that carry that tag

  Scenario: The same bookmark is reachable from any of its tags
    Given a bookmark carries the tags "cooking" and "gardening"
    When the user browses by "cooking"
    Then the bookmark appears
    And when the user browses by "gardening"
    Then the same bookmark appears

  Scenario: Return to the full list
    Given the user is browsing within a tag
    When the user clears the tag selection (clicks it again or clicks "All")
    Then the full list of bookmarks is shown

## Assumptions
- Organization is by multiple tags, not single-parent folders (client chose
  tags over folders explicitly).
- Browsing filters by one tag at a time in this scenario; filtering by several
  tags simultaneously is an open interaction question (see backlog / active
  extension) and not yet approved.
- The tag list shows a per-tag count (facilitator choice, shown; not objected).
- How tags are entered/assigned during saving is explored separately (open
  interaction question — SCN-005 candidate).
