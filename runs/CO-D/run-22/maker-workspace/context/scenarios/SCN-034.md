Scenario ID: SCN-034
Title: Export bookmarks for portability and backup
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A person can export without changing the collection. A browser-compatible bookmark file contains links, titles, original dates, and labels arranged as folders for use in browsers or other apps. A complete personal copy contains all bookmark information, reading and archive status, formatted notes, saved pages, images, and retained PDF files. Archived and Finished bookmarks are included; permanently deleted bookmarks are not.

## Gherkin
Feature: Exporting a bookmark collection

  Scenario: Prepare a browser-compatible export
    Given the collection contains bookmarks with titles, dates, and labels
    When the person prepares a browser bookmarks file
    Then a standard browser-compatible file is made available
    And it contains all non-deleted links, titles, and original dates
    And labels are represented as folders
    And the collection remains unchanged

  Scenario: Prepare a complete personal copy
    Given the collection contains notes, statuses, saved pages, images, and PDF files
    When the person prepares a complete collection copy
    Then an archive containing all non-deleted bookmark information and preserved content is made available
    And Archived and Finished bookmarks are included
    And permanently deleted bookmarks are not included
    And the collection remains unchanged

## Assumptions
- Export preparation may take longer for collections with substantial preserved content.
- The complete copy uses documented, portable files rather than an app-only opaque format.
