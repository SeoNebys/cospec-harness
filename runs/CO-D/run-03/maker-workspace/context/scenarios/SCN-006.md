Scenario ID: SCN-006
Title: Delete a bookmark immediately, with an Undo safety net
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The client deletes an item from the inline editor via a Delete action. The item
is removed immediately — no "Are you sure?" prompt, which the client found
naggy for a frequent action. A brief message with an Undo appears so an
accidental deletion can be reversed for a few seconds.

Delete means "gone for good." It is DISTINCT from archiving (tuck away but keep),
which is a separate pending requirement.

## Gherkin
Feature: Delete a bookmark

  Scenario: Delete with no confirmation prompt
    Given the client is editing a saved item
    When the client activates Delete
    Then the item is removed immediately without a confirmation prompt
    And a brief message with an Undo option is shown

  Scenario: Undo a deletion
    Given the client just deleted an item and the Undo option is visible
    When the client activates Undo
    Then the item is restored to the collection

## Assumptions
- Immediate delete + transient Undo, no up-front confirmation. (Approved.)
