Scenario ID: SCN-019
Title: Search and filter within the current library section
Type: Edge Case
Approval status: approved
Approval session: SESSION-019
Approval cycle: 1

## Approved behaviour
Search and tag filtering operate within the library section the person is viewing. All bookmarks and Read later exclude archived bookmarks so tucked-away items do not return to everyday views. Archive provides its own search and tag filtering across all archived bookmarks, keeping them findable when the person intentionally looks there.

## Gherkin
Feature: Finding bookmarks within library sections

  Scenario Outline: Everyday sections exclude archived bookmarks
    Given a bookmark has been archived
    And the person is viewing <section>
    When the person searches or filters by one of that bookmark's tags
    Then the archived bookmark is not included in the results

    Examples:
      | section       |
      | All bookmarks |
      | Read later    |

  Scenario: Find a bookmark within Archive
    Given bookmarks have been archived
    And the person is viewing Archive
    When the person searches or filters by tag
    Then matching archived bookmarks are shown
    And active bookmarks outside Archive are not included

## Assumptions
- Search and tag filtering always state or imply the current section through the surrounding page.
- Search in Archive covers the complete archived collection, including items not initially displayed.
