Scenario ID: SCN-014
Title: Widen search results with or
Type: Happy Path
Approval status: approved
Approval session: SESSION-014
Approval cycle: 1

## Approved behaviour
The person can combine search conditions with the word "or". A bookmark remains visible when either condition matches, widening the results to the union of both searches.

## Gherkin
Feature: Combining bookmark searches

  Scenario: Match either of two text searches
    Given one bookmark contains "grid"
    And a different bookmark contains "JavaScript"
    And another bookmark contains neither term
    When the person searches for "grid or JavaScript"
    Then the grid bookmark and JavaScript bookmark are shown
    And the bookmark matching neither term is hidden

## Assumptions
- Search command words ignore capitalization.
