Scenario ID: SCN-007
Title: Return to an existing bookmark instead of saving a duplicate
Type: Edge Case
Approval status: approved
Approval session: SESSION-007
Approval cycle: 1

## Approved behaviour
When a person tries to save the exact address of a bookmark already in the library, the app does not create another bookmark and the library count remains unchanged. It briefly explains that the link is already saved and brings the existing bookmark card into view so the person can continue from there.

## Gherkin
Feature: Avoid duplicate bookmarks

  Scenario: Save an address that is already bookmarked
    Given the library already contains a bookmark with a particular web address
    When the person tries to save that exact web address again
    Then no new bookmark is created
    And the library count remains unchanged
    And the app explains that the link is already saved
    And the existing bookmark card is brought into view

## Assumptions
- This scenario covers an exact match of the full saved address.
- The original bookmark and its details are left unchanged.
