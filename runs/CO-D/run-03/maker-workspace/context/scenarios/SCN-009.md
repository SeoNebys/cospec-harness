Scenario ID: SCN-009
Title: Large library loads incrementally; search/filter/count/sort span the whole collection
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

- With a large library (hundreds/thousands of bookmarks), the list loads more
  bookmarks as the user scrolls (incremental loading), rather than rendering
  everything at once.
- While the next group is being fetched, a clear loading indicator ("Loading more
  bookmarks…") is shown.
- Search, filters (To read / Finished / All / Archived scope), the result count,
  and the selected sort order all apply to the ENTIRE collection — not only the
  portion currently loaded. The visible cards are simply how much has been drawn
  so far.
- A count line communicates the whole size (e.g. "Showing 20 of 1,284").

## Gherkin

Feature: Large library handling

  Scenario: Incremental loading with an indicator
    Given a library larger than one screenful
    When the user scrolls to the end of the loaded items
    Then more bookmarks load and a "loading more" indicator is shown while fetching

  Scenario: Operations span the whole collection
    Given only part of the collection is currently loaded
    When the user searches, filters, or changes the sort order
    Then the operation is applied across the entire collection, not just loaded items
    And the count reflects the whole collection
