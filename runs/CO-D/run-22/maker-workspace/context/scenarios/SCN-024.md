Scenario ID: SCN-024
Title: Reject an invalid bookmark address
Type: Error Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When entered text is not a complete web address, saving is blocked before any retrieval attempt. No bookmark is added, the existing collection stays unchanged, and a clear inline message explains the problem and shows the shape of a valid address so the person can correct it.

## Gherkin
Feature: Saving bookmarks

  Scenario: Attempt to save malformed address text
    Given the person has entered text that is not a complete HTTP or HTTPS web address
    When they try to save the bookmark
    Then no bookmark is added
    And the collection remains unchanged
    And the address field is marked as needing correction
    And an inline message gives an example of a complete web address

## Assumptions
- Only complete HTTP and HTTPS addresses are accepted.
- The entered text remains available for correction.
