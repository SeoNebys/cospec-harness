Scenario ID: SCN-005
Title: Keep and complete a read-later queue
Type: Happy Path
Approval status: approved
Approval session: SESSION-005
Approval cycle: 1

## Approved behaviour
While saving a bookmark, the person may optionally add it to Read later in the same action. The saved card visibly shows its Read later status, and the bookmark also appears in a separate Read later section. In that section, the person checks an item off when finished; it leaves the queue but remains saved in All bookmarks.

## Gherkin
Feature: Read-later queue

  Scenario: Add a bookmark to Read later while saving
    Given the person is entering a web address to save
    When the person chooses Add to Read later and saves the link
    Then the bookmark is saved in All bookmarks
    And its card visibly shows Read later status
    And it appears in the separate Read later section

  Scenario: Complete a read-later item without deleting its bookmark
    Given a saved bookmark appears in the Read later section
    When the person checks that item off
    Then it is removed from the Read later section
    And it remains saved in All bookmarks

## Assumptions
- Read later is optional for each bookmark.
- Read later is chosen before selecting Save link.
- Completion uses a check-circle interaction that resembles ticking off a reading list.
- Completing an item changes queue membership, not bookmark existence.
