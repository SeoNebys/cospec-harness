Scenario ID: SCN-004
Title: Browse bookmarks by a tag in the sidebar
Type: Happy Path
Approval status: approved
Approval session: SESSION-004
Approval cycle: 1

## Approved behaviour

The client's tags are visible at a glance in the sidebar with a count beside each one. Choosing "Recipes" narrows the library to bookmarks with that tag. The filtered view clearly identifies Recipes as the active tag and shows the number of matching bookmarks, reassuring the client that the filter took effect.

## Gherkin

Feature: Browse bookmarks by tag

  Scenario: Show bookmarks belonging to one tag
    Given the library contains two bookmarks tagged "Recipes"
    And it contains one bookmark without the "Recipes" tag
    And the sidebar lists tags with their bookmark counts
    When the user chooses "Recipes" in the sidebar
    Then only the two bookmarks tagged "Recipes" are shown
    And "Recipes" is identified as the active tag
    And the result count shows two bookmarks

## Assumptions

- The sidebar is the primary place for browsing tags.
- Each sidebar tag shows its bookmark count.
- The filtered result area shows both the active tag and matching bookmark count.
