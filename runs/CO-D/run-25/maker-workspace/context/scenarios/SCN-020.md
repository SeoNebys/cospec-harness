Scenario ID: SCN-020
Title: Mark a Read later bookmark as read
Type: Happy Path
Approval status: approved
Approval session: SESSION-020
Approval cycle: 1

## Approved behaviour
A bookmark already in Read later has a direct "Mark as read" action on its card. Using it removes the Read later status and clears the item from the to-read pile, but preserves the bookmark in the main collection.

## Gherkin
Feature: Read later

  Scenario: Finish reading a saved bookmark
    Given a saved bookmark is in Read later
    When the person marks it as read from its card
    Then it is removed from Read later
    And it remains saved in the main bookmark collection

## Assumptions
- "Mark as read" does not create a separate archive or reading-history status.
