Scenario ID: SCN-002
Title: Correct an entry's automatically gathered title and description
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
On a saved entry, the client clicks an "Edit" link on the card. The Edit form
opens in place (inline) with "Save changes" and "Cancel" actions. It contains:
the Link (URL), the title, and the description, plus a checkbox "Re-fetch page
details from this link when I save".

The client edits the fields and clicks Save changes; the card returns to its
normal appearance showing the updated values, with a small "· edited" note next
to the site name. Cancel discards changes.

URL editing behaviour (confirmed):
- By default (checkbox unticked), changing the URL PRESERVES the curated title
  and description; the site name and favicon update to match the new link.
- If the "Re-fetch page details" checkbox is ticked, saving re-gathers title,
  description, favicon, and preview image fresh from the (new) link, overwriting
  the current values. The default is to keep the client's curated text.

The preview image, favicon, and site name are otherwise auto-derived, not free-
text editable. The client confirmed inline editing with Save/Cancel feels
natural, that keeping title/description on URL change (unless re-fetch is asked)
is the right default, and that the checkbox is a clear way to replace details.

## Gherkin
Feature: Correct automatically gathered details

  Scenario: Editing title and description inline
    Given a saved entry with automatically gathered details
    When the client clicks Edit on the entry
    Then the title and description become editable fields in place
    And Save changes and Cancel actions are shown

  Scenario: Saving corrections
    Given the client is editing an entry's title and description
    When the client changes the text and clicks Save changes
    Then the entry shows the corrected title and description
    And the entry is marked as edited

  Scenario: Cancelling corrections
    Given the client is editing an entry's title and description
    When the client clicks Cancel
    Then the entry keeps its previous title and description unchanged

  Scenario: Editing the URL keeps curated text by default
    Given the client is editing an entry and the re-fetch option is off
    When the client changes the URL and clicks Save changes
    Then the entry keeps its current title and description
    And the site name and favicon update to match the new URL

  Scenario: Editing the URL with re-fetch replaces the details
    Given the client is editing an entry and ticks Re-fetch page details
    When the client changes the URL and clicks Save changes
    Then the entry re-gathers title, description, favicon, and preview image from the new URL

## Assumptions
- The Edit form covers URL, title, and description (fuller management).
- Re-fetch is opt-in; default preserves curated title/description.
- Tags and note are managed in the separate organize panel (SCN-003).
