Title: Personal display preferences (text size, density, items per load, default sort), remembered
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

A display-preferences area lets the user set personal choices, with a live preview
and automatic saving (remembered for next time):
- Text size: Small / Medium / Large — how large bookmark text appears.
- List density: Comfortable (roomy cards with descriptions) vs Compact (tighter
  rows, more bookmarks visible; less per-item detail). Density controls how much
  information each bookmark shows.
- Items per load: 20 / 50 / 100 — how many bookmarks are fetched at a time while
  scrolling a large library (SCN-009). Distinct from density.
- Default sort order: the remembered default (SCN-010), surfaced here too.

Changes save automatically (a confirmation line appears) and persist across
sessions. A live preview reflects text size and density immediately.

No light/dark appearance setting in this version.

## Gherkin

Feature: Display preferences

  Scenario: Change and remember a preference
    Given the display preferences panel
    When the user changes text size, density, items-per-load, or default sort
    Then the preview updates (for text size/density) and the choice is saved automatically
    And the choice is applied again on the next visit

  Scenario: Density vs items-per-load are independent
    Then density changes how much detail each bookmark shows
    And items-per-load changes how many are fetched at once

## Assumptions
- Preferences are per user (single-user app), stored durably.
- Default sort here is the same setting as SCN-010.
