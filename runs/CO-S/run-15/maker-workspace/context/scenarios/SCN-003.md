Scenario ID: SCN-003
Title: Find a saved link by searching or filtering by tag
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The client can locate a saved link two ways. (1) A single search box filters the
list as the client types, matching text against the link's title, web address,
and tags together; the count shows "N of M" while filtering, and a "Clear"
control returns to the full list. (2) Clicking a tag chip on any link filters
the list to links carrying that tag; a banner ("Filtered by tag … — show all")
shows the active tag filter and offers a one-click return to the full list.
When nothing matches the current search, a friendly "No links match your
search" message is shown instead of a blank list. This is the client's primary
goal (reliably finding a saved link).

## Gherkin
Feature: Finding saved links

  Scenario: Filter by typed search across title, address and tags
    Given several saved links
    When the client types text into the search box
    Then only links whose title, web address, or tags contain that text remain
    And the count shows how many of the total are shown

  Scenario: Clear the search
    Given an active typed search
    When the client clears the search
    Then the full list of links is shown again

  Scenario: Filter by clicking a tag
    Given a saved link showing a tag chip
    When the client clicks that tag chip
    Then only links carrying that tag are shown
    And a banner indicates the active tag filter with a way to show all

  Scenario: Return to full list from a tag filter
    Given an active tag filter
    When the client chooses "show all"
    Then the full list of links is shown again

  Scenario: No matches
    Given an active search
    When no link matches
    Then a "no links match" message is shown instead of an empty list

## Assumptions
- Search is a single box matching title, address, and tags together, as-you-type.
- Typed search and tag-click filtering are separate paths; starting one clears
  the other.
- The count reads "N of M" while a filter is active.
