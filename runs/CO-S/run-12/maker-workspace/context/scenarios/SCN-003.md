Scenario ID: SCN-003
Title: Keep a personal note with a bookmark
Type: Happy Path
Approval status: approved
Approval session: SESSION-003
Approval cycle: 1

## Approved behaviour
The client can add a personal note to one bookmark and save it. The note stays off collection cards so the collection remains uncluttered. It appears in a distinct note area on that bookmark's details view and can be edited later.

## Gherkin
Feature: Personal bookmark notes

  Scenario: Add and view a note for one bookmark
    Given a bookmark is being edited
    When the user adds a personal note and saves the changes
    Then the note is attached only to that bookmark
    And the note appears in a distinct area on the bookmark details view
    And the note does not appear on the bookmark card in the collection

  Scenario: Edit an existing bookmark note
    Given a bookmark details view shows a personal note
    When the user chooses to edit the note
    Then the existing note is available to change and save again

## Assumptions
- Notes are free-form text.
- Notes are managed from the bookmark's own edit and details views.
