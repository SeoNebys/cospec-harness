Scenario ID: SCN-005
Title: Open a saved bookmark for reading without losing the library
Type: Happy Path
Approval status: approved
Approval session: SESSION-005
Approval cycle: 1

## Approved behaviour
Clicking a saved bookmark opens its original page in a new browser tab. The bookmark library remains open and unchanged in the original tab, preserving the person's place while they read and return to continue through saved items. Editing remains a separate action and does not replace the ordinary open-for-reading behavior.

## Gherkin
Feature: Revisit a saved bookmark

  Scenario: Open the original page from a bookmark
    Given the library contains a bookmark for an original page
    When the person clicks the bookmark rather than its Edit action
    Then the original page opens in a new browser tab
    And the bookmark library remains open at the same place in the original tab

## Assumptions
- The original page is currently available.
- Opening a bookmark for reading is the card's primary action.
- The distinct Edit bookmark action does not open the original page.
- Original pages open in a new tab so the library is preserved for continued browsing.
