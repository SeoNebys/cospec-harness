Scenario ID: SCN-005
Title: Correct the web address in the same inline editor
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The inline editor includes a "Web address" field alongside the title and summary,
so the client fixes everything about an item in one place. By default, changing
the address does NOT re-fetch information — the client's existing title, summary,
and image are kept, because the common case is a slightly-wrong link for the same
content.

## Gherkin
Feature: Correct the web address

  Scenario: Change the address without disturbing the other details
    Given the client is editing a saved item
    When the client changes the "Web address" field and saves
    Then the item's address is updated
    And its title, summary, and image are left unchanged

## Assumptions
- Address editing lives in the same inline editor as title and summary. (Approved.)
- Default behaviour on address change is NOT to re-capture. (Approved.)
