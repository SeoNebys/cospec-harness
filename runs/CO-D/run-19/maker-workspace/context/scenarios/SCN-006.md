Title: Precisely narrow a large bookmark library
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Precise search builds on immediate plain search. Quoted wording matches only that exact sequence of words. A visible choice switches typed words between requiring all words, matching the exact wording, or allowing any word. Labels can be visibly selected for inclusion or toggled to a clearly marked exclusion state. Typed shortcuts can express exact labels, exclusions, and OR conditions. Visible choices and typed shortcuts can be combined in one readable search screen, cooperate on one result set, and show one honest result count. A selected label can also be combined with typed words to require both conditions.

## Gherkin
Feature: Precisely search saved bookmarks

  Scenario: Search for exact quoted wording
    Given the library contains bookmarks where words may occur together or separately
    When the client encloses wording in quotation marks in the search field
    Then only bookmarks containing those words together and in that order are shown
    And the interface explains that exact wording is being matched

  Scenario: Include one exact label and exclude another with visible controls
    Given the library contains bookmarks with overlapping labels
    When the client selects one label to include
    And toggles another label to its visibly marked exclusion state
    Then only bookmarks with the included label and without the excluded label are shown
    And the client can read back both conditions from the controls

  Scenario: Match any typed word
    Given bookmarks contain different words
    When the client types multiple words
    And selects the visible any-word choice
    Then bookmarks containing at least one of the typed words are shown

  Scenario: Combine a chosen label with typed words
    Given a label has been selected for inclusion
    When the client types a word in the search field
    Then only bookmarks that have the label and contain the word are shown

  Scenario: Combine visible conditions with typed shortcuts
    Given the client has selected a label using the visible controls
    When the client adds a compatible typed exclusion shortcut
    Then both conditions are applied to one result set
    And one combined result count is shown

## Assumptions
- Visible point-and-click controls are the primary everyday interaction; typed shortcuts remain available for speed.
- An excluded word or label rejects a bookmark even if another included condition matches it.
- Quoted matching is case-insensitive, like plain search.
