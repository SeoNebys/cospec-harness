Scenario ID: SCN-002
Title: Re-adding a link that is already saved opens the existing bookmark
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

When the client enters a link they have already saved and chooses Add, the app
does not create a duplicate. Instead it scrolls to and briefly highlights the
existing bookmark, opens it for editing so the client can update it, and shows a
message explaining that the link is already saved and can be updated.

## Gherkin

Feature: Saving a link

  Scenario: Re-adding a link I already saved
    Given I have already saved a particular link
    When I enter the same link and choose Add
    Then no duplicate bookmark is created
    And the app scrolls to and briefly highlights the existing bookmark
    And opens that bookmark for editing
    And shows a message that it is already saved and can be updated

## Assumptions

- Two addresses are treated as the same link when they match after ignoring a
  leading "www.", a trailing slash, and the http/https difference. Finer
  equivalence rules (e.g. tracking query parameters) are not yet explored.
