Scenario ID: SCN-002
Title: Review and correct page details before saving
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
After the app obtains a title and description for a new web address, the user can review both values in ordinary text fields, change either value, and save the bookmark with the corrected details.

## Gherkin
Feature: Saving bookmarks

  Scenario: Correct an obtained title before saving
    Given the app has obtained a title and description for a new web address
    When the user replaces the obtained title before saving
    And saves the link
    Then the bookmark is saved with the replacement title
    And the obtained description is preserved

  Scenario: Correct an obtained description before saving
    Given the app has obtained a title and description for a new web address
    When the user replaces the obtained description before saving
    And saves the link
    Then the bookmark is saved with the replacement description
    And the obtained title is preserved

## Assumptions
- The title and description are shown for review before the bookmark is committed.
- Both values are editable using ordinary text fields.
- The bookmark is not saved until the user confirms the save after review.
