Scenario ID: SCN-004
Title: Add existing and new tags to a bookmark
Type: Happy Path
Approval status: approved
Approval session: SESSION-004
Approval cycle: 1

## Approved behaviour
While reviewing a bookmark, the user can type into its tag field. Matching existing tags appear as clickable suggestions without requiring the same capitalisation. Selecting a suggestion attaches the established tag with its existing spelling. When the typed value is new, pressing Enter creates and attaches it. Existing and newly created tags can be attached together.

## Gherkin
Feature: Tag a bookmark

  Scenario: Reuse an existing matching tag
    Given the user is reviewing a bookmark
    And an existing tag named "Health" is available
    When the user types "hea" in the tag field
    Then the app suggests the existing "Health" tag
    When the user selects that suggestion
    Then the "Health" tag is attached using its established spelling

  Scenario: Create a new tag alongside an existing tag
    Given the user has attached the existing "Health" tag to a bookmark
    And no existing tag matches "Walking"
    When the user types "Walking" and presses Enter
    Then a new "Walking" tag is created
    And both "Health" and "Walking" are attached to the bookmark

## Assumptions
- Tags are attached while the user reviews the bookmark before saving.
- Existing-tag matching is case-insensitive.
- Selecting a suggestion reuses the existing tag instead of creating a duplicate.
