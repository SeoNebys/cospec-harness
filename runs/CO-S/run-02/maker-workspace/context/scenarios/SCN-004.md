Scenario ID: SCN-004
Title: Keep and view a separate reading list
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Each bookmark has a clearly labeled Read later control. Activating it immediately confirms that the bookmark is in the reading list. A separate Read later view shows only the bookmarks marked this way. The client preferred the text label over a symbol because its meaning is unambiguous.

## Gherkin
Feature: Reading list

  Scenario: Mark a bookmark to read later
    Given a bookmark is not in the reading list
    When the user activates its clearly labeled Read later control
    Then the bookmark is added to the reading list
    And the bookmark immediately shows that it is in the reading list

  Scenario: View only bookmarks in the reading list
    Given one bookmark has been marked to read later
    And other bookmarks have not been marked to read later
    When the user opens the Read later view
    Then the marked bookmark is visible
    And bookmarks not marked to read later are hidden

## Assumptions
- Reading-list membership is controlled separately on each bookmark.
- The reading list is a focused view of saved bookmarks, not a separate copy.
- The control uses the words Read later rather than an icon alone.
