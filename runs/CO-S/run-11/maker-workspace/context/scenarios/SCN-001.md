Scenario ID: SCN-001
Title: Save a link with auto-filled details
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The user pastes or types a link into a "Paste a link" box shown at the top of
the save area. A moment after the link is entered, the Title and Description
fields below are filled in automatically from the link, and are briefly
highlighted to show what was auto-filled. Both fields remain editable, so the
user can correct them before saving (the client edited the description in
review). Clicking "Save bookmark" adds the bookmark to a "Saved" list, with the
newest bookmark appearing at the top. After saving, the input fields clear,
ready for the next link.

## Gherkin
Feature: Save a bookmark with auto-filled details

  Scenario: Auto-fill details after entering a link
    Given the save area is shown with an empty link box
    When the user enters a valid link and moves focus away from the box
    Then the Title and Description fields are filled in automatically from the link
    And the auto-filled fields are highlighted
    And both fields remain editable

  Scenario: Correct an auto-filled field before saving
    Given a link has been entered and its details were auto-filled
    When the user edits the Title or Description
    Then the edited values are kept for saving

  Scenario: Save the bookmark
    Given a valid link has been entered and its details are present
    When the user clicks "Save bookmark"
    Then the bookmark is added to the top of the "Saved" list
    And the link, title and description input fields are cleared

## Assumptions
- The link box is placed first, before Title and Description.
- Both Title and Description are auto-filled (not just one).
- Auto-filled values are editable before saving.
- Newest saved bookmark appears at the top of the list.
- In the prototype, auto-fill is simulated; real detail retrieval from the link
  is a Phase 2 implementation concern, not an approved behaviour detail.
