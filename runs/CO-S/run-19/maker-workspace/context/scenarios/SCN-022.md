Scenario ID: SCN-022
Title: Archive a bookmark that is still in Read later
Type: Edge Case
Approval status: approved
Approval session: SESSION-022
Approval cycle: 1

## Approved behaviour

When a bookmark that is still pending in Read later is archived, it is removed from both the everyday list and the reading queue and appears in Archive. Restoring it returns it to All bookmarks only and does not silently reinstate the old Read later status, leaving the reading queue clear.

## Gherkin

Feature: Coordinate Read later and Archive status

  Scenario: Archive a pending reading item
    Given a bookmark is visible in All bookmarks
    And the bookmark is pending in Read later
    When the user archives the bookmark
    Then the bookmark is removed from All bookmarks
    And the bookmark is removed from Read later
    And the bookmark appears in Archive

  Scenario: Restore without reinstating the old reading reminder
    Given an archived bookmark was pending in Read later before it was archived
    When the user restores the bookmark to the library
    Then the bookmark appears in All bookmarks
    And the bookmark does not appear in Read later

## Assumptions

- Archive membership and Read later membership cannot be active at the same time.
- Restoring an archived item never revives its previous Read later status.
