# Business goal statement

- Cycle: 1
- Interface form: Web app (opens in a browser)
- Status: Confirmed (Phase 1, Step 1)

## Core goal (client's language)

> One personal place where I can save links and reliably find them again,
> instead of losing them in a long browser-bookmark list.

**The main payoff is being able to find a link again.** Organising the
collection is valued, but mainly because it makes retrieval dependable and keeps
the collection manageable.

## Supporting intents (client's language)

- "organise them by topic"
- "search their titles or notes"
- "keep track of things I still want to read"
- "archive links I want to retain without cluttering the main view"
- "mainly for my own collection, not for sharing with other people"

## Verbatim client utterances

1. "I want one personal place where I can save links and reliably find them
   again, instead of losing them in a long browser-bookmark list. I'd like to
   organise them by topic, search their titles or notes, keep track of things I
   still want to read, and archive links I want to retain without cluttering the
   main view. This is mainly for my own collection, not for sharing with other
   people."
2. "Yes, being able to find a link again is the main payoff. I do value keeping
   the collection organised, but mainly because that makes retrieval dependable
   and keeps it manageable."
3. "I picture it as a web app I can open in my browser."
