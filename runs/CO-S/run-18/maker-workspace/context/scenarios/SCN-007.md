Scenario ID: SCN-007
Title: Permanently delete a bookmark with confirmation
Type: Happy Path
Approval status: approved
Approval session: SESSION-007
Approval cycle: 1

## Approved behaviour
Permanent Delete is available in a bookmark card's actions menu. Choosing it opens a separate confirmation that names the bookmark and clearly warns that removal is permanent and cannot be undone. The bookmark is deleted only after explicit confirmation. Cancelling closes the warning and leaves the bookmark and all counts unchanged.

## Gherkin
Feature: Permanently deleting bookmarks

  Scenario: Confirm permanent deletion
    Given a saved bookmark is visible
    When the person chooses permanent Delete from its card menu
    Then a separate confirmation names the bookmark
    And it warns that deletion cannot be undone
    When the person explicitly confirms permanent deletion
    Then the bookmark is removed from the library for good

  Scenario: Cancel permanent deletion
    Given the permanent-deletion confirmation is open for a bookmark
    When the person chooses Cancel
    Then the confirmation closes
    And the bookmark remains unchanged
    And all library counts remain unchanged

## Assumptions
- Permanent deletion has no undo.
- A separate confirmation is required every time.
- Cancelling the confirmation leaves the bookmark and counts unchanged.
