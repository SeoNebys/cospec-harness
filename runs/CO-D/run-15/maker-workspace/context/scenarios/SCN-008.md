Scenario ID: SCN-008
Title: Add a lightly formatted and searchable bookmark note
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

The client can add one personal note to a bookmark and apply lightweight formatting using direct controls for bulleted lists and bold text. The formatted result is displayed directly on the bookmark. Words in the note remain part of the same case-insensitive search used for the title, description, and web address.

## Gherkin

Feature: Add searchable personal context to bookmarks

  Scenario: Save and display a formatted note
    Given the client is viewing an existing bookmark without a personal note
    When the client adds a note containing a bulleted list or bold text
    And saves the note
    Then the note is displayed directly on the bookmark
    And the note's bullets and bold emphasis are displayed as formatted content

  Scenario: Find a bookmark by words in its formatted note
    Given a bookmark has a formatted personal note containing the word "Sunday"
    And "Sunday" is not present in its title, description, or web address
    When the client searches for "sunday" using any capitalization
    Then that bookmark is shown in the search results

## Assumptions

- Each bookmark has one personal note.
- Lightweight formatting includes bulleted lists and bold text.
- Search uses the readable words in the note and ignores capitalization.
- The note is displayed directly on the bookmark.
- Formatting is entered with direct, plainly labeled controls rather than special typed symbols.
