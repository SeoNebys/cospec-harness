Scenario ID: SCN-012
Title: Correct an invalid web address before saving
Type: Error Case
Approval status: approved
Approval session: SESSION-012
Approval cycle: 1

## Approved behaviour
When submitted text is not a usable web address, the app does not attempt to retrieve details and does not change the bookmark count. It highlights the address field, shows a concise inline correction with a concrete example of a valid address, and leaves the field focused and ready to replace.

## Gherkin
Feature: Validate a submitted web address

  Scenario: Submit text that is not a usable web address
    Given the bookmark collection has a known count
    When the user submits text that is not a usable web address
    Then no page-detail retrieval is attempted
    And the bookmark count remains unchanged
    And the address field is highlighted
    And an inline message gives a concrete valid-address example
    And the address remains focused and ready to correct

## Assumptions
- A usable address identifies an HTTP or HTTPS page.
- Correcting the field removes the stale error presentation.
