Scenario ID: SCN-012
Title: Save a valid page when its details cannot be retrieved
Type: Error Case
Approval status: approved
Approval session: SESSION-012
Approval cycle: 1

## Approved behaviour
When a valid page address does not provide automatic page details, the app
explains that the details are unavailable without blocking the save. The person
can enter a title and optional description manually. The saved bookmark uses a
neutral site icon and keeps the valid destination address.

## Gherkin
Feature: Save pages with unavailable details

  Scenario: Page details cannot be retrieved
    Given the person has entered a valid web address
    When the app cannot retrieve the page title, description, or icon
    Then the person is told that page details are unavailable
    And the person can enter a title and description manually
    When the person saves those details
    Then a bookmark is added with the manually entered details
    And a neutral site icon is shown
    And selecting the bookmark opens the original address

## Assumptions
- Failure to retrieve page details does not imply that the address itself is invalid.
- A manually entered description is optional.
- A neutral icon replaces an unavailable page icon.
