Scenario ID: SCN-016
Title: Ignore tracking additions when detecting duplicates
Type: Edge Case
Approval status: approved
Approval session: SESSION-016
Approval cycle: 1

## Approved behaviour
An already-saved page is still treated as the same bookmark when a later save
attempt adds recognizable tracking parameters to its address. No duplicate is
created, the existing bookmark is brought into view, and its cleaner saved
address is preserved rather than replaced by the tracked address.

## Gherkin
Feature: Prevent duplicate bookmarks

  Scenario: Save an existing page with tracking parameters
    Given a clean page address is already saved
    And another address points to the same page with recognizable tracking parameters
    When the person attempts to save the tracked address
    Then no new bookmark is created
    And the existing bookmark is brought into view
    And the clean saved address remains unchanged
    And the person is told that tracking text was ignored

## Assumptions
- Recognizable campaign parameters such as utm_source and utm_campaign do not
  identify distinct page content.
- Meaningful non-tracking query parameters are not covered by this scenario.
