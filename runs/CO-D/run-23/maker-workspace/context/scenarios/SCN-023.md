Scenario ID: SCN-023
Title: Import into an existing library without overwriting or duplicating
Type: Edge Case
Approval status: approved
Approval session: SESSION-023
Approval cycle: 1

## Approved behaviour
When a browser bookmark file is imported into a non-empty library, the preview clearly reports how many links already exist and how many are genuinely new. Confirming adds only new bookmarks. Existing matches are not duplicated, and their manually edited titles and descriptions are not overwritten. Any new folder-derived labels from the import are added to those existing bookmarks.

## Gherkin
Feature: Import browser bookmarks

  Scenario: Import a file containing existing and new links
    Given the library already contains edited bookmarks
    And the browser bookmark file contains 14 matching links and 233 new links
    When the person reviews the import
    Then the preview identifies 14 already-saved links
    And it identifies 233 new bookmarks to add
    And it explains how matching links will be handled
    When the person confirms the import
    Then the 233 new bookmarks are added
    And no duplicates are created for the 14 matches
    And existing edited titles and descriptions remain unchanged
    And new folder-derived labels are added to the matching existing bookmarks

## Assumptions
- Import matching follows the approved duplicate-detection rules.
- Imported labels are merged without removing existing labels.
