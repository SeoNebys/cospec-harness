Scenario ID: SCN-011
Title: Invalid link input is gently declined without saving
Type: Error Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

When the client tries to add something that is not a usable link (e.g. free
text), the app gently declines with a short message ("that doesn't look like a
link yet") and does not create a bookmark or open the review panel. A plain
address without a scheme (e.g. "example.com/page") is accepted and treated as a
normal link.

## Gherkin

Feature: Saving a link

  Scenario: Reject non-link input
    Given the add box
    When I enter text that is not a usable link and choose Add
    Then a short message explains it doesn't look like a link
    And no bookmark is created and no review panel opens

  Scenario: Accept an address without a scheme
    When I enter an address such as "example.com/page" and choose Add
    Then it is accepted as a normal link

## Assumptions
- A missing http/https scheme is assumed to be https.
