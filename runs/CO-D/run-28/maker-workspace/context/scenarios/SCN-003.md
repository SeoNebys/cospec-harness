Scenario ID: SCN-003
Title: Find a link by searching across all its information, case-insensitively
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A search box sits above the list. As the client types, the list narrows
immediately to bookmarks whose address, title, description, or personal note
contains the text, ignoring capitalization. Matching text is highlighted in the
results. A running count shows how many of the total are shown. Clearing the box
restores the full list. This is the heart of the app: getting back to a saved
link quickly.

## Gherkin
Feature: Search bookmarks

  Scenario: Narrow the list by a search term
    Given several bookmarks are saved
    When the client types a term in the search box
    Then only bookmarks whose address, title, description, or note contain the term are shown
    And the match is case-insensitive
    And matching text is highlighted
    And a count of shown-of-total is displayed

  Scenario: Clearing the search restores all bookmarks
    Given a search term is narrowing the list
    When the client clears the search box
    Then all bookmarks are shown again

## Assumptions
- Search matches across all four fields together; no field-by-field mode is
  needed (client confirmed).
