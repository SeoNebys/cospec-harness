Scenario ID: SCN-013
Title: Sort the collection (date added, recently updated, title)
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

A Sort control (a dropdown) orders the list. Options:
- Date added — newest first (default for this cycle; the default becomes a
  display preference, SCN-block 6)
- Date added — oldest first
- Recently updated
- Title — A to Z
- Title — Z to A

"Recently updated" orders by the last meaningful change to a bookmark, where a
meaningful change includes editing its details (title/description/address),
notes, tags, reading status, or archive status.

The selected sort order stays applied across searches and view switches, so a
filtered result is ordered by the same choice.

## Gherkin
Feature: Sorting

  Scenario: Sort by date added
    When the user selects "Date added — newest/oldest first"
    Then the list orders by save time accordingly

  Scenario: Sort by recently updated
    Given a bookmark saved long ago is edited (details/notes/tags/status)
    When the user selects "Recently updated"
    Then that bookmark appears at the top

  Scenario: Sort by title
    When the user selects "Title — A to Z" or "Z to A"
    Then the list orders alphabetically by title accordingly

  Scenario: Sort persists across search and views
    Given a sort is selected
    When the user searches or switches view
    Then the shown results keep that sort order

## Assumptions
- Default sort is "Date added — newest first" until the user sets a default in
  display preferences.
- "Recently updated" excludes mere opening of the original page (no
  "recently opened" sort).
