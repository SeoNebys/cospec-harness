Scenario ID: SCN-009
Title: Clear an active label filter
Type: Happy Path
Approval status: approved
Approval session: SESSION-009
Approval cycle: 1

## Approved behaviour
While the collection is filtered, the active label is shown beside the filtered list as a removable control. Removing it immediately restores the full collection, the "Recently saved" heading, and the full bookmark count.

## Gherkin
Feature: Bookmark labels

  Scenario: Return from a label filter to all bookmarks
    Given the collection is filtered by the "Reference" label
    And the active "Reference" label is visibly removable beside the list
    When the person removes the active label
    Then every bookmark is shown again
    And the list heading is "Recently saved"
    And the full bookmark count is restored

## Assumptions
- The active filter and its removal action are colocated with the filtered list.
