Scenario ID: SCN-010
Title: Preserve input when page details cannot be retrieved
Type: Error Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When a valid address cannot provide the title and description needed for a recognizable bookmark, no bookmark is created. The entered address and optional label remain in place, an inline message explains the failure, and the save action becomes Try again.

## Gherkin
Feature: Retrieving bookmark details

  Scenario: Page details cannot be retrieved
    Given the client has entered a valid web address and an optional label
    When the app cannot retrieve that page's title and description
    Then no bookmark is created
    And the library remains unchanged
    And the entered address remains in the save form
    And the entered label remains in the save form
    And an inline message explains that the page details could not be retrieved
    And the client can try the save again

## Assumptions
- A bookmark is not saved unless recognizable page details can be retrieved.
- Retrying uses the address and label already present in the form.
