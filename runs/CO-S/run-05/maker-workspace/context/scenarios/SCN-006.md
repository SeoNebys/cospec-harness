Scenario ID: SCN-006
Title: Reject input that isn't a link
Type: Error Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
If the user tries to save text that doesn't look like a link (e.g. no dot / not
a web address), the save is blocked and a short message explains why. The client
did not want accidental garbage entries in the list.

## Gherkin
Feature: Saving a link

  Scenario: Attempt to save non-link text
    Given the user has typed text that is not a valid link
    When the user clicks Save
    Then the link is not added
    And a short message explains that it doesn't look like a link

## Assumptions
- "Looks like a link" heuristic: contains a dot and a domain-like structure;
  a leading http(s):// is optional. Fine-grained URL validation is not required.
