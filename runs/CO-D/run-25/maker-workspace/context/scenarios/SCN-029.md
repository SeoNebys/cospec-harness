Scenario ID: SCN-029
Title: Preserve stray note-formatting symbols literally
Type: Edge Case
Approval status: approved
Approval session: SESSION-029
Approval cycle: 1

## Approved behaviour
Light note formatting is applied only when the shorthand is complete and unambiguous. Lone or unmatched formatting symbols remain visible exactly as typed and do not unexpectedly format the rest of the note.

## Gherkin
Feature: Personal bookmark notes

  Scenario: Save incomplete formatting shorthand
    Given a bookmark's personal note editor is open
    When the person writes "Multiply 2 * 3 before trying this."
    And writes "**unfinished thought"
    And saves the note
    Then the lone asterisk appears literally
    And the unmatched double asterisk appears literally
    And no unintended text is bolded

## Assumptions
- Only complete supported formatting patterns are rendered.
