Scenario ID: SCN-002
Title: Correct a bookmark's title and description in place
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A person can choose Edit details directly on a saved bookmark card, correct its title and description in place, and save those changes. The corrected values remain on the card while its site and preview image stay unchanged.

## Gherkin
Feature: Editing bookmark details

  Scenario: Correct the title and description of a saved bookmark
    Given a bookmark card contains automatically gathered details
    When the person chooses to edit details on that card
    And replaces its title and description
    And saves the changes
    Then the card shows the replacement title and description
    And the bookmark's site and preview image remain unchanged

## Assumptions
- Editing is started with a visible Edit details button on the bookmark card.
- The title and description are edited directly within the card.
- The person provides acceptable replacement text for both fields.
