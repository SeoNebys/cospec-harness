Scenario ID: SCN-001
Title: Save a new link with page details filled in
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
From an empty personal collection, the user pastes a web address and activates one clear save action. The app obtains the page title and description without requiring the user to type them, saves one bookmark, and shows it under Recently saved.

## Gherkin
Feature: Saving bookmarks

  Scenario: Save a new web address
    Given the personal bookmark collection is empty
    And a web address is in the save field
    When the user chooses to save the link
    Then the app saves one bookmark for that web address
    And the bookmark contains the page title and description obtained by the app
    And the bookmark appears under "Recently saved"

## Assumptions
- The app opens directly to a save field.
- Saving is initiated through one clear button.
- Automatically obtained page details include a title and description.
- The saved bookmark is immediately visible under Recently saved.
