Scenario ID: SCN-024
Title: Explain and recover from an empty Read later shelf
Type: Edge Case
Approval status: approved
Approval session: SESSION-024
Approval cycle: 1

## Approved behaviour

When bookmarks exist but none are marked Read later, the Read later view states that there is nothing to read later without implying that the whole collection is empty. Search and label controls remain available because they still apply to the wider collection, and an action returns directly to all bookmarks.

## Gherkin

Feature: Empty filtered bookmark views

  Scenario: Open Read later when no bookmarks are marked
    Given the collection contains bookmarks
    And no bookmark is marked Read later
    When the user opens the Read later view
    Then the screen says that there is nothing to read later
    And search and label controls remain available
    And the screen offers an action to view all bookmarks

  Scenario: Return from an empty Read later view
    Given the Read later view is empty
    When the user chooses to view all bookmarks
    Then the full collection is shown

## Assumptions

- An empty filtered shelf is distinguished from an entirely empty collection.
