Title: Archive to declutter the main view
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A bookmark can be archived to keep it without cluttering the main view. An
archived bookmark:
- disappears from the All view immediately,
- is excluded from normal searches while in the All (or Read later) view,
- appears in a dedicated Archived view, where it can be searched, and
- can be restored to All with "Restore to All".
Archiving does not delete the bookmark.

## Gherkin
Feature: Archive

  Scenario: Archive a bookmark
    Given a bookmark in the All view
    When the user presses "Archive"
    Then the bookmark disappears from the All view
    And it appears in the Archived view
    And the Archived count increases and the All count decreases

  Scenario: Archived items are out of normal searches
    Given an archived bookmark
    When the user searches while viewing All (or Read later)
    Then the archived bookmark is not among the results

  Scenario: Search within the Archived view
    Given archived bookmarks
    When the user opens the Archived view and searches
    Then the search applies to the archived bookmarks

  Scenario: Restore an archived bookmark
    Given a bookmark in the Archived view
    When the user presses "Restore to All"
    Then it returns to the All view

## Assumptions
- Archiving hides from All and from normal (non-archived) searches
  (client-confirmed).
- Archived items are searchable only after switching to the Archived view
  (client-confirmed).
- Archive is reversible (restore) and non-destructive.
