Scenario ID: SCN-005
Title: Search the bookmark collection as text is entered
Type: Happy Path
Approval status: approved
Approval session: SESSION-005
Approval cycle: 1

## Approved behaviour

The client can use a search box above the collection to narrow the visible bookmarks as each character is entered, without pressing a Search button. The matching result count updates at the same time. Search checks the bookmark title, description, site name, and web address, allowing a bookmark to be found from remembered wording in its description.

## Gherkin

Feature: Finding saved bookmarks

  Scenario: Narrow bookmarks while typing a remembered word
    Given the collection contains bookmarks with different titles and descriptions
    When the user types a word that appears in one bookmark's description
    Then the collection immediately shows the matching bookmark without a separate submit action
    And the result count immediately reflects the visible matches

  Scenario Outline: Match searchable bookmark details
    Given a saved bookmark has a known <field>
    When the user types wording from that <field>
    Then the matching bookmark is included in the visible results

    Examples:
      | field       |
      | title       |
      | description |
      | site name   |
      | web address |

## Assumptions

- The search box is positioned above the bookmark collection.
- Results use the existing card presentation.
