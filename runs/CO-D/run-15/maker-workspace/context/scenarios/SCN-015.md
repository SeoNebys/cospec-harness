Scenario ID: SCN-015
Title: Remove one tag from one bookmark
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

The client can remove one tag directly from a bookmark without a confirmation prompt. Other tags on that bookmark remain. The removed tag is not removed from other bookmarks and remains available as an existing-tag suggestion when still used elsewhere.

## Gherkin

Feature: Correct bookmark tags

  Scenario: Remove one tag from a multiply tagged bookmark
    Given a bookmark has the tags "Cooking" and "Italian"
    And "Italian" is also used elsewhere in the collection
    When the client removes "Italian" from this bookmark
    Then this bookmark retains "Cooking"
    And this bookmark no longer has "Italian"
    And no confirmation is required
    And "Italian" remains on other bookmarks
    And "Italian" remains available as an existing-tag suggestion

## Assumptions

- Removing a tag from one bookmark is a small, reversible action.
- Removing the tag association from a bookmark does not globally delete the tag.
