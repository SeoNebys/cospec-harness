Title: Organize a bookmark with tags
Type: Happy Path
Approval status: approved
Approval session: SESSION-004
Approval cycle: 1

## Approved behaviour

The client can open tag editing for a bookmark and assign more than one tag. The client can type a new tag name to create it. As the client types, matching tags that already exist are offered with the number of bookmarks using each tag, allowing an existing tag to be reused instead of creating an accidental near-duplicate. Saved tags appear on the bookmark and in the sidebar.

## Gherkin

Feature: Tag bookmarks

  Scenario: Create a new tag for a bookmark
    Given a bookmark already has the tag "science"
    When the user opens tag editing
    And types the new tag "animals"
    And saves the tags
    Then the bookmark shows both "science" and "animals"
    And both tags appear in the sidebar

  Scenario: Reuse an existing tag offered while typing
    Given the tag "animals" already exists in the library
    And a bookmark does not yet have the tag "animals"
    When the user opens tag editing
    And types "ani"
    Then the app offers the existing "animals" tag
    And shows how many bookmarks already use it
    When the user chooses "animals" and saves the tags
    Then the existing tag is assigned to the bookmark
    And no new near-duplicate tag is created

## Assumptions

- Tag names are displayed in lowercase.
- A bookmark can have multiple tags.
- The tag editor uses the side-panel pattern established for editing bookmark details.
- Entered text can create a new tag when no existing suggestion is chosen.
