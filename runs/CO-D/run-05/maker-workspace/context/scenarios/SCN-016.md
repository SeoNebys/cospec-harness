Scenario ID: SCN-016
Title: Take my whole collection back out
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The client can export their whole collection to a normal bookmarks file — the everyday kind
that loads straight into a browser. This is the "I'm not locked in" guarantee: knowing they
can walk out with their collection is precisely what makes them comfortable pouring
everything in.

Crucially, export carries not just the links but the client's FILING: labels are written as
folders, so re-loading the file elsewhere drops them back into roughly the organisation they
built (confirmed by round-tripping the file back into import — labels returned as folders).
Personal notes ride along too (as bookmark descriptions). A bare link-and-title file was
explicitly judged NOT enough — that would leave their filing system trapped.

## Gherkin
Feature: Exporting the collection

  Scenario: Export to a standard bookmarks file
    Given my saved collection
    When I export
    Then I get a standard bookmarks file that loads into a browser

  Scenario: Filing survives the export
    Given links carrying labels and notes
    When I export and then re-import the file
    Then labels come back (as folders) and notes come back (as descriptions)

## Assumptions
- Labels → folders; a multi-label link appears under each of its label folders.
- Notes → bookmark descriptions.
