Scenario ID: SCN-013
Title: Select multiple bookmarks and act on them together
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Each card has a quiet, always-visible checkbox. Selecting one or more bookmarks
reveals a group action bar showing the count. The available group actions are:
add tags, remove tags, mark as read, mark unread, archive, and delete. In the
Archived view the archive action is replaced by restore.

The bar also offers "Select all N matching", which extends the selection to every
bookmark in the current filtered view — respecting the active tab, search, and tag
together, and never reaching into another view.

Bulk delete asks for a single clear confirmation ("Delete N bookmarks
permanently?") before removing. The bulk add/remove tag boxes offer existing-tag
suggestions: "add" suggests all existing tags (guarding against near-duplicates);
"remove" suggests only the tags present on the selected bookmarks.

## Gherkin
Feature: Bulk actions

  Scenario: Select several and act together
    Given several bookmarks are selected via their checkboxes
    Then a group action bar shows the selected count
    And the client can add tags, remove tags, mark read, mark unread, archive,
        or delete all of them at once

  Scenario: Select all matching the current filter
    Given a search, tag, or tab is narrowing the list
    When the client chooses "Select all N matching"
    Then every bookmark in that filtered view is selected
    And the selection never includes bookmarks from other views

  Scenario: Archived view offers restore
    Given the Archived view is active with bookmarks selected
    Then the group action offers restore instead of archive

  Scenario: Bulk delete is confirmed
    When the client chooses to delete the selected bookmarks
    Then a single "Delete N bookmarks permanently?" confirmation is shown
    And confirming removes them all; cancelling keeps them

  Scenario: Tag suggestions in bulk boxes
    When the client adds tags in bulk
    Then existing tags are suggested to avoid near-duplicates
    When the client removes tags in bulk
    Then only tags present on the selected bookmarks are suggested

## Assumptions
- Checkboxes are always visible but visually quiet (client-confirmed).
- "Select all matching" = current tab + search + tag; never cross-view (client-confirmed).
- Applying a group action clears the selection afterwards.
