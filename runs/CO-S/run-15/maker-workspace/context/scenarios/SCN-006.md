Scenario ID: SCN-006
Title: Saving a duplicate link takes the client to the existing bookmark
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When the client saves a link whose web address matches one already saved, no
second copy is created. Instead the app clears any active search/filter, shows a
highlighted message ("This link is already saved — here it is, ready to edit"),
scrolls to the existing bookmark, briefly flashes it, and opens its title for
editing so the client can adjust the existing entry instead of duplicating it.

## Gherkin
Feature: Duplicate link handling

  Scenario: Save a link that already exists
    Given a link with a given web address is already saved
    When the client saves the same web address again
    Then no new copy is created
    And any active search or filter is cleared so the existing item is visible
    And the app scrolls to and highlights the existing bookmark
    And the existing bookmark's title is opened for editing
    And a message states the link is already saved

## Assumptions
- Two links are "the same" when they have the same (normalised) web address.
- The existing entry, not the new attempt, is what the client is taken to.
