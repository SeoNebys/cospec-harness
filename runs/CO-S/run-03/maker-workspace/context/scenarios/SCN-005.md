Scenario ID: SCN-005
Title: Add a personal note to a bookmark
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A person can add or change a personal note through the bookmark's existing
inline details editor. After saving, the personal note remains visibly attached
to the bookmark in its own labelled area, separate from the automatically
gathered summary.

## Gherkin
Feature: Personal bookmark notes

  Scenario: Add a personal note through inline editing
    Given a saved bookmark has an automatic summary and no personal note
    When the person opens its inline details editor
    And enters a personal note
    And saves the changes
    Then the note is shown on that bookmark
    And the note is labelled as the person's note
    And the note is visually separate from the automatic summary

## Assumptions
- Personal notes use the same inline editor as title and summary corrections.
- A saved personal note remains visible on the bookmark in the library.
- Each bookmark has one personal note field.
