Scenario ID: SCN-039
Title: Reopen a saved search against the current collection
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Selecting a saved search reruns its stored query against the collection as it exists now. Newly saved matching bookmarks appear automatically, so the saved search remains a living one-click shortcut rather than a frozen list.

## Gherkin
Feature: Saved searches

  Scenario: Reopen a saved search after a new bookmark matches it
    Given "Pasta weekends" stores the query "pasta AND #weekend"
    And two bookmarks matched when the search was saved
    And a third matching bookmark was added later
    When the person selects "Pasta weekends"
    Then the stored query runs against the current collection
    And all three current matching bookmarks appear
    And the new bookmark is included without editing the saved search

## Assumptions
- Saved searches are rerun on demand rather than maintained as copied result sets.
- Normal search rules, including archive exclusion, apply when rerunning a saved search.
