Scenario ID: SCN-001
Title: Save a link with auto-filled details and personal context
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The user pastes a link and saves it. The app looks up the page and pre-fills the
title, description, page icon, and a preview image. The user can correct the
title and description, add tags, and write a longer personal note with simple
formatting (bold, bullet lists, safe links). On confirming, the bookmark appears
in the saved list showing its icon, preview thumbnail, title, address,
description, note (formatted), and tags. The user does not need to edit the
collected icon or preview image.

## Gherkin
Feature: Save a bookmark

  Scenario: Save a new link with auto-filled metadata
    Given the user has an address that is not yet saved
    When the user pastes the address and starts saving
    Then the app pre-fills the title, description, page icon, and preview image
    And the user can edit the title and description
    And the user can add tags and a formatted personal note
    When the user confirms the save
    Then the bookmark is added to the saved list
    And it shows its icon, preview, title, address, description, note, and tags

  Scenario: Formatted note renders safely
    Given a note contains **bold**, "- " bullet lines, and [text](https URL) links
    When the bookmark is displayed
    Then bold, bullet lists, and clickable safe links are rendered
    And any other content is shown as plain text (no unsafe markup)

## Assumptions
- Icon and preview are collected automatically from the page; not hand-edited.
- Only http/https links render as clickable in notes.
- Tags are entered as a comma-separated list.
