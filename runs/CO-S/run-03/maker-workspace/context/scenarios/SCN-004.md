Scenario ID: SCN-004
Title: Narrow the bookmark library by tag
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
All tags used in the library are visible in a tag bar above the bookmark list.
Choosing a tag narrows the list to bookmarks with that tag and makes the active
filter clear. Clearing the filter restores the full bookmark list.

## Gherkin
Feature: Filtering bookmarks by tag

  Scenario: Show bookmarks for one tag
    Given the library contains bookmarks with different tags
    And all tags used in the library are shown above the bookmark list
    When the person chooses one tag from the tag bar
    Then only bookmarks with that tag are shown
    And the chosen tag is visibly identified as the active filter

  Scenario: Clear the active tag filter
    Given the bookmark list is narrowed to one tag
    When the person clears the tag filter
    Then all bookmarks are shown again

## Assumptions
- The tag bar shows every tag currently used by at least one bookmark.
- Only one tag is selected at a time in this flow.
- The tag bar appears above the bookmark list.
