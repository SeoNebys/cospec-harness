Scenario ID: SCN-014
Title: Display controls — sort, amount shown, text size, and a saved default
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The list offers display controls that always respect the current search / tag /
view filters:
- Sort order: Newest first, Recently updated, Oldest first, Title A–Z, Title Z–A.
  "Recently updated" reflects changes to a bookmark's content or organisation
  (title, address, description, note, or tags). Marking read/unread or
  archiving/restoring does NOT count as an update and does not reshuffle the list.
- Amount shown at once (e.g. 10 / 25 / 50 / All); when more match than are shown,
  a "Show more" control reveals the next batch and states how many remain
  (load-more, not numbered pages).
- Text size can be increased or decreased for reading comfort.
- "Set as my default" remembers the current sort, amount shown, and text size
  together, so they are restored on return.

## Gherkin
Feature: Display controls

  Scenario: Sort orders
    Given saved bookmarks
    When the client chooses a sort order
    Then the (filtered) list is ordered accordingly

  Scenario: Recently updated reflects content/organisation edits only
    Given a bookmark
    When its title, address, description, note or tags change
    Then its "updated" time advances (so "Recently updated" brings it to the top)
    And marking it read/unread or archiving/restoring does not change its order
        under "Recently updated"

  Scenario: Amount shown with load-more
    Given more bookmarks match than the chosen amount
    Then only that many are shown with a "Show more" control stating how many remain
    And "Show more" reveals the next batch

  Scenario: Text size
    When the client increases or decreases text size
    Then the list text scales accordingly

  Scenario: Save default
    When the client sets the current sort, amount and text size as default
    Then those settings are restored when the client returns

## Assumptions
- Load-more rather than numbered pages (client confirmed).
- Sort, amount, and text size are remembered together via an explicit "Set as my
  default" (client confirmed).
- Sorting/paging respect the active filters.
