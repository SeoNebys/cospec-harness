Scenario ID: SCN-006
Title: Edit a saved bookmark
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Every bookmark card has an Edit action. Editing opens a form where the user can
change the address, title, description, tags, and note; changes update the
bookmark in place. Opening the existing bookmark from a duplicate warning lands
on this same edit form. If the user changes the address to one that already
belongs to another bookmark, the change is blocked (no duplicates). The user does
not edit the icon/preview manually.

## Gherkin
Feature: Edit a bookmark

  Scenario: Edit details in place
    Given a saved bookmark
    When the user edits its address, title, description, tags, or note and saves
    Then the bookmark is updated in place

  Scenario: Open existing-from-duplicate lands on the edit form
    Given a duplicate-save warning is shown for an existing bookmark
    When the user chooses to open the one they already have
    Then that bookmark opens in the edit form

  Scenario: Editing an address into a collision is blocked
    Given two bookmarks with different addresses exist
    When the user edits one address to equal the other's address
    Then the change is blocked and the bookmark is not updated

## Assumptions
- Editable fields: address, title, description, tags, note (not icon/preview).
