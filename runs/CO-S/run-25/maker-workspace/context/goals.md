# Business goal

## Cycle 1 — Session date: 2026-09-26

### Client's request (verbatim)
"I want to build an app to save and manage bookmarks."

"Right now my bookmarks become a cluttered pile, so I often can't find something
when I need it—or I forget why I saved it.

The bigger goal is a dependable personal library of useful links. I want to save
a page quickly, organize it with tags and notes, search it easily later, keep a
clear reading list, and archive things I want to retain without leaving them in
my everyday view. It would also be reassuring to preserve a copy in case the
original page changes or disappears."

"I picture it as a web app I can use in my browser, with a clear, readable layout
that works well for everyday use."

### Confirmed goal statement
A dependable personal library of useful links. The core value is trust —
anything saved is findable later and never lost, and clutter never gets in the
way.

Capabilities the client expressed:
- Save a page quickly
- Organize with tags and notes
- Search and find easily later
- Keep a clear reading list (things to get to)
- Archive things to retain without leaving them in the everyday view
- Preserve a copy in case the original page changes or disappears

### Interface form
Web app used in the browser, with a clear, readable layout for everyday use.

### Status
Goal confirmed by client on 2026-09-26.
