Type: Happy Path

## Approved behaviour

The user can import a browser bookmarks export file (Chrome/Firefox/Safari/Edge
HTML). Before importing, a **preview** shows how many bookmarks and folders were
found, the **folder → tag** mapping, and how many links are already saved.

Options (with sensible defaults):
- **Add each folder name as a tag** (default on) — matches the user's tag-based
  organization.
- **Skip links already saved** (default on) — avoids duplicates.

Import **preserves each bookmark's original title, its original date added, and
any per-link tags** carried in the file's standard `TAGS` field (added alongside
the folder tag). Imported bookmarks therefore keep their real history rather than
all appearing as saved today. Missing details are filled in automatically where
possible.

## Gherkin
Feature: Import browser bookmarks

  Scenario: Preview before import
    When the user chooses a browser bookmarks file
    Then a preview shows the count, folders, folder→tag mapping and duplicate count

  Scenario: Folders become tags by default
    Given "add folder name as a tag" is on
    When the user imports
    Then each imported bookmark is tagged with its folder name

  Scenario: Skip duplicates by default
    Given "skip links already saved" is on
    When the user imports
    Then links already in the library are not duplicated

  Scenario: Preserve original title, date and tags
    When bookmarks are imported
    Then each keeps its original title and original date added
    And any per-link tags from the file are applied in addition to the folder tag
    And imported bookmarks do not all show today's date

## Assumptions
- Import format is the standard Netscape bookmarks HTML (ADD_DATE, TAGS).
- Folder→tag and skip-duplicates are toggleable, defaulting on.
