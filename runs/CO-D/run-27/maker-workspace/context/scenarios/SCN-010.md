Title: Saved views (named search + tag include/exclude + filter + sort), live
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A saved view has a name and remembers: the free-text search (words/phrases; manual
#tag / NOT #tag still allowed), an explicit set of Include tags, an explicit set of
Exclude tags, the list filter (All/To read/Read/Archived), and the sort order. The
Save-view dialog provides separate Include-tags and Exclude-tags pickers that use the
same existing-tag suggestions as the bookmark editor, and shows a live summary of
exactly what will be saved. Views appear as named chips; clicking one restores its
search, tag include/exclude, filter, and sort in one click, and each opening
recomputes the matches live (newly saved links that match appear automatically —
the list is not frozen). A bookmark matches a view's tag rules when it has ALL
included tags and NONE of the excluded tags. When a view with tag filters is open, a
bar shows the active Including/Excluding tags with a one-click Clear. Views persist
and can be deleted from their chip.

## Gherkin
Feature: Saved views

  Scenario: Save a view with explicit include/exclude tags
    Given a search, filter and sort are set
    When the client opens Save view, adds Include and Exclude tags via the pickers, names it, and saves
    Then a named view chip appears remembering search, include tags, exclude tags, filter and sort

  Scenario: Open a view restores everything and computes live
    Given a saved view
    When the client clicks its chip
    Then the search, include/exclude tags, filter and sort are restored
    And only bookmarks with all included tags and none of the excluded tags (and matching search/filter) are shown
    And an active-tags bar shows the include/exclude tags with a Clear option
    When a new matching bookmark is later added and the view is reopened
    Then the new bookmark appears automatically

  Scenario: Delete a view
    When the client removes a view via its chip
    Then the view no longer appears

## Assumptions
- Include = must have all; Exclude = must have none.
- Tag choices can also be expressed manually in search; both coexist.
