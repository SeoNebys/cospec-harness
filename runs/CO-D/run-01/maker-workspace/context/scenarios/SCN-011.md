Scenario ID: SCN-011
Title: Open the original page from a bookmark card
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The main body of a bookmark card is a large, forgiving target for opening the saved original page. A visible Open original cue makes that destination clear. The page opens in a new browser tab so the collection remains available. The dedicated Read later toggle and three-dot action menu are independent controls and do not open the page when selected.

## Gherkin
Feature: Open an original bookmarked page

  Scenario: Open the original from the card body
    Given a saved bookmark card is visible
    When the person selects the card body outside its dedicated controls
    Then the original saved page opens in a new browser tab
    And the bookmark collection remains open in its current tab

  Scenario: Use a card control without opening the original
    Given a saved bookmark card is visible
    When the person selects its Read later toggle or three-dot action menu
    Then that control performs its own action
    And the original page is not opened

## Assumptions
- The card includes a visible Open original cue.
- The card's main body is clickable, rather than only its title.
- Original pages open in a new tab.
