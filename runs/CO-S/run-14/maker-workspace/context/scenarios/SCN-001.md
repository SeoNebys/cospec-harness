Scenario ID: SCN-001
Title: Save a link and have its details filled in automatically
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

From the main "My Bookmarks" screen there is a single box at the top. The user
pastes a link into it and presses Save. The new item appears immediately at the
**top** of the saved list (newest first). While details are being gathered the
item briefly shows a "Getting details…" state, then it fills in automatically
with:
- the page **title**
- a short **description** (one to two sentences, sized for scanning)
- the **site icon**
- a **preview image**, shown only when the page has one; when none is available
  no thumbnail is shown and the layout stays clean

Each saved item also shows the site name, when it was saved, and the link itself.
The link is shown small and subdued so it does not distract from the title,
description and icon, while remaining accessible.

The client approved this saving + automatic-details behaviour, including
newest-at-top ordering and the single paste-and-Save interaction.

## Gherkin
Feature: Save a link with automatic details

  Scenario: Save a link whose page has a preview image
    Given the user is on the My Bookmarks screen
    When the user pastes a link into the save box and presses Save
    Then a new item appears at the top of the saved list
    And it briefly shows a "getting details" state
    And it is then filled in with the page title, a short description, the site icon and a preview image
    And the link is shown in a subdued style

  Scenario: Save a link whose page has no preview image
    Given the user is on the My Bookmarks screen
    When the user saves a link for a page that has no preview image
    Then the new item is filled in with title, description and site icon
    And no thumbnail image is shown for that item

  Scenario: Newest saved item appears first
    Given the saved list already contains items
    When the user saves a new link
    Then the new item appears above all existing items

## Assumptions
- Saving is done by pasting a link and pressing Save (single input method).
- Ordering is newest-first.
- Description is a short 1–2 sentence summary.
- Automatic details (title, description, icon, preview) are gathered by the
  system after saving; the preview is optional/conditional on availability.
