Scenario ID: SCN-011
Title: Finish the last item in Read later
Type: Edge Case
Approval status: approved
Approval session: SESSION-011
Approval cycle: 1

## Approved behaviour
When the client marks the final Read later item as read, the focused list becomes a friendly all-caught-up state. The Read later count becomes zero while the main collection count remains unchanged, reinforced by a confirmation that the bookmark is still in the collection. A prominent action returns directly to all bookmarks.

## Gherkin
Feature: Empty Read later state

  Scenario: Mark the final waiting bookmark as read
    Given exactly one bookmark remains in Read later
    When the user marks it as read
    Then Read later shows an all-caught-up state
    And the Read later count becomes zero
    And the main collection count remains unchanged
    And the app confirms that the bookmark remains in the collection
    And an action offers to browse all bookmarks

## Assumptions
- Finishing a Read later item changes only its Read later status.
- The empty state uses positive completion language.
