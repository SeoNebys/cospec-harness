Scenario ID: SCN-012
Title: Prevent an unrecognizable untitled bookmark
Type: Error Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
If the title is erased during editing, saving is blocked. The inline editor
stays open and explains that a title is needed to recognize the bookmark.
The automatic summary and personal note may be empty.

## Gherkin
Feature: Editing bookmark details safely

  Scenario: Try to save a blank title
    Given a bookmark's inline details editor is open
    When the person erases the title and tries to save
    Then the changes are not saved
    And the inline editor remains open
    And a message explains that the bookmark needs a recognizable title

  Scenario: Save with an empty summary and note
    Given a bookmark has a non-empty title
    And its summary and personal note are empty
    When the person saves the details
    Then the changes are saved

## Assumptions
- Every bookmark must have a non-empty title.
- Summary and personal note are optional.
