Scenario ID: SCN-013
Title: Require all terms and labels in a search
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A person can explicitly combine terms and labels with AND so that only bookmarks satisfying every required condition appear. The result explains that all conditions were met.

## Gherkin
Feature: Precise bookmark search

  Scenario: Require text and both named labels
    Given one pasta bookmark carries both "Cooking" and "Weekend"
    And other pasta bookmarks carry only one of those labels
    When the person searches for "pasta AND #cooking AND #weekend"
    Then only the pasta bookmark carrying both labels appears
    And the result explains that the text and both required labels matched

## Assumptions
- Explicit AND overrides the default OR treatment of multiple labels.
- Operators and labels ignore capitalization.
