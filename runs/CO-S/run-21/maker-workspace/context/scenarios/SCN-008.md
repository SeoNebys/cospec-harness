Scenario ID: SCN-008
Title: Search across all meaningful bookmark text
Type: Happy Path
Approval status: approved
Approval session: SESSION-008
Approval cycle: 1

## Approved behaviour
Search narrows the collection as the person types and looks across bookmark titles, descriptions, personal notes, and URLs rather than titles alone. The results show a matching count. When a match comes from a normally hidden field such as a personal note or URL, the result identifies that field and shows the matching content.

## Gherkin
Feature: Search the bookmark collection

  Scenario Outline: Find a bookmark from any searchable field
    Given a saved bookmark contains the text "<text>" in its <field>
    And no other bookmark contains that text in a searchable field
    When the person types "<text>" in search
    Then the collection narrows to that bookmark
    And the result count shows one bookmark
    And the result identifies the matching <field> when that field is normally hidden

    Examples:
      | field       | text     |
      | title       | calmer   |
      | description | habits   |
      | note        | workshop |
      | URL         | workbench.example |

## Assumptions
- Search responds as the person types without a separate submit action.
- Search matching is not case-sensitive.
- Notes and URLs may need a visible match explanation because they are not otherwise prominent on the card.
