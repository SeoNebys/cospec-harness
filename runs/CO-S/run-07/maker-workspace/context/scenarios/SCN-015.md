Title: Explain an empty Read later view
Type: Edge Case
Approval status: approved
Approval session: SESSION-015
Approval cycle: 1

## Approved behaviour
When the library contains bookmarks but none are marked for later, the Read later view shows a zero count and a helpful empty state instead of a blank list. It explains how bookmarks are added there, reassures the user that the full library still exists, and offers one action that returns to All bookmarks.

## Gherkin
Feature: Handle an empty Read later view

  Scenario: Return from an empty Read later view
    Given the library contains bookmarks
    And none are marked to read later
    When the user switches to the Read later view
    Then the view shows a count of zero
    And explains that bookmarks appear there when marked with Read later
    And makes clear that the full library still exists
    And offers a Show all bookmarks action
    When the user chooses to show all bookmarks
    Then the All bookmarks view is restored

## Assumptions
- This state differs from a completely empty library because existing bookmarks remain in All bookmarks.
