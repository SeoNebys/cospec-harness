Scenario ID: SCN-016
Title: Select bookmarks and act on them in bulk
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Each bookmark has a selection checkbox. When one or more are selected, a bulk
action bar shows the count and offers: add tags, remove tags, mark "To read",
mark finished, archive, and delete. In the Archived view, the bulk actions are
Restore and Delete permanently instead. Bulk delete asks for a single
confirmation. A "Select all in this view" control selects exactly the bookmarks
currently shown — the current tab filtered by the active search — and never
bookmarks outside that scope (e.g. archived/hidden items).

## Gherkin
Feature: Bulk actions

  Scenario: Act on a manual selection
    Given several bookmarks are selected
    When the client chooses a bulk action (add/remove tags, mark to-read,
         mark finished, archive)
    Then the action is applied to all selected bookmarks

  Scenario: Bulk delete confirmation
    Given several bookmarks are selected
    When the client chooses bulk delete
    Then the app asks for a single confirmation
    And on confirmation all selected bookmarks are permanently removed

  Scenario: Select all in the current view/search
    Given a tab and/or search filter showing a subset of bookmarks
    When the client chooses "Select all in this view"
    Then exactly the currently shown bookmarks are selected
    And bookmarks outside the current filter (including archived) are not selected

  Scenario: Archived selection actions
    Given selected bookmarks in the Archived view
    Then the offered bulk actions are Restore and Delete permanently

## Assumptions
- Selection is by per-item checkbox; "select all in view" scopes to filtered
  results only.
