Scenario ID: SCN-005
Title: Mark a link to read later and view the reading list
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

Each link has a "Read later" toggle. Clicking it marks the link to read (shown as
"★ Marked to read" with a subtle highlight on the card). A marked link remains in
the "All" view and also appears under a "To read" tab. Tabs (All / To read) at
the top switch which links are shown, each with a live count. Search filters
within the currently selected tab only. Clicking the marked button again clears
the mark, which removes the link from the "To read" list — the client confirmed
this is how they would indicate they have finished reading it.

## Gherkin
Feature: Read later

  Scenario: Mark a link to read later
    Given a link that is not marked to read
    When the client clicks its "Read later" toggle
    Then the link is marked to read
    And it still appears in the "All" view
    And it also appears under the "To read" tab
    And the "To read" count increases by one

  Scenario: View only the reading list
    Given some links are marked to read
    When the client selects the "To read" tab
    Then only links marked to read are shown

  Scenario: Search stays within the current tab
    Given the client is on the "To read" tab
    When the client types a search word
    Then only marked links that match the word are shown

  Scenario: Mark as read (unmark) removes it from the reading list
    Given a link is marked to read
    When the client clicks the marked toggle again
    Then the link is no longer marked
    And it disappears from the "To read" tab
    And it remains in the "All" view

## Assumptions
- "Read later" is a per-link marker (overlay), not a move out of the main list.
- View switching is via tabs (All / To read) with counts.
- Search operates within the currently selected tab.
