Approval cycle: 1

## Approved behaviour

The user can export their bookmarks in one of two formats:
- **Browser bookmarks file (.html)** — re-importable into any browser; records
  each link's **title, original date added (ADD_DATE), and tags (TAGS)** so that
  information is preserved for other browsers or a re-import here.
- **Full backup (.json)** — the richer format that includes everything the app
  knows: tags, notes, and read-later / archive state, so the whole library can be
  restored.

The two serve distinct needs: the browser file for **moving links**, the full
backup for **restoring the app's richer information**.

## Gherkin
Feature: Export bookmarks

  Scenario: Export a browser-compatible file
    When the user exports as a browser bookmarks file
    Then a file is downloaded that records each link's title, date added and tags

  Scenario: Export a full backup
    When the user exports as a full backup
    Then a file is downloaded that includes tags, notes and read-later/archive state

## Assumptions
- Browser file uses the standard bookmarks HTML format.
- Full backup preserves all app-specific fields for restore.
