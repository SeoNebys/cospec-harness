Scenario ID: SCN-014
Title: Change a bookmark's saved URL, optionally refreshing details
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

In a bookmark's edit panel there is a **Link (URL)** field so the saved address
can be changed. Alongside it is an **optional** choice: "Update title, description
& preview from this link." When the URL is changed and that option is selected,
the automatic details are re-gathered from the new link; when it is not selected,
the user's existing title/description/wording are kept as-is. The choice is made
each time (not always, not never), because sometimes the user wants the fresh page
details and sometimes wants to keep their own wording.

## Gherkin
Feature: Change a saved URL

  Scenario: Change URL and refresh details
    Given the user is editing a bookmark
    When the user changes the Link (URL) and chooses to update details from it
    And presses Done
    Then the bookmark's address is updated
    And its title, description and preview are re-gathered from the new link

  Scenario: Change URL and keep existing wording
    Given the user is editing a bookmark
    When the user changes the Link (URL) and does not choose to update details
    And presses Done
    Then the bookmark's address is updated
    And its existing title, description and note are unchanged

## Assumptions
- The refresh option only takes effect when the URL actually changed.
