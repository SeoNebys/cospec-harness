Scenario ID: SCN-016
Title: Keep unusually detailed bookmark cards compact
Type: Edge Case
Approval status: approved
Approval session: SESSION-016
Approval cycle: 1

## Approved behaviour
When a bookmark has an unusually long title, description, website address, or many tags, its card remains compact by default so the library is easy to scan. The card indicates that more tags exist and offers Show full details. Expanding reveals all content without opening the website; it can be collapsed again. Compacted content remains fully searchable and editable.

## Gherkin
Feature: Display unusually detailed bookmarks

  Scenario: Expand and collapse a long bookmark card
    Given a saved bookmark has a very long title, description, address, and many tags
    When the library displays the bookmark
    Then its card shows a compact preview
    And indicates when additional tags are hidden
    And all compacted content remains searchable and editable
    When the user selects Show full details
    Then the card reveals the full title, description, address, and every tag
    And the original website does not open
    When the user selects Show less
    Then the card returns to its compact preview

## Assumptions
- Compacting content does not alter the stored bookmark details.
- The expand control is separate from the action that opens the original website.
