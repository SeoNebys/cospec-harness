Scenario ID: SCN-001
Title: Save a new bookmark with automatically fetched page details
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A person pastes a new web address. The app automatically fetches and previews the page title and description before saving. When the person saves, the bookmark appears in the bookmark list with its title, description, and site. The save entry is cleared and the person remains on the bookmark list.

## Gherkin
Feature: Saving bookmarks

  Scenario: Save a new web address with fetched details
    Given the bookmark list is empty
    When the person pastes a new web address
    Then the app fetches and previews the page title and description
    When the person saves the bookmark
    Then the bookmark appears in the bookmark list with its title, description, and site
    And the save entry is cleared
    And the person remains on the bookmark list

## Assumptions
- The fetched title and description are previewed before saving.
- Saving returns the person to the bookmark list.
- The pasted address is valid, reachable, and has fetchable page details.
- The address has not already been saved.
