Scenario ID: SCN-017
Title: Undo removal of the last bookmark
Type: Edge Case
Approval status: approved
Approval session: SESSION-017
Approval cycle: 1

## Approved behaviour
Removing the only bookmark changes the collection count to zero and shows the friendly empty-collection state while the eight-second Undo remains available. Choosing Undo restores the bookmark and returns the count to one.

## Gherkin
Feature: Managing saved bookmarks

  Scenario: Remove and restore the only bookmark
    Given the collection contains exactly one bookmark
    When the person removes that bookmark
    Then the collection count becomes zero
    And the friendly empty-collection state is shown
    And Undo remains available
    When the person chooses Undo
    Then the bookmark is restored
    And the collection count returns to one
    And the empty-collection state is no longer shown

## Assumptions
- The standard empty-collection state is shown even while removal can still be undone.
- The Undo window is eight seconds, as approved in SCN-010.
