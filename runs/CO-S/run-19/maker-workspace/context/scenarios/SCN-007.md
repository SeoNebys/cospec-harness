Scenario ID: SCN-007
Title: Move a bookmark through the Read later queue
Type: Happy Path
Approval status: approved
Approval session: SESSION-007
Approval cycle: 1

## Approved behaviour

A direct Read later button on each bookmark lets the client add it to a temporary reading queue in one click. The Read later section shows only bookmarks that are still pending. Marking an item as read removes it from that queue but keeps the bookmark safely available in All bookmarks. This action is distinct from deletion.

## Gherkin

Feature: Read bookmarks later

  Scenario: Add a bookmark to the reading queue
    Given a bookmark is visible in All bookmarks
    And it is not currently in Read later
    When the user selects the bookmark's direct "Read later" action
    Then the bookmark appears in the Read later queue
    And the Read later count increases

  Scenario: Finish reading without deleting the bookmark
    Given a bookmark is in the Read later queue
    When the user opens Read later
    Then the queue shows the pending bookmark
    When the user marks the bookmark as read
    Then it is removed from the Read later queue
    And it remains available in All bookmarks

## Assumptions

- Read later is a temporary status rather than a separate copy of the bookmark.
- The direct Read later action is visible on each bookmark card.
- Marking an item as read does not archive or delete it.
