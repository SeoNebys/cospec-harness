Scenario ID: SCN-017
Title: Keep unusually long bookmark details usable
Type: Edge Case
Approval status: approved
Approval session: SESSION-017
Approval cycle: 1

## Approved behaviour
An unusually long title is limited to two visible lines in the collection and
an unusually long description is limited to one visible line, keeping the list
scannable. The complete title and description remain stored and are visible and
editable in the bookmark's Edit view.

## Gherkin
Feature: Display bookmark details

  Scenario: View and edit unusually long details
    Given a bookmark has an unusually long title and description
    When the person views it in the collection
    Then the visible title is limited to two lines
    And the visible description is limited to one line
    When the person opens Edit
    Then the complete title and description are available
    And no stored text has been truncated

## Assumptions
- Visual truncation in the collection never changes stored bookmark details.
