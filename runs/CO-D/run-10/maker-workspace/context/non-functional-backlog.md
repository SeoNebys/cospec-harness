# Non-functional backlog

- Keep the visible "View details & note" action on every bookmark card visually calm so it does not compete with the preview picture and title or make a long library feel busy.
- Live search should continue narrowing results without a perceptible delay as the personal library grows.
- Keep the Sort control compact beside the result count; the user prefers a dropdown because sorting is changed infrequently.
- Keep ordinary bookmark cards free of checkboxes and batch controls until the user deliberately enters the temporary selection mode.
- Keep import and export in the compact Library tools menu beside Save a link; the everyday sidebar should remain focused on browsing, Read later, Archive, and labels.
- If it remains simple to support, typed search shortcuts such as `#label` and quoted phrases may complement the visible Search options controls, but they must not replace or complicate the chosen visible controls.
