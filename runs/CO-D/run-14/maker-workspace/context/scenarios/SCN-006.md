Scenario ID: SCN-006
Title: Combine broad text with either of two specific tags
Type: Happy Path
Approval status: approved
Approval session: SESSION-006
Approval cycle: 1

## Approved behaviour
The client can express a combined search in one typed request. A search for bookmarks that mention Rome and have either the articles tag or the books tag returns only bookmarks satisfying both the broad-text portion and at least one of those specific tag criteria. The search interface makes its interpretation visible, and tag criteria target tags rather than the same words appearing elsewhere.

## Gherkin
Feature: Combine bookmark search criteria

  Scenario: Combine broad text with either of two tags
    Given the library contains bookmarks with varied text and tags
    When the client searches for bookmarks that mention "Rome"
    And specifies either the tag "articles" or the tag "books"
    Then every result contains "Rome" in a broadly searchable field
    And every result has the exact tag "articles" or the exact tag "books"
    And a bookmark matching only one side is excluded

## Assumptions
- The combined search is written in one search field rather than assembled from a permanently visible tray of tag toggles.
- The site displays how it interpreted a combined search.
- Tag criteria match tag names specifically and do not match the same word in descriptions, notes, titles, or addresses.
