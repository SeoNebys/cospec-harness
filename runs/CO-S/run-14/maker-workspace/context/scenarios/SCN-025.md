Scenario ID: SCN-025
Title: Notes support Markdown, displayed formatted
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

A bookmark's note is written and edited as **Markdown** and **displayed
formatted** when viewing. Supported formatting includes headings, bold, italic,
inline code and code blocks, bullet and numbered lists, links, and block quotes.
Editing a note returns the **raw Markdown** to change (not the formatted view).
Text that is not valid Markdown simply appears as plain text. For safety, any
raw HTML pasted into a note is shown as **text, not executed**, and only
http/https links become clickable.

## Gherkin
Feature: Markdown notes

  Scenario: View a note formatted
    Given a note contains Markdown
    When the bookmark is viewed
    Then the note is shown with the Markdown rendered (headings, bold, italic, lists, links, code, quotes)

  Scenario: Edit returns raw Markdown
    Given a note is shown formatted
    When the user edits it
    Then the raw Markdown text is presented for editing

  Scenario: Plain text stays plain
    Given a note has no Markdown syntax
    Then it is shown as plain text

  Scenario: HTML is not executed
    Given a note contains raw HTML
    Then the HTML is shown as text and not executed
    And only http/https links are made clickable

## Assumptions
- A safe subset of Markdown is supported; unknown syntax renders as text.
