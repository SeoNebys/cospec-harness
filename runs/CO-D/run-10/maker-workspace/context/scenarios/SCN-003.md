Scenario ID: SCN-003
Title: Organize a bookmark with personal labels
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Labels are managed alongside a bookmark's title and description. The user types directly to add a label. As they type, matching labels already in the library appear and are clearly identified for reuse. An exact label entered with different capitalization reuses the existing label rather than creating a near-duplicate. A bookmark can have multiple labels, and removing one selected label leaves the others intact. After saving, the assigned labels appear on the bookmark's library card.

## Gherkin
Feature: Organize bookmarks with labels

  Scenario: Reuse a matching existing label
    Given the library already has a label named "architecture"
    And the user is editing a bookmark's details
    When the user types part of that label in the label field
    Then the existing label appears as a matching suggestion
    When the user chooses that suggestion
    Then "architecture" appears as a selected label on the bookmark

  Scenario: Prevent a case-only label duplicate
    Given the library already has a label named "architecture"
    When the user enters "Architecture" as a label
    Then the existing "architecture" label is assigned
    And no second label differing only by capitalization is created

  Scenario: Assign more than one label
    Given a bookmark already has the "architecture" label selected
    When the user adds the "History" label
    Then both labels appear as selected on the bookmark

  Scenario: Remove one selected label
    Given a bookmark has "architecture" and "History" selected
    When the user removes "History"
    Then "History" is no longer selected
    And "architecture" remains selected

  Scenario: See assigned labels on a saved bookmark
    Given the bookmark has "architecture" selected
    When the user saves the bookmark changes
    Then the bookmark card appears in the library
    And the card shows the "architecture" label

## Assumptions
- Labels are managed on the same details screen as the bookmark title and description.
- Typing a label and pressing Enter is the primary assignment method.
- Matching suggestions are based on labels already used in the personal library.
