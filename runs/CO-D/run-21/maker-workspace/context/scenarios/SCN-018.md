Title: Preferences (default sort, page size, text size)
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The user can set preferences: default sort (newest first / oldest first / title
A–Z / Z–A), number displayed per page (10 / 20 / 50 / 100), and text size (Small /
Normal / Large). Changes take effect immediately and are remembered across
sessions, including on returning to the default list. The default sort seeds the
list order and the Sort control; the page size drives paging and "Load more"; the
text size adjusts overall reading size.

## Gherkin
Feature: Preferences

  Scenario: Change preferences takes immediate effect
    When the user changes default sort, page size, or text size and saves
    Then the list updates immediately to reflect them

  Scenario: Preferences persist across sessions
    Given the user has set preferences
    When the user returns later (including to the default list)
    Then the saved preferences are still in effect
