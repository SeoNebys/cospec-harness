Scenario ID: SCN-012
Title: Act on several bookmarks at once — Select mode, select-all, reversible bulk actions, guarded bulk delete
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The client can act on many bookmarks at once without touching them one by one.

Entering selection ("clean until I ask"):
- A "Select" button switches on selection mode. Only then do checkboxes appear and a
  tap on a card ticks it (instead of visiting). "Done" leaves the mode and restores
  the clean, visit-first list. (Style chosen over always-visible checkboxes, which
  would clutter the everyday view.)
- "Select all" picks the entire currently shown/filtered set at once (e.g. the whole
  "To read" pile), so acting on a filtered group needs no manual ticking. It toggles
  to "Clear all" when everything shown is selected.

Bulk actions (on the selected set):
- Mark read, Mark to-read (the inverse), Add label, Remove label (which lists the
  labels present on the selection so the client knows what they're stripping), Set
  aside. All are reversible and act in one confident tap, each offering a brief Undo.
- Delete is deliberately set apart (own corner, red, past a divider) and is the ONLY
  guarded one: it first asks for confirmation ("permanently delete N … can't be
  undone") AND then still offers an Undo. Two layers, because bulk delete can erase
  many things forever in one tap. Principle: friction proportional to what can be
  lost.

## Gherkin
Feature: Bulk actions on selected bookmarks

  Scenario: Select the whole filtered pile and mark it read
    Given the "To read" filter is active with several bookmarks
    When the client enters Select mode and chooses "Select all"
    And chooses "Mark read"
    Then all shown bookmarks are marked read
    And an Undo is offered

  Scenario: Reversible bulk actions offer undo
    Given several bookmarks are selected
    When the client chooses Set aside / Mark to-read / Add label / Remove label
    Then the action applies to all selected
    And an Undo is offered

  Scenario: Bulk delete is doubly guarded
    Given several bookmarks are selected
    When the client chooses Delete
    Then a confirmation appears stating the count and that it cannot be undone
    When the client confirms
    Then the bookmarks are deleted
    And an Undo is still offered afterward

## Assumptions
- Selection mode is off by default (no checkboxes on the everyday list).
- Remove-label offers only labels actually present on the selection.
