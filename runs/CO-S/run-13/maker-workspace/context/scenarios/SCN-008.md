## Approved behaviour

Each bookmark card has an "Edit" control (in All bookmarks, Read later, and
Archived). Clicking it turns the card into an edit form where the client can
change the Web address, Title, Description, Tags, and Note. "Save changes" applies
the edits and shows a "Changes saved" confirmation; "Cancel" discards them. This
is how the client corrects details after saving, including details that were
auto-filled earlier, and cleans up or relocates an address while keeping the same
bookmark.

Editing the web address:
- A missing scheme has "https://" added automatically.
- Unusable text is rejected with "That doesn't look like a web address".
- Changing to an address another bookmark already uses is blocked with a message
  (which notes if that other copy is in Read later or Archived), so no duplicates
  are created via editing.
- When the address changes, the site name and icon follow the new address. The
  app keeps the address exactly as typed (it does not strip tracking text).

## Gherkin
Feature: Editing a saved bookmark

  Scenario: Edit a bookmark's details
    Given a saved bookmark
    When I choose Edit and change its title, description, tags, or note
    And I save the changes
    Then the bookmark shows the updated details
    And a "Changes saved" confirmation is shown

  Scenario: Cancel editing
    Given I am editing a bookmark
    When I cancel
    Then the bookmark keeps its original details

  Scenario: Edit the web address
    Given I am editing a bookmark
    When I change its web address to a valid, unused address
    Then the bookmark is updated and its site name and icon follow the new address

  Scenario: Address edit collision is blocked
    Given another bookmark already uses a given address
    When I try to change this bookmark's address to that same address
    Then the change is blocked with a message and no duplicate is created
