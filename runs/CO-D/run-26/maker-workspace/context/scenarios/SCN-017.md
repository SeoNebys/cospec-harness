Scenario ID: SCN-017
Title: Import and export a standard browser bookmarks file
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
From Settings, the client can import and export a standard browser bookmarks HTML
file (the Netscape bookmark format browsers use).

Export writes the whole collection — including archived bookmarks, which are placed
in a clearly named "Archived" folder — preserving each bookmark's title, address,
tags, original saved date, and description.

Import adds bookmarks from a chosen file to the existing collection (it never
replaces it) and preserves titles, tags, original saved dates, and descriptions.
Links already present (matched by address) are skipped, so existing notes and
curated details are never overwritten. A short summary reports how many were
imported and how many were skipped. Bookmarks found in an "Archived" folder are
imported as archived, so an export/import round-trip preserves archived status.
Non-web entries are ignored.

## Gherkin
Feature: Import and export

  Scenario: Export the whole collection
    When the client exports from Settings
    Then a standard bookmarks file is produced containing every bookmark
    And archived bookmarks are placed in an "Archived" folder
    And each entry preserves title, address, tags, original saved date, and description

  Scenario: Import adds without overwriting
    When the client imports a bookmarks file
    Then new links are added to the existing collection
    And links already present (by address) are skipped, not overwritten
    And a summary reports the number imported and skipped

  Scenario: Import preserves details
    Given an imported file with titles, tags, saved dates, and descriptions
    When it is imported
    Then those details are preserved on the new bookmarks
    And bookmarks under an "Archived" folder are imported as archived

## Assumptions
- Format is the standard Netscape bookmark file (TAGS and ADD_DATE attributes,
  DD descriptions, H3 folders).
- Duplicate handling on import is skip (client-confirmed); import is additive,
  never destructive (client-confirmed).
- Export includes archived items in an "Archived" folder (client-confirmed).
