Scenario ID: SCN-010
Title: Recover from a search with no matches
Type: Edge Case
Approval status: approved
Approval session: SESSION-010
Approval cycle: 1

## Approved behaviour
The client searched for a term that matched no saved bookmark. The collection was replaced by a plain no-matches message without changing or removing any bookmark. Clearing the search immediately restored the full collection. The client confirmed this made the empty result reassuring and easy to recover from.

## Gherkin
Feature: Search bookmarks

  Scenario: Search finds no saved pages
    Given the collection contains bookmarks
    When the user enters a search term that matches none of them
    Then a plain no-matches message is shown
    And no bookmark is changed or removed

  Scenario: Clear a search with no matches
    Given a search currently has no matches
    When the user clears the search box
    Then the full collection is immediately restored

## Assumptions
- An empty search is equivalent to showing all bookmarks.
- A no-match result is a temporary view and never modifies saved data.
