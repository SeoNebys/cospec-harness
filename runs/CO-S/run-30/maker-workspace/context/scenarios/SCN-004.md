Scenario ID: SCN-004
Title: Organize a bookmark with personal labels
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Labels are optional when saving a bookmark. The client can add a personal label while saving, or add labels to an existing unlabeled bookmark later using an editor directly beneath its card. A bookmark can keep several labels at once, with each label shown as a chip rather than replacing the others. The card remains the link to the saved page.

## Gherkin
Feature: Labeling bookmarks

  Scenario: Add an optional label while saving
    Given the client is saving a new web address
    When the client enters a personal label and saves the bookmark
    Then the bookmark is saved with the enriched page details
    And the label appears as a chip on the bookmark card

  Scenario: Save without a label
    Given the client is saving a new web address
    When the client leaves the optional label blank and saves the bookmark
    Then the bookmark is saved without a label
    And the client can add a label later

  Scenario: Add a label to an existing bookmark
    Given an existing bookmark has no label
    When the client adds a label using the editor beneath its card
    Then the label appears as a chip on that bookmark
    And the bookmark card continues to open the saved page

  Scenario: Keep several labels on one bookmark
    Given a bookmark already has one label
    When the client adds another label
    Then both labels appear on the bookmark
    And the first label is not replaced

## Assumptions
- Labels are optional.
- Labels are personal text chosen by the client.
- One bookmark may have several labels.
- Label controls associated with a card do not replace the card's saved-page link.
