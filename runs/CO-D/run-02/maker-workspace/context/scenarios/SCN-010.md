Scenario ID: SCN-010
Title: Quiet saved / updated dates on each bookmark
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

Each bookmark card shows, quietly at the bottom, the date it was saved
("Saved …"). If the bookmark was later edited on a different calendar day than it
was saved, an "· Updated …" date is also shown. A quick correction made on the
same day it was saved does not add a redundant "updated today" note. The dates
are muted and unobtrusive, meant to help the client trust and place items in a
large collection without cluttering the calm layout.

## Gherkin

Feature: Saved and updated dates

  Scenario: Show the saved date
    Given a saved bookmark
    Then its card shows the date it was saved

  Scenario: Show an updated date only for a later-day edit
    Given a bookmark that was edited on a later calendar day than it was saved
    Then its card also shows the date it was updated

  Scenario: No redundant same-day updated date
    Given a bookmark edited on the same day it was saved
    Then no "updated" date is shown, only the saved date

## Assumptions
- "Updated" reflects edits to the bookmark's content (title, note, tags,
  reading-list choice) made through the edit panel.
