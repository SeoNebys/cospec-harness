Scenario ID: SCN-005
Title: Change the order the bookmark list is sorted in
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

Above the bookmark list there is a "Sort by" drop-down menu with four choices:
Newest first, Oldest first, Title A–Z, and Title Z–A. Newest first is the default.
Choosing an option immediately reorders the list. "Newest/Oldest" order by the
date the bookmark was saved. The chosen sort order stays applied while the client
also searches or filters by a tag.

## Gherkin
Feature: Sorting the bookmark list

  Scenario: Default order is newest first
    Given I have several saved bookmarks
    Then by default the list is ordered with the most recently saved first

  Scenario: Change the sort order
    Given the bookmark list is shown
    When I choose a different option in the "Sort by" menu
    Then the list is immediately reordered accordingly
      | option        | order                          |
      | Oldest first  | earliest saved first           |
      | Title A–Z     | alphabetical by title ascending |
      | Title Z–A     | alphabetical by title descending |

  Scenario: Sort order persists across search and filter
    Given I have chosen a sort order
    When I search or filter by a tag
    Then the shown results keep that sort order

## Assumptions
- Sort control is a drop-down menu with exactly these four options.
- Newest/Oldest are based on the saved date (not last-opened). (Confirmed.)
- Newest first is the default. (Confirmed.)
