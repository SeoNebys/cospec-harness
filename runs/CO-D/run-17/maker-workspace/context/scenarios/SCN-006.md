Scenario ID: SCN-006
Title: Reading/reference split via a temporary "To read" flag
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Every saved link always lives in the single library ("All"). "To read" is a
temporary unread flag; a link that is not flagged To read is treated as
Reference. When saving, the default is Reference, because most saves are keepers;
the client can instead choose "To read" in the review panel. The library offers
three views: All, To read, and Reference, each showing a count. The To read view
lists only flagged links; Reference lists everything not flagged. Marking a
To-read link as read removes it from the To read view and makes it a Reference
link, while it remains in All. Marking a Reference link "To read" moves it into
the To read view. The reading/reference state can also be changed while editing a
link. Each view has a calm empty state when it has no links.

## Gherkin
Feature: Reading list vs reference

  Scenario: Save defaults to Reference
    Given a looked-up link is in the review panel
    Then the "Reference" option is selected by default
    When the client saves it without changing the choice
    Then the link appears with a Reference badge and in the Reference and All views

  Scenario: Flag a link to read
    Given a looked-up link is in the review panel
    When the client chooses "To read" and saves
    Then the link appears in the To read view and in All

  Scenario: Marking a To-read link read moves it to Reference
    Given a link is flagged To read
    When the client marks it as read
    Then it leaves the To read view
    And it becomes a Reference link
    And it remains in the All view

  Scenario: Move a Reference link back into To read
    Given a link is a Reference link
    When the client chooses "Move to To read"
    Then it appears in the To read view

  Scenario: Change reading state while editing
    Given the client is editing a saved link
    When the client switches its choice between To read and Reference and saves changes
    Then the link's view membership updates accordingly

  Scenario: Empty To read view
    Given no links are flagged To read
    When the client opens the To read view
    Then a calm empty state is shown instead of a list

## Assumptions
- Reference is defined as "not currently flagged To read"; there is no separate
  stored "read" state distinct from Reference.
- Default reading state on save is Reference.
- The three views are All, To read, and Reference, each with a count.
