# Business goal statement

Cycle: 1
Session: SESSION-001
Status: confirmed

## The client's request (verbatim)

> My bookmarks are scattered across browsers, and once I save something it tends
> to disappear into a long, messy list. I want one calm place where I can save a
> link quickly, organise it with tags, add my own notes, and reliably find it
> again by searching what I remember about it.
>
> I'd also like a proper "read later" view so saved articles don't get mixed up
> with everything else. Once I'm done with something, I should be able to mark it
> as read or archive it without losing it. The main difference for me would be
> trusting that saved links are organised, searchable, and still available when I
> need them.

## Core goal (confirmed ranking)

The single most important outcome: **"I can always find and trust what I saved."**

Saved links are organised, searchable, and still available when needed. The
client confirmed that findability and trust are the main goal, and that the other
capabilities are means in service of that end.

## Supporting capabilities (client's language)

- Save a link quickly, without friction
- Organise with the client's own tags
- Add the client's own notes to a saved link
- Find again by searching what the client remembers about it
- A separate "read later" view so articles to read don't get tangled up with
  everything else (matters a lot, but supports the larger goal)
- Finish without losing: mark as read / archive, but keep it around

## Interface form

A web app usable from any browser. Should feel comfortable on the phone too, but
does not need to be a separate mobile app.

## Notes

- Scattered-across-browsers is the current pain; "one calm place" is the desired
  feeling.
