Scenario ID: SCN-006
Title: Filter the collection by label
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The collection shows a persistent list of labels with the number of bookmarks under each one. Selecting a label makes it visibly active and narrows the collection to bookmarks carrying that label. The person can return to all bookmarks from the same list.

## Gherkin
Feature: Finding bookmarks by label

  Scenario: Show bookmarks carrying a selected label
    Given the collection contains bookmarks with several labels
    And two bookmarks carry the label "Cooking"
    When the person selects "Cooking" from the label list
    Then "Cooking" is shown as the active label
    And only the two bookmarks carrying "Cooking" are shown

  Scenario: Return to the full collection
    Given a label filter is active
    When the person selects all bookmarks
    Then every bookmark in the collection is shown
    And no individual label is active

## Assumptions
- The label list appears beside the collection at desktop sizes.
- Each label shows its bookmark count.
- Only one label filter is active at a time.
