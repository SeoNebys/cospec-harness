Scenario ID: SCN-025
Title: Retain a saved search when it has no current results
Type: Edge Case
Approval status: approved
Approval session: SESSION-025
Approval cycle: 1

## Approved behaviour
When a saved search's live conditions currently match no bookmarks, the app shows a clear zero-result state without deleting or hiding the saved search. It remains in the sidebar and its active conditions remain available to review and adjust. Future matching bookmarks can appear when the saved search is opened again.

## Gherkin
Feature: Saved searches

  Scenario: Open a saved search with no current matches
    Given a named search is saved in the sidebar
    And no current bookmark satisfies its conditions
    When the person opens the saved search
    Then a clear zero-result state is shown
    And the saved search remains in the sidebar
    And its conditions remain visible and editable
    And the saved search remains able to include future matches

## Assumptions
- An empty result set does not imply that a saved search is invalid.
