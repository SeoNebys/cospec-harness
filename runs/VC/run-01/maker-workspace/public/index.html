Search syntax

  • machine learning — matches URL, title, description, notes and tags
  • "exact phrase" — match the words together
  • tag:news — a specific tag   (also title:, url:, desc:, notes:)
  • rust AND async — both must match (space also means AND)
  • python OR ruby — either matches
  • docker NOT windows or -windows — exclude
  • (a OR b) AND tag:work — group with parentheses
