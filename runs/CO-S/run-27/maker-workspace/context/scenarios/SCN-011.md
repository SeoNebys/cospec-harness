Scenario ID: SCN-011
Title: Save a valid address when page details cannot be fetched
Type: Error Case
Approval status: approved
Approval session: SESSION-011
Approval cycle: 1

## Approved behaviour
When an address is valid but the app cannot retrieve the page title and description, it plainly explains the failure, uses the site name as a fallback title, and still allows the person to edit the title, optionally add a description and tags, and save the bookmark.

## Gherkin
Feature: Recovering from page-detail failures

  Scenario: Page details are unavailable for a valid address
    Given the person enters a valid web address
    And the page title and description cannot be retrieved
    Then the app plainly explains that the details could not be fetched
    And the site name is supplied as the editable title
    And the description remains optional and editable
    And tags can be added
    And the valid bookmark can still be saved

## Assumptions
- Failure to fetch page details does not mean the address itself is invalid.
- A bookmark requires a title, with the site name serving as the fallback.
- A description is optional.
