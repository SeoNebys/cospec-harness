Scenario ID: SCN-005
Title: Filter the collection by selecting a bookmark tag
Type: Happy Path
Approval status: approved
Approval session: SESSION-005
Approval cycle: 1

## Approved behaviour
Selecting a tag pill on a bookmark narrows the collection to every bookmark carrying that tag and hides unrelated bookmarks. The active tag is clearly shown above the results, and using its × restores the full collection so the client cannot become stuck in a filtered view.

## Gherkin
Feature: Filter bookmarks by tag

  Scenario: Show all bookmarks carrying a selected tag
    Given the collection contains bookmarks with different tags
    When the client selects a tag pill on a bookmark
    Then every bookmark carrying that tag is shown
    And bookmarks without that tag are hidden
    And the selected tag is shown as the active filter

  Scenario: Return from a tag filter to the full collection
    Given the collection is filtered by a tag
    When the client clears the active tag filter
    Then all bookmarks in the collection are shown

## Assumptions
- Tag filtering matches the complete tag and ignores letter case.
- A bookmark with multiple tags is included when any one of its tags is the selected filter.
