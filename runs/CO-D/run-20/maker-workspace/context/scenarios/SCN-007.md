Scenario ID: SCN-007
Title: Permanently delete a bookmark with confirmation
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

A Delete action permanently removes a bookmark. It first shows a confirmation
that names the bookmark and clearly states the deletion is permanent and cannot
be undone — explicitly distinct from Archive (which only hides and is
restorable). Confirming removes the bookmark for good; cancelling leaves it
untouched. Delete is available for both normal and archived bookmarks.

## Gherkin
Feature: Delete

  Scenario: Confirmation is required and distinguishes delete from archive
    Given any bookmark (normal or archived)
    When the user clicks Delete
    Then a confirmation appears naming the bookmark and stating the action is
      permanent and cannot be undone, unlike Archive

  Scenario: Cancel leaves the bookmark untouched
    Given the delete confirmation is shown
    When the user clicks Cancel
    Then the bookmark remains unchanged

  Scenario: Confirming permanently removes the bookmark
    Given the delete confirmation is shown
    When the user clicks "Delete permanently"
    Then the bookmark is removed from the collection entirely

## Assumptions
- Deletion is permanent with no separate recovery path (Archive covers
  reversible hiding).
