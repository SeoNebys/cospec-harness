## Approved behaviour
Absence of data shows helpful guidance, never a blank screen:
- A brand-new (empty) Library shows a welcoming first-run message explaining how to
  save the first link and that a title and preserved copy are added automatically.
- An empty Reading list and empty Archive each show their own guiding message.
- A search with no matches shows a clear "no links match" message (from SCN-004).

Oversized content keeps a card tidy:
- A very long title is shown on one line, truncated with "…". The full title
  remains reachable on hover and in full in the Edit form and the saved-copy view.
- A long description is limited to two lines; a long note shows a two-line preview
  with expand (SCN-003).
- Many tags wrap neatly onto multiple rows; long unbroken text wraps rather than
  overflowing.

## Gherkin
Feature: Empty and oversized states

  Scenario: First-run empty library
    Given the library has no links
    When the client opens the Library
    Then a welcoming message explains how to save the first link

  Scenario: Empty reading list / archive
    Given no links qualify for a view
    When the client opens that view
    Then a guiding empty-state message is shown

  Scenario: Very long title
    Given a saved link with a very long title
    Then the card shows the title on one line truncated with an ellipsis
    And the full title is available on hover, in Edit, and in the saved-copy view

  Scenario: Many tags and long content
    Given a link with many tags and long description/note
    Then tags wrap onto multiple rows
    And description and note are limited with preview/expand
    And nothing overflows the card

## Assumptions
- Truncating an over-long title (with full text reachable elsewhere) is acceptable.
- Preview limits: description ~2 lines, note ~2 lines with expand.
