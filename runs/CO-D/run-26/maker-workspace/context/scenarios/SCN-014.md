Scenario ID: SCN-014
Title: Notes support simple formatting, shown rendered
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A bookmark's note supports simple formatting and displays that formatting when
viewed. Supported formatting: headings, bold, italic, inline code, bulleted
lists, numbered lists, block quotes, and links. The client can apply formatting
two ways: a small toolbar of buttons (bold, italic, heading, bulleted list,
numbered list, quote, link) that inserts the marks, and/or by typing the marks
directly (e.g. `**bold**`, `## heading`, `1. item`, `> quote`). On the card, the
note is shown with the formatting rendered. Any raw markup a client pastes is
shown as text, never executed.

## Gherkin
Feature: Formatted notes

  Scenario: Render supported formatting
    Given a note using headings, bold, italic, inline code, bullet lists,
          numbered lists, quotes, or links
    When the bookmark is viewed
    Then the note is displayed with that formatting rendered

  Scenario: Apply formatting with the toolbar
    When the client selects text and clicks a toolbar button (e.g. Bold)
    Then the corresponding marks are inserted around the selection
    And typing the marks by hand produces the same result

  Scenario: Pasted markup is safe
    Given a note containing raw HTML-like markup
    When the note is displayed
    Then the markup is shown as plain text and not executed

## Assumptions
- Supported set: headings (1–3 levels), bold, italic, inline code, bulleted lists,
  numbered lists, quotes, links (client-confirmed to include headings, numbered
  lists, and quotes).
- Both a toolbar and direct typing are offered (client-confirmed).
- Links in notes open in a new tab; clicking a note link does not also open the
  bookmark's own page.
