Scenario ID: SCN-005
Title: Read later lane
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A bookmark can be marked "Read later". A read-later bookmark:
- remains in the "All" view, shown with a "Read later" flag, and
- also appears in a focused "Read later" view listing only read-later items.
Marking a read-later bookmark as read ("Mark as read") clears its flag: it drops
out of the Read later view immediately but stays in the collection (still in
All, findable by search). The three views (All / Read later / Archived) each show
a live count.

## Gherkin
Feature: Read later lane

  Scenario: Mark a bookmark to read later
    Given a bookmark in the All view that is not marked read later
    When the user presses "Read later"
    Then the bookmark shows a "Read later" flag in the All view
    And it appears in the Read later view
    And the Read later count increases

  Scenario: Read later view shows only read-later items
    Given some bookmarks are marked read later
    When the user opens the Read later view
    Then only read-later, non-archived bookmarks are listed

  Scenario: Mark as read retires it from the lane
    Given a bookmark marked read later
    When the user presses "Mark as read"
    Then it no longer appears in the Read later view
    And it remains in the All view without the flag
    And it remains findable by search

## Assumptions
- "Read later" is a status independent of tags (client-confirmed as a separate
  lane rather than a tag).
- A read-later item stays in All with a flag (client-confirmed).
- "Mark as read" is the action that removes an item from the Read later lane
  (client-confirmed).
