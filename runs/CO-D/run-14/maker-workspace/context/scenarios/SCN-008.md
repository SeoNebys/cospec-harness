Scenario ID: SCN-008
Title: Search for a literal phrase containing operator words
Type: Edge Case
Approval status: approved
Approval session: SESSION-008
Approval cycle: 1

## Approved behaviour
The client can put a phrase in quotation marks to make every word inside literal text, including words such as "and" that otherwise act as search instructions. A quoted phrase matches only when its words appear together in the same order in a broadly searchable field. Quoted matching remains case-insensitive. The plain-language interpretation confirms that the input is being treated as an exact phrase.

## Gherkin
Feature: Search for literal phrases

  Scenario: Treat an operator word inside quotes as ordinary text
    Given a bookmark title contains the phrase "Law and Order"
    When the client searches for '"Law and Order"'
    Then that bookmark is included in the results
    And "and" is treated as literal text rather than an operator

  Scenario: Require quoted words to be adjacent and ordered
    Given other bookmarks contain the same words separately or in a different order
    When the client searches for '"Law and Order"'
    Then those other bookmarks are not included in the results

  Scenario: Match a quoted phrase without regard to capitalization
    Given a searchable field contains the phrase "Law and Order"
    When the client searches for the same quoted phrase with different capitalization
    Then the bookmark is included in the results

## Assumptions
- Double quotation marks delimit a literal phrase.
- "Exact phrase" means adjacent words in the same order, not case-sensitive character equality.
- Quoted phrases search the same broad text fields as ordinary text search.
