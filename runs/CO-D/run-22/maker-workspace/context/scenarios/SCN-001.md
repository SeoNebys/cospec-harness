Scenario ID: SCN-001
Title: Save a bookmark with automatically gathered details
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A person can paste a web address into the prominent save field and save it with minimal effort. The saved bookmark appears as a card containing its site, automatically gathered title and description, and a representative preview image when the page provides one.

## Gherkin
Feature: Saving bookmarks

  Scenario: Save a link with automatically gathered context
    Given the personal bookmark collection does not contain the link
    And the linked page provides a title, description, site name, and preview image
    When the person pastes the web address into the prominent save field
    And saves the bookmark
    Then one bookmark is added to the collection
    And its card shows the gathered site name, title, description, and preview image
    And the person does not have to enter those details manually

## Assumptions
- The submitted text is a valid web address for a reachable page.
- The linked page exposes title, description, site, and preview-image information that can be gathered.
- The collection belongs to one person and does not require a login flow.
