Title: View Archive and restore a bookmark
Type: Happy Path
Approval status: approved
Approval session: SESSION-015
Approval cycle: 1

## Approved behaviour
Archive is available in persistent side navigation. Opening it shows set-aside bookmarks separately from All bookmarks. Because recovery is the main purpose of this view, each archived bookmark has a prominent Restore button. Restoring moves the bookmark back to All bookmarks and updates both collection counts. A visible Restore button is preferred over an overflow-menu action.

## Gherkin
Feature: Recover archived bookmarks

  Scenario: View an archived bookmark and restore it
    Given one bookmark is in Archive
    And two bookmarks are in All bookmarks
    When the person opens Archive from persistent side navigation
    Then the archived bookmark is shown separately from All bookmarks
    And a prominent Restore action is visible on it
    When the person clicks Restore
    Then the bookmark is removed from Archive
    And the bookmark returns to All bookmarks
    And the Archive count changes to zero
    And the All bookmarks count changes to three

## Assumptions
- Restore returns a bookmark to All bookmarks with its existing details intact.
- The Archive view has the same persistent collection navigation as other views.
