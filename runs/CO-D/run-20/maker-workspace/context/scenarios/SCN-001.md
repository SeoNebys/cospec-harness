Scenario ID: SCN-001
Title: Save a link with fetched page details via a review step
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

From one dependable place, the user pastes a link into a single box and clicks
Save. Rather than saving instantly, the app fetches the page's details (real
title, description, site icon, preview image) and presents them in an editable
review panel with the address shown. The user may correct the title and/or
description, then confirms with "Add to bookmarks" (or cancels). On confirmation
the entry joins the collection at the top of the list (newest first). Saving is
one link, then a quick review, then one click.

A saved entry shows: the site icon, the title, a description, a preview
thumbnail on the left, and the full address underneath, plus a "Saved" time.
Clicking the title (the entry) opens the original page in a new browser tab; the
full address underneath also opens it.

## Gherkin
Feature: Save a link

  Scenario: Save a new link through the review step
    Given the user is on the bookmarks page
    And the link is not already saved
    When the user pastes a link and clicks Save
    Then the app presents an editable review panel pre-filled with the page's
      fetched title, description, preview image and site icon, and shows the address
    When the user optionally edits the title and/or description and clicks "Add to bookmarks"
    Then a new entry is added at the top of the list
    And the entry shows the site icon, title, description, left-hand preview thumbnail,
      full address and saved time
    And clicking the title or the address opens the original page in a new tab

  Scenario: Cancel before adding
    Given the review panel is shown for a pasted link
    When the user clicks Cancel
    Then no entry is added and the review panel closes

## Assumptions
- The prototype simulates the fetched metadata; the production app reads the
  actual page's title/description/icon/preview.
- Newest saved entries appear at the top of the list.
- The review step before saving is desired (approved as quick enough).
