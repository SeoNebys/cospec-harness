Scenario ID: SCN-011
Title: Open a saved page without losing the bookmark list
Type: Happy Path
Approval status: approved
Approval session: SESSION-011
Approval cycle: 1

## Approved behaviour
Clicking anywhere on a bookmark card opens its saved web address in a separate browser tab. The bookmark app remains in its original tab at the same place, so the user can return without losing their current list, collection filter, or browsing position.

## Gherkin
Feature: Opening saved bookmarks

  Scenario: Open a saved page from its bookmark card
    Given the bookmark list contains “MDN Web Docs”
    When the user clicks anywhere on the “MDN Web Docs” card
    Then the saved web address opens in a separate browser tab
    And the bookmark app remains open in its original tab
    And the original list and current place remain unchanged

## Assumptions
- The whole bookmark card is the opening target.
- Saved pages open in a separate browser tab by default.
- Opening a bookmark does not clear the current bookmark-list state.
