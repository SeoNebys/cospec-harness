Scenario ID: SCN-012
Title: Permanently delete a bookmark from its editor
Type: Happy Path
Approval status: approved
Approval session: SESSION-012
Approval cycle: 1

## Approved behaviour

Permanent deletion begins from inside the bookmark editor rather than from a control on the card face. Selecting Delete there opens a clear confirmation that names the bookmark and states that deletion is permanent. Confirming removes the card immediately and updates the collection count. No undo is required after this explicit confirmation.

## Gherkin

Feature: Managing saved bookmarks

  Scenario: Permanently delete a bookmark
    Given a bookmark is present in the collection
    When the user opens its editor
    And selects Delete bookmark
    Then a confirmation identifies the bookmark
    And the confirmation states that deletion is permanent
    When the user confirms deletion
    Then the bookmark is removed from the collection
    And the collection count decreases immediately

## Assumptions

- Permanent deletion is distinct from any future behaviour that hides a bookmark while retaining it.
- The explicit permanent-deletion confirmation is sufficient; no post-deletion undo is required.
