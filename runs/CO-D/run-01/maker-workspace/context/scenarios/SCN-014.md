Scenario ID: SCN-014
Title: Save a valid link when page details are unavailable
Type: Error Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When a valid web address cannot be reached or does not provide usable page details, the app honestly explains the failure but does not block saving. The person can supply a required recognizable title and an optional description. Missing site icons and pictures remain absent rather than being fabricated or causing the save to fail.

## Gherkin
Feature: Save when automatic details are unavailable

  Scenario: Continue manually after detail collection fails
    Given the person submits a valid web address
    And the app cannot collect usable details from its page
    When the failure state is shown
    Then the person can provide a required title and optional description
    And the valid address can still be saved as a bookmark
    And unavailable icons and pictures remain absent

## Assumptions
- A personal title is required when no title can be gathered.
- A manually supplied description is optional.
- Detail-collection failure does not imply the destination address is invalid.
