Scenario ID: SCN-020
Title: Preserve the complete library across visits
Type: Edge Case
Approval status: approved
Approval session: SESSION-020
Approval cycle: 1

## Approved behaviour

Closing the browser, restarting the computer, or returning later does not lose or reset the personal library. All bookmarks and their edited details, tags, Read later status, Archive contents, saved views, and saved page copies remain exactly as the client left them. Saved or organized information never quietly disappears between visits.

## Gherkin

Feature: Persist the personal bookmark library

  Scenario: Return to the complete library after closing the browser
    Given the user has saved and organized bookmarks
    And the library contains edited details, tags, Read later items, archived items, saved views, and saved page copies
    When the user closes the browser
    And later reopens the application
    Then every bookmark remains available
    And edited details and tags remain unchanged
    And Read later and Archive membership remain unchanged
    And saved views remain available
    And saved page copies remain available

## Assumptions

- Persistence applies across browser closures and computer restarts.
- The application is a lasting personal library rather than a temporary browser session.
