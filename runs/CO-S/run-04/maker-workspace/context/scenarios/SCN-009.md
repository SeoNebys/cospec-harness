Scenario ID: SCN-009
Title: Saving a link that is already saved (duplicate)
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When the client saves a link that already exists in the collection, the app does
NOT create a duplicate. Instead it shows a message "You've already saved this
link." with a "Show it" action. Choosing Show it navigates to the existing
bookmark and briefly highlights it, where the client can edit it if needed. If
the existing bookmark is archived, the message says so and Show it switches to
the Archive view to reveal it. Link comparison ignores a trailing slash and is
case-insensitive on scheme/host. The client confirmed: no duplicate; take me to
the existing one; handle archived duplicates the same way.

## Gherkin
Feature: Prevent duplicate bookmarks

  Scenario: Saving an existing link
    Given a link is already saved
    When the client saves the same link again
    Then no second copy is created
    And a message states the link is already saved
    And a Show it action is offered

  Scenario: Jumping to the existing bookmark
    Given the duplicate message is shown
    When the client chooses Show it
    Then the app navigates to and highlights the existing bookmark

  Scenario: Existing duplicate is archived
    Given the already-saved link is in the Archive
    When the client saves it again
    Then the message indicates it is in the Archive
    And Show it reveals it in the Archive view

## Assumptions
- Link equality ignores trailing slash and is case-insensitive on scheme/host.
- The existing bookmark can be edited after being revealed.
