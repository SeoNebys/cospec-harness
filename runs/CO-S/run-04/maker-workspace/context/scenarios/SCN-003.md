## Approved behaviour
On a saved entry, the client clicks "Add tags & note" (labelled "Tags & note"
once some exist), opening a single panel that groups both. Tags and the note are
managed together (client confirmed grouping them is right).

Tag entry uses a "pick or type" method (comparison option C, chosen by client):
- Previously used tags across all bookmarks are shown as clickable chips under
  "Your tags"; clicking one adds/removes it (toggles).
- A new tag is created by typing under "Add new" and pressing Enter.
Reusing an existing tag is quick; creating a new one is still easy.

The note is a private free-text field that supports simple Markdown when
displayed (bold, italic, bullet lists, links, inline code). On the card, the
saved note renders that formatting; it is the client's own private note.

After Save, the card shows the chosen tags as chips and the note rendered below
the description. Cancel discards changes.

## Gherkin
Feature: Organize a bookmark with tags and a note

  Scenario: Opening the organize panel
    Given a saved entry
    When the client clicks Add tags & note
    Then a single panel opens containing both tag entry and a note field

  Scenario: Reusing an existing tag
    Given other bookmarks already use one or more tags
    When the client opens the organize panel
    Then those tags are offered as clickable chips
    And clicking a chip adds that tag to the bookmark

  Scenario: Creating a new tag
    Given the organize panel is open
    When the client types a new tag under Add new and presses Enter
    Then the new tag is added to the bookmark

  Scenario: Writing a private note with Markdown
    Given the organize panel is open
    When the client types a note using simple Markdown and clicks Save
    Then the card shows the tags as chips
    And the card renders the note with its Markdown formatting (bold, lists, links)

## Assumptions
- Tags are shared/suggested across all of the client's bookmarks.
- Markdown subset for notes: bold, italic, bullet lists, links, inline code.
- The note is private to the client (single-user app).
