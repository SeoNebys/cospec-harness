# Non-functional backlog

## Cycle 1

- Card controls should remain clear and leave room for additional saved-item actions as they are introduced; the visible Edit action must not become buried merely because more actions exist.
- The web app is desktop-first but should remain comfortably usable in a phone-sized browser; no separate installable mobile app is required.
- Bookmark cards should remain visually even and quickly scannable when saved content is unusually long.
