Scenario ID: SCN-007
Title: A group disappears once its last link is gone
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Groups are labels on links, not standalone containers. The set of groups shown in
the sidebar is exactly the set of groups currently used by at least one link. When
the last link carrying a given group is removed (or that group is detached from it),
the group disappears from the sidebar automatically. If the user was viewing that
group at the moment it empties, the view falls back to "All bookmarks". The client
chose auto-removal over keeping empty groups, to keep the sidebar tidy.

## Gherkin
Feature: Groups reflect only links in use

  Scenario: Emptied group leaves the sidebar
    Given a group that only one link belongs to
    When that link is removed or the group is detached from it
    Then the group no longer appears in the sidebar

  Scenario: Viewing a group that empties falls back to all
    Given the user is viewing a single group
    When that group loses its last link
    Then the view switches to "All bookmarks"

## Assumptions
- A group has no independent existence apart from the links labelled with it (no
  separate "create empty group" concept). Revisit only if the client later wants
  pre-made empty groups.
