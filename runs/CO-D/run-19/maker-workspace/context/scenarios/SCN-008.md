Scenario ID: SCN-008
Title: Archive and restore bookmarks without losing them
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The infrequent Archive action is placed in each bookmark card's extra-actions menu rather than shown as a permanent button. Moving a bookmark to Archive removes it from All bookmarks, confirms that it can be restored, and updates the counts. Archive is a distinct destination in the side navigation with a reassuring Set aside, not lost heading. Archived bookmarks remain searchable within Archive but are excluded from All bookmarks, Read Later, and their everyday searches. Restore returns an archived bookmark to All bookmarks and confirms the move.

## Gherkin
Feature: Set bookmarks aside without losing them

  Scenario: Move a bookmark to Archive
    Given an active bookmark is shown in All bookmarks
    When the client opens its extra-actions menu
    And chooses Move to Archive
    Then the bookmark is removed from All bookmarks
    And the Archive count increases
    And the client is told it can be restored at any time

  Scenario: Browse and search archived bookmarks deliberately
    Given a bookmark is archived
    When the client browses or searches All bookmarks or Read Later
    Then the archived bookmark is not included
    When the client enters Archive and searches for it
    Then the archived bookmark is included in the Archive results

  Scenario: Restore an archived bookmark
    Given a bookmark is shown in Archive
    When the client selects Restore
    Then the bookmark is removed from Archive
    And the bookmark is returned to All bookmarks
    And the client is told it was restored
    And the navigation counts are updated

## Assumptions
- Moving a queued bookmark to Archive also removes it from Read Later.
- Search is scoped to the selected side-navigation destination.
- Archive is reversible and is not permanent deletion.
