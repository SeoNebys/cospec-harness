Scenario ID: SCN-001
Title: Save a link with automatically gathered page details
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

While already signed in with an empty collection, the client uses the paste box shown directly on the collection page to paste and save a link without first opening another control. The app gathers the page title, a short description, the site's identity, and a preview image without requiring the client to type those details. A readable saved item appears in the collection and selecting it opens the original page.

## Gherkin

Feature: Save bookmarks

  Scenario: Save a link and gather its page details
    Given the client is signed in and viewing an empty bookmark collection
    And the collection page shows the link paste box
    When the client pastes a valid page link into that box and saves it
    Then the app gathers the page title, a short description, the site's name and icon, and a preview image
    And the app adds a readable item containing those details to the collection
    And selecting the saved item opens the original page

## Assumptions

- The client is already signed in.
- The page is publicly reachable and provides the details displayed in the confirmed example.
- The collection is initially empty for this scenario.
- The paste box remains visible on the collection page so repeated saving does not require an extra opening action.
- Manual correction of gathered details is covered separately by SCN-009.
