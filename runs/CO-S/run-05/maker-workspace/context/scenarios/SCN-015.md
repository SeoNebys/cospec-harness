Scenario ID: SCN-015
Title: Keep captured page details stable over time
Type: Edge Case
Approval status: approved
Approval session: SESSION-015
Approval cycle: 1

## Approved behaviour

After a bookmark is saved, its captured title and description remain as the
client recognized them. Later changes on the source page do not silently alter
those saved details.

## Gherkin

Feature: Saved bookmark details

  Scenario: A source page changes after it was bookmarked
    Given a bookmark was saved with a captured title and description
    When the source page later changes its title or description
    Then the bookmark continues to show the originally captured title and description

## Assumptions

- Saved page details are a stable snapshot and are not refreshed automatically.
- Client-initiated editing of saved details is explored separately.
