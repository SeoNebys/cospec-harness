Scenario ID: SCN-011
Title: Find bookmarks using personal note text
Type: Happy Path
Approval status: approved
Approval session: SESSION-011
Approval cycle: 1

## Approved behaviour
Search includes a bookmark's personal note alongside its title, description, and source. Note matching ignores capitalization and continues to combine with an active label filter.

## Gherkin
Feature: Search personal bookmark notes

  Scenario: Find a bookmark by a word only in its note
    Given a bookmark's note contains the word "closures"
    And its title, description, and source do not contain that word
    When the person searches for "closures"
    Then that bookmark is included in the results

  Scenario: Match note text without regard to capitalization
    Given a bookmark's note contains the word "closures"
    When the person searches for "CLOSURES"
    Then that bookmark is included in the results

  Scenario: Search note text within a label filter
    Given a label filter is active
    When the person searches for note text
    Then only bookmarks carrying that label and matching the note text are shown

## Assumptions
- Notes participate in the same text search as titles, descriptions, and sources.
