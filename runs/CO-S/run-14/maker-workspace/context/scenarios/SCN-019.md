Scenario ID: SCN-019
Title: Preserve a full-page copy of a bookmark (manual or automatic)
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

A bookmark can have a preserved **full-page copy** stored as a **self-contained
file** that keeps the page's **layout and images** (not just extracted text), so
the content survives if the original later changes or goes offline. If the link
is a **PDF**, the **original PDF file** is preserved in its native format rather
than converted to a web page.

Control:
- **Automatic saving is a setting** the user can turn **on or off**: when on, a
  full-page copy is saved automatically for every new bookmark.
- **Per-bookmark manual controls remain** regardless of the setting: "Save a
  copy" when none exists, and "View copy" / "Update copy" when one does.
- Viewing a copy is **read-only**; "Update copy" re-captures the current page.
- A bookmark with a copy shows a "Copy saved" indicator.

## Gherkin
Feature: Preserve a full-page copy

  Scenario: Manually save a full-page copy
    Given a bookmark has no copy
    When the user chooses "Save a copy"
    Then a full-page copy (layout and images) is preserved
    And the bookmark shows a "Copy saved" indicator with View / Update actions

  Scenario: Preserve a PDF in its original format
    Given a bookmark's link is a PDF
    When a copy is saved
    Then the original PDF file is preserved (not converted to a web page)

  Scenario: Automatic copy setting
    Given the "automatically save a copy" setting is on
    When the user saves a new bookmark
    Then a full-page copy is preserved automatically

  Scenario: Setting off keeps manual control
    Given the automatic setting is off
    Then no automatic copy is made
    And the user can still save or update a copy per bookmark

  Scenario: View is read-only; update re-captures
    Given a bookmark has a copy
    When the user views it
    Then it opens read-only
    And "Update copy" re-captures the page

## Assumptions
- A copy is a self-contained file preserving layout + images; PDFs kept as PDF.
- The automatic-save toggle is a user setting (also see display preferences).
