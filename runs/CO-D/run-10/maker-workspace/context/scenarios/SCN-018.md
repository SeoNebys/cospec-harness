Scenario ID: SCN-018
Title: Archive and restore a bookmark without losing information
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Archive is a gentle, reversible action above permanent deletion in bookmark details. Archiving moves a bookmark out of All bookmarks, removes it from everyday search results, raises the Archive count, and confirms the move without destructive warnings. The Archive sidebar view shows the whole bookmark with its picture, title, description, labels, and details-and-note access intact. Restore to All bookmarks returns it to the main library, reduces the Archive count, preserves every saved detail, and confirms the restoration.

## Gherkin
Feature: Archive bookmarks

  Scenario: Archive a bookmark without deleting it
    Given the user has opened a bookmark's details
    When the user chooses Archive bookmark
    Then the bookmark leaves All bookmarks
    And the Archive count increases
    And the app confirms it moved to Archive
    And no saved bookmark information is lost

  Scenario: Exclude an archived bookmark from everyday search
    Given a bookmark is archived
    When the user searches the main library for words unique to that bookmark
    Then the archived bookmark does not appear in the results
    And the Archive count continues to show that it is safely stored

  Scenario: View an archived bookmark
    Given a bookmark is archived
    When the user opens Archive
    Then the bookmark appears with its picture, title, description, labels, and details-and-note access intact

  Scenario: Restore an archived bookmark
    Given the user is viewing a bookmark in Archive
    When the user chooses Restore to All bookmarks
    Then the bookmark returns to All bookmarks
    And the Archive count decreases
    And all saved bookmark information remains intact
    And the app confirms the restoration

## Assumptions
- All bookmarks and everyday search exclude archived bookmarks.
- Archive appears above permanent deletion in bookmark details.
