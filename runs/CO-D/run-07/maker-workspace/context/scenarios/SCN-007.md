Scenario ID: SCN-007
Title: Absence-of-data states (empty collection and empty focused views)
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When there are no bookmarks at all (new user), the collection shows a welcoming
prompt — "No bookmarks yet. Paste a link in the box above and press Save to keep
your first one." — rather than a blank page; the save box is present right above
it, making the next action obvious. Saving the first link replaces the empty
message with the bookmark.

When a focused view has no items, a clear explanatory message is shown instead of
a blank list:
- To read empty: "Nothing left to read — you're all caught up."
- Finished empty: "Nothing marked as finished yet."
The All / To read / Finished switch remains visible in every state so the client
can always change views. The client confirmed no extra action buttons are needed
in these empty states because the save box and the view switch are already
present.

## Gherkin
Feature: Empty states

  Scenario: Empty collection for a new user
    Given I have no bookmarks
    Then a welcoming prompt to save my first link is shown
    And the save box is available above it

  Scenario: Empty To read view
    Given no bookmark has status "To read"
    When I open the To read view
    Then a message "Nothing left to read — you're all caught up." is shown
    And the All / To read / Finished switch remains visible

  Scenario: Empty Finished view
    Given no bookmark has status "Finished"
    When I open the Finished view
    Then a message "Nothing marked as finished yet." is shown
    And the All / To read / Finished switch remains visible

## Assumptions
- Empty-state messages guide rather than merely state "no results".
- The view switch and save box are always visible, so no extra call-to-action
  buttons are required in empty states.
