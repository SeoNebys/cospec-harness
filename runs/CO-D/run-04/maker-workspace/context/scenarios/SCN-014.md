Scenario ID: SCN-014
Title: Deliberately create a new label
Type: Edge Case
Approval status: approved
Approval session: SESSION-014
Approval cycle: 1

## Approved behaviour
When no existing label matches typed text, pressing Enter deliberately creates
a new label. The label name receives tidy capitalization, is attached to the
bookmark as a chip, and appears in the sidebar with an updated count. Merely
typing does not silently create a label.

## Gherkin
Feature: Create bookmark labels

  Scenario: Create a label that does not exist
    Given a bookmark is open for editing
    And no existing label matches the entered label name
    When the person deliberately presses Enter
    Then a new label is created with tidy capitalization
    And the label appears as a chosen chip on the bookmark
    When the person saves the bookmark
    Then the new label appears in the sidebar with the bookmark included in its count

## Assumptions
- Typing alone never creates a label.
- Pressing Enter is the explicit create action when there is no existing match.
