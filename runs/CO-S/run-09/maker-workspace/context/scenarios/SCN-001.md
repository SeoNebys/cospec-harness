Scenario ID: SCN-001
Title: Save a new bookmark with automatically gathered context
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A person starts with an empty library and pastes a new web address into the prominent paste field. The app automatically presents the page title, description, source, icon, and preview. Saving gives a clear confirmation and immediately shows one complete, enriched bookmark in the library rather than only the raw link.

## Gherkin
Feature: Save an enriched bookmark

  Scenario: Gather context for a pasted link
    Given the bookmark library is empty
    When the person pastes a new web address
    Then the app shows the page title, description, source, icon, and preview before saving

  Scenario: Save the enriched bookmark
    Given the app has gathered the context for a new web address
    When the person saves the bookmark
    Then the app confirms that it was saved to the library
    And the library contains one bookmark with the gathered title, description, source, icon, and preview

## Assumptions
- The pasted web address identifies a page whose descriptive details can be gathered.
- The library is empty at the start of this first-use flow.
- A single prominent paste field is the starting interaction for saving a bookmark.
- The saved bookmark appears immediately below the confirmation so the person can verify what was stored.
