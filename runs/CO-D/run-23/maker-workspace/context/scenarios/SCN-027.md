Scenario ID: SCN-027
Title: Reject an invalid import file without changing the library
Type: Error Case
Approval status: approved
Approval session: SESSION-027
Approval cycle: 1

## Approved behaviour
If the person chooses a file that is not a valid browser bookmark export, the app rejects it before importing anything. It clearly identifies that the file is unsuitable, states that the library has not changed, and offers a direct Choose another file action.

## Gherkin
Feature: Import browser bookmarks

  Scenario: Choose a file that is not a browser bookmark export
    Given the library has not been changed by the pending import
    When the person chooses an invalid import file
    Then the file is rejected before any bookmark is imported
    And the app explains that it is not a browser bookmark file
    And it states that the library is unchanged
    And the person can choose another file directly

## Assumptions
- An invalid file never causes a partial import.
