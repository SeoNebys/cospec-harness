Scenario ID: SCN-012
Title: Search by an exact bookmark label
Type: Happy Path
Approval status: approved
Approval session: SESSION-012
Approval cycle: 1

## Approved behaviour
Typing a label name with a leading hash in live search immediately shows bookmarks carrying that exact label. Label matching ignores capitalization but does not return labels that merely contain the same letters.

## Gherkin
Feature: Searching bookmarks

  Scenario: Find bookmarks carrying an exact label
    Given two bookmarks carry the label "Reference"
    When the person types "#reference" into search
    Then those two bookmarks are shown immediately
    And label capitalization does not affect the match
    And bookmarks carrying only partially matching labels are not included

## Assumptions
- A leading hash distinguishes a label search from ordinary text search.
