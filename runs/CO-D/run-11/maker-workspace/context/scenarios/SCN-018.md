Scenario ID: SCN-018
Title: Import and export standard browser bookmark files
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The client can export all bookmarks to a standard Netscape bookmark HTML file
(the format browsers use), carrying each bookmark's title, tags, original saved
date, and personal note. The client can import such a file. On import:
- Titles, tags, and original saved dates are retained (so date-based sorting
  reflects the true saved time).
- Folder structure from the file is converted to tags: every folder the client
  deliberately created becomes a tag, at every nesting level; generic top-level
  browser containers ("Bookmarks bar", "Bookmarks menu", "Other bookmarks",
  "Favorites", etc.) are NOT turned into tags. Any TAGS already in the file are
  also kept.
- A link whose address is already saved is skipped and reported — never
  overwritten or duplicated, so previously edited bookmarks are not silently
  changed.
- Invalid or unreadable entries are skipped and counted; the rest of the file
  still imports.
- A summary reports how many were imported and how many skipped.

## Gherkin
Feature: Import / export

  Scenario: Export
    When the client exports
    Then a standard Netscape bookmark HTML file is produced carrying titles, tags,
         original saved dates and notes

  Scenario: Import retains titles, tags and saved dates
    When the client imports a bookmark file
    Then titles, tags and original saved dates are retained

  Scenario: Folders become tags, except generic containers
    Given an imported file with nested folders
    Then each deliberately-created folder name becomes a tag at every level
    And generic top-level containers are not turned into tags

  Scenario: Existing addresses are skipped, not overwritten
    Given a link in the file whose address is already saved
    Then it is skipped and reported, leaving the existing bookmark unchanged

  Scenario: Invalid entries skipped, import continues
    Given some invalid entries in the file
    Then they are skipped and counted and the remaining valid entries are imported

## Assumptions
- Standard Netscape bookmark HTML format (client confirmed "standard browser
  bookmark files").
- Import skips (does not merge/overwrite) existing addresses (client confirmed).
- Folder-to-tag conversion excludes generic containers, includes user folders at
  all depths (client confirmed).
