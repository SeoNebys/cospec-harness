Scenario ID: SCN-013
Title: Move reading status in either direction
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Reading status is reversible. A bookmark marked Read offers Mark unread, which returns it to Read later. Moving in either direction does not change the bookmark's labels or saved-page destination, and the status control remains separate from opening the card.

## Gherkin
Feature: Reversing bookmark reading status

  Scenario: Return a read bookmark to Read later
    Given a bookmark has the Read status
    When the client chooses Mark unread
    Then its status changes to Read later
    And its labels remain unchanged
    And its saved-page destination remains unchanged

## Assumptions
- Mark unread means return to Read later.
- Reading status can move repeatedly in either direction.
