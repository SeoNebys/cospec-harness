Scenario ID: SCN-002
Title: Find a bookmark using remembered page details
Type: Happy Path
Approval status: approved
Approval session: SESSION-002
Approval cycle: 1

## Approved behaviour
With several saved bookmarks visible, the client typed an uppercase search term. The collection immediately narrowed to the one bookmark whose title contained the same term in lowercase. The client approved immediate, case-insensitive matching across the bookmark title, short description, and source site.

## Gherkin
Feature: Search bookmarks

  Scenario: Search saved page details without regard to capitalization
    Given the collection contains several bookmarks
    When the user enters a search term using different capitalization from the saved text
    Then the collection immediately shows only bookmarks whose title, short description, or source site contains that term
    And matching does not depend on capitalization

## Assumptions
- Search results narrow immediately as text is entered.
- The first version searches automatically collected titles, short descriptions, and source sites.
- Personal notes are deferred and therefore are not yet part of searchable content.
