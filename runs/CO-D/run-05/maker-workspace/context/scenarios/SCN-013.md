Title: Clean display with missing optional details and long text
Type: Edge Case
Approval status: approved
Approval session: SESSION-001

## Approved behaviour

A bookmark with no tags and no note displays cleanly — just its title and site,
with no empty leftover boxes or placeholders. Long text (a long title, note or
description) wraps comfortably and never breaks the layout or spills off-screen.

## Gherkin

Feature: Bookmark display

  Scenario: Bookmark without optional details
    Given a saved bookmark with no tags and no note
    Then it displays only its title and site with no empty note or tag area

  Scenario: Long text wraps
    Given a bookmark with a very long title, note or description
    Then the text wraps comfortably without breaking the layout

## Assumptions
- Tags and note are optional; their absence leaves no visual residue.
