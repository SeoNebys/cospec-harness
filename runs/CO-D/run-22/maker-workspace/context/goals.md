# Cycle 1 goal

> Right now my bookmarks are honestly a mess. I save links in my browser and then never find them again — they just pile up in one big list and I can't remember what any of them were. So the main thing I want is to actually be able to find things later.
>
> A few things I keep wishing for: when I paste a link, I'd love it to just figure out the title and a little picture and description on its own, instead of me typing all that. Then I want to organize things — put labels on them so I can pull up, say, everything about cooking, or everything I tagged for work. And a real search that looks inside everything I've saved, not just the titles.
>
> The other big one is a "read later" pile. I save tons of articles meaning to read them, and they get lost among stuff I've already read. I'd like to keep those separate and check them off as I go.
>
> Basically: save a link with as little effort as possible, and always be able to find it again.

## Confirmed addition

> The only thing I'd add so we're on the same page: when I save a link, I don't just want to find it later, I also want to be able to tidy it up. So being able to fix the title or description if the automatic one is off, add my own notes, and change the labels afterward matters to me. And if I try to save something I've already saved, I'd rather it just take me to the one I already have instead of making a duplicate.
>
> But the overall shape — easy saving, automatic context, and finding things again through labels, search, and a read-later pile — yes, that's exactly what I'm after.

## Confirmed interface

> A web app, I think. I mostly save things while I'm at my computer browsing, so something I can just open in my browser makes the most sense. It'll only be me using it — I don't need other people to log in or share anything. Just my own personal collection that I can get to from my browser.
