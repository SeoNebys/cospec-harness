Title: Display preferences in Settings (default sort, items per page, text size)
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A Settings area (opened from the top bar) holds display preferences and the
occasional data tools (import/export). Display preferences:
- Default sort — the same four options as the inline sort (Newest, Oldest,
  Title A–Z, Title Z–A); changing it here changes and remembers the sort.
- Show per page — how many bookmarks are shown at once (e.g. 10, 25, 50, 100, or
  All). When more match than are shown, a "Show N more" control reveals the next
  batch; the visible count resets when the filter, sort, or view changes.
- Text size — Small, Medium, or Large, applied across the collection.

All three preferences are remembered across visits. Import and export live in the
same Settings area since they are occasional management tasks rather than
everyday actions.

## Gherkin
Feature: Display preferences

  Scenario: Set the default sort from Settings
    When the client changes "Default sort" in Settings
    Then the list re-sorts accordingly and the choice is remembered

  Scenario: Limit how many are shown per page
    Given more bookmarks match than the chosen per-page count
    Then only that many are shown with a "Show more" control for the rest
    And the visible count resets when the filter, sort, or view changes

  Scenario: Change text size
    When the client selects Small, Medium, or Large
    Then the collection's text scales accordingly and the choice is remembered

## Assumptions
- Settings is reached from a top-bar control; import/export moved here from the
  header (client-confirmed occasional-task placement).
- Per-page options include an "All" choice.
- Preferences persist per client (locally in the prototype; per account in the
  real app).
