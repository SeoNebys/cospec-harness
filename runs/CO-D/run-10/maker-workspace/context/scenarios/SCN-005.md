Scenario ID: SCN-005
Title: Keep and revisit a personal note on a bookmark
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The user writes a personal note in a roomy note area alongside the bookmark's other details. Saving returns to the clean library card without putting the private note text on the card. Each card has a calm, visible View details & note action that reopens the bookmark details and restores the saved note for reading or editing. The note editor provides in-place bullet-list formatting, and a reopened formatted note displays its bullet points as a clean list rather than raw formatting symbols.

## Gherkin
Feature: Personal bookmark notes

  Scenario: Save a personal note without crowding the library card
    Given the user is editing a bookmark's details
    When the user writes a personal note and saves the changes
    Then the note is stored with the bookmark
    And the user returns to the library
    And the note text is not shown on the bookmark card

  Scenario: Reopen and read a saved note
    Given a bookmark has a saved personal note
    When the user chooses View details & note on its card
    Then the bookmark details open
    And the saved note is present and readable as the user left it

  Scenario: Format and reread a bulleted note
    Given the user is editing a bookmark's personal note
    When the user activates bulleted-list formatting and enters multiple items
    And saves the bookmark changes
    And later reopens the bookmark details
    Then the note displays those items as a clean bulleted list
    And no raw formatting symbols are shown

## Assumptions
- Personal notes live inside bookmark details and are not displayed on library cards.
- Personal-note words will be included by search.
- View details & note is a visible, subdued action on each card.
