Scenario ID: SCN-001
Title: Save a bookmark with automatically collected page details
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

Starting from an empty collection, the client saves a bookmark by supplying
only its web address. The saved bookmark appears with a clear page title, a
short description, and the originating site so it can be recognized and
revisited without the client typing those details.

## Gherkin

Feature: Saving bookmarks

  Scenario: Save a first bookmark from its web address
    Given the bookmark collection is empty
    When the client saves a valid web address
    Then a bookmark is added to the collection
    And its page title is shown
    And a short page description is shown
    And the originating site is shown

## Assumptions

- The collection begins with an empty state when no bookmarks have been saved.
- The client is not required to type the page title, description, or site.
- The supplied page exposes enough information for those details to be collected.
