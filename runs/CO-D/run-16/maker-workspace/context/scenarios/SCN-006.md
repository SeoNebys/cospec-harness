Scenario ID: SCN-006
Title: Find bookmarks by searching everything, live
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A search box lets the client find bookmarks by any remembered detail. Plain text
is matched, case-insensitively, across title, description, note, tags, and web
address all at once. The list filters live as the client types, matching words
are highlighted, and a "X of Y match" count is shown. When nothing matches, a
"No matches" message invites trying another word. A clear (✕) control resets the
search and restores the full list.

## Gherkin
Feature: Search bookmarks

  Scenario: Live, case-insensitive search across all fields
    Given saved bookmarks exist
    When the client types a word into the search box
    Then the list filters live to bookmarks whose title, description, note,
         tags, or address contain that word, ignoring capitalisation
    And matching text is highlighted
    And a count of matches out of the total is shown

  Scenario: No results
    Given a search that matches nothing
    Then a "No matches" message is shown

  Scenario: Clearing the search
    Given an active search
    When the client clears it
    Then the full list is restored

## Assumptions
- Plain-text search matches substrings (partial words) across all fields.
