Scenario ID: SCN-013
Title: Jot a personal note on a link
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The Edit panel has a "My note" field where the client writes a few lines in their own
voice (why they saved it, "the good part is halfway down"). The note is clearly the
client's own words, visually distinct from the auto-generated summary (a soft highlighted
"MY NOTE" block). The note shows RIGHT ON the link's card, not hidden inside Edit — "a
message to future-me, and future-me needs to see it without going digging."

The note is included in what search reads: searching a word that appears only in a note
finds the link and highlights the word (closing the loop on "something I jotted down
myself").

Refinement: a very long note must not swallow the list — show the first part with a way to
expand it; normal short notes show in full.

## Gherkin
Feature: Personal note

  Scenario: Add a note and see it on the card
    Given a saved link
    When I write a note in Edit and press Done
    Then the note shows on the link's card, distinct from the summary

  Scenario: Find a link by a word only in its note
    Given a link whose note contains "mushroom" but nothing else does
    When I search "mushroom"
    Then the link is found and the word is highlighted in the note

  Scenario: Long note is truncated with expand
    Given a link with a very long note
    When I view the list
    Then only the first part shows, with a way to expand it

## Assumptions
- Note is free text, private to the client.
- Search haystack now = title + summary + site + note.
