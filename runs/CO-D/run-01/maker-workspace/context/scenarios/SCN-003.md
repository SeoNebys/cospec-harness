Scenario ID: SCN-003
Title: Add a personal note to a bookmark
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A personal note can be written in the same editing screen as the bookmark's editable title and description. Saving adds the note to the bookmark card so the reason for saving the link, a reminder, or a next action can be understood at a glance.

## Gherkin
Feature: Personal bookmark notes

  Scenario: Add a personal note to a saved bookmark
    Given a saved bookmark's details are open for editing
    When the person writes a personal note and saves the changes
    Then the note is saved with that bookmark
    And the note is visible on the bookmark card

## Assumptions
- Notes belong with the person's editable title and description.
- A saved note is visible directly on the bookmark card.
- Basic formatting of longer notes is explored separately.
