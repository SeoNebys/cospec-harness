Scenario ID: SCN-021
Title: Import and export bookmarks in the standard bookmark HTML format
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The user can import existing browser bookmarks from a standard bookmark HTML file. Import
preserves each link's title, its labels (from a TAGS attribute and/or the containing folder
names), and its added date where available. Links already saved (matched by address) are
skipped, and the user is told how many were imported and how many skipped. Imported links are
added without a preserved copy (the user can capture one later).

When folder and tag names overlap, they are merged into labels without creating case-duplicate
labels.

The user can export their whole collection (including archived links) to a standard bookmark
HTML file (Netscape format), preserving titles, labels (as tags), and original dates, so the
file can be re-imported here or into a browser.

## Gherkin
Feature: Import and export

  Scenario: Import a bookmark HTML file
    Given the user has a standard browser bookmark HTML file
    When the user imports it
    Then each link is added with its title, labels (from tags and/or folders), and date where available
    And links already saved are skipped
    And the user is told how many were imported and skipped

  Scenario: Import merges folder and tag labels without duplicates
    Given an imported link has a folder name and a tag with the same name (any case)
    When it is imported
    Then it receives a single label, not two duplicates

  Scenario: Export bookmarks
    Given the user has saved bookmarks (including archived ones)
    When the user exports
    Then a standard bookmark HTML file is produced for the whole collection
    And it preserves titles, labels, and original dates

## Assumptions
- The interchange format is the standard Netscape bookmark HTML.
- Folder names and a TAGS attribute both map to labels on import; labels export as tags.
- Duplicate detection on import uses the same address normalisation as SCN-003.
