Scenario ID: SCN-024
Title: Keep long bookmark details compact and expandable
Type: Edge Case
Approval status: approved
Approval session: SESSION-024
Approval cycle: 1

## Approved behaviour
An unusually long description and personal note are each shortened to a couple of lines on the bookmark by default so the collection remains scannable. Show more expands the complete text in place without leaving the list, and Show less restores the compact card. No saved text is permanently hidden.

## Gherkin
Feature: Display long bookmark content

  Scenario: Scan a bookmark with long text
    Given a bookmark has a long description and personal note
    When it appears in the collection
    Then the description and note are compacted to a couple of lines
    And a Show more action is available

  Scenario: Read and collapse all long text
    Given a long bookmark is compacted
    When the person selects Show more
    Then the complete description and note expand in place
    When the person selects Show less
    Then the bookmark returns to its compact form

## Assumptions
- Expansion affects the card in place and does not navigate away.
- Full saved text always remains accessible from the card.
