Scenario ID: SCN-006
Title: Find bookmarks with forgiving search and a label
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Search updates the visible library as the client types. It ignores capitalization and matches partial remembered text found in either bookmark titles or descriptions. A selected sidebar label combines with the search text, so a bookmark must satisfy both to remain visible.

## Gherkin
Feature: Searching bookmarks

  Scenario: Find a bookmark by partial text in its description
    Given the library contains bookmarks with enriched titles and descriptions
    When the client types part of a word that appears in one bookmark's description using different capitalization
    Then that bookmark remains visible
    And bookmarks without the text in their title or description are hidden
    And the results update as the client types

  Scenario: Find a bookmark by partial text in its title
    Given the library contains bookmarks with enriched titles and descriptions
    When the client types part of a bookmark title
    Then bookmarks whose titles contain that text remain visible
    And capitalization does not affect the match

  Scenario: Combine search text with a selected label
    Given search text currently matches bookmarks with different labels
    When the client selects one label in the sidebar
    Then only bookmarks matching both the search text and the selected label remain visible
    And the displayed bookmark count reflects the combined result

## Assumptions
- Search is case-insensitive.
- Partial text means a contiguous portion of text in a title or description.
- Search and label filters use an AND relationship.
- Search results update while the client types.
