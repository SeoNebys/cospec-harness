Scenario ID: SCN-001
Title: Save a link with automatic page details
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A person begins with an empty bookmark library, pastes a valid web address into
the always-visible save box at the top, and saves it. The bookmark appears in
the library with its page title, website name, and short summary filled in
automatically.

## Gherkin
Feature: Saving bookmarks

  Scenario: Save a valid link and retrieve its page details
    Given the bookmark library is empty
    And a valid web address has been entered in the save box
    When the bookmark is saved
    Then one bookmark appears in the library
    And its page title is filled in automatically
    And its website name is filled in automatically
    And its short summary is filled in automatically

## Assumptions
- Retrieving the remote page details succeeds.
- The save box is always visible at the top of the library.
- The first-use library is empty.
