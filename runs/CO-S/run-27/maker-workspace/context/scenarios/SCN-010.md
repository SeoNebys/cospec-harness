Scenario ID: SCN-010
Title: Reject an invalid web address
Type: Error Case
Approval status: approved
Approval session: SESSION-010
Approval cycle: 1

## Approved behaviour
When a person enters text that is not a complete web address, saving remains disabled and a plain-language message beside the field explains that the address does not look complete. No broken bookmark is saved.

## Gherkin
Feature: Validating bookmark addresses

  Scenario: Enter text that is not a web address
    Given the person is entering a bookmark address
    When the entered text is not a complete web address
    Then saving remains disabled
    And a plain-language message beside the field explains the problem
    And no bookmark is saved

## Assumptions
- A complete web address is required to save a bookmark.
- Validation feedback appears beside the save field.
