Scenario ID: SCN-003
Title: Organise and browse links by topic (several topics per link)
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

When saving a link, the client can assign it one or more topics (added one at a
time; previously used topics are suggested). A link may carry several topics at
once (e.g. both "Cooking" and "Weeknight"); it is not restricted to a single
topic. Each entry displays all of its topics as small tags. Above the list, a
topic bar shows "All" plus every topic in use. Selecting a topic — either from
the topic bar or by clicking a topic tag on a link — filters the collection to
links carrying that topic. Selecting "All" restores the full collection. The
topic filter and the search box combine: when both are active, only links that
carry the selected topic AND match the search text remain. The running count and
the empty-state message reflect the active topic and search.

The client compared two alternatives (one topic per link vs. several topics per
link) via side-by-side prototypes and chose several-topics-per-link.

## Gherkin

Feature: Organising links by topic

  Scenario: Assign several topics to a link when saving
    Given I am saving a link
    When I add one or more topics
    Then the link is saved carrying all of those topics
    And every topic is shown on the link's entry

  Scenario: Filter the collection by selecting a topic
    Given I have links that carry topics
    When I select a topic from the topic bar or click a topic tag on a link
    Then only links carrying that topic are shown
    And selecting "All" shows the whole collection again

  Scenario: Topic filter and search combine
    Given I have selected a topic
    When I also type text in the search box
    Then only links that carry that topic and match the search text remain

## Assumptions

- A link may carry zero, one, or several topics.
- Topics are free-text; existing topics are offered as suggestions.
- A topic can be selected from the topic bar or by clicking a topic tag shown on
  a link.
- The topic filter and the text search combine (both narrow the list).
- Search text is matched against title/description/note/address (SCN-002); topic
  membership is handled by the topic filter, not by the text search.
