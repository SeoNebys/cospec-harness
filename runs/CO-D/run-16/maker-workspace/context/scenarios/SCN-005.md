Scenario ID: SCN-005
Title: Editing a link into one that already exists is prevented
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When the client edits a bookmark's link to an address that is already saved as
a different bookmark, the app prevents creating a duplicate. It leaves the
existing bookmark intact, informs the client the link is already saved, and
takes them to that existing bookmark to update it instead.

## Gherkin
Feature: Prevent duplicate bookmarks via editing

  Scenario: Editing a link to match another bookmark
    Given two different bookmarks exist
    When the client edits one bookmark's link to match the other's address
    And saves the change
    Then no duplicate is created
    And the edited bookmark's link is not changed to the clashing address
    And the existing (clashing) bookmark is left intact
    And the client is directed to the existing bookmark to update it

## Assumptions
- Links are matched ignoring protocol, "www.", and trailing slashes.
