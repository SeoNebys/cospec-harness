Scenario ID: SCN-007
Title: Browse bookmarks by label
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The collection has persistent navigation down the left side, with All bookmarks and Read later above a vertically growing list of labels. Selecting a label shows only bookmarks carrying it and changes the collection heading to that label. Matching bookmark cards continue to show all of their labels, preserving the context that a bookmark can belong to multiple groups.

## Gherkin
Feature: Browse by label

  Scenario: View bookmarks carrying a label
    Given the left navigation lists the person's labels
    When the person selects a label
    Then the collection heading changes to that label
    And only bookmarks carrying the selected label are shown
    And each matching card continues to show all labels attached to it

## Assumptions
- Collection navigation and the label list remain down the left side on a wide screen.
- The vertical label list can grow beyond the initial sample labels.
- Filtering by one label does not visually remove other labels from matching cards.
