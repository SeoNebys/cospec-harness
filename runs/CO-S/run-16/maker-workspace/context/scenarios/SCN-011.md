Scenario ID: SCN-011
Title: Recover clearly from a search with no matches
Type: Edge Case
Approval status: approved
Approval session: SESSION-011
Approval cycle: 1

## Approved behaviour

When a search has no matching bookmarks, the application clearly says that nothing was found while preserving the text the client entered. It makes clear that the collection is merely filtered rather than changed, and a Clear filters action immediately restores the full saved collection.

## Gherkin

Feature: Handle searches with no matches

  Scenario: Search for words that occur in no bookmark
    Given the personal collection contains saved bookmarks
    When the user enters a search phrase that matches none of their searchable content
    Then the application shows that no bookmarks were found
    And the entered search phrase remains visible
    And no saved bookmark is changed or deleted
    When the user clears the filters
    Then the full collection is shown again

## Assumptions

- Searchable content includes titles, source sites, captured descriptions, and personal notes.
- Clear filters also clears an active tag if one is selected.
