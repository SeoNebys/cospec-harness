# Business goal

Cycle: 1
Session: SESSION-001
Status: confirmed

## Goal statement (client's words)

"I'm constantly leaving useful links in open tabs, messages to myself, and
random notes, then I can't find them when I need them. I want one calm, readable
place where I can save a link quickly, find it again by searching or organizing
it with tags, and keep track of things I still mean to read.

The bigger goal is a dependable personal reference library. I'd like saved links
to retain useful page details automatically, and ideally preserve the content in
case the original page later changes or disappears. I also want to be able to put
older links away without permanently deleting them.

This is mainly for me alone. Sharing and collaboration aren't important for the
first version."

## Interpreted direction (confirmed by client)

One calm, readable personal place to:
- Save a link quickly, with low friction
- Have recognizable page details filled in automatically on save
- Find links again by searching and by organizing with tags
- Track reading progress: separate unread, finished, and archived links
- Correct or add details and notes after saving
- Avoid duplicates: re-saving the same address opens the existing entry
- Put older links away (archive) without permanently deleting

Deeper purpose: a dependable personal reference library the client can trust
over time.

## Interface form (confirmed)

Web application, used mainly in a desktop browser. Must remain comfortable on a
phone screen for quick saving / lookup, but no separate mobile app is needed.
=> Responsive web layout.

## Scope of the first version (essential — confirmed)

1. Quick saving of a link
2. Automatic fill of recognizable page details on save
3. A readable list of saved links
4. Strong search
5. Tags for organizing
6. A clear way to separate unread / finished / archived links
7. Editing details and notes after saving
8. Duplicate handling: re-saving an existing address opens the existing entry

## Recorded for later cycles (NOT in this cycle's scope)

- Preserving a local copy of a page's content, so a saved link survives if the
  original page changes or disappears. (Client: important to the long-term goal,
  but can come after the basic experience is solid.)
- Importing existing browser bookmarks. (Client: "would also be useful later.")

These are logged here only; per the experiment scope, no additional cycle is
started for them in this trial.
