Scenario ID: SCN-004
Title: Narrow the list by filtering on tags
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Above the list, a "Filter by tag" row shows the client's tags as clickable chips.
Clicking a tag chip filters the list to bookmarks carrying that tag. Selecting a
second tag narrows further — only bookmarks that carry ALL selected tags are
shown (AND / narrowing, confirmed by client). A "Clear" action resets filters
(and search). A small result line shows how many matched and which tags/search
are active. Tag filters and the search box combine — both apply together.

## Gherkin
Feature: Filter bookmarks by tag

  Scenario: Filtering by a single tag
    Given bookmarks with various tags
    When the client clicks a tag chip in the filter row
    Then only bookmarks carrying that tag are shown

  Scenario: Selecting multiple tags narrows to all of them
    Given a tag filter is already active
    When the client selects a second tag
    Then only bookmarks carrying BOTH selected tags are shown

  Scenario: Clearing filters
    Given one or more tag filters (and/or a search) are active
    When the client clicks Clear
    Then all filters and the search are removed and the full list returns

  Scenario: Filters and search combine
    Given a search word and a tag filter are both active
    Then only bookmarks matching both the search and the tag are shown

## Assumptions
- Multiple selected tags combine with AND (narrowing).
- The filter row lists all tags used across the client's bookmarks.
