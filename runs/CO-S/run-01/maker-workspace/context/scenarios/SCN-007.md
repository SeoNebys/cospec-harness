Scenario ID: SCN-007
Title: Saving while offline — save now, resolve title later
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
If the client saves a link while there is no internet connection (so the page
title cannot be fetched), the link is still saved immediately rather than lost.
The title is resolved later when possible, and in the meantime the link behaves
like the "title not found" case (shows the site name with the ability to give it
a recognizable name). Client's rationale: losing a link because of a wifi hiccup
would be unacceptable; never block the save.

## Gherkin
Feature: Saving without a connection

  Scenario: Save a link while offline
    Given the client has no internet connection
    When the client saves a link
    Then the link is saved immediately and not lost
    And it shows the site name with the option to add a recognizable name
    And the real title is fetched later when a connection is available

## Assumptions
- Saving never depends on a successful title fetch (consistent with SCN-006).
- Title fetch is retried later when connectivity returns.
