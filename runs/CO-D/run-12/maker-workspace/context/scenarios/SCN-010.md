Scenario ID: SCN-010
Title: Correct text that is not a usable web address
Type: Error Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When the user enters text that is not a usable web address, the app stops before trying to obtain details or save it. The entered text remains available to correct, and a plain inline message explains the problem and gives an example of a complete address.

## Gherkin
Feature: Saving bookmarks

  Scenario: Enter text that is not a web address
    Given the save field contains text that is not a usable web address
    When the user asks the app to get details
    Then the app does not try to save the text
    And the entered text remains in the field
    And an inline message explains that a complete web address is needed
    And the message shows an example of a complete web address

## Assumptions
- Invalid-address feedback is shown beside the save field.
- The user's original text is preserved for correction.
