Scenario ID: SCN-007
Title: Saving something that is not a web link
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When the user tries to save text that does not look like a web address, the app
neither silently refuses nor blindly saves it. It shows a gentle warning
("<text> doesn't look like a web link. Save it anyway?") with two choices:
"Save anyway" (saves the text as entered) or "Cancel" (keeps the text in the box
to fix, saves nothing). The user is never blocked, but is protected from saving
typos by accident.

## Gherkin
Feature: Guarding against non-link input

  Scenario: Warn on text that is not a web link
    Given the user enters text that does not look like a web address
    When the user confirms saving
    Then a gentle warning asks whether to save it anyway
    And nothing is saved yet

  Scenario: Save anyway
    Given the "doesn't look like a web link" warning is shown
    When the user chooses "Save anyway"
    Then the entered text is saved as a link

  Scenario: Cancel the non-link save
    Given the "doesn't look like a web link" warning is shown
    When the user chooses "Cancel"
    Then nothing is saved
    And the entered text remains in the box to correct

## Assumptions
- The check is a soft warning, never a hard block.
- "Looks like a web link" is judged heuristically (Phase 2 to define exactly).
