Scenario ID: SCN-016
Title: Keep a valid link when page details cannot be loaded
Type: Error Case
Approval status: approved
Approval session: SESSION-016
Approval cycle: 1

## Approved behaviour
If a valid link's title and description cannot be obtained, the link is still saved as To read. Its source is used as a temporary title, a clear message explains that page details could not be loaded, and the person is directed to Edit to fill them in manually.

## Gherkin
Feature: Recover from unavailable page details

  Scenario: Save a valid link whose details cannot be loaded
    Given the person enters a valid web address
    And the page title and description cannot be obtained
    When the person saves the link
    Then the link is retained as a bookmark
    And it is marked To read
    And its source is used as a temporary title
    And a message explains that the page details could not be loaded
    And the message directs the person to edit the bookmark manually

## Assumptions
- Preserving the chosen valid link is more important than requiring automatic details.
