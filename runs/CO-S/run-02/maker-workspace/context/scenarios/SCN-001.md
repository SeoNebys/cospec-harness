Scenario ID: SCN-001
Title: Save a bookmark from its address
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
From an empty bookmark collection, the client pastes one web address into an always-visible saving box and saves it. The bookmark appears with the page title, a short description, and the original address filled in automatically. The client approved both the resulting bookmark and the effortless single-box flow, preferring the box to remain visible because it makes saving quicker.

## Gherkin

    Given the bookmark collection is empty
    And a web page has a title and short description
    When the user pastes the page address into the saving box
    And saves the bookmark
    Then the bookmark appears in the collection
    And it shows the page title
    And it shows a short page description
    And it shows the original page address

## Assumptions
- The saving control accepts one web address at a time.
- The saving box remains visible on the main bookmark screen.
- Page details available to the app include a title and short description.
- The page address remains visible after saving.
