Title: Three views (Collection, Reading list, Archive) with search scoped to the current view
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

The bookmarks are presented through three views selected by a control at the top:

- Collection: all active (non-archived) bookmarks, read or unread, whether or not
  they are on the reading list. New saves land here.
- Reading list: only active bookmarks the client has marked to read later.
- Archive: only bookmarks the client has explicitly archived.

Search is scoped to the current view: from the Collection or Reading list it
searches only active bookmarks and never surfaces archived ones; from the Archive
it searches only archived bookmarks. The match count names the scope (e.g. "in
your collection", "in the archive").

## Gherkin

Feature: Views and search scope

  Scenario: New saves appear only in the Collection
    When I save a new bookmark
    Then it appears in the Collection view
    And not in the Reading list unless I chose to read it later

  Scenario: Search is scoped to the current view
    Given both active and archived bookmarks
    When I search from the Collection or Reading list
    Then only active bookmarks can match, never archived ones
    And when I search from the Archive
    Then only archived bookmarks can match

## Assumptions
- The three views are mutually consistent projections of the same bookmarks by
  their archived / reading-list state.
