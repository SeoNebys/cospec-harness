# Business goal statement

## Cycle 1 — Bookmark save & management app

### Goal (in the client's words)

> Right now my bookmarks become a pile that I rarely revisit because I can't
> quickly find the one I remember saving. I'd like one dependable place where I
> can save a link quickly, give it useful tags or a note, and later find it by
> searching whatever I remember about it.
>
> Finding things again is the bigger priority, though saving should still feel
> effortless. I'd also like to separate things I intend to read later from
> things I've finished with, without having to delete useful links.

### Confirmed summary

One dependable place to save a link quickly with tags or a note, so it can later
be found by searching whatever the client remembers about it. Priorities, in
order:

1. **Finding again** (top priority) — search by anything remembered (tags, note,
   title, etc.).
2. **Effortless saving** — quick capture with tags/note.
3. **Separating "to read later" from "finished"** — without deleting useful
   links.

### Interface form

Web app used in the browser, with a clean, readable list of saved links.

### Status

- Goal confirmed by client: yes
- Interface form confirmed: yes (web app)
