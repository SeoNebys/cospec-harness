Scenario ID: SCN-002
Title: Find a saved link by searching
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Below the save area there is a single search box. As the user types, the list of
saved links narrows in real time to those whose title, site name, or tags
contain the typed text. Clearing the search box restores the full list. Matching
text is visually highlighted in the results. This is confirmed as the primary,
and preferred, way the user finds a saved link ("search feels more like how my
brain works"). Keeping finding to a single search box was explicitly valued as
"less for me to think about".

## Gherkin
Feature: Finding a saved link by search

  Scenario: Narrow the list by typing
    Given several links are saved
    When the user types text into the search box
    Then the list shows only links whose title, site, or tags contain that text
    And the matching text is highlighted

  Scenario: Clearing the search restores everything
    Given the user has typed a search term
    When the user clears the search box
    Then the full list of saved links is shown again

## Assumptions
- Search matches across title, site name, and tags together (one field, one way
  of finding). Client confirmed merging tags into search rather than a separate
  filter panel.
- Search is live/incremental (filters as you type). Client reacted positively to
  the narrowing-as-you-type behaviour.
