Scenario ID: SCN-026
Title: Save a bookmark when page details are unavailable
Type: Error Case
Approval status: approved
Approval session: SESSION-026
Approval cycle: 1

## Approved behaviour
If a valid link does not provide a title, description, site icon, or preview image, the bookmark is still saved so the link is not lost. The card uses the site name and simple visual fallbacks, clearly explains that page details were unavailable, and remains editable so the person can supply better details later.

## Gherkin
Feature: Saving bookmarks

  Scenario: Page details cannot be gathered
    Given a valid web address does not provide usable page details
    When the person saves that address
    Then the bookmark is saved
    And its card uses the site name and simple visual fallbacks
    And the app explains that some page details were unavailable
    And the person can edit its title and description

## Assumptions
- Preserving a valid link is more important than requiring complete page details.
- The same fallback applies when details are absent or cannot be reached.
