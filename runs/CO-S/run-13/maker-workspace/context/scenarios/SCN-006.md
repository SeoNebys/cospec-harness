Scenario ID: SCN-006
Title: Mark a bookmark for "read later" and view a focused read-later list
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

"Read later" is a marker applied to a bookmark that already lives in the single
library — not a separate store. Above the list there are two tabs, "All bookmarks"
and "Read later", each showing a count. Each bookmark card has a "+ Read later"
control; clicking it marks the bookmark (the control becomes "✓ In read later")
and the Read later count increases. The Read later tab shows only marked
bookmarks. Clicking the control again on a bookmark in the Read later view removes
the marker (the client's way of saying "read it / done"); the bookmark leaves the
Read later view but remains in All bookmarks — it is not deleted. When the
Read later view has no items, a clear "Your read-later list is empty" message is
shown. Search, tag filter, and sort operate within the current tab.

## Gherkin
Feature: Read-later list

  Scenario: Mark a bookmark to read later
    Given a saved bookmark that is not marked for read later
    When I click its "Read later" control
    Then the bookmark is marked for read later
    And the Read later count increases

  Scenario: View the read-later list
    When I open the "Read later" tab
    Then only bookmarks marked for read later are shown

  Scenario: Mark as read removes it from the read-later view only
    Given a bookmark is marked for read later
    When I remove the read-later marker
    Then it no longer appears in the Read later tab
    And it still appears in All bookmarks (it is not deleted)

  Scenario: Empty read-later list
    Given no bookmarks are marked for read later
    When I open the "Read later" tab
    Then a "Your read-later list is empty" message is shown

## Assumptions
- "Read later" is a reversible marker within the one library, not a separate
  storage location. (Confirmed.)
- Removing the marker does not delete the bookmark. (Confirmed.)
- Search / tag filter / sort apply within the currently selected tab.
