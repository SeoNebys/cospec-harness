Scenario ID: SCN-001
Title: Save a bookmark from its web address
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A person pastes a web address into the save bar above their collection and saves it. The bookmark appears in the collection as a skimmable card without requiring manual entry. The card shows the page's site icon, source site, title, short description, address, and the page's actual preview image when the page provides one.

## Gherkin
Feature: Saving bookmarks

  Scenario: Save a page that provides bookmark details
    Given the personal bookmark collection is open
    And a web page provides a title, description, site icon, and preview image
    When the person pastes the page address into the save bar and saves it
    Then a bookmark is added to the collection
    And the bookmark shows the page's title, description, site icon, source site, address, and preview image
    And the person did not have to enter those details manually

## Assumptions
- The page provides all of the metadata used in this happy path.
- The save bar remains above the bookmark collection.
- A saved bookmark is presented as a skimmable card.
