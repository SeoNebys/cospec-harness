Scenario ID: SCN-006
Title: Browse all bookmarks carrying a label
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Labels are shown in a row above the bookmark collection with the number of bookmarks carrying each label. Selecting a label in one click narrows the collection to all bookmarks carrying it. A bookmark may carry more than one label and is included in each corresponding label count and view.

## Gherkin
Feature: Organizing bookmarks with labels

  Scenario: View all bookmarks carrying a label
    Given saved bookmarks carry labels
    And some bookmarks carry more than one label
    When the user selects a label from the row above the collection
    Then only bookmarks carrying that label are shown
    And the label shows the number of bookmarks carrying it
    And bookmarks carrying other labels as well remain included

## Assumptions
- Labels are displayed in a row above the bookmark collection.
- Each label displays its bookmark count.
- Selecting a label is a one-click filter action.
