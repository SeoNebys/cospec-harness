Scenario ID: SCN-010
Title: Click a tag to filter by that tag
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

Clicking a tag shown on a bookmark fills the search box with that exact tag
condition (as `#tag`) and applies it, narrowing the current view to bookmarks
carrying that tag.

## Gherkin

Feature: Search bookmarks

  Scenario: Filter by clicking a tag
    Given a bookmark displaying a tag
    When the user clicks that tag
    Then the search box is filled with that tag condition
    And the current view is narrowed to bookmarks carrying that exact tag

## Assumptions
- Clicking a tag is equivalent to searching "#tag".
