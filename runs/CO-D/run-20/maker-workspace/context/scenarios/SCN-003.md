Scenario ID: SCN-003
Title: Edit a saved entry's title, description and address
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

Each saved entry has an Edit action. Editing lets the user change the entry's
title, description, and address (link) in place. Correcting the address (e.g. a
mistyped link or a moved page) updates the entry — including its icon and preview
which follow the new address — while the title continues to open the corrected
page. Saving applies the changes in place; cancelling leaves the entry untouched.

Forward expectation (not yet built): once tags and notes are part of an entry,
they should be editable through this same edit action.

## Gherkin
Feature: Edit a saved entry

  Scenario: Edit title and description in place
    Given a saved entry exists
    When the user opens Edit, changes the title and/or description, and clicks Save changes
    Then the entry updates in place with the new title and description

  Scenario: Correct the address of an entry
    Given a saved entry exists
    When the user opens Edit, changes the address, and clicks Save changes
    Then the entry's address is updated and its icon/preview follow the new address
    And clicking the title opens the corrected page

  Scenario: Cancel editing
    Given the edit form is open for an entry
    When the user clicks Cancel
    Then the entry remains unchanged

## Assumptions
- Address changes recompute the derived site icon/preview from the new address;
  the user's edited title/description are preserved.
