Title: Save prepared bookmark details to the library
Type: Happy Path
Approval status: approved
Approval session: SESSION-002
Approval cycle: 1

## Approved behaviour
After reviewing the prepared page details, the user can save the bookmark. The app returns the user to their library and shows the saved bookmark as a card containing its title, description, and source website, along with an immediate confirmation that it was saved.

## Gherkin
Feature: Save a prepared bookmark

  Scenario: Save a bookmark to the library
    Given the user has prepared a bookmark with a title, description, and web address
    When the user saves the bookmark
    Then the app returns the user to their bookmark library
    And the library shows a card for the saved bookmark
    And the card shows the bookmark title, description, and source website
    And the card confirms that the bookmark was saved just now

## Assumptions
- The prepared bookmark has a non-empty title and a valid web address.
- Saving succeeds without an external service or connection error.
- The newly saved bookmark is immediately visible in the library.
