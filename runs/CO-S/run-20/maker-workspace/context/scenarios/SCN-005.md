Scenario ID: SCN-005
Title: Archive links to retain them without cluttering the main view
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

Any link can be archived from its entry. An archived link leaves the main
collection view immediately and is excluded from the main collection's search
and topic browsing, so it no longer clutters everyday use — but it is fully
retained. The client reaches archived links through a separate "Archive" area
(opened from a "View archive" control that shows a count of how many links are
archived). Within the archive, search and topic filtering work the same way, so
archived links stay findable there. The client is content to search the archive
separately rather than have everyday search reach into it. Restoring an archived
link returns it to the normal collection exactly as before (its topics, note, and
reading status are retained).

## Gherkin

Feature: Archiving links

  Scenario: Archive a link
    Given a link in my main collection
    When I archive it
    Then it is removed from the main collection view
    And it does not appear in the main collection's search or topic results

  Scenario: View archived links separately
    Given I have archived links
    When I open the archive
    Then only archived links are shown
    And I can search and filter them by topic within the archive

  Scenario: Restore an archived link
    Given an archived link
    When I restore it to the collection
    Then it returns to the main collection retaining its topics, note, and reading status

  Scenario: See how many links are archived
    Given I have archived links
    When I look at the archive control
    Then it shows the number of archived links

## Assumptions

- Archived links are excluded from the main collection view AND from the main
  collection's search/topic results (client confirmed this is desired).
- The archive is a separate space that is itself searchable and topic-filterable.
- Restoring returns a link to the normal collection with its previous details
  intact.
- The archive control shows a count of archived links.
