Scenario ID: SCN-003
Title: Reversible "Read later" list separate from the main view
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A bookmark can be marked "Read later" and unmarked again at any time — it is a
reversible choice, not fixed at save time. The user switches to a separate
"Read later" tab/view that shows only the bookmarks currently marked for reading
later (and not archived). In the main "All" view, bookmarks marked for reading
later carry a small "Read later" badge so they are recognisable. Search and tag
filtering operate within the Read later view.

## Gherkin
Feature: Read later list

  Scenario: Mark a bookmark to read later
    Given a saved bookmark that is not archived
    When the user marks it "Read later"
    Then it appears in the Read later view
    And it shows a "Read later" badge in the All view

  Scenario: Unmark a bookmark
    Given a bookmark marked "Read later"
    When the user unmarks it
    Then it no longer appears in the Read later view
    And its "Read later" badge is removed in the All view

  Scenario: Search within the Read later view
    Given several bookmarks marked "Read later"
    When the user searches or clicks a tag while on the Read later view
    Then only matching Read later bookmarks are shown

## Assumptions
- Read later is a per-bookmark reversible flag, toggled at any time.
- Archived bookmarks do not appear in the Read later view even if flagged.
- New bookmarks are not marked "Read later" by default.
