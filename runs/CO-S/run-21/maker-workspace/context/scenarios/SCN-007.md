Scenario ID: SCN-007
Title: Return from a tag filter to all bookmarks
Type: Happy Path
Approval status: approved
Approval session: SESSION-007
Approval cycle: 1

## Approved behaviour
The tag row includes a persistent "All" choice alongside the other tag filters. Choosing it after filtering restores every bookmark, resets the collection heading to its normal all-bookmarks label, and resets the result count. This persistent route is preferred over a contextual clear-filter action that appears only while filtering.

## Gherkin
Feature: Leave a tag-focused collection

  Scenario: Return to all bookmarks from a tag filter
    Given the collection is filtered to one tag
    And the tag row includes a visible "All" choice
    When the person chooses "All"
    Then every bookmark is shown again
    And the collection heading returns to "All bookmarks"
    And the result count shows the full collection count
    And the "All" choice remains visible in the tag row

## Assumptions
- "All" is placed with tag filters rather than elsewhere on the page.
- Only one tag filter is active at a time in this flow.
