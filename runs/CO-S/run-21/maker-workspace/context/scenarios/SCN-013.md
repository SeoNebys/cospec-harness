Title: Mark a Read later item as read
Type: Happy Path
Approval status: approved
Approval session: SESSION-013
Approval cycle: 1

## Approved behaviour
Within the Read later view, each queued bookmark has an explicit "Mark as read" button. Using it removes the bookmark from the Read later pile, updates the waiting count, and clearly reassures the person that the bookmark remains safe in All bookmarks. An explicit button is preferred over a compact checkbox because its effect is clearer.

## Gherkin
Feature: Work through the Read later pile

  Scenario: Mark a queued bookmark as read
    Given two bookmarks are in the Read later pile
    And the person is viewing Read later
    When the person clicks "Mark as read" on one bookmark
    Then that bookmark is removed from the Read later view
    And the waiting count changes from two to one
    And the app explains that the bookmark remains in All bookmarks
    And the bookmark still exists in All bookmarks

## Assumptions
- Marking as read clears only Read later status.
- The action does not archive or delete the bookmark.
