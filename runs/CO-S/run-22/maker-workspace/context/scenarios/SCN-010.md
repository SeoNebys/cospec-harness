Scenario ID: SCN-010
Title: Remove a saved link with confirmation
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Each saved link has a "Remove" action. Clicking it does not delete immediately;
instead the link asks the client to confirm with "Remove" and "Keep" choices.
Choosing "Keep" cancels and leaves the link untouched. Choosing "Remove" deletes
the link permanently (no undo / recycle bin) and the saved-links count decreases.
The confirmation guards against an accidental single click; permanent deletion is
acceptable once the client has explicitly confirmed it.

## Gherkin
Feature: Removing a saved link

  Scenario: Confirmation is required before removal
    Given a saved link
    When the client clicks Remove
    Then the link asks the client to confirm with Remove/Keep and is not yet deleted

  Scenario: Cancel removal
    Given the removal confirmation is showing on a link
    When the client clicks Keep
    Then the link is left in place unchanged

  Scenario: Confirm removal
    Given the removal confirmation is showing on a link
    When the client clicks Remove
    Then the link is permanently deleted
    And the saved-links count decreases by one

## Assumptions
- Removal requires an explicit confirmation step.
- Deletion is permanent; no undo or recycle bin (per client's decision).
