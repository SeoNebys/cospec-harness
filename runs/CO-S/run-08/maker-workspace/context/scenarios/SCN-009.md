Scenario ID: SCN-009
Title: Address without a scheme is tidied to a working link
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When the client saves (or edits) a link whose address lacks "http://" or
"https://" (e.g. "example.com"), the app silently prepends "https://" so the saved
link is clickable and opens correctly. The client approved this quiet tidying
rather than being prompted about it.

## Gherkin
Feature: Address normalization

  Scenario: Add scheme to a bare address
    Given the client enters the address "example.com" with no scheme
    When the client saves the link
    Then the stored link opens as "https://example.com"
    And the client is not prompted to correct the address

## Assumptions
- Normalization only adds a missing scheme; it does not otherwise rewrite the
  address.
- The same normalization applies on create and on edit.
