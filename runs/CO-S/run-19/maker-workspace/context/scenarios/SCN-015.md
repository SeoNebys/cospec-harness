Scenario ID: SCN-015
Title: Remove the final tag without changing the bookmark
Type: Edge Case
Approval status: approved
Approval session: SESSION-015
Approval cycle: 1

## Approved behaviour

A bookmark is allowed to have no tags. Removing its final tag leaves its title, description, source, image, address, and other details untouched. When no bookmarks use the removed tag, that tag also disappears from the sidebar instead of remaining as an empty entry.

## Gherkin

Feature: Remove bookmark tags

  Scenario: Remove a bookmark's only tag
    Given a bookmark has exactly one tag
    And no other bookmarks use that tag
    When the user removes the tag
    And saves the tag changes
    Then the bookmark has no tags
    And all non-tag bookmark details remain unchanged
    And the unused tag no longer appears in the sidebar

## Assumptions

- Tags do not exist independently once no bookmarks use them.
- A bookmark does not require at least one tag.
