# Cycle 1 goal

## Confirmed goal

> Right now I keep bookmarks in my browser and it's a mess — I save a link and then can never find it again.
>
> The core of it is: save a link fast, tag it, and find it again later.
>
> Saving a link fast, tagging it, and being able to find it again — by search, by tag, or in a read-later view — is exactly the heart of it, and editing, deleting, and opening links belong right there with it.
>
> When I paste a link, the app should pull in the page's title and description automatically so I'm not typing everything by hand. And if I happen to paste a link I've already saved, I'd rather it take me to edit the existing one than end up with duplicates.

## Deferred until a later cycle

> Saving a note on a link, keeping a saved copy of the page in case it disappears, and tidying up old ones by archiving instead of deleting.

## Confirmed interface and audience

> A web app, please. I mostly save links while I'm browsing on my computer, so something I can open in my browser makes the most sense. It's just me using it — I don't need accounts for other people or anything like that.
