Scenario ID: SCN-003
Title: Add a note to a saved link with Markdown, preview and expand
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
From a saved item's card, the client can add a personal note (capturing why the
link was saved). The note is written in plain Markdown; after saving, the note is
displayed rendered (bold, italic, inline code, links, headings, bulleted/numbered
lists).

On the card, a short note is shown in full. A longer note (roughly more than two
lines) is shown as a two-line preview, keeping cards compact and the library
scannable, with a "show full note" control that expands the fully rendered note
inline and a "show less" control to collapse it again.

Editing happens in raw Markdown (the client types the markup directly); no rich
live-formatting editor is required. The client can edit an existing note at any
time.

## Gherkin
Feature: Note on a saved link

  Scenario: Add a note in Markdown
    Given a saved item exists in the library
    When the client adds a note written in Markdown and confirms
    Then the note is saved
    And the note is displayed rendered from its Markdown

  Scenario: Short note shown in full
    Given a saved item has a short note (about two lines or fewer)
    Then the whole note is shown on the card without an expand control

  Scenario: Long note previewed and expandable
    Given a saved item has a note longer than about two lines
    Then the card shows a two-line preview and a "show full note" control
    When the client selects "show full note"
    Then the fully rendered note is shown inline
    And a "show less" control collapses it back to the preview

  Scenario: Edit an existing note
    Given a saved item has a note
    When the client edits the note and confirms
    Then the card shows the updated rendered note

## Assumptions
- Notes are edited as raw Markdown text and rendered read-only after saving.
- Supported Markdown: bold, italic, inline code, links, headings, lists (baseline;
  exact supported subset finalised in implementation).
- Preview threshold is approximately two lines / a short length; exact cutoff is a
  presentation detail.
- The note lives on the card, consistent with the scannable-card layout (SCN-001,
  SCN-002).
