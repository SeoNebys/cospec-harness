# Business goal statement

## Cycle 1 — recorded SESSION-001

### The problem (client's words)
"Right now when I find something worth keeping, I just dump it into my browser's
bookmarks, or sometimes I email the link to myself or leave the tab open. The
problem is it all turns into a giant pile. A month later I *know* I saved that
article about something, but I can't find it — the browser folders are a mess and
searching only really looks at the page title, which is often useless. So things
I save just... disappear. I basically never look at them again."

### The goal
The core value is **rediscovery**, not saving. When the client half-remembers
something they saved, they must be able to dig it back up later.

Priority order (client's words):
1. **Finding again (matters most)** — "really *search* them properly — not just
   the title, but whatever I remember about it." Plus labelling: "I want to be
   able to label things in my own way so I can group them."
2. **Saving fast** — "Saving needs to be quick and painless or I won't do it."
   Auto-capture: "when I save something, it grabbed the title and a picture or
   something on its own, so I'm not typing all that in."

Success/failure line (client's words):
"If I save something and can't rediscover it, the app has failed me."

### Scope
- Users: just the client. "It's just for me — no one else uses it."
- Interface form: web browser app. "Something I use in my web browser. That's
  where I'm living when I come across links."
