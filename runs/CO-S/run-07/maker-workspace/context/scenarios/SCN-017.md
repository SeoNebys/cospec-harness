Scenario ID: SCN-017
Title: Continue through a large library in one list
Type: Edge Case
Approval status: approved
Approval session: SESSION-017
Approval cycle: 1

## Approved behaviour
In a large library, bookmarks are ordered with the newest saves first. The first group is shown initially, and Show more bookmarks appends an older group beneath it so the user remains in one continuous list. Search and tag filtering always examine the entire library, including bookmarks not yet visible in the list.

## Gherkin
Feature: Browse a large bookmark library

  Scenario: Append older bookmarks to the current list
    Given the library contains more bookmarks than the initial group
    And the visible bookmarks are ordered newest first
    When the user selects Show more bookmarks
    Then the next older group is appended below the visible bookmarks
    And the bookmarks already visible remain in place

  Scenario: Search and filter beyond the visible group
    Given the library contains bookmarks that are not yet visible
    When the user searches or selects a tag filter
    Then matching considers every bookmark in the library
    And matching bookmarks can be shown regardless of their previous visibility

## Assumptions
- Loading an additional group does not change the newest-first ordering.
- The exact group size may adapt to the final screen without changing the approved behaviour.
