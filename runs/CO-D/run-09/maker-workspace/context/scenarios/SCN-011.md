Scenario ID: SCN-011
Title: A page whose details cannot be read automatically
Type: Error Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When the app cannot read a page automatically (e.g. a private or restricted page), the
review panel does not fail. It calmly explains that it couldn't read the page and asks
the user to add a title themselves, while still allowing the link to be saved. The site
icon is still shown where possible; no preview image is shown.

## Gherkin
Feature: Unreadable page on save

  Scenario: Auto-fill cannot read the page
    Given the user is saving a link whose page cannot be read
    When the app finishes trying to read the page
    Then the panel explains it couldn't read the page and asks for a title
    And the user can still save the link with details they provide

## Assumptions
- The link is still saved normally once the user supplies a title.
- In the prototype, unreadable pages are simulated by certain address endings.
