# Business goal statement

Cycle: 1
Session: SESSION-001
Interface form: Web app (used mainly in the browser)
Users: Single user — personal tool, no sharing or other users

## Goal (in the client's words)

> Right now my links are scattered across browser bookmarks, notes, and messages
> to myself, so I often can't find something when I need it. I want one place
> where I can quickly save a link, organize it with tags, search for it later,
> and keep track of things I still want to read without cluttering everything else.

Confirmed direction:
> "Being able to reliably find links again is the main goal, and I also want a
> clear read-later queue I can work through."

## Core goal

Reliably **find a saved link again when it's needed**, from one trusted place.

## Supporting needs (means to the goal)

- Save a link quickly, with low friction
- Organize links with tags
- Search links later
- A clear **read-later queue** to work through, kept distinct from the general
  collection so it doesn't clutter everything else

## Confirmation

- Direction confirmed by client in SESSION-001.
- Interface form confirmed: web app.
