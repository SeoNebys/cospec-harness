Scenario ID: SCN-013
Title: Explain an empty read-later list
Type: Edge Case
Approval status: approved
Approval session: SESSION-013
Approval cycle: 1

## Approved behaviour
When no bookmarks are marked for later, the Read later view plainly states that it is empty, reminds the person to use a bookmark's star to add something, and offers a way back to all bookmarks.

## Gherkin
Feature: Empty read-later list

  Scenario: No bookmarks are marked for later
    Given no bookmarks are marked for later
    When the person opens Read later
    Then the app states that nothing is saved for later
    And it explains that a bookmark's star adds it to the list
    And it provides a way back to all bookmarks

## Assumptions
- The empty-state guidance is shown inside the normal Read later view.
