Scenario ID: SCN-001
Title: Save a link by pasting it; the app captures the real page title
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The client pastes a raw link into a single input and presses Save — nothing else
is required (no manual name or description). The saved item appears immediately
at the top of the list, showing a brief "Fetching title…" state while the app
automatically retrieves the page's real title (e.g. an article headline). Once
retrieved, the item displays the real page title on top and the site address
(host) underneath. Newest saved items appear first. The client explicitly does
NOT want to type names manually, and explicitly wants the real page title (not a
site-name guess) so saved items can be told apart later.

## Assumptions
- Saving requires only the raw link; no manual name/description entry.
- Each list item shows: real page title (primary), site host (secondary).
- Ordering is newest-first.
- A transient "Fetching title…" state is acceptable to the client.
- (Prototype-only) title fetch is simulated for known example links.
