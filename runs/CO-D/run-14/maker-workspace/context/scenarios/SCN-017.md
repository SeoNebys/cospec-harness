Scenario ID: SCN-017
Title: Leave an empty read-later pile reassuring and useful
Type: Edge Case
Approval status: approved
Approval session: SESSION-017
Approval cycle: 1

## Approved behaviour
When the client marks the final Read later item as read, the count reaches zero and the section shows a friendly "all caught up" state rather than a blank screen. The state explicitly reassures the client that the bookmark remains in the library and provides one clear action to browse the library again.

## Gherkin
Feature: Complete the read-later pile

  Scenario: Mark the final queued item as read
    Given Read later contains exactly one bookmark
    When the client marks that bookmark as read
    Then the Read later count becomes zero
    And a friendly all-caught-up state is shown
    And the state explains that the bookmark remains in the library
    And the client can return directly to the library

## Assumptions
- The preservation reassurance is shown whenever the pile becomes empty.
- The empty state has one primary route back to the library.
