# Business goal statement

- Cycle: 1
- Session: SESSION-001
- Interface form: Web app (opened in a browser)

## Primary goal (client's words)

"Right now, my bookmarks are scattered and hard to find again. I want one
personal place where I can quickly save a link, have its page details filled in
automatically, then organize it with tags and notes."

"The main difference would be being able to reliably find things later through
search and filters, keep a separate read-later list, and archive links I want to
retain without cluttering the main view."

## Core outcome

Reliably finding saved links again later. Everything else serves that outcome:
one personal home for links where nothing gets lost and the main view stays
uncluttered.

## What the client values (verbatim / near-verbatim)

- Quick saving that still produces useful, recognizable entries.
- Automatic page details are a **core** part (not just convenience): collect the
  page **title, description, favicon, and preview image**.
- Let the client **correct the title or description**.
- Organize with **tags and notes**.
- Reliable **search and filters** to find things later.
- A separate **read-later list**.
- **Archive** links to retain without cluttering the main view.

## Scope notes

- Single personal user ("one personal place", "personal").
- Interface: web app in a browser (confirmed).

## Assumptions to confirm during SbE loop

- Single-user, personal use (no sharing/collaboration mentioned).
- "Automatic page details" are fetched from the link's page when saving.
