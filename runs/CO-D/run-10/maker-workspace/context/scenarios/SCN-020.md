Scenario ID: SCN-020
Title: Sort the current bookmark view
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A compact Sort dropdown sits beside the current result count and offers Newest first, Oldest first, and Name A–Z. Newest first is the default. Changing the selection reorders cards immediately. The chosen order continues to apply when moving between All bookmarks, a label view, and search results rather than resetting with each view.

## Gherkin
Feature: Sort bookmark views

  Scenario Outline: Reorder the current bookmark view
    Given the user is viewing a set of bookmarks
    When the user chooses <order> from the Sort dropdown
    Then the visible bookmark cards immediately appear in <order>

    Examples:
      | order        |
      | Newest first |
      | Oldest first |
      | Name A-Z     |

  Scenario: Preserve the chosen order across views
    Given the user has chosen a bookmark order
    When the user moves between All bookmarks, a label, and search results
    Then each view uses that chosen order

## Assumptions
- Newest first is the initial order for a new library.
