Scenario ID: SCN-012
Title: Trying to save something that is not a link
Type: Error Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When the user tries to save text that is not a web address (e.g. free text with spaces
or no domain), the app gently points out that it doesn't look like a link and gives an
example, without opening the save panel or saving anything.

## Gherkin
Feature: Invalid save input

  Scenario: Save non-link text
    Given the save bar contains text that is not a web address
    When the user presses Save
    Then a gentle message says it doesn't look like a link and shows an example
    And no save panel opens and nothing is saved

## Assumptions
- A "link" is recognised by starting with http(s):// or containing a domain-like dot,
  and containing no spaces.
