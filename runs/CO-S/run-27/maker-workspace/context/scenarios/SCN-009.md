Scenario ID: SCN-009
Title: Edit the existing bookmark when an address is already saved
Type: Happy Path
Approval status: approved
Approval session: SESSION-009
Approval cycle: 1

## Approved behaviour
When a person pastes an address that has already been saved, the app clearly explains that it is already saved and opens the existing bookmark's edit form with its current title, description, and tags filled in. The app does not create a second copy.

## Gherkin
Feature: Preventing duplicate bookmarks

  Scenario: Paste an address that is already saved
    Given a bookmark with an address already exists
    When the person pastes that same address into the save field
    Then the app explains that the address is already saved
    And the existing bookmark's edit form opens
    And its current title, description, and tags are filled in
    And no additional bookmark is created

## Assumptions
- Duplicate detection happens as soon as the pasted address is recognized.
- The person is taken directly to editing without an additional confirmation step.
- Exact duplicate-address behavior is approved; address normalization edge cases are explored separately.
