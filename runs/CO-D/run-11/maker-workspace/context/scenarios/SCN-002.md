Scenario ID: SCN-002
Title: Edit a saved bookmark's title, description and web address
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
From a saved bookmark the client opens an editor and can change the bookmark's
title, its description, and its web address. Saving the changes updates the
bookmark in place and briefly highlights it. Cancelling discards the changes.
An empty web address is not accepted.

## Gherkin
Feature: Edit a bookmark

  Scenario: Correct a bookmark's details
    Given a saved bookmark
    When the client opens its editor and changes the title, description or web
         address and saves the changes
    Then the bookmark is updated in place with the new values
    And the updated bookmark is briefly highlighted

  Scenario: Cancel editing
    Given the client is editing a saved bookmark
    When the client cancels
    Then no changes are applied

  Scenario: Web address cannot be emptied
    Given the client is editing a saved bookmark
    When the client clears the web address and tries to save
    Then the change is rejected and the client is told an address is required

## Assumptions
- Both title and description are editable; address is also editable (client
  confirmed the address addition).
