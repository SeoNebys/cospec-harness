Scenario ID: SCN-005
Title: Reuse an existing label from suggestions
Type: Happy Path
Approval status: approved
Approval session: SESSION-005
Approval cycle: 1

## Approved behaviour
As a person types a label, labels previously used anywhere in the collection are suggested when their beginnings match, regardless of capitalization. Choosing a suggestion fills in the established spelling so the same label can be reused consistently.

## Gherkin
Feature: Reuse personal labels consistently

  Scenario Outline: Suggest an existing label without regard to capitalization
    Given the label "reference" has been used in the collection
    When the person begins a bookmark label with "<typed text>"
    Then "reference" is suggested as a previously used label
    When the person chooses that suggestion
    Then the label field uses the established spelling "reference"

    Examples:
      | typed text |
      | ref        |
      | Ref        |
      | REF        |

## Assumptions
- Suggestions draw from labels used anywhere in the personal collection.
- Suggestions match from the beginning of a label.
