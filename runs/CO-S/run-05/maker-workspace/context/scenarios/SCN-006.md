Scenario ID: SCN-006
Title: Preserve a bookmark when page details cannot be collected
Type: Error Case
Approval status: approved
Approval session: SESSION-006
Approval cycle: 1

## Approved behaviour

If a page's title and description cannot be collected, the link is still
saved using its address for recognition. It is clearly marked as needing
details and offers a way to try collecting the details again later, so a
temporary page failure never loses the bookmark.

## Gherkin

Feature: Saving bookmarks

  Scenario: Page details are unavailable while saving
    Given the client supplies a valid web address
    And the page's title and description cannot be collected
    When the save attempt completes
    Then the bookmark is kept in the collection
    And its address is shown for recognition
    And it is marked as needing details
    And the client can retry collecting the details later

## Assumptions

- Failure to collect page details does not prevent a valid address from being saved.
- The originating address is available even when other details are unavailable.
