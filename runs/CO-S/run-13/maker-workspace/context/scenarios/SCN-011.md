## Approved behaviour

When there are no saved bookmarks at all (a new user), the list area shows a
clear, welcoming message: "No bookmarks yet. Paste a web address above to save
your first one." The tab counts read 0. The save form is fully available. The
state reads as welcoming, not broken.
