Scenario ID: SCN-016
Title: Import browser bookmarks and export the collection (standard format)
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Import (from Settings → Import browser bookmarks): the client chooses the .html
bookmarks file exported from their browser. A preview shows how many were found,
how many are new versus already saved (skipped, using the SCN-003 same-link
rule). On import: browser folders become tags, each bookmark's original saved
date is preserved, and imported bookmarks start as "To read". The preview
explains that preserved copies are NOT created during import (to keep a large
import quick); the client can "Save a copy" on any bookmark afterward.

Export (from Settings → Export collection): produces a file in the standard
browser-bookmark HTML format so browsers and other bookmark tools can open it. It
includes the whole collection, including archived bookmarks. It preserves at
least titles, tags, and saved dates when moved to other tools, and also carries
the app-specific details (read status, archived flag, notes) so a re-import here
loses nothing. The file downloads and can be re-imported.

The client confirmed: folders→tags; dates preserved; duplicates skipped; imported
links start To read; the no-auto-copy exception is acceptable as long as it is
explained in the preview and copies can be made afterward; export uses the
standard format, includes archived items, and preserves titles/tags/dates (plus
app extras).

## Gherkin
Feature: Import and export

  Scenario: Import a browser bookmarks file
    When I import a browser .html bookmarks file
    Then a preview shows the number found, new, and already-saved (skipped)
    And it explains preserved copies are not made during import
    When I confirm the import
    Then new bookmarks are added with folders as tags and original dates kept
    And they start as "To read"
    And links already saved are skipped (no duplicates)

  Scenario: Export the collection
    When I export the collection
    Then I get a standard browser-bookmark HTML file
    And it includes all bookmarks, including archived ones
    And it preserves titles, tags and saved dates for other tools
    And it also carries read status, archived flag and notes for re-import here

## Assumptions
- Import maps folders to tags; skips duplicates by the same-link rule; no auto
  preserved copies during import.
- Export uses the Netscape/standard bookmark HTML format (interoperable), with
  extra attributes for app-specific fields.
