Scenario ID: SCN-014
Title: Prevent blank and duplicate labels
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The Add action remains unavailable for a blank or whitespace-only label. Re-entering a label already attached to the bookmark does not create another pill, even if capitalization or surrounding spaces differ, and the client is told that the label is already attached.

## Gherkin
Feature: Keep personal labels tidy

  Scenario: Attempt to add a blank label
    Given the quick label input is empty or contains only spaces
    Then the Add action is unavailable
    And no label is created

  Scenario: Re-enter an attached label with different capitalization or spacing
    Given a bookmark already has a label
    When the client enters the same label with different capitalization or surrounding spaces
    And chooses Add
    Then no second label pill is created
    And the client is told that the label is already on the bookmark

## Assumptions
- Label uniqueness ignores capitalization and surrounding whitespace while preserving the existing label's displayed spelling.
