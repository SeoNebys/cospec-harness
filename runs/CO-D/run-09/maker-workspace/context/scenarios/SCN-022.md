Scenario ID: SCN-022
Title: Display preferences — text size and how many items are shown
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A Display panel lets the user set simple display preferences: the text size of the list
(Small / Medium / Large) and how many items are shown at a time (5 / 10 / 25 / 50 / Show all).
When more results exist than the chosen number, a "Show more" control reveals the next batch,
and the count shows "Showing N of M". These preferences are remembered between sessions,
alongside the remembered sort order. "Select all in this view" still spans all matching
results, not just the currently shown batch.

## Gherkin
Feature: Display preferences

  Scenario: Change the text size
    Given the Display panel is open
    When the user chooses a text size
    Then the list text scales accordingly

  Scenario: Limit how many items are shown
    Given more results exist than the chosen number
    When the user sets "items shown" to that number
    Then only that many are shown with a "Show more" control and a "Showing N of M" count
    And "Show more" reveals the next batch

  Scenario: Preferences are remembered
    Given the user has set a text size and an items-shown number
    When the user reopens the app
    Then the same text size and items-shown number are used

  Scenario: Select all still spans all matching results
    Given the list is limited to a shown batch
    When the user chooses "Select all in this view"
    Then all matching results are selected, not just the shown batch

## Assumptions
- Defaults: Medium text size, 25 items shown.
- Changing search, filter, sort, or view resets to the first batch.
