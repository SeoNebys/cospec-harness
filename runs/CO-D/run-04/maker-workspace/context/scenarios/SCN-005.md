Scenario ID: SCN-005
Title: Edit a saved link's details in a focused pop-up
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Each card has an Edit control (appears on hover). Activating it opens a focused
pop-up dialog with the library dimmed behind it. The pop-up lays out all the
link's fields together with room to breathe: Name, Description, and Web address.
The client can change any of them and Save, or Cancel to discard. The library
holds still (does not reflow) while editing. Editing is how the client corrects
a mangled auto-title or fills in an unreadable one, and how they get the final
say over the app's guess.

## Gherkin
Feature: Edit a saved link

  Scenario: Editing a link's details in the pop-up
    Given a saved link is shown in the library
    When the client activates Edit on its card
    Then a focused pop-up opens with Name, Description and Web address fields
    And the library is dimmed and does not move behind it
    When the client changes fields and saves
    Then the card reflects the new details
    When the client cancels instead
    Then no changes are kept

## Assumptions
- Editing chosen as a focused pop-up (vs in-place / per-field), because the
  client often edits several fields at once and wants no list reflow.
  (client confirmed, comparing 3 styles)
- The web address itself is editable (to fix a slightly-wrong paste).
  (client confirmed)
