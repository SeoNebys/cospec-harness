Scenario ID: SCN-007
Title: Archive a bookmark to keep it without cluttering the main view
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Each bookmark can be archived. Archived bookmarks are hidden from both the All
view and the To read view, so they do not clutter the main lists, but are kept.
An Archived view lists them, where they can be unarchived, returning them to the
main list. View tabs show counts.

## Gherkin
Feature: Archiving

  Scenario: Archive a bookmark
    Given a bookmark shown in the main list
    When the client archives it
    Then it is hidden from the All and To read views
    And it appears in the Archived view

  Scenario: Unarchive a bookmark
    Given an archived bookmark
    When the client unarchives it
    Then it returns to the main list

## Assumptions
- Archived items are excluded from To read as well as All (client confirmed).
