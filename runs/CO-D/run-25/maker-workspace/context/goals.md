# Cycle 1 goal

## Client statement

> Right now saving a link is kind of a mess for me. I paste a URL into wherever and then I have to type in what it is myself, and later I can't find anything because it's just a wall of links with no real way to search or sort them.
>
> So when this is done, I'd want a few things to feel different:
>
> When I save a link, I mostly just want to drop in the address and have it figure out the rest — grab the page's title, a short description, the little site icon, maybe a preview image — so I'm not typing all that by hand. If I want to fix the title or description afterward, I should be able to.
>
> Then I want to actually be able to find things again. I want to search across my links — the titles, descriptions, my own notes — and have it not care about capital letters. And I want to organize with labels I put on things, so I can click a label and just see those.
>
> I also want a way to say "I'll read this later" and keep those separate, so my to-read pile doesn't get lost in everything else.
>
> And the list itself should be pleasant to skim — I want to see what each thing is at a glance, not decode a raw link.
>
> That's the heart of it for me.

## Confirmation

> Yes, that's the right overall goal. You've captured the heart of it — saving starts with just a URL and fills itself in, I can still fix the details, and later I can actually find things again through search, my notes, and labels, with a separate read-later pile and a list that's easy to skim.
>
> There's more I'll care about as we get further in, but as the big picture, that's exactly it. Let's go.

## Interface form

> A web app, please. I'd like to open it in my browser on my computer. It's really just for me — my own personal collection — so nothing fancy about other people using it.
