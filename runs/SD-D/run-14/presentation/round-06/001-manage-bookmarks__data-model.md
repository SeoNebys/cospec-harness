# Data Model: Bookmark Manager

## Conventions

- Identifiers are opaque UUID strings generated by the server.
- Timestamps are UTC ISO-8601 values at the contract boundary and integer epoch milliseconds in SQLite.
- Boolean values are constrained integers (`0` or `1`) in SQLite.
- User-facing text is stored as entered after trimming outer whitespace; normalized companion values support uniqueness and case-insensitive matching.
- All foreign keys are enforced. Destructive cascades are explicitly listed below.
- Image content is stored in the controlled asset directory; database rows store only opaque asset IDs and metadata.

## Entity: Bookmark

The authoritative record for a saved destination.

| Field | Type | Required | Rules |
|---|---|---:|---|
| `id` | UUID | yes | Primary key |
| `url` | string | yes | Normalized public HTTP(S) URL; maximum 4,096 characters |
| `normalized_url` | string | yes | Unique; scheme/host normalized, fragment removed; used for duplicate detection |
| `title` | string | yes | 1–500 characters after retrieval/fallback; defaults to hostname when no title is available |
| `description` | string | no | Maximum 2,000 characters |
| `notes` | string | no | Maximum 20,000 characters |
| `favicon_asset_id` | UUID | no | References an active favicon asset |
| `preview_asset_id` | UUID | no | References an active preview-image asset |
| `is_favorite` | boolean | yes | Default `false` |
| `read_state` | enum | yes | `read` or `unread`; default `read` |
| `archived_at` | timestamp | no | Null means active |
| `metadata_status` | enum | yes | `pending`, `complete`, `partial`, `failed` |
| `metadata_error_code` | string | no | Stable error code when status is partial/failed |
| `metadata_refreshed_at` | timestamp | no | Last terminal enrichment attempt |
| `title_source` | enum | yes | `retrieved`, `user`, or `fallback` |
| `description_source` | enum | no | `retrieved` or `user` |
| `favicon_source` | enum | no | `retrieved` or `user` |
| `preview_source` | enum | no | `retrieved` or `user` |
| `created_at` | timestamp | yes | Immutable |
| `updated_at` | timestamp | yes | Updated on user-visible or capture-state change |

**Indexes**: unique `normalized_url`; `created_at`; `updated_at`; `archived_at`; `(read_state, archived_at)`; `(is_favorite, archived_at)`; normalized title and destination expressions used by supported sorts.

**Relationships**:

- Many-to-many with Tag through BookmarkTag.
- Zero-or-one current PageSnapshot.
- Zero-or-many CaptureJob records, with at most one active job per bookmark.
- Asset references use restrictive deletion; replacement changes the reference before old-file cleanup.

## Entity: Tag

| Field | Type | Required | Rules |
|---|---|---:|---|
| `id` | UUID | yes | Primary key |
| `name` | string | yes | Trimmed, 1–80 characters |
| `normalized_name` | string | yes | Case-folded; unique |
| `created_at` | timestamp | yes | Immutable |

Tag suggestions search `normalized_name` by prefix and then substring, returning at most 20 existing tags ordered by prefix quality, usage count, then name.

## Entity: BookmarkTag

| Field | Type | Required | Rules |
|---|---|---:|---|
| `bookmark_id` | UUID | yes | Foreign key to Bookmark, cascade on bookmark delete |
| `tag_id` | UUID | yes | Foreign key to Tag |
| `created_at` | timestamp | yes | Immutable |

The compound primary key is (`bookmark_id`, `tag_id`). Removing the last association does not automatically delete the Tag; unused tags remain available for reuse and can be cleaned through settings in a future feature.

## Entity: Asset

| Field | Type | Required | Rules |
|---|---|---:|---|
| `id` | UUID | yes | Primary key and only public path identifier |
| `kind` | enum | yes | `favicon`, `preview`, or `snapshot` |
| `relative_path` | string | yes | Server-generated path below the asset root; unique |
| `media_type` | enum | yes | Approved image types only |
| `byte_size` | integer | yes | Positive and within kind-specific limit |
| `width` | integer | no | Positive pixels when known |
| `height` | integer | no | Positive pixels when known |
| `content_hash` | string | yes | Digest used for integrity/deduplication checks |
| `created_at` | timestamp | yes | Immutable |

Only the storage service converts an asset ID into a path. User-provided filenames or paths are never persisted.

## Entity: PageSnapshot

| Field | Type | Required | Rules |
|---|---|---:|---|
| `bookmark_id` | UUID | yes | Primary key and foreign key to Bookmark, cascade on delete |
| `asset_id` | UUID | no | Current viewable snapshot asset; null for pending/failed-without-prior-capture |
| `status` | enum | yes | `pending`, `complete`, `partial`, `failed` |
| `captured_url` | string | no | Final public URL after redirects |
| `captured_at` | timestamp | no | Present for complete/partial capture |
| `limitation_code` | string | no | Stable reason for partial/failed capture |
| `error_message` | string | no | Sanitized user-facing explanation |
| `updated_at` | timestamp | yes | Last status change |

**Invariant**: A refresh does not clear the prior `asset_id` while work is pending. On success, the new asset replaces it atomically. On refresh failure, the prior asset remains viewable and status/error describe the failed refresh separately in the API projection.

## Entity: SavedView

| Field | Type | Required | Rules |
|---|---|---:|---|
| `id` | UUID | yes | Primary key |
| `name` | string | yes | Trimmed, 1–120 characters |
| `normalized_name` | string | yes | Case-folded; unique |
| `query` | string | yes | Maximum 2,000 characters; must parse successfully |
| `filters_json` | object | yes | Versioned canonical filters: tags, favorite, read, archive state |
| `sort_field` | enum | yes | `createdAt`, `updatedAt`, `title`, or `destination` |
| `sort_direction` | enum | yes | `asc` or `desc` |
| `created_at` | timestamp | yes | Immutable |
| `updated_at` | timestamp | yes | Changes when definition or name changes |

Saved views contain no bookmark IDs. Opening one evaluates its definition against current records.

## Entity: DisplayPreferences

Singleton row for this installation.

| Field | Type | Required | Rules |
|---|---|---:|---|
| `singleton_key` | string | yes | Fixed value `default` |
| `theme` | enum | yes | `light`, `dark`, or `system`; default `system` |
| `density` | enum | yes | `comfortable` or `compact`; default `comfortable` |
| `updated_at` | timestamp | yes | Last preference change |

## Entity: CaptureJob

Durable work record for metadata and snapshot retrieval.

| Field | Type | Required | Rules |
|---|---|---:|---|
| `id` | UUID | yes | Primary key |
| `bookmark_id` | UUID | yes | Foreign key to Bookmark, cascade on delete |
| `kind` | enum | yes | `initial` or `refresh` |
| `status` | enum | yes | `pending`, `processing`, `succeeded`, `partial`, `failed`, `cancelled` |
| `replace_user_metadata` | boolean | yes | True only after explicit confirmation |
| `attempt_count` | integer | yes | Starts at zero; bounded retry count |
| `available_at` | timestamp | yes | Supports bounded retry delay |
| `started_at` | timestamp | no | Current/last attempt |
| `finished_at` | timestamp | no | Terminal state time |
| `error_code` | string | no | Stable diagnostic category |
| `created_at` | timestamp | yes | Immutable |

**Invariant**: A partial unique index allows no more than one `pending` or `processing` job per bookmark. At startup, stale `processing` jobs return to `pending` with their attempt count preserved.

## Derived API Projection: BookmarkSummary

List endpoints join Bookmark with tags, asset URLs, current snapshot status, and selection-safe identifiers. The projection also includes:

- `displayHost`, derived from the normalized destination.
- `snapshot.available`, true only when a current asset exists.
- `snapshot.refreshStatus`, allowing a prior snapshot to remain available while refresh is pending/failed.
- `tagNames`, deterministically sorted case-insensitively.

## Search Model

The parsed query is ephemeral and is never stored as executable SQL.

```text
Expression = Term(text | phrase | exact-tag)
           | Not(Expression)
           | And(Expression, Expression)
           | Or(Expression, Expression)
```

- Plain terms perform case-insensitive substring matching against each searchable Bookmark field and Tag name.
- A phrase performs case-insensitive contiguous matching within any one field.
- An exact tag matches `Tag.normalized_name` exactly.
- Filters are applied as an additional AND around the parsed expression.
- Empty query text produces a match-all expression.

## State Transitions

### Bookmark lifecycle

```text
active ──archive──> archived
archived ──restore──> active
active|archived ──confirmed delete──> deleted (terminal)
```

Deletion cascades tag joins, capture jobs, and snapshot metadata; referenced asset files are queued for idempotent cleanup.

### Read state

```text
read ──mark read later/unread──> unread
unread ──mark read──> read
```

Archive/restore does not change read state. The dedicated unread view additionally requires active state.

### Capture lifecycle

```text
pending ──worker claim──> processing
processing ──all expected outputs captured──> succeeded/complete
processing ──some usable outputs captured──> partial
processing ──retryable failure, attempts remain──> pending
processing ──terminal failure──> failed
pending|processing ──bookmark deleted──> cancelled/deleted
```

### User-edit protection

Editing title, description, favicon, or preview sets the corresponding source to `user`. Normal enrichment updates only non-user fields. An explicit refresh with replacement confirmation may reset selected fields to retrieved/fallback values; unconfirmed refresh never overwrites them.

## Transaction Boundaries

- Bookmark creation, initial PageSnapshot row, and CaptureJob creation are one transaction.
- Bookmark edits and tag replacement are one transaction.
- Saved-view create/update validates the query before its transaction.
- Explicit-ID and all-results bulk mutations are each one transaction after the server resolves and reports the current target count.
- Snapshot replacement writes a temporary file first, then transactionally changes Asset/PageSnapshot references, then removes the prior file idempotently.
- Bookmark deletion commits relational deletion before best-effort file removal; failed cleanup is retained in an internal cleanup queue/log and never resurrects the bookmark.
