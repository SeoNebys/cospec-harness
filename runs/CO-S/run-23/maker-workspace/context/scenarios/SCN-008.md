Scenario ID: SCN-008
Title: Reject text that is not a usable web address
Type: Error Case
Approval status: approved
Approval session: SESSION-008
Approval cycle: 1

## Approved behaviour
From an empty collection, the client attempted to save prepared text that was not a web address. Nothing was added, the collection remained empty, and the address box received a clear correction message explaining what a complete web address looks like. The client confirmed the app should neither save invalid text nor fail silently.

## Gherkin
Feature: Save bookmarks

  Scenario: Attempt to save text that is not a web address
    Given the collection is empty
    And the address box contains text that does not identify a web page
    When the user saves the bookmark
    Then no bookmark is created
    And the collection remains empty
    And a clear correction message is shown at the address box
    And the user can correct the entered text

## Assumptions
- Only complete web addresses using HTTP or HTTPS can be saved.
- Invalid input remains available for correction.
