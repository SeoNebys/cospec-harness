Scenario ID: SCN-003
Title: Correct a bookmark's address and refresh its page details
Type: Happy Path
Approval status: approved
Approval session: SESSION-003
Approval cycle: 1

## Approved behaviour
The web address is editable in the same inline bookmark editor. When the person replaces it with the address of a genuinely different page and saves, the card gathers fresh page-owned details so its title, description, source, site icon, and preview image describe the new destination rather than the old one.

## Gherkin
Feature: Editing bookmark details

  Scenario: Point a bookmark at a different page
    Given a saved bookmark is visible in the collection
    When the person opens its inline editor
    And replaces its address with the address of a different page
    And saves the changes
    Then the bookmark points to the new address
    And its title, description, source, site icon, and preview image are gathered from the new page
    And none of the old page's gathered details remain on the card

## Assumptions
- The replacement address points to a genuinely different page that provides fresh details.
- Protection for a carefully hand-corrected title is an edge case to resolve separately.
