Scenario ID: SCN-005
Title: Open a preserved reading copy of a saved web page
Type: Happy Path
Approval status: approved
Approval session: SESSION-005
Approval cycle: 1

## Approved behaviour
When a normal web page is saved as a bookmark, the app preserves a clean, readable copy of its meaningful text and images. The bookmark card indicates that a copy was saved and provides a direct action to view it. The copy records when it was saved and where it originally came from, and remains readable even if the original address later stops working.

## Gherkin
Feature: Preserve saved content

  Scenario: Read a saved copy when the original page is unavailable
    Given a normal web page was saved as a bookmark
    And the app preserved its meaningful text and images
    And the original address is no longer available
    When the person chooses to view the saved copy from the bookmark card
    Then a clean reading copy opens
    And it contains the preserved text and images
    And it shows when the copy was saved
    And it identifies the original source

## Assumptions
- A readable copy is preserved automatically for a normal web page.
- The saved-copy action is available directly on the bookmark card.
- Normal web pages are presented in a clean reading view rather than as a visual facsimile of the original layout.
