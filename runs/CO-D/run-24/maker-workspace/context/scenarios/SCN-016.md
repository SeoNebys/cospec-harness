Title: Personal settings — default sort, list density, text size
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

A Settings screen holds the client's personal preferences:
- Default sort order (newest/oldest/title A–Z/Z–A): used each time the app opens.
- List density with three levels — Comfortable (shows everything), Cozy (smaller
  previews, shorter descriptions), Compact (hides previews and descriptions to fit
  many more per screen). The client confirmed three levels are useful, each with a
  clear purpose.
- Text size: Small / Medium / Large, resizing the list text for comfort on phone
  vs. large monitor.

Changes apply immediately (no separate save step) so the client can compare them.
The preferences follow the client across devices along with the bookmarks (part
of the one shared account, SCN-011). No other settings are needed for this build.

## Gherkin

Feature: Settings

  Scenario: Default sort on open
    Given the client sets a default sort order
    When the app is opened
    Then the list uses that order by default

  Scenario: List density
    When the client selects Comfortable, Cozy, or Compact
    Then the amount shown per card changes immediately (Compact hides previews and descriptions)

  Scenario: Text size
    When the client selects Small, Medium, or Large
    Then the list text resizes immediately

  Scenario: Preferences follow the account
    Given preferences are set
    When the client uses another device signed into the same account
    Then the same preferences apply

## Assumptions

- Settings: default sort, density (3 levels), text size (3 levels).
- Changes apply live; persisted per account and synced across devices.
- No additional settings in this build.
