Scenario ID: SCN-016
Title: Import an existing browser bookmark collection
Type: Happy Path
Approval status: approved
Approval session: SESSION-016
Approval cycle: 1

## Approved behaviour
From an empty library, a person can choose the bookmark file exported by their browser. Before anything changes, the app previews how many bookmarks were found, which browser folders will become labels, and how many original saved dates are available. Nothing is imported until the person confirms. The imported bookmarks retain their names, use their former folders as labels, and retain original saved dates whenever the browser file contains them.

## Gherkin
Feature: Import browser bookmarks

  Scenario: Review and import an existing browser collection
    Given the person's library is empty
    And they have a bookmark file exported by their browser
    When they choose that file for import
    Then the app previews the number of bookmarks found
    And it previews the browser folders that will become labels
    And it shows how many original saved dates were found
    And the library remains unchanged
    When the person confirms the import
    Then the bookmarks are added with their existing names
    And browser folders are represented as labels
    And available original saved dates are retained

## Assumptions
- Import accepts a standard bookmark file exported by a browser.
- Import always requires review and confirmation before modifying the library.
- Original saved dates can only be retained when present in the imported file.
