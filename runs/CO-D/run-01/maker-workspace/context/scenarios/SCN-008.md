Scenario ID: SCN-008
Title: Manage a separate Read later pile
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Each bookmark has a dedicated, always-visible bookmark-shaped toggle for the frequently used Read later status. Turning it on adds a visible status marker, increments the Read later count, and includes the item in the separate Read later view. Turning the lit toggle off while viewing Read later removes the item from that view, decrements the count, and shows a friendly all-caught-up state when no items remain. Finishing an item clears only its Read later status; the bookmark remains in All bookmarks.

## Gherkin
Feature: Read later collection

  Scenario: Add a bookmark to Read later
    Given a saved bookmark is not marked for later
    When the person turns on its visible Read later toggle
    Then the card shows that it is saved for later
    And the Read later navigation count increases
    And the bookmark appears in the Read later view

  Scenario: Finish a Read later bookmark
    Given a bookmark is visible in the Read later view
    When the person turns off its lit Read later toggle
    Then the bookmark is removed from the Read later view
    And the Read later count decreases
    And an all-caught-up state is shown when no items remain
    And the bookmark remains in All bookmarks without a Read later marker

## Assumptions
- Read later is a dedicated visible toggle because it is changed frequently.
- Other less-frequent bookmark actions remain in the three-dot action menu.
- Read later status is independent of whether the bookmark itself is retained.
