Scenario ID: SCN-025
Title: Keep an archived bookmark archived when its address is saved again
Type: Edge Case
Approval status: approved
Approval session: SESSION-025
Approval cycle: 1

## Approved behaviour

When an address belongs to an existing archived bookmark, the app does not create a duplicate and does not automatically return the bookmark to the active collection. It opens the existing bookmark for editing, clearly indicates that the bookmark is archived, and provides a separate, deliberate action to restore it.

## Gherkin

Feature: Preventing duplicates across the archive

  Scenario: Save the address of an archived bookmark again
    Given a bookmark for the address is archived
    When the user attempts to save that address again
    Then no additional bookmark is created
    And the archived bookmark opens for editing
    And the editor clearly indicates that the bookmark is archived
    And the bookmark remains archived
    And the user can explicitly choose to restore it

## Assumptions

- Duplicate recognition applies across both active and archived bookmarks.
- Editing an archived bookmark does not implicitly restore it.
