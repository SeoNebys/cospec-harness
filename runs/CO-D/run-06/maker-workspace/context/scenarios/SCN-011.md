Scenario ID: SCN-011
Title: Reject a malformed web address
Type: Error Case
Approval status: approved
Approval session: SESSION-011
Approval cycle: 1

## Approved behaviour
If a person enters something that is not a valid web address, the app does not save a bookmark or increase the collection count. It shows a correction beside the save form so the address can be fixed there.

## Gherkin
Feature: Saving bookmarks

  Scenario: Submit a malformed web address
    Given the person has entered text that is not a valid web address
    When the person tries to save the bookmark
    Then no bookmark is added
    And the collection count remains unchanged
    And a corrective message is shown beside the save form

## Assumptions
- A complete HTTP or HTTPS web address is considered valid input.
- The entered value remains available to correct.
