Scenario ID: SCN-018
Title: Add and revise a personal note
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A person can add their own note to a saved bookmark, see it clearly distinguished from the automatically gathered description, and reopen it for editing later. Personal notes are included in bookmark search.

## Gherkin
Feature: Personal bookmark notes

  Scenario: Add a personal note
    Given a saved bookmark has an automatically gathered description
    When the person adds and saves a personal note
    Then the note appears on the bookmark
    And it is visibly identified as the person's note
    And it remains distinct from the gathered description
    And it can be found through search

  Scenario: Revise a personal note
    Given a saved bookmark has a personal note
    When the person chooses to edit the note
    And saves revised text
    Then the revised note replaces the previous note

## Assumptions
- Notes are optional.
- Personal notes and gathered descriptions are stored and presented separately.
