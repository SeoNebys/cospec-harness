Scenario ID: SCN-007
Title: Open the original page from a bookmark
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Selecting a bookmark's title or anywhere on its card opens the original page.
The user does not have to aim at the small address text. The Edit button and tag
chips retain their own actions and do not open the page.

## Gherkin
Feature: Open the original page

  Scenario: Open from the card
    Given a saved bookmark
    When the user clicks the card or its title (not the Edit button or a tag)
    Then the original page opens

  Scenario: Interactive elements keep their behaviour
    When the user clicks the Edit button or a tag chip on a card
    Then editing or tag-filtering happens instead of opening the page

## Assumptions
- The page opens in a new browser tab.
