Scenario ID: SCN-014
Title: Recognize the same page despite superficial address differences
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Addresses that lead to the same page are treated as one bookmark even when they differ by a www prefix, a trailing slash, or common tracking information added when a link is copied. Attempting to save any such variation opens the existing bookmark for editing instead of creating a near-identical duplicate.

## Assumptions
- Tracking information is removed only when it is known not to identify distinct page content.
- Meaningful address information that selects different content is preserved.
