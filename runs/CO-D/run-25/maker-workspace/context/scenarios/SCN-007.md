Scenario ID: SCN-007
Title: Reuse an existing label from suggestions
Type: Happy Path
Approval status: approved
Approval session: SESSION-007
Approval cycle: 1

## Approved behaviour
As the person types a label, existing labels that begin with those letters are suggested without requiring matching capitalization. Selecting a suggestion adds it as a pill using its established spelling, helping avoid near-duplicate labels.

## Gherkin
Feature: Bookmark labels

  Scenario: Select a matching existing label
    Given the personal collection already contains the labels "Reference", "Research", and "Reading"
    And a bookmark's inline editor is open
    When the person types "re" in the label field
    Then "Reference", "Research", and "Reading" are suggested
    When the person selects "Reference"
    Then "Reference" is added as a label pill with its established spelling

## Assumptions
- Suggestions match from the beginning of an existing label.
- Matching does not care about capitalization.
