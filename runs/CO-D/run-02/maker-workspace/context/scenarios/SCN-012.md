Scenario ID: SCN-012
Title: Calm empty states for the initial app, each view, and no search matches
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

Instead of a blank screen, the app shows a calm, explanatory message when there
is nothing to display:
- Before anything is saved: an invitation to paste a link to begin.
- An empty Reading list: explains bookmarks can be added to read later.
- An empty Archive: explains archived bookmarks are kept here, out of the
  collection and searches.
- A collection emptied only because everything is archived: explains that.
- A search with no matches: a "no matches" message naming the current view,
  rather than an empty list.

## Gherkin

Feature: Empty states

  Scenario: Initial empty app
    Given no bookmarks have been saved
    Then a message invites me to paste a link to begin

  Scenario: Empty reading list
    Given no bookmarks are on the reading list
    When I open the Reading list
    Then a message explains I can add bookmarks to read later

  Scenario: Empty archive
    Given nothing is archived
    When I open the Archive
    Then a message explains archived bookmarks are kept here

  Scenario: No search matches
    Given a search that matches nothing in the current view
    Then a "no matches" message is shown that names the current view

## Assumptions
- Empty-state messages are informational only; no data is implied.
