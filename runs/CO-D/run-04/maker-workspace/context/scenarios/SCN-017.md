## Approved behaviour
### PDFs as first-class documents
When the thing saved is a PDF (paper, manual, menu), the saved copy IS the
actual PDF file (pages intact), not a text scrape. A PDF link is a first-class
citizen in every other way: findable by its name, note, and labels; flaggable
read-later; set-aside-able; sortable; deletable — no special case off to the
side. (Future bonus, not committed: searching the words *inside* the PDF;
finding it by name/label is enough for now.)

### Opt-in public web-archive copy (belt & braces)
For the precious few links the client truly cannot lose, they can choose to also
lodge a copy in an independent public web archive — a copy that lives outside
this app and outside the client's computer. This is strictly per-link and never
automatic. The FIRST time, it explains in full that this makes a public copy and
shares the address with an outside service, and asks yes/no; once understood,
subsequent uses need only a light "make a public copy? yes/no". A link with a
public copy shows an indicator and a link to view it. Automatic or bulk
public-archiving is explicitly forbidden — the client chooses each one, eyes
open.
