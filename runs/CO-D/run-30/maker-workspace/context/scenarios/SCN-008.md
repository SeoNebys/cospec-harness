Scenario ID: SCN-008
Title: Reuse existing labels or create a new label for a bookmark
Type: Happy Path
Approval status: approved
Approval session: SESSION-008
Approval cycle: 1

## Approved behaviour

The bookmark editor includes a label picker that visibly offers labels the client has already created. The client can select one or more of those labels and can create a new personal label from the same picker. Saving updates the card to show every selected label. Surfacing existing labels helps the client reuse them rather than accidentally creating near-duplicates from memory.

## Gherkin

Feature: Organizing bookmarks with labels

  Scenario: Add a newly created label alongside an existing label
    Given a bookmark already has the label "Recipes"
    And the collection has a known set of existing labels
    When the user opens the bookmark editor
    Then the label picker offers the existing labels for selection
    When the user creates and selects the label "Weekend plans"
    And saves the bookmark
    Then the card shows both "Recipes" and "Weekend plans"

## Assumptions

- Labels are created by the user rather than selected from a fixed system vocabulary.
- A bookmark may carry more than one label.
- Existing labels are surfaced in the picker to encourage reuse.
