Scenario ID: SCN-012
Title: Combine text and labels in one search box
Type: Happy Path
Approval status: approved
Approval session: SESSION-012
Approval cycle: 1

## Approved behaviour
Typing a label with a leading # in the search box treats it as a required label while other typed words search the bookmark's text. Label names after # ignore capitalization. Multiple #labels require a matching bookmark to carry all of them.

## Gherkin
Feature: Search with inline label conditions

  Scenario: Combine a note word with a label
    Given the JavaScript bookmark has a note containing "closures"
    And it carries the label "reference"
    When the person searches for "closures #reference"
    Then only bookmarks containing "closures" and carrying "reference" are shown

  Scenario: Match an inline label without regard to capitalization
    Given a bookmark carries the label "reference"
    When the person searches with "#REFERENCE"
    Then that bookmark satisfies the label condition

  Scenario: Require every inline label
    Given the person types multiple #labels
    When search results are evaluated
    Then only bookmarks carrying all typed labels are shown

## Assumptions
- Plain search text and inline label conditions are combined as requirements.
- Either/or label combinations are handled separately by conditional search.
