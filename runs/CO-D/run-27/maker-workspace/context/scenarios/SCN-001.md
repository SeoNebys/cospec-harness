Scenario ID: SCN-001
Title: Quick-save a link with fetched page details and a review step
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The client pastes a web address into a single input at the top of the page and
presses Save. The app fetches the page's details (title, short description, site
icon, and preview image when available) and presents a "Review & save" panel with
those details pre-filled. The client may correct the title and description in that
panel before saving. On pressing "Save bookmark", the bookmark is stored and
appears at the top of the list (newest first), showing the preview thumbnail, site
icon, title, a two-line description, and the address. Before anything is saved the
page shows a friendly empty state. A brief confirmation ("Saved …") is shown after
saving.

## Gherkin
Feature: Save a link

  Scenario: Save a new link after reviewing fetched details
    Given the bookmark list is empty
    And the page shows the empty state
    When the client pastes a valid web address and presses Save
    Then the app fetches the page's title, description, site icon and preview image
    And a review panel appears with the title and description pre-filled
    When the client optionally edits the title or description and presses "Save bookmark"
    Then the bookmark is stored
    And it appears at the top of the list showing preview, icon, title, description and address
    And a "Saved" confirmation is shown

  Scenario: Newest saved link appears first
    Given at least one bookmark is already saved
    When the client saves another link
    Then the newly saved bookmark appears above the existing ones

## Assumptions
- The review-before-save step appears on every save (client confirmed this trade-off).
- Real page-detail retrieval is a build-time capability; the prototype simulated it
  with pre-loaded details for example links (recorded in session log).
- The label/title is derived from the fetched details, not from the raw URL text.
