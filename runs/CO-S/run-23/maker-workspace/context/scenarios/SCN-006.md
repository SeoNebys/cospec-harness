Scenario ID: SCN-006
Title: Edit an existing bookmark and its tags
Type: Happy Path
Approval status: approved
Approval session: SESSION-006
Approval cycle: 1

## Approved behaviour
From a duplicate-save notice, the client opened the already saved bookmark directly for editing. Its address, title, description, and tags were available to change. Saving a prepared revision updated the existing card in place, displayed the revised title and newly added Reference tag, and kept the collection count at one. The client confirmed this supports both editing and tag assignment without creating a duplicate.

## Gherkin
Feature: Edit bookmarks

  Scenario: Open the existing bookmark from a duplicate-save notice
    Given saving an address has identified an existing bookmark
    When the user chooses to edit the existing bookmark
    Then that bookmark opens for editing
    And its address, title, description, and tags are available to change

  Scenario: Save changes to an existing bookmark
    Given an existing bookmark is open for editing
    And its title and tags have been changed
    When the user saves the changes
    Then the existing bookmark card shows the revised title and tags
    And no additional bookmark is created
    And the collection count remains unchanged

## Assumptions
- Editing includes the address, title, automatically collected description, and tags.
- Tags can be added or removed from the edit form as comma-separated names.
- Personal notes are deferred and are not present in the edit form.
- A duplicate-save notice provides a direct Edit existing action.
