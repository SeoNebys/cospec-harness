Scenario ID: SCN-005
Title: Search bookmark titles, descriptions, and personal notes
Type: Happy Path
Approval status: approved
Approval session: SESSION-005
Approval cycle: 1

## Approved behaviour

The client searches from a prominent box above the library and results narrow live while typing. A query can find a bookmark through its title, description, or personal note. When a result matched only through a note, the bookmark explains that source and shows the relevant note text. The matching bookmark count is shown.

## Gherkin

Feature: Search bookmarks

  Scenario Outline: Search across recognizable bookmark text
    Given the library contains bookmarks with titles, descriptions, and personal notes
    When the user types a query found in a bookmark's <field>
    Then the results update live
    And only matching bookmarks are shown
    And the matching bookmark count is shown

    Examples:
      | field       |
      | title       |
      | description |
      | note        |

  Scenario: Explain a result matched only through a personal note
    Given the query does not appear in a bookmark's title or description
    And the query appears in that bookmark's personal note
    When the user types the query
    Then that bookmark is shown in the results
    And the result states that the match came from the user's note
    And it shows the relevant note text

## Assumptions

- Search updates live as the user types.
- The search box appears prominently above the bookmark library.
- Search is not limited to page addresses or exact address matching.
