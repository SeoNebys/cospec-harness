Scenario ID: SCN-016
Title: Show an all-caught-up Read later state
Type: Edge Case
Approval status: approved
Approval session: SESSION-016
Approval cycle: 1

## Approved behaviour
When the final item is checked off, the separate Read later section remains available with a zero count. It shows a clear, friendly message that nothing is waiting and reminds the person that items are added by choosing Add to Read later while saving. The state reads as all caught up rather than missing or broken data.

## Gherkin
Feature: Empty read-later queue

  Scenario: Complete the last read-later item
    Given exactly one bookmark remains in Read later
    When the person checks it off
    Then the Read later count becomes zero
    And the Read later section remains available
    And an all-caught-up message is shown
    And the message explains how to add an item again while saving
    And the completed bookmark remains in All bookmarks

## Assumptions
- Empty Read later is distinct from an error or loading state.
- The Read later navigation item is not hidden when empty.
