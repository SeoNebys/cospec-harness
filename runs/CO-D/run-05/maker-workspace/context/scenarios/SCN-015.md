Title: Collect and show the page's icon and preview image
Type: Happy Path

## Approved behaviour

When a link's details are looked up, the app also collects the page's real site
icon (favicon) and its preview image, and shows them: during saving, the icon
and the preview image appear alongside the fetched title and description; on each
saved bookmark, the icon appears with the entry and the preview image appears as
a thumbnail to the right, making the list easy to scan. Fallbacks: if the icon
cannot be loaded, a coloured-letter avatar is shown instead; if the page provides
no preview image, a quiet "No preview image available" message is shown instead
of a blank gap. Neither fallback prevents saving.

## Gherkin

Feature: Page icon and preview image

  Scenario: Icon and preview image are collected and shown
    Given the user saves a link whose page provides an icon and a preview image
    Then the icon and preview image are shown while saving
    And the saved bookmark shows the icon and a preview thumbnail

  Scenario: No preview image available
    Given a link whose page provides no preview image
    Then a quiet "No preview image available" message is shown instead of a blank gap
    And the bookmark can still be saved

  Scenario: Icon cannot be loaded
    Given a bookmark whose site icon cannot be loaded
    Then a coloured-letter avatar is shown in its place

## Assumptions
- The icon is the site favicon; the preview image is the page's preview (e.g. og:image).
- Fallbacks never block saving.
