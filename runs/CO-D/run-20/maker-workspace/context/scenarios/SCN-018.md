Title: Personal display preferences (default sort, items per page, text size)
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

A Settings panel holds personal, app-wide display preferences that persist and
take effect immediately:
- Default sort: which sort order the app uses, including the order it opens with.
  Changing it reorders the list now and keeps the Sort control in sync.
- Items shown per page: how many bookmarks are revealed at first, with a
  "Show more" control to reveal further batches (progressive, not numbered
  pages); "All" reveals everything.
- Text size: Small / Medium / Large, adjusting the reading size of titles,
  descriptions and notes across the app.

Crucially, the items-per-page limit is display-only. Search, result counts, and
"Select all" always operate over the full current result set — "Select all"
selects every matching bookmark, including ones not yet revealed by Show more —
and the interface states this (a line above Show more, and the action-bar hint).

## Gherkin
Feature: Display preferences

  Scenario: Default sort applies and is the startup order
    When the user sets a default sort
    Then the list reorders immediately, the Sort control matches, and the app opens in that order

  Scenario: Items per page is display-only with Show more
    Given a page size smaller than the number of results
    Then only that many rows are revealed with a "Show more" control
    And the count and search still reflect the full result set
    And a line states the limit is display-only

  Scenario: Select all covers unrevealed matches
    Given results are paginated by the page size
    When the user chooses "Select all N matching"
    Then all N matching bookmarks are selected, including those not yet revealed

  Scenario: Text size adjusts reading size
    When the user changes text size
    Then titles, descriptions and notes resize accordingly across the app

## Assumptions
- Preferences persist per user and apply app-wide; changes are immediate.
- "Show more" progressive reveal is preferred over numbered pages.
