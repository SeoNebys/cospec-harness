Title: Change the order of the list
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Newest-first is the everyday default and stays that way. A Sort control lets the client
change the order occasionally: Newest first, Oldest first, and By name (A–Z) — to find
oldest saves or line things up by name to hunt something down.

## Gherkin
Feature: Sorting the list

  Scenario: Sort oldest first
    Given a list of saved links
    When I choose "Oldest first"
    Then the earliest-saved links appear at the top

  Scenario: Sort by name
    When I choose "By name (A–Z)"
    Then links are ordered alphabetically by title

  Scenario: Default order
    Given I have not changed the sort
    Then the list is newest-first

## Assumptions
- Sorting relies on knowing when each link was saved (see SCN-015 import: original save
  dates must be preserved so oldest-first stays meaningful).
