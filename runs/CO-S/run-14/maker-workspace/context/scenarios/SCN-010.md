Scenario ID: SCN-010
Title: Save a link whose page details cannot be read, then fill them in
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

When the automatic detail gathering cannot read a page's title, description, icon
or preview, the bookmark is **still saved** so the link is not lost. The saved
item **immediately opens with empty "Add a title" and "Add a description" fields**
(with a neutral placeholder icon and no preview) so the user can enter the
details themselves and press Done.

## Gherkin
Feature: Fallback when page details cannot be read

  Scenario: Details cannot be read
    Given the user saves a link whose page details cannot be read
    Then the bookmark is still created (the link is not lost)
    And it opens with empty title and description fields for the user to fill in
    And it shows a neutral placeholder icon and no preview

## Assumptions
- The link is saved even when no metadata is available.
- The user can enter title and description manually.
