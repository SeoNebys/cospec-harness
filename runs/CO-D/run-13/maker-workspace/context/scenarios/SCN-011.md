Scenario ID: SCN-011
Title: Long content — two-line titles, clamped descriptions, and a note preview
Type: Edge Case (boundary — long text)
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

To keep a calm, scannable list while never hiding distinguishing detail:
- A title may wrap to TWO lines before being shortened with an ellipsis (a single
  line could hide the part that distinguishes similar links).
- A description clamps to two lines.
- A long personal note shows a PREVIEW with a "Show full note" control; expanding
  it reveals the whole formatted note in place, with "Show less" to collapse.
  Viewing the full note does NOT require opening Edit, and the preview keeps a
  long note from taking over the list.
- Many tags on an entry wrap to multiple rows; a long address does not break the
  layout.

The client approved the two-line title, two-line description, and the note
preview height/behaviour.

## Gherkin

Feature: Handle long content gracefully

  Scenario: Long title
    Given an entry has a very long title
    Then the title is shown on up to two lines, then shortened

  Scenario: Long description
    Given an entry has a long description
    Then the description is clamped to two lines

  Scenario: Long note preview and expand
    Given an entry has a long note
    Then a preview is shown with a "Show full note" control
    When the client chooses "Show full note"
    Then the whole formatted note is shown in place
    And a "Show less" control collapses it again

## Assumptions
- The note-preview threshold and preview height are tunable defaults.
- Full note rendering uses the same safe formatting as SCN-006.
