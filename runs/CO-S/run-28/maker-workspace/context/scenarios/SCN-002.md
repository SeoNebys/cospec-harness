Scenario ID: SCN-002
Title: Edit a saved bookmark (title and tags) in place via the pencil
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

Each saved item shows a small, always-visible pencil (✎) next to its title.
Clicking the title itself opens the original page (the title stays a link).

Clicking the pencil opens an "edit this bookmark" form in place (no separate pop-up
window) containing the current title and the current tags (comma-separated), both
editable. While editing tags, existing tags are suggested as the user types (same
suggestion behaviour as saving — most-used first, with counts; choosing a suggestion
inserts that exact tag). The user reviews the changes and presses Save to apply them
together; Cancel (or Escape) discards all changes and restores the previous values.
Confirming an empty title keeps the previous title.

Chosen from three compared alternatives for the rename control, then extended:
- Version A (inline pencil) — CHOSEN for the control
- Version B (modal dialog) — rejected (heavier)
- Version C (click the title to edit) — rejected (would take clicking-the-title away
  from opening the page)
For editing tags, "one edit form (title + tags together, explicit Save)" was chosen
over "edit chips directly in place" because the user wants to review changes before
saving and prefers an explicit save over instant, un-undoable tag changes.

## Gherkin
Feature: Edit a saved bookmark

  Scenario: A saved item offers a visible edit control and an opening title
    Given a saved link is shown in the list
    Then its title is a link that opens the original page
    And a visible pencil control is shown next to the title

  Scenario: Edit title and tags together
    Given a saved link is shown in the list
    When the user clicks the pencil
    Then an in-place edit form shows the current title and tags, both editable
    When the user changes the title and/or tags and presses Save
    Then the item shows the updated title and tags
    And no separate pop-up window is used

  Scenario: Tag suggestions while editing
    Given existing tags are in use
    When the user types in the tags field of the edit form
    Then matching existing tags are suggested (most-used first) and can be inserted

  Scenario: Cancel an edit
    Given the user is editing a bookmark
    When the user presses Escape or Cancel
    Then the previous title and tags are restored unchanged

## Assumptions
- Confirming an empty title keeps the previous title.
- Tags are normalised to lower case; duplicates are collapsed.
- Only one item is in edit mode at a time.
