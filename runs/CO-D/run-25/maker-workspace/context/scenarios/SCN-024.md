Scenario ID: SCN-024
Title: Prevent saving the same destination twice
Type: Edge Case
Approval status: approved
Approval session: SESSION-024
Approval cycle: 1

## Approved behaviour
When the person tries to save an address whose destination is already bookmarked, no new bookmark is created and there is no option to create a duplicate. The app explains that it is already saved, brings the existing bookmark into view, and highlights it so the person can open or edit that copy.

## Gherkin
Feature: Saving bookmarks

  Scenario: Save an already bookmarked destination
    Given the destination is already present in the collection
    When the person pastes its address into the save bar and saves
    Then no new bookmark is created
    And the app says the bookmark is already saved
    And the existing bookmark is brought into view and highlighted
    And no action to save another copy is offered

## Assumptions
- Duplicate detection is based on the destination address.
- Destination normalization details are resolved separately if needed.
