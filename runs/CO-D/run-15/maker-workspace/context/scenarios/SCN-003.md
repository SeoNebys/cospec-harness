Scenario ID: SCN-003
Title: Add a free-form tag to a bookmark
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

From an existing bookmark, the client chooses to add a tag. An inline field appears directly on the bookmark; the client types their own free-form word and presses Enter. The tag is saved and displayed directly on the bookmark without opening a separate dialog.

## Gherkin

Feature: Organize bookmarks with tags

  Scenario: Add a tag to a bookmark
    Given the client is viewing an existing bookmark
    When the client chooses to add a tag to that bookmark
    Then an inline tag field appears on the bookmark
    When the client enters a free-form tag name
    And presses Enter
    Then the tag is saved on that bookmark
    And the tag is displayed directly on the bookmark

## Assumptions

- This scenario confirms adding one tag; multiple tags remain to be explored.
- Suggestions from previously used tags and consistent capitalization are covered by SCN-004.
- The client begins the action from the bookmark itself.
- Tag entry uses a lightweight inline field on the bookmark rather than a separate dialog.
