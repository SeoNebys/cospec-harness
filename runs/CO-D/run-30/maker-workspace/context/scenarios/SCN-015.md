Scenario ID: SCN-015
Title: Mark several selected bookmarks to read later
Type: Happy Path
Approval status: approved
Approval session: SESSION-015
Approval cycle: 1

## Approved behaviour

While in selection mode, the client can mark every selected bookmark to read later with one action. The action turns Read later on for unmarked items and leaves already-marked items marked; it never toggles an existing item off. The selected bookmarks remain selected for another batch action. The Read later view immediately includes the newly marked bookmarks together with items that were already in the reading pile.

## Gherkin

Feature: Managing bookmarks in bulk

  Scenario: Add several bookmarks to the reading list
    Given two unmarked bookmarks are selected
    And another bookmark is already marked to read later
    When the user applies Mark read later to the selection
    And opens the Read later view
    Then all three bookmarks are visible
    And the result count shows three results
    And the original two bookmarks remain selected

  Scenario: Include an already-marked bookmark in a batch
    Given a selection contains a bookmark already marked to read later
    When the user applies Mark read later
    Then that bookmark remains marked

## Assumptions

- Batch Mark read later is an additive action, not a toggle.
