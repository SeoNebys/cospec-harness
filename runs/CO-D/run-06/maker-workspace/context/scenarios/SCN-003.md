Scenario ID: SCN-003
Title: Recognize a bookmark that is already saved
Type: Edge Case
Approval status: approved
Approval session: SESSION-003
Approval cycle: 1

## Approved behaviour
When a person tries to save a web address that is already in the collection, no second copy is created and the collection count does not increase. The app brings the existing bookmark into focus and presents its current title ready to change in place.

## Gherkin
Feature: Saving bookmarks

  Scenario: Save an address that is already in the collection
    Given a bookmark for a web address already exists in the collection
    When the person tries to save the same web address again
    Then no additional bookmark is created
    And the collection count remains unchanged
    And the existing bookmark is brought into focus
    And its current title is presented for editing in place

## Assumptions
- Duplicate recognition compares the submitted web address with saved web addresses.
- Editing the existing bookmark's title happens directly within its list item.
