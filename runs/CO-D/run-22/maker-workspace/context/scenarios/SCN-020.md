Scenario ID: SCN-020
Title: Return to an existing bookmark on duplicate save
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When a person tries to save the exact address of an existing bookmark, no duplicate is created. The collection count stays unchanged, a clear message explains that the link is already saved, and the existing bookmark is brought into focus with its personalized title, description, labels, notes, and other edits intact.

## Gherkin
Feature: Avoiding duplicate bookmarks

  Scenario: Save an address that is already in the collection
    Given a bookmark with an address already exists
    And it may contain personalized information
    When the person tries to save the exact same address again
    Then no new bookmark is created
    And the collection count is unchanged
    And the person is told that the link is already saved
    And the existing bookmark is brought into focus
    And none of its information is overwritten

## Assumptions
- This scenario covers an exact repeated address.
- Duplicate detection happens before gathered information or defaults could overwrite the existing bookmark.
