Title: Day one — a welcoming empty library
Type: Edge Case (absence of data)
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The first time the app is opened, the library is empty — and instead of a cold
blank box, it shows a warm launchpad: one line on WHY ("where you can actually
find it again"), and two clearly-billed front doors given equal weight —
"Save your first link" (paste into the box) and "Bring in what you already have"
(import existing browser bookmarks, with the preview-first flow of SCN-015),
because the client arrives with a mountain, not empty-handed. A quiet
reassurance covers both halves of trust: it's private (just the client, nothing
public) AND it's theirs to keep (export anytime, never locked in).

The empty state is a launchpad, not a tutorial: no click-through tooltips. It
disappears the instant the first link is saved or an import completes, giving
way to the normal library.

## Gherkin
Feature: First-run empty state

  Scenario: Opening an empty library
    Given the library has no links
    Then a welcome is shown with two equal paths: save one link, or import many
    And a note that the library is private and exportable
    And no forced tutorial

  Scenario: The launchpad clears once there is content
    When the client saves a first link or completes an import
    Then the welcome is replaced by the normal library view

## Assumptions
- Import billed equally with saving, on day one. (client confirmed)
- Reassurance covers privacy AND exportability/anti-lock-in. (client confirmed)
- Helpful, not a nagging tutorial. (client confirmed)
