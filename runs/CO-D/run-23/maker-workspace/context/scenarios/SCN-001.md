Scenario ID: SCN-001
Title: Save a link with automatically gathered details
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A person pastes a web address into the prominent save box on the main page and saves it. The app gathers the page title, a short description, the site's icon, and the source without requiring those details to be typed. The saved link appears as a readable card beneath the save box rather than as a raw web address.

## Gherkin
Feature: Save a bookmark

  Scenario: Save a link without manually entering its details
    Given the personal bookmark library is empty
    And the main page has a prominent box for saving a web address
    When the person pastes a web address and saves it
    Then the app gathers the page title, a short description, the site's icon, and the source
    And the app adds the bookmark to the library
    And the bookmark is shown as a readable card beneath the save box
    And the person is not required to type the gathered details

## Assumptions
- The save box is available directly on the main page.
- Each bookmark is presented as its own card.
- The gathered details are the title, short description, site icon, and source site.
