Scenario ID: SCN-003
Title: Edit a saved bookmark later
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

Each saved card offers an Edit action. Choosing it opens the same review/edit
panel pre-filled with the bookmark's current details. From this one panel the
client can edit the **address**, title, page description, their own **note**, and
**tags** (and the reading-list choice). Changing the address updates the
bookmark's link and site; an unusable address is ignored, keeping the previous
one. The client chooses Save changes; the card updates in place and briefly
highlights to confirm the change.

## Gherkin

Feature: Saving a link

  Scenario: Editing a saved bookmark
    Given a saved bookmark
    When I choose Edit on its card
    Then an edit panel opens pre-filled with its current address, title,
         description, note, tags, and reading-list choice
    When I change any of them and choose Save changes
    Then the card updates in place
    And it briefly highlights to confirm the change

  Scenario: Editing the address
    Given the edit panel
    When I change the address to a usable link and save
    Then the bookmark's link and site are updated
    And if the new address is not usable, the previous address is kept

## Assumptions

- Editing covers the address, title, page description, personal note, tags, and
  reading-list membership from the one panel.
