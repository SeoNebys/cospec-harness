Scenario ID: SCN-004
Title: Create and assign a tag from a bookmark card
Type: Happy Path
Approval status: approved
Approval session: SESSION-004
Approval cycle: 1

## Approved behaviour

The client can create a new tag and assign it to an existing bookmark in one step directly from that bookmark's card. After the client enters the new tag name and confirms, the tag appears on the card immediately and is added to the always-visible sidebar with an updated count. The application confirms that both the bookmark and sidebar were updated.

## Gherkin

Feature: Create and assign personal tags

  Scenario: Create a tag from a bookmark card
    Given a saved bookmark does not have a tag named "Reference"
    And the sidebar does not contain a tag named "Reference"
    When the user creates and adds the tag "Reference" from that bookmark's card
    Then the bookmark card displays the tag "Reference"
    And the sidebar displays "Reference" with a count of one
    And the application confirms that the bookmark and sidebar were updated

## Assumptions

- Creating a tag from a card also assigns it to that bookmark; no separate assignment step is required.
- The new tag becomes available for filtering in the sidebar immediately.
- Reusing and removing tags are explored separately from this happy path.
