Scenario ID: SCN-004
Title: Preserve personal wording when correcting an address
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When a bookmark's title or description contains wording written by the person, correcting its web address keeps that personal wording without requiring confirmation. The site, preview image, and other page-derived details refresh from the new page, but personal wording is never silently replaced.

## Gherkin
Feature: Correcting a bookmark address

  Scenario: Keep personalized details after correcting an address
    Given a saved bookmark has an incorrect web address
    And the person has personalized its title or description
    When the person replaces the web address with a different valid page address
    And saves the changes
    Then the bookmark points to the new address
    And its site, preview image, and non-personalized page details are refreshed from the new page
    And every personalized title or description remains unchanged
    And no confirmation is required

## Assumptions
- The app distinguishes personalized values from automatically gathered values.
- Each personalized field takes precedence independently.
- The replacement address is valid and its page details can be gathered.
