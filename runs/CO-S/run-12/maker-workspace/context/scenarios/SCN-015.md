Scenario ID: SCN-015
Title: Preserve saved details when the original page changes
Type: Edge Case
Approval status: approved
Approval session: SESSION-015
Approval cycle: 1

## Approved behaviour
After a bookmark is saved, its stored title, description, picture, personal note, and tags remain the client's record. The app does not silently refresh, overwrite, or remove those saved details if the external page later changes or disappears. Opening the original link still visits whatever is currently available at that address.

## Gherkin
Feature: Preserve a bookmark over time

  Scenario: The external page changes after a bookmark was saved
    Given a bookmark has stored page details, a personal note, and tags
    When the external page later changes or becomes unavailable
    Then the stored title, description, picture, note, and tags remain unchanged
    And no saved detail is silently refreshed or removed
    But opening the bookmark still visits the original address and its current response

## Assumptions
- Saved bookmark data is a durable snapshot until the client explicitly edits it.
- Opening a link is separate from changing its stored bookmark details.
