Scenario ID: SCN-026
Title: Reject an invalid edited address without partial changes
Type: Error Case
Approval status: approved
Approval session: SESSION-026
Approval cycle: 1

## Approved behaviour
If a replacement web address is invalid, saving an edited bookmark is blocked. The side panel remains open, all pending edits remain intact, and a clear message says how to correct the address and that nothing has been saved. The existing bookmark remains completely unchanged. After correction, all pending edits apply together.

## Gherkin
Feature: Save bookmark edits atomically

  Scenario: Attempt to save edits with an invalid address
    Given a person has changed several bookmark fields in the editor
    And the replacement web address is invalid
    When the person selects Save changes
    Then the editor remains open
    And all pending edits remain in the editor
    And a message explains how to enter a complete address
    And the message says nothing has been saved
    And the existing bookmark remains completely unchanged

  Scenario: Correct the address and save all pending edits
    Given a set of bookmark edits was blocked by an invalid address
    When the person replaces it with a complete valid address
    And saves again
    Then all pending edits are applied together
    And the editor closes

## Assumptions
- Bookmark editing is all-or-nothing rather than partially applied.
