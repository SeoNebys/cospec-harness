Scenario ID: SCN-008
Title: Tag bookmarks with freeform, normalised, autocompleted tags
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

A bookmark can carry many freeform tags. Tags are entered as chips: type a tag
and press Enter or comma to add it; click the chip's × to remove it. Tags can be
added/removed both while saving (in the review panel) and later via Edit.

Tags are normalised to a consistent form: lowercased, with spaces turned into
hyphens (e.g. "Machine Learning" -> machine-learning). The same normalised tag
cannot be added twice to one bookmark.

Each bookmark displays its tags as clickable chips (shown as #tag). Clicking a
tag chip filters the collection to that tag (it fills the search box with #tag),
using the same search engine — so tags combine with words and boolean operators
(e.g. #reference OR #recipe).

While typing a tag, the app suggests the user's existing tags that match the
typed letters, excluding tags already on the current bookmark. Selecting a
suggestion reuses that exact existing tag, helping avoid near-duplicates. The
app does not silently merge differently-spelled tag names; suggestions only
surface existing tags for the user to choose.

## Gherkin
Feature: Tags

  Scenario: Add and remove tags as chips
    Given the tag editor is open for a bookmark (on save or edit)
    When the user types a tag and presses Enter or comma
    Then it is added as a chip in normalised form (lowercased, spaces to hyphens)
    And clicking a chip's × removes it
    And the same normalised tag cannot be added twice to that bookmark

  Scenario: Filter by clicking a tag chip
    Given a bookmark displays a tag chip
    When the user clicks the chip
    Then the search box is set to #tag and the collection filters to that tag

  Scenario: Tags combine with the query language
    When the user searches "#reference OR #recipe"
    Then bookmarks having either tag are shown

  Scenario: Suggest existing tags while typing
    Given the user has existing tags
    When the user types letters into the tag box
    Then matching existing tags (excluding those already on this bookmark) are suggested
    And selecting one adds that exact existing tag
    And no automatic merging of differently-spelled tags occurs

## Assumptions
- Tag filtering reuses SCN-004's search engine via the #tag term.
- Suggestions match on the typed letters occurring anywhere in an existing tag.
