Scenario ID: SCN-015
Title: Show a clear empty search result
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When no bookmark matches a search, the filtered bookmark area explicitly says that no bookmarks match rather than appearing blank or broken. The query stays in the field so it can be revised or cleared, and the underlying collection remains untouched.

## Gherkin
Feature: Empty bookmark search result

  Scenario: Search finds no bookmarks
    Given the collection contains saved bookmarks
    When the person enters a query that matches none of their saved information
    Then the bookmark area explains that no bookmarks match
    And the query remains available to revise or clear
    And no saved bookmark is changed or removed

## Assumptions
- The no-results message appears in the normal results area.
- Clearing the query returns to the unfiltered collection.
