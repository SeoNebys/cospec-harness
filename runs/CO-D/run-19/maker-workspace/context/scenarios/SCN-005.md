Scenario ID: SCN-005
Title: Filter the library by exact labels
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A row above the library shows every available label for topic-first browsing. Labels displayed as pills on bookmark cards are also selectable for finding more like the item already in view. Selecting a label through either path shows only bookmarks carrying that exact label, highlights the same active label in the row, displays an updated count, and offers a clear way back to the full library. Both entry paths share one filter state and coexist with search.

## Gherkin
Feature: Browse bookmarks by exact label

  Scenario: Start a label browse from the library label row
    Given the library displays a row of all available labels
    When the client selects a label in that row
    Then only bookmarks carrying that exact label are shown
    And the selected label is visibly active
    And the matching bookmark count is shown
    And a clear way to return to all bookmarks is shown

  Scenario: Find more like a visible bookmark
    Given a bookmark card displays a label pill
    When the client selects that label pill
    Then only bookmarks carrying that exact label are shown
    And the matching label in the library label row is visibly active
    And the same clear way to return to all bookmarks is shown

## Assumptions
- One exact label is selected through these direct label-filter entry points at a time.
- Combining labels and exclusions is covered by the precise-search behaviour.
