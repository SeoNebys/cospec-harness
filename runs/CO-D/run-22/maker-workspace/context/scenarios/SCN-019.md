Scenario ID: SCN-019
Title: Format a personal note with a visual toolbar
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A personal note can contain bold emphasis and bulleted lists. A small visual formatting toolbar lets the person apply formatting without typing special symbols, and the saved note preserves that formatting in its distinct Your note presentation.

## Gherkin
Feature: Personal bookmark notes

  Scenario: Save a formatted personal note
    Given a person is writing a personal note on a bookmark
    When they apply bold emphasis and a bulleted list using the visual toolbar
    And save the note
    Then the note appears in the bookmark's Your note section
    And the bold emphasis and bulleted list are preserved

## Assumptions
- The initial formatting set includes bold emphasis and bulleted lists.
- Formatting controls visually affect the note while it is being written.
- Formatted note text remains searchable as ordinary text.
