Scenario ID: SCN-001
Title: Save a web address as a recognizable bookmark
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
From an empty collection, the client saved a prepared web address from an always-visible address box. The saved item appeared in the collection with its source site, an automatically filled title and short description, and the time it was saved. The client confirmed that this was enough context to recognize the page at a glance without opening it.

## Gherkin
Feature: Save bookmarks

  Scenario: Save a web address with automatically collected context
    Given the bookmark collection is empty
    And a web address is entered in the always-visible address box
    When the user saves the bookmark
    Then one bookmark is added to the collection
    And the bookmark shows the source site
    And the bookmark shows an automatically collected title
    And the bookmark shows an automatically collected short description
    And the bookmark shows when it was saved
    And the saved details are sufficient to recognize the page without opening it

## Assumptions
- The address box is always visible at the top of the collection screen.
- Page title and short description are collected automatically when the bookmark is saved.
- A compact card is used to present the bookmark's source, title, description, and saved time.
- The app has one user and requires no multi-user workflow.
