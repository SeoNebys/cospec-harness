Scenario ID: SCN-013
Title: Automatic preserved local copy of each saved page; optional Internet Archive
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

Local preserved copy:
- Whenever a bookmark is saved, the app automatically captures a preserved copy in
  the background.
  - A normal web page is kept as a self-contained page file (opens exactly as it
    was when saved, even if the original later changes or disappears).
  - A PDF preserves the original PDF file itself (not a page snapshot).
- Saving the bookmark is NOT blocked if the copy fails. On failure the bookmark is
  still saved and the copy shows a clear failed state with "Try again" (and the
  option to open the live page instead). The user can retry later.
- The preserved copy shows its saved date and size, with actions: View saved copy,
  Download (copy / PDF), and Refresh copy. The original live page remains
  reachable separately ("Open live page").
- While capturing, a non-blocking "saving a copy…" status is shown.

Internet Archive (strictly opt-in, per bookmark):
- A separate, optional action lets the user save a public copy to the Internet
  Archive. It is NEVER automatic — sending a page address to the third-party
  service happens only when the user chooses it for that bookmark.
- Once done, the bookmark shows the archive date and a link to view it on
  web.archive.org.

## Gherkin

Feature: Preserved copies

  Scenario: Automatic local copy on save (normal page)
    Given the user saves a normal web page
    Then a self-contained page copy is captured in the background
    And the bookmark is saved even while the copy is still capturing

  Scenario: PDF preserves the original file
    Given the user saves a PDF link
    Then the original PDF file is preserved as the copy

  Scenario: Copy failure does not block saving
    Given the copy cannot be captured (blocked or unreachable)
    Then the bookmark is still saved
    And the copy shows a failed state with a "Try again" option

  Scenario: Internet Archive is opt-in only
    Given a saved bookmark
    Then no copy is sent to the Internet Archive automatically
    When the user chooses "Save a copy to the Internet Archive" for that bookmark
    Then the page is submitted to archive.org and the archive link is shown

## Assumptions
- Storage of copies is local to the app; capacity/retention is a non-functional
  concern (see non-functional-backlog.md).
- "Self-contained page file" means the page and its needed assets saved together.
