Scenario ID: SCN-033
Title: Recognize tracked and section links as an existing bookmark
Type: Edge Case
Approval status: approved
Approval session: SESSION-033
Approval cycle: 1

## Approved behaviour
Common marketing tracking parameters and jump-to-section fragments do not make an address a different destination for duplicate detection. Saving such a variant points to the existing clean bookmark and creates no near-duplicate.

## Gherkin
Feature: Saving bookmarks

  Scenario: Save a tracked section link for an existing page
    Given the clean MDN grid page is already bookmarked
    When the person saves the same page with newsletter tracking parameters and a section fragment
    Then no new bookmark is created
    And the existing clean bookmark is brought into view and highlighted

## Assumptions
- Known tracking parameters and URL fragments are ignored for duplicate comparison.
- Parameters that identify genuinely different page content are not automatically discarded.
