Scenario ID: SCN-006
Title: Archive links out of the everyday view, fully recoverable
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The library has an "Archive" view (tab) in addition to Library and Reading list.
The client can archive any link; an archived link disappears from both the Library
and the Reading list, keeping the everyday view uncluttered. Nothing is deleted:
the archived link, with its tags and notes, is kept intact and visible in the
Archive view, and can be restored to the Library at any time.

Search operates within the active view, so an archived link only appears in search
results while the client is viewing the Archive; a search from the Library or
Reading list does not surface archived links. When nothing is archived, the
Archive view shows a friendly empty-state message.

## Gherkin
Feature: Archive

  Scenario: Archive a link
    Given a link is in the Library
    When the client archives it
    Then the link no longer appears in the Library or Reading list
    And the link appears in the Archive view with its tags and notes intact

  Scenario: Restore an archived link
    Given a link is in the Archive
    When the client restores it
    Then the link reappears in the Library

  Scenario: Archived links excluded from everyday search
    Given an archived link exists
    When the client searches from the Library or Reading list
    Then the archived link is not in the results
    When the client searches within the Archive view
    Then the archived link can be found

  Scenario: Empty archive
    Given no links are archived
    When the client opens the Archive view
    Then a friendly empty-state message is shown

## Assumptions
- Archiving is non-destructive and reversible (restore).
- Archived links are excluded from the reading-list count and views.
- Search scope follows the active view (consistent with SCN-005).
