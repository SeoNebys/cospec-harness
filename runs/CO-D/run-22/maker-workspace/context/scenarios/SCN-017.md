Scenario ID: SCN-017
Title: Save a new bookmark to Read later
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The ordinary bookmark-save flow includes an optional Add to Read later checkbox. When selected, the bookmark is saved with its automatically gathered details and placed directly into Read later. When not selected, the same single Save button saves it without placing it in the reading queue.

## Gherkin
Feature: Managing a reading queue

  Scenario: Save a new bookmark into Read later
    Given the person is saving a new web address
    When they select "Add to Read later"
    And save the bookmark using the normal save action
    Then the bookmark is saved with its gathered details
    And it appears in Read later
    And it is visibly marked as Read later

  Scenario: Save without adding to Read later
    Given the person is saving a new web address
    When they leave "Add to Read later" unselected
    And save the bookmark using the normal save action
    Then the bookmark is saved with its gathered details
    And it does not appear in Read later

## Assumptions
- Add to Read later is unselected by default.
- One Save button is used for both destinations.
