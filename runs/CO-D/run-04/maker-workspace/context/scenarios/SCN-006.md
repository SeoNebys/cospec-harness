Scenario ID: SCN-006
Title: Find bookmarks with plain and precise searches
Type: Happy Path
Approval status: approved
Approval session: SESSION-006
Approval cycle: 1

## Approved behaviour
Search narrows the visible collection as the person types and ignores letter
case. Plain words search across bookmark titles, descriptions, website names,
addresses, and labels. The same search box supports label-only searches, quoted
exact phrases, excluded terms, either/or searches, and adjacent criteria that
must all match.

## Gherkin
Feature: Search the bookmark collection

  Scenario: Find a word remembered from any bookmark detail
    Given bookmarks have titles, descriptions, website names, addresses, and labels
    When the person types a word in the search box using any letter case
    Then the collection updates as they type
    And bookmarks containing the word in any searchable detail are shown
    And bookmarks not containing the word are hidden

  Scenario: Search only within a label
    Given bookmarks carry different labels
    When the person searches for "label:recipes"
    Then only bookmarks carrying the "Recipes" label are shown

  Scenario: Search for an exact phrase
    Given multiple bookmarks contain the same individual words
    When the person encloses those words in quotation marks
    Then only bookmarks containing the words together in that order are shown

  Scenario: Exclude a matching term
    Given recipe bookmarks include a carrot bookmark and another recipe bookmark
    When the person searches for "label:recipes -carrot"
    Then recipe bookmarks containing "carrot" are excluded
    And the other matching recipe bookmarks remain

  Scenario: Match either side of a search
    Given some bookmarks carry "Recipes" and others carry "Work"
    When the person searches for "label:recipes OR label:work"
    Then bookmarks carrying either label are shown

  Scenario: Require adjacent criteria to both match
    Given recipe bookmarks contain different words
    When the person searches for "potatoes label:recipes"
    Then only bookmarks that contain "potatoes" and carry "Recipes" are shown

## Assumptions
- Search results update while typing without a separate submit action.
- Search syntax and ordinary words share one search box.
- A minus sign excludes a criterion, quotation marks denote an exact phrase,
  uppercase OR widens a search, and adjacent criteria must all match.
