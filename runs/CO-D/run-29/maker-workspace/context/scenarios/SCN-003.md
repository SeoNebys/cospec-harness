Scenario ID: SCN-003
Title: Correct a saved bookmark's web address
Type: Happy Path
Approval status: approved
Approval session: SESSION-003
Approval cycle: 1

## Approved behaviour
The web address is editable when a saved bookmark is opened for editing. Saving a corrected address retains it with the bookmark, and selecting the bookmark title afterward opens the corrected address. Correcting the address preserves the client's existing title, description, site icon, and preview rather than fetching replacements.

## Gherkin
Feature: Edit saved bookmarks

  Scenario: Correct a bookmark's web address without replacing its other details
    Given a saved bookmark is open for editing
    And it has an existing title, description, site icon, and preview
    When the client changes its web address and saves the changes
    Then the corrected address is retained for the bookmark
    And the existing title, description, site icon, and preview remain unchanged

  Scenario: Visit a bookmark after its address is corrected
    Given a bookmark has a corrected web address
    When the client selects the bookmark title in the collection
    Then the corrected web address is opened

## Assumptions
- The corrected address is a valid web address.
- Correcting an address does not trigger page-detail retrieval.
