Scenario ID: SCN-004
Title: Re-saving a link already saved takes the client to the existing item
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The client often forgets they already saved something. When they save a link
that already exists in the collection, the app does not create a second copy and
does not stop to ask. It quietly jumps to the existing item and briefly flashes
it with a message ("You already saved this — here it is.").

Matching tolerates trivial differences in the address (scheme, "www.", trailing
slash, letter case) so a near-identical link still counts as the same one.

## Gherkin
Feature: Duplicate save handling

  Scenario: Save a link that is already saved
    Given the collection already contains an item for a link
    When the client saves that same link again (allowing trivial URL differences)
    Then no second copy is created
    And the app scrolls to and highlights the existing item
    And the app shows a brief "already saved" message
    And the client is not asked to make a decision

## Assumptions
- Duplicate detection ignores scheme, "www.", trailing slash, and case. (Approved.)
- Silent redirect to the existing item, no confirmation prompt. (Approved.)
