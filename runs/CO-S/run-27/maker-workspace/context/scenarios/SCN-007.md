Scenario ID: SCN-007
Title: Edit a saved bookmark
Type: Happy Path
Approval status: approved
Approval session: SESSION-007
Approval cycle: 1

## Approved behaviour
Edit and Delete controls are shown directly on each bookmark card. Choosing Edit opens a form where the web address, title, description, and tags can all be changed. Saving returns to the card with the updated details and a visible confirmation.

## Gherkin
Feature: Editing bookmarks

  Scenario: Edit bookmark details
    Given a saved bookmark appears in the list
    When the person chooses Edit directly on its card
    Then a form shows the bookmark's web address, title, description, and tags as editable values
    When the person changes the title and saves
    Then the bookmark card shows the updated title
    And the app visibly confirms that the bookmark was updated

## Assumptions
- Edit and Delete controls are always visible directly on the bookmark card.
- Editing uses a dedicated form rather than editing fields in place on the card.
- Saving changes returns the person to the bookmark card.
