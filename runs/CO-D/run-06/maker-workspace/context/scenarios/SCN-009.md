Scenario ID: SCN-009
Title: Set a bookmark aside (a drawer) without deleting it, and pull it back
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
"Set aside" is a gentler alternative to deletion — a drawer, not the trash. It is
for things the client is done with for now but does not want to lose.
- In the editor, next to "Delete forever" (red), there is a distinct "Set aside"
  (yellow) action. The two are clearly separate so they are not muddled.
- Setting a bookmark aside removes it from the main list; an Undo bar is offered
  briefly (same forgiving net as delete).
- Set-aside bookmarks live under a "Set aside" tab (with a count). From there each
  can be "Put back" into the main list at any time — nothing set aside is ever lost.
- Set-aside bookmarks are hidden from the main list AND from everyday search by
  default. A "also search things I've set aside" toggle opts them back into search
  when the client actually needs one. ("Out of sight until I ask.")
- Naming confirmed: "Set aside" (not "Archive"/"Hide"/"Snooze") — it conveys both
  "stops cluttering me" and "still kept".

## Gherkin
Feature: Setting bookmarks aside

  Scenario: Set a bookmark aside
    Given the editor is open for a bookmark in the main list
    When the client chooses "Set aside"
    Then the bookmark leaves the main list
    And it appears under the "Set aside" tab
    And an Undo is briefly offered

  Scenario: Put a set-aside bookmark back
    Given a bookmark is set aside
    When the client chooses "Put back" for it
    Then it returns to the main list

  Scenario: Set-aside items are excluded from everyday search by default
    Given a set-aside bookmark matches a search term
    When the client searches without opting in
    Then that bookmark does not appear
    When the client enables "also search things I've set aside"
    Then that bookmark appears in the results

## Assumptions
- Set aside / delete both live only in the editor (not on list cards).
- The main list and default search show only not-set-aside bookmarks.
