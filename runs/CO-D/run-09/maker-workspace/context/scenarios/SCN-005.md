Scenario ID: SCN-005
Title: Open a saved link's original page
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
On a saved-link card, clicking the title or the site icon opens the original page
in a new browser tab, leaving the bookmark list open in the current tab. Clicking
elsewhere on the card does not open the page, avoiding accidental openings. Opening
the page to read is kept separate from opening the link to edit.

This interaction was chosen from three compared alternatives (whole-card opens vs.
title/icon opens vs. a dedicated "Open" action). The client selected title/icon
because it is familiar, avoids accidental opening, and keeps the list available.

## Gherkin
Feature: Opening the original page

  Scenario: Open the page from a card
    Given a saved link is shown as a card
    When the user clicks the card's title or site icon
    Then the original page opens in a new browser tab
    And the bookmark list remains open in the current tab

  Scenario: Clicking elsewhere on the card does not open the page
    Given a saved link is shown as a card
    When the user clicks a part of the card other than the title or site icon
    Then the original page is not opened

## Assumptions
- The page opens in a new tab (not the current one) so the list is not lost.
