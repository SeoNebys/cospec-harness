Scenario ID: SCN-001
Title: Save a recognizable bookmark from a web address
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

From an empty personal collection, the client can use a focused add-bookmark pop-up to submit a public web address. The saved link appears immediately in the main collection as a card containing the page title, source site, preview image, short description, and reading time, so it is recognizable without reopening the page. A confirmation tells the client that the bookmark was saved and its page details were added automatically.

## Gherkin

Feature: Save bookmarks with recognizable page context

  Scenario: Save a public web page to an empty collection
    Given the personal bookmark collection is empty
    And the add-bookmark pop-up is open
    When the user submits the address of a public web page
    Then the bookmark is added to the main collection
    And its card shows the page title, source site, preview image, short description, and reading time
    And the application confirms that the bookmark and its page details were saved

## Assumptions

- The submitted address points to a reachable public web page whose details can be retrieved.
- The title, source, preview, description, and reading time are generated automatically rather than entered by the user.
- New bookmarks appear in the main collection immediately after saving.
