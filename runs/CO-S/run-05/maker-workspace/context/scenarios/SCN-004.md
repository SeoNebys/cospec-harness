Scenario ID: SCN-004
Title: Keep a focused read-later pile
Type: Happy Path
Approval status: approved
Approval session: SESSION-004
Approval cycle: 1

## Approved behaviour

The client marks a bookmark with a clearly labeled "Read later" button. The
bookmark appears in a focused Read later view available from the sidebar while
remaining available in the full bookmark collection.

## Gherkin

Feature: Read-later bookmarks

  Scenario: Add a bookmark to the reading pile
    Given a saved bookmark is visible in the full collection
    When the client marks it using the "Read later" button
    Then the bookmark remains in the full collection
    And the bookmark is shown in the Read later view

## Assumptions

- Read later is a separate view in the sidebar.
- Marking a bookmark for later does not move it out of the full collection.
- The marking control uses a text label rather than an unexplained icon.
