Scenario ID: SCN-006
Title: Archive and restore a bookmark, independent of reading status
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

Archiving is separate from reading status. Archiving a bookmark hides it from the
normal To read and Done views and shows it only in the Archived view, while
remembering whether it was "To read" or "Done". The Archived view displays each
item's remembered status. Restoring a bookmark removes it from Archived and
returns it to the exact reading status it had before archiving.

## Gherkin

Feature: Archive

  Scenario: Archiving hides a bookmark from normal views
    Given a bookmark with a reading status of "Done"
    When the user archives it
    Then it no longer appears in the "Done" or "To read" views
    And it appears only in the "Archived" view
    And the Archived view shows its remembered status as "Done"

  Scenario: Restoring returns a bookmark to its prior status
    Given an archived bookmark whose remembered status is "Done"
    When the user restores it
    Then it leaves the "Archived" view
    And it returns to the "Done" view

  Scenario: Restoring a To read bookmark
    Given an archived bookmark whose remembered status is "To read"
    When the user restores it
    Then it returns to the "To read" view

## Assumptions
- Archived is a flag orthogonal to the To read / Done reading status.
- Restore always returns to the remembered reading status, never a default.
