Scenario ID: SCN-001
Title: Save, view, open, and correct a bookmark
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A pasted web address is saved as a readable card whose title, description, source site, site icon, and original address are filled automatically. The card appears in the library below the prominent save box. Selecting the card opens the original page in a new browser tab while the library stays open. Selecting the pencil changes the title and description into fields inside the card; saving those fields updates the card and confirms the change. The same editor is available immediately after saving and when returning to an existing bookmark later.

## Gherkin
Feature: Save and use a readable bookmark

  Scenario: Save a link with automatically fetched details
    Given the personal bookmark library is open
    And the web address has not already been saved
    When the client pastes the address and saves it
    Then one bookmark card is added to the library
    And the card shows the fetched page title, description, source site, site icon, and original address

  Scenario: Open a saved bookmark
    Given a bookmark card is shown in the library
    When the client selects the card outside its controls
    Then the original page opens in a new browser tab
    And the bookmark library remains open in its existing tab

  Scenario: Correct fetched details immediately after saving
    Given a bookmark has just been saved
    When the client selects its pencil control
    And changes its title or description
    And saves the change
    Then the updated text is shown in the same card
    And a confirmation that the changes were saved is shown

  Scenario: Correct fetched details later
    Given an existing bookmark is shown in the library
    When the client selects its pencil control
    Then its title and description become editable inside the card
    And the card stays in its position in the library

## Assumptions
- Metadata fetching succeeds for this happy path; failures and incomplete metadata remain to be explored.
- The saved web address itself is not changed through the in-card editor.
- The product is a personal web app and does not include multi-user accounts in this cycle.
