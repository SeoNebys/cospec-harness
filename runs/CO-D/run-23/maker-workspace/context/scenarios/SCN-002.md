Scenario ID: SCN-002
Title: Find saved bookmarks by remembered words
Type: Happy Path
Approval status: approved
Approval session: SESSION-002
Approval cycle: 1

## Approved behaviour
As a person types in the search box beneath the always-available save box, the visible bookmark cards narrow immediately without requiring a search button. Matching ignores capitalization and checks each saved bookmark's title, description, and full web address. Cards retain their clean display, including a concise source site rather than exposing the full address.

## Gherkin
Feature: Search saved bookmarks

  Scenario: Narrow the library immediately by words in a description
    Given the library contains several saved bookmarks
    And one bookmark has the word "keyboard" in its description but not its title
    When the person types "keyboard" into search
    Then the visible list immediately narrows to the matching bookmark
    And no search submission is required

  Scenario: Search without regard to capitalization
    Given a saved bookmark contains the word "keyboard"
    When the person searches for "Keyboard"
    Then that bookmark is included in the results

  Scenario: Find a bookmark by its full web address
    Given a saved bookmark has an address on "css-tricks.com"
    And its card shows a concise source site
    When the person types "css-tricks.com" into search
    Then that bookmark is included in the results
    And its card retains the clean concise display

## Assumptions
- Search is placed directly beneath the always-available save box.
- Search filters results as the person types.
- Search covers titles, descriptions, and full saved web addresses.
- Searching bookmark notes is deferred until personal notes are explored.
