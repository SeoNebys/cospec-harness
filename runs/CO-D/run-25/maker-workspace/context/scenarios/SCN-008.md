Scenario ID: SCN-008
Title: Filter the collection by a bookmark label
Type: Happy Path
Approval status: approved
Approval session: SESSION-008
Approval cycle: 1

## Approved behaviour
Clicking a label pill on a saved bookmark keeps the person in their collection and narrows the list to every bookmark carrying that label. The list heading changes to the selected label and the visible bookmark count updates to match.

## Gherkin
Feature: Bookmark labels

  Scenario: View bookmarks carrying a selected label
    Given the collection contains bookmarks with different labels
    When the person clicks the "Reference" label on a bookmark card
    Then only bookmarks carrying "Reference" remain visible
    And the list heading is "Reference"
    And the visible bookmark count matches the filtered results

## Assumptions
- Filtering happens in the collection view.
- Returning to all bookmarks is explored as a related behaviour.
