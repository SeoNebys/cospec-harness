Scenario ID: SCN-015
Title: Retain Read Later and Archive status indefinitely
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Bookmarks do not expire, move, or disappear from Read Later or Archive because time has passed. Their status changes only through an explicit client action such as marking reading complete, restoring, archiving, or deleting.

## Gherkin
Feature: Keep bookmark status dependable over time

  Scenario: Time passes without client action
    Given a bookmark is in Read Later or Archive
    When any amount of time passes without an explicit status-changing action
    Then the bookmark remains in the same destination
    And it is not automatically expired, moved, deleted, or reshuffled

## Assumptions
- There are no automatic retention or cleanup policies in this personal app.
