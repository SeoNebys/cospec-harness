Scenario ID: SCN-007
Title: Archive a bookmark to keep it without cluttering the main list
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

Each non-archived bookmark card has an "Archive" control. Archiving removes the
bookmark from the "All bookmarks" view and from the "Read later" view, keeping the
main list uncluttered, but never deletes it. An "Archived" tab (with a count)
lists archived bookmarks; an archived card shows a "↩ Restore to bookmarks"
control (the read-later and tag-filter actions are hidden there, keeping the
archive a quiet holding area) and, per SCN-008, an "Edit" control. Restoring
returns the bookmark to All bookmarks.
Archived bookmarks do not appear in the normal search/sort/filter of All
bookmarks; they are found via the Archived tab. When there are no archived
bookmarks, a clear "No archived bookmarks" message is shown.

## Gherkin
Feature: Archiving bookmarks

  Scenario: Archive a bookmark
    Given a bookmark shown in All bookmarks
    When I archive it
    Then it no longer appears in All bookmarks or Read later
    And it appears in the Archived tab
    And it is not deleted

  Scenario: Restore an archived bookmark
    Given a bookmark in the Archived tab
    When I restore it
    Then it appears again in All bookmarks

  Scenario: Archived items are excluded from normal browsing
    Given a bookmark is archived
    When I search, sort, or filter within All bookmarks
    Then the archived bookmark is not included

  Scenario: Empty archive
    Given no bookmarks are archived
    When I open the Archived tab
    Then a "No archived bookmarks" message is shown

## Assumptions
- Archiving is reversible and never deletes the bookmark. (Confirmed.)
- Archived items are excluded from All bookmarks, Read later, and their
  search/sort/filter. (Confirmed.)
- Archived cards expose Restore and Edit (Edit added per SCN-008; to confirm).
