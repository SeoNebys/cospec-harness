Scenario ID: SCN-009
Title: Explain a search with no matching bookmarks
Type: Edge Case
Approval status: approved
Approval session: SESSION-009
Approval cycle: 1

## Approved behaviour

When no bookmarks match a search, the bookmark cards are replaced by a clear
message naming the unmatched search and a Clear search action. Clearing the
search restores the full collection.

## Gherkin

Feature: Searching bookmarks

  Scenario: No bookmarks match the search
    Given the collection contains no bookmark matching "astronomy"
    When the client searches for "astronomy"
    Then the client is told that no bookmarks were found
    And the unmatched search text is shown
    When the client clears the search
    Then the full bookmark collection is shown again

## Assumptions

- The no-results explanation appears where bookmark cards normally appear.
- Clearing a search is available directly from that explanation.
