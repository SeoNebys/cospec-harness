Scenario ID: SCN-003
Title: Open a saved bookmark from its card
Type: Happy Path
Approval status: approved
Approval session: SESSION-003
Approval cycle: 1

## Approved behaviour
The user can click a saved bookmark card to open its original website in a new browser tab. The bookmark library remains open in the original tab.

## Gherkin
Feature: Open a saved bookmark

  Scenario: Open the original website from a bookmark card
    Given the library contains a saved bookmark
    When the user clicks the bookmark card
    Then the bookmark's original website opens in a new browser tab
    And the bookmark library remains open in the original browser tab

## Assumptions
- The bookmark has a valid original web address.
- The browser permits a new tab to open from the user's click.
- Any separate controls later placed within a bookmark card perform their own action rather than opening the website.
