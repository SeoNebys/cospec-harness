Scenario ID: SCN-007
Title: Tagging links, tag reuse suggestions, and stacking tag filters
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When saving or editing a link, the client can add tags by typing a word and
pressing Enter, which turns it into a removable chip; a chip is removed with its
× (or Backspace on an empty tag box). While typing, the app suggests tags the
client has already used and that are not already on this link, so the client can
reuse an existing tag instead of creating a near-duplicate. Each saved card shows
its tags as chips. Clicking a tag chip adds that tag as an active filter while
staying in the current view (All / To read / Reference); multiple tag filters
stack (a link must have all active tags), and each active-tag filter can be
removed individually. Tag filters and text search apply together.

## Gherkin
Feature: Tagging and tag-based rediscovery

  Scenario: Add and remove tags on a link
    Given the client is saving or editing a link
    When the client types a word and presses Enter
    Then the word becomes a removable tag chip
    When the client removes a chip
    Then that tag is no longer on the link

  Scenario: Reuse an existing tag via suggestion
    Given the client has previously used the tag "article"
    When the client types "art" in the tag box of another link that lacks it
    Then "article" is offered as a suggestion to reuse
    And choosing it adds "article" rather than a near-duplicate

  Scenario: Filter by clicking a tag, staying in the current view
    Given the client is on the Reference view
    When the client clicks a tag chip on a card
    Then the library filters to that tag and remains on the Reference view
    And an active-tag filter chip appears that can be removed

  Scenario: Stack multiple tag filters and combine with search
    Given one tag filter is active
    When the client clicks another tag and also types search words
    Then only links matching all active tags and the search remain

## Assumptions
- Tags are single words, lower-cased on entry.
- Tag suggestions are drawn from tags already used across the library.
- Multiple active tag filters combine with AND and with the text query.
