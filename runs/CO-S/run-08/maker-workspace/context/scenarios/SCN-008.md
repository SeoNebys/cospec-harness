Scenario ID: SCN-008
Title: Saving a link that already exists opens it for editing
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When the client saves a link whose address matches one already saved, the app
does not create a duplicate. Instead it shows a notice ("You already saved this
link — opening it so you can edit it instead.") and opens the existing bookmark
in edit mode. Two addresses are treated as the same link even if they differ only
by a trailing slash or a missing "https://". The client approved matching
duplicates this way and preferring to edit the existing entry.

    And a notice explains it is already saved
    And the existing bookmark opens in edit mode

## Assumptions
- Duplicate detection compares normalized addresses (scheme added, trailing
  slashes ignored, case-insensitive).
- Only the address determines duplication (not title or topic).
