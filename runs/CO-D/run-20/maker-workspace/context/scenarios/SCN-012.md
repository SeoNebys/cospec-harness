Scenario ID: SCN-012
Title: Long text in a bookmark (title wraps; description clamps with Show more)
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

A very long title wraps and remains fully visible (including long unbroken
strings). A long description is shortened after a few lines to keep the list
readable, with a "Show more" control that reveals the full text and can collapse
it again ("Show less").

## Gherkin
Feature: Long text

  Scenario: Long title stays fully visible by wrapping
    Given a bookmark with a very long title
    Then the title wraps and is shown in full

  Scenario: Long description clamps with a Show more control
    Given a bookmark with a long description
    Then the description is clamped after a few lines with a "Show more" control
    When the user clicks "Show more"
    Then the full description is shown and can be collapsed again

## Assumptions
- The same collapse pattern is used for long notes (SCN-009).
