Scenario ID: SCN-002
Title: Tag a bookmark while saving and reuse an existing tag
Type: Happy Path
Approval status: approved
Approval session: SESSION-002
Approval cycle: 1

## Approved behaviour
While saving a bookmark, a person can type a tag and press Enter to turn it into a chip. Tags may contain spaces. As the person types, matching tags they have already used are suggested. Pressing Enter while a matching suggestion is shown reuses that existing tag rather than creating a near-duplicate. Saved tags appear on the bookmark in the list.

## Gherkin
Feature: Tagging bookmarks

  Scenario: Add a new tag while saving
    Given a person is previewing the fetched details for a new bookmark
    When the person types a tag and presses Enter
    Then the tag is attached to the bookmark as a chip
    And the tag may contain spaces

  Scenario: Reuse a matching existing tag
    Given the tag "reference" has been used before
    And a person is adding tags while saving a bookmark
    When the person types "ref"
    Then the existing "reference" tag is suggested
    When the person presses Enter
    Then the existing "reference" tag is attached rather than a new near-duplicate
    When the person saves the bookmark
    Then all attached tags appear on the bookmark in the list

## Assumptions
- Tags are attached during the save flow before the bookmark is saved.
- Matching suggestions are drawn from tags the person has used previously.
- A matching suggestion takes priority when Enter is pressed.
