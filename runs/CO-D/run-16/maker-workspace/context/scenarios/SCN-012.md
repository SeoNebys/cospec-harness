Scenario ID: SCN-012
Title: Input that is not a web address is rejected
Type: Error Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When the client enters text that is not a valid web address (e.g. free text with
spaces, or a bare word with no domain), the app does not create a bookmark. It
shows a clear message asking the client to enter a valid web address. This is
distinct from a valid address whose details merely cannot be fetched (SCN-011),
which remains saveable.

## Gherkin
Feature: Reject non-address input

## Assumptions
- Validity: no whitespace, and a domain with at least one dot (protocol and path
  optional).
