Scenario ID: SCN-005
Title: Narrow word-search results with a tag filter
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

The client can search the visible saved information—the title, description, and web address—without matching capitalization. They can combine those word matches with a visible tag selected above the collection, and the collection shows only bookmarks that satisfy both the words and the tag. The visible tags also remind the client which tags are available without opening another control.

## Gherkin

Feature: Rediscover saved bookmarks

  Scenario: Combine capitalization-insensitive word search with a tag
    Given two saved bookmarks have visible details containing the word "Rome"
    And one of those bookmarks has the tag "Travel"
    When the client searches for "rome" using any capitalization
    Then both bookmarks containing "Rome" in their visible saved details are shown
    When the client selects the "Travel" tag filter
    Then only the bookmark that matches the word and has the "Travel" tag is shown

  Scenario: Match words in each kind of visible saved detail
    Given bookmarks have a saved title, description, and web address
    When the client searches for a word present in any one of those fields
    Then each bookmark containing that word in its title, description, or web address is shown

## Assumptions

- Word matching is case-insensitive.
- Word search covers the saved title, description, and web address, not the full unseen contents of the page.
- Tag and word criteria are combined so a result must satisfy both.
- The client's own bookmark notes and searching those notes remain to be explored separately.
- Tag filters remain visibly laid out above the collection rather than hidden in a dropdown.
