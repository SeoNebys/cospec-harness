Scenario ID: SCN-036
Title: Add a label to selected bookmarks in bulk
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A person can select several bookmarks in the active filtered or search view and add one label to all of them in a single action. Select all shown selects only the currently visible result set, not hidden bookmarks elsewhere. The new label is added while every bookmark's existing labels remain intact.

## Gherkin
Feature: Bulk bookmark organization

  Scenario: Add a label to every bookmark shown in a filtered view
    Given a filtered view shows four Cooking bookmarks
    And those bookmarks have differing existing labels
    When the person chooses "Select all shown"
    And bulk-adds the label "Favorites"
    Then all four visible bookmarks gain "Favorites"
    And each bookmark retains its existing labels
    And bookmarks outside the visible filtered view remain unchanged

## Assumptions
- Bulk selection is scoped to the current result set.
- Adding a label is additive and does not replace other labels.
