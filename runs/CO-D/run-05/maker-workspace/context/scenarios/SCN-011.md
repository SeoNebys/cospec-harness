## Approved behaviour

When a view has no bookmarks to show — including a brand-new, empty app — the
list area shows a calm, explanatory message appropriate to that view rather than
a blank space: To read explains that saved links land there, Done and Archived
each show their own matching message. The same applies when a search yields no
matches (a clear "no matches in this view" message).

## Gherkin

Feature: Empty states

  Scenario: Empty view shows a helpful message
    Given a view with no bookmarks
    Then a calm explanatory message for that view is shown instead of a blank area

  Scenario: Brand-new empty app
    Given no bookmarks have ever been saved
    Then the To read view shows its explanatory empty message

## Assumptions
- Each of the three views has its own empty message.
