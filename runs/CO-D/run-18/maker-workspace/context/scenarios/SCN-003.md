Scenario ID: SCN-003
Title: Find bookmarks with capitalization-insensitive text search
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Typing in the library search box immediately narrows the visible bookmarks without requiring a submit action. Matching ignores capitalization and searches each bookmark's title, description, personal note, and web address. Each result card displays the note and web address as context so the person can understand why it matched. The visible result count updates with the filtered list.

## Gherkin
Feature: Search saved bookmarks

  Scenario Outline: Search all saved text without regard to capitalization
    Given the library contains bookmarks with saved titles, descriptions, personal notes, and web addresses
    When the user types an uppercase query that appears only in a bookmark's <field>
    Then that bookmark remains visible immediately
    And bookmarks without the query in any searchable field are hidden
    And the visible result count is updated
    And the result displays the matching bookmark's note and web address as context

    Examples:
      | field       |
      | title       |
      | description |
      | note        |
      | web address |

## Assumptions
- Search updates as the user types and requires no separate submit action.
- Result cards show the saved note and web address in addition to the title and description.
- Search applies to active library bookmarks.
