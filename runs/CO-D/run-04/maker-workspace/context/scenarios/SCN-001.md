Scenario ID: SCN-001
Title: Save a link and see it recognizably in the library
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The client pastes a web address into a box at the top of the library and saves
it (button or Enter). The new link appears immediately at the top of the list.
Briefly it shows a "reading the page…" state, then the page's name (title) and a
one-line description fill in automatically, with no typing required from the
client. Each saved link is shown as a card: the page name in bold, a one-line
description under it, and the source website (domain) with a small icon at the
bottom. The full raw URL is deliberately not shown — the site name + icon is
enough to recognize it. This automatic recognition is the core relief the client
was after.
