Scenario ID: SCN-010
Title: Undo an accidental bookmark removal
Type: Edge Case
Approval status: approved
Approval session: SESSION-010
Approval cycle: 1

## Approved behaviour
Choosing Remove from a bookmark's action menu removes it immediately without a confirmation dialog. A temporary Undo action then allows an accidental removal to be reversed. Undo restores the bookmark to its original position and restores the collection count.

## Gherkin
Feature: Managing saved bookmarks

  Scenario: Undo a bookmark removal
    Given the collection contains a saved bookmark
    When the person removes that bookmark from its action menu
    Then the bookmark immediately disappears without a confirmation dialog
    And an Undo action is shown for eight seconds
    When the person chooses Undo
    Then the bookmark returns to its original position
    And the collection count is restored

## Assumptions
- The Undo action remains available for eight seconds.
