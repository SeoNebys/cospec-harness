# Cycle 1 goal

> Honestly, the main thing is I want to stop losing links. Right now I paste things into notes and emails to myself and I can never find them again.
>
> So when this is done, I'd love to just drop in a web address and have it saved — and ideally it figures out the page's title and a little description on its own, so I'm not typing all that in. Then later I want to actually *find* things: search by words, and organize with tags or labels so I can pull up, say, everything about cooking in one click.
>
> A couple of other things that matter to me: some links I save meaning to read later, so I'd want a way to set those aside and come back to them. And if I save something I've already saved, I don't want a bunch of duplicates piling up — it should just take me to the one I already have.
>
> That's the gist of my frustration today.

Confirmed direction:

> One dependable place to save links with the details filled in, no duplicates, and then find things again through search, labels, or a read-later set.

Interface form:

> A web app would suit me best — something I can open in my browser on my computer. That's where I'm usually saving and looking things up anyway. It's just for me, so I don't need anything fancy for other people logging in.
