# Test strategy

## Unit and integration

- URL completion, validation, duplicate normalization, and meaningful-query retention.
- Metadata extraction and relative asset resolution.
- Nested browser folder parsing, import preview counts, duplicate preservation, saved dates, exports, and full backup restoration.
- API creation, sanitization, update, canonical labels, batch changes, atomic persistence, and reopening the same data file.

## Browser acceptance

- Empty-library entry, invalid-address recovery, gathered details, editing, labels, formatted notes, Read later, and normalized duplicate handling.
- Note search with match explanation, complete search reset, Read later completion, Archive inspection, and restoration.
- Browser-file preview/import, saved labels and dates, sorting, advanced search combinations/exclusions, and visible-result batch selection.
- Batch labelling, archiving, deletion cancellation, and confirmed deletion.
- Both downloadable export formats and complete-backup restoration.
- Manual save fallback when page details cannot be gathered.

## Manual visual checks

- Empty and populated desktop layouts.
- Equal-height cards with clamped long text and `+N more` labels.
- Details editor with reopened formatted bullet notes.
- Responsive layout at narrow desktop/mobile widths.
