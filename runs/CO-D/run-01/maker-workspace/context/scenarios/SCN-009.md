Scenario ID: SCN-009
Title: Archive and restore a bookmark
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Archive is a distinct, reversible action in the bookmark's three-dot menu. Archiving removes a bookmark from All bookmarks and normal label views while preserving it unchanged in a separate Archive area in the left navigation. From Archive, the menu offers Restore to All bookmarks. Restoring returns it intact to the everyday collection and removes it from Archive.

## Gherkin
Feature: Bookmark archive

  Scenario: Tuck a bookmark away
    Given a saved bookmark is visible in the everyday collection
    When the person chooses Archive from its action menu
    Then the bookmark is hidden from All bookmarks and normal label views
    And the bookmark remains unchanged in the Archive view
    And the Archive count increases

  Scenario: Restore an archived bookmark
    Given a bookmark is visible in Archive
    When the person chooses Restore to All bookmarks from its action menu
    Then the unchanged bookmark returns to All bookmarks
    And it is removed from Archive
    And the Archive count decreases

## Assumptions
- Archive has a persistent place in the left navigation, separate from labels.
- Archived bookmarks do not appear in ordinary collection or label views.
- Archive is reversible, while deletion is a separate permanent action.
