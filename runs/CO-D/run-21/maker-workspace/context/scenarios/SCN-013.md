Scenario ID: SCN-013
Title: Archive and restore, separate from permanent delete
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A bookmark can be archived and later restored, indefinitely; archiving never loses
anything. A separate "View" switch (Active / Archived) defaults to Active. The
Active list and its search never include archived bookmarks; searching while in
Archived searches only archived bookmarks. Active cards offer Archive and Delete;
archived cards (shown dimmed with an "Archived" badge) offer Restore and Delete.
Delete is permanent and always shows a clear confirmation warning that it cannot be
undone, with the ability to cancel. Delete works from either view. The View switch
is independent of the read/unread "Show" filter.

## Gherkin
Feature: Archive and delete

  Scenario: Archive hides from active but keeps the bookmark
    Given an active bookmark
    When the user archives it
    Then it no longer appears in the Active list or Active search
    And it appears under View: Archived

  Scenario: Archived search is scoped to the archive
    Given the View is Archived
    When the user searches
    Then only archived bookmarks are searched

  Scenario: Restore
    Given an archived bookmark
    When the user restores it
    Then it returns to the Active list

  Scenario: Permanent delete requires confirmation
    When the user deletes a bookmark from either view
    Then a confirmation warns the deletion is permanent
    And on confirm the bookmark is removed for good
    And on cancel nothing is deleted

## Assumptions
- Default View is Active. Archive is reversible indefinitely.
- Delete is available from both Active and Archived, always confirmed.
