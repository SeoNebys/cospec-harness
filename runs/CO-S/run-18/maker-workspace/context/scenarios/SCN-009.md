Scenario ID: SCN-009
Title: Add an optional personal note while saving
Type: Happy Path
Approval status: approved
Approval session: SESSION-009
Approval cycle: 1

## Approved behaviour
The quick-save form keeps the optional personal-note field out of the way until the person chooses Add a note. They can write the note before saving; afterward, it is visible on the bookmark card and can be found through broad search.

## Gherkin
Feature: Personal bookmark notes

  Scenario: Reveal and save an optional note
    Given the person is entering a web address to save
    And the optional note field is hidden
    When the person chooses Add a note
    And enters a personal note
    And saves the link
    Then the bookmark is saved with that note
    And the note is visible on its bookmark card
    And text from the note can be used to find the bookmark through search

## Assumptions
- Adding a note is optional.
- The note is entered as part of the save action.
- The note field is revealed on demand to keep everyday saving compact.
