Type: Happy Path

## Approved behaviour
A search box lets the client find links by a few remembered words. Search is
case-insensitive and looks across the title, the page description, the web
address, and the client's personal note. Behaviour:
- Several plain words narrow together (implicit AND — all must appear).
- "quoted text" matches that exact phrase; quoting is also the one way to search
  a word literally (e.g. "or" searches for the word rather than acting as an
  operator).
- #tag matches links carrying that tag specifically.
- and / or / not combine terms and are case-insensitive (and = AND = And);
  parentheses group, e.g. rome (#article OR #book).
- Matches are highlighted in the results. When nothing matches, a calm
  "no links match" state is shown. Search applies within the current view (All /
  To read / Reference) and combines with any active tag filters.

## Gherkin
Feature: Search query language

  Scenario: Implicit AND across remembered words
    Given links exist
    When the client searches "deep cables"
    Then only links containing both words (in title, description, address, or note) remain

  Scenario: Exact phrase with quotes
    When the client searches "deep-sea cables"
    Then only links containing that exact phrase remain

  Scenario: Tag term
    When the client searches "#article"
    Then only links tagged article remain

  Scenario: Boolean composition with grouping, case-insensitive
    When the client searches "rome (#article or #book)"
    Then links whose note/text contains rome and that are tagged article or book remain
    And "rome (#article OR #book)" behaves identically regardless of operator case

  Scenario: NOT excludes
    When the client searches "database not sqlite"
    Then links matching database but also containing sqlite are excluded

  Scenario: Quoting makes an operator word literal
    When the client searches for "or" in quotes
    Then it is treated as the literal word, not the OR operator

  Scenario: No matches
    When the search matches nothing
    Then a calm "no links match your search" state is shown

## Assumptions
- Searchable fields: title, description, web address, personal note; tags via #tag.
- Operators and/or/not are case-insensitive; quotes force literal text.
- Search scope is the current view and stacks with active tag filters.
