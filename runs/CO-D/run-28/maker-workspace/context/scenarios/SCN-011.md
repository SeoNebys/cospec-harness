Scenario ID: SCN-011
Title: Empty or invalid address saves nothing and explains
Type: Error Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
If the client presses Add with an empty box or with text that is not a valid
link, no bookmark is created and a gentle notice explains that it doesn't look
like a valid link yet. No draft opens.

## Gherkin
Feature: Input validation on save

  Scenario: Empty address
    Given the save box is empty
    When the client presses Add
    Then no bookmark is created
    And a notice explains a valid link is needed

  Scenario: Invalid address
    Given the client typed text that is not a valid link
    When the client presses Add
    Then no bookmark is created
    And a notice explains it doesn't look like a valid link yet

## Assumptions
- A bare host without scheme is accepted (a scheme is added), not treated as
  invalid.
