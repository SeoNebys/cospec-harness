Scenario ID: SCN-006
Title: Separate "to read" from "finished" without deleting (reversible)
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Every bookmark has a reading status shown as a badge: "To read" or "Finished".
Newly saved bookmarks start as "To read". Each bookmark has a button that moves
it between the two states ("Mark as finished" / "Move to To-read"); the move only
changes status and never deletes the bookmark, and it is fully reversible.

The collection has a switch with three views: All (the full active collection,
the default), To read, and Finished. The status view narrows together with the
search box and any active tag filters (all combine with AND), so the client can,
for example, see only unread bookmarks with a particular tag or matching a
search.

The client confirmed: All shows the full active collection; To read and Finished
are useful focused views; moving between them is clear and reversible; new
bookmarks starting as "To read" is right; and status combining with search and
tags matches expectations.

## Gherkin
Feature: Reading status

  Scenario: New bookmark starts as To read
    When I save a new bookmark
    Then its status is "To read"

  Scenario: Mark a bookmark finished without deleting it
    Given a "To read" bookmark
    When I press "Mark as finished"
    Then its status becomes "Finished"
    And the bookmark is not deleted

  Scenario: Move a finished bookmark back to To read
    Given a "Finished" bookmark
    When I press "Move to To-read"
    Then its status becomes "To read"

  Scenario: Focused views
    When I choose the To read (or Finished) view
    Then only bookmarks with that status are shown
    And choosing All shows the full active collection

  Scenario: Status combines with search and tags
    Given the To read view is selected
    When I also apply a tag filter and/or search text
    Then only "To read" bookmarks matching those are shown

## Assumptions
- Two statuses only: "To read" (default) and "Finished".
- Status is independent of tags and search; all three narrow together (AND).
- Nothing is ever deleted by changing status.
