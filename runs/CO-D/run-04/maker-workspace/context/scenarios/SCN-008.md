Scenario ID: SCN-008
Title: Archive and restore a bookmark
Type: Happy Path
Approval status: approved
Approval session: SESSION-008
Approval cycle: 1

## Approved behaviour
Archiving removes a bookmark from All bookmarks without deleting it and adds it
to a separately counted Archive view. Archived bookmarks remain out of normal
search results and only appear when the person deliberately searches within
Archive. Restoring returns the same bookmark, unchanged, to All bookmarks and
does not create a duplicate.

## Gherkin
Feature: Archive older bookmarks

  Scenario: Move a bookmark out of the everyday collection
    Given a bookmark is visible in All bookmarks
    When the person archives it
    Then it leaves All bookmarks
    And the Archive count increases
    And the same bookmark is visible in Archive

  Scenario: Keep archived bookmarks out of normal search
    Given a bookmark has been archived
    When the person searches for it in All bookmarks
    Then it is not included in the results
    When the person opens Archive with the same search
    Then the archived bookmark is included in the results

  Scenario: Restore an archived bookmark
    Given a bookmark is visible in Archive
    When the person restores it
    Then the same bookmark returns unchanged to All bookmarks
    And it leaves Archive
    And no duplicate bookmark is created

## Assumptions
- Archive has a persistent sidebar entry and count.
- Search is scoped to the currently selected collection view.
- Archiving preserves the bookmark and all its details.
