Scenario ID: SCN-010
Title: Recover immediately from a search with no matches
Type: Edge Case
Approval status: approved
Approval session: SESSION-010
Approval cycle: 1

## Approved behaviour

When a query matches no bookmarks, the query remains visible, the result count becomes zero, and a plain message says that no bookmarks match. Clearing the query with the control inside the search box immediately restores the full library and its count.

## Gherkin

Feature: Search bookmarks

  Scenario: Show an understandable no-results state
    Given the library contains bookmarks
    When the user types a query that matches no title, description, or personal note
    Then no bookmark cards are shown
    And the query remains visible
    And the result count shows zero bookmarks
    And a message says that no bookmarks match the search

  Scenario: Clear an unsuccessful search
    Given a search has no matching bookmarks
    When the user clears the query using the control inside the search box
    Then the search box is empty
    And the full bookmark library returns immediately
    And the full bookmark count is restored

## Assumptions

- The clear-search control appears inside the search box while a query is present.
- Clearing a query does not require a separate submission action.
