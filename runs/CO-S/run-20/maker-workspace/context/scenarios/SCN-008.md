Type: Happy Path

## Approved behaviour

A saved link can be edited or deleted from its entry, in both the main collection
and the archive. Choosing "Edit" loads the link's current details into the save
form (retitled "Edit link"); updating applies the changes to the same link
without creating a duplicate, and "Cancel edit" abandons the changes. Choosing
"Delete" asks for confirmation, warns that it is permanent, and notes that
Archive is the reversible alternative; only after confirmation is the link
removed permanently. Editing preserves the link's saved date, reading status, and
archived state. Entries with a very long title and several topics wrap and lay
out cleanly rather than breaking the layout.

## Gherkin

Feature: Managing a saved link

  Scenario: Edit a saved link
    Given a saved link
    When I choose Edit and change its details
    And I choose Update
    Then the same link reflects the changes
    And no duplicate is created
    And its saved date, reading status, and archived state are preserved

  Scenario: Cancel an edit
    Given I have started editing a link
    When I cancel the edit
    Then the link is left unchanged

  Scenario: Delete a link permanently
    Given a saved link
    When I choose Delete and confirm the permanent removal
    Then the link is removed from the collection

  Scenario: Long title and many topics lay out cleanly
    Given a link with a very long title and several topics
    When I view its entry
    Then the title and topic tags wrap without breaking the layout

## Assumptions

- Editing reuses the save form; the address is editable.
- Delete requires confirmation and is permanent; Archive (SCN-005) is the
  reversible alternative.
- Edit and Delete are available in both the main collection and the archive.
- A link may have zero topics; entries adapt to any number of topics.
