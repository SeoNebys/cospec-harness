Scenario ID: SCN-015
Title: Refine search without memorizing special syntax
Type: Happy Path
Approval status: approved
Approval session: SESSION-015
Approval cycle: 1

## Approved behaviour
Guided search controls let the person combine an exact phrase, a required label, and an excluded site so all selected conditions must match, without memorizing operators or punctuation. Within a label group, they can instead choose to match any selected label. For example, selecting Design or Reference includes bookmarks carrying either label and excludes unrelated labels. An exact phrase or site exclusion can still narrow those either-or results further.

## Gherkin
Feature: Guided advanced bookmark search

  Scenario: Require several different search conditions
    Given the library contains bookmarks with different wording, labels, and source sites
    When the person enters the exact phrase "keyboard navigation"
    And selects the label "Design"
    And excludes "css-tricks.com"
    Then only bookmarks satisfying every selected condition are shown
    And the person does not need to type search operators

  Scenario: Match either of two labels
    Given one bookmark is labeled "Design"
    And another is labeled "Reference"
    And a third is labeled "Books"
    When the person selects Design and Reference
    And chooses Match any selected
    Then the Design bookmark is shown
    And the Reference bookmark is shown
    And the Books bookmark is not shown

  Scenario: Narrow an either-or group further
    Given bookmarks match either Design or Reference
    When the person adds an exact phrase or excluded site
    Then those conditions further narrow the combined label results

## Assumptions
- Guided controls are the primary everyday interface for refined search.
- Exact-phrase and exclusion conditions apply to the combined label results.
- A text expression may exist as an additional path, but is not required for everyday use.
