## Approved behaviour

Consolidated edge behaviours for the additional feature blocks:

- Import with no bookmarks: importing a file containing no links shows a clear
  message ("No bookmarks were found in that file…") instead of a silent no-op.
- Offline copy + archive/delete: archiving a bookmark keeps its offline copy
  (indicator remains, visible in the Archived view); deleting the bookmark
  removes it and its offline copy together.
- PDF detection is robust to query/hash suffixes (e.g. /a.pdf?v=2 is a PDF).
- Items-per-page = All (or a page size larger than the result set) reveals
  everything with no "Show more".
- Selection is pruned if a selected bookmark is removed; the count stays accurate.
- Empty/whole-collection sorting and paging show the calm empty state with no
  broken controls.

## Gherkin
Feature: Additional edge cases

  Scenario: Import a file with no bookmarks
    When the user imports a file containing no links
    Then a clear "no bookmarks found" message is shown and nothing is added

  Scenario: Offline copy persists through archive but not delete
    Given a bookmark with an offline copy
    When it is archived
    Then it keeps its offline copy in the Archived view
    When it is deleted
    Then the bookmark and its offline copy are removed together

  Scenario: PDF detection with suffixes
    Given a link ending in .pdf followed by a query or hash
    Then it is treated as a PDF for offline saving

  Scenario: Page size All
    Given items-per-page is All or larger than the result set
    Then all results are revealed with no Show more control

- These consolidate edge behaviour already demonstrated for SCN-013..018.
