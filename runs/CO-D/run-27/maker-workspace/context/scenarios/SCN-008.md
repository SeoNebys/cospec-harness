Scenario ID: SCN-008
Title: Notes on a bookmark with Markdown and a read-only formatted view
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A bookmark can carry a free-text note, added when saving and edited anytime in the
editor. The editor shows the raw note text; the note supports simple Markdown:
headings, bold, italic, links, and bulleted/numbered lists (images, tables, and
code blocks are not supported). On the card, the note appears as a clean plain-text
preview (Markdown stripped) trimmed to about three lines, with an "Open note" action
that opens a read-only view rendering the note's Markdown formatting (no edit mode).
From that view the client can Edit (jumps to the editor) or Close. Note text is
included in ordinary word search alongside title, description, and address. Links in
notes are limited to http/https/mailto and open in a new tab; any HTML in the note
is shown as text, not executed.

## Gherkin
Feature: Notes on a bookmark

  Scenario: Add and preview a note
    Given the client is editing or saving a bookmark
    When the client types a note using Markdown and saves
    Then the card shows a plain-text preview trimmed to about three lines

  Scenario: View the full formatted note read-only
    Given a bookmark with a note
    When the client chooses "Open note"
    Then the note is shown with its Markdown formatting rendered, read-only
    And links open in a new tab
    When the client chooses Edit
    Then the editor opens showing the raw Markdown text

  Scenario: Notes are searchable
    Given a note containing a word not in the title/description/address
    When the client searches that word
    Then the bookmark matches

  Scenario: Notes render safely
    Given a note containing raw HTML such as a script tag
    When the note is viewed
    Then the HTML is shown as text and not executed

## Assumptions
- Supported Markdown subset: headings, bold, italic, links, unordered/ordered lists.
- Preview strips Markdown; full formatting only in the Open-note view.
