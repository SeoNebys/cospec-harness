Scenario ID: SCN-016
Title: Select several bookmarks, or all in the current filtered view
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

Each bookmark has a selection checkbox. Selecting one or more reveals a bulk
action bar showing the count. A **"Select all in view"** action selects every
bookmark currently shown — this respects the active view (All / To read /
Archived) and any active search/tag filter, so it means "all in *this* filtered
view", not the entire library. When everything in the view is selected the action
becomes **"Clear this view"**. A **Clear** action deselects everything.

## Gherkin
Feature: Bulk selection

  Scenario: Select individual bookmarks
    When the user ticks the checkboxes of several bookmarks
    Then the bulk action bar shows the number selected

  Scenario: Select all in the current filtered view
    Given a view and/or filter is active
    When the user chooses "Select all in view"
    Then exactly the bookmarks currently shown become selected
    And no bookmarks outside the current view/filter are selected

  Scenario: Clear the selection
    When the user chooses Clear
    Then no bookmarks are selected and the bulk bar is hidden

## Assumptions
- Selection scope never reaches beyond the current view/filter.
