Scenario ID: SCN-006
Title: Recover from a search with no matching bookmarks
Type: Edge Case
Approval status: approved
Approval session: SESSION-006
Approval cycle: 1

## Approved behaviour
When search text matches no bookmarks, the list is replaced by a clear “No bookmarks match that search” state rather than appearing broken. If a collection filter is active, the message explains that the selected collection contains no match. Clearing the search removes only the search text, preserves the selected collection filter, and restores that collection’s bookmarks.

## Gherkin
Feature: Empty bookmark search results

  Scenario: Show no matches within a selected collection
    Given the “Web development” collection filter is selected
    And it contains “MDN Web Docs” and “CSS-Tricks”
    When the user searches for “recipe”
    Then no bookmark cards are shown
    And the result count is 0
    And a message says that no bookmarks match the search
    And the message explains that “Web development” contains no saved link with that text
    And an action to clear the search is shown

  Scenario: Clear an unsuccessful search while keeping the collection filter
    Given the “Web development” collection filter is selected
    And the search for “recipe” has no matches
    When the user clears the search
    Then the search text is removed
    And the “Web development” filter remains selected
    And “MDN Web Docs” and “CSS-Tricks” are shown again

## Assumptions
- An empty search result is visually distinct from an application error.
- Clearing search does not clear an active collection filter.
