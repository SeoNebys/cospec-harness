Scenario ID: SCN-006
Title: Archive and restore a bookmark
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

Archiving a bookmark hides it from the normal list (All / To read / Reference)
and from normal searches, while keeping it available in a dedicated "Archived"
view. From the Archived view the user can restore it to the normal collection.
Search works within the Archived view over archived items. Archiving is a
separate state from permanent deletion; nothing is destroyed.

## Gherkin
Feature: Archive

  Scenario: Archive hides a bookmark from normal views and search
    Given a non-archived bookmark
    When the user clicks "Archive"
    Then it no longer appears in All / To read / Reference
    And it is excluded from searches performed in those views

  Scenario: Archived items are found in the Archived view and are searchable there
    Given an archived bookmark
    When the user opens the "Archived" view
    Then the bookmark is listed
    And a search in that view can match it

  Scenario: Restore returns a bookmark to the normal collection
    Given an archived bookmark
    When the user clicks "Restore"
    Then it returns to the normal collection and leaves the Archived view

## Assumptions
- Archive/restore preserves all of the bookmark's data.
