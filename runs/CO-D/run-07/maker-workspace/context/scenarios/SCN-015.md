Scenario ID: SCN-015
Title: Preserved page copy (automatic, self-contained) + Internet Archive option
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Each bookmark can hold a preserved copy of the page so it stays readable even if
the original changes or disappears. By default a self-contained copy is made
automatically for every newly saved bookmark; this automatic copying can be
turned off in Settings, and a manual "Save a copy" action remains available on
each bookmark either way. The bookmark shows "Saved copy · captured <date> · View
copy"; opening it shows the preserved snapshot, clearly marked as a saved copy and
not the live page. For a PDF link, the preserved copy is the PDF file itself
(labelled "Saved copy (PDF)"). Sending a page to the Internet Archive is a
separate, explicit action ("Save to Internet Archive"), never automatic; once
done, an Internet Archive link is shown alongside the saved copy.

The client confirmed: automatic copies as the default (best supports not losing
things), a Settings switch to turn automatic copying off while keeping manual
"Save a copy", self-contained copies that work without the live page, PDF-as-PDF,
and Internet Archive as a separate explicit action.

NOTE (prototype limitation, recorded per principles): a Phase-1 prototype cannot
truly fetch and store live pages. The prototype simulates the capture — "View
copy" opens a generated snapshot and the Internet Archive link is illustrative.
The approved behaviour is the automatic self-contained capture; the real capture
and storage is a build-time integration (see NFR backlog).

## Gherkin
Feature: Preserved copies

  Scenario: Automatic copy on save (default)
    Given automatic copying is on
    When I save a new bookmark
    Then a self-contained preserved copy is made and shown with its capture date

  Scenario: Turn automatic copying off but keep manual copies
    Given I turn off automatic copying in Settings
    When I save a new bookmark
    Then no copy is made automatically
    But I can still choose "Save a copy" on that bookmark

  Scenario: View a preserved copy
    Given a bookmark has a preserved copy
    When I open "View copy"
    Then I see the saved snapshot, marked as a copy rather than the live page

  Scenario: PDF preserved as the PDF
    Given a bookmark's link is a PDF
    Then its preserved copy is the PDF file itself

  Scenario: Internet Archive is explicit
    When I choose "Save to Internet Archive" for a bookmark
    Then an Internet Archive link is added
    And this never happens automatically

## Assumptions
- Preserved copies are self-contained (do not depend on the live page).
- Automatic copying default on; toggle in Settings; manual copy always available.
- Internet Archive submission is always a separate manual action.
