Scenario ID: SCN-014
Title: Export all links to a take-anywhere file
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The client can export all their links to a plain file they can download and take
anywhere, so they never feel locked in the way browser folders trapped them. The
export lists each link with its title, address and labels.

## Gherkin
Feature: Export bookmarks

  Scenario: Export everything to a file
    Given the client has saved links
    When the client exports
    Then all links are presented as plain text including title, address and labels
    And the client can download them as a file

## Assumptions
- Export is plain and portable (no lock-in); exact file format TBD in build.
- Export reflects current labels and edits.
