Scenario ID: SCN-003
Title: Add several tags to a bookmark
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A person can tag a bookmark without opening its full details editor. The
bookmark offers a dedicated action for adding tags. Several comma-separated
tags can be added at once, and the saved tags appear as labels on the bookmark.

## Gherkin
Feature: Organizing bookmarks with tags

  Scenario: Add several tags from the bookmark list
    Given a saved bookmark has no tags
    When the person chooses to add tags from that bookmark
    And enters several tag names separated by commas
    And confirms the tags
    Then each tag appears as a label on that bookmark
    And the full bookmark details editor is not opened

## Assumptions
- A dedicated add-tags action is displayed on each bookmark.
- Commas separate multiple tag names entered together.
- Tags are visibly represented as labels on the bookmark.
