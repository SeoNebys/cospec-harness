Scenario ID: SCN-017
Title: Restore an archived bookmark to the active collection
Type: Edge Case
Approval status: approved
Approval session: SESSION-017
Approval cycle: 1

## Approved behaviour

The client restores an archived bookmark through its More actions menu. It
leaves the Archive view and returns to the active collection with its title,
description, originating site, and labels intact. Restoring it does not add it
to the reading pile.

## Gherkin

Feature: Archiving bookmarks

  Scenario: Restore an archived bookmark
    Given an archived bookmark has a title, description, originating site, and labels
    When the client chooses "Restore" from its More actions menu
    Then the bookmark is no longer shown in the Archive view
    And it is shown in the active bookmark collection
    And its title, description, originating site, and labels are unchanged
    And it is not marked for later

## Assumptions

- Restore is an occasional action placed in the More actions menu.
- Restoring does not recover an earlier Read later mark.
