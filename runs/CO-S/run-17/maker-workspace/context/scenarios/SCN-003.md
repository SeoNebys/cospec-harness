Scenario ID: SCN-003
Title: Reuse an existing tag through typing suggestions
Type: Happy Path
Approval status: approved
Approval session: SESSION-003
Approval cycle: 1

## Approved behaviour

From a saved bookmark, the client chooses Add tag beneath the bookmark and begins typing. Matching tags used before are suggested inline and identified as existing tags. Choosing a suggestion adds that existing tag beneath the bookmark and briefly confirms the update, avoiding an accidental duplicate tag.

## Gherkin

Feature: Organize bookmarks with consistent tags

  Scenario: Add a previously used tag to a bookmark
    Given a saved bookmark does not have the existing tag "Recipes"
    And "Recipes" has been used on another bookmark before
    When the user chooses Add tag beneath the bookmark
    And types text matching "Recipes"
    Then "Recipes" is suggested as a tag used before
    When the user chooses the "Recipes" suggestion
    Then the existing "Recipes" tag appears beneath the bookmark
    And a brief confirmation is shown
    And no duplicate tag is created

## Assumptions

- Tags appear beneath each bookmark.
- Adding a tag uses an inline type-to-find interaction.
- Matching existing tags are labeled as used before.
- Example existing tags during approval were Recipes, Research, and Design.
