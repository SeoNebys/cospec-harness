Scenario ID: SCN-001
Title: Save a new web page with automatically gathered details
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Starting from an empty personal library, the user begins saving a link in a focused pop-up. They provide only the web address, and the app gathers a title, description, source icon, and preview picture. Before saving, the user can directly revise the gathered title and description; the icon and preview picture remain automatic. Saving closes the pop-up, briefly confirms success, and immediately shows the new bookmark as a visual card with its preview picture, source, title, and description.

- Saving begins in a focused pop-up over the library.
