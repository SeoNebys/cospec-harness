Scenario ID: SCN-005
Title: Pull up every link under a label
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A bar above the list shows the client's labels, each with a count of how many links it
holds, plus an "All" option (the default). Clicking a label narrows the list to just the
links carrying that label, with a clear "Showing [label]" note and an obvious way back to
"All". Clicking a label chip shown on an individual link jumps to that same pile — a
shortcut the client welcomed. Because a link can carry several labels, it appears under
each of its labels.

## Gherkin
Feature: Viewing links by label

  Scenario: Filter to one label from the bar
    Given links carrying various labels
    When I click a label in the bar
    Then only links carrying that label are shown
    And a "Showing [label]" note and a way back to All are visible

  Scenario: A multi-labelled link appears under each of its labels
    Given a link labelled both "work stuff" and "articles to read"
    When I view "work stuff" and then "articles to read"
    Then that link appears in both

  Scenario: Jump to a label from a link
    Given a link showing its labels
    When I click one of those labels
    Then the list narrows to that label

## Assumptions

  recorded for later (see non-functional backlog and deferred ideas).
