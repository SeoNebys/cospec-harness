Scenario ID: SCN-012
Title: Distinguish zero search results from an unfinished expression
Type: Edge Case
Approval status: approved
Approval session: SESSION-012
Approval cycle: 1

## Approved behaviour
A complete search with no matching bookmarks replaces the list with a calm “No matching bookmarks” state while preserving the entered search so it can be changed or cleared. An unfinished explicit combination does not claim there are no matches; it instead asks the client to finish the combination and waits for more input.

## Gherkin
Feature: Search feedback states

  Scenario: Show that a complete search has no matches
    Given the client has entered a complete valid search
    And no bookmark satisfies it
    Then the collection is replaced by a calm no-matching-bookmarks state
    And the entered search remains available to change or clear

  Scenario: Wait for an unfinished combination
    Given the client is typing an explicit grouped search
    And the expression is not yet complete
    Then no no-matches claim is shown
    And guidance asks the client to finish the combination
    And the partial search remains available to continue typing

## Assumptions
- The distinction is evaluated live as the client types.
- A syntactically complete search with zero results is different from an expression that cannot yet be evaluated.
