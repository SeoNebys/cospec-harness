Scenario ID: SCN-009
Title: Sort the current bookmark results
Type: Happy Path
Approval status: approved
Approval session: SESSION-009
Approval cycle: 1

## Approved behaviour
A compact sort dropdown remains available for the current collection or search results. Recently added is the default. The person can switch to title order, which alphabetizes the currently displayed results. The chosen order applies to whatever result set the person is viewing. A compact dropdown is preferred over always-visible sort buttons.

## Gherkin
Feature: Sort bookmark results

  Scenario: Default current results to recently added order
    Given bookmark results are visible
    Then the sort control shows "Recently added"
    And the current results are ordered by when they were added, newest first

  Scenario: Sort current results by title
    Given bookmark results are visible
    When the person changes the sort order to "Title A–Z"
    Then the currently displayed results are ordered alphabetically by title

## Assumptions
- Date sorting is newest first.
- Title sorting is ascending.
- The sort control is a compact dropdown.
