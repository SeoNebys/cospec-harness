Scenario ID: SCN-016
Title: Preserve saved details when the webpage changes or disappears
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Once a bookmark is saved, its title, description, personal note, and labels remain exactly as the user left them. Later changes to the webpage do not silently overwrite saved details, and the saved details remain available even if the webpage disappears.

## Gherkin
Feature: Preserving saved bookmarks

  Scenario: The webpage changes after saving
    Given a bookmark has saved details and user-authored changes
    When the webpage later changes its title or description
    Then the saved title and description remain unchanged
    And the personal note and labels remain unchanged

  Scenario: The webpage disappears after saving
    Given a bookmark has a saved title, description, personal note, and labels
    When the webpage is no longer available
    Then the bookmark remains in the collection
    And its saved title, description, personal note, and labels remain available

## Assumptions
- Page details are captured when the bookmark is saved and are not refreshed automatically later.
- External page availability does not control retention of saved bookmark details.
