Scenario ID: SCN-004
Title: Filter the library by one tag
Type: Happy Path
Approval status: approved
Approval session: SESSION-004
Approval cycle: 1

## Approved behaviour
A persistent list of all previously used tags appears beside the bookmark list, with a bookmark count for each tag. Selecting one tag narrows the list to bookmarks carrying that tag. The person can repeatedly move between tags, selecting one at a time, while the separate broad-search field remains available.

## Gherkin
Feature: Filtering bookmarks by tag

  Scenario: Show bookmarks carrying a selected tag
    Given the library contains bookmarks with several tags
    And each used tag is shown beside the bookmark list with its bookmark count
    When the person selects one tag
    Then only bookmarks carrying that tag are shown
    And the selected tag remains visibly selected

  Scenario: Move from one tag filter to another
    Given one tag is currently selected
    When the person selects a different tag from the persistent tag list
    Then the bookmark list shows bookmarks carrying the newly selected tag
    And only the newly selected tag remains selected

## Assumptions
- One tag filter is active at a time.
- The tag list stays in place beside the bookmark list while results change.
- Tag counts describe how many bookmarks carry each tag.
- Broad search and tag filtering are separate ways to find bookmarks.
