Scenario ID: SCN-004
Title: Write and edit a personal note on a saved link
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

Each saved link can carry the user's own free-text note. When a link has no
note, the card shows a subtle "＋ Add a note" affordance; clicking it opens an
inline text area where the user types a note and presses "Save note" (or
"Cancel"). Once saved, the note is displayed on the card as a distinct,
highlighted block. Clicking the note reopens it for editing; saving an empty
note clears it back to the "Add a note" state. The note is the user's own words
(distinct from the auto-filled description).

## Gherkin
Feature: Notes on a link

  Scenario: Add a note to a link
    Given a saved link with no note
    When the user opens the note editor, types a note, and saves
    Then the note is shown on that link's card

  Scenario: Edit an existing note
    Given a link that has a note
    When the user opens the note and changes the text and saves
    Then the updated note is shown

  Scenario: Clear a note
    Given a link that has a note
    When the user opens the note, removes all text, and saves
    Then the link shows the "add a note" affordance again

## Assumptions
- One free-text note per link (not multiple notes).
- The note is separate from the auto-filled page description.
- Notes are plain text.
