Scenario ID: SCN-011
Title: Add an immediately visible and searchable personal note
Type: Happy Path
Approval status: approved
Approval session: SESSION-011
Approval cycle: 1

## Approved behaviour

A dedicated Add note action on the bookmark opens an inline personal note field without mixing it into title and description correction. Saving returns to the bookmark with the note visible beneath it, changes the action to Edit note, briefly confirms that the note is searchable, and makes its content available to search immediately. The note can be edited later through the same action.

## Gherkin

Feature: Add personal context to bookmarks

  Scenario: Add a personal note to a bookmark
    Given a saved bookmark has no personal note
    When the user chooses Add note on the bookmark
    And enters a note
    And saves it
    Then the bookmark returns to its usual display
    And the note is visible beneath the bookmark
    And the action is labeled Edit note
    And a brief confirmation says the note is searchable
    And the note is immediately included in bookmark search

  Scenario: Reopen a saved personal note for editing
    Given a bookmark has a personal note
    When the user chooses Edit note
    Then the existing note opens inline for editing

## Assumptions

- Notes use a dedicated Add note or Edit note action rather than the broader Edit details action.
- Saved notes are visible beneath their bookmarks.
- Saved note changes are searchable immediately.
