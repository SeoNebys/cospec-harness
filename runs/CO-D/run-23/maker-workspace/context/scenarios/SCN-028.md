Scenario ID: SCN-028
Title: Keep the preserved version separate from the changing live page
Type: Edge Case
Approval status: approved
Approval session: SESSION-028
Approval cycle: 1

## Approved behaviour
A saved page copy is an immutable snapshot of the version captured on its saved date. It is never silently refreshed or overwritten when the original website changes. View saved copy always opens that preserved historical version, while selecting the bookmark title opens the live website as it exists now, allowing the person to compare both without losing what they originally kept.

## Gherkin
Feature: Preserve saved content over time

  Scenario: The live website changes after a copy was saved
    Given a page was saved with a preserved copy on a particular date
    And the live website has since changed
    When the person chooses View saved copy
    Then the exact version captured on the saved date is shown
    And it has not been silently refreshed or overwritten
    When the person selects the bookmark title
    Then the current live website opens

## Assumptions
- Preserved copies are immutable after successful capture.
- The saved date identifies when the preserved version was captured.
