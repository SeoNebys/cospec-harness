Scenario ID: SCN-016
Title: Order the visible bookmark collection
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The library shows newest bookmarks first by default. A compact “Order by” control immediately above the cards can switch the visible collection to title order from A to Z. Ordering applies within the current search and tag filters: filtering decides which bookmarks are visible, while ordering decides their arrangement. The client selected the compact control above the cards after comparing it with ordering choices in the sidebar.

## Gherkin
Feature: Order bookmarks

  Scenario: Show newest bookmarks first by default
    Given the library contains bookmarks saved at different times
    When the user opens the library
    Then the bookmarks are ordered from newest to oldest

  Scenario: Order bookmarks by title
    Given multiple bookmarks are visible
    When the user selects "Title A–Z" from the compact order control above the cards
    Then the visible bookmarks are arranged alphabetically by title

  Scenario: Order filtered bookmarks
    Given a search or tag filter narrows the visible bookmarks
    When the user changes the order
    Then only the matching bookmarks remain visible
    And those matching bookmarks are arranged in the selected order

## Assumptions
- Newest first is the default order.
- The approved ordering control is a compact selector above the cards, not a sidebar section.
- Title order is ascending from A to Z.
