Scenario ID: SCN-007
Title: Incomplete or oversized entries display gracefully
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
- A link saved with a blank title shows its web address as its display name.
- A link saved with a blank topic is grouped under a heading called
  "Uncategorized" (client refinement, replacing the earlier "Untitled topic").
- A link with a very long title and/or very long address wraps within its row and
  remains readable without breaking the layout.
The client confirmed the address-as-name fallback and the readable wrapping, and
requested the "Uncategorized" label for missing topics.

## Gherkin
Feature: Graceful display of imperfect entries

  Scenario: Blank title falls back to the address
    Given a link is saved with an address but no title
    When the list is shown
    Then the link's display name is its web address

  Scenario: Blank topic groups under Uncategorized
    Given a link is saved with no topic
    When the list is shown
    Then the link appears under an "Uncategorized" topic heading
    And an "Uncategorized" topic button is available

  Scenario: Very long text wraps
    Given a link with a very long title and address
    When the list is shown
    Then the text wraps within the row and remains readable

## Assumptions
- "Uncategorized" is treated as a normal topic for grouping and filtering.
