Scenario ID: SCN-012
Title: Track reading status (unread / read)
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Each bookmark has a reading status: unread or read. Unread bookmarks show a small
dot; each card has a control to toggle between "Mark read" and "Mark unread". The
list "Show" filter offers All / Unread only / Read only, and combines with search
and sorting. Marking an item read while viewing "Unread only" removes it from that
view immediately. The save form has a "Read later (leave unread)" checkbox that is
checked by default; unchecking it saves the bookmark as already read. New links
are therefore unread by default.

## Gherkin
Feature: Reading status

  Scenario: New link is unread by default
    When the user saves a link with "Read later" left checked
    Then the bookmark is unread and shows the unread dot

  Scenario: Save a reference as already read
    When the user unchecks "Read later" before saving
    Then the bookmark is saved as read with no unread dot

  Scenario: Toggle read status
    When the user clicks "Mark read" on an unread bookmark
    Then it becomes read and the control reads "Mark unread"

  Scenario: Unread-only view updates on marking read
    Given the list is filtered to "Unread only"
    When the user marks one of them read
    Then it disappears from the view immediately

## Assumptions
- Default reading status for new links is unread ("read later").
- The Show filter combines with search and sort.
