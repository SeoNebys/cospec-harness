Scenario ID: SCN-021
Title: Show the real site icon (with fallback) and a preview image where available
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When collecting page details, the app uses the site's real favicon for quick
recognition; if it cannot be loaded, it falls back gracefully to the coloured
letter tile. A page preview image (og:image) is shown as a thumbnail on the right
of the item when one is available; when no preview exists, the thumbnail is simply
omitted (no placeholder). The preview's right-side placement and size add context
without overpowering the title and description.

## Gherkin
Feature: Favicon and preview image

  Scenario: Real favicon with graceful fallback
    Given a saved bookmark
    When the site's real icon can be loaded
    Then it is shown
    And when it cannot be loaded the coloured letter tile is shown instead

  Scenario: Preview shown only where available
    Given a bookmark whose page has a preview image
    Then a preview thumbnail is shown on the right of the item
    And when no preview image exists no thumbnail (and no placeholder) is shown

## Assumptions
- EXTERNAL-FETCH DEPENDENCY: fetching the real favicon and the og:image preview is
  done server-side/externally in a real build. The prototype attempts the real
  favicon with fallback and SIMULATES the preview thumbnail; a real preview fetch
  is not claimed. Validation is a Phase 2 concern.
