# Non-functional backlog

## NFR-001 — Calm, scannable interface

The client repeatedly preferred a clean, low-clutter collection: compact cards, always-visible organization, labeled stateful actions, and infrequent actions kept in a secondary menu. Preserve clear hierarchy and avoid controls that compete with bookmark content.

## NFR-002 — Immediate finding feedback

Search and tag narrowing should feel immediate while typing and selecting, including in collections with hundreds of bookmarks. Keep the applied search and tag context visibly understandable.

## NFR-003 — Clear protection against accidental loss

State changes should be explicit and reassuring. Distinguish filtering, Read later removal, archiving, restoration, and validation from deletion; keep confirmations concise and make reversible outcomes clear.
