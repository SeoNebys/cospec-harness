Scenario ID: SCN-004
Title: Organise with tags — add with suggestions, narrow by matching all
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When saving or editing a bookmark, the client adds tags by typing a word and
pressing Enter (or comma), forming removable chips. As they type, existing tags
are suggested beneath the field so the same spelling is reused; arrow keys move
through suggestions, and a "Create new tag" option appears when the typed tag is
genuinely new. Saved bookmarks show their tags as chips. Tag chips also appear
under the search box with counts. Selecting one or more tag chips narrows the
list to bookmarks that carry ALL selected tags; a clear control resets the
selection. Selecting a tag chip on an item toggles it as a filter too.

## Gherkin
Feature: Tagging and tag filtering

  Scenario: Add a tag with suggestion of existing tags
    Given the client is adding or editing a bookmark
    When the client types the beginning of a tag name
    Then existing matching tags are suggested
    And the client can pick a suggestion or create a new tag
    And chosen tags appear as removable chips

  Scenario: Narrow the list by matching all selected tags
    Given bookmarks carry various tags
    When the client selects one or more tag chips
    Then only bookmarks carrying all of the selected tags are shown
    And a clear control resets the tag selection

## Assumptions
- Tags are lowercased for consistent reuse.
- Tag entry is chip-style (type + Enter); client confirmed a toolbar-free,
  suggestion-assisted input.
