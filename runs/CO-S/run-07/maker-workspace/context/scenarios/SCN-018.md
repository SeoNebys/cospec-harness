Scenario ID: SCN-018
Title: Protect the saved bookmark from invalid edits
Type: Error Case
Approval status: approved
Approval session: SESSION-018
Approval cycle: 1

## Approved behaviour
If an edit leaves the title empty or replaces the website address with an unusable value, saving is blocked. The attempted values remain visible, a clear message appears beside each affected field, and the previously saved bookmark remains unchanged until all required edits are valid.

## Gherkin
Feature: Validate edits without damaging a saved bookmark

  Scenario: Block invalid bookmark edits
    Given a valid bookmark is saved in the library
    And the user is editing it inline
    When the user clears the title
    And replaces the website address with an unusable value
    And tries to save the changes
    Then the edit form remains open with the attempted values
    And a title message appears beside the title field
    And an address message appears beside the website address field
    And the previously saved bookmark remains unchanged

## Assumptions
- The same title and address rules apply when creating and editing bookmarks.
- Optional descriptions and an empty tag set do not block saving.
