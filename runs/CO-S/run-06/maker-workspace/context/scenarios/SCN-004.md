Scenario ID: SCN-004
Title: Archive links out of everyday views while keeping them searchable and restorable
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A bookmark can be archived to keep it without cluttering the everyday views.
An archived bookmark disappears entirely from the All view and the Read later
view, and lives only in a separate Archive tab/view. Within the Archive view it
remains fully searchable and tag-filterable, and each archived bookmark offers a
"Restore to All" action that returns it to the everyday views. Nothing is lost
by archiving.

## Gherkin
Feature: Archive

  Scenario: Archive a bookmark
    Given a saved bookmark shown in the All view
    When the user archives it
    Then it no longer appears in the All view or the Read later view
    And it appears in the Archive view

  Scenario: Search within the Archive view
    Given archived bookmarks
    When the user searches or clicks a tag while on the Archive view
    Then only matching archived bookmarks are shown

  Scenario: Restore an archived bookmark
    Given an archived bookmark
    When the user restores it
    Then it returns to the All view
    And it no longer appears in the Archive view

## Assumptions
- Archiving is reversible via Restore; archiving is not deletion.
- Restoring returns the bookmark to All; its prior Read later flag state is
  retained (a restored bookmark keeps whatever Read later state it had).
- Archived bookmarks are excluded from All and Read later regardless of tags.
