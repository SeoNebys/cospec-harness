Scenario ID: SCN-001
Title: Quickly save a link, review the auto-filled details in place, and confirm
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
From the main screen there is an always-visible save area at the top. The client
pastes a link and presses Add. The app looks up the page and, in the same
expanding panel, fills in a title and (when available) the site's description
automatically, while the address stays visible. The client can adjust the title
and description and optionally write their own note before confirming. Pressing
Save bookmark commits it; the new bookmark appears at the top of the list and the
save area clears, ready for the next link. Cancelling discards the draft without
saving. This single-panel review keeps saving quick while allowing correction
before the save is confirmed.

## Gherkin
Feature: Quick save with in-place review before confirming

  Scenario: Save a link after reviewing auto-filled details in place
    Given the save area is empty at the top of the screen
    When the client enters a link and presses Add
    Then the app fetches the page and fills the title and site description automatically in the same panel
    And the address remains visible during review
    When the client optionally adjusts the title or description and optionally writes a note
    And the client presses Save bookmark
    Then a bookmark is created with those details
    And it appears at the top of the list
    And the save area is cleared and ready for the next link

  Scenario: Cancel a draft before saving
    Given the client has pressed Add and the draft panel is open
    When the client presses Cancel
    Then no bookmark is created
    And the save area returns to its empty state

## Assumptions
- The address is normalised (a scheme is added if omitted).
- Automatic lookup succeeds in the happy path; failure handling is an edge case
  to explore later.
- Review-before-confirm uses a single expanding panel (client chose Option C over
  an inline draft card and a pop-up dialog).
