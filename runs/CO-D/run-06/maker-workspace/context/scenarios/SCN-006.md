Scenario ID: SCN-006
Title: Open a saved bookmark — click the card to visit the page, pencil to edit it
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Visiting the saved page is the everyday action; editing is the occasional one, and
the interface reflects that split.
- Clicking anywhere on a bookmark card (or its title) opens the actual saved web
  page (in the real app, in a new tab). A click means "go", never "edit".
- Each card has a small, unobtrusive edit (pencil) button. Only the pencil opens the
  editor; clicking it does not also trigger a visit.
- The editor lets the client change the Title, Description, My notes, and Labels of
  an already-saved bookmark and Save the changes; the card updates to reflect them.
  Labels are added/removed as pills (same labeling behaviour as SCN-002).

## Gherkin
Feature: Visiting and editing a saved bookmark

  Scenario: Clicking a bookmark visits its page
    Given a saved bookmark
    When the client clicks the card (not the pencil)
    Then the bookmark's web page is opened

  Scenario: Editing is behind the pencil
    Given a saved bookmark
    When the client clicks the card's edit (pencil) button
    Then the bookmark editor opens
    And the page is not visited

  Scenario: Edit and save changes to a saved bookmark
    Given the editor is open for a bookmark
    When the client changes the title, description, note, or labels
    And saves
    Then the bookmark reflects the changes

## Assumptions
- Visiting opens the page in a new tab (prototype simulated the visit with a
  confirmation toast because prototype links are not live — reason logged here).
- The edit affordance is a per-card pencil button; only it opens the editor.
