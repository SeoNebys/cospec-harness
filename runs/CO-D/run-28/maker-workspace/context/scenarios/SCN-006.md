Scenario ID: SCN-006
Title: Mark a bookmark to read later and view the reading list
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Each bookmark has a "read later" mark, distinct from tags, toggled on the item
(☆ Read later / ★ To read). A "To read" view lists only the marked, non-archived
bookmarks. Toggling the mark off removes it from that view. The view tabs show
counts.

## Gherkin
Feature: Read later

  Scenario: Mark a bookmark to read later
    Given a saved bookmark
    When the client toggles its read-later mark on
    Then it is included in the To read view

  Scenario: The To read view shows only marked, non-archived bookmarks
    Given some bookmarks are marked to read later
    When the client opens the To read view
    Then only marked, non-archived bookmarks are shown

  Scenario: Unmark a read-later bookmark
    Given a bookmark is marked to read later
    When the client toggles the mark off
    Then it no longer appears in the To read view

## Assumptions
- Read-later is a dedicated per-bookmark mark, not a tag (client confirmed).
