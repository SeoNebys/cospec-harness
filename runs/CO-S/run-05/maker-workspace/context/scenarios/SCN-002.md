Scenario ID: SCN-002
Title: Add a visible label directly to a bookmark
Type: Happy Path
Approval status: approved
Approval session: SESSION-002
Approval cycle: 1

## Approved behaviour

The client adds a label directly from a bookmark card by choosing to add a
label, typing its text, and pressing Enter. The new label remains visible on
the card, alongside a clear way to add another label.

## Gherkin

Feature: Organizing bookmarks with labels

  Scenario: Add a label inline
    Given a saved bookmark is visible in the collection
    When the client adds the label "learning" directly on its card
    Then the "learning" label is shown on that bookmark card
    And a direct way to add another label remains available

## Assumptions

- Labels are displayed on bookmark cards.
- Adding a label uses an inline text field and Enter rather than a separate edit window.
- A bookmark can have more than one label.
