Scenario ID: SCN-012
Title: Exclude a label from search results
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A person can use NOT with a label to exclude bookmarks carrying that label while retaining bookmarks that match the rest of the query. Results explain the exclusion used.

## Gherkin
Feature: Precise bookmark search

  Scenario: Exclude bookmarks carrying a label
    Given the collection contains pasta bookmarks with and without the label "Weekend"
    When the person searches for "pasta NOT #weekend"
    Then only pasta bookmarks without the "Weekend" label appear
    And the results explain that "Weekend" was excluded

## Assumptions
- AND, OR, and NOT are recognized as search operators without regard to capitalization.
- NOT applies to the following term, label, or parenthesized group.
