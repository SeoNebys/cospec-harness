Title: Reusable live collections defined by search text plus included/excluded tags
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

- A collection is a saved, named search made of three parts:
  - Free-text search.
  - Included tags — a bookmark must have ALL of them.
  - Excluded tags — a bookmark must have NONE of them.
- The tag fields use the same as-you-type suggestions from previously-used tags,
  so collection definitions stay consistent with existing tag names.
- Saved collections appear in a Collections list; clicking one re-applies its
  definition. Saving over the same name updates that collection.
- Collections are LIVE (dynamic): they always show whatever currently matches, and
  update automatically as bookmarks are added, changed, or removed — not a frozen
  snapshot of what matched when saved.
- Status (To read / Finished / All) and sort order are NOT part of a collection.
  After opening a collection the user can switch status view and change the sort
  order; the user's remembered default sort (SCN-010) is applied initially.
- Need for "any of these tags" is covered by the existing search query language
  (SCN-003), not a separate collection field.

## Gherkin

Feature: Saved collections

  Scenario: Define and save a collection
    Given the user sets search text, included tags, and excluded tags
    When the user names it and saves it as a collection
    Then it appears in the Collections list

  Scenario: Open a collection applies its definition live
    Given a saved collection
    When the user opens it
    Then the current bookmarks matching (text AND all included tags AND no excluded tags) are shown
    And the result reflects later additions/changes automatically

  Scenario: Status and sort are outside the collection
    Given an opened collection
    Then the user's default sort order is applied initially
    And the user can switch To read / Finished / All and change the sort order
    And those choices are not stored as part of the collection

## Assumptions
- Included tags = AND; excluded tags = NONE; free text as in normal search.
- Managing collections (rename/delete) follows the same list; save-over updates.
