Scenario ID: SCN-021
Title: Reject text that is not a usable web address
Type: Error Case
Approval status: approved
Approval session: SESSION-021
Approval cycle: 1

## Approved behaviour
If the entered text is not a usable web address, the app does not create a broken bookmark or change the library. It shows a gentle inline explanation and a concrete example of a complete address so the person can correct the entry.

## Gherkin
Feature: Validate a bookmark address

  Scenario: Try to save text that is not a web address
    Given the person has entered text without a usable web destination
    When they try to save it
    Then no bookmark is created
    And the library remains unchanged
    And an inline explanation identifies the problem
    And the explanation includes an example of a complete web address

## Assumptions
- Invalid address text is distinguishable from a valid address whose page is temporarily unreachable.
