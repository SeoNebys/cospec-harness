Scenario ID: SCN-019
Title: Keep personal display and ordering defaults
Type: Happy Path
Approval status: approved
Approval session: SESSION-019
Approval cycle: 1

## Approved behaviour
A person can save personal defaults for the number of bookmarks shown per page, bookmark-card text size, and the order used whenever the library opens. Saving returns to the library with those choices applied, and they persist for future visits. Choosing a different order from the ordinary ordering menu only rearranges the current view and does not replace the saved default.

## Gherkin
Feature: Personal library settings

  Scenario: Save comfort and display defaults
    Given the person is viewing Settings
    When they choose 50 bookmarks per page
    And choose Large text
    And choose Name A–Z as the default order
    And save the settings
    Then the library returns in name order
    And bookmark cards use the larger text size
    And the library reports 50 bookmarks per page
    And those choices persist for future visits

  Scenario: Temporarily reorder without changing the default
    Given Name A–Z is the saved default order
    When the person chooses a different order from the library's ordering menu
    Then the current visible list uses that order
    And Name A–Z remains the saved default for the next visit

## Assumptions
- Settings are personal to the app's single user.
- Available page sizes include 25, 50, and 100 bookmarks.
- Available text sizes include Small, Comfortable, and Large.
