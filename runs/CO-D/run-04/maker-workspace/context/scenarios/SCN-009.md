Scenario ID: SCN-009
Title: Permanently delete a bookmark
Type: Happy Path
Approval status: approved
Approval session: SESSION-009
Approval cycle: 1

## Approved behaviour
Permanent deletion is separate from archiving. It is available inside the
bookmark's Edit view and requires an explicit confirmation warning that the
action cannot be undone. Confirming removes the bookmark from the collection
completely and does not place it in Archive.

## Gherkin
Feature: Permanently remove bookmarks

  Scenario: Permanently delete a bookmark
    Given a bookmark is open for editing
    When the person chooses to delete it
    Then a confirmation explains that deletion cannot be undone
    When the person confirms permanent deletion
    Then the bookmark is removed from the collection
    And the bookmark is not added to Archive

## Assumptions
- Permanent deletion is available from Edit rather than as a row-level action.
- Deletion always requires a separate confirmation.
- There is no restore or undo after confirmed deletion.
