Scenario ID: SCN-004
Title: Return to an existing bookmark when the same address is saved again
Type: Edge Case
Approval status: approved
Approval session: SESSION-004
Approval cycle: 1

## Approved behaviour

When the client attempts to add the exact web address of a bookmark already in the collection, the app does not create another card and does not show a warning that must be dismissed. It quietly opens the existing bookmark's editor. Saving there updates the existing card, and the collection count remains unchanged.

## Gherkin

Feature: Preventing duplicate bookmarks

  Scenario: Save an address that is already in the collection
    Given one bookmark has already been saved for a web address
    When the user attempts to add that exact web address again
    Then no additional bookmark is created
    And the existing bookmark's editor opens without a separate warning
    When the user adjusts the title and saves
    Then the existing card immediately shows the adjusted title
    And the collection still contains one bookmark

## Assumptions

- This scenario compares exact web addresses.
- The existing bookmark can be updated using the already-approved editing behaviour.
