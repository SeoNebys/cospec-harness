Scenario ID: SCN-017
Title: Recover from a search with no matches
Type: Edge Case
Approval status: approved
Approval session: SESSION-017
Approval cycle: 1

## Approved behaviour
When a search matches no bookmarks, a dedicated state says there are no matches and reassures the person that the collection still exists. The entered search remains available to revise. Clearing it restores all bookmarks.

## Gherkin
Feature: Recover from an empty search result

  Scenario: Search returns no bookmarks
    Given the collection contains bookmarks but none mention "saturn"
    When the person searches for "saturn"
    Then no bookmark cards are shown
    And the screen says there are no matching bookmarks
    And the screen reassures the person that the collection still exists
    And "saturn" remains in the search box

  Scenario: Clear a search with no results
    Given a search has no matching bookmarks
    When the person clears the search
    Then all bookmarks are shown again

## Assumptions
- An empty result is visually distinct from an empty collection.
