# Business goal statement

## Cycle 1 — confirmed

### The client's words (verbatim)

> Right now, useful links disappear into a long, messy list, and I often can't
> remember enough about them to find them again. I'd like one place where I can
> save links, organise them by topic, and later search or filter them easily.
>
> Finding the right link again matters most, although saving it should still be
> quick enough that I'll actually use the app.
>
> Yes, that captures it. I picture it as a web app I can use in my browser,
> ideally from different devices.

### Goal summary

One place to save links, organise them by topic, and reliably get back to the
right one later through search and filtering.

**Success test:** "I can always find the link I saved, even weeks later."

### Priority

- Primary: finding the right link again (search / filter / organise by topic)
- Secondary: saving must stay quick and low-effort, so the app actually gets used

### Interface form

Web app, used in the browser, accessed from different devices.

### Notes for later exploration

- "from different devices" implies access from more than one place — to be
  explored (may touch accounts / sync). Recorded, not yet a scenario.
