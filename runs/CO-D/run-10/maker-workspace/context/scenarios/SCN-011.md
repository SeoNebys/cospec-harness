Scenario ID: SCN-011
Title: Recover clearly from a search with no matches
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When live search finds no bookmarks, the library shows an explicit No bookmarks found state, repeats the user's search words, explains that nothing matched, and offers Clear search. Clearing restores the full library, so a blank result cannot be mistaken for a broken or vanished library.

## Gherkin
Feature: Empty search results

  Scenario: Search has no matches
    Given the library contains bookmarks
    When the user enters search words that match none of them
    Then no bookmark cards are shown
    And the app says that no bookmarks matched the entered words
    And offers an action to clear the search

  Scenario: Clear a search with no matches
    Given search currently has no matches
    When the user clears the search
    Then the search words are removed
    And the full library returns

## Assumptions
- The entered search words are echoed in the empty state.
