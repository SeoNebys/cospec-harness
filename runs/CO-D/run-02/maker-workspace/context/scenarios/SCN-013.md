Scenario ID: SCN-013
Title: A personal note, separate from the page description, with simple formatting
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

Each bookmark has the client's own **note**, kept separate from the page's
auto-collected description. In the save/edit panel the description is labelled as
coming from the page, and "Your note" is a distinct field. The note supports
simple formatting — bold, italic, bullet lists, and links — entered via
formatting **buttons** (select text, press Bold / Italic / • List); the stored
note uses the same simple markup underneath, so typing the marks also works. A
live preview shows the formatted result while editing.

On the card, the note renders (not raw marks) as its own subtly-outlined block
positioned beneath the page description and above the tags, so it is easy to scan
and clearly the client's own content.

## Gherkin

Feature: Personal note

  Scenario: Note is separate from the page description
    Given the save or edit panel
    Then the page's description and my own note are separate fields

  Scenario: Format a note with the buttons
    Given the note field
    When I select text and use the Bold, Italic, or List buttons
    Then the note gains that formatting, shown in a live preview

  Scenario: Rendered note on the card
    Given a bookmark whose note uses bold, italic, bullets, or links
    Then the card shows the note rendered as a distinct block beneath the
         description and above the tags

## Assumptions
- "Simple formatting" is limited to bold, italic, bullet lists, and links.
- Links in notes must start with http/https to render as links.
