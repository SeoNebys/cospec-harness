Scenario ID: SCN-020
Title: Permanently delete a bookmark after explicit confirmation
Type: Happy Path
Approval status: approved
Approval session: SESSION-020
Approval cycle: 1

## Approved behaviour
Every bookmark has a clear Delete action. Selecting it does not immediately remove anything; a confirmation names the bookmark and explains that permanent deletion removes the bookmark, personal notes, Read later membership, and saved readable copy. Only an explicit "Delete permanently" action completes removal. Deletion affects only the client's stored material and never the original website.

## Gherkin
Feature: Permanently delete bookmarks

  Scenario: Explain the full effect before permanent deletion
    Given a bookmark has notes, Read later membership, and a saved readable copy
    When the client selects Delete
    Then a confirmation explains that all of those stored items will be removed
    And nothing has been deleted yet

  Scenario: Confirm permanent deletion
    Given the permanent-delete confirmation is open
    When the client selects "Delete permanently"
    Then the bookmark is removed from the library
    And its personal notes are removed
    And its Read later membership is removed
    And its saved readable copy is removed
    But the original website is unaffected

## Assumptions
- Permanent deletion requires confirmation before any data is removed.
- Deletion applies to all client-owned data attached to that bookmark.
- The confirmation safeguard is preferred to a time-limited undo notification.
