Scenario ID: SCN-013
Title: Recover from a search with no results
Type: Edge Case
Approval status: approved
Approval session: SESSION-013
Approval cycle: 1

## Approved behaviour
When a search has no matching bookmarks, the collection shows an explicit
no-results state instead of a blank area. The message suggests changing or
clearing the search, and a one-click clear control restores the full collection.

## Gherkin
Feature: Search the bookmark collection

  Scenario: No bookmarks match a search
    Given bookmarks exist in the collection
    When the person enters a search with no matches
    Then no bookmark items are shown
    And an explicit no-results message is shown
    And the person is prompted to change or clear the search
    When the person clears the search
    Then the full collection is shown again

## Assumptions
- The clear-search control remains visible in the search box while a query is present.
- A zero-result search is distinct from an entirely empty collection.
