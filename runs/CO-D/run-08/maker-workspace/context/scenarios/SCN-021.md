Scenario ID: SCN-021
Title: Preserve saved bookmark details when the source changes
Type: Edge Case
Approval status: approved
Approval session: SESSION-021
Approval cycle: 1

## Approved behaviour
After a bookmark is saved, changes to or disappearance of the outside page never silently replace or remove the stored title, description, labels, note, or other saved information. Details captured automatically and details edited by the person remain stable unless the person chooses to change them.

## Gherkin
Feature: Preserve captured bookmark information

  Scenario: The outside page changes after saving
    Given a bookmark has saved title, description, labels, and a personal note
    When the outside page later changes its title or description
    Then the bookmark's saved information remains unchanged

  Scenario: The outside page disappears after saving
    Given a bookmark has saved details and personal organization
    When the outside page becomes unavailable
    Then the bookmark's title, description, labels, note, and address remain saved

## Assumptions
- Outside content never silently overwrites stored bookmark information.
- Only an explicit person-initiated edit changes saved details.
