Scenario ID: SCN-010
Title: Preserve bookmarks and collections between visits
Type: Edge Case
Approval status: approved
Approval session: SESSION-010
Approval cycle: 1

## Approved behaviour
When the user closes the browser and returns to the app later on the same computer, saved bookmarks and named collections remain available. Temporary interaction state—including search text, selected checkboxes, and a partially open form—does not need to remain. The collection does not need to follow the user to a different computer in this cycle.

## Gherkin
Feature: Returning to saved bookmarks later

  Scenario: Preserve saved content for a later visit on the same computer
    Given the user has saved bookmarks and created named collections
    When the user closes the browser
    And returns to the app later on the same computer
    Then the saved bookmarks are still available
    And the named collections and their membership are still available

  Scenario: Reset temporary interaction state between visits
    Given the user has typed a search, selected bookmark checkboxes, or left a form open
    When the user closes the browser
    And returns to the app later
    Then the temporary search, selections, and open form may be reset
    And the saved bookmarks and collections remain unchanged

## Assumptions
- Persistence is required for later visits on the same computer.
- Cross-computer syncing is outside this cycle.
- Temporary interface state does not need persistence.
