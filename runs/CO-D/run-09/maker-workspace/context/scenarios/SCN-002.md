Scenario ID: SCN-002
Title: Reuse previously-used labels while saving
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
While adding labels in the review panel, the app suggests labels the user has used
before as clickable chips. Clicking a suggested label adds it to the link. Labels
already added to the current link are not suggested again. This keeps the user's
labels consistent over time.

## Gherkin
Feature: Consistent labels

  Scenario: Suggest previously-used labels
    Given the user has saved links with some labels before
    When the user is adding labels in the review panel
    Then previously-used labels are shown as clickable suggestions
    And labels already added to the current link are not suggested

  Scenario: Reuse a suggested label
    Given previously-used labels are suggested
    When the user clicks a suggested label
    Then that label is added to the current link

## Assumptions
- Suggestions are drawn from the labels present on already-saved links.
