Scenario ID: SCN-004
Title: Filter bookmarks by clicking a tag
Type: Happy Path
Approval status: approved
Approval session: SESSION-004
Approval cycle: 1

## Approved behaviour
A person can click a tag chip on a bookmark to narrow the list to every bookmark carrying that exact tag. The filtered list clearly identifies the active tag and offers a way to clear the filter and return to all bookmarks.

## Gherkin
Feature: Filtering bookmarks by tag

  Scenario: Open an exact tag filter from a bookmark
    Given multiple bookmarks carry the tag "web design"
    When the person clicks the "web design" tag chip on a bookmark
    Then the list shows only bookmarks carrying exactly that tag
    And the app visibly identifies "web design" as the active tag filter
    And the app offers a way to clear the filter

  Scenario: Clear an active tag filter
    Given the bookmark list is filtered to one tag
    When the person clears the tag filter
    Then all bookmarks are shown again

## Assumptions
- Tag chips displayed on bookmarks are the controls for opening a tag filter.
- Tag filtering uses exact tag identity rather than a partial text match.
