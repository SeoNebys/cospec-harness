# Non-functional backlog

- The web app should not be broken when used from a phone, although it is primarily intended for a computer browser. A separate mobile app is not required.
- The client prefers the link paste box to remain visible on the collection page, avoiding an extra click when saving links repeatedly. The client described this as a small style choice rather than a major concern.
- The client prefers tag entry to stay inline on the bookmark because it feels quicker and lighter for frequent tagging; a separate dialog feels like unnecessary ceremony. The client described this as a minor preference.
- The client prefers tags to remain visibly laid out above the collection rather than hidden in a dropdown, both for faster selection and as a reminder of which tags exist. The client described this as a minor preference.
- The client mildly prefers a checkbox for the read-later flag because its checked or unchecked state is easy to read at a glance.
- The client prefers the focused read-later view to use a plainly labeled “Mark as read” action for clearing an item, because unchecking a box can feel like merely undoing a mistake. This works alongside the checkbox used to show and set flag state in the full collection; the client described the distinction as an ideal rather than a strong requirement.
- The client prefers direct bold and list controls for note formatting rather than typed formatting symbols. A live preview before saving is reassuring and should ideally accompany those controls; the client described this as a mild preference.
- The client mildly prefers a focused edit window for changing the bookmark address, title, and description together because it feels tidier and less cramped than editing in place.
- The client mildly prefers email-and-password sign-in over a delivered code because this frequently used app should not require waiting for and copying a code each time.
- The client mildly prefers loading more bookmarks into one continuous list rather than numbered pages because continuous scrolling better preserves their sense of place during casual browsing. An overall count should still communicate collection size.
