# Business goal statement

Cycle: 1
Phase confirmed in: Phase 1, Step 1 (Goal exploration)
Interface form: Web app (browser-based), comfortable on both computer and phone;
not a separate mobile app.

## Core goal (in the client's words)

> The main problem is that I save useful links and then lose track of them. I want
> one calm, searchable place where I can quickly save a link, add a little context
> or a few labels, and find it again later—even if I only remember a word or topic.
>
> I'd also like to separate things I still intend to read from things I've finished
> with, without having to delete useful links. Ideally, saving shouldn't feel like
> data entry: the app should fill in the page details for me and let me adjust them
> when needed.

## Confirmed framing

- **Primary goal:** confidently *finding a saved link again later*, even from a
  vague memory (a single word or topic).
- **Means to that end (not the point in themselves):**
  - A few labels and a little personal context per link.
  - A read status separating "still intend to read" from "finished with", while
    *keeping* useful links rather than deleting them.
- **Overall quality wanted:** calm, uncluttered, low-effort.
- **Low-effort saving:** the app fills in page details automatically; the user can
  adjust them when needed.

## Confirmation record

- Client confirmed the framing: "Finding things again is the main goal, and the
  labels and read status help keep everything manageable."
- Client confirmed interface form: "primarily as a web app I can use in a normal
  browser ... work comfortably on both a computer and a phone, but it doesn't need
  to be a separate mobile app."
