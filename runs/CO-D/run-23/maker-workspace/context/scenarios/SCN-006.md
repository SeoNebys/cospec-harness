Scenario ID: SCN-006
Title: Preserve and reopen the original PDF file
Type: Edge Case
Approval status: approved
Approval session: SESSION-006
Approval cycle: 1

## Approved behaviour
When a saved address points to a PDF, the app preserves the actual PDF file rather than converting it into a cleaned-up reading copy. The bookmark card clearly identifies it as a PDF and provides an action to open the saved document. The original document opens in a PDF viewer with its real filename and can be downloaded, remaining available even if the source link later stops working.

## Gherkin
Feature: Preserve saved content

  Scenario: Open a preserved PDF after its source disappears
    Given a bookmark was saved from an address pointing to a PDF
    And the app preserved the original PDF file
    And the source address is no longer available
    When the person chooses to open the saved PDF from its bookmark card
    Then the original PDF document opens in a PDF viewer
    And the viewer shows the real filename
    And the preserved PDF can be downloaded

## Assumptions
- The PDF file itself is preserved automatically.
- PDF bookmark cards are visually identified as PDFs.
- PDF files retain their original filename.
