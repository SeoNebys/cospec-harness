Scenario ID: SCN-028
Title: Protect hand-written details when an address changes
Type: Edge Case
Approval status: approved
Approval session: SESSION-028
Approval cycle: 1

## Approved behaviour
When changing a bookmark address would replace a title or description the person previously edited, the app warns before overwriting that writing and offers an explicit choice. Keeping the person's writing still updates the address and page-owned visuals; choosing fresh page details replaces the edited text deliberately.

## Gherkin
Feature: Editing bookmark details

  Scenario: Keep a hand-written title while changing the address
    Given a bookmark title was edited by the person
    When the person changes the bookmark to a different page address and saves
    Then the app warns that gathering new details would replace the edited title
    When the person chooses to keep their title
    Then the address, site icon, and preview image update for the new page
    And the hand-written title remains unchanged

  Scenario: Deliberately replace hand-written details
    Given the warning about replacing edited details is visible
    When the person chooses to use new page details
    Then the title and description are gathered from the new page

## Assumptions
- The app distinguishes person-edited text from automatically gathered text.
- Automatic refresh remains straightforward when no personal writing would be lost.
