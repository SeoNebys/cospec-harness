Scenario ID: SCN-011
Title: Explain an empty search result
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When the current search and label selection match no bookmarks, the app shows a clear No bookmarks found state and a zero count instead of an unexplained blank list. The search term remains visible so the client understands the result, and Clear search restores the full library.

## Gherkin
Feature: Empty search results

  Scenario: No bookmark matches the current search
    Given the library contains bookmarks
    When the client's current search and label selection match none of them
    Then no bookmark cards are shown
    And the visible count is zero
    And a No bookmarks found explanation is shown
    And the search term remains visible
    And the client can clear the search to restore the full library

## Assumptions
- An empty result is distinct from an empty library.
- Clear search removes the text query while retaining the library's bookmarks.
