Scenario ID: SCN-002
Title: Adjust automatically collected wording while saving
Type: Happy Path
Approval status: approved
Approval session: SESSION-002
Approval cycle: 1

## Approved behaviour

When the client pastes a valid page address into the save pop-up, the page title and description appear automatically without an extra confirmation step. The client can adjust either field before saving. The site's name, icon, and web address remain tied to the original page and cannot be rewritten. The saved card displays the client's adjusted wording.

## Gherkin

Feature: Saving bookmarks

  Scenario: Adjust collected details before saving
    Given the user is adding a new bookmark
    When the user pastes a valid web address
    Then the collected title and description appear automatically
    And no separate action is required to collect them
    When the user adjusts the title and description and saves the bookmark
    Then the bookmark card shows the adjusted title and description
    And the site name, site icon, and web address still identify the original page

## Assumptions

- Automatic collection begins after the pasted address is valid.
- Only the title and description are editable during saving.
- The page identity fields are derived from the submitted web address.
