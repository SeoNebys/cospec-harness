Scenario ID: SCN-015
Title: Preserve a private copy of a page, optionally submit to the Internet Archive
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
For links the client particularly cares about, two distinct, manual per-bookmark
actions are available from the "⋯ More" menu, with results shown as badges on the
card:

1. **Preserve a copy** — makes a private preserved copy, always available to the
   client. For an ordinary web page the copy is stored as a single self-contained
   HTML file; for a PDF address the copy is the PDF file itself. The card shows a
   "Preserved copy" badge (or "Preserved PDF" for a PDF) with the date and a link
   to view the copy. Re-preserving updates the copy.

2. **Send to the Internet Archive** — submits the page to the Internet Archive, a
   public third party. Because this creates a public copy, a brief confirmation
   explaining that is shown before submission begins; the client can cancel. On
   success the card shows an "On the Internet Archive" badge linking to the public
   copy.

The two actions are independent: preserving a private copy never publishes
anything to a third party, and sending to the Internet Archive is a separate,
explicit choice. Preservation is manual (no automatic preservation in this cycle).

## Gherkin
Feature: Preservation

  Scenario: Preserve a private copy of a web page
    Given a bookmark for an ordinary web page
    When the client chooses "Preserve a copy"
    Then a private preserved copy is made and stored as a single self-contained HTML file
    And the card shows a "Preserved copy" badge with the date and a view link
    And nothing is published to any third party

  Scenario: Preserve a PDF link
    Given a bookmark whose address is a PDF
    When the client preserves a copy
    Then the preserved copy is the PDF file itself
    And the card labels it as a preserved PDF

  Scenario: Send to the Internet Archive with a public-copy confirmation
    When the client chooses "Send to Internet Archive"
    Then a brief confirmation explains this creates a public third-party copy
    And cancelling submits nothing
    And confirming submits the page and then shows a link to the public copy

## Assumptions
- Real page capture and real Internet Archive submission are built in the
  implementation phase; the prototype simulates them (client acknowledged).
- Private preserved copy storage: self-contained HTML for pages, the PDF itself
  for PDF links (client-confirmed).
- Preservation is manual per bookmark; no auto-preserve this cycle (client-confirmed).
- Both actions live in the "⋯ More" menu; results shown as card badges (client-confirmed).
