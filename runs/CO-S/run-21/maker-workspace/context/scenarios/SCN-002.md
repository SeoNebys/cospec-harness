Scenario ID: SCN-002
Title: Edit collected title and description inline
Type: Happy Path
Approval status: approved
Approval session: SESSION-002
Approval cycle: 1

## Approved behaviour
A person can open title-and-description editing directly inside an existing bookmark card. Both collected values become editable together in place. An explicit save returns the same card to its normal view with the updated title and description, without navigating away. Inline editing is preferred over a separate side panel.

## Gherkin
Feature: Correct automatically collected bookmark details

  Scenario: Edit title and description within a bookmark card
    Given an enriched bookmark has an automatically collected title and description
    When the person opens title-and-description editing on that bookmark
    Then the title and description become editable together inside the card
    When the person changes both values and explicitly saves them
    Then the card returns to its normal view without navigating away
    And the card shows the updated title and description

## Assumptions
- Editing is deliberately opened rather than always active.
- Title and description changes are committed together through one explicit save.
- Other bookmark details are not part of this editing interaction.
