Scenario ID: SCN-012
Title: Correct an invalid web address before saving
Type: Error Case
Approval status: approved
Approval session: SESSION-012
Approval cycle: 1

## Approved behaviour

When the client tries to save text that is not a complete web address, the app creates no bookmark, keeps the entered text in place so it can be corrected, and shows a nearby message explaining the full-address format with an example. The error does not interrupt the client with a separate dialog.

## Gherkin

Feature: Validate bookmark addresses

  Scenario: Reject text that is not a complete web address
    Given the bookmark save field contains "this is not a link"
    When the user tries to save the bookmark
    Then no bookmark is created
    And the entered text remains in the save field
    And a message beside the field asks for a complete web address
    And the message includes an example of a complete web address

## Assumptions

- A complete address begins with http or https.
- Invalid-address feedback appears beside the save field rather than in a separate dialog.
- The client can edit and resubmit the original text.
