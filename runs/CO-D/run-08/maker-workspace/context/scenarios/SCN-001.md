Scenario ID: SCN-001
Title: Save a readable bookmark from a web address
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A person with an empty personal collection can paste a valid web address and save it. The saved bookmark appears beneath the save area with the page title, a short description, its source, and a default status of To read.

## Gherkin
Feature: Save bookmarks

  Scenario: Save a link with automatically obtained page details
    Given the personal bookmark collection is empty
    When the person pastes a valid web address and saves it
    Then a bookmark is added beneath the save area
    And the bookmark shows the page title
    And the bookmark shows a short page description
    And the bookmark shows its source
    And the bookmark is marked To read

## Assumptions
- New bookmarks default to To read.
- The collection is displayed below the save area.
- The referenced page provides enough information to produce a title and short description.
