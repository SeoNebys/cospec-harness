Scenario ID: SCN-015
Title: Open a saved bookmark's original webpage
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The title on each library card is a link to that bookmark's saved original web address. Selecting the title opens the real original page in a new browser tab, preserving the person's place, search, and filters in the library. The client selected the clickable title after comparing it with a separate “Open original page” control, preferring the natural web convention and cleaner card.

## Gherkin
Feature: Open a saved bookmark

  Scenario: Follow a bookmark from the library
    Given a saved bookmark is visible in the library
    When the user selects its title
    Then the bookmark's saved original web address opens
    And it opens in a new browser tab
    And the library remains open in its existing state

## Assumptions
- The title is the approved click target for opening the original page.
- Opening the original page does not replace the library tab.
