Scenario ID: SCN-018
Title: Browse a large collection with numbered pages
Type: Edge Case
Approval status: approved
Approval session: SESSION-018
Approval cycle: 1

## Approved behaviour

When the personal collection contains hundreds of bookmarks, ordinary browsing is divided into numbered pages. The client can see their current page, jump directly to a visible page number, and move backward or forward, giving them a clear sense of position in the whole collection without endless scrolling.

## Gherkin

Feature: Browse a large bookmark collection without losing position

  Scenario: Move between numbered collection pages
    Given the personal collection contains more bookmarks than fit on one page
    When the user views All bookmarks
    Then the collection shows a fixed group of bookmarks
    And the current page number is visibly active
    And controls are available to move backward, move forward, or choose a visible page number
    When the user chooses another page
    Then that page's group of bookmarks is shown
    And the chosen page number becomes visibly active

## Assumptions

- Ordinary unfiltered browsing uses 20 bookmarks per page.
- Page controls include direct page numbers and previous/next actions.
