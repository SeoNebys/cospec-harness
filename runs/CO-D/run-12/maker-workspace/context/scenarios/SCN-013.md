Scenario ID: SCN-013
Title: Keep long notes and many labels manageable on a card
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A long personal note starts folded on its bookmark card to keep the collection easy to scan. The user can expand and fold the note in place, and its bold text, bulleted lists, and links remain formatted. When a bookmark has many labels, they wrap onto additional lines without breaking the card.

## Gherkin
Feature: Bookmark card boundaries

  Scenario: Read a long formatted note
    Given a bookmark has a long personal note containing supported formatting
    When the bookmark is shown in the collection
    Then the note is initially folded on its card
    When the user chooses to show the full note
    Then the note expands in place
    And its bold text, bulleted lists, and links remain formatted
    When the user chooses to show less
    Then the note folds again

  Scenario: Display many labels on one bookmark
    Given a bookmark carries enough labels to exceed one line
    When its card is shown
    Then the labels wrap onto additional lines
    And the card remains usable

## Assumptions
- Long notes are folded by default in collection views.
- Expanding a note does not navigate away from the collection.
