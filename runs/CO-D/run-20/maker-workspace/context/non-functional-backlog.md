# Non-functional & scope backlog

Recorded during Phase 1. Not implemented as functional scenarios in this cycle
unless promoted. Kept for later attention.

## Non-functional
- Visual/UX polish: colours, spacing, typography, the preview-image treatment,
  and animation are placeholder-level in the prototype; refine later.
- Performance with a large collection: live search should stay responsive as the
  number of bookmarks grows (hundreds+). Confirm acceptable responsiveness.
- Durability: saved bookmarks (and their tags/notes/status) must persist reliably
  between sessions.

## Scope items surfaced (need a client decision)
- Cross-device access: the client uses the app on both computer and phone, so the
  saved collection must live in one shared place both devices reach. Whether it is
  protected by a personal sign-in is an open question posed to the client.

## Candidate future cycles (recorded, not started this cycle)
- Importing existing browser bookmarks / open tabs to seed the collection (relates
  to the client's original pain of scattered links). Not requested yet.
- "Show more" behaviour tuning for extremely long notes if needed.
