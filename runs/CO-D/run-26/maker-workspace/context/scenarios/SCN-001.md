Scenario ID: SCN-001
Title: Save a new link with auto-filled details and optional tags, note, and read-later
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The client enters or pastes a link and starts saving. The app reads the page and
automatically fills in a title and description, and collects the site's icon and a
small page preview image. The filled-in details are shown for review before saving;
the client can adjust the title and description, add comma-separated tags, add an
optional personal note, and turn a "Read later" switch on or off. Confirming adds
the bookmark to the single collection. Each collection card shows the site icon,
title (clickable, opens the link in a new tab), the address, the description, the
note when present, the tags when present, a "Read later" marker when that status is
on, and a small preview thumbnail that aids recognition without dominating the card.

## Gherkin
Feature: Save a link to the collection

  Scenario: Auto-fill details when a new link is entered
    Given the client is on the bookmarks page
    And the link is not already in the collection
    When the client enters a link and starts saving
    Then the app reads the page and fills in a title and description
    And it collects the site icon and a page preview image
    And it shows these details for review before the bookmark is saved

  Scenario: Adjust details and add tags, note, and read-later before saving
    Given the auto-filled details are shown for review
    When the client edits the title or description
    And adds one or more comma-separated tags
    And optionally writes a personal note
    And optionally turns the "Read later" switch on
    And confirms adding it to the collection
    Then the bookmark is added to the single collection
    And its card shows the icon, title, address, description, note, tags,
        preview thumbnail, and a "Read later" marker when that status is on

  Scenario: Title falls back to the link when left empty
    Given the auto-filled details are shown for review
    When the client clears the title and confirms saving
    Then the bookmark is saved using the link as its title

## Assumptions
- Saving is a two-step flow (enter link -> review auto-filled details -> confirm),
  explicitly confirmed by the client.
- Tags are entered as comma-separated text.
- The clickable title opens the original link in a new browser tab.
- In the prototype, page reading is simulated; the real implementation reads the
  actual page for title, description, icon, and preview.
