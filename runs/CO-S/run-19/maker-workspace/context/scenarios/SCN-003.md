Scenario ID: SCN-003
Title: Find a bookmark using remembered words
Type: Happy Path
Approval status: approved
Approval session: SESSION-003
Approval cycle: 1

## Approved behaviour

In a library containing multiple bookmarks, the client can type remembered words into a search field. Results update while the client types and include bookmarks whose title, description, or website contains the entered text. The client does not need to enter an exact whole title or whole word to find a match.

## Gherkin

Feature: Search saved bookmarks

  Scenario: Find a bookmark from part of a remembered word
    Given the library contains several bookmarks
    And one bookmark has the title "The surprising intelligence of octopuses"
    When the user types "octopus" into the search field
    Then the results update without a separate submission action
    And only bookmarks with matching text remain visible
    And the bookmark titled "The surprising intelligence of octopuses" is visible

  Scenario Outline: Find a bookmark by searchable page detail
    Given the library contains a bookmark with a known <field>
    When the user types text contained within that <field>
    Then the bookmark appears in the search results

    Examples:
      | field       |
      | title       |
      | description |
      | website     |

## Assumptions

- Search is not case-sensitive.
- Search matches text contained within a title, description, or website rather than requiring an exact whole-field or whole-word match.
- Results update as the search text changes.
