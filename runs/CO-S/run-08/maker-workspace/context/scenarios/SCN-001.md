Scenario ID: SCN-001
Title: Save a link and see it grouped under its topic
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
From the main screen the client enters a link address, a title, and a topic in
the add box at the top, then saves. The saved link immediately appears in the
list below, placed under a heading for its topic. Topic headings are ordered
alphabetically and each heading shows a count of how many links it holds. Saving
requires three fields (address, title, topic), which the client confirmed feels
quick enough. The client confirmed the new link landed under the expected topic
and that the alphabetical topic groups make the list easy to scan.

## Gherkin
Feature: Saving a link under a topic

  Scenario: Save a link with a topic
    Given the bookmarks screen is open
    When the client enters a link address, a title, and the topic "Reading"
    And the client saves the link
    Then the link appears in the list under a "Reading" topic heading
    And the topic heading shows the number of links it contains

  Scenario: Topics are ordered alphabetically
    Given several links exist under different topics
    When the list is displayed
    Then the topic headings appear in alphabetical order

## Assumptions
- A link is described by three fields: address, title, topic.
- Links are grouped visually under their topic rather than shown as one flat list.
- Each topic heading displays a count of its links.
- (Open) Behaviour when the topic field is left empty is not yet explored.
