## Approved behaviour

The user pastes a link into the save box. After a brief "looking up the page
details…" indication, the page's title and description are fetched
automatically and shown in editable fields, with a reassuring hint that they
were filled in for the user and can be edited. The user may correct the title
and/or description, add their own tags (typed and confirmed one at a time,
removable), and write a context note ("why are you saving this?"). Pressing
Save adds the bookmark to the saved list, showing its title (link to the URL),
site, note and tags. The save form then resets.

## Gherkin

Feature: Save a link

  Scenario: Details are auto-filled and editable
    Given the user is on the bookmarks screen
    When the user enters a valid link whose page can be looked up
    Then a brief lookup indication is shown
    And the page title and description are filled into editable fields
    And a hint indicates the fields were auto-filled and may be edited

  Scenario: Correct details and save with tags and a note
    Given a link's details have been auto-filled
    When the user edits the title or description
    And the user adds one or more tags
    And the user writes a context note
    And the user presses Save
    Then a new bookmark is added to the saved list
    And it shows the (possibly edited) title linking to the URL, its site, the note and the tags
    And the save form is cleared

## Assumptions
- Details fetch automatically on entry of the link, without a separate fetch button.
- The Save action requires a valid link (see SCN-002 for lookup failure).
