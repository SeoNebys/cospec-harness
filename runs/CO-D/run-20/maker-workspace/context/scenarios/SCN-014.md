Scenario ID: SCN-014
Title: Bulk actions on selected bookmarks with whole-collection safeguards
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

Each bookmark has a selection checkbox. When one or more are selected, an action
bar shows the selected count and offers: Add tag…, Remove tag…, Mark to read,
Mark as read, Archive (or Restore when in the Archived view), and Delete.

- Add tag…: type a tag; it is added (normalised, de-duplicated) to each selected
  bookmark.
- Remove tag…: choose from the tags actually present on the selected bookmarks
  (a union list). Removing a tag removes it from those selected bookmarks that
  have it and leaves the others unchanged.
- Mark to read / Mark as read / Archive / Restore: applied to all selected.
- Delete: shows a confirmation naming the count and stating it is permanent and
  cannot be undone (distinct from Archive); Cancel leaves them, confirming
  deletes them together.

Any bulk change counts as an update for "Recently updated" sorting.

Scope safeguards:
- An action applies to exactly the ticked bookmarks — including ones scrolled
  off-screen; the count always reflects the true number selected.
- Changing the search or switching views clears the selection, so hidden
  bookmarks can never be acted on by accident.
- "Select all N shown" selects only the bookmarks in the current search/view at
  that moment; a hint states it never covers the whole collection. There is no
  control that silently selects everything.

## Gherkin
Feature: Bulk actions

  Scenario: Apply an action to selected bookmarks
    Given several bookmarks are selected
    When the user chooses a bulk action (tag/mark/archive/delete)
    Then it is applied to exactly those selected bookmarks

  Scenario: Remove a tag only from those that have it
    Given selected bookmarks where only some carry tag T
    When the user removes tag T in bulk
    Then T is removed from those that had it and others are unchanged

  Scenario: Selection clears when the shown set changes
    Given bookmarks are selected
    When the user changes the search or switches view
    Then the selection is cleared

  Scenario: Select all shown is scoped
    Given a search or view is active
    When the user clicks "Select all N shown"
    Then only the bookmarks currently shown are selected, never the whole collection

  Scenario: Bulk delete requires confirmation
    Given selected bookmarks
    When the user chooses Delete
    Then a confirmation naming the count and permanence is shown; Cancel keeps them, confirm deletes them together

## Assumptions
- Bulk delete is permanent (Archive remains the reversible option).
