Scenario ID: SCN-004
Title: Track what is still to read (reading queue)
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

Every link has a reading status: "To read" or "Read", shown as a badge on the
entry. A newly saved link starts as "To read" (the client accepts this default,
noting that some links are saved as references and can be switched to "Read"
quickly). The client changes the status by hand: an entry offers "Mark as read"
and, for read links, "Move back to 'to read'". Marking is always manual — merely
opening a link does not change its status (client explicitly preferred keeping
control). A reading-status switch above the list offers "All", "To read", and
"Read"; selecting one filters the list to that status. This status filter
combines with the topic filter and the text search (all narrow together). Read
links remain in the collection (shown slightly dimmed with a "Read" badge) so
they are still covered by search and topics; they are not hidden.

## Gherkin

Feature: Tracking what is still to read

  Scenario: A newly saved link starts as "To read"
    Given I save a new link
    Then it is marked "To read"

  Scenario: Mark a link as read
    Given a link marked "To read"
    When I mark it as read
    Then its badge changes to "Read"
    And it no longer appears when I view the "To read" queue

  Scenario: Move a read link back to the reading queue
    Given a link marked "Read"
    When I move it back to "to read"
    Then its badge changes to "To read" again

  Scenario: View only the reading queue
    Given I have links of mixed reading status
    When I select "To read"
    Then only links still to read are shown

  Scenario: Read links stay in the collection
    Given a link marked "Read"
    When I search or filter by topic
    Then the read link is still included in the results

## Assumptions

- New links default to "To read".
- Reading status is changed manually; opening a link does not mark it read.
- The reading-status filter (All / To read / Read) combines with the topic
  filter and the text search.
- Read links remain in the collection, shown dimmed with a "Read" badge, and are
  never hidden by the reading status alone.
