Scenario ID: SCN-017
Title: Act on selected bookmarks together (tag, read/unread, archive, delete)
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

With one or more bookmarks selected, the bulk action bar can:
- **Add a tag to all** selected (with suggestions from existing tags; existing
  tags on an item are not duplicated).
- **Remove a tag from all** selected — the remove box **suggests only tags that
  are actually present on the selected bookmarks**, which makes removal clear and
  avoids mistakes.
- **Mark read later** (flag all) and **Mark read** (turn the flag off for all) —
  a clear pair.
- **Archive** all selected.
- **Delete** all selected, with a **single undo** covering the whole batch.

## Gherkin
Feature: Bulk actions on selected bookmarks

  Scenario: Add a tag to all selected
    Given several bookmarks are selected
    When the user adds a tag in the bulk bar
    Then that tag is added to every selected bookmark (no duplicates)

  Scenario: Remove a tag from all selected
    Given several bookmarks are selected
    When the user opens the remove-tag box
    Then only tags present on the selected bookmarks are suggested
    And choosing one removes it from every selected bookmark that has it

  Scenario: Mark read-later / read for all selected
    When the user chooses "Read later" then "Mark read"
    Then all selected bookmarks are flagged, then unflagged

  Scenario: Archive all selected
    When the user archives the selection
    Then every selected bookmark is archived

  Scenario: Delete all selected with one undo
    When the user deletes the selection
    Then all selected bookmarks are removed
    And a single undo restores the whole batch within the grace period

## Assumptions
- Remove-tag suggestions are scoped to tags on the selected items.
- Bulk delete shares the same undo-then-permanent model as single delete.
