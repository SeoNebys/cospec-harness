Scenario ID: SCN-013
Title: Empty states and long-content display
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The app shows friendly, situation-specific empty-state messages rather than a
blank screen: when there are no bookmarks at all, when a search returns no
results, when the "To read" list is empty, and when the "Finished" list is
empty. Long content (titles, notes, descriptions, web addresses) wraps within
its card so nothing is cut off or pushed off-screen. If a saved page later
becomes unreachable (dead link), the bookmark is left unchanged; automatic
dead-link detection is out of scope for this version.
