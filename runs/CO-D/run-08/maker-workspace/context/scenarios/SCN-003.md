Scenario ID: SCN-003
Title: Reuse an existing bookmark when saving a duplicate
Type: Edge Case
Approval status: approved
Approval session: SESSION-003
Approval cycle: 1

## Approved behaviour
When an exact web address is already saved, saving it again does not create another bookmark. The saved-link count remains unchanged, a clear message says the link was already saved, and the existing bookmark is brought into focus with a brief visual highlight.

## Gherkin
Feature: Avoid duplicate bookmarks

  Scenario: Save an address that is already in the collection
    Given a bookmark exists for a web address
    When the person attempts to save the exact same web address again
    Then no additional bookmark is created
    And the saved-link count remains unchanged
    And the person is told the link is already saved
    And the existing bookmark is brought into focus and highlighted

## Assumptions
- Exact matching addresses identify a duplicate.
- Address variations are not covered by this scenario.
