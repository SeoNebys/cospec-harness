Scenario ID: SCN-002
Title: Group related bookmarks into a named collection
Type: Happy Path
Approval status: approved
Approval session: SESSION-002
Approval cycle: 1

## Approved behaviour
From a collection containing several bookmarks, the user can select multiple related bookmark cards using the controls beside them, choose to group the selected bookmarks, name the collection, and create it. The selected bookmarks then appear together under that named collection, visually separated from the other bookmarks, with clear confirmation that the collection was created.

## Gherkin
Feature: Organizing related bookmarks

  Scenario: Select related bookmarks for organization
    Given the personal collection contains “MDN Web Docs”, “CSS-Tricks”, and unrelated bookmarks
    When the user selects “MDN Web Docs” and “CSS-Tricks” using the controls beside their cards
    Then both bookmark cards are visibly selected
    And an action to group the selected bookmarks is available

  Scenario: Create a named collection from selected bookmarks
    Given “MDN Web Docs” and “CSS-Tricks” are selected
    When the user chooses to group the selected bookmarks
    And names the collection “Web development”
    And creates the collection
    Then “MDN Web Docs” and “CSS-Tricks” are shown together under “Web development”
    And they are visually separated from the unrelated bookmarks
    And a clear confirmation says the collection was created and the bookmarks were grouped

## Assumptions
- A collection can hold multiple bookmarks.
- Selection controls appear beside each bookmark card.
- This flow places each selected bookmark into the newly named collection.
- Named collections, rather than labels, are the organization method for this cycle.
