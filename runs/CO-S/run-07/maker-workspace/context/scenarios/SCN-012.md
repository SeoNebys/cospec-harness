Scenario ID: SCN-012
Title: Save manually when page details cannot be retrieved
Type: Error Case
Approval status: approved
Approval session: SESSION-012
Approval cycle: 1

## Approved behaviour
If a valid web address does not provide page details, the app preserves the address, explains that the details could not be filled in, and allows the user to enter them manually. A title is required so the bookmark remains recognisable; the description may be empty. Once a title is supplied, the bookmark can still be saved normally.

## Gherkin
Feature: Recover when page details cannot be retrieved

  Scenario: Manually complete and save a bookmark
    Given the user has entered a valid web address
    And the app cannot retrieve the page title or description
    When the app presents the bookmark details
    Then the original web address remains in place
    And the app explains that the details could not be filled in
    And the title and description can be entered manually
    When the user enters a title and saves
    Then the bookmark is saved with the preserved address and manual details

  Scenario: Require a title for a manually completed bookmark
    Given page details could not be retrieved
    And the title is empty
    When the user tries to save the bookmark
    Then saving is blocked
    And the user is asked to enter a title

## Assumptions
- A description is optional.
- Failure to retrieve details does not imply that the web address itself is invalid.
