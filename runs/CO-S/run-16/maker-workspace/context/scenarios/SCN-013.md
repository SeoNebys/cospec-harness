Scenario ID: SCN-013
Title: Remove the last bookmark from Read later without losing it
Type: Edge Case
Approval status: approved
Approval session: SESSION-013
Approval cycle: 1

## Approved behaviour

The client can use the labeled In Read later control to remove a bookmark from the reading list. When it is the last waiting bookmark, the Read later count disappears and the dedicated view clearly says that nothing is waiting to be read. The bookmark itself remains safely available under All bookmarks.

## Gherkin

Feature: Clear the reading list without deleting bookmarks

  Scenario: Remove the only bookmark from Read later
    Given exactly one bookmark is marked for Read later
    And the user is viewing the dedicated Read later list
    When the user removes that bookmark from Read later
    Then the bookmark is removed from the dedicated list
    And the Read later count disappears
    And the view says that nothing is waiting to be read
    And the bookmark remains in All bookmarks

## Assumptions

- The labeled card control changes from "In Read later" back to "Read later" after removal.
- Removing a bookmark from Read later does not change its tags, note, or archive state.
