Scenario ID: SCN-001
Title: Save a new link with auto-filled details, optional tags and note
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The user pastes a link into the "Paste a link" field and presses "Get details".
The app retrieves the link's basic details and fills in a title and a
description, both of which the user can edit before saving. The user may
optionally add tags (typed as words separated by commas) and a free-text note.
On pressing "Save bookmark", the link is added to the saved collection and
appears in the list showing its title, address, description, tags, and note.
When no links are saved yet, the collection shows an empty-state message.

## Gherkin
Feature: Save a link

  Scenario: Fetch details for a pasted link
    Given the user is on the bookmarks screen
    And the "Paste a link" field contains a valid link address
    When the user presses "Get details"
    Then the app fills in a title and a description for that link
    And the title and description are editable

  Scenario: Save a link with optional tags and a note
    Given the app has filled in the title and description for a pasted link
    When the user optionally edits the title or description
    And the user optionally enters comma-separated tags
    And the user optionally enters a note
    And the user presses "Save bookmark"
    Then the link is added to the saved collection
    And the saved entry shows its title, address, description, tags, and note
    And the entry form is cleared for the next link

  Scenario: Empty collection
    Given the user has not saved any links yet
    When the user views the saved collection
    Then an empty-state message is shown instead of a list

## Assumptions
- The app obtains the title and description from the link's page ("auto-fetch");
  in the Phase 1 prototype this retrieval is simulated.
- Details are retrieved when the user presses "Get details" (client-confirmed),
  not automatically on paste.
- Tags are entered as words separated by commas (client-confirmed).
- Title and description are editable before saving (client-confirmed).
