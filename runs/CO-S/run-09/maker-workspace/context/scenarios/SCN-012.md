Scenario ID: SCN-012
Title: Recognize duplicate pages despite referral information in the address
Type: Edge Case
Approval status: approved
Approval session: SESSION-012
Approval cycle: 1

## Approved behaviour
When a person pastes an address for an already saved page that differs only by extra referral or tracking information, the app recognizes it as the same page. It keeps exactly one bookmark and offers Review & update for the existing item instead of making a near-duplicate.

## Gherkin
Feature: Prevent duplicate bookmarks

  Scenario: Detect the same page with referral information
    Given the library contains a bookmark for a page
    When the person pastes an address for that page with extra referral or tracking information
    Then the app identifies the existing bookmark
    And the library still contains exactly one bookmark for the page
    And the app offers to review and update the existing bookmark

## Assumptions
- Referral and tracking information that does not identify different page content is ignored for duplicate detection.
- Meaningful address differences that identify different pages are not automatically merged.
