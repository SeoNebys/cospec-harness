Scenario ID: SCN-004
Title: Filter by clicking a tag
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Clicking a tag chip shown on a bookmark filters the list to that exact tag,
without the user having to type. This is equivalent to searching "#tag".

## Gherkin
Feature: Tag filtering by click

  Scenario: Click a tag to filter
    Given a bookmark shows the tag "travel"
    When the user clicks that tag
    Then the search becomes "#travel"
    And the list shows only bookmarks tagged exactly "travel"

## Assumptions
- Clicking a tag replaces the current search with that tag filter.
