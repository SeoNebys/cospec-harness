Scenario ID: SCN-028
Title: Show a helpful empty search result
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When a valid search matches no bookmarks, the result is presented as a calm empty state rather than an error. It states that nothing matched, suggests trying fewer words or a different label, and keeps the original query available to adjust.

## Gherkin
Feature: Searching saved bookmarks

  Scenario: Search with no matching bookmarks
    Given the collection contains no bookmark matching the query
    When the person performs the search
    Then no result cards are shown
    And a non-error empty state says that nothing matched
    And it suggests adjusting the words or label
    And the original query remains in the search field

## Assumptions
- A zero-result search is valid and is not treated as a system error.
