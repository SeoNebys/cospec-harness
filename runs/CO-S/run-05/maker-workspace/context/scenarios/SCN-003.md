Scenario ID: SCN-003
Title: Tag a link flexibly (multiple tags) and use tags to find
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When saving a link the user may optionally add one or more tags in a separate
"Tags (optional)" box, typed as comma-separated words. A link may carry several
tags at once and thereby appears under every one of them — there is no
requirement to file a link under a single category (this directly fixed the
client's "a Tokyo restaurant is both travel and cooking" concern). Tags may be
left blank to save a bare link quickly. Each saved link displays its tags as
small chips. Clicking a tag chip drops that word into the search box, showing
all links carrying that tag — i.e. tags are simply words the single search
already understands, not a separate filtering system.

## Gherkin
Feature: Flexible multi-tagging

  Scenario: Save a link with multiple tags
    Given the user is saving a link
    When the user enters several comma-separated tags and saves
    Then the link is stored with all of those tags
    And the link appears when searching for any one of those tags

  Scenario: Save a link with no tags
    Given the user is saving a link
    When the user leaves the tags box blank and saves
    Then the link is stored with no tags and still appears in the list

  Scenario: A link belongs to more than one topic at once
    Given a link is tagged both "travel" and "cooking"
    When the user searches "travel"
    Then the link appears
    When the user searches "cooking"
    Then the same link also appears

  Scenario: Clicking a tag finds links with that tag
    Given saved links display their tags as chips
    When the user clicks a tag chip
    Then that tag's text is placed in the search box
    And the list narrows to links carrying that tag

## Assumptions
- Tags are entered comma-separated in a dedicated optional box (client confirmed
  natural).
- Tags are optional; a bare link with no tags is valid (client valued this for
  saving in a hurry).
- Clicking a tag reuses the single search box rather than a separate filter
  (client confirmed).
