Scenario ID: SCN-003
Title: Search bookmark details and labels from one box
Type: Happy Path
Approval status: approved
Approval session: SESSION-003
Approval cycle: 1

## Approved behaviour

The client enters one word in a single search box. The resulting bookmarks
include matches found through automatically collected page details as well as
matches found through labels, allowing retrieval whether the client remembers
a tag or only words associated with the page.

## Gherkin

Feature: Searching bookmarks

  Scenario: Find bookmarks through both page details and labels
    Given the collection contains bookmarks with titles, descriptions, originating sites, and labels
    And one bookmark has "learning" in its description
    And another bookmark has the label "learning"
    When the client searches for "learning" in the bookmark search box
    Then both matching bookmarks are shown
    And bookmarks with no match in their title, description, originating site, or labels are not shown

## Assumptions

- A single search box searches titles, descriptions, originating sites, and labels together.
- Search results update from the entered word without requiring a separate search mode for labels.
