Scenario ID: SCN-015
Title: Click a label to filter the list to that label
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Each label shown on a card is tappable. Clicking a label filters the list to that
label by placing it into the search box (as `#label`), so the filter is visible,
combinable, and clearable like any search. If the search box is empty, clicking a
label sets that label filter. If a search is already in progress, the label is added
so it narrows the current results — the combined effect is "the existing search AND
this label". Clicking a label already present in the search does not add it again.

## Gherkin
Feature: Filter by clicking a label

  Scenario: Click a label with an empty search
    Given the search box is empty
    When the user clicks a label on a card
    Then the search box shows "#label"
    And the list is filtered to links carrying that label

  Scenario: Click a label with an active search
    Given a search is already in progress
    When the user clicks a label on a card
    Then the label is added so the results are narrowed to "existing search AND that label"
    And the previous search is not discarded

  Scenario: Click a label already applied
    Given the current search already includes that label
    When the user clicks the same label again
    Then the search is unchanged

## Assumptions
- A multi-word label is inserted quoted (`#"..."`).
- Narrowing is expressed as "(existing search) AND #label".
