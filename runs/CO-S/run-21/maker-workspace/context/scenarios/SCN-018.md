Scenario ID: SCN-018
Title: Add one tag to several selected bookmarks
Type: Happy Path
Approval status: approved
Approval session: SESSION-018
Approval cycle: 1

## Approved behaviour
After selecting several bookmarks, the person chooses Add tag from the bulk-action bar. The same compact, narrowing existing-tag suggestions used for a single bookmark are reused. Selecting a tag attaches it to every selected card at once, and one confirmation states the tag and the number of affected bookmarks.

## Gherkin
Feature: Tag several bookmarks in one action

  Scenario: Add an existing tag to a selection
    Given two bookmarks are selected
    When the person chooses "Add tag"
    And types text that narrows the familiar compact tag suggestions
    And selects the existing tag "Reading"
    Then "Reading" is attached to both selected bookmarks
    And the app confirms that two bookmarks were affected

## Assumptions
- A tag already present on one selected bookmark is not duplicated.
- Bulk tagging uses the same tag vocabulary and suggestions as single-bookmark tagging.
