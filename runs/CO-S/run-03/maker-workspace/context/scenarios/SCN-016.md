Scenario ID: SCN-016
Title: Remove a tag directly from a bookmark
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Each tag label on a bookmark has a direct removal action. Choosing the × on one
label removes only that tag immediately, leaving the bookmark's other tags and
its separate Add tags action unchanged.

## Gherkin
Feature: Removing bookmark tags

  Scenario: Remove one tag directly
    Given a bookmark has several tag labels
    When the person chooses the × on one tag label
    Then that tag is removed from the bookmark
    And the other tag labels remain
    And the Add tags action remains available

## Assumptions
- Tag removal is immediate and does not require a separate save step.
- Removing a tag does not remove or alter the bookmark.
