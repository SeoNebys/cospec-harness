Scenario ID: SCN-015
Title: Preserve personal bookmark details when the webpage changes
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
After a bookmark is saved, later changes to the webpage do not silently replace the stored title, description, labels, personal note, or preview information. Those saved details remain exactly as the user left them. Clicking the bookmark still opens the current live version of the webpage at its saved address.

## Gherkin
Feature: Preserve a bookmark over time

  Scenario: The source webpage changes after being bookmarked
    Given the user saved and personalized a bookmark
    And the source webpage later changes its title, description, or preview
    When the user returns to the library
    Then the stored bookmark details remain as the user left them
    And the user's labels and personal note remain unchanged
    When the user opens the bookmark
    Then the current live webpage opens at the saved address

## Assumptions
- Page details are gathered when a bookmark is first saved and are not refreshed automatically afterward.
