Scenario ID: SCN-014
Title: Recover from a search with no matches
Type: Edge Case
Approval status: approved
Approval session: SESSION-014
Approval cycle: 1

## Approved behaviour

When search text matches no bookmarks, the app shows a simple no-results message and suggests trying different words. No bookmark data changes. Clearing the search immediately restores the full library.

## Gherkin

Feature: Search saved bookmarks

  Scenario: Clear a search with no matches
    Given the library contains bookmarks
    When the user enters search text that matches none of them
    Then the app says that no bookmarks were found
    And suggests trying different words
    And no bookmarks are changed or removed
    When the user clears the search
    Then the full library is shown again

## Assumptions

- A no-results search is represented as an empty result view, not as an error.
- Clearing search text restores the prior complete library view.
