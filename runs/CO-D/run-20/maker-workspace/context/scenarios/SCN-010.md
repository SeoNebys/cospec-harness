Scenario ID: SCN-010
Title: Empty-data states (new collection, empty views, no search results)
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

When there is no data to show, the app presents a clear, calm state rather than a
blank or broken screen:
- A brand-new collection with nothing saved shows an inviting empty state
  prompting the user to paste their first link.
- An empty view (To read / Reference / Archived with no matching items) shows a
  short message specific to that view (e.g. "No archived bookmarks.").
- A search that matches nothing shows a "nothing matched" message naming the
  query, leaving the collection intact behind it.

## Gherkin
Feature: Empty-data states

  Scenario: New empty collection
    Given the user has no saved bookmarks
    Then an inviting empty state prompts them to paste their first link

  Scenario: Empty view
    Given a view (To read / Reference / Archived) has no items
    When the user opens that view
    Then a short message specific to the view is shown

  Scenario: No search results
    Given saved bookmarks exist
    When the user searches a term that matches none of them (in the current view)
    Then a "nothing matched" message naming the query is shown and no bookmark is listed

## Assumptions
- Empty states never mark a loading/error placeholder as ready.
