Scenario ID: SCN-010
Title: Open the original page from a readable bookmark card
Type: Happy Path
Approval status: approved
Approval session: SESSION-010
Approval cycle: 1

## Approved behaviour
Each saved bookmark appears as a clear, scannable card containing its title, short description, tags, web address, and any personal note or status. Selecting the title opens the original page in a new browser tab, leaving the bookmark library available in its existing tab.

## Gherkin
Feature: Viewing and opening bookmarks

  Scenario: Scan a saved bookmark
    Given a bookmark has been saved with page details and tags
    When the person views the bookmark list
    Then the bookmark appears as a readable card
    And its title, short description, tags, and web address are visible
    And its personal note or status is visible when present

  Scenario: Open the saved page while keeping the library available
    Given a bookmark card is visible
    When the person selects its title
    Then the original web address opens in a new browser tab
    And the bookmark library remains open in the existing tab

## Assumptions
- The bookmark title is the link to the original page.
- Opening a bookmark does not modify its saved state.
