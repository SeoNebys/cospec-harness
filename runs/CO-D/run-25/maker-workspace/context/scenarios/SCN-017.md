Scenario ID: SCN-017
Title: Match an exact phrase with quotes
Type: Happy Path
Approval status: approved
Approval session: SESSION-017
Approval cycle: 1

## Approved behaviour
Text inside quotation marks is treated as an exact phrase. The words must appear together in the quoted order within a bookmark's searchable information; bookmarks containing the same words separately or in another order are not included.

## Gherkin
Feature: Combining bookmark searches

  Scenario: Match words together and in order
    Given one bookmark contains the phrase "modern JavaScript"
    And another bookmark contains both words in different positions
    When the person searches for "\"modern JavaScript\""
    Then only the bookmark containing the exact phrase is shown

## Assumptions
- Exact phrase matching ignores capitalization, consistently with other search.
- Quotes distinguish literal text from search command words.
