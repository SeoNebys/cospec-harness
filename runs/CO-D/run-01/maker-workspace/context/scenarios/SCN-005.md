Scenario ID: SCN-005
Title: Organize a bookmark with labels
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A bookmark can have multiple labels. From its action menu, the person opens a searchable list of existing labels, narrows the list by typing, and selects one or more. Matching ignores capitalization and steers the person toward an existing label to avoid near-duplicates. When no existing label has the entered name, the chooser offers to create it in place. Saved labels appear as chips on the bookmark card.

## Gherkin
Feature: Bookmark labels

  Scenario: Find and attach existing labels
    Given a bookmark's label chooser is open
    And existing labels are available
    When the person searches for an existing label and selects one or more matches
    Then the chosen labels are associated with the bookmark
    And each chosen label appears as a chip on its card

  Scenario: Create a new label when none has the same name
    Given a bookmark's label chooser is open
    When the person enters a label name that does not match an existing label regardless of capitalization
    Then the chooser offers to create that label
    And saving creates and attaches the new label
    And the new label appears as a chip on the bookmark card

## Assumptions
- Labels are managed through the bookmark's always-visible action menu.
- The searchable checklist is the chosen interaction for finding and selecting labels.
- One bookmark can have multiple labels.
- Existing-name matching is case-insensitive.
