Scenario ID: SCN-005
Title: Archive a bookmark without deleting it, and restore it
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

The client can archive any active bookmark to set it aside without deleting it.
An archived bookmark is removed from the everyday lists (the All / To read /
Finished tabs, which show only non-archived bookmarks) and moves to a separate
"Archived" tab that is deliberately set apart from the everyday tabs.

Archived bookmarks keep all their data — title/details, tags, note, and reading
status. From the Archived tab, a single "Restore" button returns a bookmark to
the active lists, intact. Nothing is ever deleted by archiving.

Search and tag browsing work within the Archived tab too, so the client can dig
out a specific archived bookmark.

## Gherkin

Feature: Archive without deleting

  Scenario: Archive an active bookmark
    Given an active (non-archived) bookmark
    When the client archives it
    Then it no longer appears in the All / To read / Finished tabs
    And it appears in the Archived tab
    And none of its data (details, tags, note, status) is lost

  Scenario: Everyday lists exclude archived bookmarks
    Given some bookmarks are archived
    When the client views the All, To read, or Finished tab
    Then archived bookmarks are not shown there
    And the tab counts exclude archived bookmarks

  Scenario: Restore an archived bookmark
    Given an archived bookmark
    When the client restores it
    Then it returns to the active lists with its tags, note, and reading status intact

  Scenario: Search within archived bookmarks
    Given the client is on the Archived tab
    When the client searches or filters by tag
    Then only archived bookmarks matching the search/tag are shown

## Assumptions

- Archiving is reversible and never deletes. (Confirmed by client.)
- Archived bookmarks live in a separate tab, excluded from All/To read/Finished.
  (Confirmed by client.)
- Restore returns the bookmark with all attributes intact. (Confirmed by client.)
- An archived bookmark's reading status is not changed while archived; the client
  restores it first, then re-marks it. The status control is hidden while archived.
  (Confirmed by client during edge-case exploration.)
