Scenario ID: SCN-010
Title: Helpful empty states for each view and for no search matches
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When a list has nothing to show, a friendly message explains why rather than a
blank screen:
- No bookmarks at all: invitation to save the first link.
- No search/tag matches: suggestion to change words or clear a tag.
- Empty "To read": explains how items get there.
- Empty "Archived": explains archived items are kept here, out of the main list.

## Gherkin
Feature: Empty states

  Scenario: No bookmarks yet
    Given there are no bookmarks
    Then the list shows an invitation to save the first link

  Scenario: No matches for the current search or tags
    Given a search or tag filter yields nothing
    Then the list explains nothing matched and how to broaden

  Scenario: Empty To read view
    Given no bookmarks are marked to read later
    When the client opens the To read view
    Then it explains how to mark items to read later

  Scenario: Empty Archived view
    Given nothing is archived
    When the client opens the Archived view
    Then it explains archived items are kept there

## Assumptions
- Empty-state messaging is per view and per filter context.
