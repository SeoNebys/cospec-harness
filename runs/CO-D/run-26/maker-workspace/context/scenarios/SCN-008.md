Scenario ID: SCN-008
Title: Save a link whose page can't be read automatically
Type: Error Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When the app cannot read a page's details automatically (e.g. the page is
unreachable or has no usable metadata), it does not block saving. It shows a
clear notice that the page couldn't be read automatically, leaves the title blank
for the client to type, and lets the client fill in the details manually and save
the bookmark normally. A difficult page never prevents the client from saving.
