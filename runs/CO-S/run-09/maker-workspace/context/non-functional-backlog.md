# Non-functional backlog

- Prefer explicit text labels over ambiguous icon-only actions, especially for consequential or infrequent actions.
- Keep library cards visually compact and scannable while preserving complete content in focused views.
- Avoid cluttering everyday bookmark cards with destructive controls.
- Preserve a person's place in the library while opening reading content.
- Use plain, specific confirmations and recovery messages that make outcomes unmistakable.
