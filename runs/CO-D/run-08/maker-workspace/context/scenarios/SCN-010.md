Scenario ID: SCN-010
Title: Edit all remembered details of a bookmark
Type: Happy Path
Approval status: approved
Approval session: SESSION-010
Approval cycle: 1

## Approved behaviour
Selecting Edit bookmark opens a side panel over the still-visible collection. A person can change the title, description, web address, personal note, and labels, then save all changes together without altering untouched details or status. The card shows the updated readable details and note afterward. It shows only the short source during normal use; the full address remains in the editor and is used when opening the bookmark.

## Gherkin
Feature: Edit a saved bookmark

  Scenario: Update a bookmark's remembered details

    Then the editor closes
    And all changed details are retained

    And the note is visible on the bookmark
    And the card shows the short source rather than the full web address

## Assumptions
- Editing takes place in a side panel without leaving the collection.
- Label suggestions remain available inside the editor.
