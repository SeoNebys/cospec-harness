Scenario ID: SCN-007
Title: Add a personal note to a link
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
In the edit pop-up, the client can write their own note about why they saved a
link — a line to their future self — kept clearly separate from the page's own
description. On the card the note is shown in a visually distinct "Note to self"
style (sticky-note look) so it is never confused with the page description.

## Gherkin
Feature: Personal note

  Scenario: Writing a note to self
    Given a saved link is being edited
    When the client writes a personal note and saves
    Then the note is shown on the card
    And it is visually distinct from the page's description

## Assumptions
- Note is distinct from, and never merged with, the page description.
  (client confirmed)

## Open wish (recorded, not yet approved)
- The note may later support light formatting (a bullet or two, bold) rather
  than a single flat line. (see candidates)
