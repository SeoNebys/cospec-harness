Scenario ID: SCN-011
Title: Add a bookmark to Read later
Type: Happy Path
Approval status: approved
Approval session: SESSION-011
Approval cycle: 1

## Approved behaviour
Each bookmark card has an always-visible Read later action because it is expected to be used often. One click immediately adds the bookmark to the Read later pile, briefly confirms the action, and leaves a lasting "In Read later" marker on the card. The visible action is preferred over placing it in an overflow menu.

## Gherkin
Feature: Set bookmarks aside to read later

  Scenario: Add a bookmark to Read later from its card
    Given a bookmark is not in the Read later pile
    And its Read later action is visible on the card
    When the person clicks the Read later action
    Then the bookmark is immediately added to the Read later pile
    And the app briefly confirms the action
    And the card shows a lasting "In Read later" marker

## Assumptions
- Adding to Read later does not remove the bookmark from the full collection.
- No confirmation dialog is required for adding to Read later.
