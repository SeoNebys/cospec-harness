Scenario ID: SCN-023
Title: Show an unambiguous zero-result search state
Type: Edge Case
Approval status: approved
Approval session: SESSION-023
Approval cycle: 1

## Approved behaviour
When no bookmarks match a search, the entered search term remains visible in context, the result count shows zero bookmarks, and the page plainly states that no bookmarks match. The state does not imply that the saved collection has been deleted.

## Gherkin
Feature: Understand an empty search result

  Scenario: Search for text that matches no bookmark
    Given the collection contains saved bookmarks
    When the person enters a search term that matches none of them
    Then the result heading retains the search term in context
    And the result count shows zero bookmarks
    And the page states that no bookmarks match the search
    And the saved collection remains unchanged

## Assumptions
- Clearing the search restores the collection.
- A zero-result search does not alter filters or bookmark data.
