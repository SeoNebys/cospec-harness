Scenario ID: SCN-002
Title: Revise a saved bookmark from its action menu
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Each saved bookmark has an always-visible three-dot action menu. Choosing Edit details opens the bookmark's title and description for revision. Saving the changes updates the card while leaving its automatically supplied site name, site icon, and picture unchanged. The menu is the intended home for other bookmark-specific actions added later.

## Gherkin
Feature: Revise saved bookmark details

  Scenario: Open editing from the bookmark action menu
    Given a saved bookmark is visible in the collection
    When the person opens its always-visible action menu and chooses Edit details
    Then the saved title and description are available to revise
    And the automatically supplied site name, site icon, and picture are not editable

  Scenario: Save revised bookmark details
    Given a saved bookmark's details are open for editing
    When the person revises the title or description and saves the changes
    Then the bookmark card shows the revised wording
    And its automatically supplied site identity and picture remain unchanged

## Assumptions
- An always-visible three-dot menu is the chosen entry point for bookmark-specific actions.
- The three-dot menu remains visible without pointer hover and can be used on touch screens.
- Editing appears in a focused overlay without leaving the collection.
