Scenario ID: SCN-009
Title: Personal Markdown note, distinct from the page description
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Each link has a personal "note" field that is separate from the auto-fetched
description. The description describes the page; the note records why the client
saved it or what they thought about it. The note is written and edited as
Markdown-style text and is displayed with its formatting rendered when viewing
the card (e.g. bold, italic, inline code, bullet lists, links, blockquotes,
small headings). The note is optional, editable at any time, and its text is
included in search.

## Gherkin
Feature: Personal note

  Scenario: Add a formatted note when saving
    Given a link is being saved
    When the client writes a Markdown note and saves
    Then the card displays the note with its formatting rendered
    And the page description remains shown separately and unchanged

  Scenario: Edit the note later
    Given a saved link has a note
    When the client edits the note text and saves changes
    Then the updated, rendered note is shown

  Scenario: Note is searchable
    Given a word appears only in a link's note
    When the client searches that word
    Then the link is found

## Assumptions
- Note and description are separate fields with distinct roles.
- Markdown rendering is limited to a safe common subset; links are sanitised to
  http/https/mailto.
