Scenario ID: SCN-035
Title: Reorder the current bookmark view
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A person can order the bookmarks in the current view by newest first, oldest first, or title A–Z. Changing the order rearranges only the bookmarks already in the active collection, label, or search view and does not reset the person to the full collection.

## Gherkin
Feature: Ordering bookmark views

  Scenario: Order a filtered label view by title
    Given the person is viewing four bookmarks labelled "Cooking"
    And the view is ordered newest first
    When the person changes the order to title A–Z
    Then the same four Cooking bookmarks are shown alphabetically
    And no bookmark outside the Cooking view is added

  Scenario Outline: Order the active view by date
    Given a collection, label, or search view is active
    When the person chooses <order>
    Then only bookmarks in that active view are rearranged by <order>

    Examples:
      | order        |
      | newest first |
      | oldest first |

## Assumptions
- Imported original bookmark dates participate in date ordering.
- The preferred default order is configurable separately.
