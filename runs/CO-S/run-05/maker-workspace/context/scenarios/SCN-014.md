Scenario ID: SCN-014
Title: Remove a bookmark from the reading pile without losing it
Type: Edge Case
Approval status: approved
Approval session: SESSION-014
Approval cycle: 1

## Approved behaviour

When the client clears the Read later mark from a bookmark in the reading pile,
the bookmark disappears from that focused view but remains in the full active
collection. It is neither deleted nor archived.

## Gherkin

Feature: Read-later bookmarks

  Scenario: Finish a bookmark without archiving it
    Given an active bookmark is marked for later
    And it is visible in the Read later view
    When the client removes its Read later mark
    Then it is no longer shown in the Read later view
    And it remains in the active bookmark collection
    And it is not archived

## Assumptions

- The active Read later button also removes the Read later mark.
