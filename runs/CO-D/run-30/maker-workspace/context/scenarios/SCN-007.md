Title: Filter the collection using a label chip
Type: Happy Path
Approval status: approved
Approval session: SESSION-007
Approval cycle: 1

## Approved behaviour

Labels appear as a row of chips above the bookmark cards and are also visible on each applicable card. Selecting a label immediately shows only bookmarks carrying that label, updates the result count, and leaves live search available. The client preferred this light, at-a-glance row over a sidebar for a small personal set of labels.

## Gherkin

Feature: Organizing bookmarks with labels

  Scenario: Show bookmarks carrying a selected label
    Given the collection includes two bookmarks labelled "Recipes"
    And labels are shown as a row of chips above the collection
    When the user selects the "Recipes" chip
    Then only the two recipe bookmarks are visible
    And the result count shows two results
    And the live search box remains available
    And the "Recipes" label is visible on each result card

## Assumptions

- A chip for showing all bookmarks appears alongside the user's labels.
- Filtering begins immediately when a label is selected.
- The expected number of personal labels is small enough for a horizontal row.
