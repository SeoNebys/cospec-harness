Scenario ID: SCN-010
Title: Recover easily from a search with no matches
Type: Edge Case
Approval status: approved
Approval session: SESSION-010
Approval cycle: 1

## Approved behaviour
When no bookmark matches the current search, collection cards temporarily give way to a clear no-results message. The search field retains the query and remains available, with a clear control, so the client can revise or reset it immediately. The presentation makes clear that only the search result is empty and the collection itself is intact.

## Gherkin
Feature: Search with no matching bookmarks

  Scenario: Enter a search that matches nothing
    Given the collection contains bookmarks
    When the user enters a search term that matches no title, description, or note
    Then no bookmark cards are shown
    And a clear no-results message is shown
    And the search term remains available to revise
    And a clear control can reset the search and reveal the collection again

## Assumptions
- A no-results search never changes or deletes bookmark data.
- The result count becomes zero while the unmatched search is active.
