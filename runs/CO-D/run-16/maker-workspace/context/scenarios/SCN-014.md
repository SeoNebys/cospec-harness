Scenario ID: SCN-014
Title: Permanently delete a bookmark with confirmation
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The client can permanently delete a bookmark. Because deletion cannot be undone,
the app asks for confirmation first. On confirmation, the bookmark is removed
entirely (it does not go to the Archive). Deletion is a separate action from
archiving.

## Gherkin
Feature: Delete a bookmark

  Scenario: Delete with confirmation
    Given a saved bookmark
    When the client chooses to delete it
    Then the app asks the client to confirm the permanent deletion
    And on confirmation the bookmark is removed entirely
    And it does not appear in the Archive

  Scenario: Cancel deletion
    Given the confirmation prompt is shown
    When the client cancels
    Then the bookmark is not deleted

## Assumptions
- Delete and Archive are distinct actions.
