Scenario ID: SCN-008
Title: Organize bookmarks with overlapping tags
Type: Happy Path
Approval status: approved
Approval session: SESSION-008
Approval cycle: 1

## Approved behaviour
A bookmark can carry several tags at the same time, such as “work” and “reading.” Selecting a tag narrows the collection to every bookmark carrying that tag. Tags are overlapping labels rather than single-choice folders.

## Gherkin
Feature: Organizing saved bookmarks

  Scenario: Filter the collection by a tag
    Given saved bookmarks carry one or more tags
    When the person selects a tag
    Then the collection shows every bookmark carrying that tag

  Scenario: One bookmark belongs to several tag groupings
    Given a saved bookmark carries multiple tags
    When the person filters the collection by any one of those tags
    Then that bookmark is included in the matching collection

## Assumptions
- Tags may overlap on the same bookmark.
- Tags act as collection filters rather than exclusive folders.
