Scenario ID: SCN-038
Title: Save a reusable search query
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A person can save the current search under a recognizable name. It appears in a persistent Saved searches list with the underlying query visible. The saved item stores the query itself rather than freezing the current result list, so it is a living shortcut capable of reflecting later collection changes.

## Gherkin
Feature: Saved searches

  Scenario: Save the current search
    Given the current query is "pasta AND #weekend"
    And matching results are visible
    When the person chooses to save the search
    And names it "Pasta weekends"
    Then "Pasta weekends" appears in Saved searches
    And its underlying query is shown
    And the query, rather than the current result identifiers, is stored

## Assumptions
- Saved-search names are editable user-provided text.
- Saved searches do not duplicate or freeze bookmark data.
