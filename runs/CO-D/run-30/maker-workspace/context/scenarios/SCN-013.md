Scenario ID: SCN-013
Title: Permanently delete several bookmarks using selection mode
Type: Happy Path
Approval status: approved
Approval session: SESSION-013
Approval cycle: 1

## Approved behaviour

Bulk actions begin from a deliberate Select items mode rather than always-visible checkboxes. In that mode each card can be selected, the action bar shows the number selected, and Done selecting exits the special picking state. Deleting the selection opens a count-specific confirmation stating that removal is permanent and cannot be undone. Confirming removes all selected bookmarks and updates the collection count.

## Gherkin

Feature: Managing bookmarks in bulk

  Scenario: Select and permanently delete several bookmarks
    Given the collection contains six bookmarks
    When the user enters selection mode
    And selects two bookmarks
    Then the bulk action bar shows two selected
    When the user chooses to delete the selection
    Then a confirmation states that two bookmarks will be permanently deleted and cannot be restored
    When the user confirms
    Then the selected bookmarks are removed
    And the collection count shows four saved

  Scenario: Leave selection mode without acting
    Given the user is in selection mode
    When the user selects Done selecting
    Then the collection returns to ordinary browsing mode

## Assumptions

- The same selection mode will host additional bulk cleanup actions.
- Permanent bulk deletion does not provide undo after explicit confirmation.
