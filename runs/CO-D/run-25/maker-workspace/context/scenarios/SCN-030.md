Scenario ID: SCN-030
Title: Explain when a search has no matches
Type: Edge Case
Approval status: approved
Approval session: SESSION-030
Approval cycle: 1

## Approved behaviour
When a valid search matches no bookmarks, the cards are replaced by a clear no-results message rather than a blank space. A direct Clear search action restores the full collection immediately.

## Gherkin
Feature: Searching bookmarks

  Scenario: Search with no matching bookmarks
    Given the collection contains no bookmark matching "quantum-banana"
    When the person searches for "quantum-banana"
    Then no bookmark cards are shown
    And a clear no-results message is shown
    When the person clears the search
    Then the full collection is restored immediately

## Assumptions
- A no-results state is distinct from an empty collection.
