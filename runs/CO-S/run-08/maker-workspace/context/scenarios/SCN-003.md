Scenario ID: SCN-003
Title: Filter links to a single topic with topic buttons
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A row of topic buttons is shown (one per existing topic, plus an "All" button).
Clicking a topic button narrows the list to only that topic's links; the active
button is visually marked. Clicking "All" returns to showing every topic. The
client can still type in the search box while a topic is selected, and the two
combine (search applies within the selected topic). The client chose this over a
dropdown and over clicking topic headings, because the available choices are
visible and switching or resetting takes a single click.

## Gherkin
Feature: Filtering links by topic

  Scenario: Filter to a single topic
    Given links exist under several topics
    And a row of topic buttons including "All" is shown
    When the client clicks the "Design" topic button
    Then only links whose topic is "Design" are shown
    And the "Design" button is marked as active

  Scenario: Return to all topics clears the search
    Given the list is filtered to the "Design" topic
    And the search box contains text
    When the client clicks the "All" button
    Then links from every topic are shown again
    And the search box is cleared

  Scenario: Search within a selected topic
    Given the list is filtered to the "Design" topic
    When the client types text into the search box
    Then only "Design" links whose title, address, or topic contain the text remain

## Assumptions
- One button per existing topic is generated automatically, plus a leading "All".
- Topic buttons are ordered with "All" first, then topics alphabetically.
- Topic filter and text search combine (both narrow the same list).
- Selecting a specific topic does not clear the search box.
- Clicking "All" resets to the full list: it clears both the topic filter and
  the search box (client-confirmed refinement).
