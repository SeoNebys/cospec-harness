Scenario ID: SCN-006
Title: Archive a link and restore it later
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

Each active link has an "Archive" action. Archiving removes the link from the
"All" and "To read" views and places it under an "Archived" tab, where it is
shown slightly dimmed. Archiving also clears any "read later" mark (the client is
done with it). Archived links remain searchable within the Archived tab and can
be restored to "All" at any time via a "Restore" action. The client confirmed
archive means "keep it out of the way but recoverable."

## Gherkin
Feature: Archive a link

  Scenario: Archive an active link
    Given an active link (shown under "All")
    When the client archives it
    Then it no longer appears under "All" or "To read"
    And it appears under the "Archived" tab
    And its "read later" mark, if any, is cleared

  Scenario: Restore an archived link
    Given a link is archived
    When the client restores it
    Then it appears again under "All"
    And it no longer appears under "Archived"

  Scenario: Archived links are searchable within the Archived tab
    Given the client is on the "Archived" tab
    When the client searches for a word in an archived link
    Then that archived link is shown

## Assumptions
- "All" and "To read" views show non-archived links only.
- Archiving clears the "read later" mark.
- Archived links are retained and restorable (not deleted).
