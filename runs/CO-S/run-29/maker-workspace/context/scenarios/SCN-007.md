Scenario ID: SCN-007
Title: Add a later bookmark to an existing collection
Type: Edge Case
Approval status: approved
Approval session: SESSION-007
Approval cycle: 1

## Approved behaviour
A bookmark can be saved without immediately assigning it to a named collection and organized later. Using the same bookmark-selection interaction, the user can select a later bookmark, choose to organize it, select an existing collection, and add it there. The bookmark then appears alongside the collection’s existing bookmarks, the collection count increases, and a clear confirmation is shown.

## Gherkin
Feature: Adding bookmarks to existing collections

  Scenario: Add a later bookmark to an existing collection
    Given “Web development” contains “MDN Web Docs” and “CSS-Tricks”
    And “web.dev Performance” is saved outside that collection
    When the user selects “web.dev Performance”
    And chooses to organize the selected bookmark
    And chooses the existing “Web development” collection
    And adds the bookmark to that collection
    Then “web.dev Performance” is shown alongside the other bookmarks in “Web development”
    And the “Web development” count changes from 2 to 3 bookmarks
    And a confirmation says it was added to “Web development”

## Assumptions
- A bookmark can be saved before it is placed in a named collection.
- The same selection-based organization interaction is used for new and existing collections.
