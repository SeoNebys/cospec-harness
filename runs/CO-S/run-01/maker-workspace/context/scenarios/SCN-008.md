Scenario ID: SCN-008
Title: Delete a saved link instantly, with a brief Undo safety net
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Each saved link has a delete (trash) control. Clicking it removes the link
immediately — no per-item confirmation dialog. A brief "Deleted … — Undo" bar
appears for a few seconds; clicking Undo restores the link exactly where it was.
If the client does nothing, the bar fades and the deletion stands. Deleting all
links returns to the empty state (SCN-005). Client's rationale: clearing out old
links is frequent, so per-deletion confirmation would be tedious; the few-second
Undo is a sufficient safety net (rejected: confirm-before-every-delete).

## Gherkin
Feature: Deleting a saved link

  Scenario: Instant delete with undo available
    Given the client has saved links
    When the client clicks delete on a link
    Then the link is removed immediately
    And an "Undo" option appears for a few seconds

  Scenario: Undo a deletion
    Given a link was just deleted and the Undo option is showing
    When the client clicks Undo
    Then the link is restored to its previous position

  Scenario: Deletion stands after the undo window
    Given a link was just deleted
    When the client does not click Undo within the window
    Then the Undo option disappears and the link stays deleted

## Assumptions
- Undo window is a few seconds (exact duration a Phase 2 detail).
- Delete is per-link; no multi-select delete in this version (not requested).
- Deleting the last link shows the empty state.
