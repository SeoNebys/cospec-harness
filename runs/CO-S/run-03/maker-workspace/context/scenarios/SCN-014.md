Scenario ID: SCN-014
Title: Start new bookmarks as unread
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A newly saved bookmark starts as unread and immediately contributes to the
unread count, reflecting that saved links are usually intended for later. Its
labelled status action allows it to be marked read immediately when needed.

## Gherkin
Feature: Default bookmark status

  Scenario: Save a new bookmark
    Given a valid new web address is ready to save
    When the person saves the bookmark
    Then the bookmark starts as unread
    And the unread count increases
    And the bookmark offers a labelled action to mark it read

## Assumptions
- All newly saved bookmarks default to unread.
- The person can change the status immediately after saving.
