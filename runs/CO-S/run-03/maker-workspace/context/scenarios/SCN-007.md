Scenario ID: SCN-007
Title: Keep and view an unread pile
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Each bookmark has a clearly labelled action that changes between marking it
unread and marking it read, making both the current state and next action clear.
The unread count updates immediately. Choosing the unread view shows only unread
bookmarks, where an item can also be marked read to remove it from that pile.

## Gherkin
Feature: Read-later bookmarks

  Scenario: Mark a bookmark unread
    Given an existing bookmark is read
    When the person marks it unread using its labelled status action
    Then the bookmark is visibly identified as unread
    And its status action offers to mark it read
    And the unread count increases

  Scenario: View only unread bookmarks
    Given one bookmark is unread and other bookmarks are read
    When the person chooses the unread view
    Then only the unread bookmark is shown

  Scenario: Mark a bookmark read from the unread view
    Given an unread bookmark is shown in the unread view
    When the person marks it read
    Then it is removed from the unread view
    And the unread count decreases

## Assumptions
- Existing bookmarks used in this flow begin as read.
- A labelled status button appears on each bookmark.
- The unread view is available above the bookmark list.
