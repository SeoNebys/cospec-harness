# Privacy and persistence evidence

The ownership matrix returns enumeration-safe `404` outcomes for foreign bookmarks, tags, collections, saved searches, and reports foreign bulk IDs only as `not_found`. Restart coverage reopens an authenticated bookmark from the same persisted database. Version tests reject stale bookmark, tag, collection, and saved-search writes; desktop and phone journeys show a conflict dialog while retaining unsaved bookmark input. Existing recovery tests verify generic responses, single-use reset tokens, and session revocation.
