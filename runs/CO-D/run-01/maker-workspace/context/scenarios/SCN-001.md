Scenario ID: SCN-001
Title: Save a recognizable bookmark with reviewed details
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A person pastes a web address into the prominent add field and asks to add it. Before saving, the app shows the page title, description, site name, site icon, and picture that it gathered automatically. The title and description can be edited directly during this review, while the site identity and picture remain automatically supplied. Saving creates a recognizable bookmark card that retains any revised title and description.

## Gherkin
Feature: Save a bookmark with recognizable details

  Scenario: Review automatically gathered details before saving
    Given the personal bookmark collection is open
    When the person submits a web address to add
    Then the app shows a review containing the gathered page title, description, site name, site icon, and picture
    And the bookmark has not yet been saved

  Scenario: Revise the personal wording and save the bookmark
    Given the gathered bookmark details are open for review
    When the person changes the title and description and saves the bookmark
    Then a bookmark card is added to the collection
    And the card shows the revised title and description
    And the automatically supplied site name, site icon, and picture remain associated with it

## Assumptions
- Adding begins from one prominent web-address field at the top of the collection.
- Gathered details are reviewed before the bookmark is saved.
- The title and description are personal, editable wording.
- The site name, site icon, and picture are automatically supplied and not editable in this flow.
- The application is a personal web app and does not present a multi-user account or login flow.
