Scenario ID: SCN-013
Title: Import an existing pile of bookmarks at once, folders becoming labels
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The client can bring their whole existing bookmark pile in at once (in the real
app, by choosing their browser's exported bookmarks file) rather than re-adding
links one by one. On import:
- Each bookmark's folder path becomes labels, split into separate labels — a
  bookmark from "Recipes/Italian" arrives wearing both "recipes" and "italian"
  (never a combined "recipes/italian"). Old filing is preserved as labels, freed
  from single-folder prison.
- Duplicates already saved are skipped (the no-duplicate promise holds at the
  front door).
- Each imported link keeps its original saved date from the file; only links
  with no date fall back to the import date. This preserves the sense of "when"
  and keeps date sorting meaningful across the imported pile.
- A summary reports how many were added, skipped as duplicates, and ignored as
  non-links.

## Gherkin
Feature: Import bookmarks

  Scenario: Import a pile, converting folders to labels
    Given the client imports bookmarks that include folder paths
    When the import runs
    Then each bookmark is added with its folder path split into separate labels
    And a nested folder "Travel/Japan" becomes labels "travel" and "japan"

  Scenario: Duplicates are skipped on import
    Given the client already has a link that also appears in the import
    When the import runs
    Then that link is not added a second time
    And the summary reports it as skipped

  Scenario: Original dates are preserved
    Given an imported bookmark carries an original saved date
    When it is imported
    Then it keeps that original date rather than today's date
    And an imported bookmark without a date falls back to the import date

## Assumptions
- Real import reads the browser's exported bookmarks file; prototype simulates
  via paste / sample.
- Folder path is split on "/" into separate lowercase labels.
- Background summary/copy capture for imported links happens later (as for any
  saved link).
