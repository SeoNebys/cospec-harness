Title: Saving edge cases — incomplete address and unreadable page
Type: Error Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

While the entered address is not yet a valid link, saving is unavailable, so an
empty or broken entry cannot be saved by accident. When a valid address is
entered but the page's details cannot be read automatically (e.g. the page is
temporarily unreachable), the client is told the details couldn't be fetched and
that they can add a title themselves — and the link can still be saved. The
client explicitly wants a temporary page problem never to block keeping the
address. If the title is left blank in that case, it falls back to the site name.

## Assumptions

- Address validity is required before saving is possible.
- Failure to auto-read a page never blocks saving; manual entry is offered.
- A blank title falls back to the site name.
