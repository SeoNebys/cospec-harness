Scenario ID: SCN-004
Title: Find bookmarks with immediate plain search
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The library has a prominent search field. As the client types, the bookmark list immediately narrows without requiring a submit action. Matching is case-insensitive and searches across each bookmark's title, description, source site, original web address, and labels. The number of matching results is shown.

## Gherkin
Feature: Search across saved bookmarks

  Scenario: Narrow the library while typing
    Given the library contains bookmarks with different details and labels
    When the client types words into the search field
    Then the bookmark list immediately shows only bookmarks containing all of those words
    And no separate search submission is required
    And the matching result count is shown

  Scenario: Match any searchable bookmark detail without regard to capitalization
    Given a word appears in a bookmark's title, description, source site, original address, or labels
    When the client searches for that word using any capitalization
    Then the bookmark is included in the results

## Assumptions
- Multiple unquoted words all need to occur somewhere within the combined searchable bookmark details.
- Searchable personal bookmark notes are reserved for a later cycle because notes are not part of the current approved bookmark model.
- Quoted phrases and explicit include/exclude search expressions are reserved for later exploration.
