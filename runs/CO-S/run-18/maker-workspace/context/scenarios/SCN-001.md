Scenario ID: SCN-001
Title: Save a link with automatic page details
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A person pastes a valid web address into one prominent field and selects Save link. The app retrieves the page title and a short description, saves the bookmark, and shows it as a clean, scannable card containing the title, description, and web address.

## Gherkin
Feature: Saving bookmarks

  Scenario: Save a link and collect its page details
    Given the personal bookmark library is empty
    When the person enters a valid web address and chooses to save it
    Then the bookmark is saved without requiring the person to type its title or description
    And the saved bookmark is shown in the library
    And its card shows the collected title, short description, and web address

## Assumptions
- The app is a personal web app used in a computer browser.
- Saving is initiated with one prominent web-address field and a Save link button.
- The source page exposes a usable title and short description.
- Selecting the displayed title opens the original page.
