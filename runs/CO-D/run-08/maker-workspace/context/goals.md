# Cycle 1 goal

## Client statement

> Honestly, right now my bookmarks are a mess. I save links in my browser and in a few different places, and then I can never find anything again. They pile up into these huge folders and I forget why I even saved half of them.
>
> So what I'm hoping for is a proper home for all my links — one place where, when I paste in a web address, it actually saves it in a useful way. Ideally it would grab the page's title and a little description on its own, so I'm not staring at a wall of raw web addresses trying to remember what each one was.
>
> The big thing is being able to find things again later. I'd love to organize them with my own labels, and to be able to search through them and actually get results. And I've got two kinds of links, really — stuff I want to read later, and stuff I've already dealt with. I'd like to keep those straight so my "to read" pile doesn't get buried.
>
> That's the heart of it for me: save a link easily, have it look readable, and find it again when I need it.

## Confirmed clarification

> The one thing I'd add so it's really clear: those labels aren't just for looks — I want to be able to click a label and see only the links with that label, and I want search and labels to work together so I can really narrow things down. And when I go back to a saved link, tapping it should take me straight to the actual page.
>
> But the shape of it — one dependable home, paste-and-it-fills-itself, my own labels, real search, and keeping "to read" separate from "done" — that's what I'm after.

## Confirmed interface

> A web app would be perfect. I'd like to just open it in my browser on my computer and have it there whenever I need it. It's really just for me — I don't need other people logging in or sharing accounts. So something I open in the browser and it's my own personal collection of links.
