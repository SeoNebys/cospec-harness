Title: Find a bookmark from its web address
Type: Happy Path
Approval status: approved
Approval session: SESSION-011

## Approved behaviour
Live search also looks through each bookmark's web address without regard to capitalization. A person can find a bookmark from a remembered site name even when that text is not in the title, description, or personal note.

## Gherkin
Feature: Searching bookmarks

  Scenario: Find a bookmark by its source site
    Given a bookmark points to "developer.mozilla.org"
    When the person types "MOZILLA" into search
    Then that bookmark remains visible
    And bookmarks whose searchable details and address do not contain "mozilla" are hidden

## Assumptions
- Address text participates in the same case-insensitive live search as titles, descriptions, and notes.
