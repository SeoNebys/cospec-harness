Scenario ID: SCN-008
Title: Long text and large tag sets stay tidy
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The layout stays stable when content is extreme:
- A very long bookmark title is capped (shown up to two lines) so it is enough
  to recognize the item without one card growing huge and throwing off the even
  rhythm of the list.
- A very long/messy link address (e.g. with tracking parameters) is trimmed
  with an ellipsis on a single line rather than wrapping and bloating the card.
- When the user has accumulated many tags, the tag browser stays a compact,
  scrollable strip instead of spilling downward and pushing the list off
  screen. The user scrolls within the strip to reach all tags.

## Assumptions
- Two-line title cap is acceptable (client confirmed) — recognition over
  completeness.
- Long addresses are trimmed, not wrapped (client confirmed).
- Many tags stay in a scrollable strip rather than, e.g., showing only
  most-used tags (client confirmed this approach).
