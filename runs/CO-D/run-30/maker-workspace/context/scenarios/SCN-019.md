Scenario ID: SCN-019
Title: Recover clearly from a search with no matches
Type: Edge Case
Approval status: approved
Approval session: SESSION-019
Approval cycle: 1

## Approved behaviour

When live search finds no matching bookmarks, the cards are replaced by a clear No bookmarks found state and the result count shows zero. The app does not loosen or reinterpret the query to show unrelated items. The entered query and its clear control remain available, and clearing it immediately restores the full collection.

## Gherkin

Feature: Finding saved bookmarks

  Scenario: Search has no matches
    Given the collection contains saved bookmarks
    When the user enters a query that matches none of them
    Then no bookmark cards are shown
    And the result count shows zero results
    And a clear No bookmarks found message is shown
    And the query remains unchanged
    When the user clears the query
    Then the full collection is restored

## Assumptions

- Search does not silently broaden a query to produce approximate results.
