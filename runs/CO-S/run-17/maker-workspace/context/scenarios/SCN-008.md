Scenario ID: SCN-008
Title: Recover cleanly from bookmark saving problems
Type: Error Case
Approval status: approved
Approval session: SESSION-008
Approval cycle: 1

## Approved behaviour

Saving handles three common problems without losing the client's work or cluttering the library. An incomplete address stays in the field with a plain inline explanation of a complete address. If page details cannot be retrieved, the valid address is kept and the client can supply a required title and optional description. If the page was already saved, the app warns the client and shows the existing bookmark instead of creating another copy.

## Gherkin

Feature: Recover from bookmark saving problems

  Scenario: Reject an incomplete page address without clearing it
    Given the user has entered text that is not a complete page address
    When the user tries to save it
    Then no bookmark is created
    And the entered text remains in the address field
    And an inline message explains that a complete address starts with http:// or https://

  Scenario: Save recognizable details when page details are unavailable
    Given the user has entered a valid page address
    And the app cannot retrieve its title and description
    When the retrieval attempt finishes
    Then the valid address is retained
    And the user is told that page details could not be retrieved
    And the user can provide a required title
    And the user can provide an optional description
    And the bookmark can be saved with those details

  Scenario: Avoid creating a duplicate bookmark
    Given a bookmark with the entered page address already exists
    When the user tries to save the same address again
    Then no duplicate bookmark is created
    And the user is told that the page is already saved
    And the existing bookmark is shown

## Assumptions

- A usable page address begins with http:// or https://.
- A manually supplied title is required for recognizability; a description is optional.
- Page addresses uniquely identify duplicate bookmarks in this cycle.
