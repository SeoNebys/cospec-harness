Scenario ID: SCN-007
Title: Empty screens that welcome or reassure, never look like loss
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

The app distinguishes three kinds of "empty list" so the client never mistakes
an empty screen for lost data.

Day one (nothing ever saved):
- A friendly welcome: a bookmark icon, "Nothing saved yet", and a pointer to
  "＋ Add bookmark", plus the quiet promise "it'll live here where you can
  always find it".
- The search box is **hidden** until something is saved (nothing to search yet);
  it appears once the first bookmark exists. The client liked this "earn its
  place" behaviour and did not find the layout shift jarring.
- It welcomes and points; it does not over-explain.

Everything set aside (things exist but all are tucked away):
- The main list shows "Everything is tucked away in 🗂 Set aside — your main
  list is clear", reassuring the client *where* their stuff is rather than
  implying it is gone. Doubles as a reminder the tray is there to dig from.

No search/roundup results (things exist, none match the current query/label):
- A plain "Nothing to show for that." (per SCN-001's no-match behaviour).

## Gherkin

Feature: Empty states

  Scenario: First-ever visit
    Given the client has never saved anything
    Then a welcoming empty state points them to "Add bookmark"
    And the search box is not shown
    When the client saves their first bookmark
    Then the list and the search box appear

  Scenario: All items set aside
    Given every bookmark is set aside
    When the client views the main list
    Then a message says everything is tucked away in the set-aside tray
    And it does not read as data loss

  Scenario: No results for a query or roundup
    Given bookmarks exist in the main list
    When the current search or roundup matches none of them
    Then a plain "nothing to show" message is shown

## Assumptions

- The search box is shown only when at least one bookmark is saved.
- The three empty states are distinguishable by wording/visuals.
