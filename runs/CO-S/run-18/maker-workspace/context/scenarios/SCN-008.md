Scenario ID: SCN-008
Title: Return to an existing bookmark instead of duplicating it
Type: Edge Case
Approval status: approved
Approval session: SESSION-008
Approval cycle: 1

## Approved behaviour
When the person tries to save an address already in the library, the app creates no new bookmark and leaves the library count unchanged. It explains that the address was already saved, brings the existing bookmark into view, and temporarily highlights it.

## Gherkin
Feature: Preventing duplicate bookmarks

  Scenario: Save an address that already exists
    Given the library already contains a bookmark for a web address
    When the person tries to save the same web address again
    Then no new bookmark is created
    And the library count is unchanged
    And the app explains that the address was already saved
    And the existing bookmark is brought into view and temporarily highlighted

## Assumptions
- Duplicate detection compares web addresses.
- The existing bookmark and its saved information remain unchanged.
- The highlight is temporary and does not alter the bookmark.
