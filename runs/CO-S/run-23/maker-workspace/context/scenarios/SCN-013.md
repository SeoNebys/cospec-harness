Scenario ID: SCN-013
Title: Preserve saved state across visits while resetting search
Type: Edge Case
Approval status: approved
Approval session: SESSION-013
Approval cycle: 1

## Approved behaviour
The client confirmed that bookmarks, tags, edits, and read-later status must remain exactly as left after closing the browser and returning on another day. A search is temporary viewing state and should reset to the full collection rather than preserving partially entered text.

## Gherkin
Feature: Preserve bookmark collection

  Scenario: Return after closing the browser
    Given the user has saved and edited bookmarks, assigned tags, and set read-later status
    When the user closes the browser and returns on another day
    Then all bookmarks remain as saved
    And their tags and edits remain as saved
    And their read-later status remains as saved

  Scenario: Return after leaving a search active
    Given the user has entered a search term
    When the user closes the browser and later returns
    Then the search box is empty
    And the full collection is shown

## Assumptions
- Persisted state belongs to the single user of the app.
- Search text and filtered search results are temporary and are not persisted.
