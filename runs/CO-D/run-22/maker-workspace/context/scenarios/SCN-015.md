Scenario ID: SCN-015
Title: Search for a logical operator as literal text
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A person can enclose a logical operator word such as "and" in quotation marks to search for it as ordinary text rather than use it as an instruction. The result explains that the quoted word was interpreted literally.

## Gherkin
Feature: Precise bookmark search

  Scenario: Treat a quoted operator as ordinary text
    Given a bookmark contains the word "and" in its searchable information
    When the person searches for '"and"'
    Then bookmarks containing the literal word "and" appear
    And the word is not treated as a logical operator
    And the search interpretation explains that it is ordinary text

## Assumptions
- Quoting an entire operator word escapes its operator meaning.
- Literal operator matching retains the general capitalization-insensitive search behaviour.
