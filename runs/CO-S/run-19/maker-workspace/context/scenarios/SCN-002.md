Scenario ID: SCN-002
Title: Correct a bookmark's title or description
Type: Happy Path
Approval status: approved
Approval session: SESSION-002
Approval cycle: 1

## Approved behaviour

From the bookmark list, the client can choose Edit details on a bookmark. A side panel opens while the library remains visible. The client can correct the title or description and save the changes. The card immediately shows the corrected details and the app confirms that the update was saved.

## Gherkin

Feature: Correct bookmark details

  Scenario: Correct an inaccurate title and description
    Given a saved bookmark has an inaccurate title or description
    And the bookmark is visible in the library
    When the user chooses to edit the bookmark's details
    Then an editing panel opens beside the visible library
    When the user changes the title or description
    And saves the changes
    Then the bookmark card shows the corrected title and description
    And the app confirms that the details were updated

## Assumptions

- Title and description are the page details the user can correct in this flow.
- Editing uses a side panel and does not navigate away from the library.
- Saving the correction leaves the bookmark's web address, source, preview image, and saved time unchanged.
