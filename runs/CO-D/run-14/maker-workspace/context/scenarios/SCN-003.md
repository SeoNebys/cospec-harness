Scenario ID: SCN-003
Title: Reuse an existing tag while saving a bookmark
Type: Happy Path
Approval status: approved
Approval session: SESSION-003
Approval cycle: 1

## Approved behaviour
While reviewing a new bookmark, the client can type part of a tag name. Previously used tags that match without regard to letter case appear as suggestions beneath the tag field. Choosing a suggestion attaches that exact existing tag, and the tag is visible on the saved bookmark in the library.

## Gherkin
Feature: Tag bookmarks consistently

  Scenario: Choose a previously used tag from suggestions
    Given the tag "travel" has been used before
    And a new bookmark is being reviewed
    When the client types "tra" in the tag field
    Then "travel" is suggested beneath the field
    When the client chooses "travel" and saves the bookmark
    Then the new bookmark displays the existing "travel" tag
    And no differently capitalised copy of that tag is created

## Assumptions
- Tag suggestions are shown in a matching dropdown beneath the tag field while the client types; tags are not displayed as a permanently expanded tray.
- Matching ignores letter case.
- Tags are visible on bookmark entries in the library.
