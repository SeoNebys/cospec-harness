Scenario ID: SCN-013
Title: Very long titles and descriptions stay tidy
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When a saved link has a very long title (including a long unbroken string) or a long
description, the card wraps the text neatly within its bounds instead of overflowing or
breaking the layout. Long descriptions are limited to a few lines so cards stay uniform
and the list remains calm.

## Gherkin
Feature: Long content display

  Scenario: A card with a very long title
    Given a saved link has a very long title
    When it is shown in the list
    Then the title wraps within the card without overflowing or breaking the layout

  Scenario: A card with a long description
    Given a saved link has a long description
    When it is shown in the list
    Then the description is limited to a few lines so cards stay uniform

## Assumptions
- Long descriptions are clamped for display; the full text is preserved and shown in the
  editor.
