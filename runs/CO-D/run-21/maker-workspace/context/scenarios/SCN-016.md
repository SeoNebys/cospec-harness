Title: Saved searches (reusable dynamic views)
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A search can be saved for reuse and shown as a clickable chip. A saved search
remembers the search terms plus the Show (read status) and View (active/archived)
filters. It is created via a builder with: a "Search terms" field supporting the
full approved search syntax (exact phrases, AND/OR/NOT, parentheses); searchable
"Include tags" and "Exclude tags" pickers (existing tags, no syntax typing); and
Show/View selectors. On save, the free search terms are grouped and the tag
conditions are AND-ed to the whole, so included/excluded tags always apply to the
entire query. Applying a saved search restores the whole scope. Saved searches are
dynamic: because the filter re-runs live, a bookmark appears automatically when it
starts matching and disappears when it stops. Saved searches can be deleted
(confirmed) without affecting bookmarks.

## Gherkin
Feature: Saved searches

  Scenario: Build with tag pickers and search terms
    When the user creates a saved search with terms and include/exclude tag pickers
    Then the query groups the terms and applies the tag conditions to the whole
    And the user never types tag syntax manually

  Scenario: Apply restores the whole scope
    When the user clicks a saved search chip
    Then its search terms, Show filter, and View are all applied

  Scenario: Saved search is dynamic
    Given a saved search is active
    When a bookmark is edited so it now meets the conditions
    Then it appears in the results automatically
    And when it no longer meets them it disappears

  Scenario: Delete a saved search
    When the user deletes a saved search
    Then it is removed and bookmarks are unaffected

## Assumptions
- Include/Exclude pickers offer existing tags only; new tags aren't created here.
- Search terms support the full approved syntax; tags are AND-ed around them.
