Scenario ID: SCN-010
Title: Add a personal note to a bookmark
Type: Happy Path
Approval status: approved
Approval session: SESSION-010
Approval cycle: 1

## Approved behaviour
A person opens a roomy side-panel editor from a bookmark, writes a personal note, and saves it deliberately. Saving closes the editing space and returns focus to the bookmark card, where the personal note remains visibly attached and is clearly distinguished as the person's own context. A side panel is preferred over editing the note inline because notes may be longer.

## Gherkin
Feature: Remember why a bookmark mattered

  Scenario: Add a personal note from a bookmark
    Given a saved bookmark has no personal note
    When the person opens the bookmark's note editor
    Then a roomy side panel provides space to write the note
    When the person enters a note and explicitly saves it
    Then the side panel closes
    And the person returns to the bookmark card
    And the saved personal note is visibly attached to that card

## Assumptions
- The note is personal to the bookmark owner.
- Note changes require an explicit save.
- Saved notes are visible on their bookmark card.
