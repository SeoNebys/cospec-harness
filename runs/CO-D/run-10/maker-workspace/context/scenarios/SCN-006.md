Scenario ID: SCN-006
Title: Find bookmarks with live full-library search
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A search field remains visible above the library and narrows bookmark cards instantly as the user types. Search matches words across bookmark titles, descriptions, web addresses, and private personal notes. When a result matches somewhere other than its title, the card explains the source of the match without exposing private note text. Clearing the search empties the field, restores the full library, and changes the heading from Search results back to All bookmarks.

## Gherkin
Feature: Search the bookmark library

  Scenario Outline: Narrow the library from different bookmark information
    Given the library contains several bookmarks
    When the user types a word found in a bookmark's <source>
    Then the matching bookmarks appear immediately without a separate submit action
    And non-matching bookmarks are hidden
    And a non-title match identifies the matching source without revealing private note text

    Examples:
      | source        |
      | title         |
      | description   |
      | web address   |
      | personal note |

  Scenario: Clear a search
    Given the library is narrowed by a search
    When the user clears the search field
    Then the search field is empty
    And all bookmarks are shown
    And the library heading is All bookmarks

## Assumptions
- Search is case-insensitive.
- Search is always available above the library.
- Personal-note text remains hidden on cards even when it produces a match.
