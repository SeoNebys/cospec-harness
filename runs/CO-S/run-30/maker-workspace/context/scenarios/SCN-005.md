Scenario ID: SCN-005
Title: Filter the library by a personal label
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The client's personal labels remain visible in a sidebar beside the bookmark list. Selecting a label narrows the library to bookmarks carrying that label, hiding bookmarks outside the selected group. The displayed bookmark count reflects the filtered result.

## Gherkin
Feature: Filtering bookmarks by label

  Scenario: Show bookmarks carrying one selected label
    Given the library contains bookmarks with overlapping personal labels
    And the labels are visible in a sidebar beside the library
    When the client selects one label
    Then only bookmarks carrying that label are shown
    And bookmarks without that label are hidden
    And the visible bookmark count is updated

  Scenario: Return to the complete library
    Given the library is filtered by a label
    When the client selects all bookmarks
    Then every bookmark is shown
    And the full bookmark count is restored

## Assumptions
- Selecting one label filters by that label.
- Label navigation remains visible in a sidebar on the desktop web app.
- The sidebar includes a way to return to all bookmarks.
