Scenario ID: SCN-018
Title: Browse and search a large bookmark library
Type: Edge Case
Approval status: approved
Approval session: SESSION-018
Approval cycle: 1

## Approved behaviour
When the library has grown large, the app initially presents a manageable set of recently saved bookmarks. Choosing Show older bookmarks appends more cards to the same list so browsing can continue without moving between numbered pages. Search and tag filtering always consider the entire relevant library, including bookmarks not currently displayed.

## Gherkin
Feature: Large bookmark libraries

  Scenario: Reveal older bookmarks in the same list
    Given the library contains more bookmarks than are initially shown
    When the person chooses Show older bookmarks
    Then an older set of bookmark cards is appended to the current list
    And the cards already shown remain in place

  Scenario: Search across bookmarks not currently displayed
    Given the library contains bookmarks beyond the initially shown set
    When the person searches or filters by tag
    Then matching bookmarks are considered across the entire relevant library
    And results are not limited to cards that were already displayed

## Assumptions
- Recently saved bookmarks appear first.
- Older bookmarks are revealed in manageable batches.
- Search and filtering do not require the person to reveal older batches first.
