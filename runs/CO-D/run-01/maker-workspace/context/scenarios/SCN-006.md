Scenario ID: SCN-006
Title: Search all saved bookmark information
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The collection has a prominent search field that filters bookmarks immediately as the person types, without a separate submit action. Matching searches the saved title, description, web address, site name, labels, and personal note. Matching does not depend on capitalization, and the result count and visible cards update to reflect the query.

## Gherkin
Feature: Search bookmarks

  Scenario: Find a bookmark using any saved information
    Given bookmarks contain titles, descriptions, web addresses, site names, labels, and personal notes
    When the person types a search term found in any of those fields
    Then matching bookmarks remain visible as the person types
    And non-matching bookmarks are hidden
    And the result count reflects the visible matches

  Scenario: Search without regard to capitalization
    Given saved bookmark information contains a word
    When the person searches for that word using different capitalization
    Then the same bookmarks match each capitalization

## Assumptions
- Search updates on every input change and has no separate submit button.
- Search covers saved bookmark information, not the full text of the remote page.
- Matching is case-insensitive.
