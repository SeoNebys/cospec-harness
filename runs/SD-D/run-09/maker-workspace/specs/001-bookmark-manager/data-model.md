# Data Model: Bookmark Manager

**Feature**: 001-bookmark-manager | **Date**: 2026-09-18 | **Phase**: 1

Derives the persistent structures from the spec's Key Entities and Functional
Requirements. Storage is SQLite (`data/bookmarks.db`); snapshot binaries live on
disk under `data/snapshots/`. Dates are stored as ISO-8601 UTC strings unless
noted. IDs are opaque strings (e.g. ULIDs) generated by the app.

## Entity: Bookmark

The saved reference to a web page.

| Field              | Type        | Notes / Rules |
|--------------------|-------------|---------------|
| `id`               | string PK   | Generated on create. |
| `url`              | string      | Original address as entered/edited. Required. |
| `normalizedUrl`    | string      | Normalized form (Decision 9). **Unique** among non-deleted bookmarks; drives de-duplication (FR-005/006). |
| `title`            | string      | Auto-collected **and reviewed/edited before commit** (FR-002/003). Falls back to host/URL when the page can't be read promptly (FR-007). **Never modified by background jobs.** |
| `description`      | string      | Auto-collected and reviewed/edited before commit. May be empty. **Never modified by background jobs.** |
| `note`             | string      | Markdown source; rendered on view (FR-010). May be empty. |
| `faviconPath`      | string?     | Local path/URL to stored favicon; null if none. |
| `previewImagePath` | string?     | Local path/URL to stored preview (`og:image`); null if none. |
| `read`             | boolean     | `false` = unread/read-later. New bookmarks default `false` (FR-021). |
| `archived`         | boolean     | `true` hides from normal list & search (FR-022/023). Default `false`. |
| `snapshotType`     | enum        | `html` \| `pdf` \| `none`. Set when capture resolves. |
| `snapshotPath`     | string?     | Path under `data/snapshots/` (`<id>.html` or `<id>.pdf`); null until available. |
| `snapshotStatus`   | enum        | `pending` \| `available` \| `unavailable` (FR-029/031). |
| `webArchiveUrl`    | string?     | Internet Archive snapshot link; null until preserved (FR-030). |
| `metadataStatus`   | enum        | Outcome of the pre-commit collection: `collected` (page read) \| `fallback` (page unreadable promptly; fallback title used) (Decision 5). Informational only. |
| `dateAdded`        | datetime    | Set on create; preserved from import `ADD_DATE` (FR-020/026). |
| `dateUpdated`      | datetime    | Bumped on any edit; used by "last updated" sort (FR-018). |

**Validation**
- `url` MUST parse as a valid web address after normalization, else reject (FR-004).
- `normalizedUrl` uniqueness enforced by index; create against an existing value
  resolves to "open existing for edit" rather than insert (FR-006).
- `title` non-empty after save (fallback applied when metadata absent).

**State transitions**
- Read: `unread (read=false)` ⇄ `read (read=true)`.
- Archive: `active (archived=false)` ⇄ `archived (archived=true)` — reversible,
  never implies deletion (FR-022).
- Snapshot: `pending` → `available` (path + type set) | `unavailable`. Captured in
  the background; it writes only snapshot fields (and favicon/preview if still
  empty) and **never** `title`/`description` (Decision 11 no-overwrite rule).
- Metadata: resolved once, before commit — `collected` or `fallback`; not changed
  by background work.
- Deletion: hard delete removes the row, its tag links, and its snapshot file
  (FR-011). Distinct from archive.

## Entity: Tag

| Field   | Type      | Notes / Rules |
|---------|-----------|---------------|
| `id`    | string PK | Generated on create. |
| `name`  | string    | Unique, case-insensitive; trimmed; no leading `#`. |

- Many-to-many with Bookmark via `bookmark_tags`.
- Suggestions (FR-009) come from existing tag names, ranked by prefix match then
  usage count.
- May originate from an imported folder name (FR-026).
- A tag with zero remaining bookmarks may be pruned (housekeeping); not required
  for correctness.

### Join: bookmark_tags

| Field         | Type   | Notes |
|---------------|--------|-------|
| `bookmarkId`  | string FK → Bookmark(id), cascade delete |
| `tagId`       | string FK → Tag(id) |

Primary key `(bookmarkId, tagId)`.

## Entity: SavedFilter

A named, reusable view (FR-032).

| Field           | Type        | Notes / Rules |
|-----------------|-------------|---------------|
| `id`            | string PK   | Generated on create. |
| `name`          | string      | Required; unique per collection. |
| `query`         | string      | Search expression (may be empty). |
| `includeTags`   | string[]    | Tag names that MUST be present. |
| `excludeTags`   | string[]    | Tag names that MUST be absent. |
| `dateCreated`   | datetime    | |

- Applying a filter combines `query` (parsed per the search grammar) AND all
  `includeTags` AND NOT any `excludeTags`, over the current view.
- Editing/deleting a filter never affects bookmarks (FR-032).

## Entity: Snapshot (on-disk artifact)

Not a table of its own; represented by the Bookmark's `snapshotType`,
`snapshotStatus`, and `snapshotPath`. The stored file is:
- a **self-contained single HTML file** with inlined assets for web pages, or
- a **downloaded PDF** for PDF targets (FR-029).

Served read-only through the snapshot endpoint; deleted with its bookmark.

## Entity: DisplayPreferences

Single-row settings for the one user (FR-033).

| Field           | Type    | Notes / Rules |
|-----------------|---------|---------------|
| `defaultSort`   | enum    | `dateAdded_desc` \| `dateAdded_asc` \| `title_asc` \| `title_desc` \| `dateUpdated_desc`. |
| `itemsPerPage`  | integer | Bounded (e.g. 10–200); default 25. |
| `fontSize`      | enum    | `small` \| `medium` \| `large`. Default `medium`. |

Persisted; applied on load across reloads.

## Views (query-time, not stored)

- **All / normal**: `archived = false`, default. Searchable.
- **Unread / Read-Later**: `archived = false AND read = false` (FR-021).
- **Archived**: `archived = true`; searchable within this view only; excluded from
  the other two (FR-023).

Each view supports the search grammar, tag include/exclude, sorting (FR-018), and
pagination (`itemsPerPage`).

## Derived: search index inputs

For evaluation (Decision 4) each bookmark contributes:
- lower-cased concatenation of `title`, `description`, `note`, `url` (text terms &
  phrases match here, case-insensitively — FR-014);
- its set of tag names (matched by `#tag` tokens — FR-015).

## Relationships summary

```text
Bookmark 1───* bookmark_tags *───1 Tag
Bookmark 1───0..1 Snapshot(file)
SavedFilter references Tag names (include/exclude) by value, not FK
DisplayPreferences: singleton
```
