Scenario ID: SCN-007
Title: Delete a bookmark permanently
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

The user can delete a bookmark. Delete is a permanent removal, distinct from the
reversible Archive action: a deleted bookmark is removed from all views entirely.

## Gherkin

Feature: Delete a bookmark

  Scenario: Delete removes a bookmark entirely
    Given a saved bookmark
    When the user deletes it
    Then it is removed from all views
    And it does not appear in the Archived view

## Assumptions
- Delete is permanent removal, unlike Archive which is reversible.
