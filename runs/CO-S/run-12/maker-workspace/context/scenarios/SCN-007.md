Scenario ID: SCN-007
Title: Archive and restore a bookmark without losing it
Type: Happy Path
Approval status: approved
Approval session: SESSION-007
Approval cycle: 1

## Approved behaviour
The client can archive a bookmark directly from its collection card with one clearly labelled action. It immediately leaves the main collection, the main and Archive counts update, and a brief confirmation explains where it went. The Archive view retains the bookmark and all of its details. One explicit Restore to collection action returns it to the main collection and updates the counts again. Archiving is distinct from permanent deletion.

## Gherkin
Feature: Archive bookmarks without losing them

  Scenario: Archive a bookmark from the collection
    Given a bookmark is visible in the main collection
    When the user selects its Archive action
    Then the bookmark leaves the main collection
    And the main collection count decreases
    And the Archive count increases
    And a brief confirmation says that the bookmark moved to Archive

  Scenario: View an archived bookmark with its details intact
    Given a bookmark has been archived
    When the user opens Archive
    Then the archived bookmark is shown there
    And its saved image, site, title, description, tags, and note remain intact

  Scenario: Restore an archived bookmark
    Given a bookmark is visible in Archive
    When the user selects Restore to collection
    Then the bookmark returns to the main collection
    And it leaves Archive
    And the main collection and Archive counts update

## Assumptions
- Archive is available beside the main collection.
- Archive and permanent deletion are separate operations.
- The archive action uses explicit text directly on the collection card.
- Restoring retains all bookmark state and details.
