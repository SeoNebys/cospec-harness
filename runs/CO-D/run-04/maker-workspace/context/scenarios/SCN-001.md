Scenario ID: SCN-001
Title: Save a readable bookmark and reopen its website
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A person saves a bookmark by providing only the page's web address. The saved
item is made recognizable with the page icon, title, short description, and
website name. Selecting the bookmark itself opens the original website directly
in a new browser tab rather than opening an intermediate information page.

## Gherkin
Feature: Personal bookmark collection

  Scenario: Save a bookmark from a web address
    Given the personal bookmark collection is empty
    When the person saves a valid web address
    Then a bookmark is added to the collection
    And the bookmark shows the page icon, title, short description, and website name
    And the person was not required to enter any of those page details

  Scenario: Reopen a saved website
    Given a bookmark is visible in the collection
    When the person selects the bookmark item
    Then the original website opens directly in a new browser tab
    And no intermediate bookmark information page is shown

## Assumptions
- This is a personal web app used in a desktop browser.
- No account or login is required.
- The whole bookmark item is the target for opening the original website.
