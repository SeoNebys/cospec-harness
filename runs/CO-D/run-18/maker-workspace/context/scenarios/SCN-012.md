Scenario ID: SCN-012
Title: Keep long bookmark content intact behind compact card previews
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
An unusually long title is shortened after a couple of lines on the library card, a long description after a few lines, and a long formatted note fades out rather than stretching the card. This keeps the card grid tidy and scannable. Opening the bookmark for editing shows the full untrimmed title, complete description, and complete formatted note; shortening applies only to the library-card preview and never discards saved content.

## Gherkin
Feature: Display long bookmark content

  Scenario: Keep a library card compact when its content is unusually long
    Given a bookmark has an unusually long title, description, and formatted note
    When it is displayed in the library grid
    Then its title is shortened after a compact number of lines
    And its description is shortened after a compact number of lines
    And its note fades out within the card
    And the card does not expand to display all of the long content

  Scenario: Preserve complete long content for editing
    Given a library card displays shortened content
    When the user opens that bookmark for editing
    Then the full untrimmed title is available
    And the complete description is available
    And the complete formatted note is available

## Assumptions
- Compact shortening applies only to the library-card preview.
- Saved content is never truncated or discarded.
