## Approved behaviour
Settings covers display preferences in addition to sort default and preserved
copies:
- Items per page: 10, 25 (default), 50, 100, or All. The collection shows one
  page at a time with Prev / Next controls and a "Page X of Y" indicator; the
  pager is hidden when everything fits or "All" is chosen. Paging applies to the
  current search/filter/sort result, and changing search, filters, status, scope,
  or opening a saved view returns to page 1.
- Text size: Small / Medium (default) / Large, scaling the whole app uniformly.

Both preferences are remembered between visits (like the sort default).

## Gherkin
Feature: Display settings

  Scenario: Items per page with paging
    Given more bookmarks match than the items-per-page setting
    Then only one page is shown with Prev/Next and a page indicator
    And paging respects the current search, filters and sort

  Scenario: Change items per page
    When I set items per page in Settings
    Then the collection pages at that size
    And "All" shows everything with no pager

  Scenario: Change text size
    When I set text size in Settings
    Then the whole app scales to that size

  Scenario: Preferences persist
    Then items-per-page and text size are remembered on my next visit

## Assumptions
- Default items per page 25; default text size Medium.
- Changing any filter/search/sort/scope resets to page 1.
- Preferences persist per person (prototype uses browser local storage).
