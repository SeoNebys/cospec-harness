Scenario ID: SCN-018
Title: Require a title while allowing an empty description
Type: Edge Case
Approval status: approved
Approval session: SESSION-018
Approval cycle: 1

## Approved behaviour

A bookmark must have a non-empty title so that it remains recognizable, while its description may be empty. If the client tries to save corrected details without a title, the editor stays open, explains that a title is required, and leaves the existing saved bookmark unchanged. Once a title is provided, the correction can be saved even with an empty description.

## Gherkin

Feature: Correct bookmark details

  Scenario: Reject corrected details with no title
    Given a saved bookmark has existing details
    And the user has opened its details editor
    When the user clears the title
    And tries to save the changes
    Then the editor remains open
    And a message says that a title is required
    And the saved bookmark remains unchanged

  Scenario: Save a title with no description
    Given the user is editing a bookmark's details
    When the user enters a non-empty title
    And leaves the description empty
    And saves the changes
    Then the bookmark shows the new title
    And the bookmark has no description

## Assumptions

- Title is required for recognition and search.
- Description is optional.
