Scenario ID: SCN-012
Title: Clear feedback for an incomplete or invalid link
Type: Error Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

When the text entered in the link box is not yet a valid link, the app shows a
gentle notice that it doesn't look like a full link yet (a link usually starts
with https://), rather than pretending a page lookup was attempted and failed.
The Save action stays inactive until the input is a valid link. This is distinct
from SCN-002, where a valid link's page lookup fails.

## Gherkin

Feature: Save a link

  Scenario: Incomplete link shows guidance, not a false lookup failure
    Given the link box contains text that is not a valid link
    Then a gentle notice explains it doesn't look like a full link yet
    And no page-lookup-failed message is shown
    And the Save action is inactive

  Scenario: Save becomes available once the link is valid
    Given an incomplete link with the Save action inactive
    When the user completes it into a valid link
    Then the Save action becomes available

## Assumptions
- Invalid-link feedback is visually distinct from a failed page lookup (SCN-002).
