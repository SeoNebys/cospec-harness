Scenario ID: SCN-025
Title: Opening a bookmark's title goes to its original address
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Selecting (clicking) a bookmark's title opens the bookmark's original web
address. This is the basic navigation behaviour shown throughout the prototype.

## Gherkin
Feature: Open the original link

  Scenario: Open via title
    Given a saved bookmark
    When the client selects (clicks) its title
    Then the bookmark's original web address is opened

## Assumptions
- Opens the original live address (distinct from the app's preserved copy,
  SCN-020, and the Internet Archive copy, SCN-021).
