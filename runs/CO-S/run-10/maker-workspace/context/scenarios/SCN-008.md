Scenario ID: SCN-008
Title: Saving a link that is already saved (duplicate prevention)
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

When the client tries to save a link that is already saved (matched by its web
address, ignoring a leading "www." and a trailing slash), the app does not create
a second copy. Instead:
- If the existing copy is active: the app shows "You already saved this link,"
  briefly highlights the existing copy, and offers an "Edit this bookmark →"
  action that opens that bookmark's tag/note editor directly (so the client can
  add a tag or note, which is the common reason for re-saving).
- If the existing copy is archived: the app shows "You already saved this — it's
  in your Archived list," switches to the Archived tab, and highlights it. It is
  not auto-restored and no edit shortcut is offered; the client decides whether to
  restore it there.

The client confirmed this prevents duplicates while making it easy to update the
existing bookmark, and that archived links remain under their control.

## Gherkin
Feature: Duplicate prevention when saving

  Scenario: Re-saving an active link offers editing it
    Given a link is already saved and active
    When the client saves the same web address again
    Then no second copy is created
    And the app indicates the link is already saved
    And the existing copy is highlighted
    And the client is offered a direct action to edit that bookmark

  Scenario: Re-saving an archived link points to it in Archive
    Given a link is already saved and archived
    When the client saves the same web address again
    Then no second copy is created
    And the app indicates it is already saved in the Archived list
    And the Archived tab is shown with the existing copy highlighted
    And the link is not automatically restored

## Assumptions
- Duplicate matching normalises the address: lower-cased, "www." and a trailing
  slash ignored; path and query otherwise significant.
- The common reason for re-saving an active link is to add/adjust tags or a note.
