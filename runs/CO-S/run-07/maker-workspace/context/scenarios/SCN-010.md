Scenario ID: SCN-010
Title: Confirm before removing a bookmark
Type: Happy Path
Approval status: approved
Approval session: SESSION-010
Approval cycle: 1

## Approved behaviour
Selecting Remove on a bookmark does not immediately delete it. The app asks for confirmation and explains that the bookmark will leave the library and Read later. Confirming permanently removes that bookmark from both views while leaving every other bookmark and their tags untouched. Choosing to keep it cancels the removal.

## Gherkin
Feature: Remove a saved bookmark

  Scenario: Confirm removal of a bookmark
    Given the library contains a saved bookmark
    When the user selects Remove on that bookmark
    Then the app asks the user to confirm the removal
    And explains that the bookmark will leave the library and Read later
    When the user confirms the removal
    Then the bookmark is removed from the library
    And it is removed from Read later
    And other bookmarks and their tags remain unchanged

  Scenario: Cancel removal of a bookmark
    Given the app is asking the user to confirm a bookmark's removal
    When the user chooses to keep the bookmark
    Then the confirmation closes
    And the bookmark remains unchanged in the library

## Assumptions
- Removal is permanent after confirmation and does not offer a subsequent Undo action.
- A tag used by the removed bookmark remains available when it is also used by another bookmark.
