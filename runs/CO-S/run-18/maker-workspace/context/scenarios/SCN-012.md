Scenario ID: SCN-012
Title: Reject an incomplete or malformed web address
Type: Error Case
Approval status: approved
Approval session: SESSION-012
Approval cycle: 1

## Approved behaviour
When the person tries to save text that is not a complete valid web address, no bookmark is created and the library remains unchanged. A clear inline message gives an example of a complete address, and focus returns to the address field for immediate correction.

## Gherkin
Feature: Validating bookmark addresses

  Scenario: Attempt to save an invalid address
    Given the person has entered an incomplete or malformed web address
    When the person chooses Save link
    Then no bookmark is created
    And the library count remains unchanged
    And an inline message shows an example of a complete web address
    And the address field is ready for correction

## Assumptions
- A complete address includes a supported web scheme and host.
- The invalid value remains visible so the person can correct it.
