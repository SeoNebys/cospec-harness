Scenario ID: SCN-013
Title: Reject an unusable web address inline
Type: Error Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When entered text is not a complete usable web address, saving is blocked. The app preserves the entered text and shows a gentle inline explanation beside the field, including an example of a complete address, so the person can correct it without dismissing a pop-up or starting over.

## Gherkin
Feature: Validate a bookmark address

  Scenario: Submit text that is not a usable web address
    Given the add-bookmark field contains text that is not a complete HTTP or HTTPS address
    When the person tries to add it
    Then no bookmark is saved
    And the entered text remains in the field
    And an inline message explains the expected address with an example

## Assumptions
- Saved destinations use HTTP or HTTPS addresses.
- The validation message clears as the person corrects the entry.
