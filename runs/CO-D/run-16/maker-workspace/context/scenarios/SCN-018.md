Scenario ID: SCN-018
Title: Sort bookmarks by date added or title
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A sort control offers four choices: Newest first, Oldest first, Title A–Z, and
Title Z–A. The default is Newest first. Sorting reorders whatever is currently
shown — it applies within the selected tab and to the current search results —
rather than being a separate view.

## Gherkin
Feature: Sorting

  Scenario Outline: Reorder the current view
    Given bookmarks are shown in a tab and/or search
    When the client selects sort "<sort>"
    Then the shown bookmarks are reordered by <criterion>

    Examples:
      | sort          | criterion                    |
      | Newest first  | date added, most recent first |
      | Oldest first  | date added, oldest first      |
      | Title A–Z     | title ascending               |
      | Title Z–A     | title descending              |

  Scenario: Sort respects current filter
    Given a tab and/or search filter is active
    When the sort is changed
    Then only the currently shown bookmarks are reordered (filter unchanged)

## Assumptions
- Default sort is Newest first.
- Title sort uses the displayed title (falling back to the address if untitled),
  case-insensitively.
