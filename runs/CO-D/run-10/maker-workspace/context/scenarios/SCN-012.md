Scenario ID: SCN-012
Title: Finish an empty Read later list with a useful next step
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When no bookmarks remain in Read later, the view shows a positive Nothing waiting for you state with a checkmark, explains that the list is clear, reminds the user that bookmark clocks refill it, and offers Browse all bookmarks. Choosing that action returns to the full library.

## Gherkin
Feature: Empty Read later list

  Scenario: The final Read later item is marked as read
    Given exactly one bookmark remains in Read later
    When the user marks that bookmark as read
    Then no bookmark cards remain in the view
    And the app positively confirms that the reading list is clear
    And explains how bookmarks can be added again
    And offers an action to browse all bookmarks

  Scenario: Return from an empty Read later list
    Given the Read later list is empty
    When the user chooses Browse all bookmarks
    Then the full bookmark library is shown

## Assumptions
- An empty Read later list is a successful completion state, not an error.
