Scenario ID: SCN-005
Title: Add and remove multiple labels on a bookmark
Type: Happy Path
Approval status: approved
Approval session: SESSION-005
Approval cycle: 1

## Approved behaviour
Labels are managed in the same edit view as a bookmark's other details. As the
person types, matching existing labels are suggested to avoid near-duplicate
labels. A bookmark can carry more than one label and appears under each of them.
Chosen labels appear as removable chips. Removing one label preserves the other
labels and updates the sidebar counts.

## Gherkin
Feature: Organize a bookmark with labels

  Scenario: Add multiple existing labels
    Given existing labels include "Work" and "Recipes"
    And a bookmark is open for editing
    When the person types part of an existing label name
    Then the matching existing label is suggested
    When the person chooses "Work" and "Recipes" and saves the changes
    Then the bookmark carries both labels
    And the bookmark is included under either label
    And both sidebar label counts include the bookmark

  Scenario: Remove one of several labels
    Given a bookmark carries the labels "Work" and "Recipes"
    When the person removes "Recipes" and saves the changes
    Then the bookmark still carries "Work"
    And the bookmark no longer carries "Recipes"
    And the sidebar counts reflect the removal

## Assumptions
- Labels are managed in the established bookmark edit view.
- Matching existing labels are suggested while typing.
- Chosen labels are represented as individually removable chips.
