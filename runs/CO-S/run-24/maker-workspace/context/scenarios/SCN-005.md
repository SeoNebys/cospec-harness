Scenario ID: SCN-005
Title: Find a saved link by searching and filtering by tag
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

The user finds a link again using a search box and tag filtering, which can be
combined.

Search: as the user types, the collection narrows to links matching all the typed
words. A match is found if the word appears in any of the link's title,
description, tags, full web address, or the user's note. Matched text is
highlighted in the results. A clear (×) empties the search.

Tag filtering: clicking a tag chip on any card filters the collection to links
carrying that tag. Active tag filters appear as removable pills below the search
box, with a "Clear" to remove all. Multiple tag filters combine (a link must
carry all active tags).

Combination: search words and tag filters apply together (AND). Filtering also
works within the Reading list view.

No results: when nothing matches, a plain message ("No links match …, try fewer
words or clearing a filter") is shown instead of an empty screen.

## Gherkin
Feature: Find a link

  Scenario: Search across all of a link's text
    Given saved links
    When the user types a word in the search box
    Then only links whose title, description, tags, web address or note contain
         that word remain
    And the matching text is highlighted

  Scenario: Search requires all words
    Given the user types two words
    Then only links containing both words remain

  Scenario: Filter by clicking a tag
    When the user clicks a tag on a card
    Then only links carrying that tag remain
    And the active tag filter is shown as a removable pill

  Scenario: Combine search and tag filter
    Given a tag filter is active
    When the user also types a search word
    Then only links matching both the tag and the word remain

  Scenario: No matches
    Given a search or filter that nothing matches
    Then a clear "no matches" message is shown, not an empty screen

## Assumptions
- Search is case-insensitive, substring, whitespace-separated words combined with AND.
- Tag filters combine with AND; multiple tags allowed.
- Search + tag filters compose, and apply within the current view (All / Reading list).
- Results keep newest-first ordering.
