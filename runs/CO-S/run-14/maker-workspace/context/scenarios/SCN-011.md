Scenario ID: SCN-011
Title: Edit a bookmark's title and description later
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

Every saved bookmark has an **"✎ edit"** control next to its title. Using it
turns the title into an editable field and the description into an editable box,
with a **Done** button to save the changes. This lets the user correct or improve
the automatically gathered title and description at any time (this is the same
editable state reached from the duplicate notice in SCN-009 and from the
missing-details fallback in SCN-010).

## Gherkin
Feature: Edit title and description

  Scenario: Edit a bookmark's title and description
    Given a saved bookmark is shown
    When the user activates its edit control and changes the title and/or description
    And presses Done
    Then the bookmark shows the updated title and description

## Assumptions
- Title and description are freely editable text.
