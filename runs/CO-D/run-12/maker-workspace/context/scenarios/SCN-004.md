Scenario ID: SCN-004
Title: Find bookmarks using any remembered words
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
As the user types, the collection immediately narrows to bookmarks whose title, description, personal note, or full web address contains the entered words. Results remain normal bookmark cards in newest-first order and do not add an explanation of which field matched.

## Gherkin
Feature: Finding bookmarks

  Scenario Outline: Narrow bookmarks using remembered words
    Given the collection contains bookmarks with titles, descriptions, personal notes, and web addresses
    When the user types a word found only in a bookmark's <field>
    Then the results immediately narrow to include that bookmark
    And the result is displayed as its normal bookmark card
    And no field-match explanation is added to the card

    Examples:
      | field         |
      | title         |
      | description   |
      | personal note |
      | web address   |

  Scenario: Keep multiple search results in collection order
    Given multiple bookmarks contain the user's search words
    When the user types those words
    Then all matching bookmarks are shown
    And they remain ordered newest first

## Assumptions
- Search updates while the user types without a separate search action.
- Search considers the full saved web address, not only the displayed site name.
- Matching is presented without identifying the matching field.
