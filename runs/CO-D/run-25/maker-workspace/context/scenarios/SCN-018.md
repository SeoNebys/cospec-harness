Scenario ID: SCN-018
Title: Search for a command word as literal text
Type: Happy Path
Approval status: approved
Approval session: SESSION-018
Approval cycle: 1

## Approved behaviour
Putting a search command word inside quotation marks treats it as literal searchable text rather than an operator. A quoted single word matches that whole word and does not match the same letters embedded inside a longer word.

## Gherkin
Feature: Combining bookmark searches

  Scenario: Search for the literal word and
    Given two bookmarks contain the standalone word "and"
    And another bookmark contains "advanced" but not the standalone word "and"
    When the person searches for "\"and\""
    Then the two bookmarks containing the standalone word are shown
    And the bookmark containing only "advanced" is hidden

## Assumptions
- Quoted literal-word and exact-phrase matching ignores capitalization.
