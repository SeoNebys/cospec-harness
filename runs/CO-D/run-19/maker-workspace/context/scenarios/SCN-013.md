Scenario ID: SCN-013
Title: Keep empty and incomplete searches helpful
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A search with no matches shows a calm Nothing found state and suggests changing or clearing the search. An opening quotation mark without a closing mark is treated as unfinished typing: useful partial matches remain visible and a gentle prompt explains how to complete exact-phrase searching.

## Gherkin
Feature: Recover from searches that cannot yet produce final results

  Scenario: Search returns no matches
    Given the library contains bookmarks
    When the client searches for text that matches none of them
    Then a Nothing found state is shown instead of a blank or error screen
    And the client is prompted to change or clear the search

  Scenario: Search contains an unclosed quotation mark
    Given the client has started a quoted search phrase
    When the closing quotation mark has not yet been typed
    Then useful partial matches remain visible
    And the client is gently prompted to finish the quotation mark
    And the input is not treated as a broken search

## Assumptions
- Clearing the search immediately restores the current destination's full unfiltered list.
