Scenario ID: SCN-024
Title: Show bookmarks in pages with a chosen page size
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

The list shows a chosen number of bookmarks per page (5 / 10 / 25 / 50 / All).
When there are more results than the page size, a **"Showing X–Y of N"** count and
**Prev / Next** paging controls appear; when everything fits (or "All" is chosen),
no pager is shown. Paging works together with the current view, filters and sort.
If the current page falls out of range (e.g. after deleting items), it is clamped
to a valid page.

## Gherkin
Feature: Paged list

  Scenario: Page through results
    Given there are more bookmarks than the page size
    Then only one page is shown at a time with a count and Prev/Next controls
    And Next/Prev move between pages

  Scenario: All on one page
    When the page size is "All" (or results fit in one page)
    Then no pager is shown

  Scenario: Page clamped after changes
    Given the user is on the last page
    When items are removed so fewer pages remain
    Then the shown page is clamped to a valid page

## Assumptions
- Page size is a display preference (SCN-023).
- Paging applies after view/filter/sort.
