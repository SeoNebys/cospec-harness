Scenario ID: SCN-014
Title: Narrow search with phrases, labels, exclusions, and either-or groups
Type: Happy Path
Approval status: approved
Approval session: SESSION-014
Approval cycle: 1

## Approved behaviour
Guided search controls let the person combine remembered wording with labels and an excluded source without memorizing special syntax. An exact phrase, a chosen label, and a site exclusion can be combined so every requirement must be satisfied. Within a label group, the person can instead choose to match any selected label, such as Design or Reference; a bookmark matching either is included. Exact phrases and exclusions can still narrow that either-or label group further.

## Gherkin
Feature: Refine bookmark search

  Scenario: Combine an exact phrase, required label, and excluded site
    Given the library contains bookmarks with different text, labels, and source sites
    When the person enters the exact phrase "keyboard navigation"
    And chooses the label "Design"
    And excludes "css-tricks.com"
    Then only bookmarks satisfying all three conditions are shown

  Scenario: Match any of several labels
    Given one bookmark is labeled "Design"
    And another bookmark is labeled "Reference"
    And a third bookmark is labeled "Books"
    When the person selects "Design" and "Reference" in the label group
    And chooses to match any selected label
    Then the Design bookmark is shown
    And the Reference bookmark is shown
    And the Books bookmark is not shown

  Scenario: Further narrow an either-or label group
    Given a search matches bookmarks labeled "Design" or "Reference"
    When the person also supplies an exact phrase or excludes a site
    Then the phrase and exclusion further narrow the combined label results

## Assumptions
- Guided controls are the default everyday interaction.
- People do not need to remember search operators or punctuation.
- Conditions outside an either-or label group must all match.
- A label group can be switched between matching any selected label and all selected labels.
