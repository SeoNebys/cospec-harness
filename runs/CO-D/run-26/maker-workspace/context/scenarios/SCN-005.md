Scenario ID: SCN-005
Title: Browse a topic by tag, from a tag bar or from a card, combined with search
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The client can browse the collection by tag in two complementary ways that are
both available at once:
- A "Browse by tag" bar above the list shows every tag in alphabetical order,
  each with a count of how many bookmarks carry it. Clicking a tag browses it.
- Clicking a tag chip on any bookmark card browses that same tag ("more like
  this").

When a tag is being browsed, the list shows only bookmarks carrying that tag, and
a banner names the active tag with a way to clear it. Browsing a tag combines with
any active search: only bookmarks that satisfy both the search and the tag are
shown, and both the search text and the active tag stay visible so the client
understands why those results appear. Clearing either the tag or the search
widens the results accordingly.

## Gherkin
Feature: Browse by tag

  Scenario: Browse a tag from the tag bar
    Given the collection contains bookmarks with tags
    And the tag bar lists all tags alphabetically with counts
    When the client clicks a tag in the tag bar
    Then only bookmarks carrying that tag are shown
    And a banner names the active tag with a way to clear it

  Scenario: Browse a tag by clicking it on a card
    When the client clicks a tag chip on a bookmark card
    Then only bookmarks carrying that tag are shown
    And the active tag is indicated with a way to clear it

  Scenario: Tag browsing combines with search
    Given a search is active
    When the client also browses a tag
    Then only bookmarks matching both the search and the tag are shown
    And both the search text and the active tag remain visible
    When the client clears the tag or the search
    Then the results widen accordingly

## Assumptions
- Tags are listed alphabetically with counts (client-confirmed over most-used-first).
- Both browsing gestures (bar and card chip) are available together (client-confirmed).
- The active tag is a single tag at a time in this cycle.
