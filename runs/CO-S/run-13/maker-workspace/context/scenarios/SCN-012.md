Scenario ID: SCN-012
Title: Long text and many tags wrap neatly within a card
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

A bookmark with an unusually long title, description, note, and web address, and a
large number of tags, displays with all content wrapping inside its card. Nothing
overflows the card or breaks the surrounding layout; long unbroken strings (like a
long address) wrap rather than forcing horizontal scrolling.

## Gherkin
Feature: Robust card layout

  Scenario: Very long content and many tags
    Given a bookmark with very long title, description, note, address, and many tags
    When it is shown in the list
    Then all its content wraps within the card
    And the layout does not overflow or break

## Assumptions
- Long unbroken strings are wrapped/broken to fit the card width.
- There is no fixed limit on the number of tags shown on a card.
