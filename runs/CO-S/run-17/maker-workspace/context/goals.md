# Cycle 1 goal

## Client statements (verbatim)

> Honestly, right now my bookmarks are just a messy pile in my browser — a long list of links where I can barely remember what any of them were or find the one I need later. So the big things I'd want to be different:
>
> - When I paste in a link, the app should grab the page's title and a short description on its own, so I'm not staring at a bunch of cryptic web addresses. I'd like to tweak that title or description if it's off.
> - I want to organize things with tags and then quickly narrow down to, say, everything tagged "recipes."
> - Real search that actually looks inside the titles, descriptions, and my own notes — not just an exact match on the address.
> - A way to mark things as "read this later" and see just those, then check them off once I've read them.
> - Clicking an item should take me to the actual page.
>
> Basically, today saving a bookmark means losing it. I want to be able to save something and actually find and revisit it later without digging. That's the core of it for me.

> Yes, that's the right direction — that captures the heart of it well.
>
> One thing I'd add so it's clear: when I say organize, I don't just want to slap tags on things. I want tags to actually help me find stuff — like being able to jump to just one tag's links, and having the app suggest tags I've already used so I don't end up with "recipe," "recipes," and "cooking" all meaning the same thing.
>
> But yes, recognizable, organizable, searchable, a read-later list, and quick to get back to the real page — with the ability to fix what got pulled in automatically. That's what I'm after.

> A web app makes the most sense to me — something I can open in my browser on my computer. That's where I run into most of my links anyway, so being able to just pull it up in a browser tab is what I picture.
>
> It's really just for me, so I'm not worried about accounts for other people or anything fancy like that.

## Confirmed goal

Today saving a bookmark means losing it. I want to be able to save something and actually find and revisit it later without digging. Bookmarks should be recognizable, organizable, searchable, usable as a read-later list, and quick to get back to the real page, with the ability to fix what got pulled in automatically. Tags should actually help me find stuff, including jumping to one tag's links and suggesting tags I've already used so I don't end up with different tags that all mean the same thing.

## Confirmed interface and audience

A web app opened in a browser on the client's computer. It is for the client alone; accounts for other people are outside the current goal.
