# Data Model: Bookmark Manager

**Date**: 2026-09-16  
**Storage**: SQLite with foreign keys and transactional writes

All persisted timestamps are UTC RFC 3339 values. Primary identifiers are opaque UUID strings generated by the application. User-owned rows always carry or join through a user identifier; repository methods require the current user identifier rather than accepting an unscoped lookup.

## User

Represents an account holder and ownership boundary.

| Field | Type | Rules |
|---|---|---|
| id | text | Primary key |
| email | text | Original display form; 3–254 characters |
| email_key | text | Trimmed, case-normalized; unique |
| password_hash | text | Versioned scrypt parameters, salt, and derived hash; never exported |
| created_at | timestamp | Required |
| updated_at | timestamp | Required |

**Relationships**: One user owns many sessions, bookmarks, tags, icons, and import batches.

## Session

Represents one revocable signed-in browser session.

| Field | Type | Rules |
|---|---|---|
| id | text | Primary key; not the browser token |
| user_id | text | Required foreign key to User; cascade delete |
| token_hash | blob | SHA-256 of the random browser token; unique |
| created_at | timestamp | Required |
| last_seen_at | timestamp | Required; updated with bounded frequency |
| expires_at | timestamp | Required |

Only the un-hashed random token is sent in the HttpOnly cookie. Expired sessions are rejected and eligible for cleanup.

## Bookmark

Represents one saved destination and its user-controlled organization state.

| Field | Type | Rules |
|---|---|---|
| id | text | Primary key |
| user_id | text | Required foreign key to User; cascade delete |
| url | text | Required absolute HTTP/HTTPS URL; max 4,096 characters |
| canonical_key | text | Required duplicate identity; unique with user_id |
| title | text | Required; normalized; 1–300 Unicode code points |
| description | text | Required, may be empty; max 1,000 code points |
| notes | text | Required, may be empty; max 5,000 code points |
| is_favorite | integer boolean | Required; default false |
| read_later_state | text enum | none, unread, or read; default none |
| read_later_added_at | timestamp nullable | Present for unread/read |
| read_at | timestamp nullable | Present only for read |
| archived_at | timestamp nullable | Null means active |
| metadata_refreshed_at | timestamp nullable | Last successful page-detail preview applied by the user |
| created_at | timestamp | Required |
| updated_at | timestamp | Required |

**Database rules**:

- Unique index on (user_id, canonical_key), including archived rows.
- Check read_later_state is one of the three defined values.
- none requires both reading timestamps null.
- unread requires read_later_added_at and requires read_at null.
- read requires both reading timestamps.
- User-visible sorting adds id as a stable tie-breaker.

**Relationships**: Many-to-many with Tag through BookmarkTag; zero or one BookmarkIcon.

## BookmarkIcon

Stores a safe, app-owned raster representation of a bookmark's site icon.

| Field | Type | Rules |
|---|---|---|
| bookmark_id | text | Primary and foreign key to Bookmark; cascade delete |
| user_id | text | Required; must match bookmark owner |
| content_hash | blob | SHA-256 of normalized PNG bytes |
| media_type | text | Fixed image/png |
| content | blob | Required; maximum 256 KiB after normalization |
| width | integer | 1–512 |
| height | integer | 1–512 |
| created_at | timestamp | Required |

Icons are served only after bookmark ownership is verified, with image/png and nosniff headers. Remote icon URLs and SVG are not persisted.

## Tag

Represents a reusable label within one user's collection.

| Field | Type | Rules |
|---|---|---|
| id | text | Primary key |
| user_id | text | Required foreign key to User; cascade delete |
| name | text | Trimmed display name; 1–60 code points |
| name_key | text | Unicode-normalized, case-folded name; unique with user_id |
| created_at | timestamp | Required |
| updated_at | timestamp | Required |

**Rules**:

- Unique index on (user_id, name_key) prevents case-only duplicates.
- Suggestions are always constrained by user_id.
- Tags with no BookmarkTag rows are deleted and no longer suggested.

## BookmarkTag

Join entity between Bookmark and Tag.

| Field | Type | Rules |
|---|---|---|
| bookmark_id | text | Foreign key to Bookmark; cascade delete |
| tag_id | text | Foreign key to Tag; cascade delete |

Primary key is (bookmark_id, tag_id). A service transaction verifies both rows have the same owner. Add an index on (tag_id, bookmark_id) for all-tags filtering.

## BookmarkSearch

FTS5 external-content search index synchronized in the same transaction as bookmark or tag changes.

| Column | Contents |
|---|---|
| bookmark_id | Unindexed bookmark row identifier |
| title | Bookmark title |
| url | Submitted destination |
| description | Retrieved/user-edited description |
| notes | Personal notes |
| tags_text | Current tag display names separated by spaces |

The application constructs an escaped AND-only expression. Search results always join back to Bookmark and apply user_id before returning data.

## ImportBatch

Represents a short-lived preview and its eventual commit outcome.

| Field | Type | Rules |
|---|---|---|
| id | text | Primary key and opaque preview token |
| user_id | text | Required foreign key to User; cascade delete |
| format | text enum | browser-html or complete-json |
| file_name | text | Sanitized display name |
| file_hash | blob | SHA-256 of uploaded bytes |
| status | text enum | previewed, committing, completed, partial, failed, expired |
| total_count | integer | Non-negative |
| valid_new_count | integer | Non-negative |
| duplicate_count | integer | Non-negative |
| invalid_count | integer | Non-negative |
| created_at | timestamp | Required |
| expires_at | timestamp | Required; preview cannot commit afterward |
| completed_at | timestamp nullable | Set for terminal committed states |

Previewing may create ImportBatch/ImportEntry staging rows but never bookmark rows. Batches are user-scoped and expire after a short configured interval.

## ImportEntry

Stores the normalized parsed snapshot used by commit so an uploaded file cannot change between preview and confirmation.

| Field | Type | Rules |
|---|---|---|
| id | text | Primary key |
| import_batch_id | text | Required foreign key; cascade delete |
| ordinal | integer | Required source order; unique within batch |
| source_path | text | Folder path for display/troubleshooting |
| payload_json | text | Validated normalized entry, not raw executable HTML |
| classification | text enum | new, duplicate, or invalid |
| outcome | text enum | pending, imported, skipped_duplicate, failed |
| error_code | text nullable | Stable machine-readable reason |
| error_message | text nullable | Safe user-facing detail |
| committed_bookmark_id | text nullable | Result when imported |

For browser HTML, entries can commit independently and produce partial status. Retrying an interrupted batch does not duplicate previously committed entries. Complete JSON restoration validates every entry first and commits atomically.

## State Transitions

### Read-Later

    none
      └─ Add to read later ─> unread
    unread
      ├─ Mark read ────────> read
      └─ Remove from list ─> none
    read
      ├─ Mark unread ──────> unread
      └─ Remove from list ─> none

Adding an item from none sets read_later_added_at. Moving to read sets read_at. Marking unread clears read_at but preserves the original added timestamp. Removing resets both timestamps.

### Archive

    active ── Archive ──> archived
    archived ─ Restore ─> active
    either ── Confirmed delete ─> permanently removed

Archive changes only archived_at. It preserves favorite and read-later fields. Archived rows are excluded from active and read-later queries but included in duplicate detection, native export, and explicit archive search.

### Import Batch

    uploaded ─ Preview valid ─> previewed
    previewed ─ Confirm ──────> committing
    committing ─ All valid ──> completed
    committing ─ Some fail ──> partial       # browser HTML only
    committing ─ Fatal/atomic rollback ─> failed
    previewed ─ TTL elapsed ─> expired

Complete JSON restoration has only completed or failed terminal outcomes because it is atomic.

## Backup Projection

The native backup is a portable projection, not a database dump. It includes URL, title, description, notes, tags, icon bytes, visible states, and bookmark dates. It excludes users, password hashes, sessions, canonical keys, import staging rows, search indexes, and local primary keys. See [backup.schema.json](contracts/backup.schema.json).
