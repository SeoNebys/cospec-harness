Scenario ID: SCN-003
Title: Organise a link with tags, reusing existing tags via suggestions
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

On any saved link, the client opens an inline editor via an "Edit tags & note"
(or "＋ Add tags & note") button that expands directly under that link. In the
tags field the client types a word; as they type, tags they have used before
that match what they are typing are suggested. The client can accept a
suggestion (arrow keys + Enter, or click) to reuse an existing tag consistently,
or type a new word and press Enter/comma to create a new tag. Each tag appears as
a chip; a chip can be removed with its ✕. Only tags not already on that link are
suggested. Saved tags appear on the link and are included when searching
(SCN-002). The client confirmed inline editing is convenient and the suggestions
make tag reuse easy.

## Gherkin
Feature: Tag a link

  Scenario: Add a new tag to a link
    Given the client is editing a saved link's tags
    When the client types a word that is not an existing tag and confirms it
    Then the word is added to the link as a tag chip

  Scenario: Reuse an existing tag via a suggestion
    Given the client has previously used the tag "reading"
    And the client is editing a link that does not yet have "reading"
    When the client types the start of "reading"
    Then "reading" is offered as a suggestion
    And accepting the suggestion adds "reading" as a tag on the link

  Scenario: Suggestions exclude tags already on the link
    Given the link already has the tag "reading"
    When the client types the start of "reading" while editing that link
    Then "reading" is not offered as a suggestion

  Scenario: Remove a tag
    Given a link has a tag chip
    When the client removes that chip
    And saves
    Then the tag is no longer on the link

  Scenario: Tags are searchable
    Given a link has the tag "reading"
    When the client searches for "reading"
    Then that link appears in the results

## Assumptions
- Tags are short free text, stored lower-cased and de-duplicated per link.
- Editing happens inline on the link, not on a separate page.
- Suggestions are drawn from tags already used anywhere in the collection.
