Scenario ID: SCN-020
Title: Saved searches — one-click shortcuts to a corner of the library
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The client can pin a filter combination they reach for repeatedly as a named
"saved view", recalled in one click. A pinned "★ Saved" row sits above the
search box; clicking a saved view reconstructs exactly where the client was.

A saved view remembers the BUNDLE of: the lens (Everything / To read / Set
aside), the selected topics, and any search text — "where I was standing".
It deliberately does NOT capture the sort order: sort is the client's separate
standing preference that travels everywhere, and a saved view must not override
it (that would feel like the app overruling the client).

Creating one: a "★ Save this view" affordance appears only when the current view
is actually filtered and not already saved (never nagging on a plain library).
It suggests a name from the filter, which the client can accept or rename in
their own words ("Monday reading", "dinner ideas"). Saved views can be removed.
The active saved view is highlighted so the client knows which corner they are in.

## Gherkin
Feature: Saved searches

  Scenario: Recall a saved view in one click
    Given a saved view for a lens + topics + search
    When the client clicks it
    Then the lens, topics and search are all restored at once
    And the current sort order is left unchanged

  Scenario: Save a repeated filter
    Given the client has built a filtered view not already saved
    Then a "Save this view" affordance is offered
    When the client saves it with a suggested-or-renamed name
    Then it appears as a pinned shortcut

  Scenario: The save affordance stays out of the way
    Given the library is unfiltered
    Then no "Save this view" affordance is shown

## Assumptions
- Bundle = lens + topics + search; sort excluded on purpose. (client confirmed)
- Save offered only when there's a filter worth saving. (client confirmed)
- Suggested name, editable rename kept. (client confirmed)
