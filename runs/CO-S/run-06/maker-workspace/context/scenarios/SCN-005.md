Scenario ID: SCN-005
Title: Empty states and no-results feedback
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When there is no data to show, the app shows a clear, welcoming message rather
than a blank screen. A brand-new user with no bookmarks sees a prompt inviting
them to save their first link. The Read later and Archive views each show their
own explanatory empty message when they contain nothing. When a search or tag
filter matches nothing, the app shows "No bookmarks match your search" rather
than an empty list.

## Gherkin
Feature: Empty and no-results states

  Scenario: First-run empty main view
    Given the user has no saved bookmarks
    When the user opens the All view
    Then a message invites them to save their first link

  Scenario: Empty Read later / Archive view
    Given no bookmarks are marked read-later (respectively archived)
    When the user opens that view
    Then an explanatory empty message for that view is shown

  Scenario: Search with no matches
    Given the user has bookmarks
    When a search term or tag filter matches none of them
    Then a "no matches" message is shown instead of an empty list

## Assumptions
- Empty-view messages differ per view (All / Read later / Archive).
- The no-matches message is distinct from the first-run empty message.
