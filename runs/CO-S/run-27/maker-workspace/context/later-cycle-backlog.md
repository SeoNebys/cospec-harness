# Later-cycle requests

## Smarter duplicate-address recognition

Treat addresses that differ only by a trailing slash or common advertising-tracking information as the same bookmark when straightforward. Preserve section markers as potentially distinct bookmarks because they may point to a meaningfully different part of a page. Exact repeated addresses remain part of cycle 1.

Client framing:

> If tidying up trailing slashes and tracking bits is straightforward, I'd welcome it; if it's fiddly, it's fine to leave as a later refinement.
