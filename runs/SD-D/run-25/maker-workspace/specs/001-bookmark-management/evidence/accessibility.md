# Accessibility evidence

The release browser journey runs Axe on the loaded authenticated collection and rejects serious or critical violations. It passes in desktop Chromium and the Pixel 7 viewport. During the same run, labeled inputs, semantic navigation, dialog names, status/error regions, and keyboard-operable native controls are exercised. A contrast finding on muted navigation/status text was corrected by darkening the shared muted token before the passing run.
