Scenario ID: SCN-007
Title: Track whether a bookmark is still to be read
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A newly saved bookmark starts with a visible Read later status. A plain-language Mark as read button changes it to Read. The status control changes the bookmark without opening the saved page, while the rest of the card remains its link.

## Gherkin
Feature: Bookmark reading status

  Scenario: A new bookmark starts in the read-later state
    Given the client saves a new bookmark
    When the bookmark appears in the library
    Then its status is Read later
    And it offers a Mark as read action

  Scenario: Mark a bookmark as read
    Given a bookmark has the Read later status
    When the client chooses Mark as read
    Then its status changes to Read
    And the action does not open the saved page
    And the rest of the bookmark card continues to open the saved page

## Assumptions
- All newly saved bookmarks start as Read later.
- A plain-language button is used instead of a checkbox.
- The status can be changed independently of opening the saved page.
