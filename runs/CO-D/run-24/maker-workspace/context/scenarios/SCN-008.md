Scenario ID: SCN-008
Title: Filter by clicking a tag pill
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

Tag pills shown on a bookmark card are clickable. Clicking a tag immediately
narrows the list to bookmarks carrying that tag. It does this by applying a
`#tag` exact-tag search: the search box is populated with `#tag`, which makes it
clear how the filter is applied and lets the client clear it with the × button to
return to the full list. Clicking a tag does not open the bookmark's page.

The client confirmed this behaviour matches expectation and that reflecting the
filter in the search box is a helpful, transparent way to show what is applied.

## Gherkin

Feature: Tag filter

  Scenario: Click a tag to filter
    Given a bookmark card shows tag pills
    When the client clicks a tag pill
    Then the list shows only bookmarks with that tag
    And the search box is populated with "#<tag>"

  Scenario: Clear a tag filter
    Given a tag filter is applied via a pill click
    When the client clears the search
    Then the full list returns

  Scenario: Clicking a tag does not open the page
    When the client clicks a tag pill on a card
    Then the bookmark's page is not opened

## Assumptions

- Tag click maps to an exact `#tag` search (reuses SCN-004 semantics).
- The applied filter is transparent (visible in the search box) and clearable.
