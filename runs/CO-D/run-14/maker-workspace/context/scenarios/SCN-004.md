Scenario ID: SCN-004
Title: Create a new tag while saving a bookmark
Type: Edge Case
Approval status: approved
Approval session: SESSION-004
Approval cycle: 1

## Approved behaviour
When no existing tag matches what the client types during bookmark review, the site offers an explicit choice to create it as a new tag. Choosing that action attaches the new tag to the bookmark. New tags are standardized to lowercase. After the bookmark is saved, the new tag is treated as an existing tag and is suggested during later saves.

## Gherkin
Feature: Create reusable bookmark tags

  Scenario: Create a tag that has not been used before
    Given no existing tag matches "florence"
    And a new bookmark is being reviewed
    When the client types "florence" in the tag field
    Then the site offers to create the new tag "florence"
    When the client deliberately chooses that action and saves the bookmark
    Then the bookmark displays the tag "florence"

  Scenario: Suggest a tag created during an earlier save
    Given the client previously created the tag "florence"
    And another new bookmark is being reviewed
    When the client types "flo" in the tag field
    Then "florence" appears as an existing tag suggestion

  Scenario: Standardize a new tag's capitalization
    Given the tag "florence" does not exist
    When the client creates it using differently capitalised input
    Then one new lowercase tag named "florence" is created

## Assumptions
- Creating a new tag requires an explicit action; typing alone never creates one.
- New tag names are stored and displayed in lowercase.
- A newly created tag becomes available for suggestions immediately after it is chosen.
- The create action appears in the same dropdown used for matching existing tags.
