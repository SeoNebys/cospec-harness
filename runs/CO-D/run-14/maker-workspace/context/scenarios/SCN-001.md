Scenario ID: SCN-001
Title: Save a new bookmark with discovered and editable page details
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
From an empty library, the client can paste a web address into a save field that is already visible on the library page and continue. The site gathers the page title, description, and site icon, then presents the discovered details for review. The client can edit the discovered title and description and add optional personal notes before saving. Saving creates one library entry that uses the client's edited values.

## Gherkin
Feature: Save bookmarks

  Scenario: Save a bookmark using discovered page details
    Given the personal library is empty
    When the client pastes a valid web address into the save field on the library page
    And continues
    Then the discovered title, description, and site icon are presented for review
    And the client can add optional personal notes

  Scenario: Adjust discovered details before saving
    Given discovered page details are being reviewed
    When the client changes the title and description
    And saves the bookmark
    Then one bookmark is added to the library
    And its title and description match the client's edited values

## Assumptions
- The client is already inside their private personal library.
- The submitted address is valid and reachable, and page details are available.
- The library has no bookmarks before this flow begins.
- Personal notes are optional and do not replace the page description.
- The web-address field remains visible on the library page so saving does not require opening a separate window first.
- Continuing from the web-address field always leads to the editable review step before the bookmark is saved.
