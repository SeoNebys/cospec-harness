Scenario ID: SCN-004
Title: Add a note to a link with basic formatting
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

In the same inline editor as tags, each link has a single free-text note. The
client can apply basic formatting: a line beginning with "- " becomes a bullet
list item, and text written as [label](https://…) becomes a clickable link. When
saved, the note is shown under the link with the bullets and links rendered. Note
text is included when searching (SCN-002). The client confirmed one note per
link is right, and that bullet lists plus links are enough formatting.

## Gherkin
Feature: Note on a link

  Scenario: Add a formatted note
    Given the client is editing a saved link
    When the client writes note text containing a line starting with "- "
         and a link written as [label](https://example.com)
    And saves
    Then the note is shown under the link with the "- " line rendered as a
         bullet and the [label](url) rendered as a clickable link

  Scenario: One note per link
    Given a link already has a note
    When the client edits and saves a new note text
    Then the link shows the updated single note

  Scenario: Note text is searchable
    Given a link's note contains the word "folder"
    When the client searches for "folder"
    Then that link appears in the results

## Assumptions
- Exactly one note per link.
- Supported formatting is limited to bullet lists ("- ") and links
  ([text](url)); no bold/headings for now.
- The note is entered as plain text and rendered formatted on display.
