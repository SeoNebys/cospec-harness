Title: Search the library across all fields (scraps or exact phrase)
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A search box at the top of the library filters results live as the client
types (no Enter needed). It searches across every field of a link: the name,
the description, the client's personal note, and the web address. A match in a
hidden place (note or address) is flagged with a small "Found in your note / the
web address" tag, so the client understands why a link surfaced; matches in the
visible name/description are simply highlighted.

Multiple words are treated as separate terms: a link matches when it contains
*all* of them, in any order, located anywhere across its fields (one word may be
in the name, another in the description). Wrapping text in "quotes" matches that
exact phrase only.

Search works together with the Topics bar: typing searches *within* the
currently selected topics rather than clearing them. Clearing the search (×)
returns to the topic-filtered (or full) library.

## Gherkin
Feature: Search the library

  Scenario: Live search across all fields
    Given the library has saved links
    When the client types a word
    Then results filter live to links containing it in the name, description,
         note, or web address
    And matches in the note or address are flagged with a "Found in…" tag

  Scenario: Multiple loose words match in any order, anywhere
    When the client types two words
    Then only links containing both words are shown
    And the words may appear in any order and in different fields

  Scenario: Quoted exact phrase
    When the client wraps text in quotes
    Then only links containing that exact phrase are shown

  Scenario: Search within selected topics
    Given one or more topics are selected
    When the client types a search
    Then the search narrows within those topics without clearing them

## Assumptions
- Live-as-you-type, not press-Enter. (client confirmed)
- Loose words = AND anywhere/any order; quotes = exact phrase. (client confirmed)
- Search composes with topic filter rather than replacing it. (client confirmed)
- Ordinary search of the everyday library excludes set-aside/shelved links;
  shelved links are found only when searching within the shelf. (client
  confirmed — see SCN-013)
