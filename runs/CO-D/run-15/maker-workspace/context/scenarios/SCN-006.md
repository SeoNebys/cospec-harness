Scenario ID: SCN-006
Title: Flag a bookmark and view the read-later list
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

The client can flag a bookmark for later using a checkbox directly on that bookmark, making the current on/off state visible at a glance. The item remains in the full collection and also appears in a focused read-later view. Opening that view shows only the items currently flagged for later.

## Gherkin

Feature: Keep a read-later list

  Scenario: Flag a bookmark for later and view the focused list
    Given a bookmark is present in the full collection
    And the bookmark is not flagged for later
    When the client checks the read-later checkbox on the bookmark itself
    Then the bookmark remains in the full collection
    And the read-later view indicates that it contains one item
    When the client opens the read-later view
    Then the flagged bookmark is shown
    And bookmarks not flagged for later are not shown

## Assumptions

- Read later is an additional view of items in the collection, not a move out of the collection.
- The flagging control is a checkbox available directly on each bookmark.
- Marking an item as read and clearing it from the read-later view is covered separately by SCN-007.
