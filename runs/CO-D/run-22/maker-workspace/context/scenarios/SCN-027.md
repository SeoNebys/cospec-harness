Scenario ID: SCN-027
Title: Preserve the original PDF document
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When a bookmarked address points to a PDF, the app preserves the actual PDF file rather than only a webpage representation. If the original download later disappears, the stored PDF can still be opened in the app and downloaded as a copy. Its size and saved date are shown, and readable text inside it remains searchable.

## Gherkin
Feature: Preserving saved content

  Scenario: Open a preserved PDF after its source disappears
    Given a PDF bookmark retained the original document file
    And the original download is no longer available
    When the person opens the saved PDF
    Then the stored PDF file opens in the app
    And its saved date and file size are shown
    And the person can download their stored copy

  Scenario: Search text inside a preserved PDF
    Given a retained PDF contains readable text
    When the person searches for text from that document
    Then the PDF bookmark can appear in the results
    And search does not depend on the original download remaining available

## Assumptions
- The PDF file can be successfully retrieved when first saved.
- Searchable text can be extracted from the PDF; image-only PDF handling is explored separately if required.
