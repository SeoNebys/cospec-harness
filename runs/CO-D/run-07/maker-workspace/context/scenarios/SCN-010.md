Scenario ID: SCN-010
Title: Remember the chosen sort order between visits; Settings to manage it
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The client's chosen sort order is remembered between visits: whatever order was
last selected is the order shown on return. There is a single remembered
preference — changing the toolbar Sort control is what changes the remembered
default; the client did not want a separate temporary sort versus a fixed
default. A Settings area provides a clear place to review or deliberately change
this default order; it sets the same remembered preference as the toolbar. The
client confirmed the simpler "remember my last choice" behaviour and that
Settings is still useful as an explicit place to manage it.

## Gherkin
Feature: Remembered sort preference

  Scenario: Remember the last chosen order
    Given I chose a sort order
    When I return to the app later
    Then the collection is shown in that same order

  Scenario: Set the default from Settings
    Given I open Settings
    When I choose a default order and save
    Then that order is used now and on my next visit
    And the toolbar Sort control reflects it

## Assumptions
- One preference backs both the toolbar and Settings (no separate temporary vs.
  fixed default).
- Prototype simulates "remembered for me" with browser local storage; the real
  app would tie the preference to the client's personal account.
