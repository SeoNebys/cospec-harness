Scenario ID: SCN-013
Title: Gently reject input that is not a web address
Type: Error Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When the client tries to save something that is obviously not a web address, the
app shows a gentle inline message ("that doesn't look like a web address") and
saves nothing — catching the mistake before it becomes a broken bookmark. It does
not nag or lose what was typed.

    And no bookmark is created
