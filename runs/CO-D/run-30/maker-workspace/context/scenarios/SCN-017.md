Scenario ID: SCN-017
Title: Save with an editable site-name fallback when page details are unavailable
Type: Error Case
Approval status: approved
Approval session: SESSION-017
Approval cycle: 1

## Approved behaviour

When a valid page address is reachable but its title, description, and icon cannot be collected, the save pop-up clearly explains the problem and uses the site's name as an editable stand-in title. The client can save immediately or replace that wording first. The app does not imply that the stand-in is the page's real title, and it does not require the client to invent a title before saving.

## Gherkin

Feature: Saving bookmarks

  Scenario: Page details cannot be collected
    Given the user has entered a valid page address
    And the page details cannot be collected
    Then the save pop-up explains that the details are unavailable
    And the site's name appears as an editable stand-in title
    And the description may remain empty
    When the user saves without changing the stand-in
    Then a bookmark is saved using the site name as its title

  Scenario: Replace the fallback title before saving
    Given the site name is shown as a fallback title
    When the user replaces it with personal wording and saves
    Then the bookmark card shows the personal wording

## Assumptions

- The entered address itself is valid and reachable; only metadata collection failed.
