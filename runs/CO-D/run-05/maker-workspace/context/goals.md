# Business goal statement

Cycle: 1
Confirmed: SESSION-001

## Client's goal (in the client's words)

"I want to build an app to save and manage bookmarks."

"My browser bookmarks have become a cluttered list, so I often can't find
something again or remember why I saved it."

"I'd like one place where I can quickly save a link, organise it with tags, add
a note for context, and later find it through search. I also want a clear
distinction between things I still intend to read, things I've finished with,
and things I want to keep but archive out of the way. Ideally, saving a link
shouldn't involve copying all its page details by hand."

"I picture it as a web app I open in my browser, mainly on a computer. I don't
need it to be a team tool or a separate mobile or desktop app."

## Confirmed direction

A single personal web app to rescue links from a cluttered browser-bookmark
list. The core value is findability and remembering intent: quick, low-effort
saving with page details pulled in automatically; user tags and a context note;
search to find things later; and a clear distinction between three link states —
still to read, done with, and kept-but-archived.

## Interface form

Web app, used mainly on a desktop browser. Single personal user (no team,
no separate mobile/desktop app).

## Scope note

The real goal is findability and remembering why a link was saved. Tags, notes,
and the to-read / done / archived distinction are means in service of that goal.
