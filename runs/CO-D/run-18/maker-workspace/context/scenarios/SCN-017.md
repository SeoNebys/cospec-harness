Scenario ID: SCN-017
Title: Select and update several bookmarks together
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Every library card has an always-visible selection box. Selecting bookmarks gives each a clear outline, shows a running selected count, and reveals a batch-action bar; otherwise the bar stays out of the way. Adding a tag to the group preserves all existing tags and reports how many bookmarks changed. A selected group can be saved for later; when every selected item is already saved for later, the action becomes “Mark done” and removes the group from that view without deleting bookmarks. Archiving moves exactly the selected bookmarks with all information intact. Permanent group deletion is available only in the Archive, confirms the number selected, warns that it cannot be undone, changes nothing when cancelled, and permanently removes exactly the selected bookmarks when confirmed. The client selected always-visible boxes after comparing them with a dedicated selection mode.

## Gherkin
Feature: Manage several bookmarks together

  Scenario: Select several bookmarks
    Given multiple bookmark cards are visible
    When the user selects more than one card with its always-visible selection box
    Then each selected card has a clear selected outline
    And the selected count is displayed
    And the batch-action bar appears

  Scenario: Add a tag to selected bookmarks
    Given bookmarks with different existing tags are selected
    When the user adds a tag to the selected group
    Then every selected bookmark gains that tag
    And every bookmark retains its existing tags
    And the app reports how many bookmarks changed

  Scenario: Save selected bookmarks for later
    Given several active bookmarks are selected
    When the user saves the group for later
    Then every selected bookmark appears in Read later
    And all other bookmark information remains unchanged

  Scenario: Mark selected read-later bookmarks done
    Given every selected bookmark is already in Read later
    When the user chooses "Mark done"
    Then every selected bookmark leaves Read later
    And every selected bookmark remains in the active library

  Scenario: Archive selected bookmarks
    Given several active bookmarks are selected
    When the user archives the group
    Then exactly the selected bookmarks move to the Archive
    And their saved information remains intact
    And unselected bookmarks remain active

  Scenario: Cancel permanent deletion of selected archived bookmarks
    Given several archived bookmarks are selected
    When the user chooses permanent deletion and then cancels the confirmation
    Then the confirmation identifies the number selected and warns that deletion cannot be undone
    And every selected bookmark remains intact in the Archive

  Scenario: Confirm permanent deletion of selected archived bookmarks
    Given several archived bookmarks are selected
    When the user confirms permanent deletion
    Then exactly the selected bookmarks are permanently removed
    And they are no longer available to restore

## Assumptions
- Always-visible selection boxes are the approved interaction; a dedicated selection mode is not used.
- Batch actions appear only after one or more bookmarks are selected.
- Permanent batch deletion follows the same Archive-only rule as single-item deletion.
