Scenario ID: SCN-013
Title: Avoid saving the same web address twice
Type: Edge Case
Approval status: approved
Approval session: SESSION-013
Approval cycle: 1

## Approved behaviour

When the client tries to save a web address that is already in the active
collection, the existing bookmark is kept as the single copy and the save
window explains that another copy was not added.

## Gherkin

Feature: Saving bookmarks

  Scenario: Save an address that is already bookmarked
    Given the active collection already contains a bookmark for a web address
    When the client tries to save the same web address again
    Then the collection still contains exactly one bookmark for that address
    And the client is told that another copy was not added

## Assumptions

- Exact matching web addresses are treated as the same bookmark.
- Duplicate detection in this scenario applies to the active collection.
