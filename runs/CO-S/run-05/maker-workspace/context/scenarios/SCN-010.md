Scenario ID: SCN-010
Title: Show an understandable empty reading pile
Type: Edge Case
Approval status: approved
Approval session: SESSION-010
Approval cycle: 1

## Approved behaviour

When no bookmarks have been marked for later, the Read later sidebar view
remains open and explains that the reading pile is empty. It does not redirect
the client to the full collection, making it clear the feature is working and
simply has no items yet.

## Gherkin

Feature: Read-later bookmarks

  Scenario: Open the reading pile before anything is marked
    Given no bookmark is marked for later
    When the client opens the Read later view
    Then the Read later view remains open
    And it explains that the reading pile is empty

## Assumptions

- An empty focused view does not redirect to another view.
