Scenario ID: SCN-004
Title: Add a personal note to a bookmark
Type: Happy Path
Approval status: approved
Approval session: SESSION-004
Approval cycle: 1

## Approved behaviour
The person can add or change a personal note in the bookmark's inline editor. After saving, the note appears directly on the card in a visually distinct block, clearly separated from the description gathered from the page and easy to skim without reopening the editor.

## Gherkin
Feature: Personal bookmark notes

  Scenario: Add a personal note
    Given a saved bookmark is visible in the collection
    When the person opens its inline editor
    And writes a personal note
    And saves the changes
    Then the note appears on the bookmark card
    And the note is visually distinct from the page's description

## Assumptions
- Notes are managed in the same inline editor as other bookmark details.
- Light formatting within a note is explored as a related, separate behaviour.
