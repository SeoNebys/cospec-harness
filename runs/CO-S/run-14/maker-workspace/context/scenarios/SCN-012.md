Scenario ID: SCN-012
Title: Long titles and descriptions are shortened with expand; tags wrap
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

To keep the list scannable, a long **title** is clamped (about two lines) and a
long **description** is clamped (about three lines), each with a **"Show more" /
"Show less"** toggle to expand and collapse the full text on demand. The toggle
appears only when the text is actually truncated. A bookmark with **many tags**
shows all of them, **wrapping onto additional lines** rather than being cut off.

## Gherkin
Feature: Long content presentation

  Scenario: Long title and description are clamped with expand
    Given a bookmark has a very long title and description
    Then the title and description are shown shortened
    And a "Show more" control expands them to full length
    And "Show less" collapses them again

  Scenario: Toggle only when truncated
    Given a bookmark's title and description are short
    Then no "Show more" control is shown

  Scenario: Many tags wrap
    Given a bookmark has many tags
    Then all tags are shown, wrapping onto additional lines

## Assumptions
- Title clamps ~2 lines, description ~3 lines (exact limits are a later visual detail).
