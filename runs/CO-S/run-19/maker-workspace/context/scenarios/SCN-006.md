Scenario ID: SCN-006
Title: Save and reopen a reusable bookmark view
Type: Happy Path
Approval status: approved
Approval session: SESSION-006
Approval cycle: 1

## Approved behaviour

After setting search text, a tag filter, and a sort order, the client can use a clearly labeled Save this view button, give the view a name, and save it. The named view appears in a dedicated sidebar section. Selecting it later restores the saved search text, tag filter, sort order, and matching results together in one action.

## Gherkin

Feature: Save reusable bookmark views

  Scenario: Save and reopen a frequently used view
    Given the user has searched for "puzzles"
    And filtered the list by the tag "animals"
    And ordered the list with the oldest bookmarks first
    When the user selects "Save this view"
    And names the view "Animal minds"
    And saves it
    Then "Animal minds" appears in a saved-views section of the sidebar
    When the user returns to all bookmarks
    And selects "Animal minds"
    Then the search text "puzzles" is restored
    And the "animals" tag filter is restored
    And the oldest-first order is restored
    And the matching bookmarks are shown

## Assumptions

- The control is labeled "Save this view" rather than represented by an ambiguous symbol.
- A saved view preserves search text, one selected tag filter, and the chosen sort order.
- Saved views have user-provided names and appear in their own sidebar section.
