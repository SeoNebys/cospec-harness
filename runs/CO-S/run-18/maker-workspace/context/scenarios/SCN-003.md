Title: Search across all bookmark information
Type: Happy Path
Approval status: approved
Approval session: SESSION-003
Approval cycle: 1

## Approved behaviour
As the person types into one search field, the visible bookmark list narrows immediately. A bookmark matches when the entered text appears in its title, description, personal note, web address, or tags, allowing the person to find it using whichever detail they remember.

## Gherkin
Feature: Searching bookmarks

  Scenario Outline: Find a bookmark using any remembered information
    Given the library contains bookmarks with titles, descriptions, personal notes, web addresses, and tags
    When the person types text that appears in a bookmark's <source>
    Then matching bookmarks are shown immediately
    And non-matching bookmarks are hidden

    Examples:
      | source       |
      | title        |
      | description  |
      | personal note|
      | web address  |
      | tag           |

## Assumptions
- Search is case-insensitive.
- Search updates as the person types without a separate submit action.
- A single search field covers every searchable source.
