Scenario ID: SCN-015
Title: Create the first tag when no suggestions exist
Type: Edge Case
Approval status: approved
Approval session: SESSION-015
Approval cycle: 1

## Approved behaviour
When no tags have been used before, the optional tag field explains that the person can type a new tag and press Enter. Enter turns the text into an attached tag. Capitalization differences do not create different tag names, and a newly created tag becomes a suggestion on later saves.

## Gherkin
Feature: Creating tags

  Scenario: Create a tag without existing suggestions
    Given no tags have been used in the library
    And the person is entering a bookmark to save
    When the person types a tag name and presses Enter
    Then the text becomes a tag attached to the pending bookmark
    When the person saves the bookmark
    Then the bookmark is saved with that tag
    And the tag becomes a suggestion for later bookmarks

  Scenario: Avoid capitalization-only tag duplicates
    Given a tag name has already been used
    When the person enters the same tag name with different capitalization
    Then the existing tag is used
    And no capitalization-only duplicate tag is created

## Assumptions
- Tag names are displayed in lowercase.
- A bookmark may be saved without tags.
- Pressing Enter commits the current tag text without submitting the bookmark form.
