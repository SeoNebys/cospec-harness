Scenario ID: SCN-012
Title: Reorder the visible bookmark list
Type: Happy Path
Approval status: approved
Approval session: SESSION-012
Approval cycle: 1

## Approved behaviour
A compact ordering menu lets the person arrange visible bookmark cards by newest first, oldest first, or name A–Z. Choosing an order rearranges the list immediately without changing any bookmarks or their details.

## Gherkin
Feature: Order bookmarks

  Scenario Outline: Reorder the visible library
    Given multiple bookmarks are visible in the library
    When the person chooses <order> from the ordering menu
    Then the cards immediately appear in <expected sequence>
    And no bookmark or bookmark detail is changed

    Examples:
      | order        | expected sequence        |
      | Newest first | newest to oldest         |
      | Oldest first | oldest to newest         |
      | Name A–Z     | ascending name order     |

## Assumptions
- Ordering is controlled through one compact dropdown menu.
- The order applies to the currently visible list.
