Title: Personal collection persists across sessions, single-user, no login
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

Everything the user saves persists across sessions: links, their titles, their tags,
their read-later status, and their archived status. Closing the browser and returning
later shows the collection exactly as it was left.

This first version is a single-user personal collection on the user's own device.
There is no account, login, sharing, or multi-user support.

Confirmed via text (persistence across a real session close cannot be shown within a
single prototype view — see session-log.md).

## Gherkin
Feature: Durable personal collection

  Scenario: Data persists across sessions
    Given the user has saved links with tags, read-later flags, and archived states
    When the user closes the app and returns later
    Then all links and their titles, tags, read-later status, and archived status are unchanged

  Scenario: Single-user, no login
    When the user opens the app
    Then no account or login is required and the collection is the user's own

## Assumptions
- Persistence must survive normal browser close/reopen. Exact storage mechanism is a
  Phase 2 design decision, but durability of all listed attributes is required.
- No multi-device sync is promised in this cycle (single device). Sync could be a
  later addition.
