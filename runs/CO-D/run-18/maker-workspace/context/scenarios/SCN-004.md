Scenario ID: SCN-004
Title: Narrow the library by tag and text together
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A bookmark can have more than one tag. The library presents tags in a sidebar. Choosing one tag with a single click immediately shows bookmarks carrying that tag. A selected tag and text typed into search are both applied, so only bookmarks satisfying both remain. The client selected the sidebar interaction after comparing it with tags arranged above the bookmark cards.

## Gherkin
Feature: Filter saved bookmarks by tag

  Scenario: Narrow the library with a sidebar tag
    Given the library contains bookmarks carrying one or more tags
    When the user selects a tag in the sidebar
    Then only bookmarks carrying that tag remain visible
    And the visible result count is updated

  Scenario: Combine a tag filter with text search
    Given a tag is selected in the sidebar
    When the user types text in the search box
    Then only bookmarks that carry the selected tag and match the text search remain visible

## Assumptions
- A bookmark may carry multiple tags.
- Selecting a different tag replaces the current tag selection.
- The sidebar is the approved interaction; the alternative row of tags is not part of the approved behaviour.
