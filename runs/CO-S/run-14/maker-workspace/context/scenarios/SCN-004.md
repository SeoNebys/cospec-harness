Scenario ID: SCN-004
Title: Mark a link "read later" and view the to-read list
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

Each saved (non-archived) item has a **"Read later"** toggle. Turning it on
flags the item. The top of the screen has three view buttons — **All**,
**To read**, **Archived** — each with a count.

"To read" is a **filtered view** of the flagged items; those items **also remain
in the main "All" list** (read-later is a flag, not a separate box). Turning the
flag off removes the item from "To read" — effectively marking it as read — while
it stays in "All".

## Gherkin
Feature: Read-later flag

  Scenario: Flag an item to read later
    Given a saved item is shown in the All view
    When the user turns on its "Read later" flag
    Then the item appears in the To read view
    And the item still appears in the All view

  Scenario: To read is a filtered view
    When the user selects the To read view
    Then only items flagged read-later (and not archived) are shown
    And the view button shows the count of such items

  Scenario: Turning the flag off marks it read
    Given an item is flagged read-later
    When the user turns the flag off
    Then the item no longer appears in the To read view
    And the item still appears in the All view

## Assumptions
- Read-later is a per-item on/off flag.
- Counts are shown next to each view button.
