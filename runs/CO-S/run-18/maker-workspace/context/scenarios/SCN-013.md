Scenario ID: SCN-013
Title: Show a clear empty search result
Type: Edge Case
Approval status: approved
Approval session: SESSION-013
Approval cycle: 1

## Approved behaviour
When no bookmarks match the entered search text, the app shows a clear no-results message rather than suggesting the library is empty or lost. The saved library remains unchanged, and the entered search text stays in place for immediate revision.

## Gherkin
Feature: Empty search results

  Scenario: Search finds no matching bookmark
    Given the library contains saved bookmarks
    When the person enters search text that matches none of them
    Then a clear no-results message is shown
    And no bookmark cards are shown as matching
    And the saved library remains unchanged
    And the entered search text remains available to revise

## Assumptions
- Clearing or changing the search reveals matching saved bookmarks again.
- A no-results state is visually distinct from an empty library.
