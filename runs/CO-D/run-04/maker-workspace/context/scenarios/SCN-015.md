Scenario ID: SCN-015
Title: Require a recognizable title but allow no description
Type: Edge Case
Approval status: approved
Approval session: SESSION-015
Approval cycle: 1

## Approved behaviour
A bookmark cannot be saved without a title. If the title is empty, the review
stays open and shows inline guidance explaining that a title is needed for
recognition. A description is optional, so adding a title while leaving the
description empty allows the bookmark to be saved.

## Gherkin
Feature: Review bookmark details

  Scenario: Attempt to save without a title
    Given page details are open for review
    And the title is empty
    When the person attempts to save the bookmark
    Then the bookmark is not saved
    And the review remains open
    And inline guidance asks for a recognizable title

  Scenario: Save a title without a description
    Given page details are open for review
    And the bookmark has a title
    And the description is empty
    When the person saves the bookmark
    Then the bookmark is saved with the title
    And no description is required

## Assumptions
- Every bookmark must have a non-blank title.
- Descriptions are optional in both automatic and manual-detail save flows.
