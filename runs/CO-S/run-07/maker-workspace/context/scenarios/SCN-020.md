Scenario ID: SCN-020
Title: Preserve the personal library over time and across computers
Type: Edge Case
Approval status: approved
Approval session: SESSION-020
Approval cycle: 1

## Approved behaviour
An immediate "Saved just now" confirmation later becomes an actual saved date. The library's newest-first order is based on when each bookmark was originally saved, so editing does not move a bookmark to the top. Bookmarks, tags, and Read later choices persist after the browser closes and appear in the same personal library when the owner returns, including from another computer.

## Gherkin
Feature: Preserve a personal bookmark library over time

  Scenario: Replace the immediate confirmation with a saved date
    Given a bookmark was saved with an immediate "Saved just now" confirmation
    When the immediate confirmation period has passed
    Then the bookmark shows its actual saved date

  Scenario: Keep the original saved order after editing
    Given the library is ordered newest saved first
    And an older bookmark appears below newer bookmarks
    When the older bookmark is edited and saved
    Then it remains ordered by its original saved time
    And it does not move above the newer bookmarks

  Scenario: Return to the same library later and elsewhere
    Given the owner has saved bookmarks, tags, and Read later choices
    When the owner closes the browser and later returns to the personal app
    Then the same bookmarks, tags, and Read later choices are available
    When the owner accesses the personal app from another computer
    Then the same personal library is available there

## Assumptions
- The owner is accessing the same deployed personal app from each computer.
- The private access approach does not introduce multi-person account management.
- Saved dates are presented in a form appropriate to the owner's browser.
