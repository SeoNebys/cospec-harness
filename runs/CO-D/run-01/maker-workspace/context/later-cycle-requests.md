# Requests for later cycles

## Readable page copies

> When a page truly vanishes, the saved title and my notes help, but sometimes what I really wanted was the *content* of the page itself. So it would be reassuring if, at the time I save a link, the app could quietly keep its own copy of the page — so that if the original ever disappears, I can still read what I saved, not just my notes about it. I don't need to design that now, but keeping the bookmark intact is the floor, and having a kept copy to fall back on would be the thing that truly saves me.

Status: recorded for a later development cycle; not part of Cycle 1 implementation or acceptance.
