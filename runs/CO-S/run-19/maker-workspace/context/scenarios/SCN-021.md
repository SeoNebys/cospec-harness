Scenario ID: SCN-021
Title: Keep the saved copy unchanged when the original page changes
Type: Edge Case
Approval status: approved
Approval session: SESSION-021
Approval cycle: 1

## Approved behaviour

A saved page copy remains frozen as the version captured on the original save date, even if the live webpage changes later. The captured content is never silently refreshed or replaced. Choosing Try original page opens the current live version separately, allowing the client to compare it without affecting the dependable saved snapshot.

## Gherkin

Feature: Preserve saved pages over time

  Scenario: Keep the captured version after the original changes
    Given a readable copy of a webpage was captured on the bookmark's save date
    And the original webpage changes later
    When the user opens the saved bookmark
    Then the saved reading page shows the version captured on the save date
    And the saved copy is not silently updated from the live page
    When the user chooses "Try original page"
    Then the current live webpage opens separately
    And the saved copy remains unchanged

## Assumptions

- Saved page copies are immutable snapshots unless a future explicitly approved behavior says otherwise.
- Opening the live original never overwrites the saved copy.
