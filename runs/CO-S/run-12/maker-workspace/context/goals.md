# Cycle 1 goal

## Client goal (verbatim)

> Right now saving a bookmark is kind of clumsy for me — I just get a bare link, and later I can't remember what it was or find it again.
>
> The big picture: today my bookmarks are a messy pile I can't search or trust. I want them to be something I can actually save quickly, organize, and find again later.

## Requested outcomes (verbatim)

> - When I paste a link, the app should go grab the page's title, description, its little icon, maybe a preview image — so I'm not typing all that myself. And let me fix or add to that if I want.
> - Let me tag things and then filter down by a tag, so I can pull up "all my recipes" or "all my work stuff" easily.
> - A real search that looks inside titles, descriptions, my own notes, the whole thing — and finds it even if I don't match the capitalization.
> - A way to mark something "read this later" and see just those, then check it off once I've read it.
> - Let me add my own notes to a bookmark.
> - If I try to save a link I already saved, don't make a duplicate — just take me to the one I've got.
> - And I'd like to tidy things away without losing them — set some aside/archive them rather than only being able to delete for good.

## Interface and audience (verbatim)

> I mostly want to use this at my desk in a web browser, so a web app is what I have in mind. It's just for me — I don't need other people logging in or anything like that.

## Confirmation

Confirmed by the client in Cycle 1. The app is a personal, desktop-oriented web app.
