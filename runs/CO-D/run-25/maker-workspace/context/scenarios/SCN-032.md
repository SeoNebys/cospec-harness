Scenario ID: SCN-032
Title: Explain an empty Read later pile
Type: Edge Case
Approval status: approved
Approval session: SESSION-032
Approval cycle: 1

## Approved behaviour
When no bookmarks are marked for later, the Read later view shows a zero count and a calm empty-state message. It explains that bookmarks marked for later will appear there, treating the state as healthy rather than as an error. The same state appears after the final item is marked as read.

## Gherkin
Feature: Read later

  Scenario: Open Read later when nothing is waiting
    Given no saved bookmark is in Read later
    When the person opens Read later
    Then the visible count is zero
    And a calm message says nothing is waiting to be read
    And the message explains how bookmarks appear there

  Scenario: Finish the final Read later item
    Given one bookmark remains in Read later
    When the person marks it as read
    Then the empty Read later state is shown

## Assumptions
- An empty Read later pile is not presented as an error.
