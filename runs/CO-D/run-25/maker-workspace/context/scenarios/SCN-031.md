Scenario ID: SCN-031
Title: Keep results stable while a search command is incomplete
Type: Edge Case
Approval status: approved
Approval session: SESSION-031
Approval cycle: 1

## Approved behaviour
Because search updates while text is entered, a temporarily incomplete command does not blank results or show a disruptive error. The most recent sensible results remain visible with a gentle hint. Completing or correcting the expression removes the hint and resumes normal live search.

## Gherkin
Feature: Searching bookmarks

  Scenario: Pause after an unfinished command word
    Given live search currently shows the result for "grid"
    When the person continues the query to "grid and"
    Then the grid result remains visible
    And a gentle hint says the search command is unfinished
    When the person corrects the query to "grid"
    Then the hint disappears
    And normal live search continues

## Assumptions
- Unmatched quotation marks, unmatched parentheses, and trailing command words are treated as incomplete expressions.
