Scenario ID: SCN-010
Title: Choose sort order for the whole collection; remembered default; applies to filters and search
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

- A Sort control offers five orders:
  - Newest added (initial default)
  - Oldest added
  - Recently updated
  - Title A–Z
  - Title Z–A
- "Recently updated" orders by the most recent meaningful change to a bookmark —
  including changes to its details (title/description/link), tags, note, or
  reading status — most-recently-changed first.
- The chosen order applies consistently across the whole collection and to every
  view: search results and each filtered view (To read / Finished / All /
  Archived) use the same selected order.
- Once the user changes the sort order, the app remembers it as their preferred
  default and uses it next time. (Newest added is only the initial default.)
- A count/status line states the currently active order.

## Gherkin

Feature: Sorting

  Scenario: Default order
    Given the user has never changed the sort order
    Then bookmarks are ordered by "Newest added"

  Scenario: Change and remember the order
    When the user selects a different sort order
    Then the collection reorders accordingly
    And that order becomes the remembered default for next time

  Scenario: Recently updated definition
    Given bookmarks changed at different times (details, tags, note or status)
    When the order is "Recently updated"
    Then the most recently changed bookmark appears first

  Scenario: Order applies to filters and search
    Given a sort order is selected
    When the user applies a status filter or a search
    Then the filtered/searched results use that same sort order

## Assumptions
- The remembered default is per user (single-user app).
- Title sorting is case-insensitive alphabetical.
