Scenario ID: SCN-010
Title: Saved copy of a PDF keeps the real file, not mangled text
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When the saved link is a PDF (research papers, manuals, an emailed recipe PDF),
the saved copy keeps the actual PDF file intact and opens it as a PDF, rather
than squeezing it into the text reading view. Web pages continue to keep a
readable text copy; PDFs keep the file. The app distinguishes the two and
presents the right kind of saved copy for each.

## Gherkin
Feature: PDF saved copy

  Scenario: Saved copy of a PDF opens as a PDF
    Given the client saved a link that is a PDF
    When the client opens its saved copy
    Then the original PDF file is kept intact
    And it opens as a PDF, not as converted text

  Scenario: Web page vs PDF get different saved-copy views
    Given one saved link is a web article and another is a PDF
    When the client opens each one's saved copy
    Then the web article shows a readable text copy
    And the PDF shows the kept PDF file

## Assumptions
- The app detects PDF links and stores the file itself.
- Client considers PDFs a large share of read-later items.
