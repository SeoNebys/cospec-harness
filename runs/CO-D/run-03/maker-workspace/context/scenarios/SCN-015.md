Scenario ID: SCN-015
Title: Import browser bookmarks and export the library in standard bookmark HTML
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

Import:
- The user imports a standard bookmarks HTML file (as exported by browsers or
  other bookmark apps).
- Before importing, a preview shows: how many are new, how many are already in the
  library (matched by web address and SKIPPED — no duplicates, per SCN-006), and
  that original titles and save dates from the file are kept.
- Option "Turn browser folders into tags" (e.g. News ▸ Tech -> #news #tech):
  ON by default, to preserve the organisation the user already has.
- Option "Add imported bookmarks to To read": OFF by default (a large import of
  years-old links must not flood the To read view). The user can enable it.
- Preserved local copies (SCN-013) for imported pages are captured in the
  background afterward; importing does not wait on them.

Export:
- The user exports the library as a standard bookmarks HTML file readable by
  browsers and other apps.
- Scope choices: entire library, current view/collection, or include archived.
- The file keeps each bookmark's title, tags, and original save date using the
  standard TAGS and ADD_DATE fields.
- The user's note, reading status, and archive status are included as
  COMPATIBLE EXTRA information so that re-importing the file into THIS app restores
  those details, while the file still opens fine in other bookmark apps.

## Gherkin

Feature: Import and export

  Scenario: Import preview and dedup
    Given a bookmarks HTML file
    When the user chooses it to import
    Then a preview shows new vs already-existing (matched by web address, skipped)
    And titles and original save dates are preserved

  Scenario: Import default options
    Given the import preview
    Then "folders into tags" is on by default
    And "add to To read" is off by default

  Scenario: Export keeps standard fields plus compatible extras
    When the user exports the library
    Then the file records title, tags and original save date in standard fields
    And note, reading status and archive status are included as extra data
    And the file remains readable by other bookmark apps

  Scenario: Round-trip restores extras
    Given a file exported from this app
    When it is re-imported into this app
    Then note, reading status and archive status are restored

## Assumptions
- Standard format = Netscape bookmark HTML (TAGS, ADD_DATE).
- Import status default is neither To read nor Finished flooding; imported items
  simply live in the library (All) unless the user opts them into To read.
