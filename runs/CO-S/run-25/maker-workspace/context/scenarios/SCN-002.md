Title: Tag a saved link, reusing existing tags
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
From a saved item's card, the client opens a small tag picker via an "add tag"
affordance. The picker shows the tags already used across the library so the
client can reuse them for consistency; clicking a tag adds it, clicking an
already-applied tag removes it. The client can also type a brand-new tag and
confirm with Enter to create and apply it.

Applied tags are shown directly on the item's card (not hidden behind a details
view), so the library stays easy to scan. A tag can be removed from a card via a
small remove control on the tag chip.

Tags are automatically lowercased. Adding a tag that is already applied to the
same item (exact duplicate) has no effect.

## Gherkin
Feature: Tag a saved link

  Scenario: Reuse an existing tag
    Given a saved item exists in the library
    And tags have been used before across the library
    When the client opens the tag picker on that item
    And selects an existing tag
    Then that tag is applied to the item
    And the tag is shown on the item's card

  Scenario: Create a new tag
    Given the client has opened the tag picker on a saved item
    When the client types a tag name that does not exist and confirms
    Then the tag is created, applied to the item, and shown on its card
    And the new tag becomes available to reuse on other items

  Scenario: Tags are normalised to lowercase
    Given the client is adding a tag
    When the client enters the tag with any capitalisation
    Then the tag is stored and displayed in lowercase

  Scenario: Prevent duplicate tag on the same item
    Given an item already has a given tag
    When the client adds the same tag again to that item
    Then the item's tags are unchanged

  Scenario: Remove a tag from an item
    Given an item has a tag
    When the client removes that tag via its remove control
    Then the tag no longer appears on the item's card

## Assumptions
- The tag vocabulary offered in the picker is drawn from tags already used across
  the library.
- Tags are displayed on the card, contributing to at-a-glance scanning (SCN-001).
- Removing a tag from an item does not delete the tag from the library vocabulary
  while other items still use it (tag-vocabulary lifecycle to be explored later).
