Scenario ID: SCN-019
Title: Preserve valid edits when saving is interrupted
Type: Error Case
Approval status: approved
Approval session: SESSION-019
Approval cycle: 1

## Approved behaviour
If an otherwise valid edit cannot be saved because of a temporary interruption, the inline form stays open with every attempted change intact. The previously saved bookmark remains unchanged, a clear message explains that saving failed, and the user can retry without re-entering anything. A successful retry applies the complete edit and confirms it was saved.

## Gherkin
Feature: Recover from an interrupted bookmark update

  Scenario: Retry a failed save without losing edits
    Given a valid bookmark is saved in the library
    And the user has made valid changes in its edit form
    When saving is temporarily interrupted
    Then the edit form remains open
    And every attempted change remains in its field
    And the previously saved bookmark remains unchanged
    And the app explains that the changes were not saved
    When the user retries and saving succeeds
    Then the complete edit is applied
    And the app confirms that the changes were saved

## Assumptions
- A failed attempt does not partially apply any field.
- Retry uses the values still shown in the form.
