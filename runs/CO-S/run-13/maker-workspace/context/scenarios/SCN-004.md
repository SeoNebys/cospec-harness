Scenario ID: SCN-004
Title: Filter the list to one tag by clicking it on a bookmark
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

Each saved bookmark shows its tags as clickable labels. Clicking a tag on any
bookmark filters the list to show only bookmarks that carry that tag. A banner
appears above the list reading "Showing only tag: <tag>" with a "✕ clear" control;
clicking clear removes the filter and restores the full list. Filtering is by one
tag at a time (tags are not stacked). The tag filter works together with the
search box (both narrow the list at once). The count reads "showing X of Y" while
a filter is active.

Chosen over a dedicated filter bar (Version A) because clicking the tag where it
is seen is more natural and the banner makes the active filter and how to clear it
obvious.

## Gherkin
Feature: Filtering bookmarks by tag

  Scenario: Filter by clicking a tag on a bookmark
    Given I have bookmarks with tags
    When I click a tag shown on one of the bookmarks
    Then the list shows only bookmarks that have that tag
    And a banner shows which tag is being filtered
    And the count shows how many of the total are shown

  Scenario: Clear the tag filter
    Given a tag filter is active
    When I click the clear control in the banner
    Then the filter is removed and the full list is shown

  Scenario: Tag filter combines with search
    Given a tag filter is active
    When I also type text in the search box
    Then the list shows only bookmarks matching both the tag and the text

## Assumptions
- Filtering is by a single tag at a time (no stacking of multiple tags). (Confirmed.)
- The tag filter and the text search apply together (logical AND).
