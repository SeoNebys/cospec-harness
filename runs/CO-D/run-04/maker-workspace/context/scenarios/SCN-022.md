Scenario ID: SCN-022
Title: Pasting something that isn't a web address
Type: Error Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
If the client tries to save text that isn't a web address (a stray thought, a
typo), nothing is saved and no broken/phantom card is created. The input is
flagged calmly (not alarmingly) with a plain message — "That doesn't look like a
web address — nothing was saved" — and, since a mis-typed save is often a
mistargeted search, it offers to search the library for the typed text instead.
The typed text is never silently kept as a dead link.
