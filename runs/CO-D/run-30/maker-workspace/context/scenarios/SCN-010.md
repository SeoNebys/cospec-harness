Scenario ID: SCN-010
Title: Mark a bookmark to read later and view the reading list
Type: Happy Path
Approval status: approved
Approval session: SESSION-010
Approval cycle: 1

## Approved behaviour

Each bookmark card includes a clearly labelled Read later checkbox whose checked state is visible on the card. Checking it marks the bookmark for later. Selecting the dedicated Read later collection filter immediately shows only marked bookmarks, updates the result count, and leaves live search available. The checkbox communicates that the state can be turned on or off.

## Gherkin

Feature: Reading saved bookmarks later

  Scenario: Add a bookmark to the reading list and view it
    Given the collection contains one bookmark already marked to read later
    And another bookmark is not marked
    When the user checks "Read later" on the unmarked bookmark
    And selects the "Read later" collection filter
    Then both marked bookmarks are visible
    And the result count shows two results
    And live search remains available

## Assumptions

- Read later is a reversible state represented by a checkbox on each card.
- A dedicated Read later filter appears above the collection.
