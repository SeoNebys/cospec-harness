Scenario ID: SCN-008
Title: Move a bookmark between To read and Done
Type: Happy Path
Approval status: approved
Approval session: SESSION-008
Approval cycle: 1

## Approved behaviour
A visible action on a bookmark changes it from To read to Done. Afterward, the same control becomes Move to To read, making the two-state change reversible and making the undo direction clear.

## Gherkin
Feature: Track reading status

  Scenario: Mark a bookmark done
    Given a bookmark is To read
    When the person selects "Mark done"
    Then the bookmark becomes Done
    And its status action becomes "Move to To read"

  Scenario: Return a done bookmark to To read
    Given a bookmark is Done
    When the person selects "Move to To read"
    Then the bookmark becomes To read
    And its status action becomes "Mark done"

## Assumptions
- A bookmark has exactly one of two reading statuses: To read or Done.
- The status action is available directly on the bookmark.
