Scenario ID: SCN-008
Title: Find bookmarks by searching within the current view
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

A search box filters the bookmarks in the current view only. Search never
crosses views: searching in To read shows only To read matches; Done and
Archived likewise. Archived bookmarks never appear in an ordinary (To read or
Done) search — they are searched deliberately from the Archived view. Plain
words match against a bookmark's title, full link, description and note,
ignoring capitalisation. A hint shows the number of matches in the current view,
and a clear no-matches message when none are found.

## Gherkin

Feature: Search bookmarks

  Scenario: Plain-word search within a view, case-insensitive
    Given several bookmarks in the "To read" view
    When the user searches for a word in any case
    Then only "To read" bookmarks whose title, link, description or note contain that word (any case) are shown
    And a hint states the number of matches in "To read"

  Scenario: Search is scoped to the current view
    Given a bookmark that would match a search but has been archived
    When the user searches from the "To read" view
    Then the archived bookmark does not appear
    When the user runs the same search from the "Archived" view
    Then the archived bookmark appears

  Scenario: No matches
    Given a search with no matching bookmarks in the current view
    Then a clear "no matches" message is shown for that view

## Assumptions
- Plain words search title, link, description and note; capitalisation ignored.
- Search results never span more than the current view.
