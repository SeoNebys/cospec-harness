Scenario ID: SCN-015
Title: Prevent duplicate tags with different capitalization
Type: Edge Case
Approval status: approved
Approval session: SESSION-015
Approval cycle: 1

## Approved behaviour
Tag names are treated without regard to capitalization. Trying to add the same tag again with different capitalization does not create another chip; the bookmark keeps a single lowercase tag so labels remain consistent.

## Gherkin
Feature: Organizing saved bookmarks

  Scenario: Add the same tag with different capitalization
    Given a bookmark already has a tag
    When the person tries to add that tag again using different capitalization
    Then no additional tag chip is created
    And the bookmark keeps one lowercase version of that tag

## Assumptions
- Tag names are displayed in lowercase.
- Capitalization alone never distinguishes two tags.
