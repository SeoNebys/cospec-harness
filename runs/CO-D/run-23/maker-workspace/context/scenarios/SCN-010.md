Scenario ID: SCN-010
Title: Put a bookmark away and restore it later
Type: Happy Path
Approval status: approved
Approval session: SESSION-010
Approval cycle: 1

## Approved behaviour
A person can put a bookmark away directly from its card without a destructive warning. The bookmark disappears from the main library and is excluded from normal search, while remaining whole and unchanged in a separate Put away view. From that view, the person can restore it directly on its card, returning it to the main library and normal search. Putting away and restoring operate on the same bookmark and do not create copies.

## Gherkin
Feature: Put away bookmarks reversibly

  Scenario: Put a bookmark away without deleting it
    Given a bookmark is visible in the main library
    When the person chooses Put away on its card
    Then the bookmark is removed from the main library view
    And it remains whole and unchanged in the Put away view
    And no destructive warning is required

  Scenario: Exclude a put-away bookmark from normal search
    Given the CSS Grid bookmark is in the Put away view
    When the person searches the normal collection for "CSS Grid"
    Then that bookmark is not included in the search results
    And it remains available in the Put away view

  Scenario: Restore a put-away bookmark
    Given a bookmark is in the Put away view
    When the person chooses Restore to library on its card
    Then the same bookmark returns to the main library
    And it is included in normal search again
    And no duplicate is created

## Assumptions
- Put away is a separate view in the sidebar.
- Put away and Restore to library are direct card actions.
- Put-away bookmarks are excluded from the main library and normal search.
- Put-away bookmarks retain all their details and preserved content.
