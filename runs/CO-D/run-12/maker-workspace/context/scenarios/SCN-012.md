Scenario ID: SCN-012
Title: Show an empty Read later list without implying deletion
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When no bookmarks remain in Read later, its count is zero and the view says the user is all caught up while explicitly reassuring them that their bookmarks remain safe. Returning to All bookmarks shows the complete saved collection unchanged.

## Gherkin
Feature: Reading list

  Scenario: All read-later bookmarks have been completed
    Given saved bookmarks exist in All bookmarks
    And no bookmarks remain marked Read later
    When the user opens Read later
    Then the Read later count is zero
    And the view says the user is all caught up
    And the view explains that bookmarks remain safe in the main collection
    When the user opens All bookmarks
    Then all saved bookmarks are shown unchanged

## Assumptions
- The empty Read later view explicitly distinguishes completion from deletion.
