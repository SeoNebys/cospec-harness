Scenario ID: SCN-005
Title: Assign reusable tags while saving a bookmark
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The save preview provides a tag field beneath the editable description. As the person types, a dropdown suggests matching tags already used in the library. Choosing a suggestion adds it as a tag chip. Multiple tags can be attached, a new tag can be created by typing it and pressing Enter, and any chosen tag can be removed. Capitalization and a simple singular/plural difference resolve to the existing tag rather than creating a near-duplicate. Saving confirms the complete set of assigned tags alongside the final title and description. The client selected the dropdown suggestion presentation after comparing it with inline suggestions.

## Gherkin
Feature: Assign tags to a bookmark

  Scenario: Add more than one existing and new tag
    Given the save preview is displayed and the library already contains the tag "Recipes"
    When the user types part of "Recipes" and chooses it from the dropdown suggestions
    And the user types the new tag "Research" and presses Enter
    Then the bookmark preview shows both "Recipes" and "Research" as assigned tags

  Scenario: Remove an assigned tag
    Given a bookmark preview has more than one assigned tag
    When the user removes one tag with its remove control
    Then that tag is no longer assigned
    And the other assigned tags remain

  Scenario: Avoid a near-duplicate tag
    Given "Recipes" is already assigned to the bookmark
    When the user enters "recipe"
    Then no second tag is assigned
    And the app states that "Recipes" is already assigned

  Scenario: Confirm saved tag assignment
    Given the save preview contains final title, description, and assigned tags
    When the user saves the bookmark
    Then the confirmation displays the exact final title and description
    And the confirmation displays every assigned tag

## Assumptions
- Existing-tag suggestions appear in a dropdown adjacent to the text being typed.
- Suggestions match without regard to capitalization.
- The approved near-duplicate protection covers capitalization and simple singular/plural variants.
- Pressing Enter creates a tag when no protected existing equivalent is found.
