Scenario ID: SCN-009
Title: Sort the collection independently of search and filters
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A Sort control offers four orders: Newest saved (the default), Oldest saved,
Title A–Z, and Title Z–A. Choosing an order reorders the collection. Sorting is
independent of the active search, tag filters, and read/finished view: changing
the order never clears the current search or filters, and applying filters keeps
the chosen order. Newly saved bookmarks appear at the top under "Newest saved".
Title sorting is case-insensitive. The client confirmed these four orders,
Newest as the initial default, and independence from search/filters.

## Gherkin
Feature: Sorting

  Scenario: Choose a sort order
    When I choose one of Newest saved / Oldest saved / Title A–Z / Title Z–A
    Then the collection is reordered accordingly

  Scenario: Newest is the initial default
    Given I have not changed the order
    Then the collection is ordered by Newest saved

  Scenario: Sorting is independent of search and filters
    Given a search and/or tag and/or status filter is active
    When I change the sort order
    Then the filters remain applied
    And the visible bookmarks are shown in the new order

## Assumptions
- "Saved" order uses each bookmark's save time; title order is case-insensitive.
