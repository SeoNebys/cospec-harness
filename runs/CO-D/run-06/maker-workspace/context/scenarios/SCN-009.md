Scenario ID: SCN-009
Title: Add new or existing tags while saving
Type: Happy Path
Approval status: approved
Approval session: SESSION-009
Approval cycle: 1

## Approved behaviour
While saving a bookmark, a person can type tags freely. As they type, previously used tags with matching names are suggested without regard to capitalization and show prior usage. Choosing a suggestion adds the established tag as a removable chip. If no existing tag matches, pressing Enter creates the typed tag as a removable chip. Tags are optional and several may be added to one bookmark.

## Gherkin
Feature: Organizing saved bookmarks

  Scenario: Reuse an existing tag while saving
    Given previously used tags exist
    When the person types text matching an existing tag without regard to capitalization
    Then matching existing tags are suggested with their prior usage
    When the person chooses a suggestion
    Then the existing tag is added to the bookmark as a removable chip

  Scenario: Create a new tag while saving
    Given no existing tag matches the text the person has typed
    When the person presses Enter
    Then a new tag is added to the bookmark as a removable chip

## Assumptions
- Tags are optional.
- Several tags may be attached to one bookmark.
- Suggestions match typed text within existing tag names.
- A tag chip can be removed before saving.
