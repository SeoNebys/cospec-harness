Scenario ID: SCN-007
Title: Archive — put a bookmark away without losing it
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

Archiving a bookmark hides it from the Collection and from ordinary searches
(Collection and Reading list). It is not deleted: it lives in the Archive view,
where it can be found by searching within the Archive, and it can be restored to
the Collection at any time. Archiving and reading-list membership are independent
concepts serving different purposes.

## Gherkin

Feature: Archive

  Scenario: Archive hides a bookmark from the collection and ordinary search
    Given an active bookmark
    When I archive it
    Then it no longer appears in the Collection or Reading list
    And an ordinary search does not surface it

  Scenario: Archived bookmarks are kept and findable in the Archive
    Given an archived bookmark
    When I open the Archive view
    Then the bookmark is listed there
    And searching within the Archive can find it

  Scenario: Restore an archived bookmark
    Given an archived bookmark
    When I choose "Restore to collection"
    Then it returns to the Collection
    And its reading-list membership is unchanged

## Assumptions
- Restoring returns the bookmark to whatever reading-list state it had before
  archiving.
