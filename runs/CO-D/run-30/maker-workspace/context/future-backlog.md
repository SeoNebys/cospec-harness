# Later-cycle requests

## Preserve page content when saving

When a bookmark is saved, preserve a readable copy of the page as it existed at that time so the user can still return to its content if the original page later changes or disappears. This is a distinct future feature and is not part of cycle 1 implementation.

Captured from: SESSION-027

## User-controlled collection sorting

Clarify and design ways to sort the collection in a later cycle. Cycle 1 will use a consistent default order; this note does not expand the approved cycle 1 scope.
