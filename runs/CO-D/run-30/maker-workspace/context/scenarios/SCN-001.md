Scenario ID: SCN-001
Title: Save a new bookmark with automatically collected page details
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

From an empty personal collection, the client can open a small save pop-up and paste a web address without typing any descriptive details. After saving, the collection shows one readable card containing the site's name and icon, the page title, a short description, and the address. The card is recognizable at a glance.

## Gherkin

Feature: Saving bookmarks

  Scenario: Save the first bookmark using page details
    Given the personal bookmark collection is empty
    When the user submits the address of a web page
    Then one bookmark is saved
    And the bookmark card shows the site's name and icon
    And the bookmark card shows the page title and a short description
    And the bookmark card shows the saved web address
    And the user did not need to type those page details

## Assumptions

- The app is a personal web app for one user.
- The saved page exposes a title, description, and site identity that can be collected.
- The collection uses cards as its primary presentation.
- Adding a bookmark starts from a small pop-up.
