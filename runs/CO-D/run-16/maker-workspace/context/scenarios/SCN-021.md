Scenario ID: SCN-021
Title: Send a page to the Internet Archive
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Separately from the app's own preserved copy, the client can optionally send a
bookmarked page to the Internet Archive. This is an on-demand action, not
automatic. After submission, the bookmark shows a link to the archived copy on
the Internet Archive.

## Gherkin
Feature: Internet Archive submission

  Scenario: Submit on demand
    Given a bookmark
    When the client chooses to send the page to the Internet Archive
    Then the page is submitted to the Internet Archive
    And the bookmark shows a link to the archived copy

  Scenario: Not automatic
    Given a newly saved bookmark
    Then it is not sent to the Internet Archive unless the client requests it

## Assumptions
- Requires the external Internet Archive service; the prototype simulated it.
- The app's own preserved copy (SCN-020) is independent of this submission.
