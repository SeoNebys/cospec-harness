Scenario ID: SCN-011
Title: Open a bookmark's original web page in a new tab
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

- Several parts of a bookmark card open its original web page: the title, the
  preview image, the web address, and an explicit "Open page" button.
- The page opens in a NEW browser tab, so the bookmark library stays open and the
  user does not lose their place.
- The rest of the card is inactive for opening: clicking a tag pill filters by
  that tag, and management controls (Edit, Archive, etc.) perform their own
  actions; none of these open the page. This keeps clicks unambiguous.

## Gherkin

Feature: Open the original page

  Scenario: Open via title, preview, address, or button
    Given a saved bookmark
    When the user clicks its title, preview image, web address, or "Open page" button
    Then the original web page opens in a new browser tab
    And the bookmark library remains open in the original tab

  Scenario: Non-opening controls keep their own behaviour
    When the user clicks a tag pill
    Then results are filtered by that tag and the page is not opened
    When the user clicks a management control (e.g. Edit, Archive)
    Then that action runs and the page is not opened

## Assumptions
- "Open page" targets the bookmark's stored original URL.
- New-tab open is the default; no same-tab option is provided.
