Scenario ID: SCN-002
Title: Correct a bookmark's title and description inline
Type: Happy Path
Approval status: approved
Approval session: SESSION-002
Approval cycle: 1

## Approved behaviour
From a bookmark card, the person opens editing and the title and description become editable in place on that card. Saving the changes updates the card in place without a pop-up taking over the screen.

## Gherkin
Feature: Editing bookmark details

  Scenario: Correct an automatically gathered title and description
    Given a saved bookmark is visible in the collection
    When the person opens its details for editing
    Then the editable fields appear in place on the bookmark card
    When the person changes the title and description and saves
    Then the corrected title and description appear on that card
    And no separate pop-up is used

## Assumptions
- Inline editing is the selected interaction for bookmark corrections.
- The title and description are ordinary editable details.
- Address correction is explored separately because changing it may affect page-derived details.
