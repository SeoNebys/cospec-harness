Scenario ID: SCN-005
Title: Empty states (first run, empty tab, no search results)
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When there are no bookmarks at all (brand-new user), the app shows a welcoming
message that points directly to the "Save a link" action, and both tab counts
show 0, rather than a blank screen. When a tab has no items, it shows a short
message ("Nothing left to read — nice." for To read; "Nothing finished yet." for
Finished). When a search or tag filter returns nothing, the list shows "No
bookmarks match your search." rather than empty space.

## Gherkin
Feature: Graceful empty states

  Scenario: Brand-new user with no bookmarks
    Given no bookmarks have been saved
    When the user opens the app
    Then a welcoming message pointing to "Save a link" is shown
    And both tab counts show 0

  Scenario: Save the first bookmark clears the empty state
    Given no bookmarks have been saved
    When the user saves a bookmark
    Then the welcoming message is replaced by the bookmark in the To read tab

  Scenario: Empty tab message
    Given a tab has no bookmarks in its state
    When the user views that tab
    Then a short message for that tab is shown

  Scenario: No search results
    Given a search term or tag filter matches no bookmarks
    Then the list shows "No bookmarks match your search."

## Assumptions
- The first-run message directs the user to the save action.
- Empty-tab and no-results messages are distinct from the first-run message.
