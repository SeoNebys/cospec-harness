Scenario ID: SCN-017
Title: Bulk tag add/remove with suggestions
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When adding tags in bulk, the client gets tag suggestions drawn from their
existing tags (the same source used when saving a bookmark), with a text box and
clickable chips that filter as the client types. When removing tags in bulk, the
suggested chips are limited to the tags that actually occur on the selected
bookmarks, so the client does not need to remember or retype them. Adding a tag
skips bookmarks that already have it; removing a tag strips it from all selected
bookmarks that have it.

## Gherkin
Feature: Bulk tag suggestions

  Scenario: Bulk add tags with existing-tag suggestions
    Given several bookmarks are selected
    When the client opens the bulk "Add tags" panel
    Then suggestions from the client's existing tags are shown and filter as they type
    And applying adds the chosen tags to all selected bookmarks without duplicating

  Scenario: Bulk remove tags limited to present tags
    Given several bookmarks are selected
    When the client opens the bulk "Remove tags" panel
    Then only tags that occur on the selected bookmarks are offered
    And applying removes the chosen tags from all selected bookmarks

## Assumptions
- Tag matching is case-insensitive.
