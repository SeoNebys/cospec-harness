Scenario ID: SCN-003
Title: Narrow the collection by tag
Type: Happy Path
Approval status: approved
Approval session: SESSION-003
Approval cycle: 1

## Approved behaviour

The client's own tags are listed in the sidebar with a count of the bookmarks assigned to each one, and every bookmark card displays its assigned tags. Selecting a tag narrows the collection to bookmarks carrying that tag, clearly marks the active tag, and shows the matching result count.

The client selected the always-visible sidebar as the preferred tag interaction after comparing it with tags above the collection and tags inside a filter menu.

## Gherkin

Feature: Organize and find bookmarks with tags

  Scenario: Narrow the collection to a selected tag
    Given the personal collection contains bookmarks assigned to different tags
    And the sidebar shows each tag with its bookmark count
    When the user selects a tag from the sidebar
    Then only bookmarks assigned to that tag are shown
    And the selected tag is visibly active
    And the matching result count is shown
    And each result card displays its assigned tags

## Assumptions

- Tag names and bookmark assignments in the prototype are illustrative only.
- The approved behavior selects one tag at a time using an always-visible sidebar list.
- How tags are created and assigned is explored separately from using them to narrow the collection.
