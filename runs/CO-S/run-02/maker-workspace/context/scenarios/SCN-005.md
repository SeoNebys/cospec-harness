Scenario ID: SCN-005
Title: Edit, archive, restore, or delete a bookmark
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Less-frequent bookmark actions are grouped behind a single Manage control. The client can edit a bookmark's title or address and save the changes without recreating it. Archiving removes a bookmark from All bookmarks but retains it in an Archive view, from which it can be restored. Deleting first asks for confirmation and, once confirmed, permanently removes the bookmark instead of archiving it.

## Gherkin
Feature: Managing saved bookmarks

  Scenario: Edit a saved bookmark
    Given a bookmark has been saved
    When the user opens Manage and chooses Edit
    And changes its title or address
    And saves the changes
    Then the bookmark displays the changed details

  Scenario: Archive and restore a saved bookmark
    Given a bookmark is visible in All bookmarks
    When the user opens Manage and archives it
    Then the bookmark is absent from All bookmarks
    And it is visible in the Archive view
    When the user restores the archived bookmark
    Then it is absent from the Archive view
    And it is visible in All bookmarks

  Scenario: Permanently delete a saved bookmark
    Given a bookmark has been saved
    When the user opens Manage and chooses Delete
    Then the app asks for confirmation
    When the user confirms deletion
    Then the bookmark is permanently removed
    And it is not placed in the Archive

## Assumptions
- Edit, Archive, and Delete are grouped behind a single Manage control.
- Editing supports the bookmark title and web address.
- Archive is reversible and Delete is permanent.
- Permanent deletion requires explicit confirmation.
