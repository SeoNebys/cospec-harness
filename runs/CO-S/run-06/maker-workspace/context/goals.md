# Business goal

## Cycle 1 — recorded SESSION-001 (2026-09-17)

### Client's words (verbatim)
- "It's mainly for me. My bookmarks are scattered and I rarely find them again
  when I need them."
- "I'd like to save a link quickly, have its basic details filled in
  automatically, and add tags or a short note for context. The real payoff is
  being able to search and filter reliably later, including keeping a separate
  'read later' list and archiving links I want to retain without cluttering the
  main view."
- "Finding things again is the core goal, and quick saving makes it practical."
- "I'd like it to be a web app I can use in a browser, with a layout that also
  works comfortably on my phone."

### Goal statement
A personal bookmark tool whose core goal is **reliably finding saved links
again later** through search and filtering. Quick saving — with basic details
filled in automatically and optional tags / short note for context — is the
means that makes finding practical. Includes a separate **"read later"** list
and the ability to **archive** links to retain without cluttering the main view.

### Interface form
Web app used in a browser, with a responsive layout that also works comfortably
on a phone.

### Scope note
Single user (the client). No multi-user / sharing mentioned.
