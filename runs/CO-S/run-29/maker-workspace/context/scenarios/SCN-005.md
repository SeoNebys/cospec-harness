Scenario ID: SCN-005
Title: Reject incomplete and duplicate bookmark saves
Type: Error Case
Approval status: approved
Approval session: SESSION-005
Approval cycle: 1

## Approved behaviour
If the user tries to save without a name or with an incomplete web address, the save form remains open, preserves what was entered, shows a clear message directly beneath each problem field, and saves nothing until both problems are corrected. A complete address must begin with http:// or https://. If the web address already belongs to a saved bookmark, the duplicate is blocked even when a different name is entered, and the form points out the existing bookmark by name.

## Gherkin
Feature: Validating bookmark saves

  Scenario: Reject a missing name and incomplete web address
    Given the personal bookmark collection is empty
    And the save form is open
    When the user leaves the name empty
    And enters “developer.mozilla.org” as the web address
    And tries to save the bookmark
    Then the save form remains open
    And the entered web address is preserved
    And a message beneath the name asks for a recognizable name
    And a message beneath the address asks for a full address beginning with http:// or https://
    And no bookmark is saved

  Scenario: Save after correcting invalid fields
    Given the save form shows problems for a missing name and incomplete address
    When the user supplies a name
    And supplies a complete address beginning with http:// or https://
    And saves the bookmark
    Then the corrected bookmark is saved using the approved save flow

  Scenario: Reject a duplicate web address saved under another name
    Given “MDN Web Docs” is saved with the address “https://developer.mozilla.org”
    And the save form is open
    When the user enters the name “MDN reference copy”
    And enters the address “https://developer.mozilla.org”
    And tries to save the bookmark
    Then the save form remains open
    And no second bookmark is saved
    And a message says that the address is already saved as “MDN Web Docs”

## Assumptions
- A bookmark name is required.
- A web address is required and must begin with http:// or https://.
- Exact duplicate web addresses are not allowed, regardless of bookmark name.
- Validation problems are shown directly beneath the relevant field.
- Entered values are preserved when saving is blocked.
