Scenario ID: SCN-013
Title: Delete a bookmark with a brief undo, then permanent
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

Each bookmark has a **Delete** action. Deleting removes the item immediately and
shows a bottom **undo bar** ("Deleted … — Undo") for a few seconds; clicking Undo
restores the item to where it was. Once the undo period ends, the deletion is
**permanent**. This is distinct from archiving: archiving keeps the item, delete
removes it for good after the grace period.

## Gherkin
Feature: Delete a bookmark

  Scenario: Delete with undo
    Given a bookmark is shown
    When the user deletes it
    Then it is removed from the list immediately
    And an undo bar is shown for a few seconds
    And clicking Undo within that time restores the bookmark

  Scenario: Deletion becomes permanent
    Given a bookmark was deleted
    When the undo period elapses without Undo
    Then the bookmark is permanently removed

## Assumptions
- Deletion is quick (no confirmation prompt); safety comes from the undo window.
- After the undo window, there is no further recovery.
