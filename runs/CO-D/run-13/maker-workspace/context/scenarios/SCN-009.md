Scenario ID: SCN-009
Title: Sort the list — newest added, oldest added, or title
Type: Happy Path (edge/active-extension)
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

A Sort control offers three orders: Newest added (default), Oldest added, and
Title (A–Z). Choosing one reorders the current list. Sorting applies to the
whole matching set (current view + tag filter + search), not only what is
currently loaded (see SCN-010). The client confirmed a dropdown control and that
these three orders are enough for now (no "recently read").

## Assumptions
- Default order is Newest added.
- Sorting is applied before the "Load more" batching (SCN-010).
