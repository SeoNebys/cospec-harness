Scenario ID: SCN-016
Title: Manually edit saved bookmark details
Type: Edge Case
Approval status: approved
Approval session: SESSION-016
Approval cycle: 1

## Approved behaviour

The client can choose Edit details from a bookmark's More actions menu and
change its saved title or description. Saved changes appear on the bookmark
card immediately while the bookmark address and labels remain unchanged.

## Gherkin

Feature: Saved bookmark details

  Scenario: Change a saved bookmark title
    Given a bookmark has captured page details, an address, and labels
    When the client changes its title through "More actions" and saves
    Then the new title is shown on the bookmark card
    And its address remains unchanged
    And its labels remain unchanged

  Scenario: Change a saved bookmark description
    Given a bookmark has captured page details, an address, and labels
    When the client changes its description through "More actions" and saves
    Then the new description is shown on the bookmark card
    And its address remains unchanged
    And its labels remain unchanged

## Assumptions

- Editing details is an occasional action placed in the More actions menu.
- The editable captured details are the title and description, not the bookmark address.
