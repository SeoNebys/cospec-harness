Scenario ID: SCN-020
Title: Settings for text size and items-per-page, with Previous/Next paging
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A single Settings panel holds the client's preferences (default sort, auto local
copy, and now:) Text size — Small / Medium / Large, applied across titles,
descriptions, notes and tags; and Bookmarks shown per page — 10 / 25 / 50 / All.
The list uses classic Previous/Next paging showing the client's position
("Page p of n · showing a–b of total"); choosing All turns paging off. Changing
search, tags, view or sort returns to page 1. Preferences persist across sessions.

## Gherkin
Feature: Display settings and paging

  Scenario: Change text size
    When the client sets Text size in Settings
    Then titles, descriptions, notes and tags render at that size
    And the choice persists across sessions

  Scenario: Change items per page
    When the client sets Bookmarks shown per page
    Then the list pages in that size with Previous/Next controls
    And choosing All shows every matching bookmark without paging

  Scenario: Position is clear and resets on new filtering
    Given a paged list
    Then the current page and range of the total are shown
    And changing search, tags, view or sort returns to page 1

## Assumptions
- Paging is Previous/Next (client prefers a clear position over load-more/infinite
  scroll).
- All preferences live in one Settings panel.
