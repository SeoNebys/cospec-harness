Scenario ID: SCN-021
Title: Open the separate Read later collection
Type: Happy Path
Approval status: approved
Approval session: SESSION-021
Approval cycle: 1

## Approved behaviour
Selecting Read later in the sidebar opens a focused collection containing only bookmarks currently marked for later. Its heading and count reflect that pile, while each bookmark retains its normal card details and labels.

## Gherkin
Feature: Read later

  Scenario: View bookmarks waiting to be read
    Given two saved bookmarks are in Read later
    And another saved bookmark is not
    When the person selects Read later in the sidebar
    Then only the two Read later bookmarks are shown
    And the heading identifies the Read later collection
    And the count is two
    And their bookmark details and labels are unchanged

## Assumptions
- Read later is a focused view of saved bookmarks, not a separate copy of them.
