Scenario ID: SCN-008
Title: Archive and restore a bookmark without deleting it
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A visible Archive button moves a bookmark out of the main library without deleting it and updates the visible count. The Archive view preserves the bookmark's title, description, labels, and reading status. A visible Restore button returns the same bookmark to the main library without creating a duplicate, and both moves show clear confirmation.

## Gherkin
Feature: Archiving bookmarks

  Scenario: Move a bookmark out of the main library
    Given the main library contains a bookmark
    When the client chooses its visible Archive action
    Then the bookmark is removed from the main library
    And the main-library count decreases
    And a confirmation says the bookmark was archived rather than deleted
    And the bookmark becomes available in the Archive view

  Scenario: Preserve an archived bookmark's information
    Given a bookmark has been archived
    When the client opens the Archive view
    Then the bookmark retains its title and description
    And it retains all its labels
    And it retains its reading status

  Scenario: Restore an archived bookmark
    Given the Archive view contains a bookmark
    When the client chooses its visible Restore action
    Then that same bookmark returns to the main library
    And it is removed from the Archive view
    And no duplicate bookmark is created
    And a confirmation says the bookmark was restored

## Assumptions
- Archive is distinct from deletion and does not destroy bookmark data.
- Archive and Restore are visible plain-language buttons.
- Restoring preserves all bookmark details and identity.
