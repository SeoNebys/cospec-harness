Scenario ID: SCN-020
Title: Preserve a bookmark on the Internet Archive
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

As an **additional, independent** safeguard alongside the user's own local
full-page copy, a bookmark can be preserved on the **Internet Archive**. The user
triggers "Save to Internet Archive"; once done, the bookmark shows an
"On Internet Archive" indicator and a link to view the archived version on
archive.org. This record is **separate from** the local copy — either, both, or
neither may exist for a given bookmark.

## Gherkin
Feature: Internet Archive safeguard

  Scenario: Preserve on the Internet Archive
    Given a bookmark is shown
    When the user chooses "Save to Internet Archive"
    Then the bookmark is submitted to the Internet Archive
    And it then shows an "On Internet Archive" indicator with a link to the archived version

  Scenario: Independent of the local copy
    Given a bookmark
    Then it may have a local full-page copy, an Internet Archive record, both, or neither

## Assumptions
- The Internet Archive is an external service; availability depends on it.
- The archived-version link points to archive.org for the bookmark's URL.
