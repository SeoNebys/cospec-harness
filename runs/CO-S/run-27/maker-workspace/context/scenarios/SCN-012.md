Scenario ID: SCN-012
Title: Show a clear state when search has no matches
Type: Edge Case
Approval status: approved
Approval session: SESSION-012
Approval cycle: 1

## Approved behaviour
When search finds no matching bookmarks, the app shows a clear “No bookmarks match your search” message rather than a blank list. The search box remains available so the person can adjust or clear the search and return to their list.

## Gherkin
Feature: Empty search results

  Scenario: Search has no matches
    Given bookmarks have been saved
    When the person enters a search that matches no title, description, or tag
    Then the app states that no bookmarks match the search
    And the search box remains available
    When the person adjusts or clears the search
    Then the bookmark list updates accordingly

## Assumptions
- A no-results message replaces the list area, not the search control.
