Scenario ID: SCN-033
Title: Import existing browser bookmarks with their history
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A person can choose a browser bookmark export, review a summary before making changes, and import the collection in one action. Browser folders become labels, including each level of nested folders. Original browser-given titles and the dates first bookmarked are preserved. Existing bookmarks are skipped without overwriting personal notes or edits, and the completion summary reports what happened.

## Gherkin
Feature: Importing browser bookmarks

  Scenario: Review and import a browser bookmark collection
    Given a browser bookmark file contains bookmarks, folders, titles, and original bookmark dates
    And some links already exist in the collection
    When the person chooses the file
    Then a review shows bookmark, folder, duplicate, and new-item counts
    And it shows that folders become labels
    And it shows sample original titles and dates
    And nothing is imported before confirmation
    When the person confirms the import
    Then all new bookmarks are added
    And browser folders become labels
    And original titles and bookmark dates are preserved
    And existing bookmarks are left unchanged with their notes and edits intact
    And a completion summary reports the outcome

## Assumptions
- The browser export includes bookmark titles, folder hierarchy, and original bookmark dates.
- Imported bookmarks begin outside Read later unless the import source carries an equivalent state.
