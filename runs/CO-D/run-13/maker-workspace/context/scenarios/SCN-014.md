Scenario ID: SCN-014
Title: Permanently delete a link (separate from archiving, with confirmation)
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

Deleting a link is a distinct, deliberate action, separate from archiving
(which stays reversible). Per entry, "Delete permanently…" lives inside the
entry's Edit view, set apart from the other controls. Choosing it asks for
confirmation ("Delete permanently? This can't be undone.") with Delete /
Keep. Only on confirmation is the link removed for good.

The client approved delete living inside Edit, separated and confirmed, as safe.

## Gherkin

Feature: Permanent deletion

  Scenario: Delete a link with confirmation
    Given an entry is open in the Edit view
    When the client chooses "Delete permanently" and confirms
    Then the link is removed permanently

  Scenario: Cancel a deletion
    Given the delete confirmation is shown
    When the client chooses "Keep"
    Then the link is not deleted

## Assumptions
- Deletion is irreversible (distinct from archive, which is reversible — SCN-003).
