Scenario ID: SCN-003
Title: Find a saved link again by search and by browsing tags
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

The client can find a saved bookmark again two ways, which also combine.

Search: a single search box filters the list as the client types. It matches
across the bookmark's title, site, full web address (URL), tags, page
description, and the client's note. Matching text is highlighted in the results.
A count shows how many of the total bookmarks match.

Browse by tag: all tags in use are shown as a row of filters, and every tag also
appears on each bookmark card. Clicking a tag filters the list to bookmarks with
that tag; clicking the active tag again clears it. Only one tag filters at a time.

Combine: a selected tag and a search term narrow the list together.

Ordering stays newest-first (per SCN-001).

## Gherkin

Feature: Find a saved link again

  Scenario: Search across all bookmark fields
    Given the client has several saved bookmarks
    When the client types text into the search box
    Then only bookmarks whose title, site, web address, tags, description, or note
         contain that text remain in the list
    And the matching text is highlighted
    And a count of matching bookmarks out of the total is shown

  Scenario: Browse by clicking a tag
    Given the client has several saved bookmarks with tags
    When the client clicks a tag (in the filter row or on a card)
    Then only bookmarks carrying that tag remain in the list
    When the client clicks the active tag again
    Then the tag filter is cleared and all bookmarks are shown

  Scenario: Combine a tag filter with search
    Given a tag filter is active
    When the client also types text into the search box
    Then only bookmarks that carry the tag AND match the text remain in the list

  Scenario: No matches
    Given a search term or tag filter that nothing matches
    Then the list shows a "no matches" state with a way to clear the filters

## Assumptions

- Search reach = title + site + full URL + tags + description + note.
  (Explicitly confirmed by the client, including the later-added description and
  URL reach.)
- Search filters live as the client types (search-as-you-type).
- Only one tag filters at a time. (Presented and accepted.)
- Matching text is highlighted in results. (Presented and accepted.)
