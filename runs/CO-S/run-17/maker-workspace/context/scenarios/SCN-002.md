Scenario ID: SCN-002
Title: Correct a bookmark's recognizable details inline
Type: Happy Path
Approval status: approved
Approval session: SESSION-002
Approval cycle: 1

## Approved behaviour

From a saved bookmark, the client chooses Edit details and corrects the title or description directly within that bookmark. Saving the changes returns the bookmark to its usual display with the correction in place and a brief confirmation that it was updated.

## Gherkin

Feature: Correct bookmark details

  Scenario: Correct a bookmark title or description inline
    Given a saved bookmark shows its title and description
    When the user chooses to edit its details
    Then editable title and description fields appear inline within that bookmark
    When the user changes the title or description and saves the changes
    Then the bookmark returns to its usual display
    And it shows the corrected title and description
    And a brief update confirmation is shown

## Assumptions

- Editing begins from an Edit details control on the bookmark.
- Quick correction includes the title and description, but not the website name or page address.
- The selected interaction is inline editing rather than a modal or side drawer.
- Changing the saved page address is recorded as a request for a later cycle.
