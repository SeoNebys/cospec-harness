Scenario ID: SCN-018
Title: Keep the collection stable during an incomplete search
Type: Error Case
Approval status: approved
Approval session: SESSION-018
Approval cycle: 1

## Approved behaviour
While a conditional search is incomplete, the collection remains unchanged and the unfinished query remains in the search box. A quiet, plain-language message explains that the search needs another condition or closing parenthesis. Results update immediately once the query becomes complete.

## Gherkin
Feature: Recover from an incomplete conditional search

  Scenario: Leave a grouped condition unfinished
    Given the full collection is visible
    When the person types "rome AND ("
    Then the collection remains unchanged
    And the unfinished query remains available to edit
    And a plain-language message says the search is incomplete

  Scenario: Complete an unfinished conditional search
    Given the person has typed an incomplete search
    When the person completes it as "rome AND #article"
    Then the message clears
    And matching results appear immediately

## Assumptions
- Incomplete search text is treated as work in progress, not a destructive error.
