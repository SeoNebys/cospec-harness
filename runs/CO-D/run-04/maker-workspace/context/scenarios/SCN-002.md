Scenario ID: SCN-002
Title: Review and correct page details while saving
Type: Happy Path
Approval status: approved
Approval session: SESSION-002
Approval cycle: 1

## Approved behaviour
After a person provides a web address, the page title and description appear
automatically for review before the bookmark is saved. The person may change
either field or leave both untouched. The saved bookmark keeps the reviewed
details and continues to open the original website.

## Gherkin
Feature: Bookmark details

  Scenario: Save corrected page details
    Given the person has provided a valid web address
    And the page title and description have been retrieved
    When the person changes the title or description before saving
    And saves the bookmark
    Then the bookmark shows the changed title and description
    And selecting the bookmark still opens the original website

  Scenario: Keep retrieved page details
    Given the person has provided a valid web address
    And the retrieved page title and description are shown for review
    When the person saves without changing those details
    Then the bookmark shows the retrieved title and description
    And selecting the bookmark opens the original website

## Assumptions
- Review happens after page details are retrieved and before the bookmark is saved.
- Both title and description can be edited independently.
- Reviewing details is part of every save, even when no correction is needed.
