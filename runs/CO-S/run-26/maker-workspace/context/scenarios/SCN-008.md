Scenario ID: SCN-008
Title: Edit a saved bookmark's details (including the web address)
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

Any saved bookmark can be edited. Editing opens a form on the bookmark where the
client can change the title, the web address (URL), the description, the tags
(add via typing/Enter, remove via the pill's ×), and the note. Saving applies the
changes to the bookmark; cancelling discards them.

When the web address is edited, it is validated the same way as on save: if it is
not a valid http/https address, saving is blocked and the address field is flagged
with an inline message, and no changes are applied. When a valid new address is
saved, the shown site name follows the new address.

Long content (very long titles, descriptions, notes, and many tags) wraps neatly
within the card and never overflows horizontally.

## Gherkin

Feature: Edit a saved bookmark

  Scenario: Edit text fields and tags
    Given a saved bookmark
    When the client opens edit, changes the title/description/note and adds or removes tags, and saves
    Then the bookmark shows the updated title, description, note, and tags
    When the client opens edit and cancels instead
    Then the bookmark keeps its previous values

  Scenario: Edit the web address with a valid value
    Given a saved bookmark in edit mode
    When the client changes the web address to a valid http/https address and saves
    Then the bookmark's address is updated
    And the shown site name reflects the new address

  Scenario: Reject an invalid web address while editing
    Given a saved bookmark in edit mode
    When the client changes the web address to an invalid value and tries to save
    Then saving is blocked
    And the address field shows an inline "not a web address" message
    And none of the bookmark's values are changed

  Scenario: Long content wraps within the card
    Given a bookmark with a very long title, description, note, and many tags
    Then all content wraps within the card without horizontal overflow

## Assumptions
- All of title, address, description, tags, and note are editable. (Confirmed.)
- Address editing uses the same validation as saving. (Confirmed by client.)
