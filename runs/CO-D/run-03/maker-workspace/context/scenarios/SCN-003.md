Scenario ID: SCN-003
Title: Correct auto-captured details, at save time and later
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Because automatic capture can get the title or summary wrong, the client can
correct them.

- At save time: the moment a link is saved, its title and summary appear as
  editable fields immediately, so the client can fix them without hunting for an
  edit control. Confirming keeps the changes.
- Later: any saved item has an Edit control that opens the same editable fields
  in place (inline on the card), not on a separate page or in a popup.

## Gherkin
Feature: Correct captured details

  Scenario: Edit right after saving
    Given the client just saved a link and details were auto-captured
    When the item is saved
    Then its title and summary are immediately editable in place
    And the client can change them and confirm without any extra navigation

  Scenario: Edit an existing item later
    Given a saved item exists
    When the client activates Edit on that item's card
    Then its title and summary become editable in place on the card
    And confirming saves the changes

## Assumptions
- Editing is inline on the card, not a separate page/popup. (Approved.)
- On save, the app drops straight into edit mode on the new item. (Approved.)
