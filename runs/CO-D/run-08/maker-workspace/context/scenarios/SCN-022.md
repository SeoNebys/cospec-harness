Scenario ID: SCN-022
Title: Preserve and reopen a page copy when bookmarking
Type: Happy Path
Approval status: approved
Approval session: SESSION-022
Approval cycle: 1

## Approved behaviour
When a new bookmark is saved, Link Home automatically captures a readable copy of the page as it was at that moment. A quiet line beneath the bookmark details says "Saved with page copy" and provides an Open copy action. Opening it shows the preserved version inside Link Home, clearly marked as captured when bookmarked, rather than visiting the live page.

## Gherkin
Feature: Preserve a page copy

  Scenario: Capture a readable copy while saving
    Given a readable page can be captured
    When the person saves its web address
    Then the bookmark is saved
    And a readable copy of the page at that moment is stored
    And the bookmark says "Saved with page copy"
    And an Open copy action is available beneath its details

  Scenario: Open the preserved copy
    Given a bookmark has a saved page copy
    When the person selects Open copy
    Then the preserved page opens inside Link Home
    And it is clearly identified as captured when bookmarked
    And the live page is not opened instead

## Assumptions
- Page capture is automatic for newly saved bookmarks.
- The page-copy action is visible but visually quiet beneath bookmark details.
