Scenario ID: SCN-013
Title: Open a bookmark's original link
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Selecting a bookmark (its title/card link) opens the original web address, in a new
browser tab. Opening a link never changes its reading state (see SCN-005). This
applies to active and archived bookmarks alike.

## Gherkin
Feature: Open the original link

  Scenario: Open a bookmark
    Given a saved bookmark
    When the client selects the bookmark's link
    Then its original web address opens in a new tab
    And its reading state is unchanged

## Assumptions
- Opens in a new tab so the app stays open.

## Related scenarios
- SCN-005 (opening never auto-marks read), SCN-007 (archived items still openable)
