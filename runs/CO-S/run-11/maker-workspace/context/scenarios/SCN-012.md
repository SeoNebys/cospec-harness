Scenario ID: SCN-012
Title: Permanently delete a bookmark with confirmation
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Any bookmark (in any tab, including Archived) can be permanently deleted. The
user activates Delete and is asked to confirm ("…will be permanently removed.
This can't be undone.") with the bookmark identified. Cancelling makes no change.
Confirming removes the bookmark permanently and it disappears from all lists and
counts. This is distinct from archiving: archive hides but keeps; delete removes
for good.

## Gherkin
Feature: Permanently delete a bookmark

  Scenario: Cancel keeps the bookmark
    Given the user activates Delete on a bookmark
    When the confirmation appears and the user cancels
    Then the bookmark is unchanged

  Scenario: Confirm deletes permanently
    Given the user activates Delete on a bookmark
    When the user confirms the permanent deletion
    Then the bookmark is removed from all lists and counts

## Assumptions
- Deletion always requires an explicit confirmation.
- Delete is available for archived bookmarks too.
- There is no undo after confirmation (permanent).
