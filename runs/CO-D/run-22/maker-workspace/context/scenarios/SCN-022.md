Scenario ID: SCN-022
Title: Archive a bookmark without deleting it
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
A person can archive a bookmark to remove it from the main collection view and normal search without deleting it. The archived count increases, the total number of bookmarks kept remains unchanged, and an immediate Undo action can reverse an accidental archive.

## Gherkin
Feature: Archiving bookmarks

  Scenario: Move a bookmark out of the active collection
    Given a bookmark is in the main collection
    When the person archives it
    Then it no longer appears in the main collection view
    And it is excluded from normal search
    And the Archived count increases
    And the total number of bookmarks kept stays unchanged
    And an Undo action is offered

  Scenario: Undo an archive action
    Given a bookmark was just archived
    When the person chooses Undo
    Then the bookmark returns to the main collection view
    And the Archived count returns to its prior value

## Assumptions
- Archiving is immediate and reversible.
- Archived bookmarks retain all stored information.
- Normal search excludes archived bookmarks by default.
