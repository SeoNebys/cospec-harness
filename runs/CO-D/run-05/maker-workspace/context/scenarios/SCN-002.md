Scenario ID: SCN-002
Title: Save a link even when the page lookup fails
Type: Error Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour

When the automatic page lookup fails (e.g. a slow or unreachable site), the user
is not blocked. A calm notice explains the details could not be fetched and that
the link can still be saved, with empty title/description fields ready for the
user's own input. The Save action remains available. If the user saves without
entering a title, the link itself is used as the title.

## Gherkin

Feature: Save a link

  Scenario: Lookup fails but saving is still possible
    Given the user enters a valid link whose page cannot be looked up
    When the lookup attempt finishes without details
    Then a calm notice explains the details could not be fetched and the link can still be saved
    And the title and description fields are empty and editable
    And the Save action is available

  Scenario: Save with no title falls back to the link
    Given a link is ready to save with an empty title field
    When the user presses Save
    Then the bookmark is saved using the link itself as its title

## Assumptions
- A failed lookup never disables the Save action.
- The user is never forced to type a title.
