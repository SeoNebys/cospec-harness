Type: Happy Path

## Approved behaviour

Alongside the remembered sort order and per-page count (SCN-014), the user can
choose a text size — Small, Medium (default) or Large — for the bookmark content.
It scales the bookmark content (titles, descriptions, sites, notes, tags); the
surrounding controls do not scale with it. The choice is remembered across visits
together with sort and page size.

## Gherkin

Feature: Display preferences

  Scenario: Change text size
    When the user selects a text size (Small, Medium or Large)
    Then the bookmark content (titles, descriptions, sites, notes, tags) scales accordingly
    And the surrounding controls do not scale

  Scenario: Text size is remembered
    Given the user has chosen a text size
    When the user returns in a later visit
    Then the same text size is applied, alongside the remembered sort and page size

## Assumptions
- Options are Small, Medium (default), Large.
- Text size applies to bookmark content only; it is remembered with sort and page size.
