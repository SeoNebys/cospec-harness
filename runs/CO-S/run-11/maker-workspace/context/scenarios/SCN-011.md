Scenario ID: SCN-011
Title: Archive a bookmark (hide from lists, keep recoverable)
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Separately from the To read / Finished reading status, a bookmark can be
archived. Archiving hides it from the normal To read and Finished lists and
places it in a dedicated "Archived" view (a third tab showing a count). Archived
bookmarks are recoverable: a "Restore" control returns the bookmark to the
normal lists. Restoring preserves the bookmark's previous reading status (a
finished-then-archived bookmark returns to Finished). Archived bookmarks are
excluded from normal search results (searching from To read/Finished never shows
archived items); they appear only when the Archived tab is selected. Archiving
is not deletion — nothing is lost.

## Gherkin
Feature: Archive bookmarks

  Scenario: Archive hides from normal lists
    Given a bookmark in To read or Finished
    When the user archives it
    Then it no longer appears in the To read or Finished lists
    And it appears in the Archived tab
    And the Archived count increases

  Scenario: Restore returns it with its reading status
    Given an archived bookmark that was Finished before archiving
    When the user restores it
    Then it returns to the Finished list
    And it is removed from the Archived tab

  Scenario: Archived items are excluded from normal search
    Given an archived bookmark matches a search term
    When the user searches from the To read or Finished view
    Then the archived bookmark is not shown
    And it is only found by viewing the Archived tab

## Assumptions
- Archived is a separate dimension from the To read/Finished reading status.
- Reading status is preserved across archive/restore.
- Archived items are out of scope for normal search by design.
