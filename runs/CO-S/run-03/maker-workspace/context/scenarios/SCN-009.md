Scenario ID: SCN-009
Title: Permanently delete a bookmark
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Permanent deletion is available from a bookmark's More actions menu whether or
not the bookmark was archived first. Choosing it opens a confirmation that names
the exact bookmark and states that deletion cannot be undone. Confirming removes
the bookmark completely, updates the library count, and does not offer Undo.
Cancelling leaves the bookmark unchanged.

## Gherkin
Feature: Permanently deleting bookmarks

  Scenario: Cancel permanent deletion
    Given a bookmark is in the library
    When the person chooses Delete permanently from its More actions menu
    Then a confirmation names the bookmark
    And states that deletion cannot be undone
    When the person cancels
    Then the bookmark remains unchanged

  Scenario: Confirm permanent deletion
    Given a bookmark is in the library
    When the person chooses Delete permanently from its More actions menu
    And confirms the named irreversible deletion
    Then the bookmark is removed completely
    And the library count decreases
    And no Undo action is offered

## Assumptions
- Permanent deletion is available for active and archived bookmarks.
- Delete permanently is tucked inside the More actions menu.
- Confirmation always names the affected bookmark.
