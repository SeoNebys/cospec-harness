Scenario ID: SCN-004
Title: Edit a saved link's title and description later
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
Each saved card offers an Edit action. The client can change the title and the
description at any time and save the changes, or cancel to keep the card as it
was. Auto-gathered details are not always helpful, so the client always retains
the ability to correct them.

## Gherkin
Feature: Editing saved details

  Scenario: Edit title and description of a saved link
    Given a saved card exists
    When the client presses Edit, changes the title and description, and presses "Save changes"
    Then the card shows the updated title and description

  Scenario: Cancel an edit
    Given the client is editing a saved card
    When the client presses Cancel
    Then the card keeps its previous title and description

## Assumptions
- Editing an empty title falls back to the domain rather than saving a blank title.
