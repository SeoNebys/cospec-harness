# R3-5: 탐색적 통계 검정 분석 계획

작성일: 2026-09-28. 현재 단계는 자료 점검과 분석 계획 수립이며, 검정은 아직 실행하지 않았다.

## 1. 목적과 범위

현재 기술통계에서 관찰된 공동 구축 요구사항 커버리지의 조건 간 차이를 탐색적으로 점검한다. 기존 결과를 이미 살펴본 뒤 수립한 계획이므로 사전등록된 확증 분석으로 표현하지 않는다. 검정 결과에 따라 비교나 지표를 추가·제외하지 않는다.

기존 150회 시행과 Claude·Codex Judge의 판정을 그대로 사용한다. 실험, Judge, 판정 지침, 참조 요구사항 매핑을 변경하지 않는다. 검정은 설정된 과제·모델·지침·실행 환경에서의 차이를 다루며 인간의 참여나 다른 과제에 대한 일반화를 입증하지 않는다.

## 4. 검정 방법

### 비교할 시행의 구성

동일한 `(실행 묶음, Maker, Director, Maker 추론 수준)` 안에서 A와 B 조건의 시행을 연결한다. 각 비교·Judge에 대해 5개 실행 묶음 × 6개 모델 설정 = 30쌍이 존재한다. 이는 실험 설계상의 설정과 실행 시기를 맞춘 비교이며, 동일한 LLM 세션이나 동일 난수로 생성된 응답을 반복 측정했다는 뜻이 아니다.

### 조건 라벨 교환을 제한한 양측 순열검정

각 쌍 내부에서만 A와 B 라벨을 교환하며, 서로 다른 실행 묶음이나 모델 설정 사이에서는 교환하지 않는다. 검정 통계량은 30쌍의 커버리지 차이의 평균이다. 차이는 퍼센트포인트(pp)로 제시한다. 현재 균형 설계에서는 이 값이 조건별 전체 평균의 차이와 같다.

귀무가설 하에서 각 쌍의 두 실행 위치에 A와 B를 배정한 것을 교환할 수 있다는 조건부 무작위화 논리를 사용한다. 원래 실행 순서는 묶음별 무작위 순열이었으므로 다른 조합의 위치를 고정한 채 같은 설정의 A/B 위치만 바꾸는 배정도 허용된다. 이 해석은 조건의 영향이 없다는 귀무가설과 시행 간 간섭이 없다는 가정에 의존한다. 순서 무작위화만으로 서비스 변화나 모든 시간 의존성이 제거되었다고 주장하지 않는다. 단순히 평균만 같다는 약한 귀무가설에 대한 검정으로 표현하지 않는다.

가능한 라벨 배정은 2^30개이다. 각 지표가 고정 분모의 정수 요구사항 수에서 계산되므로, 정수 차이 합의 분포를 동적 계획법으로 집계하여 모든 배정에 대한 정확 p값을 구한다. 근사 순열 표본이나 추가 난수 시드는 필요하지 않다. 양측 p값은 절대 차이 합이 관측값 이상인 배정의 비율이다. 차이가 0인 쌍도 두 배정을 모두 세고 분모에 포함한다. 모든 차이가 0이면 p=1이다.

이 방법은 설정을 합쳐 독립 동질 표본으로 취급하는 단순 Mann–Whitney 검정보다 이번 실행 설계를 직접 반영한다. 다만 심사자가 요구한 최소 비모수 탐색 검정의 한 형태이며, 모든 방법·태도·추론 수준의 상호작용을 추정하는 분석은 아니다.

### 다중 비교와 효과의 크기

16개 검정 전체를 하나의 검정군으로 묶어 Holm 보정을 적용한다. Judge별 유리한 결과만 선택하지 않는다. 양측 원래 p값과 보정 p값을 함께 저장하고, 보정 유의수준은 0.05로 둔다.

효과의 크기는 원래 척도인 평균 커버리지 차이(pp)로 보고한다. 조건별 표본 수·평균·표준편차와 함께 해석한다. 이번 최소 분석에서는 별도의 신뢰구간 추정이나 표준화 효과크기를 추가하지 않는다. 유의하지 않다는 결과를 동등성의 입증으로 해석하지 않으며, 같은 방향의 Judge 결과도 독립적 재현 실험으로 표현하지 않는다.

## 5. 다음 실행 단계와 산출물

1. 입력 해시, 시행 수, 설계별 균형, 결측 및 요구사항 수 재현을 실행 전 다시 확인한다.
2. 분석 전용 스크립트를 이 폴더에 작성한다. 실험 저장소의 실행·집계 스크립트는 수정하지 않는다.
3. 작은 인공 예시에서 모든 라벨 배정을 직접 열거한 결과와 동적 계획법 결과를 대조한다. 영차이, 동률, 비교 방향 반전 및 Holm 보정도 확인한다.
4. 16개 검정 결과와 연결된 시행 목록을 CSV로 저장하고, 방법·입력 해시·해석을 별도 Markdown으로 정리한다. 모든 결과를 보고한다.
5. 결과를 검토한 뒤 3장 분석 방법 → 4.3절 결과 → 5장 해석 → R3-5 답변 순으로 수정안을 제시한다. 원고는 해당 수정안 승인 후 반영한다.
