Scenario ID: SCN-003
Title: Return to an existing bookmark instead of duplicating it
Type: Edge Case
Approval status: approved
Approval session: SESSION-003
Approval cycle: 1

## Approved behaviour
When a person tries to save an address that is already in the collection, the app keeps the single existing bookmark rather than adding a copy. It plainly explains that the link is already saved, scrolls the existing bookmark into view, highlights it, and leaves its inline editing action available.

## Gherkin
Feature: Avoid duplicate bookmarks

  Scenario: Save an address that is already bookmarked
    Given a bookmark already exists for a web address
    When the person tries to save the same address again
    Then the collection still contains only one bookmark for that address
    And the app explains that the address is already saved
    And the app scrolls the existing bookmark into view
    And the app highlights the existing bookmark
    And the existing bookmark remains available for inline editing

## Assumptions
- Duplicate recognition is based on the saved web address.
- Returning to the existing bookmark does not automatically enter editing mode.
