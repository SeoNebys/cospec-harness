Scenario ID: SCN-007
Title: Preserve a copy of every saved link (PDF kept as original file)
Type: Happy Path
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When a link is saved, the app automatically preserves a copy of the page as it was
at save time — no separate action is required. Each card shows a "Saved copy" flag,
and the client can open a viewer to read the preserved copy. The viewer clearly
indicates it is a preserved copy captured on a given date, distinct from the live
original (which is still reachable by clicking the title). The preserved copy stays
in the library even if the original page later changes or goes offline.

The copy captures the page's readable content (text and structure), not a
pixel-perfect image. Exception: when the link points directly to a PDF, the
original PDF file is preserved as-is (page for page), not converted into a
reader-style page. Cards for PDF links indicate a "Saved PDF".

## Gherkin
Feature: Preserve a copy

  Scenario: Automatic copy on save
    Given the client saves a link
    Then a copy of the page is preserved automatically, dated at save time
    And the card shows a "Saved copy" (or "Saved PDF" for a PDF) indicator

  Scenario: View the preserved copy of a web page
    Given a saved non-PDF link
    When the client opens its saved copy
    Then the readable content captured at save time is shown
    And it is clearly marked as a preserved copy with its capture date

  Scenario: Preserve a direct PDF as its original file
    Given a saved link that points directly to a PDF
    When the client opens its saved copy
    Then the original PDF file is preserved and shown as-is, not rewritten

  Scenario: Copy survives loss of the original
    Given the original page later changes or goes offline
    Then the preserved copy remains available in the library

## Assumptions
- Capture is automatic for every saved link at save time.
- Non-PDF pages preserve readable content; direct-PDF links preserve the file.
- PDF is detected from the link (e.g. .pdf); precise detection finalised in
  implementation.
- Depth/limits of capture (login-gated pages, large media, storage) recorded as
  non-functional considerations for later.
