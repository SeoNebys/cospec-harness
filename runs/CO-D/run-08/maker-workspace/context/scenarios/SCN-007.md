Scenario ID: SCN-007
Title: Narrow label-filtered bookmarks with search
Type: Happy Path
Approval status: approved
Approval session: SESSION-007
Approval cycle: 1

## Approved behaviour
Search matches text in bookmark titles, descriptions, and source names without regard to capitalization. When a label filter is active, typing a search keeps that label selected and further narrows only the bookmarks carrying it.

## Gherkin
Feature: Search the bookmark collection

  Scenario: Search within a selected label
    Given the "javascript" label is selected
    And two bookmarks carrying that label are visible
    When the person searches for "guides"
    Then the "javascript" label remains selected
    And only labeled bookmarks whose title, description, or source contains "guides" are shown

  Scenario Outline: Search without regard to capitalization
    Given a bookmark contains the text "Guides" in its title, description, or source
    When the person searches for "<query>"
    Then that bookmark is included in the results

    Examples:
      | query  |
      | guides |
      | Guides |
      | GUIDES |

## Assumptions
- Search covers titles, descriptions, and source names.
- When bookmark notes are introduced, their text will also be searchable.
