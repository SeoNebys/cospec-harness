Type: Happy Path
Approval status: approved

## Approved behaviour
While viewing the Read later pile, marking a bookmark as read immediately removes its card from that view and decrements the visible count. The bookmark remains saved in the full collection.

## Gherkin
Feature: Read later

  Scenario: Work through the Read later pile
    Given two bookmarks are visible in Read later
    When the person marks one bookmark as read
    Then that bookmark immediately disappears from the Read later view
    And the visible count changes to one
    And the completed bookmark remains saved under All bookmarks

## Assumptions
- Read later updates immediately without a separate confirmation step.
