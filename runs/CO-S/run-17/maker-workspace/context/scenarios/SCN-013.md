Scenario ID: SCN-013
Title: Keep oversized bookmark cards scannable without hiding tags
Type: Edge Case
Approval status: approved
Approval session: SESSION-013
Approval cycle: 1

## Approved behaviour

A bookmark with a very long title, description, or note is compacted in the library so the list remains easy to scan. A Show full bookmark action expands the card to reveal all of its text. Tags are never hidden or cut off; all tags remain visible and wrap onto additional lines as needed.

## Gherkin

Feature: Display oversized bookmark content

  Scenario: Compact long text while keeping expansion available
    Given a bookmark has a very long title, description, or personal note
    When it is shown in the bookmark library
    Then its long text is compacted to keep the list scannable
    And a Show full bookmark action is available
    When the user chooses Show full bookmark
    Then the complete title, description, and note are shown

  Scenario: Keep all tags visible on an oversized bookmark
    Given a bookmark has more tags than fit on one line
    When it is shown in the bookmark library
    Then every tag remains visible
    And the tags wrap onto additional lines

## Assumptions

- Compaction applies to long title, description, and note text in library cards.
- Tags are recognition and finding aids and therefore are not compacted away.
