Scenario ID: SCN-027
Title: Reject text that is not a web address
Type: Error Case
Approval status: approved
Approval session: SESSION-027
Approval cycle: 1

## Approved behaviour
Only complete ordinary HTTP or HTTPS web addresses can be saved. If the entered text is not such an address, no bookmark is created, the person's typing remains in the save field, and a clear example shows how to correct it.

## Gherkin
Feature: Saving bookmarks

  Scenario: Enter text that is not a web address
    Given the bookmark collection is open
    When the person tries to save "my notes page"
    Then no bookmark is created
    And the entered text remains in the save field
    And the app shows an example of a complete web address

## Assumptions
- Supported bookmark addresses begin with HTTP or HTTPS.
