Scenario ID: SCN-005
Title: Remove a bookmark from its action menu
Type: Happy Path
Approval status: approved
Approval session: SESSION-005
Approval cycle: 1

## Approved behaviour
Each saved bookmark has a small action menu. A person deliberately opens that menu and chooses Remove. The bookmark disappears from the collection, the collection count decreases, and a brief removal confirmation is shown. A permanently visible Remove button is not shown beside every bookmark.

## Gherkin
Feature: Managing saved bookmarks

  Scenario: Remove a bookmark from its action menu
    Given the collection contains a saved bookmark
    When the person opens that bookmark's action menu and chooses Remove
    Then the bookmark is removed from the collection
    And the collection count decreases by one
    And a brief removal confirmation is shown

## Assumptions
- Removal is placed inside a small per-bookmark action menu.
- The remove action takes effect immediately.
- Recovery from accidental removal is explored separately as an edge case.
