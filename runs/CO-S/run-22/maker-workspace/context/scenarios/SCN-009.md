Scenario ID: SCN-009
Title: Empty states for no links and no matches
Type: Edge Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
When no links are saved at all, the list area shows a gentle message ("No links
saved yet. Save your first one above.") rather than a blank space. When a search or
tag filter (or read view) matches no links, the list shows a clear "no links match"
message appropriate to the situation, and the count reflects zero matches. The list
otherwise simply grows and scrolls, newest first, with no cap on the number of
saved links; long titles and notes wrap rather than breaking the layout.

## Gherkin
Feature: Empty and boundary states

  Scenario: No links saved yet
    Given the client has saved no links
    Then the list shows a friendly "no links saved yet" message

  Scenario: Search or filter with no matches
    Given links are saved
    When the active search, tag filter, or read view matches none of them
    Then a "no links match" message is shown
    And the count shows zero matching links

  Scenario: Many links or long text
    Given a large number of links or links with long titles/notes
    Then the list grows and scrolls newest-first without a cap
    And long text wraps without breaking the layout

## Assumptions
- Distinct empty messages for "nothing saved" vs "nothing matches".
- No cap on number of saved links.
- Long text wraps.
