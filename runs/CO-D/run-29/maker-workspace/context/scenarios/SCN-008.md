Scenario ID: SCN-008
Title: Write, format, read, and search personal bookmark notes
Type: Happy Path
Approval status: approved
Approval session: SESSION-008
Approval cycle: 1

## Approved behaviour
The client can write and save a full personal note for a bookmark. While writing, a formatted version is shown beside the note text and updates live. Friendly controls apply headings, bullet lists, and bold emphasis without requiring memorised notation. Recognised typed-symbol shortcuts also produce the same formatting. The formatted reading view contains no stray formatting symbols. Notes stay out of ordinary collection rows, but a matching search shows an explanatory excerpt from the note.

## Gherkin
Feature: Personal bookmark notes

  Scenario: Write and save a personal note
    Given a saved bookmark is open for editing
    When the client writes a personal note and saves the changes
    Then the full note is retained with that bookmark
    And searching for text from the note finds the bookmark

  Scenario: Format a note with friendly controls
    Given the client is writing a bookmark note
    When the client applies heading, bullet-list, or bold formatting with the corresponding control
    Then the selected text or lines receive that formatting
    And the formatted version updates live beside the note text

  Scenario: Format a note with a recognised typed shortcut
    Given the client is writing a bookmark note
    When the client types a recognised heading, bullet, or bold shortcut
    Then the formatted version updates live with that formatting

  Scenario: Read the full formatted note
    Given a bookmark has a note containing a heading, bullets, and bold emphasis
    When the client opens that bookmark's details
    Then the full note is visible in a formatted reading area beside the note text
    And no formatting markers are shown in the formatted reading area

  Scenario: Keep notes out of the ordinary collection row
    Given a bookmark has a personal note
    When the client views the unsearched collection
    Then the note is not shown on the bookmark row
    When a search matches text from the note
    Then a short note excerpt explains why the bookmark matched

## Assumptions
- The formatting controls are the primary interaction; typed shortcuts are optional conveniences.
- Supported note formatting in this cycle is headings, bullet lists, and bold emphasis.
- The side-by-side note layout is used on a computer-sized browser view.
