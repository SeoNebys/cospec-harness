Title: Saving without an address is blocked
Type: Error Case
Approval status: approved
Approval session: SESSION-001
Approval cycle: 1

## Approved behaviour
The link address is required. If the client attempts to save with the address
blank, nothing is saved and focus returns to the address field. Title and topic
may be left blank. Confirmed with the client in words (no distinct visual state
beyond the save being blocked).

    When the client clicks "Save link"
    Then no link is added
    And the address field receives focus

## Assumptions
- Only the address is mandatory; title and topic are optional.
